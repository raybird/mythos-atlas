# 蓋布 (Geb)

- **文化：** 埃及神話 (Egyptian Mythology)
- **職掌：** 大地、地震、植物生長、冥界之門的守護者

## 概述

蓋布爲古埃及大地之神，赫利奧波利斯九柱神(Ennead)中的重要成員。他是大氣之神舒(Shu)與濕氣女神泰芙努特(Tefnut)之子，天空女神努特(Nut)的兄弟與丈夫。蓋布的形象通常爲側臥於地面的男子——膝肘觸地形成丘陵與谷地，身體覆蓋綠色或黑色（象徵尼羅河淤泥與植物），頭上可能戴着鵝(Egyptian goose)或蛇。有時他被描繪爲綠膚色、頭戴上下埃及雙冠或阿特夫王冠。

蓋布的名字在埃及語中意爲「嘎嘎聲」——象徵地震時大地的轟鳴。他常被稱爲「眾神之父」，因他的子女包括歐西里斯、伊西斯、賽特與奈芙蒂斯——這四位神祇構成了埃及神話中最核心的神聖家族。

## 神話事蹟

**天地分離：** 蓋布與努特原本緊密擁抱——大地貼合天空，天地之間無空間。他們的父親舒(空氣之神)介入二者之間，以雙手高舉努特向上，腳踏蓋布使之向下——從此天地分離，創造了生命所需的空間。此神話中的舒代表「生命之氣」與「秩序」，將混沌的原初結合打破爲結構化的宇宙。埃及藝術中常見舒以雙手托舉努特的經典構圖，努特身體彎曲成穹頂覆蓋着平躺的蓋布。

**大地之父與王權傳承：** 蓋布在赫利奧波利斯神學中裁定荷魯斯與賽特之間的王位之爭——他判決荷魯斯應繼承歐西里斯的王位，此裁決後由拉神與眾神議會批准。蓋布因此被視爲王權合法性的最終擔保者。法老自稱「蓋布的繼承者」，強調其統治大地的神聖權威。

**大地之鎖與冥界通道：** 蓋布的身體即爲大地——他控制着植物生長所需的土壤與水分。他同時被認爲看守着通往冥界杜阿特(Duat)的入口，死者必須穿越大地的裂縫進入來世。部分《死者之書》咒語祈求蓋布允許死者進入冥界而不受阻礙。

**笑聲引發地震：** 民間傳說中蓋布的笑聲即爲地震——當他大笑時，大地隨之顫動。此解釋賦予這位嚴肅的神祇一絲人性化的幽默色彩。

## 跨文化對應

| 文化 | 對應神祇 | 共鳴點 |
|------|---------|--------|
| 希臘 | 蓋亞 (Gaia) | 大地母神，天地分離神話中的地母角色 |
| 中國 | 后土/地母 | 大地之神，與天相對 |
| 北歐 | 喬德 (Jörð)／弗麗嘉 (Frigg) | 大地女神，索爾之母 |
| 波利尼西亞 | 帕帕圖阿努庫 (Papatūānuku) | 地母，與天父朗吉努斯分離神話結構一致 |
| 印度 | 普里提維 (Prithvi) | 大地女神，與天父迪奧斯(Dyaus)爲伴侶 |
| 美索不達米亞 | 琪 (Ki) | 大地女神，被恩利爾分離於安(天) |

## 相關神祇

- **舒(Shu)：** 父親，大氣之神，以雙手分離蓋布與努特
- **泰芙努特(Tefnut)：** 母親，濕氣女神
- **努特(Nut)：** 妻子／妹妹，天空女神
- **歐西里斯、伊西斯、賽特、奈芙蒂斯：** 子女
- **荷魯斯：** 孫子，王位繼承爭議由蓋布裁決
