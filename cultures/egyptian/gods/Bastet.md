# 芭絲特 (Bastet)

- **文化：** 埃及神話 (Egyptian Mythology)
- **職掌：** 家庭、貓、音樂、舞蹈、歡樂、生育、保護

## 概述

芭絲特（Bastet，又稱 Bast、Ubaste）是埃及神話中最受喜愛的女神之一。她的名字源自「巴斯」（Bas）——一種裝香水或藥膏的罐子，暗示她與保護性的香膏相關。芭絲特最初（古王國時期，約前2686-2181年）被描繪為**獅首女神**——在下埃及的布巴斯提斯（Bubastis，今 Tell Basta）作為戰爭女神被崇拜，與上埃及的獅首女神塞赫麥特（Sekhmet）形成南北對應。然而隨著時間推移，芭絲特的形象經歷了埃及宗教史上最獨特的轉變：從兇猛的獅神軟化為溫和的**家貓女神**。

芭絲特是拉神（Ra）之女，通常被視為「拉之眼」的溫和面向——與塞赫麥特的毀滅性不同，芭絲特代表了太陽的保護與溫柔力量。她的主要崇拜中心布巴斯提斯是一座節慶之城——希羅多德在《歷史》中記載芭絲特的年度節慶是埃及最盛大的宗教集會之一，參與者乘船沿尼羅河而下，唱歌、拍手、跳舞，場面歡樂至極。

## 神話事蹟

### 貓的神聖化

芭絲特與貓的緊密關聯始於中王國時期（約前2055-1650年），當貓（Felis catus）在埃及被完全馴化後。埃及人注意到貓具有極強的矛盾特質：白天溫馴、夜晚警覺；對人類保護性強、對獵物攻擊性強。這些特質使貓被視為芭絲特在凡間的化身。殺死一隻貓——即使是意外——在埃及被視為重罪，可能判處死刑。

芭絲特的祭司在布巴斯提斯神廟中飼養大量貓隻，這些貓死後被製成木乃伊，埋葬在神廟周圍的貓墓地。僅布巴斯提斯一地就出土了數十萬具貓木乃伊——它們被作為朝聖者的祭品或護身符出售。這種貓木乃伊的規模化生產反映了芭絲特信仰在希臘化時代（托勒密時期）的極度普及。

### 芭絲特與「拉之眼」的轉化

芭絲特與哈托爾（Hathor）、塞赫麥特共享「拉之眼」（Eye of Ra）的稱號——她們是太陽之眼的三種形態：哈托爾是溫柔之愛、塞赫麥特是毀滅之怒、芭絲特是保護之盾。在一則神話中，拉神以他的眼睛創造了芭絲特——他的眼淚落入尼羅河，化為一隻野貓，這隻貓後來成為芭絲特。母親在生產時常佩戴芭絲特護符，因為芭絲特的貓形象被認為能保護產婦與新生兒免受蛇蠍傷害（貓是天生的蛇捕殺者）。

### 芭絲特的節慶

希羅多德《歷史》卷二第60章記載了布巴斯提斯的芭絲特節：「每年當他們前往布巴斯提斯時，他們這樣做：男人和女人一起乘船，每艘船上有許多人，女人們拍著手鼓，男人們吹著笛子……當他們經過一個城鎮時，他們將船靠近岸邊，一些女人繼續唱歌，另一些女人向岸上的女人呼喊嘲笑，還有一些女人跳舞……抵達布巴斯提斯後，他們舉行盛大的獻祭，在節日期間消耗的葡萄酒比一年中其他時間的總和還多。」這段描述顯示芭絲特的節慶是埃及最具解放性的節日——社會階級與性別規範在節日期間被暫時懸置。

## 跨文化對應

| 埃及 | 跨文化對應 |
|------|-----------|
| 芭絲特（家貓女神，家庭與音樂的守護者） | ↔ 北歐弗蕾亞（Freyja，貓戰車女神、愛與豐饒） |
| 芭絲特（獅首到貓首的形象轉變） | ↔ 印度杜爾迦（Durga，乘獅戰神，女神的保護與毀滅雙面性） |
| 芭絲特（保護產婦與新生兒） | ↔ 希臘阿耳忒彌斯（Artemis，生育守護與動物之母） |
| 芭絲特的狂歡節慶 | ↔ 希臘酒神節（Dionysia，迷醉與社會階級懸置） |
| 芭絲特（音樂與舞蹈的女神） | ↔ 希臘繆斯（Muses，歌舞與藝術的靈感） |
| 貓作為芭絲特的凡間化身 | ↔ 日本貓又（Nekomata，貓的超自然化身） |
| 芭絲特從戰神轉為家庭保護神 | ↔ 中國灶神（從早期火神轉為家庭守護神） |

## 相關神祇

- **Sekhmet（塞赫麥特）** — 芭絲特的獅首對應面，毀滅與戰爭女神，芭絲特在古王國時期的原始形態
- **Hathor（哈托爾）** — 拉之眼的第三種形態，芭絲特在節慶與歡樂面向的對應
- **Ra（拉）** — 芭絲特之父，太陽神
- **Maat（瑪亞特）** — 宇宙秩序女神，芭絲特作為家庭守護者時協同瑪亞特維護和諧
- **Taweret（塔沃瑞特）** — 河馬女神，與芭絲特同樣保護孕婦與新生兒
- **Bes（貝斯）** — 矮人家庭保護神，與芭絲特共同構成埃及家庭保護神系

## 出現在

- 金字塔文本（Pyramid Texts，古王國時期對芭絲特的最早記載）
