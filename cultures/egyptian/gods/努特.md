# 努特 (Nut)

- **文化：** 埃及神話 (Egyptian Mythology)
- **職掌：** 天空、星辰、晝夜循環、死者保護、宇宙之母

## 概述

努特爲古埃及天空女神，赫利奧波利斯九柱神之一，宇宙架構的核心支柱。她是大氣之神舒(Shu)與濕氣女神泰芙努特(Tefnut)之女，大地之神蓋布(Geb)的姊妹與妻子。她的身體彎曲成穹頂覆蓋大地——她的雙手與雙腳觸及地平線的四個方位，身體上綴滿星辰。埃及人相信太陽每晚被努特吞入口中，次日清晨重新從她兩腿之間誕生。

努特的形象在埃及藝術中極具辨識度：裸體女性以弓形姿態跨越天空，身體常繪有金色星辰，雙臂與雙腿分別觸地——有時她以母牛的形象出現（「天上的母牛」），或在棺槨內側以保護死者。她的名字在埃及語中與「天空」同義。

## 神話事蹟

**天地分離與宇宙秩序：** 努特原與蓋布在原始混沌中緊緊擁抱——天地之間無分別。其父舒強行介入，高舉努特向上——從此天空與大地分離，創造了生命所需的空間。努特的身體成爲分隔宇宙之水（上界之水與下界之水的界線）的屏障。太陽船每日沿努特的身體航行，從東方上升至西方沉沒。

**吞食太陽與星辰的誕生：** 努特每日清晨以「天上的母牛」姿態誕生太陽神拉，黃昏時太陽被努特吞入口中——太陽夜間在努特的體內（即天空內部）航行。此神話解釋了晝夜循環：太陽在天空女神體內穿越冥界，次日晨重新出生。同樣地，星辰是努特身體上的裝飾——它們在夜間可見而白天被她的光芒遮蔽。

**死者之母：** 努特同時是死者進入天空來世的保護者。棺槨內側常繪有努特的形象——死者被置於她的保護之下，彷彿回到宇宙母親的子宮等待重生。《死者之書》中死者祈求「願努特給予我她身體中的位置」，象徵死者像太陽一樣穿越努特的身體獲得新生。金字塔文中法老被描述爲「努特之子」，死後升天與母親團聚。

**詛咒中的懷孕：** 拉神曾詛咒努特——不得在任何月份中的任何一天懷孕。智慧神托特以棋賽從月神孔蘇(Khonsu)手中贏得額外的五天（埃及曆法之外的「Epagomenal days」），努特在此五天中生下了歐西里斯、荷魯斯(大荷魯斯/哈羅埃里斯)、賽特、伊西斯與奈芙蒂斯。此神話解釋了埃及曆法中360天加5天節日的起源，也奠定了五神誕生的神聖脈絡。

## 跨文化對應

| 文化 | 對應神祇 | 共鳴點 |
|------|---------|--------|
| 中國 | 女媧 | 補天（修復天空）、創世女神、天地秩序 |
| 希臘 | 蓋亞 (Gaia) — 大地／烏拉諾斯 (Ouranos) — 天空 | 天空作爲天父，而努特爲天母——性別逆轉 |
| 波利尼西亞 | 朗吉努斯 (Ranginui) | 天父與地母帕帕分離，結構與舒分離蓋布與努特完全相同 |
| 美索不達米亞 | 提亞瑪特 (Tiamat) | 原水女神／混沌之龍，被馬爾杜克分裂爲天地 |
| 印度 | 阿卡莎 (Akasha) | 代表天空/空間的宇宙元素 |
| 芬蘭 | 伊爾瑪塔 (Ilmatar) | 水/空氣之母，宇宙蛋在其膝上孵化 |

## 相關神祇

- **舒(Shu)：** 父親，以雙手分離並支撐努特
- **蓋布(Geb)：** 丈夫/兄弟，大地之神
- **歐西里斯、伊西斯、賽特、奈芙蒂斯：** 在五天節日中所生的子女
- **拉(Ra)：** 每日從努特體內誕生的太陽神
- **托特(Thoth)：** 以智慧幫助努特贏得額外懷孕天數

## 出現在

- 金字塔文第1-200節：法老升天與努特的重聚
- 棺槨文與死者之書中保護死者的咒語
- 塞提一世墓與拉美西斯六世墓的天花板星象圖
- 登德拉神廟的天文天花板——努特作爲天空女神的經典描繪
