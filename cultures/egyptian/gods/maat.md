# 瑪亞特 (Ma'at / 𓐙𓌴𓂣𓏏𓁦)

- **文化：** 埃及神話 (Egyptian Mythology)
- **職掌：** 真理、正義、宇宙秩序、社會和諧

## 概述

瑪亞特（Ma'at）是埃及神話中最核心也最抽象的神祇之一——她不是以具體的擬人化神話事蹟聞名，而是作為一種宇宙原則（Order / Cosmic Balance）的化身。她的名字在埃及語中同時指涉「真理」、「正義」、「秩序」與「和諧」，是貫穿整個古埃及文明三千年歷史的終極價值。瑪亞特通常被描繪為一位頭戴鴕鳥羽毛的女性——這根羽毛正是她最具辨識度的象徵物。

瑪亞特在創世神話中出現於原初之丘（Benben）從混沌之水（Nu）中升起之時。造物主（拉或阿圖姆）將她安置於世間，以替代混沌的力量。從此，瑪亞特成為宇宙運行的根本法則：太陽每天準時升起、尼羅河每年週期性氾濫、星辰在夜空中有序運行——這一切都是瑪亞特的表現。在人類社會層面，法老的職責即是「維護瑪亞特」，確保國家與社會的運作符合宇宙秩序。法老登基時被稱為「瑪亞特之主」，所有法律與政策都必須以瑪亞特為依據。

來世審判中，瑪亞特的角色至關重要。死者的心臟被放置在瑪亞特羽毛天平的左端，羽毛在右端。若心臟與羽毛完全平衡，證明死者生前遵循了瑪亞特，即可進入來世樂園（Field of Reeds）；若心臟比羽毛重（代表罪惡），則被一旁的怪物阿米特（Ammit，鱷魚頭獅子上身河馬下身）吞噬，形神俱滅。這套「天平審判」體系是埃及宗教對世界宗教倫理思想最重要的貢獻之一。

## 跨文化對應

| 文化 | 概念／神祇 | 對應關係 |
|------|----------|---------|
| 希臘 | 泰美斯 (Themis) | 正義與秩序女神，天理的法律化身 |
| 希臘 | 迪克 (Dike) | 人間正義的執行者 |
| 波斯 | 阿沙 (Asha) | 真理／宇宙秩序，與瑪亞特的平行極其精確 |
| 印度 | 梨多 (Ṛta) | 宇宙秩序，真理的法則 |
| 中國 | 道 (Dao / 天道) | 宇宙運行的根本法則 |
| 北歐 | 厄格 (Ørlog) | 命運與宇宙法則 |

## 相關神祇
- **Ra**：太陽神，瑪亞特的女兒或姊妹（不同傳統）
- **Thoth**：智慧與書寫之神，協助瑪亞特監督天平
- **Osiris**：冥界審判的主持者
- **Ammit**：審判失敗者的吞噬者
