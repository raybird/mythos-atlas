# 托特 (Thoth)

- **文化：** 埃及神話 (Egyptian Mythology)
- **職掌：** 智慧、書寫、月亮、魔法、度量與時間

## 概述

托特爲古埃及智慧與書寫之神，朱鷺首人身或狒狒形象。他是衆神之書記官——記錄一切言語、思想與審判結果。托特被視爲文字（象形文字）、算術、幾何、天文學、魔法與醫學的發明者，相當於埃及文明的「知識總管」。希臘人將其對應於赫爾墨斯（Hermes Trismegistus），認爲他祕傳了占星術與煉金術。

托特的頭冠爲新月承託滿月——象徵其與月亮的聯繫。他是太陽神拉的「舌頭」或「心臟」，時常代理拉執行宇宙秩序（Maat）。托特的祭祀中心在赫爾莫波利斯（Hermopolis），此處神學將托特視爲創世者——以言語從原水中創造萬物。

## 神話事蹟

**荷魯斯與賽特的裁決者：** 荷魯斯與賽特爭奪埃及王權的訴訟持續了八十年，眾神議會分裂爲兩派。托特以公正書記官記錄每一證詞，並以智慧引導裁決——他寫信給已故的歐西里斯徵詢意見，最終促使眾神將王權判歸荷魯斯。托特在這場神話中最著名的扮演了「法律程序守護者」的角色。

**死者之心的秤量：** 在《死者之書》第125章的審判場景中，托特站在天平旁，記錄死者心臟與瑪亞特羽毛的對比結果。他宣告：「心臟爲善者，將進入蘆葦之野；心臟爲惡者，將被阿穆特（Ammit，吞噬獸）吞食。」托特的名義意味「秩序之度量」——他確保審判過程的絕對公正。

**魔法的傳承：** 托特被認爲撰寫了四十二卷祕密之書——其中包含宇宙的知識、咒語與儀式。傳說法老胡夫的兒子哈德傑夫（Hardjedef）發現了托特的祕密書卷，獲得理解動物語言與召喚眾神的能力。

**圖特之月：** 托特在一次與月神孔蘇（Khonsu）的賭博中贏得額外的「五分之一的日光」，將其分割爲五日——這五日被加入埃及曆法（原本360日），使努特得以在這五日中生下歐西里斯、荷魯斯（此處指長者荷魯斯）、賽特、伊西斯、奈芙蒂斯五神。

## 跨文化對應

| 文化 | 對應神祇 | 共鳴點 |
|------|---------|--------|
| 美索不達米亞 | 恩基/埃亞 (Enki/Ea) | 智慧、水、創造、文字 |
| 希臘 | 赫爾墨斯 (Hermes) | 信使、智慧、煉金術（Hermetica） |
| 北歐 | 奧丁 (Odin) | 智慧追尋、文字（如尼文）的發現者 |
| 中國 | 倉頡 | 造字、四目象徵 |
| 日本 | 菅原道真（天神） | 學問之神 |
| 印度 | 梵天 (Brahma) | 知識、創造、吠陀的源頭 |

## 相關神祇

- **拉：** 太陽神，托特常伴其左右
- **瑪亞特（Maat）：** 秩序女神，托特在審判中共同合作
- **荷魯斯：** 托特在繼承權訴訟中支持其正統地位
- **賽特：** 訴訟中的對手陣營
- **伊西斯：** 托特教導伊西斯魔法，協助其復活歐西里斯

## 出現在

- 希臘化時期赫爾墨斯主義（Hermeticism）的源頭
