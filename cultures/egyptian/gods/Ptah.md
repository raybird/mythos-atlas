# Ptah — 孟斐斯的創造主神

- **文化：** 埃及神話 (Egyptian Mythology)
- **中心崇拜：** 孟斐斯（Memphis / Ineb-hedj）
- **職掌：** 創造、工藝、建築、雕塑、萬物之言

## 概述

Ptah（普塔）是古埃及孟斐斯神學體系中的最高創造神，以「心之思維、舌之言語」創造宇宙萬物——祂先在心中構想，再以口說出，萬物便應聲而成。這一「言成肉身」的創造模式是人類最早的「道成宇宙」（Logos）思想之一，比希臘的 Logos 與《聖經·約翰福音》的「太初有道」早了至少兩千年（Allen 1988: 38-45）。

Ptah 的形象為一尊包裹在白色緊身長袍中的木乃伊化男子，手持三合一權杖（Was-scepter、Ankh 生命之符、Djed 柱），頭戴緊貼頭顱的深藍色圓帽。祂是工匠、建築師與金屬匠人的守護神，希臘人將祂與 Hephaestus 對應，反映出兩位神祇在工藝領域的平行地位。

## 神話事蹟

### 孟斐斯神學：心與舌的創造

在沙巴卡石碑（Shabaka Stone，第25王朝，約西元前710年）所記載的孟斐斯神學中，Ptah 被置於一切眾神之上。傳統的赫利奧波利斯九柱神（Ennead）體系被重新解釋為 Ptah 的顯現——Atum（創世神）是 Ptah 的心與舌，九柱神不過是 Ptah 的感官與元素的具現化。

此文本描述 Ptah 為「眾神背後的終極力量」，祂的創造包括：
1. **諸神**：經由祂的牙齒與嘴唇產生眾神之名
2. **城市**：祂建立諾姆（nome）行政區與聖殿
3. **秩序**：祂建立 Maat（宇宙秩序）
4. **食物**：祂使尼羅河氾濫供養眾生

這種「萬物由言語創生」的概念在比較神學中極為重要，因為它代表了一個高度抽象化的單一創造主思想，與埃及其他地方的多元神話形成了鮮明對比。

### 保護者與治癒者

Ptah 也被視為治癒之神。在拉美西斯二世的年代，一尊 Ptah 雕像據說能醫治疾病——信徒向雕像祈禱後在祂附近睡夢中尋求治癒指示（incubation）。此外，Ptah 也是塞提一世與拉美西斯二世等法老的個人保護神，法老在建築項目中經常向 Ptah 致敬。

### 與其他神祇的關聯

- **Ptah-Sokar-Osiris**：晚期埃及將 Ptah 與孟斐斯的墓地之神 Sokar 以及冥王 Osiris 合併，形成三位一體的冥界之神（Ptah-Sokar-Osiris）
- **Ptah-Tatenen**：與原始丘之神 Tatenen 合併，強調祂作為大地原始力量的面向
- **Apis 公牛**：孟斐斯的 Apis 神牛被視為 Ptah 在地上的活化身

## 跨文化對應

| 文化 | 對應神靈／概念 | 共通點 |
|------|-------------|-------|
| 希臘 | Hephaestus | 工匠與冶金之神 |
| 希臘 | Logos（赫拉克利特、斯多噶派） | 言語創造宇宙秩序 |
| 基督教 | 約翰福音「太初有道」 | 道（Word）創造萬物 |
| 印度 | 梵天＋辯才天女（Vāc） | 言語即創造之力（Vāc） |
| 中國 | 盤古＋「太初有言」 | 創世與語言的類比 |
| 美索不達米亞 | Ea／Enki | 智慧與創造之神，工匠的保護者 |
| 北歐 | 侏儒工匠（Dvergar） | 工藝、冶金、打造神器 |

## 相關神祇

- **Sekhmet**：Ptah 的妻子，獅頭戰爭女神
- **Nefertem**：Ptah 與 Sekhmet 之子，蓮花之神
- **Imhotep**：歷史人物被神化為 Ptah 之子，建築與醫學之神
- **Apis**：Ptah 的活化身（神牛）
