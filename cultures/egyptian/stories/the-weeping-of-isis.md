# 伊西斯的悲泣：奧西里斯之淚與哭喪的起源 (The Weeping of Isis)

- **文化：** 埃及神話 (Egyptian Mythology)

## 故事背景

在歐西里斯（Osiris）被賽特（Seth）殺害肢解後，其妻伊西斯（Isis）與奈芙蒂斯（Nephthys）踏上漫長而艱辛的搜尋之旅，收集丈夫散落於埃及各地的遺體。這則神話不僅敘述了一段愛情與復仇的故事，更解釋了埃及哭喪儀式、尼羅河泛濫的季節性節奏，以及王后在葬儀中扮演「伊西斯」角色的宗教傳統。伊西斯的悲泣被視為埃及文明中最深刻的哀悼典範——一位女神以淚水與堅毅對抗混沌，最終使亡者復活、秩序重建。

## 情節

### 第一幕：背叛與殺戮

歐西里斯統治黃金時代的埃及，教導人類農耕、法律與宗教。他的弟弟賽特嫉妒其權力，策劃了一場致命的宴會。賽特命人打造一個精美的棺木，在宴會上宣布：「誰能完美 fitting 進這個棺木，就能獲得它。」歐西里斯試躺其中，賽特的追隨者立即釘上蓋子，將棺木投入尼羅河。棺木隨河水漂至腓尼基的比布魯斯（Byblos），被一棵巨大的神樹包裹。

伊西斯得知丈夫遇害後，她的悲慟不僅是個人的喪夫之痛，更是一種宇宙性的創傷——秩序之神的死亡意味著混沌的擴張。她剪下自己的一縷頭髮，穿上喪服（這成為埃及女性 mourning 服裝的原型），踏上了搜尋之旅。

### 第二幕：悲泣與搜尋

伊西斯在尼羅河三角洲的沼澤地中搜尋歐西里斯的棺木。她沿途哭泣，淚水滴入河中——據說正是伊西斯的淚水引發了尼羅河每年的泛濫（Akhet，洪水季，每年6月至9月）。在《切斯特·比提紙莎草卷一》（Chester Beatty Papyrus I）中，伊西斯的哭聲被描述為「天地為之動容」的聲音。

伊西斯與奈芙蒂斯聯手搜尋。奈芙蒂斯以鴟鰲（野雁）的形象飛翔於沼澤地上空，而伊西斯則化為一隻燕子在河岸邊低飛搜索。在三角洲的比布魯斯，她發現了包裹歐西里斯的神樹——已被國王砍下製成宮殿的柱子。伊西斯以魔力迫使國王交出棺木。

### 第三幕：賽特的第二次侵害

伊西斯將棺木帶回埃及，藏在三角洲的沼澤深處，使用魔法使其復活。但賽特在夜間狩獵時發現了棺木——憤怒地將歐西里斯的遺體切成十四塊（對應埃及的十四個諾姆），散佈於埃及各地。伊西斯與奈芙蒂斯再次出發，乘著紙莎草船沿尼羅河而上，逐一收集這些碎片。每找到一塊，伊西斯就在當地舉行葬儀——這就是為何埃及各地都有「歐西里斯墓」的原因。最終，除了生殖器（被魚類吞噬）外，伊西斯收集了歐西里斯遺體的十三個部分。

### 第四幕：魔法復活與荷魯斯的誕生

伊西斯以咒語將歐西里斯的遺體重新組合，並以魔法創造了一個替代的生殖器。她化為一隻鳥（隼或蜂鷹），與歐西里斯的遺體結合，懷上了荷魯斯（Horus）。歐西里斯的復活不是永久性的——他不能返回陽間，而是成為冥界（Duat）的統治者。伊西斯在沼澤中秘密生下荷魯斯，獨自撫養他長大，同時保護他免受賽特的侵害。她將荷魯斯藏在尼羅河三角洲的紙莎草叢中，用魔法驅趕蛇蠍與危險動物——這就是伊西斯作為「母親與保護者」形象的起源。

### 第五幕：哭喪儀式的神話根源

伊西斯的悲泣被視為埃及哭喪儀式（*ḏr.t*）的神聖原型。在埃及葬儀中，女性哭喪者（professional mourners）扮演伊西斯與奈芙蒂斯的角色，以有節奏的哭號、抓撓面部與胸部的動作，再現兩位女神尋找歐西里斯碎片時的悲慟。這種儀式被稱為 *ḏr.t*（字面意為「搜尋」或「收集」），其核心功能不僅是表達哀悼，更是透過模仿神話中的行為來激活復活的力量。

王后在法老葬儀中扮演「伊西斯」的角色——她以伊西斯的名義悲泣，象徵著王室復活的保證。在新王國的法老墓室壁畫中，伊西斯與奈芙蒂斯常以 mourning 姿態出現於石棺兩側——她們展翅保護死者，雙手舉起悲慟的姿勢。

## 跨文化平行

| 埃及伊西斯的悲泣 | 跨文化對應 |
|----------------|-----------|
| 伊西斯搜尋歐西里斯碎片並復活之 | ↔ 希臘波瑟芬妮（Persephone）的冥界往返——兩者都涉及死亡與季節性重生 |
| 伊西斯的淚水引發尼羅河泛濫 | ↔ 巴比倫伊南娜（Inanna）下冥界——女神的離去/悲傷導致大地荒蕪或洪水 |
| 奈芙蒂斯以鴟鰲形搜尋 | ↔ 希臘雅典娜的貓頭鷹——鳥類作為智慧/搜尋的象徵 |
| 歐西里斯被肢解後碎片散佈各地 | ↔ 希臘狄奧尼索斯（Dionysus）被泰坦肢解後重生——死而復生神話的共同結構 |
| 伊西斯單獨撫養荷魯斯 | ↔ 聖母瑪利亞獨自撫養耶穌——神聖母親與受威胁孩童的原型 |
| 哭喪儀式作為復活的魔法行為 | ↔ 希臘哀歌體（threnos）與狄奧尼索斯祭典中的悲慟儀式 |
| 伊西斯化為鳥與歐西里斯結合 | ↔ 芬蘭呂希（Louhi）偷走鐵的片段中動物變形元素 |
| 伊西斯與奈芙蒂斯的姊妹聯盟 | ↔ 北歐弗蕾雅與弗麗嘉的女性神聖聯盟 |
