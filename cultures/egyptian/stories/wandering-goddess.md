# 流浪的女神：拉之眼的回歸 (The Return of the Distant Goddess)

- **文化：** 埃及神話 (Egyptian Mythology)

## 故事背景

在埃及神話的深層結構中，「拉之眼」（Eye of Ra）不僅是太陽神的一隻眼睛，更是一個獨立的神聖存在——她是拉的女性化身，兼具摧毀與保護的雙重力量。這則神話講述了拉之眼化身為獅首女神，因憤怒逃離埃及、流浪於努比亞沙漠，最終被說服歸返的故事。此神話不僅解釋了埃及節慶的起源，更暗示了上下埃及的統一以及埃及與努比亞之間的緊張關係。

## 情節

### 第一幕：太陽的憤怒

在埃及秩序井然的早期時代，拉神（Ra）以他的眼睛——太陽之眼——照耀世界，維持瑪亞特（Maat，宇宙秩序）的運行。但有一天，拉之眼對拉產生了無法平息的憤怒。不同的版本對憤怒的原因有不同的說法——塞赫麥特（Sekhmet）版本說她因拉阻止她繼續屠殺人類而憤怒，特夫努特（Tefnut）版本說她與父親發生爭執，還有一說她嫉妒拉對其他女神的偏愛。

無論原因為何，拉之眼——以獅首或貓首女神的形態——向南逃往努比亞（今蘇丹地區）。她化身為一隻兇猛的獅子（或貓），在努比亞沙漠中獨自流浪。她的離開對埃及造成了災難性的後果：太陽失去了它的保護之眼，黑暗的威脅籠罩大地；尼羅河水位下降，莊稼枯萎；沙漠中的邪惡力量（阿波菲斯之蛇的勢力）趁機開始擴張。

### 第二幕：托特的化妝

拉神決心將他的眼睛帶回埃及。他召來舒（Shu，空氣之神）和托特（Thoth，智慧之神）——這對組合具有獨特的說服力：舒是拉之眼的兄弟（另一說為她的丈夫），能以親情打動她；托特則能以智慧與語言的力量說服她。

托特採取了一個大膽的策略：他沒有以神的形態接近——因為他預見女神處於戰鬥狀態，會攻擊任何接近者。他變化為一隻狒狒（狗頭狒狒，Papio hamadryas）——這種動物在當時的埃及文化中被視為具有智慧與書寫能力的靈獸——然後以這個形態穿越沙漠，接近女神所在的地方。這是一個充滿智慧的僞裝：一隻狒狒不像一個神那樣具有威脅性，而且狒狒的跳躍與鬼臉能夠緩解緊張氣氛。

### 第三幕：努比亞的談判

托特在努比亞荒野中找到了拉之眼——她正以獅子的姿態守護著一塊水泉。托特用一個巧妙的故事開始對話。在《切斯特·比提紙莎草卷一》（Chester Beatty Papyrus I）中，托特對拉之眼講述了一個「獅子與老鼠」的寓言：一隻獅子嘲笑一隻老鼠的渺小，但後來當獅子被獵人逮捕時，正是這隻老鼠咬斷繩索救了他——這個故事暗示即使是強大的存在也需要和諧與回歸，並提醒女神憤怒與孤立最終是沒有意義的。

舒同時以兄弟的身份與她對話，提醒她在埃及的職責、她的神殿、她的人民的思念。女神動搖了，但仍有顧慮——她擔心回歸後自己的地位會被削弱，擔心再次被忽視。托特向她保證她的榮耀只會增加，而且她的回歸將被永遠銘記——這就是後來埃及每年慶祝的「流浪女神回歸節」的由來。

### 第四幕：回歸與狂歡

拉之眼最終同意返回埃及。當她跨越埃及邊界回到埃及領土時，尼羅河的水位立即恢復，河兩岸開滿了花朵。拉神為他的眼睛舉行了一場盛大的歡迎宴會——據說這就是芭絲特節（布巴斯提斯節）和哈托爾節的起源。人民以音樂、舞蹈、葡萄酒和歡樂迎接女神的歸來——這就是為什麼芭絲特節被描述為埃及最快樂的節日，充滿了歌唱、拍手鼓、飲酒和男女無拘無束的狂歡。節慶的核心儀式——飲用紅啤酒（模仿塞赫麥特醉酒的神話）——實際上是女神從憤怒到平靜、從流浪到回歸的轉化象徵。

### 第五幕：神話的意義

「流浪的女神」神話不僅僅是娛樂性的故事。埃及學家認為此神話具有多層次的象徵意義：（1）天文層次——象徵太陽在一年中的南北移動（陽光「逃離」又「回歸」）；（2）地理政治層次——暗示上下埃及的統一與對努比亞的資源獲取；（3）儀式層次——解釋了埃及節慶中狂歡、飲酒與音樂的起源；（4）心理層次——女神從獅子的暴怒到貓的溫柔的轉化，反映了人類情緒從憤怒到平靜的自然過程。芭絲特（Bastet）——貓首女神——正是這個轉化的終點：拉之眼從塞赫麥特的獅首（毀滅）到芭絲特的貓首（保護）再到哈托爾的牛首（溫柔養育），完成了她的回歸與轉化之旅。

## 跨文化平行

| 埃及流浪女神 | 跨文化對應 |
|------------|-----------|
| 拉之眼逃離至努比亞，埃及失去保護 | ↔ 美索不達米亞伊南娜下冥界（女神離去導致大地荒蕪） |
| 托特化身狒狒以故事說服女神回歸 | ↔ 希臘荷米斯以音樂與故事說服阿波羅（荷米斯偷牛神話） |
| 獅子與老鼠的寓言 | ↔ 伊索寓言中同一故事的埃及起源版本 |
| 女神的憤怒→流浪→回歸→節慶 | ↔ 希臘波瑟芬（Persephone）的冥界來回與四季節慶 |
| 太陽之眼逃離導致大地黑暗 | ↔ 北歐巴德爾之死導致光明消失與諸神黃昏 |
| 紅啤酒儀式化裝醉與狂歡 | ↔ 印度侯麗節（Holi）的色彩狂歡與社會階級懸置 |
| 女神從獅（毀滅）到貓（保護）的轉化 | ↔ 日本神話中稻荷神的狐狸從善惡不定到固定的守護者 |
