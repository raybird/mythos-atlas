# Stállu — 薩米巨人與惡靈

- **文化：** 薩米神話 (Sámi Mythology)
- **職掌：** 巨人、惡靈、荒野威脅、禁忌破壞者

## 概述

Stállu（亦拼寫為 Stállo 或 Stálo）是薩米神話中一個令人恐懼的存在——巨大的、類人但非人的生物，居住在荒野、山洞與極北的黑暗之地。Stállu 不是嚴格意義上的「神」，而是介於怪物、惡靈與堕落巨人之間的存在。他們代表了薩米人對荒野深處未知恐懼的投射——在極地漫長的冬夜中，Stállu 是那些消失在荒野中的人們的命運，也是那些違背禁忌者的終極懲罰。

Stállu 一詞可能與原始薩米語 *stālo（「巨人」或「強者」）相關，有些學者認為它與斯堪的納維亞語族的 *stal（「偷竊」）有語源聯繫——暗示 Stállu 是「偷竊者」或「掠奪者」。在不同的薩米方言中，Stállu 的描述有所差異：在北薩米語中他被稱為 Stállu，在中薩米語中為 Stálo，在南薩米語中則為 Stále。

## 神話事蹟

### Stállu 的外貌與習性

薩米口傳傳統中對 Stállu 的外貌描述高度一致：身高是普通人的三倍，皮膚灰白如冰，頭髮如糾結的苔蘚，眼睛發出微弱的磷光。Stállu 沒有腳趾（這是一個關鍵的辨識特徵——薩米人相信腳趾是文明的象徵，沒有腳趾的生物代表未被馴化的荒野力量）。他穿著由熊皮和馴鹿筋縫製的粗糙衣物，攜帶一根巨大的骨棒或石錘。

Stállu 居住在山洞或地下巢穴中，以偷竊人類的馴鹿和儲藏的食物為生。他最常見的行為是在冬夜潛入薩米人的帳篷（lavvu）附近，偷走馴鹿或綁架孤獨的旅行者。被 Stállu 綁架的人不會立即被殺害——而是被強迫為 Stállu 放牧偷來的馴鹿群，直到薩滿前來解救。

### Stállu 與英雄的較量

薩米最著名的 Stállu 故事之一講述了一位年輕的薩米英雄與 Stállu 的鬥智較量。英雄在荒野中迷路，被 Stállu 帶回巢穴。Stállu 要求英雄與他較量——比賽內容包括掰手腕、搬石頭、賽跑與猜謎。英雄每一次都巧妙地利用智慧而非力量取勝——例如在掰手腕時偷偷將手臂靠在岩石上借力，在搬石頭時用繩子將石頭綁在熊身上假裝自己搬起。最終英雄成功逃脫，而 Stállu 因憤怒過度而自己爆炸。

### Stállu 作為道德警告

在薩米教育傳統中，Stállu 的故事被用來警告兒童不要在荒野中獨自遊蕩、不要違背禁忌、不要貪婪或傲慢。Stállu 代表了自然界中那些不服從 Radien（天神）秩序的混亂力量——他們是造物秩序的反面，是荒野對文明的永恆威脅。

## 跨文化對應

| 薩米 Stállu | 跨文化對應 | 共通母題 |
|-------------|-----------|---------|
| Stállu 巨人 | 北歐 Jotun（霜巨人） | 巨人族與文明秩序的對立 |
| Stállu 無腳趾 | 希臘 Minotaur（牛頭人） | 半人半獸的荒野威脅 |
| Stállu 與英雄較量 | 赫拉克勒斯與巨人、格里菲斯與巨人 | 文化英雄戰勝混亂力量 |
| Stállu 綁架人類 | 北歐巨人綁架女神/人類 | 荒野對人類社會的侵襲 |
| Stállu 偷竊馴鹿 | 騙子神話中的偷竊母題 | 動物被盜與失而復得 |
