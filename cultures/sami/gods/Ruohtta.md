# 魯奧塔 (Ruohtta / Ruto)

- **文化：** 薩米神話 (Sámi Mythology)
- **職掌：** 疾病之神、瘟疫之神、死亡之神、冥界 Rotaimo 之主

## 概述

Ruohtta（北薩米語，字面義即「疾病」；亦作 Ruto、Rotas、Ruta，芬蘭語傳統寫作 Rutja）是薩米神話中最令人畏懼的神靈之一——他既是疾病與瘟疫的化身，也是冥界 Rotaimo（Ruohtta-áibmu，魯奧塔之國）的統治者。與掌管 Jahbmeaimo 的 Jahbme akka（死者之祖母）不同，Ruohtta 的領域帶有明確的懲罰性色彩：他接納那些「不依自然秩序而活」的人。薩米人相信，人若違反部落的禁忌與自然的法則，死後便會落入 Ruohtta 的國度，而非平等的 Jahbmeaimo。

Ruohtta 的形象與北歐人緊密相連。他以**騎馬**的形象出現——這在薩米宇宙觀中是極具衝擊力的符號，因為馬是北歐農牧民族馴養的動物，薩米牧民視之為陌生、骯髒且令人厭惡的存在。因此 Ruohtta 的馬蹄聲象徵著外來文明的入侵、疾病的蔓延與死亡的迫近。

## 神話事蹟

Ruohtta 被描述為北極地區瘟疫與流行病的人格化存在。當歐洲的鼠疫、天花與麻疹自南方沿貿易路線侵入薩米地區時，薩米人將這些災難理解為 Ruohtta 策馬而來。他的出現伴隨著嚴酷的冬季——薩米曆法中有一個被稱為「Ruto 時節」（rotto）的危險時期（約為十二月），此時 Ruohtta 的力量最為活躍，薩米人儘量留在家中、避免戶外活動，並以祭品安撫他。

Noaidi（薩滿）是人類對抗 Ruohtta 的核心力量。當瘟疫降臨時，Noaidi 會以太陽鼓（Gievrie）與 Joik 吟唱進行靈魂旅程，前往 Rotaimo 與 Ruohtta 交涉，試圖帶回病危者的靈魂。傳說中亦有以食物、馴鹿或刻有馬形的祭品來「賄賂」或「誤導」Ruohtta 的儀式——例如將祭品放在路口，希望他停留在祭品處而不再深入帳篷。

Ruohtta 也與薩米的葬儀禁忌相關。薩米人相信與 Ruohtta 有關的物品（如來歷不明的馬具、陌生的疾病）必須被隔離或焚毀，否則會招致第二次瘟疫。部分口傳傳統中，Noaidi 能將瘟疫「轉嫁」給北方巨人（Stalo）或將其封印於 Sieidi（聖石）之下。

## 跨文化對應

| 文化 | 對應神祇 | 共享特徵 |
|------|---------|---------|
| 蘇美 | Namtar（疾病與瘟疫之神） | 瘟疫人格化，以「使者」姿態降災 |
| 埃及 | Sekhmet（獅頭女神） | 以毀滅性瘟疫懲罰人類，亦能治愈 |
| 希臘 | 阿波羅（Apollo Smintheus） | 以神箭散佈瘟疫與疾病 |
| 北歐／瑞典 | Pesta（瘟疫老婦） | 以掃帚或耙子決定瘟疫擴散範圍 |
| 芬蘭 | Loviatar（九子之母，含 Rutto） | 疾病之母，誕下瘟疫九子 |
| 中國 | 瘟神（五瘟使者） | 季節性疫疾的人格化神祇 |
| 印度 | Mariamman（天花女神） | 疾病與治癒兼具的民間女神 |

## 相關神祇

- **Jahbme akka**（死者之祖母）：同樣統治冥界，但 Jahbmeaimo 無懲罰性；Ruohtta 的 Rotaimo 是罪責者的歸宿，兩者構成薩米冥界觀的雙重結構
- **Boaššu**（北極光精靈）：以暗紅極光警告瘟疫、暴風雪等災難
- **Noaidi**（薩滿）：唯一能與 Ruohtta 交涉、進入 Rotaimo 的人類
- **Stalo**（北方巨人）：瘟疫可被轉嫁的對象，薩米傳說中的邪惡外族象徵

## 出現在

- 薩米口傳傳統與 Joik 吟唱中對「Ruto 時節」的描述
- 18 世紀傳教士 Högström、Leem 對薩米疾病觀的記錄
- Qvigstad、Itkonen 蒐集的北薩米與伊納里薩米神話文本
- 薩米禁忌文化中的馬、馬具與外來物隔離規範
