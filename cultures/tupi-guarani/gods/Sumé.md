# 蘇梅 (Sumé / Sumé)

- **文化：** 圖皮-瓜拉尼神話 (Tupi-Guarani Mythology)
- **職掌：** 文明英雄、農業傳授者、法律與習俗建立者

## 概述

蘇梅（Sumé，也稱 Zumé 或 Zomé）是圖皮-瓜拉尼神話中最具爭議性的文化英雄——他在圖皮人的口傳傳統中是帶來農耕、社會秩序與宗教儀式的智慧長者，卻在十六世紀耶穌會士的記錄中被迅速比附為福音書中的聖多默（São Tomé），成為南美殖民史上最複雜的神話融合案例之一。蘇梅的形象是一位白髮、持杖的老人，從東方（大西洋方向）跨越海洋而來，教導圖皮人種植木薯、玉米與甘薯，建立婚姻制度與葬禮儀式。

## 神話事蹟

蘇梅的神話核心在於他作為「外來文明授予者」的角色。根據十六世紀耶穌會士何塞·德·安謝塔（José de Anchieta）與安德烈·特維（André Thevet）記錄的圖皮口傳：蘇梅在非常古老的時代從海上出現，他身穿白色長袍（一說赤身但渾身覆蓋白色羽毛），手持一根雕刻著蛇紋的長杖。他走訪各部族，在地上以杖尖畫出種植的溝槽，木薯和玉米便從溝中自行生長。

蘇梅同時是社會規範的制定者。他教導圖皮人一夫一妻制——在此之前男人可以隨意更換伴侶。他訂立了成年禮與命名儀式，並指示族人將死者埋入陶甕而非隨意棄置於林中。最重要的是，他禁止了食人習俗——這是圖皮社會中至高禁忌的由來之一（儘管食人在儀式性脈絡中並未完全消失）。

後期傳說中蘇梅在完成教導後返回海上。部分版本說他離開前留下了一根木杖，木杖入土生根，長出了第一批巴西木（pau-brasil），其紅色木心被視為蘇梅的血脈印記。另一些版本說蘇梅因與當地祭司衝突而被迫離開，他徒步走向大海，在灘頭劃出一個完美的十字——海水在他面前分開，他穿越海浪消失於地平線。正是這個細節使耶穌會士深信蘇梅就是聖多默——傳聞中曾到訪印度的使徒。

## 跨文化對應

| 圖皮-瓜拉尼 | 跨文化對應 |
|------------|-----------|
| 蘇梅（Sumé） | ↔ 阿茲特克／托爾特克奎策爾科特爾（Quetzalcoatl）— 白皮膚的文明傳授者 |
| | ↔ 印加維拉科查（Viracocha）— 創造者兼教師，從海路離去 |
| | ↔ 瑪雅庫庫爾坎（Kukulkan）— 羽蛇神文化英雄 |
| | ↔ 希臘普羅米修斯（Prometheus）— 為人類帶來文明的盜火者 |
| | ↔ 中國神農氏（Shennong）— 農業與草藥的建立者 |
| | ↔ 波利尼西亞毛伊（Māui）— 以巧智為人類帶來資源與技藝 |

蘇梅與中美洲奎策爾科特爾的平行最為驚人：兩者皆為白皮膚、鬍鬚的異鄉教師，從海上到來，傳授農耕與法律，最終同樣從海上離去。雖然部分學者認為這是殖民時期耶穌會士相互抄襲的結果（「聖多默說」），但也有人主張圖皮與中美洲之間存在前哥倫布時期的航海接觸，或兩者共享某種更深層的南美雨林神話結構。蘇梅與普羅米修斯的差異在於後者以偷竊方式為人類取得文明之火（帶有反叛眾神的色彩），蘇梅則以教師身分授予——更接近中國神農「嘗百草」的經驗傳承模式。

## 相關神祇

- **Nhanderuvucu** — 至高神，蘇梅的使命源自於祂的派遣
- **Mair** — 另一位文化英雄，與蘇梅的傳說在不同部族中互相補充
- **Karai** — 先知／薩滿，延續蘇梅的教導並引導族人尋找 Yvy Maraey
- **Tupa** — 雷神，蘇梅的教導與自然秩序和諧共存
