# 烏庫布·卡基什 (Vucub-Caquix) — 七金剛鸚鵡

烏庫布·卡基什（Vucub-Caquix，基切語意為「七金剛鸚鵡」）是馬雅神話《波波爾·武》（Popol Vuh）中第一位出現的巨獸型反派。他是在創世後洪水消退、世界初成之際，妄圖偽裝成太陽與月亮的傲慢存在，代表著創世之前的虛假秩序與必須被英雄擊敗的原始混沌力量。

## 神格與屬性

- **領域：** 虛假的太陽、驕傲、巨鳥、原始混沌
- **形象：** 巨大的金剛鸚鵡，羽毛閃爍著金銀寶石般的光芒，喙如磨亮的玉米石
- **象徵：** 虛假的權威、自我神化的傲慢、創世前的混沌殘餘
- **家人：** 妻子奇瑪爾瑪特（Chimalmat），兒子西帕克納（Zipacna）與卡布拉坎（Cabracan）
- **馬雅語名稱：** Vucub Caquix（七金剛鸚鵡），七在馬雅數字中具有神聖性

## 神話事蹟

### 偽裝太陽的巨鳥

在《波波爾·武》的敘事序列中，洪水消退後的世界仍然籠罩在混沌之中——太陽尚未升起，月亮亦未出現。此時烏庫布·卡基什出現在地平線上，牠的羽毛閃耀著金銀與寶石的光芒，牠大聲宣告：「我是太陽！我是月亮！我是照亮萬物的光！」牠的妻子奇瑪爾瑪特呼應牠的狂妄，稱牠為眾生的統治者。

英雄雙子的父親——渾·胡納普（Hun Hunahpu）與烏庫布·卡基什的衝突在此埋下伏筆，但真正擊敗牠的是英雄雙子烏納普（Hunahpu）與斯巴蘭克（Xbalanque）。雙子看穿了烏庫布·卡基什的虛假本質——真正太陽與月亮尚未誕生，這隻巨鳥只是佔據了光明的位置，阻礙宇宙秩序的正常建立。

### 吹箭射落傲慢

英雄雙子決定以智取而非強攻對付烏庫布·卡基什。他們藏身在一棵大樹下——烏庫布·卡基什每日飛到這棵樹上進食。當巨鳥降臨啄食果實時，烏納普舉起吹箭筒（吹箭為馬雅文化中經典的狩獵武器），瞄準烏庫布·卡基什的下顎發射。

吹箭擊中，打碎了巨鳥的喙，也打碎了牠的驕傲。烏庫布·卡基什受了重傷，瘋狂掙扎，將烏納普的手臂扯斷。雙子退卻，但並不放棄。他們偽裝成骨頭醫者（白髮祖父母）來到烏庫布·卡基什面前，說：「我們是治療骨頭的醫生。你的牙齒生病了，讓我們幫你治療。」巨鳥同意接受治療。

### 拔牙與奪寶

雙子以「治療」為名，將烏庫布·卡基什口中閃耀如寶石的牙齒全部拔除——這些牙齒是巨鳥光芒的來源。牠眼中鑲嵌的金屬圓盤也被取下。失去牙齒與金屬的烏庫布·卡基什不再閃耀，不再能冒充太陽。牠從自封的神座上跌落，在痛苦與羞恥中死去。

英雄雙子將拔下的牙齒與金屬鑲嵌到真正屬於它們的地方——部分成為日後真正太陽與月亮的光芒來源。烏庫布·卡基什的隕落象徵著虛假秩序必須被摧毁，真正的宇宙循環才能啟動。

## 跨文化對應

| 馬雅 烏庫布·卡基什 | 對應神祇／生物 | 文化 |
|---|---|---|
| 虛假太陽／偽裝光明的巨鳥 | 阿波菲斯（Apophis，黑暗蛇神試圖吞噬太陽船） | 埃及 |
| 因驕傲而墮落 | 伊卡洛斯（Icarus，蠟翼墜海） | 希臘 |
| 被拔除力量的來源 | 參孫（Samson，被剪去力量之髮） | 希伯來 |
| 巨鳥挑戰英雄 | 大鵬金翅鳥（Garuda vs 那伽） | 印度 |
| 創世前的混沌假秩序 | 提亞瑪特（Tiamat，原水混沌被擊敗） | 美索不達米亞 |

## 相關存在

- **英雄雙子（烏納普與斯巴蘭克）：** 擊敗烏庫布·卡基什的吹箭英雄
- **奇瑪爾瑪特（Chimalmat）：** 烏庫布·卡基什的妻子
- **西帕克納（Zipacna）與卡布拉坎（Cabracan）：** 烏庫布·卡基什的兒子，日後也被英雄雙子擊敗
- **渾·胡納普（Hun Hunahpu）：** 英雄雙子的父親，第一代與冥界力量交鋒者
