# 伊克斯皮亞科克 (Ixpiyacoc / Xpiyacoc) — 創世祖父與預言之神

- **文化：** 馬雅神話 (Mayan Mythology)
- **職掌：** 創世祖父、占卜與預言、智者、編年者、媒合者
- **象徵：** 占卜種子、水晶球、編織、玉米

## 概述

伊克斯皮亞科克（Ixpiyacoc，基切語意近「隱藏者」或「編織者」）是馬雅創世史詩《波波爾·烏》（*Popol Vuh*）中與妻子施穆卡內（Xmucane）並列的創世祖父母之一。這對老夫婦合稱「Tz'aqol B'itol」，意為「創造者與塑造者」——所有天神在進行重大決定之前，必定先諮詢他們兩位。伊克斯皮亞科克的角色在文本中雖然不如妻子施穆卡內那樣經常現身，但他掌握了馬雅文化最核心的知識體系：占卜（divination）與曆法計算，是人類與神靈之間最重要的溝通橋樑。

在馬雅世界觀中，伊克斯皮亞科克代表了時間的編織者與命運的解讀者，他的智慧不僅源自年紀，更來自對宇宙秩序的深刻理解。他常被描繪為一位年邁的男性，面容刻滿歲月的痕跡，手持占卜用的玉米粒或水晶。

## 神話事蹟

### 創世占卜

在《波波爾·烏》的創世敘事中，天神們（Huracan、Tepeu、Gucumatz）在創造人類之前，召喚了伊克斯皮亞科克與施穆卡內來進行占卜。他們被問及：「人類該如何被造？人類該以什麼為血肉？人類該以什麼方式繼承神性？」伊克斯皮亞科克與施穆卡內使用玉米粒與占卜水晶（紅色寶石與白色寶石）進行擲筊，以解讀天神們的意圖。

占卜的結果引導眾神找到了埋藏玉米的「分裂之水」（Paxil）與「黃色玉米堆積之處」（Cayalá），從而完成了以玉米造人的創世大業。這場占卜被認為是馬雅文明中最早的儀式性占卜行為，伊克斯皮亞科克也因此被尊為所有馬雅祭司（Ah Kin）與占卜師（Ah Tz'ite）的始祖。

### 媒合與婚姻的守護者

伊克斯皮亞科克的職權範圍也涵蓋婚姻與社會關係的締結。他的另一個名字「Cotbalamilom」（基切語意為「兩邊協商者」）揭示了他的社會功能：他是婚姻的媒合者、部落結盟的見證者、以及買賣契約的監督者。在馬雅日常社會中，人們在締結婚姻或商業關係前會向他祈禱，並以玉米粒占卜來詢問吉凶。

### 與施穆卡內的互補關係

伊克斯皮亞科克與施穆卡內構成了馬雅宇宙觀中最完善的陰陽平衡隱喻。施穆卡內代表行動——她實際動手捏造人類、研磨玉米、養育英雄雙子；伊克斯皮亞科克則代表智慧——他提供占卜指引、解讀神意、協調人神關係。兩者缺一不可，正如馬雅宇宙中的白天與黑夜、生與死、雨與旱之間的平衡關係。

## 跨文化對應

| 文化 | 對應神祇／概念 | 共享特徵 |
|------|-------------|---------|
| 中國 | 伏羲（創世神、占卜八卦的發明者） | 占卜與智慧的化身，文明秩序的奠定者 |
| 希臘 | 普羅米修斯（先知者，名字意為「預先思考」） | 以智慧協助眾神創造人類，預見未來的能力 |
| 北歐 | 密米爾（Mimir，智慧之泉守護者，預言者） | 古老智者，為眾神提供遠古知識與洞見 |
| 芬蘭 | 維伊納莫伊寧（Väinämöinen，吟唱智者） | 古老智慧的代表，以歌謠與魔法創造世界秩序 |
| 埃及 | 托特（Thoth，智慧之神、曆法與書寫的發明者） | 神聖知識與曆法的守護者，眾神的書記官 |
| 蘇美 | 恩基（Enki，智慧神、占卜與魔法的掌握者） | 以智慧引導眾神決策，人類的保護者與教導者 |

## 相關神祇

- **Xmucane（妻子）**：創世祖母，與伊克斯皮亞科克共同被稱為 Tz'aqol B'itol
- **Huracan（創世風暴）**：最早召喚祖父母進行占卜的天神
- **Tepeu（創世神）**：共同參與人類創造的主神之一
- **Hunahpu 與 Xbalanque（英雄雙子）**：伊克斯皮亞科克的後代，其命運由他占卜決定

## 出現在

- *Popol Vuh*（波波爾·烏）Part I – 創世占卜與人類的造人計劃
- 馬雅古典時期陶器與壁畫（常出現老年男性持占卜用具的場景）
- 瓜地馬拉奇奇卡斯特南戈（Chichicastenango）地區當代馬雅祭司仍保留以其為名的占卜儀式
