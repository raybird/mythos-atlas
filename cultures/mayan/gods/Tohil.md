# 托希爾 (Tohil)

- **文化：** 馬雅神話 (Mayan Mythology)
- **族系：** 基切（K'iche'）馬雅萬神殿
- **職掌：** 火、太陽、戰爭、守護神、祭祀契約之主

## 概述

托希爾（Tohil，基切語意為「打火石」或「取火者」）是《波波爾·烏》（*Popol Vuh*）第三部中出現的基切馬雅核心神祇。祂的地位特殊——既是創世後賦予人類火種的文化英雄神，也是基切部落的氏族守護神（patron deity），同時在後古典時期的殖民記錄中被視為暴烈而嗜血的神明。托希爾與創世神 Tepeu 與 Gucumatz（羽蛇）同列，但祂的職責更偏向人間：祂教導人類取火、烹煮與祭祀，並以此作為人類生存與神靈饋贈之間的契約基礎。祂的名字本身即指「取火的燧石」，暗示馬雅人以燧石打火的技術起源與神話的高度結合。

托希爾在《波波爾·烏》中還被賦予「納瓦」（nawal，守護化身）的雙重身分：祂既是神明，也是四位先祖的部落守護者。當先祖們穿越群山抵達新的家園時，托希爾隨行護衛，並要求人類以血與火持續供奉祂——這成為基切人祭祀傳統的根基。

## 神格特徵

托希爾的形象在古典與後古典時期的表現並不一致。後古典基切傳統中，祂常與太陽結合，被描繪為吞噬獵物後吐出火焰的神獸；殖民時期文獻（如《波波爾·烏》英譯者 Tedlock 的分析）則指出托希爾被天主教傳教士與阿茲特克的 Huitzilopochtli 相提並論，因兩者皆為部落守護神、皆要求人祭，且名字皆與「火／刀」相關。祂的三位一體化身——Tohil、Avilix、Hacavitz——對應基切人遷徙路線上的三座聖山，構成了地理與神聖空間的具體連結。

## 神話事蹟

### 賜火與祭祀契約

在《波波爾·烏》中，四位先祖 Balam Quitzé、Balam Acab、Mahucutah 與 Iqui Balam 被創造後，處於寒冷與黑暗中。托希爾賜予火焰，但要求人類定期供奉祭品。當雨神 Chaac 試圖以暴雨熄滅火焰時，托希爾以斗篷護住火種並與 Chaac 達成協議：人類保留火焰，但需同時祭祀雨水與火。此後，人類的祭祀儀式中永遠同時包含火祭與水祭——這一雙重元素正是馬雅農業與宇宙觀的核心隱喻。

### 納瓦之爭與部落守護

先祖們離開山居之地後，托希爾要求基切人不再敬拜其他神明，只供奉祂。祂以此維護基切部落的獨立性——當其他部落試圖與基切人聯姻、結盟或探詢其守護神祇時，基切人始終守口如瓶。托希爾甚至化身為一位乞食的少年，暗中考驗族人對祂的忠誠，確認基切人即使在困境中也不會背叛祂。這一「考驗式守護」的母題，使托希爾有別於單純的恩惠之神，成為一位要求嚴格、獎懲分明的契約之神。

### 火的被竊與戰功

當其他部落得知基切人擁有神聖之火後，派遣少女前來竊取火種。托希爾識破計謀，指示基切人以一種特殊的樹皮包裹火種，使少女們帶走的只是冒煙而不燃燒的假火。少女們被認為「觸碰了神聖之物」而招致災禍，其部落因此衰落。托希爾由此彰顯祂既是文明的賜予者，也是族群的界線守護者——祂的火焰區分了「我們」與「他們」。

## 跨文化對應

| 文化 | 對應神祇／概念 | 共享特徵 |
|------|-------------|---------|
| 希臘 | Prometheus（普羅米修斯） | 為人類取得火焰，但希臘版本為「盜火」，馬雅版本為「祈火」 |
| 印度 | Agni（阿耆尼） | 居於祭祀中心，作為人神之間的媒介 |
| 中國 | 遂人氏 | 鑽木取火的文明英雄，火焰象徵文明的轉折 |
| 阿茲特克 | Huitzilopochtli（維齊洛波奇特利） | 部落守護神、戰爭之神、要求人祭，殖民者曾將兩者並列 |
| 波斯 | Atar（阿塔爾） | 火作為神聖元素，火祭儀式居於宗教核心 |
| 北歐 | Loki 盜火／Thjálfi | 火作為考驗與契約的象徵，但無對應的部落守護神 |
