# 木人世界——波波爾·烏的第二次造人嘗試

## 背景

在《波波爾·烏》（Popol Vuh）所記載的馬雅創世序列中，造物主們經歷了四次造人嘗試。第一次是動物世界——但走獸飛禽無法開口祈禱，無法讚美眾神。第二次則是「木人」（Rij q'ij / 木製人類）的時代——這是人類真正的前驅，卻因缺乏靈魂與情感而遭毀滅。

## 神話敘事

在動物失敗後，造物主特佩烏（Tepeu）與古庫馬茨（Gukumatz），以及始祖父母舒穆卡內（Xmucane）與舒皮亞科克（Xpiacoc），決定用木材來製造人類。他們從森林中砍伐樹木，雕刻出人的形體——有軀幹、四肢、五官，外觀與真人無異。

這些木人活了下來，並開始繁衍，遍布大地。他們可以走路、說話、建造房屋，也能夠生育後代。然而他們有一個致命的缺陷——沒有記憶，沒有感恩之情，也不會向創造他們的神明祈禱。他們的心是空虛的，如同木頭本身。他們在臉上塗抹泥巴來模仿表情，卻始終無法真正理解世界的神聖性。

眾神決定毀滅這些木人。天空降下滾燙的瀝青（黑膠），大地的所有東西都開始對抗他們——狗說「你們曾經踢打我，現在我要咬你」；磨石說「你曾經用我磨碎玉米，現在我要把你壓碎」；陶鍋說「你曾經把我放在火上燒，現在我要把你煮熟」；樹木說「你把我們砍倒來蓋房子，現在我們要把你壓垮」。木人在自己創造的物品的追殺中四處奔逃，有的跑上屋頂卻被屋頂壓垮，有的爬上樹卻被樹枝彈飛，有的躲進山洞卻被岩石封住。傳說少數木人逃到森林中，演化成了現代的猴子——這也解釋了為什麼猴子與人類如此相似。

## 文化意涵

木人神話的深層結構極具衝擊力：**被造的萬物在造物主的授意下集體反抗自己的主人**。這是一種徹底的「生態學正義」——人類虐待過的物件全部起來審判人類。馬雅版本與更廣為人知的大洪水滅世（如諾亞、烏特納匹什提姆、杜卡利翁）截然不同——它不是天災而是萬物之靈的集體反撲。

木人的「無靈魂」也反映了馬雅人對人類本質的深層定義：真正的人必須能夠祈禱、記得眾神、與神聖世界保持連結。沒有記憶與感恩的人類只是徒具人形的空殼——無論文明多麼進步。

## 跨文化對照

| 文化 | 故事 | 核心差異 |
|------|------|---------|
| 希伯來 | 諾亞洪水 | 天降洪水懲罰墮落人類，義人得救 |
| 希臘 | 青銅時代 vs 黑鐵時代 | 世代退化論，非「被造物反噬」 |
| 北歐 | 尤米爾巨人身體造世界 | 原始巨人被殺後化為世界，非人類被毀 |
| 印度 | 持斧羅摩滅剎帝利 | 特定種姓被滅，非全人類 |
| 中國 | 共工怒觸不周山 | 結構性災難（天坍地陷）而非萬物審判 |
| 美索不達米亞 | 阿特拉哈希斯史詩 | 眾神以洪水滅人因人類太吵 |
| 波里尼西亞 | Tāne 造人 | 以紅土造人（成功案例） |
