# 撐天巨人巴卡布與中國崑崙撐天柱比較

## 概述

人類的神話想像中幾乎普遍存在「天空可能墜落」的焦慮——這促使各個文明創造了撐天者或撐天柱的意象。馬雅神話中的巴卡布四兄弟（Bacab）與中國神話中的撐天柱（不周山／崑崙山）代表了兩種不同的宇宙維持策略：前者以「四方位分擔」的原則將責任分散於四位神祇，後者以「中軸集中」的概念將宇宙的支撐濃縮於單一（或四極）聖山。這兩種結構不僅反映了不同的宇宙觀，也隱喻了不同的政治組織模式。

## 核心比較表

| 特徵 | 巴卡布四兄弟（馬雅） | 崑崙撐天柱（中國） |
|------|:------------------:|:-----------------:|
| 撐天者數量 | 四位（各司一方） | 最初單一（不周山），後四極（女媧修復） |
| 方位結構 | 東（紅）／北（白）／西（黑）／南（黃） | 東／南／西／北四極 |
| 支撐方式 | 以肩膀扛起天空四角 | 山體作為柱子支撐天穹 |
| 物種屬性 | 神祇（有時被描繪為人形或甲殼蟲） | 山脈（地質特徵神聖化） |
| 象徵 | 宇宙四方的平衡 | 宇宙中心的穩定 |
| 自然災害解釋 | 巴卡布疲勞或交接錯誤 → 地震洪水 | 共工撞倒不周山 → 天傾西北、地陷東南 |
| 修復機制 | 每年 Uayeb 儀式重新穩定 | 女媧斬巨龜四足代為四極 |
| 與世界樹關係 | 巴卡布守護四棵宇宙木棉樹 | 建木（神樹）生長於崑崙，為天地通道 |

## 宇宙觀的根本差異

### 馬雅：四方位分散式宇宙

馬雅宇宙觀建立在方位（directional）與顏色編碼的基礎上——世界分為四個象限，每個象限由特定的神祇、顏色、樹木與年份符號管理。巴卡布作為撐天者，同時也是這套方位系統的守護者。馬雅金字塔（特別是奇琴伊察的 El Castillo）的建築設計反映了這種四方宇宙觀——塔的四個階梯分別對應四個方位，總台階數 365 對應太陽年。

這種分散式的宇宙模型暗示了權力與責任的分擔——宇宙的穩定依賴於四位神祇的合作與輪替。如果任何一位失職，宇宙便會出現局部的失衡，但不會全面崩塌。這與馬雅城邦的政治結構一致——古典時期的馬雅並非統一的帝國，而是由數十個城邦組成的鬆散網絡，強調地方自治與平衡。

### 中國：中軸集中式宇宙

中國宇宙觀以「中」為核心——崑崙山作為世界中心軸（Axis Mundi），連接天地人三界。不周山原本是唯一的撐天柱，被共工撞斷後導致宇宙失衡（天傾西北，地陷東南）。女媧以四極修復（斬龜足以代四極），象徵從單一中軸向四方位支撐的轉變——但即使如此，崑崙仍被視為宇宙的中心。

這種模型暗示宇宙的穩定依賴於「一個正確的中心」——一旦中心受損，整個宇宙的秩序將面臨崩潰。這種結構與中國的中央集權帝國政治模式高度一致——天下圍繞一個中心運行，天子的治理維繫宇宙的和諧。

## 神話情節的功能對應

### 共工觸山 vs 巴卡布交接

中國神話中，共工（水神）與祝融（火神）爭鬥失敗後怒觸不周山——這是一個單一暴力事件導致宇宙結構改變。馬雅體系中，巴卡布交接發生於每年 Uayeb（五天凶日），是一個持續的、週期性的節律——宇宙的威脅來自於時間的推移而非一次性的衝突。

### 女媧補天 vs Uayeb 儀式

女媧以五色石補天、以龜足立四極——這是神話歷史中的一次非常規修正行為。馬雅的 Uayeb 新年儀式則是每年必須執行的常規維護——祭司齋戒五日、不升火、不吃鹽，以確保巴卡布的順利交接。中國模式強調「危機—英雄」結構，馬雅模式強調「週期—儀式」結構。

## 宇宙樹：巴卡布的 Ceiba vs 中國的建木

馬雅的木棉樹（Ceiba／Yaxche）和中國的建木是兩種宇宙觀中的世界樹原型：
- **Ceiba**：四棵木棉樹分別生長於世界四隅，巴卡布守護之。Ceiba 的枝幹支撐天空，根系深入西巴巴。
- **建木**：單一生長於崑崙山頂的宇宙樹，日中無影、呼而無響，為眾神上下天地的階梯。

四棵 vs 一棵——再次呈現分散與集中的宇宙模型差異。
