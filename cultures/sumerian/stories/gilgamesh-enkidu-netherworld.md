# 吉爾伽美什、恩奇都與冥界 (Gilgamesh, Enkidu and the Netherworld)

- **文化：** 蘇美神話 (Sumerian Mythology)

## 故事背景

〈吉爾伽美什、恩奇都與冥界〉是現存最完整的蘇美吉爾伽美什敘事詩之一（ETCSL t.1.8.1.4），成文於烏爾第三王朝時期（約公元前 2100–2000 年）。這首詩是標準巴比倫《吉爾伽美什史詩》第十二塊泥板的直接前身，為整部史詩提供了最為詳盡的冥界景觀描寫。故事的核心主題「失去之物落入冥界」和「亡魂回歸述說冥界真貌」在後世的跨文化敘事中不斷重現。

## 情節

### 第一幕：鼓與鼓槌墜入冥界

吉爾伽美什在烏魯克為人民創造了節日的歡樂。他用一根被神聖化的大樹（可能是胡魯普樹）製作了 **pukku**（鼓）與 **mikku**（鼓槌），年輕人在廣場上隨鼓聲歡舞。然而鼓與鼓槌在某次玩耍中掉入了一個深洞——那不是普通的地洞，而是通往冥界的入口。眾寡婦與年輕姑娘們為失去歡樂而哀哭。吉爾伽美什無法從冥界中取回他的珍寶，陷入深深的沮喪。

### 第二幕：恩奇都的誓言

吉爾伽美什在庭院中大聲宣告：「誰願下冥界為我取回鼓與鼓槌？」在場的僕人皆因恐懼而沉默。他的摯友恩奇都站出來：「我願意，但請告訴我冥界的事——哪些事能做，哪些不可觸犯。」

吉爾伽美什向恩奇都傳授了一整套冥界行為守則——這是他從神祇那裡聽來的智慧：
1. **不可穿潔淨的衣服**——否則冥界的守衛會視你為外人
2. **不可塗抹好油**——否則亡魂會圍繞那香氣
3. **不可向地上丟擲棍棒**——否則被棍擊中的亡魂會包圍你
4. **不可手持弓箭**——否則冥界會以為你是來征戰的入侵者
5. **不可穿鞋行走**——冥界之路必須赤足以示尊重
6. **不可親吻你的妻子和兒子**——否則冥界會看出你對人間的依戀
7. **不可打你的妻子和兒子**——否則冥界會認為你仍是陽間之人而不放你離開

### 第三幕：恩奇都違反禁令

恩奇都決心出發，他從烏魯克城門走向庫爾（Kur）——冥界的入口。然而他忘記了吉爾伽美什的告誡：他穿上潔淨的衣服、塗抹香膏、向地面投擲棍棒，做了一切被禁止的事。因此冥界緊緊抓住了他——他無法離開陰冷的冥域。

吉爾伽美什心急如焚。他前往尼普爾的恩利爾神廟，向眾神之王恩利爾祈禱，懇求祂讓恩奇都歸來。恩利爾拒絕了——因為一旦人類踏入冥界就不得返回。吉爾伽美什轉向恩基（智慧之神），恩基同意幫助。祂命令冥界之神涅伽爾（Nergal）在冥界的牆上打開一個縫隙——恩奇都的靈魂得以從裂縫中升起，回到陽間。

### 第四幕：恩奇都述說冥界真貌

恩奇都以幽靈的形態回到人間，吉爾伽美什與他展開了全詩最震撼的對話。恩奇都描述了冥界中不同類型亡魂的命運：

| 生前狀況 | 在冥界的遭遇 |
|---|---|
| 戰死沙場者 | 與父母兄弟同臥於床，受尊敬 |
| 有後代者 | 後代的祭品能送到冥界供其享用 |
| 無後代者 | 如同被遺忘的陶片散落在冥界牆角 |
| 被遺棄的胎兒 | 在冥界中無法安息，永遠漂流 |
| 葬禮被執行者 | 能在冥界喝到清水 |
| 無人埋葬者 | 在冥界街道上撿拾殘渣為食 |
| 有七個兒子者 | 「像神的戰士一樣坐在華美的椅子上」 |

這段分類體系反映了蘇美社會對「善終」與「後代祭祀」的極度重視：能否在冥界得到安息，完全取決於在陽間是否被體面地埋葬、是否有後代持續供奉。整首詩的結尾沒有提到鼓與鼓槌是否被取回——焦點已完全轉移到恩奇都帶回的冥界知識。

## 跨文化平行

- **〈伊南娜下冥界〉（蘇美）**：同樣以「進入冥界→被囚→獲救」為敘事框架，但伊南娜是女神，有完整的七門剝奪與替代者制度。
- **〈奧菲斯與尤麗狄斯〉（希臘）**：英雄下冥界尋找愛人的靈魂，因回頭違反禁令而永遠失去。恩奇都則是因違反冥界行為規範而被囚。
- **〈伊邪那岐下黃泉〉（日本）**：伊邪那岐違反不可回頭看的禁令，看見伊邪那美的腐屍而逃離——同樣以禁忌行為作為冥界故事的轉折。
- **但丁《神曲・地獄篇》**：對不同罪惡者在地獄中受不同刑罰的細緻分類，與恩奇都對冥界居民分類的結構遙相呼應。
- **〈奧德賽〉第十一卷（希臘）**：奧德修斯下冥界召喚亡魂詢問預言，同樣獲得關於未來與死亡的知識。
