# 尼努爾塔返回尼普爾 (Ninurta's Return to Nippur)

- **文化：** 蘇美神話 (Sumerian Mythology)

## 故事背景

〈尼努爾塔返回尼普爾〉（Sumerian: Ninurta pa-ud-du-a，意為「尼努爾塔，那從中出現者」）是蘇美語宗教文學中最壯麗的凱旋頌歌之一，出土於尼普爾（Nippur），約創作於公元前第三千紀末至第二千紀初。此詩歌講述戰爭與農業之神尼努爾塔（Ninurta）在完成對混沌力量的征伐後，率領凱旋隊伍返回其聖城尼普爾的場景。尼努爾塔是恩利爾（Enlil）之子，兼具戰神與灌溉之神的雙重身份——在戰場上，他是混沌力量的粉碎者；在田野上，他是河流治理者與豐收的賜予者。這首詩歌不僅是一首軍事凱旋曲，更是一部讚頌宇宙秩序從混沌中恢復的宗教文學傑作。

## 情節

### 第一幕：出征與勝利

詩歌以尼努爾塔從戰場歸來作為開端。尼努爾塔此前征伐了多個敵人，其中包括混沌怪獸阿薩格（Asag）以及威脅文明的各種混沌力量。在〈尼努爾塔戰阿薩格〉（Lugal-e）的延續中，尼努爾塔以洪水般的武力掃蕩了山脈與荒野中的敵人。歸途中，他率領的戰利品包括從被征服的山脈中取得的寶石、木材與金屬——這些象徵著將自然力量從混沌的控制中解放，納入文明秩序的範疇。

### 第二幕：尼努爾塔的武器與隨從

詩歌以壯麗的細節描繪了尼努爾塔的武裝與隨從隊伍。他攜帶七種神聖武器，每一種都具備毀滅性的力量：其中最重要的「sharur」（一種會說話的流星錘或投石器）是他最忠實的戰鬥夥伴。Sharur 不僅是武器，更是擁有自主意識的存在——它會在戰鬥中發出聲音鼓勵尼努爾塔，並在需要時提供戰略建議。這種「活的武器」的概念在古代近東文學中極為獨特。

隊伍中還包括被征服的山脈與河流，它們以擬人化的形態行進，呈現出被秩序力量馴服的自然力。山脈低頭行走，河流乖乖流淌，獅子與狼崽溫順地跟隨——這是「秩序戰勝混沌」最直觀的視覺表達。

### 第三幕：尼普爾的迎接

當尼努爾塔的隊伍接近尼普爾時，聖城的居民與低階神祇湧上街頭迎接。詩歌生動描繪了尼普爾的壯麗景象——恩利爾的神廟「恩庫爾」（Ekur，意為「山之屋」）矗立在城市中心，象徵著宇宙的中心軸。尼努爾塔走入恩庫爾，將戰利品呈獻給父親恩利爾，恩利爾以神聖的祝福回應。

### 第四幕：對自然力量的重新分配

尼努爾塔在父親的神廟中重新分配他所征服的自然力量：他指派河流去灌溉田地，命令山脈提供金屬與寶石，讓森林貢獻木材。這一過程隱喻了文明將野性自然納入有秩序的經濟與政治體系中的過程——這也是蘇美城邦國家的建構隱喻。詩歌最後以對尼努爾塔的讚頌結束，確認了他作為恩利爾指定繼承人的地位。

## 跨文化平行

- **希臘神話珀耳塞福涅（Persephone）返回地面**：尼努爾塔從混沌的地下世界凱旋返回文明世界，與珀耳塞福涅從冥界返回地面的季節循環主題相呼應。兩者都象徵著秩序從混亂（地下/死亡）中的回歸。
- **北歐神話托爾（Thor）從巨人國度歸來**：托爾經常從與巨人的戰鬥中歸來，帶著戰利品返回阿斯加德。尼努爾塔與托爾共享「雷神/戰神 + 自然力量管理者」的雙重身份。
- **印度因陀羅（Indra）戰弗栗多（Vritra）後的凱旋**：因陀羅擊殺封鎖水源的巨蛇弗栗多後，水（秩序/文明之源）重新流動——與尼努爾塔征服混沌後重新分配自然力量的主題一致。
- **聖經約書亞（Joshua）征服迦南後的凱旋**：約書亞征服敵人後將土地分配給以色列各支派，與尼努爾塔重新分配自然資源的結構平行。
- **埃及荷魯斯（Horus）擊敗賽特（Seth）後繼承王位**：年輕戰神擊敗混沌力量後獲得合法王權——尼努爾塔的凱旋直接導致他被確認為恩利爾的繼承者。
