# 帕比爾薩格 (Pabilsag / Pabilsaĝ)

- **文化：** 蘇美神話 (Sumerian Mythology)
- **職掌：** 狩獵、戰爭、弓箭、拉拉克城（Larak）守護神
- **象徵：** 弓箭、弓、獅鷲混合獸
- **聖城：** 拉拉克（Larak，位置未確定的早王朝城市）

## 概述

帕比爾薩格（楔形文字 𒀭𒉺𒂅𒊕，Pabilsaĝ，意為「始祖之箭」或「先鋒之矢」）是蘇美萬神殿中一位古老而重要的神祇，主要掌管狩獵與戰爭。他在蘇美城邦時期的神系中以「尼努爾塔（Ninurta）之父」或「尼努爾塔的前身」聞名——許多學者認為帕比爾薩格是尼努爾塔在南方城市拉拉克的早期地方形態，隨著尼努爾塔崇拜在尼普爾（Nippur）的興起而逐漸被吸收合併。帕比爾薩格的名字直接與箭矢相關，暗示他的核心神格為戰鬥與狩獵之神，如同拉弓射箭般精準而致命。

在《蘇美王表》中，帕比爾薩格被記載為大洪水前拉拉克城的傳奇統治者之一——他在位時間長達數萬年，這在神話化的王表語境中象徵神權統治的永續性。這使帕比爾薩格不僅是一名神祇，也是介於人神之間、前文明時期的神性君王。

## 神話事蹟

### 拉拉克城的守護者

帕比爾薩格與拉拉克城的緊密聯繫是蘇美神話地理學中的典型案例——每座重要城邦都有自己的守護神，而帕比爾薩格即為拉拉克的主神。拉拉克在蘇美早王朝時期（約公元前2900–2334年）是重要的政治中心之一，但在歷史記錄中逐漸式微。帕比爾薩格的崇拜可能隨著拉拉克城的衰落而轉移至其他城市，最終被納入尼努爾塔的崇拜系統。值得注意的是，拉拉克在《蘇美王表》中位列洪水前的五大城市之一——埃里都（Eridu）、巴德提比拉（Bad-tibira）、拉拉克、西帕爾（Sippar）、舒魯帕克（Shuruppak）——而帕比爾薩格正是這座聖城的統治神。

### 帕比爾薩格與尼努爾塔的關係

在蘇美神話體系中，帕比爾薩格與尼努爾塔的關係存在兩種版本。在早期的文獻中，帕比爾薩格被視為尼努爾塔的父親，尼努爾塔繼承了父親的戰鬥與狩獵屬性，並進一步發展為農耕與戰爭之神。在晚期的文獻中，帕比爾薩格與尼努爾塔被視為同一神祇的兩個名稱——帕比爾薩格強調其狩獵與弓箭屬性，尼努爾塔則強調其農業、戰爭與王權守護的多元面向。這種神祇合併的現象在美索不達米亞宗教中十分常見（如伊南娜／伊絲塔、恩基／埃亞），反映了城邦政治中心的轉移對神學體系的塑造力。

### 箭與弓的象徵系統

帕比爾薩格的名稱直接包含「箭」（𒊕，saĝ，意為「頭／尖端」）的元素，象徵他作為軍事力量的化身。在蘇美藝術中，帕比爾薩格通常被描繪為手持複合弓的戰士，有時與獅鷲或獵鷹共同出現。弓與箭在美索不達米亞文化中不僅是戰爭武器，更象徵王權與神授的統治力——國王在藝術作品中常被描繪為拉弓射箭的形象，象徵其對混亂力量的壓制。帕比爾薩格的弓箭因此不僅是狩獵工具，更是宇宙秩序（me）得以維持的武力保障。

## 跨文化對應

| 文化 | 對應神祇 | 共享特徵 |
|------|---------|---------|
| 希臘 | 阿波羅（Apollo） | 弓箭神、狩獵、遠距離精準攻擊 |
| 希臘 | 阿緹蜜絲（Artemis） | 狩獵女神，弓箭為核心象徵 |
| 北歐 | 烏勒爾（Ullr） | 弓箭與狩獵之神，冬季的統治者 |
| 印度 | 阿耆尼（Agni）之箭 | 箭為神力的延伸，象徵精準與懲罰 |
| 中國 | 后羿 | 神箭手，射日英雄，弓箭為天授力量 |
| 蘇美（晚期） | 尼努爾塔（Ninurta） | 同一神格的分化或演化 |

## 相關神祇

- **父神關係**：部分文獻中帕比爾薩格為恩利爾（Enlil）之子
- **子嗣**：尼努爾塔（戰爭與農業之神），繼承了父親的戰鬥屬性
- **配偶**：在各城邦傳統中不同，較常見的為古拉（Gula，醫療女神）或烏拉什（Urash，地母神）
- **象徵動物**：獅鷲（Imdugud / Anzû），與尼努爾塔共享此神獸圖騰
