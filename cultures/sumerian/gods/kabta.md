# 卡布塔 (Kabta)

- **文化：** 蘇美神話 (Sumerian Mythology)
- **職掌：** 星辰之神、金星伴神
- **蘇美語銘文：** dKAB.TA、dKA.AB.TA、dTA-gu₄-nu、dTA×MI
- **蘇美名：** Maḫdianna（馬赫迪安娜，意為「天之崇高者」）

## 概述

卡布塔是美索不達米亞神話中一位較為晦澀的神祇，其崇拜見於第二千紀至第一千紀的楔形文字文獻與印章。根據韋德納神名表（Weidner God-list），卡布塔常與寧辛安娜（Ninsianna）——即「天之紅女」金星之星辰化身——並列出現，地位緊隨其後。這一配對關係暗示卡布塔具有星辰屬性，其蘇美語名稱「馬赫迪安娜」（Maḫdianna，「天之崇高者」）進一步佐證了這一推測。

卡布塔最早見於烏爾第三王朝時期（約公元前2112–2004年）的文獻，說明其崇拜至少可追溯至蘇美文明晚期。在舊巴比倫時期與加喜特時期的人名中，卡布塔作為神名要素頻繁出現，如「努爾-卡布塔」（Nūr-Kabta，「卡布塔之光」）、「阿瑪特-卡布塔」（Amat-Kabta，「卡布塔的女僕」）等，反映了該神在民間信仰中的影響力。

## 神話事蹟

由於文獻保存狀態不佳，關於卡布塔的神話敘事極為有限。《An = Anum》神名表中對卡布塔的條目因泥板殘損而中斷，連其性別亦無法確定。威爾弗雷德·G·蘭伯特（Wilfred G. Lambert）推測卡布塔可能為男性，並充當寧辛安娜的配偶。拉爾薩時期（伊辛-拉爾薩時期）的印章壓印似乎支持這一觀點，顯示兩位神祇以配偶形式並列。然而，亦有印章描繪兩位女神，可能分別代表寧辛安娜與卡布塔，暗示卡布塔亦可能具有女性面向。學者阿舍-格雷夫（Asher-Greve）將寧辛安娜描述為「雙性神」（bi-gendered deity），而根據傑里米·彼得森（Jeremiah Peterson）的研究，在《An = Anum》神名表與詞彙文獻Proto-Diri中，寧辛安娜、卡布塔與馬赫迪安娜均被釋為「星辰伊什塔爾」（Ištar kakkabi），且均為女神。

值得注意的是，卡布塔常在文獻中與庫拉（Kulla，磚神）混淆。塞繆爾·諾亞·克雷默（Samuel Noah Kramer）在其著作《蘇美神話》中，因對《恩基與世界秩序》第337行的誤讀，將卡布塔等同於庫拉。蘭伯特將此錯誤歸咎於迪特爾·奧托·埃扎德（Dietz Otto Edzard）。這一混淆反映了兩位神祇在建築與天文領域的某種功能重疊——庫拉掌管磚石與建築，而卡布塔的「崇高」屬性可能與建築的天文方位有關。

## 跨文化對應

| 文明 | 對應神祇 | 共同特徵 |
|------|----------|----------|
| 蘇美—巴比倫 | 寧辛安娜 / 伊什塔爾 (Ninsianna / Ishtar) | 金星化身、星辰女神 |
| 希臘 | 阿芙蘿黛蒂 (Aphrodite) | 金星之神、愛與美 |
| 羅馬 | 維納斯 (Venus) | 金星化身、黎明之星 |
| 埃及 | 魯特 (Hathor) / 伊西斯 (Isis) | 金星關聯、天界女神 |
| 北歐 | 弗蕾雅 (Freyja) | 金星關聯（弗蕾雅之星）、愛與戰 |
| 中國 | 太白金星 / 婪女 | 金星人格化、星辰崇拜 |
| 日本 | 絢戸津比賣命 (Ahetuhime) | 金星女神、航海指引 |

卡布塔與寧辛安娜的配對關係，在跨文化視角下可與其他文明中金星男神-女神的雙重性對應。希臘傳統中，金星同時由兩位神祇代表——晨星之神福斯佛洛斯（Phosphorus）與昏星之神赫斯珀洛斯（Hesperus）——反映了金星在不同時段的雙重面向。蘇美傳統中卡布塔與寧辛安娜的配對，可能同樣反映了金星作為晨星與昏星的二元性。

## 相關神祇

- **寧辛安娜 (Ninsianna)**：金星之星辰化身，卡布塔最密切的伴神
- **庫拉 (Kulla)**：磚神，常與卡布塔在文獻中混淆
- **伊南娜 (Inanna)**：愛與戰女神，與金星崇拜密切相關
- **恩利爾 (Enlil)**：眾神之父，卡布塔在其神系中的具體位置不明
