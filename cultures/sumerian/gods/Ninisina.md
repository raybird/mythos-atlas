# 妮妮西娜 (Ninisina / Ninisinna)

- **文化：** 蘇美神話 (Sumerian Mythology)
- **職掌：** 治癒女神、伊辛（Isin）的守護女神、「偉大醫者」、聖犬之主

## 概述

Ninisina（妮妮西娜，蘇美語「nin-i₃-si-in-na」意為「伊辛的女主人」）是蘇美神話中最重要的治癒女神，也是伊辛城的守護神。她的神格與犬緊密相連——在蘇美文獻中她被尊為「神犬之女主人」，聖城伊辛的埃伽爾馬赫神廟（Egalmah）考古發掘出土大量犬隻埋葬遺存，證實狗在醫療儀式中的關鍵地位。她同時以「大地最偉大的醫者」（a-zu gal）著稱，掌管疾病之去與來：她能降下瘟疫，也能解除病痛。此雙重力量使她與埃及的塞赫麥特（Sekhmet）、印度的樓陀羅（Rudra）形成精確的職能對應——治癒之神往往同時掌握疾病之權。

妮妮西娜的家族系譜在文獻中略有分歧：主流傳統視她為天神安（An）之女，其夫為拉拉克城之神帕比爾薩格（Pabilsag），子女為復甦與治療之神達穆（Damu）與女神古努拉（Gunura）。她也與巴比倫時期的古拉（Gula）、寧卡拉克（Ninkarrak）等治癒女神相互融合，構成了近東醫療女神信仰的連續譜系。

## 神話事蹟

### 神犬與醫療儀式

妮妮西娜最具特色的神話形象是「犬之女主人」。蘇美讚美詩描寫她「手撫病者、以聖犬之舌舔淨創口」，而伊辛的神廟遺址確實出土了約三十具犬葬——這些犬被作為醫療獻祭品埋葬，病患會觸碰或親近聖犬以求痊癒。此「以犬療傷」的實踐與希臘阿斯克勒庇俄斯（Asclepius）神廟中以聖犬舔舐病患傷口的治療傳統如出一轍，顯示「犬—治癒」的象徵聯盟在古代地中海與近東世界具有深遠淵源。

### 降疫與解疫的雙重權柄

妮妮西娜的讚美詩強調她握有雙向的權柄：她可以「像籠罩大地的疫病一樣」懲罰不敬者，也可以「像春日之雨一樣」清洗病痛。此雙重性使她與塞赫麥特——既降下瘟疫又能治療的獅頭女神——構成最直接的跨文化對照。她的子神達穆繼承了此一職能循環：達穆的死亡象徵疾病與季節衰敗，其復甦則象徵治療與春季回歸，母子共同構成「死亡—治癒」的儀式循環。

### 伊辛的守護女神

作為伊辛的城邦女神，妮妮西娜在烏爾第三王朝（公元前二十一—二十世紀）的國王讚美詩中頻繁出現，被視為王權正當性與公眾健康的雙重來源。國王伊什美·達甘（Išme-Dagan）稱她為「賜我生命之神的母親」，顯示治癒女神在城邦政治中同時扮演皇家守護者的角色——此角色與埃及的伊西斯（Isis）作為法老的保護者、以及日本神話中作為大和朝廷守護者的天照大神具有功能上的平行。

## 跨文化對應

| 文化 | 對應神祇 | 共享特徵 |
|------|---------|---------|
| 希臘 | 阿斯克勒庇俄斯（Asclepius） | 聖犬與蛇為治療象徵，神廟醫術傳統 |
| 埃及 | 塞赫麥特（Sekhmet）／伊西斯（Isis） | 降疫與解疫雙重權柄；護佑王權 |
| 印度 | 樓陀羅（Rudra）／檀梵塔利（Dhanvantari） | 疾病與治癒兼備；醫神與藥學起源 |
| 迦南 | 伊什穆恩（Eshmun） | 治療之神、死而復活之青年神 |
| 中國 | 神農氏／保生大帝 | 嘗百草、醫藥之祖；民間醫療守護神 |
| 日本 | 少彥名神（Sukuna-bikona）／藥師如來 | 醫療之神、溫泉與草藥之神 |

## 相關神祇

- 父親：安（An，天神；部分文獻作恩利爾）
- 配偶：帕比爾薩格（Pabilsag，拉拉克城之神）
- 子女：達穆（Damu，復甦與治療之神）、古努拉（Gunura）
- 融合對象：古拉（Gula）、寧卡拉克（Ninkarrak）、寧伊金納
- 象徵：犬、蛇杖、藥草、淨水
- 崇拜中心：伊辛（Isin，埃伽爾馬赫神廟）、拉拉克（Larak）
