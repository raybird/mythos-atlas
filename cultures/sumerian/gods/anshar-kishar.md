# 安沙爾與基沙爾（Anšar / Kišar）— 蘇美宇宙地平線雙神

- **文化：** 蘇美神話（Sumerian Mythology）
- **職掌：** 天界地平線／大地地平線、宇宙邊界、眾神始祖序列

## 概述

安沙爾（Anšar，楔形文字 𒀭𒊹，意為「整個天界」）與基沙爾（Kišar，𒀭𒆠𒊹，意為「整個大地」）是蘇美-阿卡德創世神系中的第二世代始祖神，象徵宇宙天地的總體邊界。在巴比倫創世史詩《埃努瑪·埃利什》（Enūma Eliš）的神譜序列中，他們位於淡水神阿普蘇（Apsû）與鹹水神提亞瑪特（Tiāmat）之後，第三代眾神之祖安努（Anu，天神）之前。然而在更早的蘇美傳統中，安沙爾與基沙爾並非獨立祭拜的神祇，而是作為宇宙學概念——天與地的極限邊界——被神格化的結果。

## 神話敘事

### 蘇美傳統中的定位

在較早期的蘇美文獻中，宇宙的創生序列為：南姆（Nammu，原始海洋）→ 安（An，天）與琪（Ki，地）。安沙爾與基沙爾在此序列中並未出現，說明他們是阿卡德時期神學家為建立更複雜神系而有意識增補的「過渡神格」。他們填補了從原始水體（阿普蘇／提亞瑪特）到人格化天神（安努）之間的宇宙層級空缺——這在神話學上稱為「神譜的邏輯化重建」（theogenic systematization）。

### 《埃努瑪·埃利什》中的角色

在《埃努瑪·埃利什》泥板第一塊中，創世序列如下：

1. 阿普蘇（淡水之父）與提亞瑪特（鹹水之母）混合其水
2. 生拉赫姆（Laḫmu）與拉哈姆（Laḫamu）——淤泥之神
3. 再生安沙爾與基沙爾——天界地平線與地界地平線
4. 安沙爾生安努（Anu，天神）
5. 安努生努迪穆德（Nudimmud，即恩基／埃阿）

安沙爾在史詩中被描述為「整個天空的圓周」，他召集諸神共同對抗提亞瑪特的混沌軍隊，並最終指定馬爾杜克（Marduk）為對抗混沌的英雄。在此意義上，安沙爾扮演了「眾神議會召集者」的角色，雖然他的具體行動甚少，但其授權使馬爾杜克的英雄之旅具有神聖合法性。

### 宇宙地平線的象徵意義

安沙爾與基沙爾代表宇宙中最早的分化——在原始的天地未分狀態（阿普蘇與提亞瑪特混合之水）之後出現的第一組本體論對立。這種「宇宙分化為對立雙重」的結構在跨文化神話中極為常見：

- 安沙爾（天總體）與基沙爾（地總體）對應於安（天）與琪（地），但後者是具體的、人格化的神，而前者是抽象的邊界概念
- 此雙重結構後來影響了諾斯底主義（Gnosticism）中的「普累若麻」（Pleroma）與「索菲亞」（Sophia）的宇宙二元對立

## 跨文化對應

| 蘇美 Anšar / Kišar | 對應神祇 | 文化 | 共享特徵 |
|---|---|---|---|
| 天總體／地總體 | 烏拉諾斯（Ouranos）／蓋亞（Gaia） | 希臘 | 天地作為宇宙父母 |
| 宇宙地平線邊界 | 霜巨人尤彌爾（Ymir）的眉脊變成的世界邊界 | 北歐 | 以神體邊界定義宇宙範圍 |
| 創世第二世代的過渡神 | 梵天從金卵中誕生之前的原水之態 | 印度 | 創世序列中的「中間狀態」 |
| 從原水分化出的第一對 | 舒（Shu）與泰芙努特（Tefnut） | 埃及 | 從原始神阿圖姆生出的第一對神 |
| 抽象邊界神格化 | 陰陽二氣（未具體人格化） | 中國 | 宇宙分化為二元對立原則 |

安沙爾與基沙爾在神話學上最有意義的跨文化平行是與埃及赫利奧波利斯九柱神（Ennead）的創世序列：阿圖姆（Atum）自生後產生舒（Shu，空氣）與泰芙努特（Tefnut，濕氣）的序列。在這兩個體系中，自原始統一體分化出的第一對神都代表宇宙基本元素的分離——只是蘇美的版本中分化的是天地總體（水平方向），而埃及版本中分化的是空氣與濕氣（垂直方向）。

## 相關神祇

- **父母：** 拉赫姆（Laḫmu）與拉哈姆（Laḫamu）
- **子嗣：** 安努（Anu／An）——天神
- **孫代：** 恩利爾（Enlil）與恩基（Enki / Ea）
- **後繼影響：** 安沙爾在《埃努瑪·埃利什》中為馬爾杜克授予王權，是巴比倫神學中王權合法性的宇宙根源
