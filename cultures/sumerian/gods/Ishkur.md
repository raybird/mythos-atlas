# 伊什庫爾（Ishkur / 阿達德 Adad）

- **文化：** 蘇美爾神話 (Sumerian Mythology)
- **職掌：** 風暴與雷雨之神、天氣、豐饒

## 概述

伊什庫爾（Ishkur，楔形文字 𒀭𒅎）是蘇美爾萬神殿中的風暴與雷雨之神。他的名字在蘇美爾語中意為「山」或「風」，暗示其起源與扎格羅斯山區的雨養農業息息相關。在阿卡德—巴比倫時期，他被稱為阿達德（Adad），成為整個美索不達米亞最重要的天氣之神，與敘利亞—迦南的巴力（Ba'al）神格深度交融。

伊什庫爾在神譜中的地位較為特殊——他通常被視為安（An）之子，或恩利爾（Enlil）之子，文獻記載不一致，反映了不同城邦神學體系的差異。他的配偶是莎拉（Shala，穀物女神），象徵風暴與豐收的連結。

## 神話事蹟

### 風暴與自然之力

伊什庫爾掌管風、雷、雨、洪水——他是自然界狂暴力量的體現。他的聲音是雷鳴，他的呼吸是颶風。在蘇美爾文獻中，他被稱為「天空之龍」或「奔騰的獅子」，他發怒時烏雲遮蔽太陽，暴雨傾瀉大地。

伊什庫爾在農業社會中具有雙面性：他帶來的雨水滋養農作物，但也可能以風暴、冰雹和洪水摧毀一切。蘇美爾人敬畏他，同時祈求他的仁慈。在《伊南娜與伊什庫爾》相關頌詩中，他被描述為「天地的水閘看守者」。

### 與其他神祇的關係

伊什庫爾常被描繪為恩利爾的執行者或戰士——在幾篇神話中，他奉命以洪水或風暴懲罰人類或敵對勢力。他也在眾神會議中擔任重要角色，尤其是在洪水傳說中作為毀滅力量的執行者。

他與太陽神烏圖（Utu）形成對比——烏圖帶來秩序與正義的光明，伊什庫爾則代表自然界的不可預測力量。在巴比倫時期，阿達德與沙馬什（太陽神）經常一同被祭司召喚，作為見證盟約與審判的雙神。

### 崇拜中心

伊什庫爾的主要崇拜中心位於尼普爾（Nippur）和拉爾薩（Larsa），但他在整個美索不達米亞都有影響力。他的神廟稱作「E-dimgalanna」（「天國的神廟」）。在亞述時期，阿達德與亞述主神亞述爾（Ashur）並列，成為皇家供奉的重要對象。

### 占星與象徵

伊什庫爾在美索不達米亞天文學中與行星水星相關聯（有時也與木星相關）。他的象徵物是閃電叉（雙叉或三叉閃電），有時站在公牛背上——這兩種象徵後來影響了希臘的宙斯與印度的因陀羅圖像。

## 跨文化對應

| 文化 | 對應神祇 | 共享特徵 |
|------|---------|---------|
| 阿卡德／巴比倫 | Adad（阿達德） | 本質上同一神祇，阿卡德語名稱，崇拜擴展至整個近東 |
| 迦南／烏加里特 | Ba'al（巴力，哈達德） | 風暴之神，戰勝海神Yam，掌管雨水與豐收 |
| 希臘 | Zeus（宙斯） | 雷電、風暴、天空之主，以閃電為武器 |
| 印度 | Indra（因陀羅） | 雷雨戰神，以金剛杵（vajra）擊殺旱龍弗栗多（Vritra） |
| 北歐 | Thor（索爾） | 雷神，以雷神之鎚（Mjölnir）掌控風暴，保護人類 |
| 中國 | 雷公 | 雷鳴之神，手持雷錘，天庭執行天罰的工具 |
| 赫梯 | Teshub（特舒布） | 風暴之神，以閃電斧戰勝石巨人Ullikummi |

## 相關神祇

- 父：安（An，天空之神）或恩利爾（Enlil，風神）——文獻不一
- 配偶：莎拉（Shala，穀物女神）
- 子：吉比爾（Gibil，火神），一說為其子
- 同行者：烏圖（Utu，太陽神，作為見證者對）
- 對手：無固定神敵，但在部分文獻中與海怪相關聯
