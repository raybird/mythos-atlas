# 吉爾伽美什 (Gilgamesh)

- **文化：** 蘇美神話 (Sumerian Mythology)
- **職掌：** 冥界審判者、英雄與智慧、烏魯克城邦守護
- **象徵：** 雙斧、公牛、雪松、泥板
- **聖城：** 烏魯克 (Uruk)
- **聖數：** 11（十一任冥界法官之一）

## 概述

吉爾伽美什是蘇美神話中最特殊的神祇之一——他原本是烏魯克第一王朝的歷史國王（約公元前 2800–2700 年），死後被神化。在蘇美王表中，他是「盧加爾班達之子、寧孫女神之養子」，在位一百二十六年。與其他神祇不同，吉爾伽美什經歷了從人到神的轉變過程，因此他的神性同時承載著對死亡的理解與對永生的追求——這在神話學中極其罕見。他的形象在美索不達米亞持續傳頌超過兩千年，從蘇美語原件到阿卡德語、赫梯語與胡里安語翻譯，影響力橫跨整個古代近東。

## 神格與職掌

吉爾伽美什的神格主要體現在古迪亞（Gudea）時期與烏爾第三王朝（Ur III）的文獻中。在這些文獻中，他不僅是傳說中的英雄，更是冥界審判者——與寧吉什濟達（Ningishzida）、涅加爾（Nergal）等神祇一同在冥界執行審判功能。烏爾第三王朝的國王們將吉爾伽美什奉為祖先神（dingir-lugal-la）、為其建立神廟並舉行祭祀。

在《吉爾伽美什與庫爾》神話中，吉爾伽美什殺死天牛後被貶入冥界，眾神授予他冥界法官的職位。從此他與其他十一位神祇共同審判亡者的靈魂——這一傳統影響了希臘神話中米諾斯（Minos）與拉達曼提斯（Rhadamanthys）等冥界法官的概念。此外，他還是驅邪儀式與治療咒語中被召喚的神祇，保護生者免受惡靈侵擾。

## 神話事蹟

吉爾伽美什的事蹟可分為「人間英雄」與「冥界神明」兩個階段。作為人間英雄，他與好友恩奇都（Enkidu）共同完成多項壯舉：前往雪松森林擊敗守護者胡瓦瓦（Huwawa）、殺死襲擊烏魯克的天牛。恩奇都死後，吉爾伽美什因恐懼死亡而踏上尋求永生的旅程——他找到洪水倖存者齊烏蘇德拉（Ziusudra）、取得青春之草卻被蛇偷走。這段歷程使他領悟到「永恆不在肉體、而在名聲」的核心智慧。

## 跨文化對應

| 文化 | 對應人物 | 比較要點 |
|------|---------|---------|
| 希臘 | 赫拉克勒斯 (Heracles) | 均為半神英雄完成十二項功績後獲得神格，經歷冥界之旅 |
| 印度 | 阿周那 (Arjuna) | 史詩英雄經歷死亡恐懼後重新理解生命的意義 |
| 北歐 | 齊格菲 (Sigurðr) | 英雄之死與智慧傳承的主題平行 |
| 埃及 | 歐西里斯 (Osiris) | 從冥界君主獲得審判亡靈的功能 |
| 中國 | 后羿 | 人間英雄、求不死藥、最終與死亡和解 |

## 相關神祇

- **恩奇都 (Enkidu)** — 摯友，荒野野人，同赴冒險
- **寧孫 (Ninsun)** — 養母，烏魯克智慧女神
- **盧加爾班達 (Lugalbanda)** — 養父，古烏魯克國王
- **烏圖 (Utu)** — 太陽神，吉爾伽美什的盟友與指引者
- **伊南娜 (Inanna)** — 女神，曾追求吉爾伽美什被拒
