# Ningishzida — 冥界之蛇神

Ningishzida（𒀭𒊩𒌆𒄑𒍣𒁕，又拼作 Ningišzida）是蘇美神話中兼具植物、冥界與星座屬性的男神，其名意為「正直之樹的主人」。他以蛇纏繞樹木的形象聞名，是美索不達米亞藝術中最經典的蛇神。

## 神格與屬性

- **類別：** 冥界神、植物神、星座神（Hydra）
- **象徵：** 纏樹雙蛇、有角蛇龍（Muš-ḫuššu）、生命之樹
- **聖城：** 拉伽什（Lagash）、古爾蘇（Girsu）
- **家族：** 父親為冥界牧神寧阿蘇（Ninazu），母親為寧古拉（Ningula）
- **侍從：** 蛇龍 Muš-ḫuššu（後為馬爾杜克收為座騎）

## 神話敘事

### 蛇與地下世界
Ningishzida 與其父寧阿蘇共享冥界統治權，但 Ningishzida 的冥界職能更偏向守護而非裁決。他是冥界入口的守門者，象徵死亡過渡到新生的轉換點——蛇每年蛻皮的特性使 Ningishzida 成為循環重生之神。他的蛇形象雙蛇交纏於杖桿（類似後世希臘的 Caduceus 雙蛇杖），是美索不達米亞最早的可辨認蛇神圖騰。

### 植物豐饒
Ningishzida 同時被稱為「大地之樹的根基」，掌管樹木與地下水源的聯繫。在拉伽什的傳統中，他的蛇身鑽入地底深處，連結的地下水（Abzu 的延伸）灌溉田野，使作物生長。因此他是農業豐收的隱性守護者——看不見的地下水供應之神。

### 天文身份
在巴比倫天文系統中，Ningishzida 對應水蛇座（Hydra）。《天象指南》（MUL.APIN）記載，Ningishzida 之星位於天球南方，與巨蛇神話相關聯。他在天空中的形象是一條蜿蜒的巨蛇，守護著通往冥界的通道。

### 與古地亞的關係
拉伽什的統治者古地亞（Gudea，約公元前2144—2124年）在其奉獻神像銘文中多次提及 Ningishzida，稱其為「個人神」（個人的守護神）。古地亞的雕像上刻有 Ningishzida 的蛇徽，說明這位神祇在新蘇美時期的貴族個人崇拜中佔有重要地位。

## 跨文化對應

| 蘇美 Ningishzida | 對應神祇 | 文化 |
|---|---|---|
| 蛇纏樹神、豐饒冥界 | 瓦魯那（Varuna）那伽化身 | 印度 |
| 冥界守門蛇神 | 刻耳柏洛斯（Cerberus） | 希臘 |
| 蛻皮重生之神 | 歐西里斯復活之神 | 埃及 |
| 雙蛇杖原型 | 荷米斯雙蛇杖（Caduceus） | 希臘 |
| 連結地下水源的蛇 | 羽蛇神（Quetzalcoatl）地下河關聯 | 中美洲 |
