# 伊什塔蘭 (Ištaran / Ishtaran)

- **文化：** 蘇美神話 (Sumerian Mythology)
- **職掌：** 公正審判、邊界與疆域裁決、蛇形神祇
- **象徵：** 蛇、角蝰與穆舒胡什（mušḫuššu）
- **楔形文字：** 𒀭𒅗𒁲（dKA.DI）或 𒀭𒈲（dMUŠ）

## 概述

伊什塔蘭（Ištaran，亦記作 Ishtaran）是德爾城（Der，位於底格里斯河東岸、接近埃蘭邊境）的守護神，同時是美索不達米亞最早的「公正之神」之一。他的名字在《安＝安努姆》（An = Anum）神名表與韋德納神名表中位居高位，常被比擬為「偉大的安努」（Anu rabû），顯示他在神系中接近眾神之父的地位。與太陽神烏圖（Utu）同為聖法官傳統的核心，伊什塔蘭被稱為「閃耀面容者」（bright of visage），其正義之名在古迪亞（Gudea）與舒爾吉（Shulgi）的王室銘文中成為衡量人間統治者公正程度的標尺。

伊什塔蘭最具辨識度的特徵是其蛇形本質。阿卡德時期的圓柱印章上出現了上身為人、下身為蛇的神祇形象，學者威格曼（Frans Wiggermann）主張此即伊什塔蘭，並將其歸入「底格里斯河外蛇神」（transtigridian snake gods）群——與寧阿祖（Ninazu）、寧吉什齊達（Ningishzida）、提什帕克（Tishpak）等蛇神並列。這些蛇神的神域皆位於美索不達米亞與埃蘭文化交界帶，象徵文明邊界上的秩序守護者。

## 神話事蹟

### 德爾城的蛇門

《神廟讚美詩》（Temple Hymns）第416–423行描述德爾城伊什塔蘭神廟的入口以交纏的角蝰與穆舒胡什（mušḫuššu）裝飾——兩條蛇形生物互相環抱，構成神聖門檻的守衛母題。這座名為「埃丁加爾卡拉馬」（E-dim-gal-kal-am-ma，「土地偉大紐帶之屋」）的神廟由加喜特王朝的庫瑞加爾祖二世（Kurigalzu II）重修，其神廟旁設有圖書館，顯示德爾城在晚期仍是重要的書寫與學術中心。蛇的圖像在此不僅是神祇的象徵，更代表「界線的神聖化」——正如蛇蛻皮重生，邊界也在衝突與和解中不斷重新界定。

### 烏瑪—拉格什的裁決者

伊什塔蘭最重要的司法事蹟見於烏瑪（Umma）與拉格什（Lagash）的邊界衝突。烏瑪城與拉格什城在早王朝時期數度開戰爭奪富庶的灌溉田（古埃迪那，Gu-Edinna），最初由基什王梅西林（Mesilim）以伊什塔蘭之名立碑裁定邊界。此後雙方統治者——拉格什的恩特梅納（Entemena）與烏瑪的噶爾薩姆（Garsam／烏什）——的銘文均記載伊什塔蘭作為「中立的第三方裁決者」介入，其判斷被視為神聖契約的範本。學者指出，伊什塔蘭之所以被選為裁決神，正因其所在城市的邊境位置——德爾城本身就是一條「活界線」，讓蛇神成為「界域之神」（god of boundaries）的完美化身。

### 正義的標準

在《尼努爾塔的讚美詩》與舒爾吉讚美詩中，伊什塔蘭被反覆引為公正的標準：「如同伊什塔蘭一般作出正確的裁決」、「吾之正義可比伊什塔蘭」。這類比喻表明，伊什塔蘭在美索不達米亞文化中已經超越單純的城邦神祇，成為抽象「司法公正」的人格化象徵——類似於後世希臘的忒彌斯（Themis）或埃及的瑪亞特（Ma'at），但以男神之姿承載此一抽象原則，在近東神話中格外突出。

## 跨文化對應

| 文化 | 對應神祇 | 共享特徵 |
|------|---------|---------|
| 蘇美 | 烏圖（Utu／Shamash） | 太陽正義、司法之光照耀 |
| 希臘 | 忒彌斯（Themis）／阿波羅 | 神諭裁決、習慣法秩序 |
| 埃及 | 瑪亞特（Ma'at） | 真理與正義的人格化 |
| 印度 | 伐樓那（Varuṇa） | 契約與誓約的守護、宇宙秩序 |
| 波斯 | 密特拉（Mithra） | 誓約、契約與冥界審判 |
| 中國 | 皋陶 | 神性裁判者，以獬豸辨曲直 |
| 北歐 | 佛塞提（Forseti） | 諸神會議中的和解與調解者 |
| 希伯來 | 摩西律法中的「審判者」 | 神授法律秩序的神聖源頭 |

伊什塔蘭的蛇形本質使他在「蛇＝智慧／秩序」象徵系譜中占據獨特位置：不同於混沌巨蛇庫爾（Kur）或提亞瑪特（Tiamat），伊什塔蘭的蛇是友善的、裁決性的——蛇在此不再代表必須屠殺的混沌，而代表必須尊重與遵守的界線。六合龜、角蝰與穆舒胡什的纏繞圖像，將「蛇」的意義從威脅轉化為守護，是美索不達米亞宗教中少數以蛇為正面司法象徵的事例。

## 相關神祇

- **孫／使者：** 尼拉赫（Nirah，「小蛇」），伊什塔蘭之使者、蛇形神祇，於庫杜魯（kudurru）界碑上常以盤繞的蛇形現身
- **配偶：** 莎拉特-德爾（Šarrat-Deri，「德爾女王」），晚期文獻中的德爾城女神
- **父親：** 烏拉什（Urash）——依部分傳統，伊什塔蘭為安（An）與烏拉什之孫輩
- **對應／混淆：** 尼努爾塔（Ninurta）、寧阿祖（Ninazu）、寧吉什齊達——同屬「底格里斯河外蛇神」群
- **關聯：** 沙瑪什（Shamash）——正義之神的兩位代表
