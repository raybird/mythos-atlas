# 沙拉（Šara）

- **文化：** 蘇美神話（Sumerian Mythology）
- **職掌：** 戰爭、雨水、豐收、烏瑪城（Umma）的守護神
- **象徵：** 獅鷲（Anzû bird）、戰鎚、豐收穀穗
- **相關神祇：** 伊南娜（Inanna，母親）、寧烏爾（Ninurta，對應戰神）

## 概述

沙拉（Šara / Shara）是蘇美神話中烏瑪城（Umma）的守護神，被認為是愛與戰爭女神伊南娜（Inanna）之子。他的名字在楔形文字中寫為𒀭𒊬𒊏，與「豐收」及「穀物」的語根相關。沙拉既是戰爭之神——為烏瑪對抗拉格什（Lagash）的軍事行動提供神力庇護——也是農業豐收之神，掌管穀物生長與雨水降臨。他的雙重性格（毀滅與生產）反映了蘇美文明中戰爭與農業交替的週期性節奏。在蘇美神系中，沙拉的地位在早王朝時期（公元前 2900-2334 年）達到高峰——烏瑪城強盛時，沙拉的祭祀擴展至周邊地區。烏瑪第三王朝時期有多篇獻給沙拉的頌歌流傳。

## 神話事蹟

### 伊南娜之子

沙拉被記載為伊南娜與某位不知名配偶的兒子。在一篇來自 Fara（Šuruppak）的早王朝神名表中，沙拉被列為伊南娜的直系後裔。烏瑪城的獻祭文獻記錄了沙拉與伊南娜共享同一神廟的傳統——在烏瑪城的 E-sara 神廟中，伊南娜與沙拉一同接受供奉。此母子共享神廟的現象在蘇美宗教中並不常見，凸顯了沙拉作為「繼承母親權威」的角色。

### 烏瑪的戰神

沙拉最著名的傳奇是他作為烏瑪城軍事力量的守護者。在烏瑪與拉格什的長期邊界戰爭中（詳細記載於拉格什的邊界石碑 Entemena 圓錐銘文，約公元前 2400 年），烏瑪的統治者在每次出征前向沙拉獻祭祈求戰勝。沙拉被描繪為乘坐獅鷲戰車衝入敵陣的神——他的戰鎚落下之處，敵人如麥稈般倒伏。拉格什方面的銘文則記載拉格什守護神寧吉爾蘇（Ningirsu）最終擊退了沙拉——此為城邦戰爭神話化的典型案例，雙方各有其神保護。

### 豐收之神

除了戰爭屬性之外，沙拉也是一位農業神。烏瑪城的年曆中有一個名為「沙拉的穀物之旅」的節日——春季播種時，祭司將沙拉的雕像從神廟中抬出，巡遊田地以祝福收成。此節日持續三天，期間禁止軍事行動。

## 跨文化對應

| 文化 | 神祇 | 相似點 |
|------|------|--------|
| 希臘 | 阿瑞斯（Ares） | 戰爭之神，但阿瑞斯無農業連結 |
| 羅馬 | 馬爾斯（Mars） | 戰神兼任農業之神——與沙拉最接近的對應 |
| 北歐 | 提爾（Týr） | 戰爭之神，犧牲手臂以維護契約 |
| 印度 | 卡爾提凱亞（Kartikeya） | 戰爭之神，為濕婆之子 |
| 蒙古 | 達伊奇．騰格里（Daichi Tengri） | 戰神，賜予軍事勝利 |
| 迦南 | 巴力（Baal） | 雷雨與豐收之神，戰勝混沌海怪 |

沙拉最引人注目的跨文化對應是羅馬的馬爾斯（Mars）——從最初以農業神為主的形象，在頻繁戰爭的社會中逐漸被戰爭屬性覆蓋。馬爾斯在羅馬共和時期同時是出征前的祈禱對象與農夫祈禱豐收的神祇；沙拉在蘇美早王朝時期也肩負完全相同的雙重職掌。

## 相關神祇

- **伊南娜（Inanna）**：母親，愛與戰女神
- **寧烏爾（Ninurta）**：拉格什對應戰神，兼任農業神
- **寧吉爾蘇（Ningirsu）**：拉格什守護神，沙拉的對手
- **杜姆茲（Dumuzi）**：伊南娜的配偶（沙拉的潛在繼父）
