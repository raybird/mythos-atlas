# 齊烏蘇德拉 (Ziusudra)

- **文化：** 蘇美神話 (Sumerian Mythology)
- **職掌：** 洪水英雄、智慧之王、永生者
- **其他名稱：** 阿卡德語：烏特納匹什提 (Utnapishtim)；聖經：諾亞 (Noah)

## 概述

齊烏蘇德拉（Ziusudra，意為「遠見者／長久生命」）是蘇美洪水神話中的主角，也是人類歷史上最早的文字化洪水傳說的主人公。他的名字出現於公元前約2100年的蘇美泥板《齊烏蘇德拉洪水故事》（CBS 10673）中，作為舒魯帕克（Shuruppak）城的國王，受到恩基（Enki）的警告而建造方舟，保存人類與動物的種子。他是「大洪水前的八位國王」中的最末一位，統治期記錄於蘇美王表之中。洪水之後，他獲得永生，被遷往迪爾蒙（Dilmun，神話中的樂園），成為「永生者」的原型。

## 神話事蹟

### 洪水預警與方舟建造

人類的嘈雜與繁衍使眾神之王恩利爾（Enlil）無法安眠，他決議以洪水毀滅全人類。水神恩基（Enki）違背眾神集體決議，對齊烏蘇德拉發出預警。恩基以暗語指示：「蘆葦牆啊，仔細聆聽！拆除房屋，建造船隻；捨棄財富，尋求生命。」齊烏蘇德拉依指示建造了一艘巨大的方形船隻（與後世吉爾伽美什版本中的立方船不同），帶入各類動物與植物的種子。

### 七日洪水

洪水肆虐七日七夜，天地間一片汪洋。齊烏蘇德拉在船中見證了毀滅性的黑暗與風暴。洪水退後，他打開船窗，獻上牛羊與香祭。神聞到香氣後「如蒼蠅般聚集」，恩利爾見人類餘存勃然大怒，指責恩基洩漏天機。恩基曉以大義，恩利爾終回心轉意，賜予齊烏蘇德拉永生，將其安置在迪爾蒙──神話中被稱為「太陽升起之地」的無病無痛樂園。

### 作為智慧傳承者

齊烏蘇德拉同時被視為智慧與知識的守護者。在蘇美傳統中，他在洪水前保存了文明的法則與技藝（Me），使人類文明得以延續。此一母題直接影響了後世希臘神話中的杜卡利翁（Deucalion）與聖經中的挪亞傳說。

## 跨文化對應

| 齊烏蘇德拉 | 對應神祇/英雄 | 文化 |
|---|---|---|
| 方舟、洪水後獻祭、獲永生 | 烏特納匹什提 (Utnapishtim) | 巴比倫（《吉爾伽美什》） |
| 義人獲預警造方舟 | 挪亞 (Noah) | 希伯來（聖經《創世記》） |
| 保存人類種子、洪水後重啟文明 | 杜卡利翁 (Deucalion) | 希臘 |
| 以方舟保存生物種子 | 摩奴 (Manu) 與摩蹉魚 | 印度 |
| 恩基預警 | 恩基/Ea 智慧之神幫助人類 | 美索不達米亞 |
| 洪水前保存文明知識 | Yima 建造 Vara 保存種子 | 波斯 |

## 相關神祇

- **恩基 (Enki/Ea)：** 預警齊烏蘇德拉，人類的保護者
- **恩利爾 (Enlil)：** 降下洪水，後與齊烏蘇德拉和解
- **烏特納匹什提：** 巴比倫版本中的洪水英雄（吉爾伽美什史詩第十一塊泥板）
