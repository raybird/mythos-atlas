# 赫爾 Hel（冥界女王）

## 基本資料

- **古諾斯語**：Hel（意為「隱藏者」）
- **家族**：洛基（Loki）與安格爾波達（Angrboða）之女
- **手足**：芬里爾巨狼（Fenrir）、約爾孟甘德巨蛇（Jörmungandr）
- **統治領域**：赫爾海姆（Helheim／Niflheim）——九界之一的冥界
- **英文語源**：現代英語 Hell 一詞即源於 Hel

## 神格概述

赫爾是北歐神話中冥界的統治者，掌管所有非戰死者的靈魂——包括病死、老死或意外身亡之人。她的形象極為獨特：半身為常人膚色，半身為藍黑色，面容陰鬱兇狠。她的居所是一座名為「Éljúðnir」（暴風雪）的巨殿，圍牆高聳、大門宏偉。殿中的器物名稱無不刻意反映死亡的匱乏與悲哀——

- 餐盤名為「飢餓」（Hungr）
- 餐刀名為「饑荒」（Sultr）
- 僕人名為「懶行者」（Ganglati）與「慢行者」（Ganglöt）
- 門檻名為「絆腳石」（Fallandaforað）
- 床名為「疾病」（Kör）
- 床簾名為「災禍」（Blíkjandaböl）

## 神話事蹟

赫爾最著名的登場是在巴德爾（Baldr）之死的神話中。光明之神巴德爾被洛基設計殺害後，眾神派遣赫爾莫德（Hermóðr）騎奧丁的八足神駒斯萊普尼爾（Sleipnir）前往冥界，懇求赫爾釋放巴德爾。

赫爾提出條件：「若世上萬物——無論有生命或無生命——都為巴德爾哭泣，我便放他回去。」眾神走遍世界，萬物皆為巴德爾落淚，唯獨一個名叫索克（Þökk）的女巨人拒絕（學者普遍認為是洛基偽裝）。巴德爾因此留在冥界，直到諸神黃昏之後才得以復活。

## 學術爭論

關於赫爾究竟是古北歐人實際崇拜的女神，還是後期文學的擬人化，學界存在分歧。史諾里·斯圖魯頌（Snorri Sturluson）的《散文埃達》提供了赫爾最詳細的描述，但部分學者（如H. R. Ellis Davidson）認為這些細節受到基督教地獄觀念的影響。雅各布·格林（Jacob Grimm）則將赫爾與印度教的迦梨（Kālī）進行比較，稱其為「半女神」，認為赫爾的地位在原始日耳曼宗教中遠比後世文獻所呈現的更高。

## 跨文化對應

| 文化 | 冥界神祇 | 共通點 |
|------|---------|--------|
| 美索不達米亞 | 厄瑞什基加爾（Ereshkigal） | 冥界女王、嚴酷冷漠、冥界即死的歸宿 |
| 希臘 | 黑帝斯（Hādēs）／泊瑟芬（Persephone） | 冥界統治者、死者審判、與赫爾同為「接收靈魂者」 |
| 埃及 | 歐西里斯（Osiris）／阿努比斯（Anubis） | 死者之王／亡者引導者，審判死者的心臟 |
| 日本 | 伊邪那美（Izanami） | 黃泉國主，因死亡而污穢，無法返回人間 |
| 印度 | 閻魔（Yama） | 死亡之神、死者審判、掌管正義 |
| 阿茲特克 | 米克特蘭特庫特利（Mictlantecuhtli）與米克特卡西瓦特爾（Mictecacihuatl） | 冥界夫婦統治者、九層冥界 |
