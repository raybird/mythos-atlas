# 福爾塞提 Forseti（正義與和解之神）

## 基本資料

- **古諾斯語**：Forseti（意為「仲裁者」或「主席」）
- **父親**：光明之神巴德爾（Baldr）
- **母親**：南娜（Nanna）
- **居所**：Glitnir（閃耀之殿），據《散文埃達》描述，其殿堂以金柱銀頂為頂，方圓百里可見光芒
- **職掌**：正義、法律、和解、仲裁

## 神格概述

福爾塞提是北歐神話中掌管司法與爭端調解的神祇，為巴德爾與南娜之子。在諸神之中，他的地位相對含蓄——不同於奧丁的智慧、索爾的力量或芙蕾雅的魅惑，福爾塞提代表的是理性、公正與人際和解的力量。他被認為是所有法庭與仲裁者的守護神，訴訟雙方在法庭陳述前，皆會向福爾塞提祈禱以求公正裁決。

《散文埃達》中僅以寥寥數語記述福爾塞提：「巴德爾與南娜生子福爾塞提，他居於閃耀之殿，那裡充滿了法庭與仲裁。」然而，學者普遍認為，這段簡短的描述隱含了比文字更豐富的宗教內涵——福爾塞提可能代表了北歐社會中一種古老的司法制度與仲裁傳統。

## 神話事蹟

### 傳說一：海爾頓的仲裁

根據斯諾里的記載（部分學者認為出自已佚失的早期薩迦），荷蘭海爾頓（Heelten）地区的两名男子因財產糾紛訴諸仲裁。福爾塞提出現在他們面前，聆聽雙方的陳述後做出了公正的裁決。雙方皆心悅誠服地接受，從此該地成為一個重要的法律聖地。這則故事揭示了福爾塞提在北歐社會中的核心功能：他不是以暴力壓制爭端，而是以智慧化解矛盾。

### 傳說二：巴德爾之死後的沉默

巴德爾被洛基設計殺害後，光明消逝。福爾塞提作為巴德爾之子，在諸神黃昏前的黑暗時代中承擔了父親留下的正義使命。有學者認為，福爾塞提的「沉默」——在北歐文獻中極少被提及——本身就象徵著「正義在亂世中的邊緣化」。當諸神忙於與巨人族的永恆衝突時，福爾塞提獨自守護著那個即將崩潰的秩序。

## 跨文化對應

| 文化 | 正義/仲裁神祇 | 共通點 |
|------|-------------|--------|
| 希臘 | 忒弥斯（Themis）／狄刻（Dikē） | 正義女神、法律與秩序的守護者、手持天秤 |
| 羅馬 | 朱斯蒂蒂亞（Iustitia） | 正義的擬人化、天秤與寶劍 |
| 埃及 | 瑪亞特（Ma'at） | 真理與正義女神、心臟秤量的標準 |
| 印度 | 摩尼（Manu）／閻魔（Yama） | 法律制定者與執行者、道德秩序的守護 |
| 美索不達米亞 | 沙馬什（Shamash） | 太陽與正義之神、法庭的守護者 |
| 中國 | 皋陶（Gao Yao） | 上古司法之神、以獬豸觸邪辨曲直 |

福爾塞提與其他文化的正義神祇存在一個關鍵差異：他不以「懲罰」為主要功能，而以「調解」為核心。忒弥斯與瑪亞特代表的是宇宙的絕對秩序，閻魔與沙馬什代表的是道德審判的執行力，而福爾塞提的「仲裁」更接近一種人際間的和解機制。這反映了北歐社會中「法律集會」（þing）制度的特徵——解決爭端的方式不是由上而下的裁決，而是由社群共同參與的調解過程。

## 相關神祇

- **巴德爾**（Baldr）：父親，光明之神
- **南娜**（Nanna）：母親，忠貞女神
- **提爾**（Týr）：戰神兼正義之神，與福爾塞提共享「正義」神格，但提爾偏向戰場上的勇敢與犧牲，福爾塞提則偏向法庭上的理性與和解
- **奧丁**（Óðinn）：智慧之神，曾以一隻眼睛換取智慧——與福爾塞提以「理解」解決爭端形成互補

## 學術爭論

學者對福爾塞提的身份存在不同解釋：

1. **巴德爾之子說**：斯諾里明確將福爾塞提列為巴德爾之子。多數現代學者接受此說法，認為福爾塞提是光明之神的後裔——正義是光明的延續。
2. **弗雷（Freyr）的別名說**：部分十九世紀學者（如 Jacob Grimm）曾推測福爾塞提可能與豐收之神弗雷存在關聯，因為弗雷也是和平與繁榮的象徵。但此說法在二十世紀後已不被主流接受。
3. **歷史制度反映說**：H. R. Ellis Davidson 認為福爾塞提的存在直接反映了北歐法律集會（þing）的宗教背景——仲裁不僅是法律行為，更是一種神聖儀式。
