# 尼奧爾德 (Njörðr / Njord)

- **文化：** 北歐神話 (Norse Mythology)
- **職掌：** 海洋、風、航海、漁業、財富

## 概述

尼奧爾德（古北歐語 Njörðr）是北歐神話中掌管海洋、風與財富的華納神族（Vanir）神祇。他是弗雷（Freyr）與芙蕾雅（Freyja）的父親，在北歐萬神殿中擁有獨特的地位——他既是華納神族的核心成員之一，也是阿薩神族（Æsir）與華納神族簽訂和平協議後作為人質交換至阿斯嘉特的神祇之一。

不同於索爾或奧丁的戰鬥形象，尼奧爾德是一位與海上貿易、漁業豐收、財富積累密切相關的和平之神。維京時代的北歐人——既是掠奪者也是商人與探險家——將尼奧爾德視為遠航的安全守護者。他的居所諾阿通（Nóatún，船塢）位於海邊，象徵著他與海洋的不可分割性。

## 神話事蹟

### 與絲卡蒂的失敗婚姻

尼奧爾德最著名的神話是他與女巨人絲卡蒂（Skaði）的短暫婚姻。絲卡蒂的父親夏基（Þjazi）被阿薩神族殺害後，她全副武裝來到阿斯嘉特要求賠償。諸神同意她以挑選丈夫的方式獲得補償——但條件是她只能看到腳來選擇。絲卡蒂希望選中最英俊的巴德爾，卻選中了雙腳最美麗的尼奧爾德——因為他的腳被海水沖刷得異常潔白。

然而這場婚姻從一開始就註定失敗：尼奧爾德來自海邊的諾阿通，絲卡蒂來自雪山中的約頓海姆。他們協議輪流居住在對方的領地。在尼奧爾德的海邊，絲卡蒂無法忍受海鷗的叫聲與海浪的喧囂；在絲卡蒂的雪山中，尼奧爾德無法忍受狼嚎的淒厲與刺骨的寒風。最終兩人分居——尼奧爾德回到諾阿通，絲卡蒂回到約頓海姆。

此神話反映了北歐世界中海洋文化與內陸文化的根本衝突。尼奧爾德代表依海為生的斯堪地那維亞沿海居民，絲卡蒂代表北方山區的狩獵採集族群——兩者的生活模式完全不同，無法透過婚姻來調和。

### 財富的賜予者

尼奧爾德在《散文埃達》中被描述為「擁有大量財富者，能賜予土地與動產給向他祈禱的人」。北歐人在出海貿易或捕魚之前會向尼奧爾德獻祭，祈求風平浪靜與豐收。在維京時代的斯堪地那維亞，尼奧爾德的崇拜與農民的豐收願望及商人的貿易成功緊密相連。他與兒子弗雷共同掌管豐饒——尼奧爾德掌管海洋的豐饒（魚、貿易利潤），弗雷掌管陸地的豐饒（農作物、和平）。

### 華納神族的代表

尼奧爾德在阿薩—華納戰爭中扮演了關鍵角色。當兩族神祇以人質交換達成和平時，尼奧爾德與他的兒子弗雷被派往阿斯嘉特，成為華納神族在阿薩神族中的代表。尼奧爾德不僅在阿斯嘉特站穩了腳跟，還與奧丁等阿薩主神共享權力——這在北歐神話中極為罕見，象徵著海洋文明在諸神中的永久地位。

## 跨文化對應

| 文化 | 對應神祇 | 共享特徵 |
|------|---------|---------|
| 希臘 | 波塞冬（Poseidon） | 海洋之神，但波塞冬更暴力且具地震屬性，非財富之神 |
| 羅馬 | 涅普頓（Neptune） | 海神，主要掌管航海，不涉財富 |
| 埃及 | 努恩（Nun）／奧西里斯（Osiris） | 原初之水（Nun）／掌管豐收與死亡之神（Osiris） |
| 凱爾特 | 瑪納諾·麥克·列（Manannán mac Lir） | 海神、航海保護者、魔法與財富之神——與尼奧爾德最為接近 |
| 印度 | 伐樓那（Varuna） | 水神、宇宙秩序與海洋的守護者 |
| 中國 | 媽祖（Mazu） | 航海守護神，海上的庇護者，不涉財富 |
| 日本 | 綿津見神（Watatsumi） | 海神，掌管海洋生物與航海安全 |

## 相關神祇

- **弗雷（Freyr）：** 兒子，豐收與和平之神，共同掌管陸地豐饒
- **芙蕾雅（Freyja）：** 女兒，愛情與戰爭女神，北歐魔法的大師
- **絲卡蒂（Skaði）：** 前妻，女巨人，冬季狩獵之神
- **奧丁（Odin）：** 阿薩神族之主，尼奧爾德在阿斯嘉特的對等合作者
- **瑟路德（Særðr）：** 某些文本中提及的尼奧爾德與絲卡蒂之子，但資料殘缺不全
