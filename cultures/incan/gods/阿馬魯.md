# 阿馬魯 (Amaru / Amaro / Katari)

- **文化：** 印加神話 (Incan Mythology)
- **職掌：** 水與彩虹之蛇、地下世界（Ukhu Pacha）的守護者、地震與智慧之神

## 概述

阿馬魯（Amaru，克丘亞語意為「蛇」或「龍」；艾馬拉語稱 Katari）是安地斯宇宙觀中最具代表性的神聖巨蛇。在印加人的三界結構中，禿鷹（Kuntur）屬於上天世界 Hanan Pacha、美洲豹（Puma）屬於現世 Kay Pacha，而蛇（Amaru）則屬於地下世界 Ukhu Pacha——這三種聖獸構成了印加宇宙的三角象徵（chakana，階梯十字）。阿馬魯的形象在不同傳說中有所變異，但蛇形始終不變：有文獻描述牠擁有水晶般的眼睛、紅色的口鼻、駱馬的頭、安地斯鹿（taruka）的角與魚尾；有時又呈現為雙頭巨蛇，兩個頭分別具有美洲豹與禿鷹的特徵，象徵對立力量的調和。牠棲居於大地深處的洞穴、湖泊與泉源之中，掌控著灌溉農田的生命之水。

## 神話事蹟

### 地下世界的巨蛇與地震

在印加人的信仰中，阿馬魯盤踞於 Ukhu Pacha——即「下方的世界」，既是亡者之域，也是地下水源與祖先的發源地。牠在地底蠕動時，大地便會震動：安地斯人將地震理解為「巨蛇的翻身」。由於地震與山崩往往伴隨水患，阿馬魯同時被視為洪水與地變的肇因，這使牠既受到敬畏，也被以古柯葉、玉米酒（chicha）與駱馬祭品安撫。殖民時期的編年史家，如印卡·加西拉索·德·拉·維加（Garcilaso de la Vega）與《新知與治國良政》（*Nueva corónica y buen gobierno*，1615）的作者瓜曼·波馬·德·阿亞拉（Guaman Poma de Ayala），皆記載了安地斯人對地下巨蛇的信奉。

### 彩虹（k'uychi）與水的化身

阿馬魯最特別的神話面向在於與彩虹（克丘亞語 k'uychi）的關聯。彩虹被視為巨蛇的顯現——正如印度神話中那伽與雨、中美洲羽蛇神與水的關係，安地斯人也相信彩虹蛇掌管天降之水與泉源的分佈。因此阿馬魯既是地上的河道之蛇，也是天上的虹橋之蛇：河水蜿蜒如蛇行，虹則橫跨天際連結雲雨。由於虹蛇與洪水、雷雨的關聯，印加人忌諱用手指指向彩虹，以免招致蛇的憤怒。在秘魯胡寧（Junín）地區由小說家荷西·馬利亞·阿格達斯（José María Arguedas）記錄的傳說中，阿馬魯被描繪為棲息於萬卡湖（Wanka）中的有翼巨龍，長著駱馬頭、蛙身與蛇尾；傳說中的虹（tulunmaya）還創造了另一條色澤較深的阿馬魯作為同伴，兩蛇為爭奪湖中岩石而展開搏鬥。

### 智慧之神的形象

阿馬魯同時是知識與智慧的象徵。印加人的「知識之家」（Yachay Wasi，即培養天文、歷史與靈性學問的機構）中繪有阿馬魯的圖像，象徵蛇所代表的洞見與理解力。蛇蜕皮重生的特性也被納入神話：死亡並非終結，而是如蜕皮般的轉化與更新——這使阿馬魯成為生命循環、祖先回歸與重生觀念的核心象徵。

### 王權與抵抗的象徵

阿馬魯的圖騰還滲入印加王權的血脈。末代印加皇帝圖帕克·阿馬魯一世（Túpac Amaru I，1572 年被西班牙處決）及其後裔、1780–81 年起義反抗殖民統治的圖帕克·阿馬魯二世，皆以這條聖蛇命名——巨蛇從神話神祇轉化為抵抗與復興的旗幟，象徵印加文明在其後數百年間的持續記憶。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 澳洲原住民 | 彩虹蛇（Rainbow Serpent） | 虹與水的化身、開鑿河道、掌管洪枯 |
| 印度神話 | 那伽（Nāga）／舍沙（Śeṣa） | 水蛇、雨與泉源、智慧、地底棲居 |
| 中美洲神話 | 羽蛇神（Quetzalcoatl／Kukulkan） | 蛇與天之水、智慧之神、創世 |
| 中國神話 | 應龍／龍 | 水、河流與降雨的掌管者 |
| 美索不達米亞 | 提亞瑪特（Tiamat） | 原初水蛇、洪水與混沌的化身 |
| 埃及神話 | 阿佩普（Apep） | 地底／深淵之蛇、與天界秩序對抗 |
| 北歐神話 | 耶夢加得（Jörmungandr） | 環繞大地的世界蛇、海與地震的關聯 |

## 相關神祇

- **Ukhu Pacha（地下世界）**——阿馬魯的棲居領域，同時與 Supay（冥界之王）有所重疊
- **Pachamama（大地之母）**——地下的水與地底資源皆屬大地之母的領域，阿馬魯是其水脈的守護者
- **Inti（太陽神）**——彩虹連結上天與人間，被視為太陽光芒經水折射的顯現
- **Illapa（雷電神）**——雷、雨、虹與蛇在水循環中密切相關
- **Viracocha（創世神）**——部分傳說將阿馬魯視為與創世有關的遠古生靈
