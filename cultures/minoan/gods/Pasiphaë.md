# 帕西淮 (Pasiphaë)

- **文化：** 米諾斯神話 (Minoan Mythology)／希臘神話 (Greek Mythology)
- **職掌：** 月亮與太陽的女神、巫術、神諭、米諾斯女王

## 概述

帕西淮（Pasiphaë，希臘語 Πασιφάη，意為「全部照耀者」）是米諾斯神話中最複雜的女性人物——她既是太陽神赫利俄斯（Helios）與海洋女神珀耳塞伊斯（Perseis）之女，也是克里特國王米諾斯（Minos）的王后，以及代達羅斯建造的迷宮中彌諾陶洛斯（Minotaur）的母親。她與魔女瑟西（Circe）和美狄亞（Medea）同為赫利俄斯的後代，繼承了強大的巫術與預言能力。

在更古老的神話層次中，帕西淮最初可能是一位米諾斯的月亮女神或神聖王后——她的名字「全部照耀者」暗示她與月球反射陽光的功能相關。她在克諾索斯宮廷中的角色不僅是國王的配偶，更是神聖儀式的執行者：代表女神在人間的化身，透過神聖婚姻（hieros gamos）確保王權的合法性。

## 神話事蹟

### 赫利俄斯之女

帕西淮是太陽神赫利俄斯與海洋女神珀耳塞伊斯所生的女兒之一。她的兄弟姐妹包括魔女瑟西、科爾喀斯國王埃厄忒斯（Aeëtes，美狄亞之父）。帕西淮從父親赫利俄斯處繼承了預言能力，能解讀星辰的運動與動物的行為。她在嫁給米諾斯之前，是科爾喀斯地區的一位公主——因此她的故事與科爾喀斯—克里特之間的神話聯繫相關。

### 米諾斯的王后

米諾斯為了證明自己應繼承克里特王位，向海神波賽頓祈禱。波賽頓從海中送出一頭白色的公牛，作為米諾斯王權的標誌，但要求米諾斯將公牛獻祭歸還。米諾斯因公牛的美麗而違背諾言。作為懲罰，波賽頓讓帕西淮對公牛產生了無法抑制的慾望。帕西淮請求代達羅斯為她製作一頭中空的木製母牛——她藏身其中與公牛結合，生下彌諾陶洛斯（Minotaur，意為「米諾斯的公牛」）。

此神話在古典時代被解讀為對米諾斯背約的神聖懲罰，但在更深的神話結構中，帕西淮與公牛的結合反映了米諾斯文明中牛的神聖地位——公牛是力量與王權的象徵，女王與公牛的性結合可能曾是米諾斯新年儀式的一部分。

### 巫術與神諭

帕西淮與她的姐妹瑟西一樣，精通草藥與咒術。有傳說認為她曾以咒語使米諾斯忠於她——每當米諾斯與別的女人同床，那些女人將被蛇蠍咬死。米諾斯用另一種方式迴避了這道咒語——普洛克里斯（Procris）給了米諾斯一種草藥，使他的精子轉化為毒蟲殺死不忠的女性伴侶。帕西淮的巫術能力使她在希臘神話中被歸入「危險的智慧女性」原型——與美狄亞、瑟西和狄安娜（Diana）的神話相連。

### 女兒阿里阿德涅與忒修斯

帕西淮與米諾斯的女兒阿里阿德涅（Ariadne）繼承了母親的智慧。當雅典王子忒修斯來到克里特作為彌諾陶洛斯的祭品時，阿里阿德涅以線團幫助他逃出迷宮——這是帕西淮與波賽頓之間原有衝突的最終和解。帕西淮作為彌諾陶洛斯的母親與忒修斯逃生的間接促成者，在迷宮神話中扮演了「起源」與「終結」的兩端連接者角色。

## 跨文化對應

| 米諾斯／希臘 | 跨文化對應 |
|------------|-----------|
| 帕西淮（月神／赫利俄斯之女） | ↔ 埃及哈索爾（Hathor，太陽之女、聖牛之母） |
| 帕西淮（與公牛結合） | ↔ 埃及哈索爾（Hathor，牛女神） |
| 不忠遭到神罰的王后 | ↔ 美索不達米亞伊南娜（Inanna，與牧羊人杜姆茲的關係） |
| 智慧女性的危險力量 | ↔ 美狄亞（Medea）、瑟西（Circe） |
| 神聖婚姻中的女王 | ↔ 馬雅神話中的女王與蛇／雨神的儀式結合 |
| 帕西淮之名「全部照耀者」 | ↔ 日本天照大神（Amaterasu，太陽女神） |

## 相關神祇

- **Helios（赫利俄斯）** — 帕西淮之父，太陽神的化身
- **Minos（米諾斯）** — 帕西淮之夫，克里特國王
- **Ariadne（阿里阿德涅）** — 帕西淮之女，米諾斯的公主
- **Minotaur（彌諾陶洛斯）** — 帕西淮與公牛所生之子
- **Daedalus（代達羅斯）** — 為帕西淮建造木製母牛的工匠
- **Circe（瑟西）** — 帕西淮的姐妹，埃埃亞島魔女
