# 阿里阿德涅 (Ariadne)

- **文化：** 米諾斯神話 (Minoan Mythology)／希臘神話 (Greek Mythology)
- **職掌：** 迷宮的女主人、婚姻與蛻變之神、線團的給予者

## 概述

阿里阿德涅（Ariadne）是米諾斯國王彌諾斯（Minos）與帕西淮（Pasiphaë）的女兒，在希臘古典時期的神話體系中，她同時具有米諾斯公主與女神祭祀的雙重身分。她的名字在米諾斯線性文字B中可能意為「極其聖潔者」。阿里阿德涅以授予忒修斯線團使其從迷宮中生還而聞名，但神話的更深層記錄了她從凡人公主轉化為不朽女神的神聖婚姻（hieros gamos）過程——從克諾索斯到納克索斯再到奧林帕斯，阿里阿德涅的軌跡是米諾斯文明對希臘神話影響的最佳見證。

## 神話事蹟

### 線團與迷宮

雅典王子忒修斯作為貢品之一抵達克諾索斯，將被送入迷宮成為彌諾陶洛斯的祭品。阿里阿德涅對他一見鍾情，秘密找到忒修斯並授予他一團線——一頭繫在迷宮入口，一頭握在手中，使他在殺死彌諾陶洛斯後能夠循線返回。這著名的一幕使阿里阿德涅的線（clew）成為西方文明中解決複雜問題的象徵——英語「clue」（線索）一詞即由此而來。阿里阿德涅也給了忒修斯一把彎劍（一說代達羅斯贈送的劍），以殺死彌諾陶洛斯。作為回報，忒修斯承諾帶她逃離克里特。

### 納克索斯的遺棄

忒修斯帶著阿里阿德涅逃出克里特，在航向雅典的途中停靠納克索斯島。關於接下來發生的事有兩種截然不同的版本。在荷馬傳統中，忒修斯在阿里阿德涅睡夢中拋棄了她，原因不詳——可能因雅典娜的命令、可能因另有所愛。而在克里特版本的傳唱中，忒修斯被迫離開她，因為酒神戴奧尼索斯看見了阿里阿德涅並要求她為妻。無論起因如何，阿里阿德涅在納克索斯的海灘上醒來，發現愛人與船隊已消失在晨霧中。

### 神聖婚姻

戴奧尼索斯找到被遺棄的阿里阿德涅，與她舉行了盛大的婚禮。他送給她一頂由赫淮斯托斯打造的黃金王冠——此冠後來化為北冕座（Corona Borealis）高懸於天空。阿里阿德涅從凡人公主升格為不朽女神，成為戴奧尼索斯在奧林帕斯的合法配偶。部分神話說他們育有二子：托阿斯（Thoas）與斯塔菲洛斯（Staphylus）。她的女神身分在希臘世界受到廣泛崇拜，尤其在納克索斯、塞浦路斯與阿爾戈斯，祭儀融合了戴奧尼索斯崇拜中的狂喜元素與米諾斯迷宮的神聖性。

## 跨文化對應

| 米諾斯 | 跨文化對應 |
|--------|-----------|
| 阿里阿德涅（導引迷宮者） | ↔ 埃及哈索爾（Hathor）— 引導死者穿越冥界迷宮 |
| | ↔ 芬蘭維納莫伊寧（智慧引導者） |
| 被遺棄的公主戴奧尼索斯拯救 | ↔ 美狄亞（被伊阿宋遺棄） |
| 凡人透過神聖婚姻升格為神 | ↔ 赫拉克勒斯（功績→不朽）；埃及印闍（Imhotep） |
| 阿里阿德涅的線（指引工具） | ↔ 中國指南車；阿拉伯阿拉丁的神燈引導 |

阿里阿德涅與美狄亞（Medea）形成一組經典的平行對比：兩者皆為愛上希臘英雄的異邦公主，以智慧幫助英雄完成艱難任務（迷宮/金羊毛），後皆被英雄遺棄。但美狄亞以復仇作為回應，阿里阿德涅則得到戴奧尼索斯的拯救與不朽——兩人分別代表了「被背叛的女性神話」的兩種原型結局：毀滅性報復與神聖化超越。

## 相關神祇

- **Minos** — 米諾斯國王，阿里阿德涅之父
- **Pasiphaë** — 太陽神赫利俄斯之女，阿里阿德涅之母
- **Minotaur (Asterion)** — 彌諾陶洛斯，阿里阿德涅同母異父的兄弟
- **Dionysus** — 酒神，阿里阿德涅的丈夫與救贖者
- **Theseus** — 雅典英雄，阿里阿德涅的第一個愛人
- **Daedalus** — 迷宮建築師，為阿里阿德涅提供了間接幫助
