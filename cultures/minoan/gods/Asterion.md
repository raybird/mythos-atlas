# Asterion（阿斯特里翁）— 克里特的星之王

- **文化：** 米諾斯神話 (Minoan Mythology)／希臘神話 (Greek Mythology)
- **職掌：** 克里特之王、星辰王權的象徵、神裔米諾斯王朝的收養者與正統化者

## 概述

阿斯特里翁（Asterion，希臘語 Ἀστερίων；亦作 Asterius，Ἀστέριος）之名源自 ἀστήρ（星辰），意即「滿布星辰者」或「星中之王」。在希臘傳統中，他是歐羅巴（Europa）被宙斯化身的白牛帶到克里特之後所嫁的國王，並收養歐羅巴與宙斯所生的三個兒子——米諾斯（Minos）、拉達曼迪斯（Rhadamanthys）與薩耳珀冬（Sarpedon）。阿波羅多洛斯《書庫》（Bibliotheca 3.1.2）記載阿斯特里翁為特克塔摩斯（Tectamus）之子、屬多洛斯（Dorus）的血裔，在克里特執掌王權；狄奧多羅斯（Diodorus Siculus 5.79）則補充克里特本地王統出自「克里特人之祖」克雷斯（Cres）的譜系，阿斯特里翁正是連接「外地神裔」與「本地王權」的樞紐。

與宙斯、米諾斯那種以雷霆與征服彰顯力量的王者不同，阿斯特里翁是神話中最安靜的王者之一：他幾乎沒有自己的行動，卻以「收養」這一最溫柔的政治行為，將宙斯的私生子轉化為克里特合法的繼承者。米諾斯王朝的正統性因此是雙重的——血統上來自天界（宙斯），制度上則由人間之王阿斯特里翁加冕。神話學者（如 Burkert、Nilsson）多視此敘事為米諾斯宮廷將外來神祇與本土王權進行「神話整合」的痕跡：外來的腓尼基公主、天上的白牛與當地的王座，在阿斯特里翁的名字底下結合成一個王朝。

值得特別注意的是，某些希臘文獻中「阿斯特里烏斯／阿斯特里翁」這個名字同時被賦予了迷宮中的牛頭怪物——狄奧多羅斯（4.77）便稱米諾陶洛斯為「阿斯特里烏斯」，巴克基利德斯（Bacchylides）的殘篇亦然。同一個星辰之名，既屬於收養王子的國王，又屬於吞噬童男童女的怪物，暗示克里特神話深層的「星—牛—王」三位一體結構：金牛座、公牛的聖性與星辰王權，原本共享同一組象徵語言。

## 神話事蹟

### 收養神裔：米諾斯王朝的正統性

歐羅巴為宙斯生下三子後，阿斯特里翁迎娶她並收養其子。米諾斯成年後以天神之後的身份登上克里特王座，阿斯特里翁退居幕後。這一「養父讓位」的結構，使米諾斯的王權既免於「私生子篡位」的質疑，又保留了天界血統的神聖性。三位養子日後各自化為王權、正義與殖民的象徵：米諾斯立法統治克里特並成為冥界判官，拉達曼迪斯以公正聞名，薩耳珀冬則遠赴呂基亞建立王朝。

### 星辰之名與金牛座的呼應

阿斯特里翁之名與歐羅巴神話中的金牛座（Taurus）形成對應：宙斯化身的白牛升上天空成為星座，而人間的「星辰者」則以婚姻收編這段神話，使克里特宮廷成為天界秩序的凡間鏡像。晚近的希臘神話辭典（如 Rose）指出，阿斯特里翁可能是克里特本土一位已佚失的「星辰—公牛」神明的希臘化殘影——他的名號見證了克里特宗教如何以天上的星辰為王權背書。

### 隱藏的王者

阿斯特里翁幾乎沒有史詩性的行動，他是典型的「隱藏之王」（hidden king）：存在於敘事的邊緣，卻決定了王朝的起點。這種王者類型在神話中屢見不鮮——埃及的歐西里斯生前被動、受難，卻成為王權與復活的根源；北歐的弗雷（Freyr）同樣以內斂而豐饒的方式維繫王統。阿斯特里翁的存在提醒我們：在神話中，正統性往往不來自顯赫的行動，而來自一個名字、一場收養與一次讓位。

## 跨文化對應

| 米諾斯阿斯特里翁 | 跨文化對應 | 共通點 |
|----------------|-----------|--------|
| 星之名與天象王權 | ↔ 印度伐樓拿（Varuna） | 以星空／宇宙律法（Ṛta）標記王權與秩序 |
| 收養神裔的凡間王者 | ↔ 基督教聖若瑟（約瑟） | 以凡人身份撫養神性之子，使其繼承合法化 |
| 隱藏而受難的舊王 | ↔ 埃及歐西里斯（Osiris） | 王者以被動／受難之姿成為繼承與復活的根源 |
| 星—牛—王三位一體 | ↔ 埃及 Apis 神牛／印度南迪（Nandi） | 公牛作為神聖王權的載體 |
| 同一星名屬於王者與怪物 | ↔ 印度提婆與阿修羅共享宇宙力量之名 | 名號作為力量與地位的雙面象徵 |

## 相關神祇

- **歐羅巴（Europa）**——被宙斯化身白牛帶至克里特的腓尼基公主，阿斯特里翁之妻
- **米諾斯（Minos）**——養子，克里特立法之王，死後成為冥界判官
- **拉達曼迪斯（Rhadamanthys）**——養子，公正的冥界審判者
- **薩耳珀冬（Sarpedon）**——養子，呂基亞建國英雄
- **宙斯（Zeus）**——以白牛之身與歐羅巴結合，歐羅巴三子的生父
