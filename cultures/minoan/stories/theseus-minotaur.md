# 忒修斯斬彌諾陶洛斯 (Theseus and the Minotaur)

- **文化：** 米諾斯神話 (Minoan Mythology)／希臘神話 (Greek Mythology)

## 故事背景

雅典最偉大的英雄忒修斯（Theseus）誕生於雅典國王埃勾斯（Aegeus）與特羅曾公主埃特拉（Aethra）之間。忒修斯成年後前往雅典的路上經歷了六項重大的冒險與挑戰，進入城中時被父親的配偶美狄亞（Medea）認出並意圖毒殺，但埃勾斯在最後一刻認出忒修斯的寶劍，排除了陰謀。此時雅典正處於克里特掌控的陰影之下——每年必須向彌諾斯國王進貢七名童男、七名童女作為彌諾陶洛斯的犧牲。忒修斯決心終止這個詛咒。

## 情節

### 第一幕：貢品的命運

雅典人第三次被迫抽籤選出前往克里特的貢品時，城中充滿哀號。忒修斯自願作為七名男性貢品之一出發，向父親發誓：若成功，回航時將船上原本的黑色風帆改用白色風帆。忒修斯率領十三名青少年登船，行前得德爾菲神諭的指引：以阿芙洛狄忒為嚮導——暗示了他的勝利需要一位女性的幫助。

### 第二幕：迷宮中的線

船隊抵達克諾索斯。彌諾斯國王舉行檢閱時，阿里阿德涅的目光落在忒修斯身上——她內心震動。當夜，阿里阿德涅偷偷找到忒修斯，遞給他一個線團與一把彎劍。這線團出自代達羅斯（Daedalus）之手——迷宮的設計者保留了一個祕密：任何人持線進入迷宮，只要線不中斷就能循原路返回。阿里阿德涅對忒修斯說：「進去，殺死彌諾陶洛斯，循我的線回來。然後帶我走。」

忒修斯將線頭繫在迷宮入口的石柱上。他走進迷宮——牆壁以白石與黑石砌成，通道不斷分岔、迴旋，越走越深。牆上繪有巨大的雙斧（labrys）與跳牛壁畫。空氣中有腐肉的氣味。

### 第三幕：彌諾陶洛斯之死

彌諾陶洛斯在迷宮最深處的圓形廳堂中等著他——一個擁有人的身體與公牛的頭顱的怪物，青銅色的皮膚、鼻孔噴出熱氣。彌諾陶洛斯以角衝向忒修斯，後者閃身避開。兩者在陰暗的大廳中搏鬥——忒修斯以阿里阿德涅的彎劍格擋公牛角的撞擊，在翻滾中尋找機會。最終忒修斯抓住彌諾陶洛斯的角，用全身的重量將牠壓制在地，一劍刺入牠的咽喉。彌諾陶洛斯發出一聲低沉的喉音後倒地，彌諾斯的詛咒隨之終結。

忒修斯循著線走出迷宮——阿里阿德涅在海邊等著他。他兌現承諾，帶上阿里阿德涅，鑿穿克里特船隊的船底（一說以毒酒迷倒衛兵），連夜航向雅典。

### 第四幕：黑帆之悲

離開克里特後，船隊停靠納克索斯島。此處發生的事件版本不一——多數說忒修斯在睡夢中遺棄了阿里阿德涅（或戴奧尼索斯強行帶走了她）。忒修斯帶著傷痛繼續航行。在接近雅典的海域時，他因悲傷與疲憊忘記了更換風帆——國王埃勾斯在蘇尼翁角的懸崖上遠眺，看見回航的船掛著黑色的死亡之帆，以為兒子已死。絕望的埃勾斯跳入大海自盡——從此那片海域被稱為愛琴海（Aegean Sea）。

忒修斯返回雅典後發現父親已死。他在悲慟中繼承王位，成為雅典最偉大的國王——推行民主改革、統一阿提卡半島、建立泛雅典娜節。但彌諾陶洛斯的故事永遠改變了雅典與克里特的關係：米諾斯文明的霸權由此衰落，希臘文明的序曲開始奏響。

## 跨文化平行

| 米諾斯／希臘元素 | 跨文化平行 |
|----------------|-----------|
| 英雄自願獻身以終結貢品命運 | ↔ 埃塞俄比亞英雄拯救安德洛美達 |
| | ↔ 中國哪吒剮肉還母 |
| 陷阱／迷宮中的怪物 | ↔ 西伯利亞薩滿試煉（迷宮般的冥界路徑） |
| | ↔ 埃及死者審判大廳中的阿穆特獸 |
| 女性的線團作為指引 | ↔ 中國女媧以五彩石補天的引導象徵 |
| 忘記更換風帆導致父親死亡 | ↔ 波斯的魯斯塔姆誤殺兒子蘇赫拉布 |
| 死後命名的地名（愛琴海） | ↔ 希臘赫勒斯滂（赫勒之海） |

忒修斯與彌諾陶洛斯的故事之所以成為西方文明的核心神話之一，在於它同時處理了四個層面的轉型：個人層面（少年到英雄）、家庭層面（子代父位）、政治層面（雅典從附庸到霸主）、文明層面（米諾斯到希臘）。
