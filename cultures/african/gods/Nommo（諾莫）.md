# 諾莫（Nommo）

- **文化：** 非洲諸神話 — 多貢（Dogon，馬里共和國）
- **職掌：** 原初水靈、Amma 所造的第一活物、諾莫八族的始祖、文明的傳授者（織布、冶鐵、農耕、語言）
- **形態：** 兩棲、雌雄同體、魚身人首的祖靈；上半身為人、下半身似蛇或魚
- **詞源：** 從多貢語「使其飲用」一詞（*nommos*）衍生
- **居所：** 天狼星（`sigu tolo`）所繞的軌道世界；降臨時乘「方舟」，伴隨風與雷
- **對應神：** [Amma](Amma.md)（父，創造者）、Yurugu／Ogo（叛出的雙生兄弟，Pale Fox，「淺色狐狸」）
- **祭祀中心：** 馬里中央的班迪亞加拉懸崖（Bandiagara Escarpment）；`binu` 祖祠遍布其傳統領域
- **象徵：** 虹、蛇身、雙生、`binu` 祠的柱、石斧與門鎖上的成對雕像

## 概述

諾莫（Nommo / Nummo）不是一個神，而是一族祖靈，在多貢的宇宙論中佔據「最先被造之物」的位置。牠們的存在方式是把「起源」這個問題具體化：Amma 是不可見、無定形、尚未顯現的潛能；諾莫則是這潛能第一次獲得形體。多貢人相信，宇宙的結構建立在「成對」（`twinness`）之上——每一個存在都有一個半邊伴隨，連星座的軌道週期都「成對計算」。諾莫正是這條原則最初的體現：牠們本身就是一對一對的雙生。

諾莫的詞源本身就是一個有性意味的細節：`nommos` 源自多貢語中「使人飲用」的動態表達。這個詞把「創造」和「滋養」壓縮在一起——多貢的創造觀不把宇宙視為被建造的物件，而視為被飲用的、進入身體的流動物。這也解釋了牠們為何是水生：原初之水不是舞台，而是材料。

## 神話事蹟

### 從「宇宙卵」到第一個活物

Amma 的第一個創造物是「宇宙卵」（*egg of the world*），其中含有一切潛在的種子。蛋破之後，諾莫出現了。諾莫立刻發生變化並增殖為**四對雙生**——這四對是八個建族（`tanu`）的祖先。諾莫的職能被記錄為「使某人飲用」：牠們帶著植物降臨，把植物的纖維編織成「大地之衣」（the clothing of the earth）。大地的裸體被覆蓋，第一陣風因此產生，語言隨之出現。

### 叛者與獻祭

四對雙生之中有一對背叛了 Amma 建立的普遍秩序。這位叛者通常被記為 Ogo 或 Yurugu，即「淺色狐狸」（*Vulpes pallida*，早期英譯誤作 jackal）。牠的名字在多貢語中的語源學被解釋為「貪婪」或「欺詐」。Ogo 的背叛行動是多貢創世說的轉折點，也是「第二次創造」的必要性來源。

Yurugu 注意到大地有語言，遂**偷走大地的衣服**（即那承載語言的植物纖維編織物），由此獲得言語能力。Amma 對這次對大地的攻擊極為震怒，決定創造活物時不再需要大地女性——這就是多貢神話中著名的「獨力創造」轉折。為了贖回 Ogo 的罪過，Amma 獻祭並肢解了諾莫的後裔之一，其身體碎片散落於宇宙各處；每一處碎片落地的地點，後來都建起一座 `binu` 祖祠。**多貢境內 `binu` 祠的散布本身就是這具被肢解祖先的地理索引。**

### 諾莫與天狼星

1940 年代，法國人類學家 Marcel Griaule 與 Germaine Dieterlen（在馬里工作自 1931 年起）記錄了多貢人關於諾莫的「秘密神話」，稱諾莫是天狼星周圍世界的居民，乘「方舟」（伴隨火焰與雷鳴）降臨，帶來知識與文明。多貢人的星象學確實極為精細，天狼星被視為最關鍵的星，其出現週期被計為一百年（成對週期），並以每六十年一次的「西古」（`sigui`）儀式慶祝世界更新。

但這段記載在科學界與人類學界都有爭議。研究者 Walter van Beek 在多貢進行長期田野工作後指出，他找不到多貢人擁有先進的天狼星天文知識的證據；他主張 Griaule 的提問方式過於引導性，導致新神話在採訪過程中被創造出來——van Beek 記錄到，不同多貢受訪者對 `sigu tolo`（Griaule 聲稱是天狼星的那顆星）所指涉的說法「完全不一致」：有人說是顆不可見的星，有人說是金星。Carl Sagan 也指出，多貢人與天狼星二聯星知識的關聯，最早是在 1940 年代被報導的，而那段時期多貢人已與科學較發達的外來社會接觸，吸收了關於天狼星與太陽系的宇宙論知識。換言之，天狼星的「先進知識」很可能是近代添加的裝飾。

儘管如此，諾莫作為「原初水祖＋文明傳授者」的神話結構本身並不依賴天狼星。它在多貢宇宙論中的功能——**作為天與地、人與獸、文明與荒野之間的中介**——是穩定的，且可與其他文化的原初水靈做結構比較。

## 跨文化對應

| 文化 | 對應存在 | 共同結構與差異 |
|------|---------|---------------|
| 西非 Vodun（伏都） | `to-vodun` 水靈 | Britannica 明言多貢的 Nommo 與西非 vodun 的 `to-vodun` 水神「相似」；兩者皆為兩棲、雌雄同體的水生祖靈。伏都的水靈常被外來者與 Mami Wata 混稱，但內部功能不同 |
| 埃及 | 努恩（Nun）與原始之水 | 埃及把創造的「母體」原始之水人格化為努恩，祂自生自育、孕育拉神。努恩是**宇宙學的**（水＝未分化的存在狀態）；諾莫是**譜系學的**（水祖是具體的八族先祖） |
| 希臘 | 俄刻阿諾斯與泰堤斯 | 荷馬史詩的水神環繞世界，是「界外」（外面的）秩序；這與諾莫的「從天而降、進入人間秩序」方向相反——希臘水神多不落地，多貢水祖則專門落地並教化 |
| 印度 | 婆樓那與最初的水 | 《梨俱吠陀》1.155 以金胎（*hiraṇyagarbha*）為宇宙初始，與多貢的「宇宙卵」在「創造封於一容器內」這一點上結構同形；婆樓那的宇宙水 `apás` 則對應諾莫的滋養性 |
| 波利尼西亞 | 塔涅與塔瑪雷（Tangaroa） | 創世神自天空降下、化身各種形態、創造陸地與生命。但塔涅是**獨一**的創世者，諾莫是**成對**的；多貢的二元論在此與波利尼西亞的一元神創世構成張力 |
| 北美原住民 | 「地潛者」（Earth-Diver） | 北極與多數北美原住民神話中，鳥或水禽潛入水底帶回第一批陸地。諾莫的「兩棲祖靈降臨並覆蓋大地」與「地潛者取土造地」共享「從水域中產出陸地」的核心動機，但前者是覆蓋，後者是取回 |
| 美國西南 | 帕秋卡里（Paquríkin）與「湖中來者」 | Zuni 的湖中精靈是從水體中出現、賦予人舞蹈與知識的祖靈；這與諾莫「帶植物、編織、授予語言」的功能高度相近，差異在於 Zuni 的祖靈是**教化者**而非**創造者** |
| 印度（婆羅門） | 達摩（Dharma）與水的胚胎 | 《梨俱吠陀》以「水」（`apás`）為創造的胚胎與媒介（1.154.4），與多貢「原初之水＝創造材料」的觀點同型；兩者都把「水的能動性」先於「形體」 |

多貢諾莫的獨特處在於**它把「原初水祖」和「文明傳授者」合為一體**。埃及的努恩只孕育神，婆樓那只提供胚胎，Paquríkin 只教化——只有多貢的諾莫同時（a）來自天、（b）是水生、（c）分出人類族群、（d）帶來農業與織造與冶金。這個四合一結構是理解多貢文明觀的入口。
