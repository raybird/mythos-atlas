# 阿拉 (Ala / Ani) — 伊博大地上帝與道德守護神

- **文化：** 非洲諸神話 (African Mythologies) — 伊博 (Igbo，奈及利亞東南部)
- **職掌：** 大地、道德、豐產、生育、冥界與祖先

## 概述

阿拉（Ala，亦拼作 Ani、Ana、Ale、Ali，伊博語意即「土地」「大地」）是奈及利亞伊博人（Igbo）傳統宗教 Odinani 中最受尊崇的神祇之一，也是伊博萬神殿中地位最高的大地女神。她既是滋養萬物的母親——讓土地生產山藥與穀物、讓婦女受孕生育——同時也是伊博倫理體系（Omenala）的制定者與終極裁決者：一切律法、禁忌與道德規範皆源自於她，故學者常稱她為「道德與公平的典範」（paragon of equity）。與約魯巴神話中由 Olorun 遙控宇宙不同，阿拉是「即刻在場」的神——人類每日耕作、居住、生養、埋葬皆在她的大地之上，因此伊博人與阿拉之間具有無法逃避的親密關係（Arinze, 1970: 1–30; Metuh, 1981: 47–66）。

阿拉的地位反映了伊博社會對土地的根本依戀：土地不只是財產，而是生命、倫理與歸宿的總體。在她的雙重性格中——既是慈愛的母親又是無情的審判者——可以看見伊博人如何看待「自然」與「規範」的合一：冒犯土地即是冒犯整個共同體的生存根基。

## 神話事蹟

### 天神之女與大地的託付

在伊博創世敘事中，阿拉是至高神 Chukwu（楚庫，意即「偉大的靈」）的女兒，亦是雷神 Amadioha（阿瑪迪歐哈）的妻子。一說 Chukwu 在造天地時，將大地交由阿拉掌管，使她成為人類生活的直接監督者；另一些地區則認為阿拉與 Amadioha 象徵性地「撫養」全體伊博人——天空之雷與大地之母互為補充，共同維護由阿拉頒布的道德法。阿拉之名在許多地方與「Ani」混用，兩者皆指向「土地女神」這一身分，而她的權威滲透至伊博人生活的每一個層面：從農業曆法的制訂、新山藥節（Iri ji）的開吃儀式，到對竊盜、通姦、謀殺等罪行的裁決（Ogbaa, 1999: 13–27; Uchendu, 1965: 94–99）。

### 道德的守護者與「冒犯大地」之罪

阿拉是伊博人眼中道德的化身。她的存在使伊博人的倫理帶有強烈的「宇宙性」：違背禁忌（nso）不只是人際過失，而是「冒犯了大地」（ime ala）——一種驚動整個共同體、可能招致旱災、瘟疫或氏族衰亡的嚴重罪行。舉凡謀殺、亂倫、竊取神聖祭物、偽證等，都被視為對阿拉的直接褻瀆；傳統上，犯下此類重罪者可能被驅逐出村、剝奪正常葬禮，甚至被送入象徵「大地之子」的化身中接受懲處。伊博人相信，正因為阿拉掌管土地，生前不義者死後將無法安然進入祖先之列——審判並非等到來世，而是化為現實中的災厄降臨（Achebe, 1958: 14–16; Metuh, 1981: 76–93）。

### 冥界女王與祖先的歸宿

阿拉同時是冥界的統治者。伊博宇宙觀中，人死後靈魂回到大地之中，阿拉以「子宮」收納亡者的靈魂，使其與祖先團聚，並在適當時機轉世為後代。因此，阿拉既是生者孕育的母親，也是死者安息的歸宿——「生於土、歸於土」的循環由她一人貫通。正因如此，伊博人的葬禮格外隆重：唯有按照 Omenala 規定的儀式埋葬，亡者才能順利進入阿拉的冥界、列名祖先，繼續庇護後人。此一「大地即生命之母與死亡之歸」的雙重性格，與希臘 Gaia、中國后土、印加 Pachamama 共享相似的神話結構（Uchendu, 1965: 12–18; Mbiti, 1969: 66–75）。

### 蛇與山藥的象徵

阿拉在大地上的活象徵是蟒蛇（éké）。伊博人視蟒蛇為阿拉的化身或使者，認為牠棲息於河流、森林與田園之間，是女神臨在的標誌；因此多數伊博社區嚴禁殺害或食用蟒蛇，違者等同冒犯阿拉。此外，山藥是阿拉神性的核心載體——山藥的豐收被視為阿拉的恩賜，故每年收成後的「新山藥節」必先將首批山藥奉獻給阿拉，感謝她賜予地力與生命（Ogbaa, 1999: 30–41; Metuh, 1981: 68–74）。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 希臘 | Gaia（蓋亞）／Demeter | 大地母神、農產與生命循環的主宰 |
| 中國 | 后土／女媧 | 土地之神、生育與人倫秩序 |
| 印加（安地斯） | Pachamama | 大地母神、農作豐收與山川聖地 |
| 印度 | Prithvi／Bhūmi | 大地女神、生命的承受者 |
| 埃及 | Geb／Nut | 大地與蒼穹的結合、死者歸宿 |
| 西非約魯巴 | Odudua／Oduduwa | 地母神、造人與大地崇拜 |
| 蘇美 | Ninhursag／Ki | 大地之母、農業豐產與醫治 |

## 相關神祇

- **Chukwu／Chineke**：至高創造神，阿拉之父；地位崇高但遠離日常祭祀
- **Amadioha**：雷電與正義之神，阿拉之夫，執行阿拉頒布的道德裁決
- **Anyanwu**：太陽神，光與熱的化身
- **Mmuo（靈體）／Ndi ichie（祖先之靈）**：與阿拉冥界領域密切相關的靈界存在
- **Ekwensu**：戰爭與欺騙之神，與阿拉的道德秩序相對照
