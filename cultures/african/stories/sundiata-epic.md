# 松迪亞塔史詩（The Epic of Sundiata / Sunjata）

- **文化：** 非洲諸神話—曼德（Mande）文化，馬利帝國傳統
- **性質：** 口傳史詩，經由賈利（Jeli / griot，吟遊史官）世代傳承
- **時間背景：** 約公元13世紀初，馬利帝國建立前後

## 故事背景

曼德人的《松迪亞塔》史詩（亦拼寫為 Sunjata、Sundiata Keita）是西非最重要、最廣泛流傳的口傳史詩之一。它講述了松迪亞塔·凱塔——「獅子王子」——如何從被放逐的跛足少年成為曼德帝國的開國君主。與希臘的《奧德賽》、印度的《摩訶婆羅多》並列為世界偉大史詩，但《松迪亞塔》的特異之處在於它在13世紀初是真實歷史事件的神話化表達——松迪亞塔本人（約1190—1255年）創立了馬利帝國，其統治在阿拉伯地理學家（如伊本·巴圖塔）的旅行記錄中得到了印證（Niane, 1965）。

史詩的核心結構與比較神話學中的「英雄之旅」（Campbell 的 monomyth）高度吻合：跛足英雄受迫害→母子放逐→穿越國境獲得盟友→武裝起義→最終勝利→恢復王國秩序。然而，《松迪亞塔》的獨特性在於其對西非曼德人文化價值的不懈肯定——慷慨（donation）、勇氣、正義與對祖先的忠誠。

## 情節

### 第一階段：預言與苦難

曼德國王馬甘·孔·法塔（Maghan Kon Fatta）從一位狩獵占卜者處得知：他將與一位醜陋、駝背的女人索格隆·孔德（Sogolon Condé）結婚，並生下一子，此子將成為偉大的國王。國王依言娶索格隆——她身上長滿毛髮，形如水牛，但實際上是水牛女神的化身。索格隆懷孕後誕下松迪亞塔——嬰兒無法站立行走，雙腿軟弱無力。

幼年松迪亞塔雖然無法行走，但具有超凡的智慧與內在力量。國王的另一位妻子，薩蘇瑪·貝雷（Sassouma Bereté）對此極度嫉妒——她深怕松迪亞塔的預言將剝奪自己兒子的王位繼承權。薩蘇瑪不斷羞辱索格隆母子，散布謠言說松迪亞塔是被神遺棄的廢物。

### 第二階段：站立與流亡

某日，薩蘇瑪嘲笑索格隆：「你的兒子連站都站不起來，你們母子是曼德人的耻辱。」索格隆痛哭不已。松迪亞塔聽到母親的哭泣，內心湧起前所未有的力量——他抓住鐵棍，猛地站起，折彎鐵棍成弧形，從此不再跛足。這個「折彎鐵棍」的場景是整部史詩最著名的戲劇性時刻，象徵潛能的覺醒與命運的轉捩點（Niane, 1965: 41）。

薩蘇瑪見松迪亞塔康復，更加恐懼——她計劃謀殺松迪亞塔。馬甘國王去世後（王位暫由薩蘇瑪之子暫攝），索格隆為保全兒子性命，帶松迪亞塔與其他子女逃離曼德王國。母子一行人先後流亡至多個王國——在瓦卡杜（Wagadou）、塔貝爾（Tabon）、杜（Dou）等地——松迪亞塔在流亡期間習得軍事知識、結交戰友。最終他們停留在麥馬（Mema）王國，麥馬王以禮相待，松迪亞塔被任命為王國騎士。

### 第三階段：回歸與勝利

流亡期間，索索（Sosso）王國的暴君蘇曼古魯·坎特（Soumaoro Kanté）入侵曼德，燒殺擄掠，統治曼德人。曼德長老們秘密派遣使者前往麥馬，請求松迪亞塔回歸救國。松迪亞塔向麥馬王告別，返回曼德並召集支持者——各小王國的軍隊開始集結於他的麾下。

松迪亞塔率軍與蘇曼古魯對峙。然而蘇曼古魯不僅是人間君王——他是一個巫師之王，擁有超自然力量，能變身成多種動物、召喚惡靈。蘇曼古魯掌握一種被稱為「禁咒」（tana）的秘密：他不能觸碰雞。松迪亞塔的貼身占卜師指示他將一支箭頭刻上雞的形狀。在基里納（Kirina）決戰中，松迪亞塔向蘇曼古魯射出這支箭——箭擊中蘇曼古魯的肩膀，他應聲倒地，巫力瓦解，化作一陣旋風消失。

### 第四階段：馬利帝國的建立

擊敗蘇曼古魯後，松迪亞塔登上曼德帝國的寶座（約1235年），被尊稱為「曼薩」（Mansa，皇帝）。他重新劃分行政區，頒布被稱為「庫魯坎·富加」（Kouroukan Fouga）的建國憲章——這是一部七十條的社會契約，保障人權、環境保護、貿易自由、貴族與平民的權責分配。西非曼德文化中的 caste 階層制（鐵匠、吟遊詩人、皮革匠等各司其職）據說由此法典確立。

松迪亞塔定都尼亞尼（Niani），建立馬利帝國——到其孫曼薩·穆薩（Mansa Musa）統治時（1312—1337年），馬利帝國國力達到頂峰，成為當時世界上最富有的王國之一。

## 跨文化平行

| 元素 | 《松迪亞塔》 | 對應神話/史詩 |
|------|-------------|---------------|
| 出生預言 | 占卜者預言松迪亞塔將成偉大國王 | 希臘：宙斯預言推翻克洛諾斯；印度：黑天降生預言 |
| 跛足/殘缺英雄 | 幼年無法行走，後奇蹟站立 | 希臘：赫菲斯托斯跛足；希臘：奧狄浦斯腫腳 |
| 母親為女神化身 | 索格隆為水牛女神 | 希臘：忒提斯（Achilles 母）為海仙；愛爾蘭：Deichtine（Cú Chulainn 母） |
| 邪惡后母迫害 | 薩蘇瑪母子迫害 | 希臘：Phaedra 迫害 Hippolytus；中國：后羿傳說中的邪后 |
| 流亡與歸來 | 松迪亞塔流亡麥馬，回歸救國 | 希臘：奧德修斯返鄉；印度：羅摩流亡回歸 |
| 暴君巫王 | 蘇曼古魯為超自然暴君 | 波斯：Zahhak；北歐：Hrothgar 的 Grendel；印度：Ravana |
| 致命弱點（tana） | 蘇曼古魯不能觸碰雞 | 北歐：巴德爾的槲寄生；希臘：Achilles 之踵 |
| 建國法典 | 庫魯坎·富加七十七條 | 希臘：來古格士法典；希伯來：摩西十誡 |
| 吟唱傳承 | 賈利（griot）背誦世代系譜 | 希臘：荷馬史詩吟遊；芬蘭：卡勒瓦拉朗誦 |

## 相關主題

- **英雄之旅**（monomyth）：Campbell 框架在非洲的經典案例
- **建國神話**: 與羅慕路斯、居魯士、摩西建國神話屬於同一類型
- **跛足/殘缺英雄原型**: 跨越希臘、北歐、西歐、西非的共通英雄缺陷母題
