# Ogun 開路與鐵器時代

- **文化：** 非洲諸神話 (African Mythologies) — 約魯巴 (Yoruba) + 芳族 (Fon) + 班圖 (Bantu)

## 故事背景

Ogun（亦稱 Ogún 或 Gu）是約魯巴神話中的鐵神、戰神與開路者，也是至今仍在西非與離散非洲宗教中被廣泛祭祀的 Orisha 之一。當世界初創、眾神準備下凡建立文明時，大地被濃密的原始森林完全覆蓋——沒有道路、沒有空地、沒有可供人類居住的開闊地帶。眾神在天空邊緣徘徊，無人敢踏入這片荊棘叢生的荒野。Ogun 手持鐵刀與戰斧，宣布他將為眾生開路。

## 情節

Ogun 降臨人間，以他的鐵器砍伐樹木、劈開岩壁、焚燒荊棘。他連續七日七夜不眠不休地工作——鐵刀砍斷巨樹發出轟鳴，山石在鐵斧下四分五裂，火焰將叢林夷為平地。Ogun 的鐵器不僅開出了道路，也為人類揭示了鐵的祕密：如何從礦石中煉鐵、如何打造工具與武器、如何以金屬取代石器。

然而 Ogun 的工作充滿暴力與代價。當他砍伐的最後一棵大樹倒下時，樹根下躲藏的動物被壓死——這是神話中第一滴非狩獵的血。Ogun 因此被沾染了「血的詛咒」，從此他既是文明的建造者，也是毀滅的使者。約魯巴人說：「沒有 Ogun 就沒有道路，但每條路都浸染著鮮血。」

道路暢通後，其他神祇得以降臨人間建立城市。Obatala（創世神）在 Ogun 開闢的土地上建立了第一座城市 Ife。人類向 Ogun 學習了冶鐵技術，從石器時代邁入鐵器時代——農業工具使糧食增產，鐵製武器使部落得以防禦猛獸與敵人。Ogun 因此成為約魯巴文明中不可或缺的基礎力量。

## 跨文化平行

- **普羅米修斯（希臘）**：盜火贈予人類，使人類文明從原始邁向進步
- **祝融（中國）**：火神與工匠的始祖，教導人類用火與冶金
- **韋蘭／Weyland（北歐）**：傳奇鐵匠，以神話技藝打造不朽武器
- **赫菲斯托斯／Hephaestus（希臘）**：工匠與鍛造之神，為眾神打造武器與工具
