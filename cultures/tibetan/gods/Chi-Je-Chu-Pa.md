# 赤傑曲巴（Chi Je Chu Pa）— 苯教的創世大神

- **文化：** 西藏神話 (Tibetan Mythology)
- **職掌：** 宇宙創造、本初光明、五種元素、時間與空間的開端
- **象徵：** 五色光明、虛空（Stong-pa）、智慧放射
- **體系：** 苯教（Bön）創世神話

## 概述

赤傑曲巴（藏語：Chi Je Chu Pa，又譯「赤加曲巴」）是前佛教時期苯教創世神話中的原始存在——他被視為一切存在的開端。與中國盤古、北歐尤彌爾這類「巨人犧牲型」創世神不同，赤傑曲巴並不透過死亡或肢解來創造世界，而是以**本初光明的智慧放射**從虛空中生出宇宙。苯教經典《十萬龍經》（Klu 'bum）記載：最初只有虛空（Stong-pa），既無物質也無時間；自虛空中自發湧現了本初之光——這道光既是智慧也是能量。赤傑曲巴以五種智慧光明創造宇宙的五種元素：空、風、火、水、地，光的五種色澤（白、藍、黃、紅、綠）分別對應藏傳佛教的五佛部與五種智慧。

## 神話事蹟

### 光創世：宇宙的放射

在苯教的創世記述中，赤傑曲巴的創造並非「說有就有」的命令式創造，而是一種無聲的、向外的智慧放射——光明自然擴散，形成天、地、日月星辰與萬物。這一過程與印度吠陀「無中生有」（Asat 生 Sat）的結構相似，但赤傑曲巴以光明取代了吠陀中的「慾望」（Kāma）作為第一推動力。此「光創世」觀念後來與藏傳佛教大圓滿（Dzogchen）教法中的「本初自性光明」深度交織——創世在此被重新詮釋為覺悟本質的自然顯現。

### 雙重身份：苯教創世神與佛教光明象徵

當佛教於七世紀傳入西藏後，赤傑曲巴並未被消滅，而是被納入新的解釋框架——苯教的「虛空創世」與佛教的「無始劫」宇宙論巧妙銜接。在苯教的曼陀羅中，赤傑曲巴依然作為「最初之因」接受祭祀，而佛教徒則將這道本初光明理解為法身光明。此雙重身份使赤傑曲巴成為觀察西藏文化「佛教化而不斷裂」的關鍵案例——與念青唐古拉被降伏為佛教護法不同，赤傑曲巴代表的是宇宙觀層次的融合。

## 跨文化對應

| 赤傑曲巴 | 對應 | 文化 |
|---|---|---|
| 虛空生光明創世 | 梨俱吠陀的「無」（Asat）生「有」（Sat） | 印度 |
| 以智慧光放射創世 | 梵天以思想/言語創世 | 印度 |
| 非暴力創造 | 盤古之死、尤彌爾之死 | 中國／北歐 |
| 五色光明對應五佛部 | 五佛部智慧曼陀羅 | 藏傳佛教 |
| 本初存在自發湧現 | 阿圖姆自創生 | 埃及 |

## 相關神祇

- **辛饒米沃（Shenrab Miwo）：** 苯教教主，被視為赤傑曲巴創造秩序的教化者
- **桑波本赤（Sangpo Bumtri）：** 另一版本的苯教創世存在，以身體化生萬物
- **赤傑曲巴與吉祥天母：** 前者為本初光明，後者為佛教護法，代表苯佛融合的兩個極點
