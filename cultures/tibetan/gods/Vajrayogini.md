# 金剛亥母 — 西藏佛教的憤怒空行母

- **文化：** 西藏神話 (Tibetan Mythology)
- **職掌：** 智慧、空性、轉化、覺悟之舞

## 概述

金剛亥母（Vajrayoginī，藏語：རྡོ་རྗེ་རྣལ་འབྱོར་མ་，多傑那久瑪）是藏傳佛教中最重要與最秘密的女性本尊之一。她的名字可拆分為「vajra」（金剛，象徵不壞的空性智慧）與「yoginī」（瑜伽女，已證悟的女行者）。金剛亥母不屬於「救度型」女神——她不以溫柔的慈悲示現，而是以半怒半喜的狂舞之姿出現，手持金剛鉞刀與顱器（Kapāla），踏於印度教的時女神與大自在天之上。她象徵將貪、嗔、癡等煩惱直接轉化為智慧的能力——不是消滅煩惱，而是認識煩惱的本質即空性。金剛亥母在格魯派、噶舉派、薩迦派與寧瑪派中皆被視為最核心的無上瑜伽部本尊，其修法僅授予已完成前行的行者。

## 神話事蹟

### 金剛亥母的化身與傳承

金剛亥母的起源可追溯至印度八十四大成就者傳統。傳說金剛亥母曾以那洛巴（Nāropā）的智慧空行母身份出現——當那洛巴在尋找他的根本上師帝洛巴時，金剛亥母化身為一位醜陋的老婦人，為那洛巴指示方向。此教導的核心意義在於：智慧不以華麗的外表出現，而常常隱藏在最不起眼的型態中。在噶舉派的傳承中，金剛亥母直接向帝洛巴與那洛巴傳授「那洛六法」的究竟口訣——她不僅是禪修的本尊，更是教法的直接授予者。

### 金剛亥母與金剛手的辯論

一個重要的神話敘述了金剛亥母與金剛手菩薩（Vajrapāṇi）的辯論。金剛亥母持金剛鉞刀與顱器出現在金剛手面前，金剛手質疑她作為女性如何能證得無上智慧。金剛亥母以一聲震盪三界的吼笑回應，隨即化為金剛亥母與金剛手合一的雙運身——她揭示了「女性即智慧，男性即方便，二者本質無別」的密續核心教義。此神話常被援引來論證藏傳金剛乘對性別超越性的理解：究竟真理超越男女二相。

### 金剛亥母與薩惹哈的相遇

印度大成就者薩惹哈（Saraha）是金剛亥母的著名弟子。傳說薩惹哈以釀酒為生，金剛亥母化現為他的酒客，以買酒的因緣向他傳授大手印心要。她對薩惹哈說：「你釀的酒只能醉人一時，而我釀的空性之酒能醉人直至解脫。」此教導強調世俗與神聖的非二元性——平凡的勞動也可以是修行的道場。

### 金剛亥母淨土：空行淨土

金剛亥母的淨土稱為「空行淨土」（Khechara），位於頭頂上方的虹光輪中。修行金剛亥母法門的行者相信，透過與金剛亥母相應，臨終時可直接往生此淨土——無需經歷中陰的恐怖。噶舉派的密勒日巴與岡波巴皆以金剛亥母為本尊，顯示她在實修傳統中的至高地位。

## 跨文化對應

| 西藏金剛亥母 | 對應 | 文化 |
|------------|------|------|
| 女性智慧本尊 | 般若波羅蜜多（Prajñāpāramitā） | 印度佛教 |
| 舞踏於屍體之上 | 時母（Kālī）踏於濕婆之上 | 印度教 |
| 智慧空行母 | 伊西斯（Isis，智慧女神） | 埃及 |
| 忿怒女性化現 | 忿怒母（Machik Labdrön 的化現） | 西藏本教 |
| 持刀與顱器 | 迦梨（Kālī，持劍與首級） | 印度教 |
| 半怒半喜面容 | 獅面空行母（Siṃhamukhā，獅面女） | 西藏佛教 |

## 相關神祇

- **勝樂金剛（Cakrasaṃvara）：** 金剛亥母的男性對應本尊，二者常作為雙運修法
- **金剛手（Vajrapāṇi）：** 護法金剛，與金剛亥母有傳承上的關聯
- **吉祥天母（Palden Lhamo）：** 護法女神，功能相近但地位不同
- **度母（Tārā）：** 女性本尊但為寂靜相，金剛亥母則為忿怒相
