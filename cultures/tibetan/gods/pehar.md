# 佩哈爾 (Pehar / dPe-dkar / 貝哈爾)

- **文化：** 西藏神話 (Tibetan Mythology)
- **職掌：** 護法神、國師神諭、五身王

## 概述

佩哈爾（藏語 dPe-dkar，音譯「貝哈爾」，意為「白晶石」）是藏傳佛教最重要的世間護法神（འཇིག་རྟེན་པའི་སྲུང་མ། / jigtenpé sungma）之一，也是西藏政教合一的官方神諭——乃瓊寺（Nechung / gNas-chung）降神儀式中降臨的「乃瓊神諭」（gNas-chung chos-skyong）之主神。與出世間護法神（已證悟的智慧護法）不同，佩哈爾屬於尚未脫離輪迴但擁有極大力量的世間護法——他的權力來自誓言而非證悟。

佩哈爾的起源極為複雜。根據乃瓊寺傳承的《佩哈爾伏藏》（Pehar gter-ma），他最初是蒙古或突厥地區的神靈（部分學者認為與摩尼教或中亞祆教的守護神有關），後被蓮花生大士在八世紀入藏途中降伏，立誓守護西藏佛法。然而關於他的神話仍保留了強烈的非佛教色彩——他的五種化身（國王身、大臣身、仙人身、行者身、業力身）在藏傳佛教護法體系中是獨一無二的複數結構。

## 神話事蹟

### 中亞起源與佛教降伏

佩哈爾的起源傳說中，他原本是白哈爾國（Bha-hal / 位於中亞或新疆地區）的神靈——守護一座摩尼教寺廟的寶藏。蓮花生大士在前往西藏途中抵達此地，以神通與佩哈爾辯論七天七夜。蓮師最終以金剛橛（phurba）釘住佩哈爾的影子，迫使其現出原形——一隻白身紅喙的雪獅或三眼巨鳥。蓮師為其授予皈依戒，令其發誓守護藏傳佛教寧瑪派。

此故事與其他護法神（如吉祥天母 Palden Lhamo、多傑列巴 Dorje Legpa）的降伏結構完全相同——先是一位本土或外道神靈，被蓮師以降伏儀式收編，改宗為佛教護法。佩哈爾的特殊性在於他的摩尼教／祆教根源——藏學家 Giuseppe Tucci（1949）與 Anne-Marie Blondeau（1971）均指出，佩哈爾的五種化身與摩尼教的五明光體（Five Sons of the Living Spirit）之間存在結構平行。

### 五身王體系

佩哈爾最獨特的特徵是「五身王」（rGyal-po lnga）體系——他不僅是一位護法神，而是以五種化身組成的複合王權結構：

| 化身 | 藏文名稱 | 形象 | 職掌 |
|------|---------|------|------|
| 意之王 | Thugs-kyi rGyal-po | 騎白馬、持金剛鉞刀與顱器 | 總管一切事業 |
| 身之王 | sKu'i rGyal-po | 騎黃馬、持寶劍與盾牌 | 守護寺院物質資源 |
| 功德之王 | Yon-tan rGyal-po | 騎紅馬、持長矛與套索 | 掌管財富與受用 |
| 語之王 | gSung-gi rGyal-po | 騎藍馬、持金剛杵與金剛鈴 | 守護口傳教法 |
| 業之王 | Phrin-las rGyal-po | 騎綠馬、持戰斧與顱棒 | 執行事業與降伏 |

這五種化身分別對應五方佛（毘盧遮那、寶生、阿彌陀、不動、不空成就）的五智顏色，展現了藏傳佛教將外道護法神吸收後層層佛教化的典型過程。

### 乃瓊神諭

佩哈爾在西藏政治史上的重要性來自他與乃瓊神諭的關聯。乃瓊寺成立於 16 世紀（由第三世達賴喇嘛索南嘉措與乃瓊降神人共同創立），此後一直到 1959 年，歷任西藏噶廈政府（尤其是達賴喇嘛）在重大決策前均會諮詢乃瓊神諭——由降神人（chos-skyong / 却迥）進入深度附體狀態，代佩哈爾傳達神諭。

佩哈爾的附體徵兆極為劇烈：降神人在神壇前焚香誦咒，逐漸進入顫抖狀態，身體僵直旋轉，最後雙眼翻白以佩哈爾的身份發言。1950 年代英國外交官與西藏文獻均記錄了乃瓊神諭在政治危機中的關鍵角色——包括決定達賴喇嘛流亡印度的時機。

## 跨文化對應

| 文化 | 對應神祇/現象 | 共同點 |
|------|-------------|--------|
| 蒙古 | 白老翁（白哈爾／Pehar 的前佛教形態） | 中亞起源、轉化為佛教護法 |
| 希臘 | 德爾斐的阿波羅（神諭中發言者） | 國家級神諭、預言影響政治決策 |
| 日本 | 春日神（被佛教吸收為護法） | 本土神被佛教收編為守護者 |
| 韓國 | 薩滿神話中的降神（kangshin） | 神靈附體於巫堂（mudang）傳達訊息 |
| 非洲（約魯巴）| 伊法（Ifá）占卜系統 | 神靈透過祭司傳達指引 |
| 蒙古—西伯利亞 | 薩滿的守護靈 | 薩滿在儀式中被精靈附體後說話 |

## 相關神祇

- **多傑列巴（Dorje Legpa）**：佩哈爾的下屬護法，原為門巴族的神靈，負責執行佩哈爾的命令
- **吉祥天母（Palden Lhamo / dPal-ldan Lha-mo）**：藏傳佛教最重要的出世間護法女尊，與佩哈爾並列為西藏兩大護法
- **四臂大黑天（Mahakala）**：藏傳佛教最重要的智慧護法，掌管事業與財富
- **蓮花生大士（Padmasambhava）**：降伏佩哈爾的印度密宗大師，寧瑪派祖師

## 出現在
