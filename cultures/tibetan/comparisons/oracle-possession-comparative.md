# 聖靈附體——西藏神諭、韓國巫俗與西伯利亞薩滿教的降神傳統比較

## 一、導論

「神靈附體於人體以傳達訊息」是人類宗教史上最持久的溝通技術之一。西藏乃瓊神諭（gNas-chung chos-skyong）中，佩哈爾護法神降臨於降神人體內；韓國巫堂（mudang）在 kut 儀式中被神靈降身（kangshin / 강신）；西伯利亞薩滿在鼓聲與舞蹈中讓守護靈進入體內——三者在「降神者作為神靈的暫時容器」這一基礎上高度一致，但在儀式結構、政治角色與神學解釋上呈現明顯的差異。本文比較這三種北亞與內亞的降神傳統，探討其共享的薩滿底層與分化的歷史路徑。

## 二、三種降神傳統

### 2.1 西藏乃瓊神諭（Nechung Oracle）

乃瓊寺位於拉薩西郊哲蚌寺附近，是藏傳佛教最重要的官方神諭機構。降神人（chos-skyong / 却迥）經由嚴格的訓練與認證程序後，在特定儀式中擔任佩哈爾五身王的代言者。

降神過程：降神人先在乃瓊寺主殿的金頂內焚香、誦持護法咒（佩哈爾心咒約三至六小時）。當護法完全降臨時，降神人的身體開始劇烈顫抖、呼吸急促，瞳孔放大並上翻。他穿上沉重的絲袍（重達二十公斤），戴上極重的頭盔——頭盔的重量及絲袍的厚度使他在附體後不會因身體的劇烈動作而受傷。助手將寶劍與弓箭放入他手中，他以護法的身份面向西藏政府官員提出預言與決策建議。

乃瓊神諭在 17 世紀至 20 世紀中葉的西藏政治中扮演關鍵角色。五世達賴喇嘛（1617-1682）重建布達拉宮時，曾多次諮詢乃瓊神諭的意見。1949 年後，乃瓊神諭參與了關於達賴喇嘛流亡的重大決策。1959 年達賴喇嘛流亡印度後，乃瓊神諭在印度達蘭薩拉重建，至今仍是流亡藏人政府的精神支柱之一。

### 2.2 韓國巫堂（Mudang / 무당）

韓國巫堂（多為女性，稱為 mudang；男性稱為 paksu 무당 / 박수）在儀式（kut / 굿）中透過舞蹈、歌唱與擊鼓邀請神靈降身。韓國的降神儀式分為兩類：一為「內室降神」（naerim-gut），巫堂獲得第一次神靈附體經驗後正式成為巫堂；二為「公演降神」（kong-gut / 공굿），巫堂為委託人進行的治療、祈願或驅邪儀式。

韓國巫堂的降神特徵是高度的音樂性與戲劇性。與西藏降神人的沉重防護裝備相反，韓國巫堂在降神時穿著輕柔的白色韓服，手持神扇（神扇上用漢字書寫神靈名諱）與神器（鈴鐺、小刀、三叉戟）。在銅鈸、長鼓與簧片的節奏中，巫堂旋轉起舞——附體發生時她的動作變得極其柔軟或僵直，聲音變成神靈的說話方式。每個神靈（如將軍神、產神、龍王神）的行姿與語氣各不相同——熟練的巫堂可以在一次 kut 中讓多位神靈輪流降身。

韓國巫堂在朝鮮王朝時期（1392-1910）被儒家士大夫壓制為「迷信」，但其降神傳統從未被消滅。日據時期（1910-1945）與現代化過程中，巫堂雖被邊緣化，但在 1980 年代後的韓國隨著文化復興而重新被重視，2008 年被韓國政府指定為「重要無形文化財」（重要無形文化財第 51-3 號，首爾薩滿儀式）。

### 2.3 西伯利亞薩滿（Sáman / Шаман）

西伯利亞薩滿的降神是北亞最古老的宗教技術之一。西伯利亞各民族的薩滿儀式共享一個核心過程：薩滿以鼓聲與舞蹈進入意識轉換狀態（altered state of consciousness），其守護靈（與薩滿締結契約的動物或祖先靈魂）進入薩滿體內。在附體狀態中，薩滿的靈魂並不一定被取代——更常見的模式是薩滿的靈魂前往靈界旅行（靈魂出竅 journeying），而在尋找失落的靈魂或與精靈交涉後返回肉體。

不同於西藏降神人的被動容器模式（神靈完全取代降神人的意識），也與韓國巫堂的神靈降身模式有所不同，西伯利亞薩滿更常表現為「薩滿的主動性保留」——薩滿在附體過程中仍然指揮著自己的身體，守護靈是他對話的夥伴而非占據者。圖瓦（Tuva）與布里亞特（Buryatia）的薩滿傳統中，薩滿說「我的靈現在與我的守護靈合為一體」，而不是「守護靈取代了我」。

## 四、比較分析

### 4.1 降神的主體性：被動容器 vs 主動旅行者

三種傳統對「附體時宿主的意識何在」這一問題給出了三種不同的答案。西藏神諭中，降神人的自我意識完全消失——他被描述為「空心的容器」（sbod-sgong），佩哈爾的意識暫時居住其中。韓國巫堂的降神則保有一些模糊性——部分巫堂描述為「神靈像霧一樣包圍我，我聽到祂在說話，但我自己也在場」。西伯利亞薩滿中，靈魂出竅（journeying）遠比被佔據常見——薩滿的主體性在過程中保留，因為他需要與守護靈合作完成任務。

這種差異可歸因於佛教的「無我」（anātman）哲學對西藏降神觀念的影響——作為容器被佔據本身被視為一種修行；而西伯利亞薩滿則強調個體心志的強度——你越「是你自己」，就越能與精靈有效合作。

### 4.2 政治化的分歧

西藏乃瓊神諭經歷了最高度的政治建制化——它從一個寺院的護法儀式，轉變為西藏政府的國師級諮詢機構。韓國巫堂在朝鮮王朝被儒家意識形態壓迫至社會底層，使巫堂的降神傳統保留了「下層女性抵抗主流意識形態」的社會功能。西伯利亞薩滿則在蘇聯時期受到系統性的壓制與抹除（1920-1980 年代薩滿被視為「反革命迷信」而遭迫害），1990 年代後才開始復興。政治化程度與降神者的社會地位呈正相關。

### 4.3 共同的薩滿底層

儘管神學解釋不同，三種降神傳統共享一個深層的北亞—內亞信仰基礎：
1. **精靈世界的階層化**：存在低階精靈（自然靈）與高階神靈的區分，降神者與不同層級的神靈合作
2. **鼓／鈴的媒介功能**：聲音被認為能「打開」靈界之門
3. **季節性與場合性降神**：並非隨時可進行，需要特定的時間、場域與準備
4. **降神者的飲食限制**：西藏降神人需長期茹素，韓國巫堂需避食某些肉類，西伯利亞薩滿需在儀式前禁食

這些共性指向一個可能的共同歷史淵源：青藏高原—東北亞—西伯利亞這一廣闊區域曾共享一個古老的薩滿底層，後因佛教傳入西藏、儒家影響韓國、以及各部族的獨立演化，才分化為今日三種面貌各異的降神傳統。

## 五、結論

西藏乃瓊神諭、韓國巫堂與西伯利亞薩滿展示了「神靈附體」這一古老宗教技術的三種截然不同的命運：在西藏被建制為國家級神諭機構，在韓國被邊緣化為女性的民間療法，在西伯利亞被鎮壓後重新復興。然而三者在儀式結構與靈性世界觀上的深層相似性，強烈暗示了一個跨越高原與草原的共同文化遺產。
