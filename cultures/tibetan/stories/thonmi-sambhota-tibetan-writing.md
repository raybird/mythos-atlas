# 吞米·桑布札與藏文的創造 (Thonmi Sambhota and the Invention of Tibetan Writing)

- **文化：** 西藏神話 (Tibetan Mythology)

## 故事背景

在松贊干布（Songtsen Gampo / Srong-brtsan sGam-po，約 617-650 年）統一吐蕃各部之前，西藏沒有自己的文字。根據藏文史籍《賢者喜宴》（mKhas-pa'i dGa'-ston，成書於 1564 年）與《西藏王統記》（rGyal-rabs gSal-ba'i Me-long，成書於 1368 年）記載，松贊干布派遣了以吞米·桑布札（Thonmi Sambhota / Thon-mi Sam-bho-ṭa）為首的十六名吐蕃青年前往印度學習梵文與佛教經典。吞米·桑布札的藏文姓名「吞米」指其家族（來自吐蕃的吞氏族），「桑布札」意為「賢善的學者」或「吉祥學者」。

吞米·桑布札的故事不僅是文化的英雄史詩——它同時是藏語語言學的起源神話，與希臘神話中卡德摩斯（Cadmus）從腓尼基引入字母、或韓國世宗大王創制訓民正音的故事具有深層的結構平行。三者都將「文字」的發明歸因於一位前往文明中心（印度、腓尼基、中國）學習後返回的英雄，文字因此被神聖化為外來啟示的產物，而非內生發明。

## 情節

### 第一階段：吐蕃的無文時代

根據《賢者喜宴》，松贊干布即位後深感吐蕃無文字之苦——無法記錄法律、無法翻譯佛經、無法與鄰國通訊。他意識到西藏若要從野蠻的武士社會轉變為文明的佛法國度，必須首先獲取書寫系統。

### 第二階段：前往印度

松贊干布選中最聰明的青年吞米·桑布札——桑布札受賜黃金一升、金粉一升、諸多財寶，率十五名隨從出發前往印度。旅途極為艱險：穿越雪山、荒漠與盜匪橫行的通道。十五名隨從或因疾病、或因盜匪襲擊相繼死去——吞米獨自抵達印度。

在印度，吞米·桑布札首先拜訪了婆羅門學者李敬（Likin / Li-byin），學習梵語語法與《聲明論》（Vyākaraṇa，梵文文法學）。然而李敬自己不識字——他感嘆說：「我知語法卻無所書寫，我是一個沒有武器的獵人。」吞米隨即前往更遠的南方，尋找知曉文字的明師。

### 第三階段：師從婆羅門瑜伽師

吞米·桑布札在印度南方遇到了精通梵文與各種書體的婆羅門瑜伽師 Satamani（或作 Devavidyāsiṃha）。這位瑜伽師不僅精通佛教與印度教的經典，還熟悉多種書法字體——包括蘭札體（Rañjanā，尼泊爾/梵文裝飾字體）與瓦德體（Vartu / 瓦杜體，一種類似於笈多王朝的文字）。

吞米隨 Satamani 學習了四年，掌握了：
- 梵文語法（Panini 的 Aṣṭādhyāyī）
- 六十四種書寫體（據傳統所稱）
- 佛教經典的閱讀與翻譯

### 第四階段：創制藏文

吞米·桑布札返回西藏後，根據他在印度學習的笈多文字（Gupta script，特別是來自克什米爾一帶的瓦德字體 Vartu）創制了藏文。他做了兩項關鍵調整：

第一，忠實保留了梵文的三十四個輔音字母，但根據藏語發音省略了五個梵文中不存在的反響音（Ṇa / Ña / Ṭa / Ṭha / Ḍa）；第二，為了匹配藏語中特有的元音系統，從蘭札體中借用了符號來表示藏語的四個元音符號（i、u、e、o）以及反寫字標記等。

最終完成的藏文包含三十個輔音字母與四個元音符號——這套系統在過去一千三百多年中幾乎未變，是世界上最穩定的書寫系統之一。

### 第五階段：書寫法律與翻譯佛經

吞米·桑布札以新創的文字書寫了吐蕃第一部成文法——松贊干布的「十善法律」（bKa'-yi khrims-yig / 十善律）與「十六淨法」。同時他也開始了藏文史上最早的佛經翻譯——據傳統記載，他翻譯了《大雲經》、《寶雲經》與《普賢行願品》等經典，建立了藏傳佛教翻譯的基礎。松贊干布為了紀念吞米的成就，封他為「大堪布」（mkhan-po / 教授師），並命令王室子弟與所有大臣學習藏文。

## 跨文化平行

| 元素 | 吞米·桑布札 | 跨文化平行 |
|------|------------|-----------|
| 無文字時代的國王 | 松贊干布呼喚文字 | 埃及傳說中 Thoth 賜予文字於法老 |
| 英雄遠赴文明中心學習 | 吞米赴印度學梵文 | 希臘 Cadmus 赴腓尼基引入字母 |
| 師從當地學者 | Satamani 瑜伽師 | 希臘 Cadmus 師從腓尼基書吏 |
| 以他國文字為基礎創制 | 以笈多/瓦德字母創藏文 | 韓國世宗以漢字創訓民正音；古騰堡以歐洲中世紀字體創印刷 |
| 歸國後用來書寫法律與經典 | 十善律與佛經翻譯 | 穆罕默德以阿拉伯文記錄古蘭經；世宗頒布《訓民正音》篇 |
| 文字的神聖化 | 藏文字母被認為載有咒力 | 梵文 devanāgarī = 天城文，被視為神書 |

## 相關主題

- **文字的神聖起源**：書寫系統作為神的禮物或文明英雄的發明（埃及 Thoth、迦南 Cadmus、韓國世宗）
- **佛教翻譯運動**：藏文大藏經（Kangyur / Tengyur）的建立
- **文化英雄：連接兩種文明的使者**
