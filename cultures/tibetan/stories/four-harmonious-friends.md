# 四和合友（Four Harmonious Friends）— 以年資為序的互助寓言

- **文化：** 西藏神話 (Tibetan Mythology)

## 故事背景

「四和合友」（藏文：མཐུན་པ་སྤུན་བཞི།，thun pa spun bzhi）是藏傳佛教本生故事體系中最著名的寓言之一，也是西藏、不丹與蒙古民間藝術中最常見的圖繪母題：一隻鳥（通常為鵪鶉／原雞，在不丹亦見犀鳥）、一隻兔子、一隻獼猴與一頭大象彼此疊立，鳥居頂端、象居其下的形象，出現在寺廟壁畫、窣堵坡（stupa）浮雕與日常器皿的裝飾上——藏人或不丹人深信，凡懸掛此圖之處，十善即得增長，家中和諧、長幼有禮。故事最早的文字版本見於佛典：巴利《本生經》收錄的《鶉鳥本生》（Tittira Jātaka），以及藏譯《律事》（Vinayavastu，藏文 'dul ba'i gzhi，即《甘珠爾》律藏之首部）所載的版本。它在佛教三藏中的地位特殊——雖非所有部派皆視為佛本生，卻被普遍用作佛陀宣說「敬老而和合」之道的講經比喻。

## 情節

### 一、以樹的年資定尊卑

昔時，靠近波羅奈（Varanasi，今印度瓦拉那西）的森林中，鳥、兔、猴、象結為好友。牠們見到世人少敬老、多僭越，決心以身作則演示「長幼有序」的秩序。為了決定誰最年長，牠們以樹為尺：大象說自己年幼時，此樹已是參天大樹；獼猴說自己來時，樹才齊身之高；兔子說自己還小之時，樹不過幼苗，牠曾舔食其葉上晨露；鳥則說出令人驚異的話——「這棵樹，是我吞下的種子隨糞排出後所生。」於是年資次序排定：鳥最長，兔次之，猴再次，象最幼。

### 二、活塔與採果

年紀較輕的動物背負較年長者，疊成一座「活塔」：鳥立於兔背上、兔在猴肩、猴騎象首——藉此構成了擁抱大樹第一根枝椏的合力。此後樹愈長愈高，單憑任何一獸都無法摘取果實：鳥無法飛翔，只能啄食地面；兔能取矮處之果，猴能攀上中段樹枝，但樹梢之果仍高不可及。唯有四獸疊立，象支撐全局，方得以採擷最高處的果實，共享其味——此即「互助方能成就」的圖像化教示。

### 三、守戒與太平

鳥（最年長者）教導其餘三獸持守五戒：不殺生、不偷盜、不邪淫、不妄語、不飲酒。四獸各引同類歸於正道，眾生和樂，世間安泰。當時國王與臣民以為太平來自自身的福德，心中驕慢；一位具神通的仙人為其點明因緣：國家豐饒並非眾人之功，而是山上林中四獸持戒、感化萬物的結果。人們聞之慚愧、隨喜，亦開始守持五戒，死後多生善趣。

### 四、身分的揭曉

故事末了，佛陀揭示：此鳥正是他自己的前世——不過，不同版本對另外三獸的身分所指不一：一說兔為舍利弗、猴為大目犍連、象為阿難；另一流傳說兔為阿難、猴為舍利弗、象為大目犍連。值得注意的是，巴利《鶉鳥本生》僅有三獸而無兔——第四獸是藏傳與漢傳版本中才加入的，反映此寓言在流傳中漸次擴充的層累特徵。

## 跨文化平行

| 四和合友 | 對應 | 文化 |
|---|---|---|
| 以年資而非體力定尊卑 | 儒家「長幼有序」之禮 | 中國 |
| 四獸合體方得眾果 | 《瞎眼摸象》喻——各執一端的認識須合而為一 | 印度 |
| 鳥、兔、猴、象代表空、樹、地、地下四層棲地 | 天龍八部中飛空、行地、居水之諸趣眾生各司其位 | 印度佛教 |
| 年資判定的審辨遊戲 | 各民族「何種動物最長壽/最老」的民間問答母題 | 全球民間故事 |
| 醫院、寺壁懸圖求家宅和順 | 門神與吉祥圖騰的鎮宅護家功能 | 中國／東亞 |
