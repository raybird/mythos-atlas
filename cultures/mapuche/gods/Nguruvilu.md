# Nguruvilu（水狐蛇）

- **文化：** 馬普切神話 (Mapuche Mythology)
- **職掌：** 河川／湖泊水靈、渦流與渡河之災、水域守護者

## 概述

Nguruvilu（又拼作 Guruvilu、Guirivilu、Guirivilo、Ñirivilu，馬普切語源自 ngürü「狐狸」＋ filu「蛇」）是馬普切神話中最著名的河川水靈之一，棲居於智利中南部與阿根廷西南部的河流、湖泊與沼澤之中。祂最經典的形象是「狐首蛇身」的奇美拉：擁有狐狸的頭部、尖耳與狡黠的眼睛，胸前長著兩隻帶爪的前肢，身體則是一條可達十餘公尺的蛇尾，紅褐色的皮毛在頸部以下轉為鱗甲。十九至二十世紀的人類學採集記錄了多種變體——民族學家 Tomás Guevara（1908）記載了一種「貓頭、細身、長狐尾」的河獸；Robert Lehmann-Nitsche（1902）則記下其蛇身末端長有鉤爪，用以纏住獵物拖入水底吸血。Nguruvilu 棲身於河道的淺灘與靜水彎處，祂既是殺人的水妖，也被部分部落視為水域的「主人」與守護者——正如馬普切萬物皆有其「主人」Ngen 的宇宙觀，河川同樣由一位強而有力的主人看守。

## 神話事蹟

### 以假象誘人涉水

Nguruvilu 最危險的能力在於「欺騙」：祂潛伏在水下，將河面弄得看似淺而安全，誘使旅人、漁夫與孩童涉水而過；待獵物踏入河道中央，祂便以長尾猛烈攪動水面，製造致命的渦流，將人捲入深處淹死，再以尾端的鉤爪拖曳獵物、吸飲其血。因此民間諺語與傳說都告誡：有 Nguruvilu 棲息的河道，唯一安全的渡河方式是乘船——絕不可步行涉水。

### 尾為命脈的弱點

馬普切傳說明確指出，Nguruvilu 的生命力寄於其長尾之上——正如 de Saunière（1917/1918）所述，「其生命之源存於尾部」。故事中，英雄斬斷狐獸的尾巴，牠便當場死亡。此「命寄於肢體末梢」的設定，使其與全球神話中的「外部靈魂／命門」母題（如希臘美勒阿格的火炬、俄羅斯科謝伊的針與蛋）遙相呼應。

### 祭祀與鎮伏

Robert Lehmann-Nitsche（1902）的資料來源（其印地安報導人 Nahuelpi）指出：只要人們對 Nguruvilu 施以特定的崇拜儀式，這條「狐蛇」便不會傷害人。而當祂開始危害村落時，則必須由最強大的 Machi（薩滿祭司）或 Kalku（巫師）入水與祂搏鬥，將其擒至水面、以刀刃威嚇後驅逐出境——此一「擒伏水妖」的敘事成為馬普切薩滿醫療敘事的重要環節。

## 跨文化對應

| 馬普切 | 跨文化對應 | 共通點 |
|--------|-----------|--------|
| Nguruvilu（狐首蛇身、製造渦流拖人下水） | ↔ 日本河童（Kappa，水棲妖怪） | 棲居河中、誘人涉水、需以禮相待 |
| Nguruvilu 誘使人誤以為河水可涉 | ↔ 蘇格蘭凱爾派（Kelpie，水馬） | 以偽裝誘人下水致死 |
| Nguruvilu 的長尾鉤爪拖人吸血 | ↔ 日耳曼尼克斯精靈（Nix/Neck，水靈） | 水靈拖人入深處、溺人吸血 |
| Nguruvilu 為水域主人、須敬拜 | ↔ 中國河伯／水神信仰 | 河川之主，溺斃為其行使權 |
| Nguruvilu 尾為命脈、斷尾即死 | ↔ 俄羅斯科謝伊之針／希臘美勒阿格火炬 | 「外部靈魂」命門母題 |
| Machi 入水搏鬥鎮伏水妖 | ↔ 埃及祭司對抗阿佩普／日本御祓 | 薩滿／祭司驅逐水域之惡 |

## 相關神祇

- **Kai-Kai Filú（海蛇）** — 同屬「filu」蛇族，海中的洪水巨蛇，為 Nguruvilu 的大海對應
- **Trentren Filú（山蛇）** — 大地保護之蛇，象徵秩序與陸地安全
- **Ngen（自然守護靈）** — 馬普切「萬物皆有主」的守護靈體系，Nguruvilu 可視為水域之主的極端化身
- **Machi（薩滿祭司）** — 唯一能入水擒伏 Nguruvilu 之人
- **Pincoya（海的仙女）** — 仁慈的水域靈體，與兇惡的 Nguruvilu 形成正反兩面

## 出現在

- 馬普切口傳傳統（智利中南部河川、湖泊地帶）
- 奇洛埃（Chiloé）群島的河口與海峽傳說
- 19–20 世紀人類學採集：Guevara (1908)、Lehmann-Nitsche (1902)、de Saunière (1917/1918)
- 智利現代文學與流行文化（如 Isabel Allende《精靈之屋》曾提及水怪傳說的在地版本）
