# Trauco 森林矮人 (Trauco — El Duende del Bosque)

- **文化：** 馬普切神話 (Mapuche Mythology)

## 故事背景

Trauco 是馬普切神話中最令人著迷的森林精靈之一，棲息於智利南部瓦爾迪維亞溫帶雨林的幽暗深處。他的名字源自馬普切語 *trawün*（意為「相遇」或「會議」），暗示他作為森林居民與人類世界之間的中介角色。Trauco 的身高僅及人類膝蓋，頭頂戴著一頂由樹皮製成的錐形帽（*trarilonco* 的微型版本），手持一根敲擊聲能召喚精靈的木杖。他的面容既非美亦非醜——介於大地之靈的質樸與超自然存在的詭異之間。在馬普切宇宙觀中，Trauco 屬於 Ngen（自然元素守護靈）的下級階層，負責守護森林中的特定區域：倒下的古木、苔蘚覆蓋的岩石、以及溪流源頭。他是 *puel mapu*（東方之地，即森林與山脈）的居民，不屬於人類的 *nguillatun*（祈禱）儀式管轄範圍。

## 情節

### 與人類的相遇

馬普切口傳傳統中最常見的 Trauco 敘事結構為「迷途者遭遇」。一個獵人或採集者在森林中迷路——可能是因為偏離了祖先標記的路徑，或是因為在不該停留的區域過夜。當夜幕降臨，獵人會聽到遠處傳來有節奏的敲擊聲——那是 Trauco 用木杖敲擊空心樹幹的聲音，是警告也是召喚。如果獵人心生恐懼而尖叫逃跑，Trauco 會以一團腐爛的樹葉使人迷失更深；但如果獵人冷靜地以 *machitún*（薩滿祈禱的簡短版本）回應，Trauco 會現身引導他找到水源與庇護所。

在另一個著名版本中，一個年輕女子獨自前往森林採集 *piñones*（智利松果）。Trauco 被她的歌聲吸引，悄然跟隨。他以一陣帶有松脂香氣的霧氣包圍她——女子在霧中看到一座由螢火蟲照亮的小屋，Trauco 坐在火堆旁，以微小的手勢邀請她進入。女子在小屋中度過一夜，醒來時發現自己躺在一棵巨大的瓦爾迪維亞冷杉根部，手中握著一枚從未見過的金色種子——據說這就是 *copihue*（智利國花，紅色喇叭花）的起源。

### Trauco 與 Colocolo 的對立

馬普切神話中存在一組重要的對立關係：Trauco（森林的守護者）與 Colocolo（蛇鼠混合體，森林的腐蝕者）。根據口傳敘事，Colocolo 是 Wekufu（惡靈）的使徒，牠在森林地面下掘洞，使樹根暴露、土壤流失、溪流混濁。Trauco 以木杖敲擊地面，使土壤重新緊實——這就是為什麼在馬普切森林中，某些區域的地面異常堅硬，被稱為「Trauco 的腳印」。這組對立反映了馬普切生態觀中的核心張力：森林既是恩賜也是危險，守護者與毀滅者共存於同一片土地。

### 作為預兆的 Trauco

在馬普切農業傳統中，Trauco 的出現被視為重要預兆。如果在播種季節聽到 Trauco 的敲擊聲，被認為是豐年的吉兆——因為 Trauco 在敲擊中喚醒了沉睡的土壤精靈。相反，如果在收穫季節聽到，則預示著 *ülkün*（不祥）——可能有乾旱或蟲害。 Machi（薩滿）會根據 Trauco 出現的方位（東方為吉，西方為凶）來調整 *rütrafe*（年度儀式）的日期。

## 跨文化平行

Trauco 在跨文化比較中對應多個精靈原型：

- **歐洲矮人（Dwarf）**：日耳曼與凱爾特傳統中的森林矮人，同樣擅長手工藝、守護地下寶藏、與人類保持若即若離的關係。北歐的 *dvergar*（侏儒）同樣居住在岩石與古木之中，以錘擊聲標示存在。
- **日本山姥（Yama-uba）**：棲息於山林深處的老婦人精靈，有時引導迷途旅人，有時吞噬不敬者。與 Trauco 同樣具有「守護者/毀滅者」的雙面性。
- **凱爾特樹靈（Tree Spirit / Dryad）**：希臘神話中的樹木精靈 Dryad 與 Trauco 同樣與特定樹木綁定，樹木枯死則精靈消亡。
- **南美原住民森林精靈**：亞馬遜流域的多個原住民族群（如 Asháninka、Yanomami）皆有類似的森林守護精靈傳說，通常以矮小、與樹木融為一體的形象出現。

這些平行反映了全球範圍內「森林精靈」母題的普遍性：在人類與原始森林接觸的邊界地帶，幾乎所有文化都創造了中介性的精靈形象，用以解釋森林的不可預測性與神聖性。
