# Svetovit 的神諭 — 阿爾科納神廟的白馬預言

- **文化：** 斯拉夫神話 (Slavic Mythology) — 溫德人分支

## 故事背景

Svetovit（Световит，意為「光明之靈」或「世界之主」）是波羅的海沿岸溫德人（Wends）所崇拜的最高戰神與豐收之神。他的主要神廟位於今德國呂根島（Rügen）上的阿爾科納（Arkona）海角，這座白色石砌神廟是斯拉夫異教世界中規模最大、保存最久的聖地，直到 1168 年才被丹麥國王瓦爾德馬一世（Valdemar I）與奧布洛特主教 Absalon 聯軍摧毀。關於 Svetovit 神諭的記載主要來自丹麥歷史學家薩克索·格拉瑪提庫斯（Saxo Grammaticus）的《丹麥人的事蹟》（Gesta Danorum，約 1208 年）以及 Adam von Bremen 的《漢堡教會史》。

## 神話敘事

### 神廟與神像

阿爾科納的 Svetovit 神廟矗立於海崖之上，外牆以白色石塊砌成，與周圍暗色的森林形成強烈對比。廟內的 Svetovit 神像由深色木材雕刻而成，身高逾四米，具有四張面孔——分別朝向東、南、西、北四個方向，象徵他能同時洞察宇宙四方。神像右手持一個巨大的角杯（rhyton），以銀和黃銅鑲嵌，內中盛滿的葡萄酒被信徒視為神諭的載體。神像左腰佩劍，劍柄以寶石裝飾，象徵他作為戰爭之神的威權。神像的鬍鬚被精心梳理，長髮垂至腰際。在神像的前方，另有一座較小的雕像——一匹木雕白馬，象徵 Svetovit 的坐騎與戰爭機動性。

### 白馬預言儀式

每年一次，在秋收之後的特定日子，祭司長會舉行 Svetovit 的年度神諭儀式。此儀式是斯拉夫異教世界中最莊嚴的宗教活動之一，吸引了來自整個波羅的海沿岸的信徒。儀式分為三個階段：

**第一階段：淨化。** 祭司在神像前焚燒草藥與穀物，信徒在神廟外的聖泉中沐浴。泉中的水被禁止攪動——因為 Svetovit 的神諭之水必須保持絕對平靜。

**第二階段：問卜。** 祭司長將角杯中的陳年葡萄酒倒出一部分，然後以雙手捧杯向神像祈禱，詢問來年戰爭與豐收的吉凶。隨後，祭司將剩餘的酒一飲而盡。信徒們屏息等待——若祭司在飲酒後面露喜色，則預示來年順遂；若面露憂色或沉默不語，則預示災禍將至。在某些記錄中，預言還透過白馬的行為來傳達——若白馬在神廟前嘶鳴或踏步，則被解讀為吉兆。

**第三階段：共享。** 預言儀式結束後，信徒在神廟前的廣場上舉行大規模宴席。Svetovit 角杯中的酒被稀釋後分發給所有在場者——每人一小口，象徵與神的直接聯繫。這是一年中唯一一次凡人得以品嚐 Svetovit 聖酒的時刻。

### 白馬的神聖性

Svetovit 的白馬在溫德人信仰中具有特殊地位。據薩克索記載，白馬被養在神廟附近的聖林中，禁止任何人騎乘。每年神諭儀式前，祭司會帶領白馬穿越戰場遺跡，讓牠在屍骨間漫步——若白馬在某處停下凝視，則預示該地將在來年發生戰事。白馬死後，其皮毛會被保存在神廟中，作為下一匹聖馬誕生前的象徵物。

### 神廟的毀滅

1168 年，丹麥國王瓦爾德馬一世率軍登陸呂根島。溫德人首領 Jaromar I 向丹麥人投降，但阿爾科納的祭司們拒絕放棄信仰。Absalon 主教下令摧毀 Svetovit 神像——士兵將木像從神廟中拖出，用斧頭劈成碎片後焚燒。據亞當·布雷姆記載，當神像被劈開時，內部流出大量「陳年血液」（可能是祭司長期注入的獻祭血液與葡萄酒混合物），這一幕震驚了在場所有人。丹麥人隨後在神廟原址建起基督教堂，但斯拉夫信徒在很長一段時間內仍秘密前往廢墟中祈禱。

## 跨文化平行

| 元素 | 斯拉夫 Svetovit | 對應文化 |
|---|---|---|
| 四面神像 | Panimukha（四面神）/ Brahma（四面） | 印度吠陀 |
| 角杯飲酒預言 | Delphi 女祭司吸入蒸氣後宣示神諭 | 希臘 |
| 聖馬作為預言媒介 | Horses of the Sun（太陽馬）/ Castor 與 Pollux 的馬術 | 希臘/羅馬 |
| 四方守護 | 四天王 / Four Directions | 中國/印度/美洲 |
| 以酒/血溝通神意 | Zoroastrian Haoma 祭祀 | 伊朗/波斯 |
| 神廟毀滅與轉化 | 帕特農神廟改為基督教堂 | 拜占庭 |
| 年度大祭宴席 | Panegyris（泛希臘節慶）/ Saturnalia | 希臘/羅馬 |
