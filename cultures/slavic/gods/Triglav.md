# Triglav — 斯拉夫三頭神

- **文化：** 斯拉夫神話 (Slavic Mythology)
- **職掌：** 天空、大地、冥界三界統治；時間、命運、宇宙秩序

## 概述

Triglav（三頭神，字面意義為「三顆頭的神」）是斯拉夫神話中極為特殊的三位一體神祇。他的名字與形象出現在多處波美拉尼亞（Pomerania）斯拉夫人——即文德人（Wends）——的宗教記錄中，尤其是 12 世紀德國編年史家赫爾姆斯泰特的亞當對波羅的海沿岸斯拉夫異教神廟的描述。在斯捷格（Stettin，今什切青）的大神廟中，Triglav 的神像被描述為有三顆金頭，雙眼覆蓋著，象徵他同時觀看天界、地界與冥界。三頭的結構也隱喻著時間的三個維度：過去、現在與未來。

## 神話敘事

### 宇宙三界的統治者

Triglav 被認為是 Perun（天空）、Veles（冥界）與 Jarilo 或 Svarog（大地）三重神性的統合體。在斯拉夫三層宇宙觀（天界—地界—冥界）中，Triglav 是唯一能穿越三界而不受限的神祇。他的三顆頭分別注視三個世界，使他成為宇宙秩序的終極守護者。部分學者認為 Triglav 並非獨立的神祇，而是 Perun 在三界中的三重顯現——類似印度教的 Trimurti（梵天、毗濕奴、濕婆）結構。

### 神廟與祭祀

赫爾姆斯泰特的亞當記載斯捷格的 Triglav 神廟為三層結構，頂層為天空象徵，中層為大地，底層為冥界。神像被黃金覆蓋，三顆頭均戴金色王冠。祭司們在神廟中進行占卜與獻祭，Triglav 的祭司階級（Volkhvs）被描述為擁有穿越三界的靈視能力。神廟被摧毀後，其遺址成為基督教教堂的地基——今日什切青的聖約翰教堂即建於其上。

### 眼睛的象徵

Triglav 的眼睛被覆蓋或遮蔽，這一細節在宗教象徵學中極為重要。覆眼意味著他「看而不被看」，是超越凡人感知的神聖存在。這一特徵在跨文化比較中頻繁出現：希臘的命运三女神（Moirai）同樣以紡織遮蔽命運之線、埃及的荷魯斯之眼則以相反方式強調「視覺」作為神力的象徵。覆眼也暗示著先知者的狀態——只有閉上肉眼才能看見三界全貌。

## 跨文化對應

| 斯拉夫 Triglav | 對應神祇/概念 | 文化 |
|---|---|---|
| 三頭/三位一體 | Trimurti（梵天/毗濕奴/濕婆） | 印度 |
| 三界統治 | 三重神結構 | 凱爾特（Brigid 三相） |
| 覆眼先知 | 盲先知 Tiresias | 希臘 |
| 三頭 | Hecate Triformis（三相女神） | 希臘 |
| 三界通道 | Yggdrasil 三根 | 北歐 |

## 相關神祇

- **Perun**（雷神）—— Triglav 的天界面向
- **Veles**（冥界神）—— Triglav 的冥界面向
- **Jarilo**（春神）或 **Svarog**（天火神）—— Triglav 的大地面向
- **Rod**（創世神）—— 在某些詮釋中，Triglav 是 Rod 的三重顯化
