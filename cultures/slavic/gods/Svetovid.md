# 斯維亞托維德 (Svetovid / Svantevit)

- **文化：** 斯拉夫神話 (Slavic Mythology) — 西斯拉夫／波羅的海斯拉夫支系
- **職掌：** 至高戰神、豐收與穀物之神、神諭與占卜之主、部落邦國守護神

## 概述

Svetovid（古教會斯拉夫語 Свентовит，又作 Svantevit / Sventovit / Suentevitus）是波羅的海斯拉夫人（特別是呂根島 Rügen 的 Rani 部落）所崇拜的最高神祇。其名一般解析為原始斯拉夫語 *svęt-（神聖）加上 *vit-（主、力量、生命），合意為「聖主」或「聖力」，與印歐語系中「神聖力量具現為王權」的觀念相通。中世紀兩大史料——薩克索·格拉瑪提庫斯（Saxo Grammaticus）《丹麥人的事蹟》（*Gesta Danorum*，約 1208 年）第十四卷，與赫爾莫德（Helmold）《斯拉夫人編年史》（*Chronica Slavorum*，約 1168 年）——是關於 Svetovid 最詳盡的書面記錄，其崇拜中心位於今德國呂根島阿爾科納（Arkona）海崖上的宏大神廟，直至 1168 年才被丹麥國王瓦爾德馬一世（Valdemar I）與主教阿布薩隆（Absalon）聯軍攻陷摧毀。

## 神話事蹟

### 四張面孔與宇宙監察

Svetovid 的神像由巨木雕成，高逾四米，擁有四張面孔，各自朝向東、南、西、北四方。學者普遍將四張面孔解讀為「全向監察」——他同時洞悉四季的流轉、四方的戰事與四方的莊稼。此種「多首神」的造形與同時期波羅的海斯拉夫的 Triglav（三頭神）、Rugievit（七頭神）、Porevit（五頭神）構成一個完整的「多頭神群」，顯示當地神學以「頭的數量」量化神靈的感知與權威。Svetovid 右手持巨大的角杯（rhyton），以銀與黃銅鑲嵌，杯中注滿葡萄酒，作為來年豐收與戰爭吉凶的神諭媒介；左腰佩劍，劍柄鑲飾寶石，凸顯戰神身分。

### 神諭、聖馬與祭儀

Svetovid 的祭司以神像前的聖馬占卜——白馬禁止乘騎，於每年秋收後的神諭儀式中被牽行穿越戰地遺跡，馬匹駐足凝視之處即被解讀為來年戰場。祭司長先以角杯傾酒問卜，再將剩酒一飲而盡，視其面色判斷吉凶。廟宇同時充當戰爭掠奪的貯藏所：據薩克索記載，信徒將戰利品的三分之一奉獻入廟，由祭司保管，這使阿爾科納兼具宗教聖地與邦國寶庫的雙重地位。每年秋收後的年度大祭集結全波羅的海沿岸信徒，宴飲之際人人以角杯盛酒共飲，象徵與神聖力量共享豐收。

### 廟宇的毀滅與遺緒

1168 年丹麥人攻陷阿爾科納，阿布薩隆主教下令劈毀並焚燒 Svetovid 神像，於原址建立教堂。據赫爾莫德所述，神像被劈開時流出大量「陳年液體」（學者推測為長期灌入的祭酒與血混合物），此情節成為斯拉夫異教覆滅的象徵性圖景。此後 Svetovid 的形象被部分研究者比附為聖維特（St. Vitus）——西斯拉夫地區基督教化後，以音近聖人「收編」舊神之名，與東斯拉夫將 Veles 比附為聖布拉修斯（St. Blaise）如出一轍。

|------|---------------------|--------------|
| 四張面孔 | 觀照四方的全知 | 梵天（Brahma，四面）／中國四望之神 |

| 廟宇兼國庫與會議所 | 寶庫與政治中心 | 希臘奧林匹亞聖所／中國明堂 |
| 多頭神系一員 | 與 Triglav、Rugievit 並列 | 印度 Brahma／日本面靈神 |
| 聖地覆滅與聖人比附 | St. Vitus 收編 | 北歐 Odin→St. Olaf／希臘神祇→聖人 |

## 相關神祇

- **Triglav**（三頭神）— 西斯拉夫多頭神系的另一核心
- **Radegast**（戰神兼賓客之神）— 雷特拉神廟的主神，與 Svetovid 同屬波羅的海斯拉夫邦國神祇
- **Perun**（雷神）— 東斯拉夫的天界秩序神，與 Svetovid 的邦國守護功能平行
