# 沃佳諾伊 (Vodyanoy) — 水靈公爵

- **文化：** 斯拉夫神話 (Slavic Mythology)
- **職掌：** 水域主宰、溺死者靈魂的統治者、磨坊水車的守護與威脅

## 概述

Vodyanoy（沃佳諾伊，俄語 водяной，字面義「屬水的」「水裡的那位」）是斯拉夫民間信仰中支配一切淡水域的男性水靈——河流、深潭（омут）、湖泊、水車潭與沼澤皆屬其領地。與「美」相關的北歐水精、與「惡」相關的希臘海妖不同，沃佳諾伊既是磨坊主的契約對象，也是溺水者的掠奪者：他會把誤入深水的人拖入水底宮殿充當僕役，也會在盛怒時沖垮水壩、掀翻渡船。漁夫、磨坊主與養蜂人都向他獻祭以求平安。

## 神格與面貌

- **形態：** 綠鬚綠髮的老者，腹部隆起、身體覆滿水藻與黏液，或全身布滿黑色魚鱗、手為蹼掌、眼如炭火。他也能化身大魚、浮木、馬、孩童、白楊樹等物以誘人近水。
- **別稱：** 俄語「水爺爺」（Дѣдушка-водяной）、捷克與斯洛伐克語 vodník（沃德尼克）、斯洛文尼亞語 vodeni mož、波蘭語 topielec（「溺者」）。
- **居所：** 深潭與水車下方；據說他在水下宮殿中以水草為瓦、以蚌殼為窗，把溺亡者的靈魂貯存於陶罐（soul pots）之中。
- **家室：** 娶 rusalka（魯薩爾卡，溺亡少女所化的水澤女靈）或蟾蜍妻為伴；捷克民間傳說中常見「蟾蜍妻」變體。
- **月相祕法：** 綠鬍鬚隨月相變化——月盈時青春，月虧時衰老、鬍鬚轉白，象徵水靈與陰曆週期同頻。

## 神話事蹟

**一、溺亡契約與磨坊祭。** 斯拉夫村落傳說中，磨坊主在磨坊地基下活埋一隻黑公雞，或於興建時把黑公雞投入潭中「奠基」，向沃佳諾伊買下土地的居住權。之後每逢四季轉換，磨坊主需把麵包與鹽投入水中作為「租金」。若祭禮中斷，水靈便會讓水車停擺、引水漫田，甚至索要磨坊主的靈魂或家人作償。此「人與水靈的契約」是斯拉夫磨坊傳說的核心母題。

**二、溺水者的審判。** 沃佳諾伊對游泳者有嚴格禁忌：日落後下水、節日下水、未畫十字下水者皆被拖入深處。被拖走者的屍體「臉朝下浮起」——民間據此判斷死者是沃佳諾伊所奪。據說他不接受「已畫十字」的人，基督教化後他又被改寫為溺斃猶大所化的惡靈，顯示異教水靈與基督教敘事的融合。

**三、養蜂人的守護神。** 意外的是，沃佳諾伊也是養蜂人的守護者——傳說第一群蜜蜂從他踩死的馬身上飛出。養蜂人用蜂蜜與蜂蠟獻祭，以求蜂群繁盛；此面向顯示他並非純粹的邪惡，而是「未馴化自然」的契約之主。

## 跨文化對應

| 斯拉夫 Vodyanoy | 對應水靈 | 文化 |
|---|---|---|
| 男性水靈、以契約換取平安 | 尼克（Nix/Näck）、水鬼 | 日耳曼／北歐 |
| 水車磨坊的威脅者 | 佛塞格林（Fossegrim，瀑布琴靈） | 挪威 |
| 拖人入水的馬形水靈 | 凱爾皮（Kelpie）／水馬（Each-uisge） | 蘇格蘭／愛爾蘭 |
| 綠鬚老者、水底宮殿 | 奈基（Näkki）、阿赫蒂（Ahti） | 芬蘭 |
| 河中拖人、須以祭品安撫 | 河童（Kappa） | 日本 |
| 河界之主、嫁娶與獻祭 | 河伯、龍王 | 中國 |
| 洪水與水的混沌力量 | 波塞冬／尼普頓、埃吉爾（Ægir） | 希臘／羅馬／北歐 |

沃佳諾伊與凱爾皮、河童共享「以假象誘人下水」的行為模式；與佛塞格林、奈基共享「以契約／禁忌規範人類用水」的倫理；與河伯共享「河流需要祭品」的農業社會邏輯。其獨特性在於他把水域徹底人格化為「可協商的領主」——不是被征服的混沌，而是必須與之討價還價的鄰居。

## 相關神祇

- **Rusalka（魯薩爾卡）：** 溺亡少女所化的水澤女靈，沃佳諾伊之妻或從屬
- **Perun（佩倫）：** 雷電之神，掌管天上的水——沃佳諾伊是地上水域的對應者
- **Veles（韋萊斯）：** 冥界與豐饒之神，與水靈共同支配「地下的水域」意象
- **Domovoi（多莫沃伊）：** 家宅精靈——「居家」與「曠野」的二元結構中的室內極
