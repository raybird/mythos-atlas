# 母上巒（Mẫu Thượng Ngàn）

- **文化：** 越南神話（Đạo Mẫu／越南母道教）
- **職掌：** 山林、樹木、野生動物、狩獵、草藥
- **象徵：** 綠色長袍、山林、鹿、明月
- **相關體系：** 四府（Tứ Phủ）信仰中的第二位聖母

## 概述

母上巒（Mẫu Thượng Ngàn），又稱「山母」或「林母」，是越南本土宗教「母道教」（Đạo Mẫu）中的第二位聖母——掌管山林、樹木、野生動物與草藥。在四府（Tứ Phủ，天－地－山－水）宇宙結構中，母上巒掌管「山府」（Nhạc Phủ），地位僅次於掌管天界的母上璽（Mẫu Thượng Thiên）。她的信徒遍及越南北部山地與中部的長山山脈——採藥人、獵人、伐木者與草藥商皆以她為守護神。

母道教起源於越南北部的民間信仰，融合了佛教、道教與本土靈媒崇拜（Lên Đồng）。母上巒的崇拜中心在富壽省、太原省與諒山省的丘陵地帶。她的聖地通常位於古老的大樹（尤其是榕樹與無花果樹）之下或被認為有靈氣的山洞之中。逢每月初一與十五，信徒在樹下的聖壇獻上檳榔、清水與鮮花。

## 神話事蹟

### 山林的創造與守護

據口傳傳統，宇宙形成之初天地已分、海洋已定，但山林仍是一片混沌。母上巒從天界降下，以她的綠色長袍覆蓋大地——長袍的每一絲纖維化為一座山脈，袍上的繡花化為森林、溪流與洞穴。她呼出的氣息變成薄霧與雲海；她的腳步踩出河谷。從此越南的「Sơn Hà」（山河）有了形狀。

### 草藥與治癒

母上巒被視為越南傳統醫藥的起源之神。傳說她下山走入人間時，發現人類疾病纏身卻無藥可治。她以手杖輕觸每一棵植物——觸到的植物變為藥草（如肉桂、生薑、金銀花、黃連），未觸到的則為無用之草。她教授山民辨識藥草與製作藥方。直到今日，越南的草藥商在進山採藥前必須先向母上巒祈禱，否則相信將空手而歸。

### 獵人與動物的仲裁者

母上巒在神話中同時是獵人與動物的保護者。她規定：獵人不得在繁殖季節狩獵、不得獵殺懷孕的母獸、不得一次獵取超過所需的數量。違者將在林中迷路或被野獸攻擊。此規定反映越南山地民族的可持續狩獵倫理——母上巒被視為生態平衡的維護者。

## 跨文化對應

| 文化 | 神祇 | 相似點 |
|------|------|--------|
| 希臘 | 阿緹蜜絲（Artemis） | 狩獵女神、山林主宰、野生動物保護者 |
| 羅馬 | 狄安娜（Diana） | 森林與狩獵女神，少女守護者 |
| 凱爾特 | 阿爾迪奧娜（Arduinna） | 阿登森林女神，常騎牡鹿 |
| 印度 | 波羅筏底（Parvati） | 山神之女，喜瑪拉雅的女兒 |
| 日本 | 木花開耶姬（Konohanasakuya-hime） | 富士山神，櫻花與山林的守護者 |
| 安地斯 | 帕查瑪瑪（Pachamama） | 大地之母，山脈的守護者 |
| 中國 | 后土娘娘（Houtu） | 地母，但側重大地而非山林 |

## 相關神祇
