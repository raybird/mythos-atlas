# 聖伊羅科樹的傳說 (Itàn Igbo Iroko)

- **文化：** 約魯巴神話 (Yoruba Mythology)

## 故事背景

在約魯巴神話中，伊羅科樹（Iroko，學名 *Milicia excelsa*）不僅是西非最雄偉的樹木之一，更是一位活著的奧里沙（Orisha）。伊羅科樹在約魯巴文化中被稱為「樹王」——其高度可達四十公尺，樹幹直徑可達兩公尺，壽命長達數百年。在尼日利亞約魯巴蘭（Yorubaland）的村落中，每一棵巨大的伊羅科樹都被視為神聖不可侵犯的存在，村民會在其根部擺放供品，包括棕櫚酒、白布與 Kola nut。

這個故事起源於古老的伊費王國（Kingdom of Ifẹ）時期，講述了伊羅科樹如何從一個凡人變成奧里沙的過程，同時揭示了約魯巴文化中「樹木崇拜」的深層宇宙觀——萬物皆有靈（ẹ̀mí），尤其是那些見證了數百年滄桑的巨樹，它們是大地母親（Ilẹ̀）的脊骨。

## 情節

**第一幕——阿耶的詛咒：** 很久以前，在伊費城郊有一個名叫阿耶（Aiyé）的年輕獵人。阿耶是尚戈（Ṣàngó）的後裔，性格如雷暴般暴烈，又好酒貪杯。他的妻子歐蘭米（Ọlánremi）溫柔賢淑，為他生了三個孩子。然而阿耶長年在外打獵，將妻兒獨留在家中。

某日，阿耶在叢林深處遇見了一位名叫阿耶洛米（Aiyélomì）的年輕女子。阿耶洛米並非凡人，而是森林之神奥森（Òṣun）的女兒——雖然她表面上看似人類，但她的眼睛在月光下會泛出金色光芒。阿耶被她的美貌迷住，將她帶回家中，宣布要納她為第二位妻子。歐蘭米雖然心碎，但按照約魯巴習俗沒有反對。

阿耶洛米進入家庭後，詭異的事情開始發生。每逢滿月之夜，她的皮膚會變得如樹皮般粗糙，頭髮會生出綠色的葉芽。阿耶起初以為是錯覺，直到有一天他醒來，發現阿耶洛米已經消失了——她的位置上只有一棵幼小的樹苗，有著人類形態的樹幹和兩條像手臂般伸展的枝椏。

阿耶驚恐萬分，想要砍倒這棵樹。但當他的斧頭觸及樹幹時，樹皮發出了女人的哭聲。歐蘭米聽見哭聲後趕來，立刻認出這是森林之神對阿耶不忠的懲罰。她跪在樹前說：「妳是我們家的一部分。我會在妳的樹蔭下撫養我們的孩子。」

**第二幕——樹的成長：** 歲月流逝，阿耶在悔恨中老去，而那棵樹卻越長越大。它的樹根深入地下，連通了人間（Ayé）與天界之城（Ọ̀run）之間的通道。據說，每當月圓之夜，阿耶的靈魂會爬上這棵樹，前往天界探望已故的祖先。而樹本身也發展出了自己的神格——它開始保護經過其樹蔭下的旅人，驅散叢林中的邪靈，並為產婦遮蔭以確保順產。

到了第四代，這棵樹已經長成了伊費方圓百里內最巨大的伊羅科樹。村民們在它的根部建起了祭壇，稱之為「Igbo Iroko」——伊羅科之林。任何在伊羅科樹下許下的誓言都具有約束力；背叛誓言者會遭到樹靈的懲罰——輕則頭痛三日，重則迷失在叢林中再也找不到回家的路。

**第三幕——伊羅科樹成為奧里沙：** 當伊費的阿拉費（Aláàfin，國王）需要重建被暴風摧毀的王宮大殿時，所有建築師都指出：世界上只有一棵足夠巨大的樹木能作為中央支撐柱——那就是伊羅科樹。國王派出百名勇士前往叢林，欲砍伐這棵巨樹。然而，當第一斧落下時，大地震動，河水倒流，叢林中響起了一個深沉如低音鼓般的聲音：「我已在此守護了四百年。我的根是祖先的道路，我的枝葉是子孫的庇護。你們可以取我倒下後的木材，但我倒下後將不再屬於凡人——我將成為奧里沙。」

勇士們將此事回報國王。阿拉費親自前往伊羅科樹前，以棕櫚酒與 Kola nut 祭祀，祈求樹靈的同意。當夜，阿拉費做了一個夢：夢中，伊羅科樹化為一位身材高大、披著深綠色長袍的奧里沙，他對國王說：「你不需要砍倒我。你只需在夢中取走我的一根枝椏，它在人間便會成為一根完美的棟樑。」

翌日清晨，國王在祭壇旁發現了一根粗壯的伊羅科木材——完美無瑕，無需任何加工。伊羅科樹本身依然矗立，枝繁葉茂。從此，伊羅科樹被正式確認為奧里沙之一，成為建築保護神、叢林守護者與天人溝通的中介。約魯巴人至今在建造房屋時，會在選定的木材上潑灑棕櫚酒，以安撫伊羅科樹靈，確保建築平安無災。

## 跨文化平行

| 文化 | 平行故事 | 對應元素 |
|------|----------|----------|
| 北歐神話 | 世界樹 Yggdrasil | 巨型樹木作為天人溝通的中介軸心 |
| 凱爾特神話 | Bile 聖木 | 愛爾蘭與高盧的凱爾特部落以特定樹木作為社群守護靈 |
| 希臘神話 | 德墨忒爾與聖橡樹 | 聖樹作為豐饒與季節循環的象徵 |
| 中國神話 | 建木 / 扶桑 | 昆侖山頂的巨樹作為天地之間的通道 |
| 日本神話 | 御神木（神社神木） | 古老巨樹被繩飾標記為神聖，不可砍伐 |
| 印度教 | 榕樹（Banyan）神聖性 | 榕樹被視為毗濕奴的化身，是修行者冥想的聖所 |
