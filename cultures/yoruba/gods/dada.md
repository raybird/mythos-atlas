# 達達 (Dada)

- **文化：** 約魯巴神話 (Yoruba Mythology)
- **職掌：** 兒童、胎兒、植物生長、蔬菜、豐饒
- **象徵：** 棕櫚葉、白色棉布、芋頭、青蔬
- **顏色：** 白、綠
- **聖日：** 與 Ibeji 共享節日

## 概述

達達（Dada，亦稱 Dada-Agbaya 或 Dada-Olokunrin）是約魯巴萬神殿中掌管兒童、胎兒與植物生長的奧里沙。在約魯巴語中，「Dada」一詞同時指涉「頭髮濃密捲曲的孩子」和「蔬菜的嫩葉」——這個語義雙關精準地表達了達達的神格核心：祂既是兒童的保護者，也是植物萌芽生長的力量。達達與雙生神 Ibeji 關係密切——Ibeji 保護雙胞胎，達達則保佑所有兒童順利成長。

達達常被描繪為頭戴棕櫚嫩葉環冠的年輕女子，手持一串象徵生命延續的白色貝殼。在約魯巴傳統中，新生兒出生後第七天會舉行命名儀式（Ikosewai）——達達在該儀式中被祈求保佑嬰兒的靈魂剛硬、抵抗疾病。據 Ifá 經文記載，Olodumare 在創造人類後即派遣達達降臨人間，囑咐祂「守護那些尚未能言語的生命」。

## 神話事蹟

### 達達與 Ibeji 的約定

傳說達達與 Ibeji 原為孿生姊妹——二人同時從 Oshun 的子宮中誕生。Olodumare 分配任務時，Ibeji 負責守護雙胞胎，達達則被賦予保護所有兒童——無論是尚未出生的胎兒還是已經能夠行走的幼童。達達與 Ibeji 約定：每當一個孩子健康地度過童年，她們便會在冥界的記錄冊上畫一道線——這些線條最終將化為該人命運之布（Aso-Ori）上的紋路。

### 棕櫚葉的神蹟

在一次大旱災中，約魯巴地的兒童開始因飢餓而虛弱。達達摘下自己的棕櫚葉頭冠種入土中——瞬間長出了茂盛的芋頭、山藥與蔬菜。達達教導婦女如何採集這些植物餵養兒童，並警告：「這些蔬菜只可餵給尚未成年的孩子——成年人若食之，將永遠失去理解兒童純真的能力。」從此，芋頭與棕櫚嫩葉成為約魯巴兒童斷奶後最早接觸的固體食物，代代相傳。

### 兒童的守門者

在約魯巴宇宙觀中，達達站立於人間與冥界（Orun-Apadi）之間的關口。當一個胎兒即將降生時，達達會從 Akashic 記錄中讀取其命運，並在嬰兒的頭頂留下名為「Dada 印記」的胎記——據信這是兒童與祂之間的契約標誌。若兒童在成長過程中受到虐待或忽視，達達將以枯萎的植物或無法解釋的兒童疾病作為警示。

## 跨文化對應

- **希臘阿緹蜜絲（Artemis）**：兒童與分娩的保護女神——但阿緹蜜絲側重於分娩過程，達達則貫穿兒童的整個成長階段
- **中國送子娘娘**：賜予子嗣並保護兒童的神祇——與達達的護童職能精確對應，但送子娘娘更側重於「求子」而非「育兒」
- **印度鬼母（Hariti）**：原是食子夜叉，後被佛陀感化為兒童守護神——與達達一樣關注兒童的滋養與成長
- **埃及貝斯（Bes）**：家庭與兒童的矮人保護神——與達達同樣是非主流萬神殿但在日常崇拜中極受歡迎
- **日本菅原道真（學問之神）**：雖職掌不同，但菅原信仰中的「孩子守護」面向與達達類似

## 相關神祇

- Ibeji（雙生神）：達達的姊妹，共同構成約魯巴對兒童的雙重保護
- Oshun（愛與河）：達達的母親，賦予達達溫柔與養育的特質
- Obatala（造人神）：達達的上級——Obatala 以黏土造人，達達則確保成品健康存活
- Iku（死神）：達達的對立面——Iku 帶走生命，達達守護生命
