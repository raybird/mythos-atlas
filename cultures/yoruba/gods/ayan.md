# 阿揚 (Àyàn / Ayan Agalu / Añá)

- **文化：** 約魯巴神話 (Yoruba Mythology)
- **職掌：** 鼓樂、節奏、音樂之神，鼓樂師的始祖
- **象徵：** Bata 鼓、Gudugudu 鼓、鼓槌、會說話的木頭 (Asoro Igi)
- **顏色：** 棕色與白色
- **其他名號：** Ayan Agalu，古巴 Santería 中稱為 Añá

## 概述

阿揚（Àyàn），全名 Ayan Agalu，是約魯巴萬神殿中掌管鼓樂、節奏與神聖音樂的奧里沙。與其他主要奧里沙不同，阿揚並非以擬人化的形象廣泛出現在大眾神話中，而是作為「木頭的靈」存在於每一顆神聖的 Bata 鼓中。他被視為所有傳統約魯巴鼓樂師（也稱為 Ayan）的共同祖先——鼓師在演奏時不僅是在召喚眾神，更是讓阿揚透過自己的雙手說話。

在古巴 Santería 傳統中，阿揚被稱為 Añá，地位極其崇高：Bata 鼓必須經過 Añá 的「入靈」儀式才能真正成為神聖樂器，否則只是普通的木頭。鼓師在擊鼓時與阿揚合而為一——所謂「鼓師在動作中成為阿揚」。

## 神話事蹟

阿揚的神話並未像 Ogun、Shango 那樣有完整的敘事史詩，取而代之的是關於他起源的口傳片段與儀式知識。最核心的故事是：在眾神創造世界之時，Olodumare 注意到靈界與人間之間缺乏溝通的橋樑——人類的祈禱難以傳達上天，眾神的召喚也無法降臨人間。於是 Olodumare 命令 Orunmila 尋覓一種能穿越層界而不失真義的媒介。Orunmila 發現森林中的阿揚樹（Ayan tree）擁有獨特的木質共鳴——它能承載語言的音調與節奏而不失真。

Orunmila 切割第一顆阿揚樹木，製成了世界上第一對 Bata 鼓——稱為 Iyá「母親」（大鼓）與 Omole「孩子」（小鼓）。當鼓手首次擊打時，節奏穿越了 Orun（天界）、Ayé（人間）與 Ukhu Orun（深海），三界同時震動。Olodumare 於是任命阿揚——棲息在木頭中的神靈——為眾神的「發聲之木」，從此所有奧里沙都必須透過阿揚才能被人類完整聽見。

另一則口傳提到 Shango 的自然與阿揚樹有關：傳說 Shango 自縊的樹正是阿揚樹；他的死亡使神聖音樂與雷電的力量在樹中結合。因此每次 Bata 鼓為 Shango 擊奏時，鼓聲中都有雷鳴般的共鳴。

## 跨文化對應

| 文化 | 對應神祇 | 比較要點 |
|------|---------|---------|
| 印度 | 那達·梵天 (Nada Brahma) | 「聲即梵」——宇宙以振動創生，與阿揚的「木頭說話」概念平行 |
| 希臘 | 奧菲斯 (Orpheus) | 以音樂感動冥界與眾神，阿揚則讓眾神透過節奏降臨 |
| 中國 | 伶倫 | 黃帝樂官，取竹製笛以定音律，與阿揚取木製鼓的起源神話呼應 |
| 日本 | 天鈿女命 (Ame-no-Uzume) | 以舞蹈與鼓聲喚回天照大神，鼓樂作為溝通神人的媒介 |
| 芬蘭 | 萬奈摩寧 (Väinämöinen) | 康特勒琴（Kantele）的發明者，樂器由神木製成，自發演奏 |
| 塞內岡比亞 | 格里奧 (Jeli/Griot) | 西非吟遊詩人，以 Kora 琴承載口傳歷史，與 Ayan 鼓樂的傳承功能相似 |

## 相關神祇

- **尚戈 (Shango)**：雷神，Bata 鼓最常為他擊奏，雙頭斧與鼓構成其王權與力量的雙重象徵
- **奧貢 (Ogun)**：鐵神，鼓的鐵環與金屬部件受他的領域管轄
- **埃蘇 (Eshu)**：十字路口之神，鼓的節奏變化必須先向他致敬
- **奧順 (Oshun)**：河流女神，她的銅鈴節奏與鼓聲互補
- **奧倫米拉 (Orunmila)**：Ifá 占卜之神，指示何時擊鼓召喚特定奧里沙
