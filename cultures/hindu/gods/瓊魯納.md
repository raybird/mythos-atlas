# 瓊魯納（Varuna）— 宇宙秩序之主、海洋之神

- **文化：** 印度神話（Hindu Mythology）
- **職掌：** 宇宙秩序（Rta）、海洋、天界水流、誓約、道德律
- **聖地：** 印度各地沿海聖地、瓦拉納西（Varanasi，其名可能源於 Varuna）
- **象徵：** 絞索（pāśa）、海洋、天界戰車、千眼（洞察一切）

## 概述

瓊魯納（梵語：वरुण，Varuṇa）是印度神話中最古老的神祇之一，在《梨俱吠陀》（Rigveda）時期曾是與因陀羅（Indra）並列的至高神，被稱為「宇宙之王」（Rājā）與「Rta 的守護者」。Rta 是吠陀宇宙觀的核心概念——宇宙的內在秩序、真理與法則的統一體。瓊魯納是這一秩序的最高執行者，他以「絞索」（pāśa）束縛違背真理者，以千眼洞察一切隱蔽之罪。

隨著印度神話的演變，瓊魯納的至高地位逐漸被毗濕奴與濕婆所取代。在往世書與史詩時期，他主要被視為海洋之神與水界統治者，但其作為道德律守護者的原始特徵仍深刻影響了印度法律與倫理傳統。在佛教與印度教交織的傳統中，瓊魯納被吸納為四大天王之一——西方廣目天王（Virūpākṣa），守護增長天界的海洋與財富。

## 神話與事蹟

### 吠陀時期的至高法官

《梨俱吠陀》（Rigveda 7.86）記載了最著名的瓊魯納頌歌——一位凡人向瓊魯納懺悔自己的罪行。這位凡人（可能是一位祭司或國王）向瓊魯納傾訴他的恐懼：「我害怕自己犯了什麼隱蔽的罪，瓊魯納啊，請以你的恩慈寬恕我。」瓊魯納回應說，他不會讓懺悔者死亡，但他必須承擔自己的業報——就像兒子承擔父親的罪一樣。

這段對話揭示了瓊魯納的雙重角色：他既是寬恕者也是審判者。他不會直接免除罪行的後果，但他會給予懺悔者一條贖罪的道路。這與後來印度教中的「懺悔儀式」（prāyaścitta）有直接的關聯——瓊魯納是所有道德贖罪制度的神話原型。

### 因陀羅與瓊魯納的權力轉移

在吠陀時期，因陀羅與瓊魯納的關係充滿張力。因陀羅是戰士階級的守護神，代表勇氣與武力；瓊魯納是祭司階級的守護神，代表秩序與道德。隨著雅利安人從游牧轉向定居農業社會，因陀羅的軍事崇拜逐漸讓位於瓊魯納的法律崇拜——定居社會更需要秩序與穩定，而非戰爭英雄。

在《梨俱吠陀》中，因陀羅與瓊魯納有時被並列為「雙神」（dvau），共同統治天界。但在後來的文獻中，因陀羅逐漸吸收了瓊魯納的許多特徵，包括 Rta 的守護角色。這一轉變反映了印度社會從祭司主導（Brahmin）向武士主導（Kṣatriya）的社會結構變化。

### 海洋之主

在史詩與往世書時期，瓊魯納的主要職能轉變為海洋之主。在《摩訶婆羅多》（Mahābhārata, Ādi Parva）中，瓊魯納被描繪為統治地下海洋世界的國王，他的宮殿由寶石與珊瑚構成，無數海洋生物在其中游弋。他同時也是「水的監督者」——不僅包括海洋，還包括雲層中的水蒸氣、地下的水源以及人體中的體液。

在《羅摩衍那》中，羅摩在渡海前往楞伽之前，需向瓊魯納祈求安全通行。瓊魯納最終允許哈努曼與猴軍渡海，並警告羅摩不要輕視海洋的力量。這一情節確立了瓊魯納作為「海洋邊界守護者」的角色——人類必須尊重自然的力量，而非試圖征服它。

### 誓約與偽證的的懲罰

瓊魯納是所有誓約（samaya）的守護者。在吠陀法律傳統中，偽證者被稱為「瓊魯納的敵人」。《梨俱吠陀》記載，瓊魯納以絞索束縛那些違背誓言的人，這條絞索不是物理繩索，而是業力的束縛——說謊者將永遠被自己的罪行追隨。

這一特徵使瓊魯納成為印度法學傳統（Dharmaśāstra）的神話源頭。《摩奴法典》（Manusmṛti）中對偽證與契約的嚴格規定，可以追溯到瓊魯納作為「宇宙法官」的原型。

## 跨文化對應

| 印度瓊魯納 | 對應角色 | 文化 |
|------------|---------|------|
| 宇宙秩序（Rta）的守護者 | 宙斯（Zeus）——正義與誓約之神 | 希臘 |
| 絞索束縛罪人 | 阿努比斯（Anubis）——以天秤稱量心臟 | 埃及 |
| 海洋之主 | 波賽頓（Poseidon）——海洋之神 | 希臘 |
| 天界水流與降雨 | 因陀羅（Indra）——雨水與戰爭之神 | 印度（吠陀） |
| 道德律的神聖執行者 | 瑪亞特（Ma'at）——真理、正義與宇宙秩序的化身 | 埃及 |
| 以天眼洞察隱蔽之罪 | 千眼觀音——洞察一切苦難的慈悲之眼 | 中國佛教 |
| 誓約守護者 | 洛基（Loki）——以諾恩（Norns）之名違背誓約的對立面 | 北歐 |

## 相關神祇

- **Mitra**（密多羅，瓊魯納的雙生兄弟，契約與友誼之神）
- **Indra**（因陀羅，與瓊魯納共同分享 Rta 守護者角色的雷神）
- **Brahmā**（梵天，在後期文獻中部分取代了瓊魯納的 Rta 守護角色）
- **Nāga**（那伽，海洋中的蛇神，瓊魯納的僕從）
- **Uṣas**（烏莎斯，黎明女神，與瓊魯納共同象徵光明驅散黑暗）
