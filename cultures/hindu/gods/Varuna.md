# 伐樓拿 (Varuna) — 吠陀宇宙秩序與水域之神

- **文化：** 印度神話 (Hindu Mythology)
- **職掌：** 宇宙秩序（Ṛta／梨多）的守護者、海洋與天界之水、誓約與法、懲戒之索（Pāśa）

## 概述

伐樓拿（Varuna，天城文 वरुण）是《梨俱吠陀》中最崇高的神祇之一，其名字源於印歐語根 \*wer-（「束縛、環繞」），字義近於「束縛者」——祂與希臘天穹之神烏拉諾斯（Ouranos）被語言學界視為同一語根的遠親。在吠陀萬神殿中，祂與蜜多羅（Mitra）成對出現，合稱「蜜多羅—伐樓拿」（Mitra-Varuna），共同執掌誓言與契約；蜜多羅掌管白晝與人間之約，伐樓拿則掌管夜晚、天界之水與隱秘的審判。《梨俱吠陀》中超過八十首頌歌提及伐樓拿，專屬頌歌如 1.25、2.28、7.86–7.89、8.41–8.42 皆以祂為中心，數量僅次於因陀羅與阿耆尼。

作為梨多（Ṛta，宇宙秩序）的守護者，伐樓拿不以刀劍而以「法則」統治世界：河流按祂的律令流淌，日月按祂的軌道運行，眾生的一言一行都在祂「千目」的注視之下。祂以太陽為眼睛，並派遣無數窺探者（spaśas）潛行人間，凡違背誓約、欺瞞作惡者，終將被祂的套索（pāśa）綑縛。祂同時是四大方位守護神（Lokapāla）之一，鎮守西方。後吠陀時期，伐樓拿的宇宙秩序職能逐漸被濕婆與毗濕奴體系吸收，祂遂轉化為海洋之神，在《摩訶婆羅多》與《往世書》中統治深海與眾水——如同希臘的波塞頓從震地者轉為海神一般。

## 神話事蹟

**釋放河流：** 《梨俱吠陀》2.28 頌歌中，伐樓拿被稱為「河流之主」——祂以自己的律令開闢河床、蓄水成海，並使天雨降於大地。與因陀羅以金剛杵劈山釋放七河不同，伐樓拿的治水全憑秩序本身：祂不需武器，只須「法則」即可令自然運轉。此一形象使祂成為吠陀宇宙論中「規律性」的化身。

**千目審判與贖罪：** 伐樓拿是吠陀文獻中最早的道德審判者之一。頌歌中詩人反覆向祂懺悔：「我是否觸犯了誓約？」（RV 7.86），並請求以贖罪祭脫離祂的索縛。據傳聖者婆斯西塔（Vasishtha）曾得罪伐樓拿，被索綑縛入水，後以懺悔與犧牲求得解脫——此敘事被視為印度倫理思想中「罪—贖」結構的最早文獻。

**與蜜多羅的契約守護：** 在吠陀雙神框架中，蜜多羅見證人間契約與友誼，伐樓拿則處罰背誓者。兩者合體神「蜜多羅—伐樓拿」手持權杖與套索，驅車巡行天界，是古代印歐「誓約神」的典型型態，與祆教密特拉（Mithra）、赫梯密特拉（Mitra，見於波加茲科伊碑文）同源——吠陀時期之契約神在此獲得整片印伊語系脈絡。

## 跨文化對應

| 印度伐樓拿 | 對應神祇 | 文化 |
|---|---|---|
| 海洋與水域之主 | Poseidon 波塞頓／Neptune 涅普頓 | 希臘／羅馬 |
| 深淵淡水與秩序（Me） | Enki 恩基／Ea | 美索不達米亞 |
| 誓約與契約之神 | Mithra 密特拉 | 祆教／赫梯 |
| 宇宙秩序（Ṛta）守護 | Ma'at 瑪亞特（真理／秩序） | 埃及 |
| 道德審判與千目 | 天眼與因果的無形監察 | 中國「天」／道教監察神 |
| 索縛懲戒之套索 | Mizu ／ 北歐海神 Aegir | 日本／北歐 |

其中最關鍵的對應是「秩序」層面：伐樓拿的梨多（Ṛta）與埃及瑪亞特（Ma'at）、祆教阿沙（Asha）、希臘戴基（Dikē）共享「使宇宙運轉的內在法則」之義，而海洋或水域只是祂職掌的外在象徵之一。與純然的風暴雷神因陀羅相比，伐樓拿更接近一位「律法神」——這使祂在吠陀文明中擁有比戰鬥神更古樸、更哲學的性格。

## 相關神祇

- **蜜多羅（Mitra）：** 成對的契約神，白晝與人間之約的見證者
- **阿迭底（Aditi）：** 母親，無限之母，阿迭底耶諸神之源
- **因陀羅（Indra）：** 同為吠陀主神，以武力維持秩序，與伐樓拿形成「力」與「法」的互補
- **阿耆尼（Agni）：** 火神兼祭火媒介，將人間祈願傳達給伐樓拿
- **弗栗多（Vritra）：** 混沌旱魔，因陀羅的宿敵，亦被伐樓拿的秩序對立
- **迦葉波（Kashyapa）：** 神話中的父親，眾神與眾生之祖

## 出現在

- 《梨俱吠陀》專屬頌歌（RV 1.25、2.28、7.86–7.89、8.41–8.42）與多達八十餘首的提及
- 《阿闥婆吠陀》與《梵書》中的宇宙秩序論述
- 《摩訶婆羅多》與《毗濕奴往世書》中轉型為海洋之神與西方守護神
- 印度天文體系：水星之月宿系統與西方方位神祭祀儀式
