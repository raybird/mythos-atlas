# 烏莎斯（Uṣas）— 黎明女神

- **文化：** 印度神話 (Hindu Mythology)
- **職掌：** 黎明、破曉之光、覺醒、青春與財富
- **聖地：** 無專屬神廟；以《梨俱吠陀》頌詩為其主要崇拜場域
- **象徵：** 金紅曙光、牛拉繡彩車、驅散黑暗的金杖、不衰老的少女

## 概述

烏莎斯（梵語：उषस्，Uṣas）是印度神話中執掌黎明的女神，其名在印歐語系中可追溯至原始印歐語 *h₂éusōs*「破曉者」——與希臘的厄俄斯（Eos）、羅馬的奧羅拉（Aurora）、波羅的海的奧什琳涅（Aušrinė）同源，是語言學上最能證明「黎明女神」為原始印歐共同神祇的證據之一。《梨俱吠陀》中最多的女神頌詩即獻給烏莎斯：約二十篇完整的黎明頌誦（RV 1.48、1.92、3.61、4.52、6.64、7.75–82 等）由開篇便面向東方晨光，使烏莎斯成為吠陀詩人心目中最富情感與詩意的神格。

烏莎斯的身世被描述為「太陽蘇利耶之女、天的女兒」（divo duhitar）——她是天空之神（Dyaus）之女，夜晚女神拉特麗（Rātrī）之妹，與太陽神蘇利耶（Sūrya）扮演著晨昏交接的宇宙伴侶。她的形象是「永不衰老的少女」：每天清晨重新穿上金紅的衣袍、乘著鑲繡的彩車或牛車，以燦光「開啟天庭之門」，驅散黑夜，喚醒眾生萬物。詩人讚她「如少女微笑般降臨」「以金色光輝吻醒大地」——她把昨夜的黑暗化為新生的白晝，是時間循環中重複的奇蹟。

## 神話事蹟

**開啟天門與驅散黑暗：** 烏莎斯最核心的動作是「開門」。吠陀頌詩（RV 1.113、7.75–81）反覆描寫她「登上天庭之門」「揭示東方之福」，以不可抗拒的亮光驅離那片妨礙道路的幽暗。她的光芒「如同要衝破雲層的牛群」，率先於太陽出場，為太陽掃清路徑——因此她是「太陽的先導」「喚醒太陽的母親與新娘」。此「先於日出的女性光輝」在宇宙論上被詮釋為：幽暗的長夜因她而開裂，晝與夜、秩序與混沌在破曉那一刻被重新裁決。

**喚醒眾生與助人起身：** 頌詩以溫柔的祈願請求烏莎斯「喚醒我們」——無論是人類、飛鳥還是走獸，都在她的晨光中重獲活動。詩人並向她祈求財富、後代、長壽與「蘇摩的喜悅」，因為烏莎斯被認為「重啟每日的豐盛」：她是黎明的施予者，把把昨天失去的能量重新歸還給世界。RV 10.127 的姊妹篇〈夜頌〉則從反面定義她——夜晚女神拉特麗關閉白晝之門，直到烏莎斯再次降臨，兩篇對讀構成完整的晝夜循環神話。

**與太陽、人類的青春契約：** 烏莎斯以「遍眼中晨曦」注視著人類的勞動，詩人以她為見證，立誓每日清晨敬奉眾神（RV 7.80）。她也是「不衰老之神」——每天都以處女之身重臨，卻又象徵「每一天的消逝」：頌詩中不無感歎，烏莎斯日日迎向死亡般的夜晚，卻從不真正死去。這使她兼具「青春的喜悅」與「時間流逝的憂傷」兩種情感色調，與希臘厄俄斯為凡人愛人而流的晨露之淚遙相呼應。

**迷戀太陽蘇利耶：** RV 10.189 等頌詩暗示烏莎斯與太陽蘇利耶之間的追逐與結合——黎明追逐著太陽、卻永遠被太陽照亮，構成「光之女神戀慕光之神」的循環運動，也解釋了為何部分頌詩稱蘇利耶為烏莎斯的丈夫、烏莎斯為「太陽之母」：在時間的分界線上，兩者互為母親與愛人。此一悖論式關係（Pārvati/Shakti 教義中的「神與其光輝不分離」）成為後世吠檀多哲學「現象與本體」的象徵藍本。

## 跨文化對應

| 文化 | 對應神祇 | 共鳴點 |
|------|---------|--------|
| 希臘 | 厄俄斯（Eos） | 印歐同源黎明女神，駕金車、開啟晨門、為凡人流下晨露之淚 |
| 羅馬 | 奧羅拉（Aurora） | 拉丁化的黎明女神，繼承「玫瑰指／金紅袍」母題 |
| 波羅的海 | 奧什琳涅（Aušrinė） | *h₂éusōs*同源詞，燃紅袍染晨空，兼晨星與黎明身分 |
| 斯拉夫 | 佐莉亞（Zorya） | 星辰黎明姊妹，開啟天門、抵禦黑暗 |
| 芬蘭-烏戈爾 | 佩伊瓦塔爾（Päivätär） | 黎明織者，以金線織出曙光——與印歐系統的功能平行 |
| 中國 | 羲和（日御） | 御太陽而行、晨昏循環的權柄——東方「光之秩序」的對照 |
