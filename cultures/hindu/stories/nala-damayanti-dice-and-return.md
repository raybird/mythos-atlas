# 入身的惡魔與翻本的骰子：那羅與達摩衍蒂的失國與復國

- **文化：** 印度神話（Hindu Epic Mythology）
- **來源：** 《摩訶婆羅多》森林篇「那羅傳」（Mahābhārata, Vana Parva, Nalopākhyāna，口傳層積至成書數世紀）；民間口傳與後世轉述

## 故事背景

這是《摩訶婆羅多》裡一則「故事中的故事」：般度長子堅戰（Yudhiṣṭhira）在骰局中被詐去王國、攜兄弟流亡森林，陷入絕望。此時仙人布利哈達什瓦（Bṛhadaśva）來到林中，給他開了一劑藥——講述古代尼沙陀國（Niṣadha）君王那羅（Nala）的故事：一位同樣被骰子奪走一切的王，如何在妻子達摩衍蒂（Damayantī）的忠誠與自身技藝的轉化中，把輸掉的國度一擲贏回。「你今天失去的，曾有人以更荒謬的方式失去、又以更完整的方式奪回。」這個把故事當處方開的框架，本身就是印度敘事傳統最動人的發明之一：史詩不只是記錄苦難，而是為正在受苦的人預先準備的解藥。

## 情節

### 第一幕：天鵝傳書與百選一的擇婿

那羅英武、賢德、善御馬車；維達爾跋（Vidarbha）公主達摩衍蒂傾國之美，卻在見到那羅之前就愛上了他——一隻被她放生的天鵝飛到尼沙陀，見過那羅的風采，回來對她日復一日地稱述：「世間有一人，半神不及。」長相思的公主舉行選婿大典（svayaṃvara）。因陀羅、阿耆尼、伐由、閻摩四天神聞名下凡，卻不願空手而歸，各自幻化成與那羅一模一樣的形貌——大典現場出現五個無法分辨的「那羅」。達摩衍蒂合掌祈告：她心中的愛原是為了凡人那羅。天神們現出原形，並留下只有神才會露出的破綻：足不沾塵、無影、花環不謝、不眨眼。她把花環戴上凡人那羅的頸項。四神大喜反賜重恩：祭祀他們者必得所願，閻摩更授那羅一項奇技——凡他親手烹調的食物，必含德性之味。這口「飯香」將在故事最黑暗處成為認親的鑰匙。

### 第二幕：十二年的縫隙與入身的惡魔

選婿大典漏請了一位客人：惡神迦利（Kali，墮落時代的化身）。他目睹凡人擊敗四天神贏得公主，恨極發誓要入那羅之身。但他不動手——他等待。這一等是十二年：那羅的虔敬滴水不漏，迦利只能守在他的肩後找縫隙。終於，那羅有一次如廁後未行淨足之禮便逕自禱告。一道縫隙，迦利鑽入其身。被附身的那羅應弟弟布什卡拉（Puṣkara）之邀赴骰局，不能拒絕、也不知拒絕，一擲再擲，輸盡國庫、都城、產業；僕從散盡，只剩妻子與兒女不離。夫婦帶著孩子入森林，達摩衍蒂把兒女託回外家，堅持隨夫流亡。林中飛鳥設局騙走那羅唯一的外衣；半裸的那羅看著熟睡的妻子，做出全詩最受爭議的決定：衣衫襤褸的他只會拖垮她——他把她的紗麗割下半幅作衣，割下自己的半幅蓋在她身上，轉身離去。他賭她會回到父親宮中獲得庇護。達摩衍蒂醒來，對著森林哭喊詛咒，從此踏上尋夫之路。那羅則被蛇王迦爾柯多卡（Karkoṭaka）咬中——蛇言明：此毒將燒灼你體內的迦利，也將把你毀容成矮臂畸形人「巴胡卡」（Bāhuka），使仇家無法認出你；去阿逾陀城，做盧託帕爾納王（Ṛtuparṇa）的御者與廚師。毒與解藥同體：蛇毒既是刑罰，也是保護，更是驅魔的火。

### 第三幕：廚房裡的氣味與第二次選夫

達摩衍蒂被商隊救起，輾轉回到父親的宮廷。她的父親宣布將為她舉行第二次選婿大典——她暗中另有所圖：這是一場釣餌。她派出婆羅門四處傳話，尋找一位「寄人簷下、以勞役與技藝換食宿」的落難貴人。阿逾陀宮中的巴胡卡聽見了。大典之日，他為盧託帕爾納王御車，以神乎其技的御馬術一日千里趕到；途中還向精於計數與骰藝的王展示：看一眼樹上的枝葉便能報出總數。達摩衍蒂從御者馭馬的身手起疑，繼而宣布：第二次選婿是計，她心中從無第二人。真正的驗證在廚房——巴胡卡下廚，飯香隨蒸汽瀰漫宮殿，那是一種只屬於她丈夫的味道：閻摩所賜、「飯含德性之味」的烹技，氣味不會說謊，臉可以。她闖入廚房相認；他仍不敢應：「你何苦尋一個毀容的矮子、拋下你的丈夫？」她以不變的誓約與兒女作答。蛇毒燒盡，迦利離體，那羅恢復本形——世界文學中最著名的相認場景之一，靠的不是面容，而是一縷飯香。

### 第四幕：一擲定音

那羅借得盧託帕爾納所授的計數骰藝，加上迦利離體時為補償十二年之苦留下的賭術真傳，回到尼沙陀，向布什卡拉下最後一紙戰書：骰局重開。他以其人之道還治其身，押上「傳聞中已另嫁的達摩衍蒂」，一擲贏回王國。但他沒有復仇：赦免弟弟，待以賓禮。他與達摩衍蒂重續國祚。森林裡，堅戰聽完，流淚釋然：骰子可以被反骰，流亡有終點，德性消化得了災難。

### 深層比較

**框架敘事的藥理學。** 那羅傳最特別的地方，是它從一開始就被當作藥物使用：布利哈達什瓦不是史官，是醫者；聽眾不是後世讀者，而是剛剛被骰子毀掉人生的當事人。這與波爱修斯在死囚牢裡寫《哲學的慰藉》同構——自我治療以對話與敘事為劑型。差異在於劑量的方向：波爱修斯以哲學論證壓住命運的眩暈，印度方案則以「同病者的病例史」對症下藥——不講道理，先講一個和你一樣慘、最後贏回來的人。《一千零一夜》把這種藥理推到極致：故事直接是性命的抵押。敘事在此不是娛樂，而是一種古老的臨床技術。

**成癮的惡魔化：迦利只等你破戒。** 迦利是整個世界神話系統裡對「賭癮」最精準的寓言化：他不能創造弱點，只能等待弱點——十二年伏擊，等的是一次如廁後未洗足的儀式性疏漏。入身（possession）把成癮內在化：被附身者「不能拒絕、也不知拒絕」，這正是賭徒對自己行為的經典描述。更精密的是毒與解藥的同體設計：蛇毒燒灼惡魔、也毀容保護、最終驅魔——創傷既是刑罰又是疫苗。對照《約伯記》，約伯的苦難來自全然的「他者」（撒旦與上帝的對話），那羅的苦難卻住進了自己的身體；印度傳統在此比聖經傳統更接近現代成癮醫學的直覺——敵人不在遠方，在肩後，在皮膚之下。

**認出的知識論：氣味不會說謊。** 五個一模一樣的「那羅」、一個毀容後無法辨認的「那羅」——這則故事把自己的全部張力押在「如何確認這個人是我丈夫」上。荷馬的答案是身體的歷史（老乳母認出傷疤、婚床的結構祕密），印度史詩的答案是德性的滲出：閻摩所賜的烹技使那羅做的每一鍋飯都含德性之味，氣味成為不可偽造的身分證。臉可以被天神複製五份，也可以被蛇毒毀掉，但長年德行滲進勞動的痕跡——御馬的手勢、下廚的飯香——無法偽造、也無法抹除。這是一種深刻的敘事知識論：你真正是誰，寫在你的技藝裡，不在你的面容上。

**復國的經濟學：以妻子作注與饒恕的政治。** 最後一擲，那羅押上的是「傳聞中已再嫁的達摩衍蒂」——傳聞即籌碼，名譽即抵押品，而這枚籌碼的真實價值恰恰由她先前一手導演的假選婿大典所支撐：忠誠先被製造成公共事實，才能在賭桌上變現。更值得注意的是結尾的克制：贏回王國的那羅赦免了布什卡拉，待以賓禮。對照勾踐——臥薪嘗膽二十年，滅吳而後快——印度史詩選擇了另一條路：骰局已經證明宿怨可以了結，何必再添一次流血。兄弟相殘在《摩訶婆羅多》主線（俱盧之戰）中血流成河；那羅傳作為主線的鏡像補充，示範了「不開戰的復國」：同一套骰子，可以用來毀滅，也可以用來翻本——差別只在握骰的人是否已被驅魔。
