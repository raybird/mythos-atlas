# 福爾圖娜（Fortuna）— 命運之輪與機運女神

- **文化：** 羅馬神話
- **職掌：** 機運、命運、繁榮、個人與國家的興衰
- **聖日：** 6月11日（Fors Fortuna 節）、6月24日
- **象徵：** 船舵、豐饒角、車輪、球體

## 概述

福爾圖娜（Fortuna）是羅馬宗教中最普遍、最多面向的神祇之一。她的名字源自拉丁語 *fors*（機運），與英語 *fortune* 同源。作為機運與命運的女神，她掌管生命中一切無法以理性預測或人力掌控的部分——戰爭的勝負、商業的盈虧、政治的興衰，乃至個人的健康與婚姻。

與希臘對應神祇堤喀（Tyche）不同，福爾圖娜在羅馬的崇拜更為個人化。她同時關照國家命運與個人日常——她的神廟遍佈全帝國，崇拜者來自社會各階層。她累積了至少96種以上的稱號（epithets），超過任何其他羅馬神祇。

## 稱號與職能

福爾圖娜的稱號之多反映了她掌管的領域之廣：

| 稱號 | 拉丁語 | 職能 |
|------|--------|------|
| 長子福爾圖娜 | Fortuna Primigenia | 守護初生兒的命運，普雷內斯特（Praeneste）的主神 |
| 歸來福爾圖娜 | Fortuna Redux | 保佑旅人平安歸來 |
| 今日福爾圖娜 | Fortuna Huiusce Diei | 掌握當日的轉機 |
| 公眾福爾圖娜 | Fortuna Publica | 羅馬人民的國運 |
| 女性福爾圖娜 | Fortuna Muliebris | 女性的婚姻與美德 |
| 男性福爾圖娜 | Fortuna Virilis | 男性的機運（實際由女性崇拜，祈求丈夫的愛情） |
| 康復福爾圖娜 | Fortuna Conservatrix | 保護者和治好者 |
| 騎士福爾圖娜 | Fortuna Equestris | 騎士階層的守護神 |
| 豐收福爾圖娜 | Fortuna Annonaria | 穀物豐收 |
| 私人之福爾圖娜 | Fortuna Privata | 個人的運氣 |

## 神話與崇拜

### 起源傳說

羅馬人將福爾圖娜的崇拜追溯到王政時代。據李維與普魯塔克記載，第六代國王塞爾維烏斯·圖利烏斯（Servius Tullius）建立了福爾圖娜的首批神廟。一則神話甚至說塞爾維烏斯是福爾圖娜與一位奴隸的私生子——他的崛起本身就是福爾圖娜力量的證明。

### 普雷內斯特的神諭

福爾圖娜最著名的聖所在拉齊奧的普雷內斯特（Praeneste，今帕萊斯特里納）。那裡的福爾圖娜·普里米格尼亞神廟規模宏大，依山而建的梯形結構堪稱古代建築奇蹟。在此處，一名幼童從裝滿橡木籤的容器中抽出一支——每一支上都刻有未來的預言。這是羅馬最著名的「籤卜」（sortes）傳統，來自帝國各地的人們在此詢問未來。

### Fors Fortuna 節

每年6月24日，羅馬人舉行「福爾斯·福爾圖娜節」（Fors Fortuna）。這個節日特別具有人民性——奧維德在《歲時記》中記載，最低階層的奴隸與勞動者乘船順著台伯河而下，到城外的聖所飲酒慶祝、戴著花環划船回城。這種節日的「翻轉」性質與羅馬嚴格的階級社會形成鮮明對比——福爾圖娜的節日是短暫的底層狂歡空間。

### 羅馬人的「馴服」策略

羅馬人對待福爾圖娜的態度極具特色。他們沒有被動接受命運的不可預測性，而是通過賦予她大量稱號來嘗試「馴服」她——將她分解為可控的、特定領域的幸運。普魯塔克記載了一則寓言：福爾圖娜進入羅馬時脫下翅膀、鞋子，扔掉手中球體，宣稱她將永遠定居於此。這則神話的精髓在於：羅馬的成功不是運氣的產物，而是藉由將運氣制度化而戰勝了她。

## 跨文化對應

| 羅馬福爾圖娜 | 對應神祇 | 文化 | 相似處 |
|------------|---------|------|--------|
| 機運女神，船舵與豐饒角 | 堤喀（Tyche） | 希臘 | 城市命運女神，手持冠冕與船舵；幾乎等同的神格 |
| 命運之輪的操控者 | 拉克什米（Lakshmi） | 印度 | 財富與幸運女神，但強調吉運而非命運的翻轉 |
| 個人運氣（Fortuna Privata） | 古布勒（Gbulɛ）／法（Fa） | 西非（約魯巴） | 個人命運由神祇掌握，透過占卜揭示 |
| 機運不可預測性 | 歐爾赫（Wirr） | 日耳曼 | 命運女神的不可逆轉性 |
| 命運之輪 | 摩伊拉（Moirai）三位命運女神 | 希臘 | 命運的紡織與切割；但福爾圖娜是個人化的機運而非命中注定 |
| 豐收福爾圖娜 | 得墨忒耳（Demeter）／刻瑞斯（Ceres） | 希臘／羅馬 | 穀物豐收——福爾圖娜在此重疊於農業女神 |

## 相關神祇

- **Fors**：古早形式的機運之神，與 Fortuna 合稱 Fors Fortuna
- **Spes（希望）**與 **Fides（信義）**：常在銘文中並列出現
- **Genius**：守護個人的靈體，與 Fortuna Privata 概念互補
- **Honos** 與 **Virtus**：榮譽與美德之神——羅馬人認為美德可引導福爾圖娜
