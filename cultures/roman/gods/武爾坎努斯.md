# 武爾坎努斯（Vulcan / Vulcanus）— 火神與鍛造之神

- **文化：** 羅馬神話
- **職掌：** 火、鍛造、火山、工匠技藝、災禍與淨化
- **聖日：** 8月23日（Vulcanalia 節）
- **象徵：** 鐵鎚、砧、鉗、火山（如埃特納山）

## 概述

武爾坎努斯（Vulcanus，又譯伍爾坎）是羅馬的火神與鍛造之神，其名可能與克里特—伊特魯里亞地區的火山崇拜有關——拉丁語 *volcanus* 或 *fulgur*（閃電）可追溯至同一詞根，顯示他在羅馬最早的職掌與「燃燒的火焰」密不可分。他原是義大利半島本土的神祇，與希臘的赫菲斯托斯（Hephaestus）並不相同，但在希臘化時期透過「神祇對應」（Interpretatio Romana）與赫菲斯托斯完全融合，獲得工匠之神的職能，並被納入以朱庇特為首的十二主神之列。

與希臘赫菲斯托斯不同，武爾坎努斯的羅馬面向保留了更多「毀滅性火焰」的原始性格。在義大利古傳統中，他首先是一位**危險的火神**——城邦隨時可能被大火吞沒，武爾坎努斯正是掌控此等災禍力量的神明；直到後來，他才逐漸獲得了「眾神之鐵匠」的溫和形象。老普林尼《自然史》記載，羅馬人相信埃特納火山（Aetna）下的鍛造坊正是武爾坎努斯捶打雷電的工坊，而武爾坎努斯的名字也正是火山（volcano）一詞的語源。

## 神話事蹟

### 眾神的鐵匠與雷電的製造者

羅馬詩人維吉爾在《埃涅阿斯紀》第八卷中描述了最著名的武爾坎努斯神話場景：維納斯請求其夫為埃涅阿斯打造一面神盾，武爾坎努斯於是來到埃特納山下的洞穴工坊，喚醒沉睡的獨眼巨人（Cyclopes），命令他們鍛造未來的羅馬歷史——盾面上預鑄了羅慕路斯與雷穆斯、薩賓婦女搶婚、以及奧古斯都勝利的圖景。這個場景將武爾坎努斯定位為「帝國命運的預言者」：眾神的鐵匠同時是羅馬未來的刻畫者。

據赫西俄德傳統的羅馬化版本，武爾坎努斯是朱諾（Juno）單性生育的產物——朱諾因嫉妒朱庇特生出密涅瓦，遂獨自誕下武爾坎努斯。他天生跛足、容貌醜陋，為天后所嫌棄，被逐出奧林帕斯，墜落於利姆諾斯島（Lemnos）摔斷雙腿，此後便以跛足鐵匠的形象在世間行走。在羅馬神話中，他娶維納斯為妻，但維納斯與戰神瑪爾斯私通，並在武爾坎努斯設計的金網中被當場捉姦——奧維德《變形記》完整記錄了這段「諸神目睹的鬧劇」。

### 毀滅之火與 Vulcanalia 節

武爾坎努斯的羅馬性格仍保留「火災之神」的危險面向。每年8月23日舉行的 Vulcanalia 節，羅馬人會在火神的祭壇（Volcanal）前舉行儀式，將活魚投入火焰作為獻祭——以水中生物代替人類祈求免於火災。此時正值羅馬最炎熱乾燥的季節，穀倉與城市最易失火，此節日因此兼具「平息火神怒氣」與「儲水防火」的實用功能。老普林尼記載，火災被視為武爾坎努斯對城邦的直接懲罰，而李維則記述了火神廟被雷擊焚毀後、羅馬元老院如何舉行贖罪祭的史實——這一細節恰恰反映了羅馬人對火神的敬畏。

### 羅馬城的救火之神與護城功能

武爾坎努斯同時具有「護城」的反向功能。其最古老的聖所 Volcanal 位於羅馬廣場（Forum Romanum）的火山台地之上——傳說中，台伯河畔的石質地形正源於遠古火山活動。羅馬人在此祭祀火神，祈求他守護城市免受烈焰吞噬，使「毀滅者」轉化為「保護者」。這種將破壞性自然力加以「馴化」並納入城邦秩序的思維，是羅馬宗教最具特色的政治神學。

## 跨文化對應

| 羅馬武爾坎努斯 | 跨文化對應 | 對應關係 |
|--------------|-----------|---------|
| 火與鍛造之神 | 希臘赫菲斯托斯（Hephaestus） | 希臘化時期完全融合，等同的神格 |
| 跛足鐵匠，眾神之匠 | 北歐維蘭德（Völundr／Wayland） | 皆為被囚禁並鍛造神器的跛足工匠 |
| 火山與地下烈火 | 日本大山津見神／海神 | 火山與鍛造關聯的地下火神（母題平行） |
| 火災之神兼護城神 | 印度阿耆尼（Agni） | 火兼具毀滅與淨化、祭祀中介的功能 |
| 雷電的打造者 | 中國雷神／蚩尤（冶兵） | 火與兵器、雷電的製造者母題 |
| 眾神之匠（文明工具） | 約魯巴奧貢（Ogun）／凱爾特戈布紐（Goibniu） | 鐵匠神作為文明奠基者的原型 |

## 相關神祇

- **朱庇特（Jupiter）** — 眾神之王，武爾坎努斯為其鍛造雷電
- **朱諾（Juno）** — 單性生育武爾坎努斯之母
- **維納斯（Venus）** — 其妻，與瑪爾斯私通
- **瑪爾斯（Mars）** — 維納斯的情人，戰神
- **密涅瓦（Minerva）** — 朱庇特單性所生的智慧神，與武爾坎努斯同為工藝之神
- **維斯塔（Vesta）** — 灶火女神，與武爾坎努斯同屬「火」之領域
