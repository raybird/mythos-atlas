# 科里奧拉努斯——放逐、復仇與母親的城邦

- **文化：** 古羅馬（Ancient Rome／共和早期傳說）
- **體裁：** 政治傳奇、放逐敘事（exile and return narrative）
- **核心母題：** 英雄被逐、投靠敵人、母親阻止復仇、節制與城邦忠誠
- **主要文獻：** 李維《羅馬史》卷二、普魯塔克《科里奧拉努斯傳》、狄奧尼修斯《羅馬古事記》

## 故事背景

**蓋烏斯·馬爾基烏斯·科里奧拉努斯（Gaius Marcius Coriolanus）**是羅馬共和早期傳說中最具悲劇性的英雄。他的綽號來自十七歲時在科里奧拉（Corioli）戰役中的英勇表現——單身衝入敵城，奪取城門，因而得名「科里奧拉努斯」。他驍勇善戰、蔑視平民，深信貴族榮譽高於一切；這種性格最終使他與羅馬人民決裂。

故事的核心張力在於：**拯救城邦的英雄，為何被城邦親手放逐？** 這正是羅馬傳說最為關心的問題——共和如何理解「過度的英勇」與「節制（temperantia）」之間的界限（參見[辛辛那圖斯的犁與獨裁官](Cincinnatus.md)所樹立的對照典範）。

## 情節

### 一、饑荒與抗爭

羅馬發生嚴重饑荒，貴族囤積糧食，平民要求取消債務奴役並要求執政官讓步。科里奧拉努斯主張強硬鎮壓，公開蔑視平民的訴求，甚至說出「平民如豺狼」之類的話。 他被控煽動內亂，面臨審判。在他缺席時，群眾包圍其宅邸；最終他被判處**終身放逐**，財產充公。

### 二、投靠敵人

被逐後，科里奧拉努斯並未遠走他鄉隱居，而是前往羅馬的宿敵——沃爾西人（Volsci）的城邦，受到國王阿提烏斯·圖盧斯（Attius Tullus）的接待。他巧妙地煽動沃爾西人進攻羅馬，並親自率軍，接連攻陷多座拉丁城鎮，直逼羅馬城下。曾經的共和英雄，如今成為最危险的敌人。

### 三、母親的阻攔

羅馬派出多位使者求和，皆被拒絕。最後，科里奧拉努斯的母親**維圖里婭（Veturia）**與妻子**沃盧姆尼婭（Volumnia）**帶著他的兩個兒子，親赴敵營。維圖里婭站在兒子面前，厲聲質問：如果他攻破羅馬，是否要先踏過母親的屍體？她指著城邦的城牆說：「你曾是這裡的保護者，如今卻要成為它的毀滅者。」科里奧拉努斯崩潰，含淚撤軍。

### 四、結局的多種版本

李維記載他撤軍後不久死于沃爾西人之手（一說被認為背叛而遭私刑）；普魯塔克則記載他活到高齡，在流亡中度過餘生。悲劇作家與後世史家對結局分歧，但核心教訓一致：**他挽救了城邦，卻無法挽救自己**。他既不能回羅馬，也無法真正歸屬於沃爾西，永遠停留在兩個世界之間。

## 跨文化對應

科里奧拉努斯的故事，是「被放逐的英雄」原型的典型：

| 傳統 | 人物／文本 | 放逐原因 | 核心對應 ↔ Coriolanus |
|------|-----------|---------|---------------------|
| 羅馬 | **科里奧拉努斯** | 蔑視平民、被判終身放逐 | 主體：救國英雄被逐、率敵軍返國、被母親阻止 |
| 希臘 | **阿爾西比亞德斯** | 被雅典放逐 | ↔ 投奔斯巴達後又返國，反覆遊走於敵我之間 |
| 中國 | **伍子胥** | 父兄被楚王殺害 | ↔ 流亡異國、借兵復仇，甚至鞭屍洩憤；复仇完成後仍不得安寧 |
| 日本 | **源義經** | 遭兄長鎌倉殿猜忌 | ↔ 立下大功後被逐，逃亡中終究未能回歸 |
| 希伯來 | **大衛與掃羅** | 遭國王追殺 | ↔ 流亡期間拒絕兩次復仇機會，與科里奧拉努斯形成相反選擇 |
| 羅馬 | **辛辛那圖斯** | 自願退隱 | ↔ 同為共和英雄，但權力一到就交歸，樹立「節制」對照 |
| 羅馬 | **盧克蕾蒂亞** | 王政暴政的犧牲者 | ↔ 她的死催生共和；科里奧拉努斯則差點毀滅共和（參見[盧克蕾蒂亞之死](lucretia.md)） |
| 美索不達米亞 | **吉爾伽美什** | 追尋不朽而遠行 | ↔ 歸來時仍未獲接納，英雄的孤獨是代價 |
| 北歐 | **斯塔卡德** | 因殺害摯友被逐 | ↔ 強大戰士被社會排斥，永遠在邊界遊盪 |
| 當代 | **政治流亡者** | 政權更迭 | ↔ 忠誠的定義被撕裂：你為誰而戰，誰就視你為敵 |

### 深層比較一：放逐作為身分的死亡

羅馬的「放逐」（*exsilium*）不只是地理上的驅離，更接近**法律上的死亡**——被逐者失去公民權、財產與家族保護，成為城邦之外的「狼」。科里奧拉努斯悲劇的殘酷正在於此：他失去羅馬公民身分後，唯一能重獲身分的方式，竟是讓羅馬恐懼他。他從「城邦的守護者」變成「城邦的威脅」，這個轉換不是逐步的墮落，而是一次身分的瞬間翻轉。阿爾西比亞德斯與源義經的經歷都印證了同一結構：**英雄一旦被中心拒絕，其才華立刻被重新解讀為危險**。

### 深層比較二：母親的聲音作為城邦的聲音

維圖里婭的干涉，是世界文學中極為獨特的場景——不是國王、將軍或神祇阻止了毀滅，而是一位母親。她的論證切中了科里奧拉努斯的全部矛盾：他自認忠於羅馬，但真正使他無法下手的力量，不是政治忠誠，而是**血脈與養育的記憶**。母親在這裡成為城邦的化身：她站在城牆與兒子之間，用身體畫出一道不可逾越的界線。這種「女性作為和平中介者」的母題，也見於中國的王昭君、希臘的安德洛瑪刻，以及莎士比亞改寫版本中反覆強調的家庭倫理。

### 深層比較三：復仇的停止與羅馬的自我形象

科里奧拉努斯在城門前撤軍，是羅馬傳說中最動人的「節制」場景之一。它與辛辛那圖斯的故事形成完美對照：後者在權力頂峰時主動歸耕，前者在復仇頂峰時主動退讓；兩者共同定義了羅馬共和的理想人格——**力量必須能自我設限**。然而，科里奧拉努斯的節制來得太晚：他挽救了羅馬，卻再也回不去羅馬。相較於伍子胥鞭屍的徹底復仇，科里奧拉努斯的「半途而止」更接近悲劇——他不是不復仇，而是被親情切斷了復仇；他不是回歸，而是被永遠留在門檻上。羅馬人用這個故事告訴自己：**守護城邦的最高代價，是守護者本人無法屬於城邦**。
