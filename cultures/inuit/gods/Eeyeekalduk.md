# 伊伊卡爾德克 (Eeyeekalduk)

- **文化：** 因紐特神話 (Inuit Mythology) – 加拿大中央北極（巴芬島、坎伯蘭灣一帶）
- **職掌：** 醫藥之神、治癒的最高守護者、薩滿療病的上界會診對象

## 概述

伊伊卡爾德克（Eeyeekalduk）是因紐特神話體系中的「醫藥大神」，主要由法蘭茲·鮑亞士（Franz Boas）在一八八〇年代調查加拿大中央北極的「中央愛斯基摩人」（Cumberland Sound、Davis 海峽沿岸）時記錄下來。鮑亞士的敘述極為簡潔：他是「偉大的醫藥之神」，當薩滿（angakkuq）要為病人施行治療之前，必先呼求他的名。名稱的詞源至今不詳，但名尾的 -aluk 在因紐特語中常作「大者」的尊稱後綴，與通加索克（Torngasoak）名中的 -soak 同構，指向同類的「高位大靈」命名法。

在充滿敵意精靈的北極宇宙裡，伊伊卡爾德克的仁善屬性顯得格外醒目。因紐特的超自然世界大部分由「必須安撫的可怕存在」構成：海之下界有瑟德娜（Sedna）的怒氣、陸上有破壞禁忌者Issitoq 的飛頭監視、薩滿世界裡甚至有專門噬食薩滿的惡靈基加提利克（Kigatilik）。相形之下，伊伊卡爾德克不降病、不索供、不懲罰，他的職掌只有一件事：使病癒。他與守護獵海豹者的蓋勒特騰（Qailertetang）同屬這個神系中少數「純善意」的辦事處。

他的存在揭示了一個關鍵的制度設計：在因紐特醫療體系裡，「執行治療」與「授權治癒」是分開的。診斷、吮吸、法歌、護身符等技藝由薩滿操作，但療效最終的保證者不是薩滿本人，而是上界的醫藥大神。薩滿的靈魂飛行到他面前，等於開出的是一張「上界會診單」——這使治療的權威垂直地繫於神，而非繫於個人魅力。

## 神話事蹟

### 出診的程序：從家門到上界會診

當有人病重，家屬會延請薩滿。薩滿抵達後並不立刻動手，而是先唱自己的法歌，在鼓聲中進入出神狀態，讓幫助靈引導其靈魂升往上界，到伊伊卡爾德克處會診。會診要回答的問題是診斷：這個病從哪裡來？是靈魂被奪，是禁忌被犯，還是精靈襲擊？一旦病因判明，薩滿便回返人身，執行治療——以吮吸術從患處吸出侵入的異物，唱治病的法歌，為病人繫上護身符，或令其懺悔所犯的禁忌。整個流程裡，伊伊卡爾德克不親自現身療病，他核可的是「這個病可以治」的判決，以及治療者資格的正當性。

### 病因的三源與辦公室的分工

因紐特病因學把疾病歸於三條路徑：其一是靈魂走失或被死者之靈帶往冥界阿德里文（Adlivun），其二是狩獵與處理獵物的禁忌遭違犯、病人因此「沾染不淨」，其三是惡靈的侵襲與附身。值得注意的是，這個體系把「降病的懲罰端」與「治病的治療端」分給不同的辦事處：監視禁忌並降罰的是Issitoq 一類的懲戒靈，撕裂病人、甚至獵殺薩滿的是基加提利克一類的惡靈，而伊伊卡爾德克只負責療癒，從不因人的罪而拒絕出手。這種「懲罰與治療分屬兩個衙門」的安排，和許多神系中「同一神既降瘟又療瘟」的設計（如阿波羅、塞赫麥特）形成了鮮明的結構對照。

### 仁善之神的稀缺生態

在北極的宗教經濟學裡，神話資源優先被用來「解釋災難」：為什麼獵物不來、為什麼風暴不停、為什麼死者不散。仁善的神在這個體系裡是稀缺物種，因為仁善解釋不了災難。伊伊卡爾德克能占有一席，恰恰因為他被嵌入的是「技術」而非「解釋」：他不回答為什麼生病，只回答怎麼治好。他將薩滿的治療技藝——吮吸、推拿、法歌、護身符——收編在自己名下，使這些技藝獲得來自上界的合法性。換言之，他不是與薩滿競爭的對手，而是使薩滿的「醫療執照」得以頒發的最高單位。

## 跨文化對應

| 文化 | 對應神祇／體系 | 對應關係 |
|------|------|---------|
| 希臘 | 阿斯克勒庇俄斯 (Asclepius) | 專司醫療的神；神廟過夜求癒 vs 薩滿上界會診 |
| 美索不達米亞 | 古拉 (Gula) | 醫師女神；驅邪師與醫師雙軌分工 vs 薩滿與神分層 |
| 埃及 | 伊姆霍特普 (Imhotep) | 醫藥守護神；人臣成神 vs 技藝冠以神名 |
| 中國 | 神農 | 嘗百草定藥理；醫藥知識的神話化授權 |
| 吠陀印度 | 雙馬童 (Aśvin) | 天界醫師、行醫於神人兩界 |
| 日本 | 少名毘古那 | 與大己貴神協力傳授醫藥之道 |
| 猶太教 | 拉斐爾（《托比特書》） | 醫癒天使；魚膽療目與驅魔並行 |
| 馬雅 | 伊希切爾 (Ixchel) | 醫藥與生育女神；神所授權的療癒技術 |
| 約魯巴 | Ọ̀sanyìn | 草藥與醫療之神；藥方神聖化 |
| 現代 | 主治—專科會診—核可制度 | 執行者與授權者分離的醫療官僚結構 |

深層的比較可以從三個層面展開。第一層是「治療是技術，治癒是授權」。無論是阿斯克勒庇俄斯神廟裡的聖蛇與夢中觸摸，還是伊伊卡爾德克座前的薩滿法歌，跨文化的醫療神話反覆呈現同一結構：操作手法可以學，療效保證必須借自神。列維—史陀分析薩滿之歌時指出，療癒的效能來自把身體的不適重新組織進一套神話秩序——伊伊卡爾德克正是這套秩序在北極的名稱。安慰劑研究的現代發現，某種意義上是這條古老原理的實驗室版本：儀式的「權威包裹」本身就是藥。

第二層是「懲罰與治療的辦公室分離」。希臘的阿波羅既射瘟疫之箭又掌 Paian 治癒之歌，埃及的塞赫麥特既降瘟又由同源神祇安撫，降病與療病在同一神格內迴圈；因紐特卻把兩者拆開——Issitoq 與基加提利克負責降罰，伊伊卡爾德克只管治癒。拆開的後果是醫療的「無罪化」：治療者不必先當法官，病人不必先被定罪才有資格受治，只需由薩滿診斷出「路徑」即可進入流程。這是神話裡相當先進的一種醫療倫理設計。

第三層是「會診的垂直軸」。薩滿的靈魂飛行是因紐特宗教的核心動作：越往上界走，遇見的靈越接近秩序的源頭。伊伊卡爾德克的位置說明，療癒被安放在這條垂直授權鏈的高處——病是地上的事，醫囑來自天上的衙門。現代醫院的轉診與會診制度、醫師執照由國家而非患者頒發的設計，用世俗語言複製了同一座金字塔：決定「你能否被治」的權威，永遠不在床邊，而在制度的高處。
