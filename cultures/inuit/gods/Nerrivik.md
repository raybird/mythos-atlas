# Nerrivik — 海之供養者與海豹女巫

- **文化：** 因紐特神話 (Inuit Mythology)
- **職掌：** 海洋食物供應、海豹命運、海洋洋流、狩獵豐歉
- **象徵：** 海豹、獨木舟、冰山裂隙、旋渦
- **別名：** Sequssunaq、Nerrivik（格陵蘭語）、Sassuma Arna（「地底的母親」）
- **相關神靈：** Sedna（海洋之母）、Tekkeitsertok（馴鹿神）、Torngasoak（天空之神）

## 概述

Nerrivik（內里維克）是因紐特萬神殿中一位常被忽視卻極為關鍵的神靈——她是掌管海洋食物供應的女巫神，控制著所有海洋哺乳動物的命運。在因紐特人以海洋狩獵維生的文化脈絡中，Nerrivik 的地位僅次於 Sedna：如果 Sedna 是海洋的主人，那麼 Nerrivik 就是海洋的管家——她決定哪一隻海豹游向哪一艘獨木舟，哪一片海域的魚群在何時出現。

Nerrivik 的名字在格陵蘭因紐特語中意為「食物」或「供養者」，反映其最核心的功能：她是飢荒與豐收之間的仲裁者。在因紐特社會中，狩獵不僅是生存技能，更是一套複雜的宗教與倫理體系——獵人必須遵守嚴格的禁忌（Taboo），而 Nerrivik 正是這些禁忌的主要執行者。當獵人違反禁忌（例如在不適當的時間宰殺海豹、將海豹骨暴露在狗的面前、或以不敬的方式處理獵物的內臟），Nerrivik 會將海洋動物藏匿起來，使獵人一無所獲。

## 神話事蹟

### 海豹命運的織者

在因紐特口傳傳統中，Nerrivik 居住在海底的一座巨大冰屋中，屋內堆滿了海豹的骨頭與內臟。她坐在一張由海豹皮編織的椅子上，面前有一個巨大的石鍋，鍋中烹煮著所有海洋生物的命運。每當一個因紐特獵人在海冰上鑿洞設陷阱，Nerrivik 便從鍋中揀選一隻海豹，命令它游向那個陷阱。但她的揀選並非隨機——她會觀察獵人的品行、是否遵守禁忌、以及他家庭的需要。一個虔誠且遵守規矩的獵人會獲得更多的海豹；一個傲慢或不敬的獵人則可能空手而歸。

這個「命運之鍋」的意象在因紐特文化中具有深遠的影響。它暗示了一種前伊斯蘭時期的因果觀——行為的後果不是來自單一至高神的審判，而是由一個專門的神靈在日常生活中即時執行。這種「日常道德仲裁」的神格在全球神話中並不常見，它更接近於地中海文化中的命運三女神（Moirai）而非基督教的末日審判。

### Nerrivik 與 Sedna 的關係

Nerrivik 與 Sedna 之間的關係在不同部族的口傳傳統中有不同的描述。在格陵蘭版本中，Nerrivik 被描述為 Sedna 的女兒或侍女——她負責執行 Sedna 的意志，管理日常的食物供應。在加拿大北極版本中，Nerrivik 被視為 Sedna 的一個面向或化身——同一個海洋女神的兩個不同職能。在阿拉斯加版本中，兩者則是完全獨立的神靈：Sedna 掌管海洋生物的數量，Nerrivik 掌管它們的分佈與可及性。

這種差異反映了因紐特神話的一個核心特徵：**沒有統一的神譜**。由於因紐特人分佈在從西伯利亞到格陵蘭的廣袤北極地區，各部族的神話體系在核心主題上保持一致，但在具體的神格關係上呈現高度的地域性變化。這使得因紐特神話研究者必須同時參考多個部族的口傳統述，才能建構出較為完整的神系圖景。

### 狩獵禁忌的執行者

Nerrivik 最重要的功能之一是執行狩獵禁忌（Tirigusuq）。在因紐特社會中，禁忌不是抽象的道德律令，而是與日常生存直接相關的實用規則。例如：不可在日出前宰殺海豹（因為這會驚擾 Nerrivik 的早餐）；不可讓狗舔舐獵物的骨頭（因為這會污染獵物的靈魂）；不可在海上歌唱（因為這會引起 Nerrivik 的注意並使她分心）。違反這些禁忌的後果不是「罪」的抽象概念，而是具體的物質損失——Nerrivik 會將海豹從獵人的陷阱中移走。

這種禁忌體系與 Nerrivik 的神格共同構成了因紐特人的「宗教經濟學」：遵守禁忌 = 獲得食物 = 生存；違反禁忌 = 失去食物 = 死亡。在極端嚴酷的北極環境中，這種「行為—後果」的直接關聯使 Nerrivik 成為因紐特宗教體系中最實用、也最令人敬畏的神靈之一。

## 跨文化對應

- **希臘命運三女神（Moirai）**： Clotho（紡織生命之線）、Lachesis（分配長度）、Atropos（剪斷）——Nerrivik 的「命運之鍋」與 Moirai 的「命運之線」共享「神靈決定生物命運」的核心結構，但 Nerrivik 更側重日常物質供應而非抽象生命長度
- **美索不達米亞 Niddaba（Nidaba）**：蘇美的穀物女神與書寫女神——兩者都與「計量與分配」相關，Niddaba 計量穀物，Nerrivik 計量海豹
- **日本稻荷神（Inari）**：掌管稻米與豐收的神靈，由狐仙協助——Nerrivik 與 Inari 共享「食物供應守護者」的神格，且兩者都與動物（狐/海豹）有密切關聯
- **北歐 Freyr**：掌管豐收、陽光與和平的神——Freyr 以黃金野豬 Gullinbursti 為坐騎，Nerrivik 以海豹為使者；兩者都代表著自然的豐饒面
- **印度 Prajapati（主）**：吠陀時期的眾生之主，掌管動物與人類的繁殖——Prajapati 的「分配生命」功能與 Nerrivik 的「分配食物」功能形成平行
- **非洲 Oshun**：約魯巴的河流與豐收女神——Oshun 掌管淡水的豐饒，Nerrivik 掌管海水的豐饒；兩者都是女性神格，且都與「流動的水」密切相關

## 相關神祇

- **Sedna（海洋之母）**：Nerrivik 的上級或同一神格的不同面向——Sedna 掌管海洋生物的整體數量，Nerrivik 掌管它們的分佈
- **Tekkeitsertok（馴鹿神）**：與 Nerrivik 形成陸地—海洋的對應——Tekkeitsertok 掌管陸地動物的供應，Nerrivik 掌管海洋動物
- **Torngasoak（天空大神）**：宇宙秩序的最高守護者——Nerrivik 的禁忌執行功能最終服務於 Torngasoak 維持的宇宙秩序
- **Angakkuq（薩滿）**：人間與 Nerrivik 之間的中介者——薩滿透過儀式與 Nerrivik 溝通，協調獵人與海洋的關係
