# 阿格盧利克 (Agloolik / Agloolik)

- **文化：** 因紐特神話 (Inuit Mythology)
- **職掌：** 海象之靈、薩滿的守護精靈、水下旅程的嚮導

## 概述

Agloolik（阿格盧利克，也拼作 Agloolik 或 Aglūlik）是因紐特神話中隱秘但極為重要的精靈，棲息在冰層之下，與海象（Walrus）有著密切的共生關係。在因紐特薩滿教（Angakkuq）的傳統中，Agloolik 是一位「幫助靈」（helping spirit）——薩滿在入門過程中必須獲得至少一個強大的幫助靈，而 Agloolik 是最受尊敬的幫助靈之一。

與 Sedna（海洋之母，掌管所有海獸的分配）不同，Agloolik 不是大規模分配資源的統治者。祂的角色是局部的、個體化的——守護特定的獵人、引導特定的薩滿、保護特定的海域。每一隻海象體內都可能有 Agloolik 的化身，但祂真正的本體存在於冰層之下一個不可見的世界。

## 神話事蹟

### 薩滿的入門嚮導

在因紐特最著名的薩滿入門敘事中，未來的 Angakkuq 必須在冰面上挖掘洞穴，孤獨地面對海洋。當 Agloolik 決定出現時，海象會從冰洞中探出頭來——這不僅是動物的現身，更是靈界的邀請。薩滿必須游入冰洞，跟隨 Agloolik 潛入海底深處，在那裡接受 Sedna 的考驗。

Agloolik 在入門過程中的角色是「邊界守門人」：如果 Agloolik 不承認薩滿的資格，薩滿甚至無法抵達 Sedna 的居所。這使得 Agloolik 實際上掌握了進入因紐特靈界最深層的鑰匙。

### 海象的守護者

在因紐特獵人的故事中，Agloolik 有時會以巨大的海象形態浮出水面，警告獵人不要過度捕殺。如果獵人違反了狩獵禁忌（如對海豹或海象缺乏尊重），Agloolik 會引導海象群遷移到其他海域，使村莊陷入飢荒。這與 Sedna 困住海獸的機制不同——Sedna 以物理方式阻止海獸靠近海岸，而 Agloolik 以靈性方式使海獸「感知到危險」從而避開人類區域。

### 冰下的隱形世界

在格陵蘭東部的因紐特傳說中，Agloolik 管理著一個冰下的隱形世界——這不是死者的領域，而是活著的精靈的領域。據說在漫長的極夜中，Agloolik 會在冰層之下舉行大型的聚會，所有海洋幫助靈都會參加。有些薩滿聲稱他們曾通過 Agloolik 的帶領參加過這些聚會——在那裡，他們學會了新的治療方法或狩獵歌謠。

## 跨文化對應

| 文化 | 對應神靈 | 共享特徵 |
|------|---------|---------|
| 西伯利亞 | 海象精靈（Walrus Spirit） | 圖形相似的幫助靈系統：薩滿以動物幫手穿越靈界 |
| 北歐 | 菲恩（Fossegrim，瀑布精靈） | 水中的守護精靈，教導特定人選音樂／知識 |
| 蘇格蘭 | 凱爾比（Kelpie，水馬） | 水靈可選擇性協助或誤導人類，需符合特定條件 |
| 日本 | 河童（Kappa） | 水中的精靈，有好有壞，對人類的行為有嚴格的要求 |
| 亞馬遜 | 河豚精靈（Boto Encantado） | 水下精靈引導薩滿取得神聖知識 |

## 相關神祇

- **Sedna**：海洋之母，Agloolik 服務的至高存在；Agloolik 是通向 Sedna 的門衛
- **Angakkuq**：薩滿，Agloolik 為其最重要的幫助靈之一
- **Nanook**：北極熊之靈，陸地薩滿幫助靈，與 Agloolik 的海洋角色對應
- **Aipaloovik**：邪惡的海靈，Agloolik 的對立面——引導而非欺騙

## 出現在

- 格陵蘭東部因紐特人的薩滿入門敘事
