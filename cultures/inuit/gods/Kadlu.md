# Kadlu — 雷霆女神與暴風雪巨靈

- **文化：** 因紐特神話 (Inuit Mythology)
- **族群：** 因紐特（加拿大北極群島與哈德遜灣地區）
- **職掌：** 雷霆、閃電、暴風雪、狂風

## 概述

Kadlu（又拼寫為 Kadlu、Kadloo）是因紐特神話中的雷霆巨靈（通常為女性），為居住在蒼穹之上的巨大存在。不同於大多數文明中的雷神持鎚或戰斧的形象，Kadlu 創造雷鳴的方式極具因紐特文化的特色——祂以海豹皮在石頭上用力摩擦，產生的巨響即為雷霆；當祂在雲層之間踩踏積雪時，發出的聲音就是冬季的風暴咆哮。Kadlu 的姐妹——或她的另外兩個面向——分別掌管閃電與驟雨：其中一位以摩擦石頭產生閃光，另一位以眼淚或尿液化為雨水（Boas 1888: 598-600; Hawkes 1916: 155-158）。

## 神話事蹟

在因紐特口述傳統中，Kadlu 居住在天的最高處，平時不為凡人肉眼所見。當人類違反了部落的禁忌（如以不敬的方式對待獵物、在婦女經期時狩獵，或傷害不應傷害的動物），Kadlu 便會在天空中摩擦祂的海豹皮——每一次摩擦都發出震撼天地的雷聲，作為對人類的警告。閃電則是她的姐妹匆忙奔跑時拖曳的光芒，或者她們用以照明的方式。

部分來自巴芬島地區的傳說版本記載：Kadlu 是一名孤獨的巨人寡婦，她的兩個兒子在外出狩獵時被狼群殺害。Kadlu 在悲痛與憤怒中升上天空，成為雷霆女神，每一次雷鳴都是她的哭喊與復仇的宣言（Rink 1875: 415）。

與歐洲雷神不同， Kadlu 並非戰士或統治者，而是道德秩序的維持者與自然力量的化身。因紐特人對雷鳴的敬畏並非恐懼，更像是一種提醒——提醒人類遵守與動物和靈界之間的神聖約定。

## 跨文化對應

| 文化 | 對應神靈／概念 | 共通點 |
|------|-------------|-------|
| 北歐 | 索爾（Thor） | 雷霆之神，以鎚擊產生雷鳴，為秩序守護者 |
| 中國 | 雷公（Lei Gong） | 掌雷之神，以鎚擊鼓產生雷鳴，懲戒人間邪惡 |
| 印度 | 因陀羅（Indra） | 雷雨之神，以金剛杵擊雲降雷 |
| 馬雅 | 恰克（Chaac） | 雨水與雷霆之神，以斧劈雲 |
| 芬蘭 | 烏科（Ukko） | 雷電與天空之神，以岩石撞擊生雷 |
| 北美原住民（平原） | 雷鳥（Thunderbird） | 以拍翅產雷鳴閃電，為道德秩序的維護者 |
| 日本 | 雷神（Raijin） | 以鼓擊雷，伴隨風神一同出現 |

## 相關神祇

- **Sila**：天空與天氣之神，為 Kadlu 居住的天界之主宰
- **Aningan**：月神，掌管潮汐與季節，與 Kadlu 的暴風雪相關
- **Qailertetang**：風雪精靈，與 Kadlu 共同編織冬季風暴
- **Tornarsuk**：強大的靈體，受到 angakkuq（薩滿）的供奉
