# 蒙干古 (Mungan-ngour)

- **文化：** 澳洲原住民神話 (Aboriginal Australian Mythology)
- **區域：** 澳洲東南部 Kurnai 民族（Gippsland 地區，維多利亞州）
- **職掌：** 文化英雄、立法者、洪水審判者

## 概述

蒙干古（Mungan-ngour，在 Kurnai 語言中意為「我們之父」或「至高者」）是澳洲東南部 Kurnai 民族神話體系中的文化英雄與審判之神。與其他澳洲部落的 Bunjil（Kulin）、Baiame（Kamilaroi）等造物主類似，蒙干古在夢境時間（Dreamtime）創造了人類與動物的宇宙秩序，制定了部落法律。然而他的神話最獨特之處在於一個未曾見於相鄰部落的母題：人類違背蒙干古的禁令後，他降下大洪水毀滅了叛亂者，僅存少數忠誠者得以倖存。

蒙干古的洪水神話在澳洲原住民宇宙論中是罕見的——因為澳洲多數部落的洪水傳說屬於全球性洪水記憶（如海平面上升引發的沿海神話），而蒙干古的洪水帶有明確的道德懲罰與法律維護功能，使其更接近希伯來聖經中諾亞方舟的結構，而非單純的自然現象解釋。英國民族學家 Alfred W. Howitt（1830-1908）在 19 世紀末對 Kurnai 民族進行了詳盡的田野記錄，他在《澳洲東南部的原住民部落》（1904）中完整記錄了蒙干古神話，並指出其洪水故事的獨特性。

## 神話事蹟

### 創世與立法

蒙干古在夢境時間將人類創造於 Gippsland 的沿海平原。與 Kulin 傳統的 Bunjil 先造動物再造人的次序不同，蒙干古首先創造了人類——他從桉樹的樹瘤中取出人形，以白蟻窩的黏土貼合關節，將赭石粉吹入其鼻孔賦予呼吸。然後他創造了所有動物，每一種都有特定的名字與棲息地。

蒙干古為人類制定了三條不可違背的律法：第一，不得殺害同族（部落內禁止暴力）；第二，成年儀式（Kurnai 稱為 Jeraeil）的祕密不得洩漏給未經啟蒙的婦女與兒童；第三，所有的獵物必須與部族共享，不可私佔。這些法律構成了 Kurnai 社會秩序的基礎。

### 禁令被打破

蒙干古在完成創世與立法後，返回了天空（一說為遠方的雷雲之中）。他留下了代表他在人界的聲音——雷鳴從天邊傳來的低吼提醒人類履行義務。

然而人類逐漸忘記了他的教導。在成年儀式中，一名剛剛接受啟蒙的年輕男子違反了最嚴重的禁忌：他向未經啟蒙的婦女洩漏了 Jeraeil 儀式的內容——包括男性入會者象徵性地被「野獸吞噬」後重生的秘密儀式。這是對蒙干古法律的直接挑釁。

### 審判洪水

蒙干古從天界目睹人類的背叛，降下了毀滅性的洪水。雷聲連日不絕，暴雨傾盆，河流氾濫，整個 Gippsland 地區變成了巨大的內海。人類與動物倉皇逃往最高的山丘——但洪水追上了他們。

在此洪水神話中，蒙干古的審判不是無差別的毀滅。據 Howitt 的記述，少數堅守法律的人類在洪水來臨前得到了預警——他們前往高處的洞穴避難，帶著火種與袋鼠皮。洪水退去後，他們成為 Kurnai 的祖先。大多數違背法律者則連同他們的傲慢一起被洪水沖走。

### 化為水龍捲

洪水消退後，蒙干古不再以人形或巨靈形態出現。他化為了水龍捲（waterspout）——從海面竄升的旋轉水柱——以及陸地上的旋風（whirlwind）。Kurnai 人相信，每當在九十哩海灘（Ninety Mile Beach）附近看到水龍捲，或 Grass Tree 平原上揚起旋風，就是蒙干古在巡視大地——查看他的法律是否依然被遵守。

## 跨文化對應

| 文化 | 神祇／人物 | 共同點 |
|------|-----------|--------|
| 希伯來聖經 | 耶和華（諾亞方舟） | 人類違法 → 神降洪水懲罰 → 少數義人獲救 |
| 美索不達米亞 | 恩利爾（Enlil，Ziusudra 洪水） | 神因人類吵鬧／犯罪決定毀滅，少數人獲預警 |
| 希臘 | 宙斯（杜卡利翁洪水） | 青銅人類傲慢 → 洪水毀滅 → 杜卡利翁與皮拉擲石重生 |
| 印度 | 梵天（摩蹉／魚警告摩奴） | 大洪水警告 → 摩奴建舟得救 |
| 印加 | Viracocha | 第一代巨人不敬 → 洪水毀滅 |

## 相關神祇

- **本吉爾（Bunjil）**：Kulin 民族的造物主與立法者，功能與 Mungan-ngour 高度對應，但 Bunjil 並未以洪水懲罰人類
- **巴亞米（Baiame）**：Kamilaroi 民族的至高神，同樣是立法者與文化英雄
- **塔彭（Tapun）**：部分澳洲傳說中的暴風雨神靈
