# Bres (布瑞斯)

- **文化：** 凱爾特神話 (Celtic Mythology)
- **職掌：** Tuatha Dé Danann 的短期國王、半人半 Fomoire、豐饒與危機
- **象徵：** 「美」與「醜」的對比——美貌與殘暴的統一
- **父親：** Elatha（Fomoire 王族）
- **母親：** Ethniu（或 Eriu，愛爾蘭地母神之一）

## 概述

Bres（古愛爾蘭語：*Bres*，意為「美麗」或「繁盛」）是凱爾特神話中最複雜的人物之一——他同時是 Tuatha Dé Danann 的國王與 Fomoire（冥界巨人族）的王子，既是豐饒的象徵，也是壓迫的化身。Bres 的故事是凱爾特神話中關於「正當統治」（*fír flatha*）主題的核心文本，探討了王權的道德責任與政治合法性的問題。

在《莫伊圖拉之戰》（*Cath Maige Tuired*）的敘事中，Bres 被選為 Tuatha Dé Danann 的過渡國王——因為他的母親 Ethniu 是愛爾蘭的女兒（或地母神），使他擁有統治愛爾蘭的合法資格。然而 Bres 的統治以苛政與吝嗇著稱：他將 Tuatha Dé Danann 的土地、牲畜與財富獻給他的 Fomoire 父親 Elatha，導致眾神貧困飢餓。

## 神話敘事

### 苛政與 *fír flatha* 的違反

Bres 的統治違反了凱爾特「公正之王」（*fír flatha*）的原則。在凱爾特王權理論中，國王必須慷慨、好客、守護弱者——Dagda 的永不空竭大鍋正是此理想的象徵。Bres 卻反其道而行：

- **取消宴會：** Bres 停止為 Tuatha Dé Danann 舉辦宴會，違背了凱爾特最重要的社交與政治義務
- **減少供品：** 德魯伊與詩人（*fili*）的供品被削減至正常水平的三分之一，導致 Brigid 之子 Ruadan 出逃
- **外族統治：** Bres 將 Tuatha Dé Danann 的戰士送往 Fomoire 領土從事奴役勞動

詩人 Cairbre 的《抱怨之歌》（*Song of Bres*）是凱爾特文學中最古老的王權批評文本之一，直接指責 Bres 的失德。

### 推翻與寬恕

Dagda 與 Lugh 聯合推翻 Bres 的統治後，面對如何處置俘虜的問題。Bres 懇求寬恕，並聲稱若被釋放將教導 Tuatha Dé Danann 以豐饒的農業知識——何時耕種、何時收穫。Dagda 與 Lugh 同意饒他性命，但 Bres 教導的知識被認為是不完整的或故意誤導的。

### 第二次莫伊圖拉之戰的背叛

在第二次莫伊圖拉之戰中，Bres 背叛 Tuatha Dé Danann，加入 Fomoire 一方。在戰鬥中，Balor（Fomoire 王）的邪眼殺死了 Nuada——Bres 的背叛與 Nuada 的死亡之間存在敘事關聯，暗示背叛者與被背叛的正義之間的張力。

## 跨文化對應

| 凱爾特 Bres | 對應人物/概念 | 文化 |
|---|---|---|
| 美貌的暴君 | 路西法（Lucifer） | 基督教傳統 |
| 半人半魔的國王 | 哈迪斯劫持 Persephone | 希臘 |
| 背叛者 | 蘭斯洛特（Lancelot） | 亞瑟王傳說 |
| 豐饒知識交換 | 普羅米修斯的禮物 | 希臘 |
| 正當統治原則 | *fír flatha* ↔ 中國「天命」 | 中國 |
| 苛政導致推翻 | 暴君被推翻（如商紂王） | 中國 |
| 半神背叛者 | 羅波那（Ravana） | 印度 |

## 相關神祇

- **Dagda：** 推翻 Bres 的 Tuatha Dé Danann 領袖
- **Lugh：** 光之神，Bres 的主要對手
- **Nuada：** Bres 的前任國王，因失去手臂退位
- **Elatha：** Bres 的 Fomoire 父親
- **Ethniu / Eriu：** Bres 的母親，愛爾蘭的土地化身
