# 波斯與埃及創世神話比較：原水、秩序與神聖光輝

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology) vs 埃及神話 (Egyptian Mythology)

## 比較動機

波斯（瑣羅亞斯德教）與埃及神話是古代近東兩大文明的宗教核心。兩者都以「原水」（primordial waters）作為創世的起點，都以「秩序」（Ma'at vs Asha）作為宇宙運行的根本原則，也都發展出複雜的神聖王權與死後審判體系。然而，兩者的神學框架截然不同——埃及是多神教的宇宙再生敘事，波斯是善惡二元論的線性宇宙劇。本文將比較這兩個系統在創世神話層面的結構異同，探討古代近東共享的創世母題如何在不同的文化土壤中開出截然不同的花朵。

## 核心概念對照

### 一、原水中的誕生：努恩（Nun）與努姆（Nammu）

**埃及：努恩（Nun）**

埃及神話的創世始於努恩（Nun）——一片無邊無際的黑暗原水。努恩不是神，而是混沌的原始狀態。在赫利奧波利斯（Heliopolis）的創世神學中，太陽神阿圖姆（Atum）從努恩中的「原始丘」（benben）浮現，自發地誕生。阿圖姆的誕生標誌著宇宙秩序（Ma'at）的開始。努恩並未消失，而是持續存在於地下與天空的邊緣，包圍著物質世界——每日夜晚太陽船穿行努恩，便是對創世的不斷重演。

**波斯：努姆（Nammu）**

波斯神話（深受蘇美傳統影響）中的原水女神努姆（Nammu，蘇美語 Nammu / Namma）是宇宙最初的狀態。根據蘇美—波斯神話傳統，努姆是天（An）與地（Ki）的母親，她從原水中自發地孕育出原始的天與地。天與地的分離（由大氣神恩利爾 Enlil 完成）標誌著秩序的開始。與埃及努恩不同的是，努姆更像是一位「人格化的母親」，而努恩則是一個「非人格的狀態」。

### 二、秩序的本質：瑪亞特（Ma'at）與阿莎（Asha）

**埃及：瑪亞特（Ma'at）**

瑪亞特是埃及神話中最核心的抽象概念——她既是女神（頭戴鴕鳥羽毛），也是正義、真理、宇宙秩序與平衡的化身。瑪亞特不是被創造的，而是與宇宙同在的永恆原則。阿圖姆創造世界時，實際上是將瑪亞特的秩序從努恩的混沌中「分離」出來。在死者之書中，死者的心臟必須在天秤上與瑪亞特的羽毛稱量——心臟若重於羽毛，靈魂將被吞噬。

**波斯：阿莎（Asha）**

阿莎（阿維斯塔語 Aša，中古波斯語 Arta）是波斯神話中對應瑪亞特的核心概念——真理、正義、正確的秩序。然而，與瑪亞特不同的是，阿莎是阿胡拉·馬茲達（Ahura Mazda）創造的，是善的產物而非宇宙的永恆屬性。更重要的是，阿莎有其對立面——德魯傑（Druj，謊言與混亂），兩者之間的鬥爭構成了波斯神話的核心戲劇。瑪亞特是宇宙的背景秩序，阿莎則是需要被捍衛的價值。

### 三、創世者的角色

**埃及：多神協作**

埃及的創世是一個多神協作的過程。阿圖姆（自生者）是第一個神，但他通過噴嚏或唾液生下了舒（Shu，空氣）與泰芙努特（Tefnut，濕氣）。舒與泰芙努特生下蓋布（Geb，大地）與努特（Nut，天空）。蓋布與努特生下歐西里斯、伊西斯、賽特與奈芙蒂斯。這個「赫利奧波利斯九柱神」（Ennead）體系展示了創世是一個逐步分化、層層遞進的過程。

**波斯：至高神的獨創**

波斯神話的創世更強調阿胡拉·馬茲達作為至高創造者的唯一性。在《阿維斯塔》的〈亞斯納〉（Yasna）中，阿胡拉·馬茲達以「善思」（Vohu Manah）為媒介，在光明中冥想，首先創造了天空的原型，然後依次創造了水、大地、植物、動物、人類。每一個創造都是有意識、有目的的善的行動。然而，安格拉·曼紐（Angra Mainyu）的入侵扭曲了這些創造——死亡、疾病、黑暗都是惡對善的「污染」。

### 四、結構對照表

| 結構要素 | 埃及創世神話 | 波斯創世神話 |
|---------|-------------|-------------|
| **起點** | 努恩（Nun），黑暗原水 | 努姆（Nammu），原水女神；或直接由阿胡拉·馬茲達創造 |
| **創世者** | 阿圖姆（Atum），自生者 | 阿胡拉·馬茲達（Ahura Mazda），智慧主 |
| **創造方式** | 自發誕生後以噴嚏/唾液生神 | 以「善思」冥想，以意志創造 |
| **秩序原則** | 瑪亞特（Ma'at），永恆的背景秩序 | 阿莎（Asha），善的產物，需被捍衛 |
| **混亂來源** | 賽特（Set），混沌之神（內在衝突） | 安格拉·曼紐（Angra Mainyu），惡神（外在入侵） |
| **宇宙結構** | 蓋布（地）與努特（天）被舒（空氣）分離 | 天（An）與地（Ki）被恩利爾（Enlil）分離 |
| **時間觀** | 循環：太陽船每日重演創世 | 線性：世界從創造走向終極善化 |
| **神聖王權** | 法老是荷魯斯之子，神的地上代理人 | 國王是阿胡拉·馬茲達的代理人，但非神 |
| **死後世界** | 冥界之旅，心臟審判，永恆樂園 | Chinvat 橋審判，復活，弗拉肖凱雷提 |

## 關鍵差異與啟示

### 混亂的來源：內在 vs 外在

最根本的差異在於「混亂」的性質。在埃及神話中，賽特殺死歐西里斯是內在的家族衝突——兄弟相殘是宇宙秩序的一部分。賽特既是混沌的化身，也是太陽船夜間航行的保護者（他站在船頭擊退阿佩普）。埃及神話接受了衝突與混亂作為宇宙運行的必要元素。

在波斯神話中，安格拉·曼紐是外在的入侵者——他從虛空中闖入阿胡拉·馬茲達創造的完美世界，帶來死亡與腐敗。善惡的鬥爭是宇宙性的、不可調和的。這導致了波斯神話強烈的末世論傾向——最終善必須徹底消滅惡，世界才能恢復完美。

### 時間的本質：循環 vs 線性

埃及神話的時間是循環的——太陽船每日夜間穿行努恩，擊敗阿佩普，清晨在東方重生。尼羅河的年度泛濫與退去重複著創世的節奏。死者在冥界接受審判後，義人的靈魂（ba 與 ka 結合為 akh）加入太陽船的航行，參與這個永恆的循環。

波斯神話的時間是線性的——世界被創造為一萬兩千年，分為三個階段。惡的入侵是歷史性的事件，弗拉肖凱雷提（宇宙最終更新）是不可逆轉的終點。這種線性時間觀深刻影響了後來的猶太教、基督教與伊斯蘭教的末世論。

### 創造的性質：自發 vs 意志

埃及的創世帶有自發性——阿圖姆從努恩中「自然浮現」，沒有外在的推動力。創造的動力來自宇宙自身的潛能。

波斯的創世是高度意志化的——阿胡拉·馬茲達有意識、有目的地創造，每一步都是「善思」的體現。這反映了波斯神話對理性與有意識創造的重視——宇宙不是偶然的產物，而是至高智慧的精心設計。

## 共享的深層結構

儘管有上述重大差異，兩個系統共享一些深層結構：

1. **原水分離**：兩者都以原水作為起點，以天地分離作為創世的核心事件。
2. **秩序 vs 混亂**：兩者都以秩序（Ma'at/Asha）對抗混亂（Isfet/Druj）作為宇宙的根本張力。
3. **神聖王權**：兩者都將王權神聖化，認為統治者是神在人間的代理人。
4. **死後審判**：兩者都有死後審判的概念，義人獲得永恆獎賞，惡人受到懲罰。
5. **光明 vs 黑暗**：兩者都以光明象徵善、以黑暗象徵惡，太陽神在兩個體系中都扮演重要角色。
