# 瑣羅亞斯德教的夢境與預言——跨文化比較

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **類型：** 跨文化比較 (Cross-Cultural Comparison)

## 概述

夢境與預言在瑣羅亞斯德教中佔有神聖地位——它們不僅是個體心理的反映，更是阿胡拉·馬茲達（Ahura Mazda）與安格拉·曼紐（Angra Mainyu）在靈界交戰的前線。在《阿維斯塔》中，夢（cašni- / čišnīh）被分為兩類：來自善神的「啟示之夢」（ahratūm / 阿什塔·維希什塔）與來自惡魔的「誘惑之夢」（drug / 德魯傑）。先知瑣羅亞斯德本人即通過夢境獲得神啟，而波斯帝國的國王（如居魯士大帝、達里厄斯一世）則通過夢境預知王權更迭。這種夢境神學與希臘、希伯來及印度的夢境傳統形成了一個跨越古代世界的比較神話學網絡。

## 瑣羅亞斯德教的夢境觀

### 夢境分類

根據《阿維斯塔》的〈萬迪達德〉（Vendidad）第7章與〈扎姆亞德·亞什特〉（Zamyād Yasht），瑣羅亞斯德教將夢境分為三種：

1. **阿胡拉·馬茲達的夢**（Ahunāvaitī）：至高神在睡眠中向虔誠者傳達旨意。瑣羅亞斯德在三十歲時，正是在夢中看到一道耀眼的白光——那是阿胡拉·馬茲達的第一次召喚。夢中的聲音對他說：「來吧，人類的子嗣，因為你將成為真理（Asha）的守護者。」

2. **Daena 的夢**（Daenā-čišnīh）：Daena（靈魂之女/業之化身）在夢中顯現，預示死者死後的命運。行善者在夢中見到美貌的 Daena 在花園中等待，行惡者則見到醜陋的 Daena 在黑暗的深淵中。

3. **惡魔的夢**（Aēšma）：安格拉·曼紐的僕從（如 Bushyasta「催眠者」）以噩夢折磨人類，使人恐懼、懶惰或犯罪。虔誠者在睡前誦讀 Ahuna Vairya 祈禱咒語以抵禦惡魔的夢境入侵。

### 國王的預言之夢

波斯帝國的歷史中，國王的夢境被視為神聖預言的載體：

- **居魯士大帝的夢**：根據《居魯士的夢》（Cyropaedia）記載，居魯士在征服巴比倫前夢見希斯塔斯普（Hystaspes）之子達里厄斯（Darius）駕著有翼的戰車飛上天際——此夢預示了阿契美尼德王朝的更迭。
- **達里厄斯的夢**：貝希斯敦銘文（Behistun Inscription）記載，達里厄斯在奪取王位前多次獲得預言之夢，阿胡拉·馬茲達在夢中賜予他王權的合法性。
- **伊斯凡迪亞爾（Esfandiyār）的夢**：在《王書》（Shahnameh）中，英雄伊斯凡迪亞爾在出征前夢見自己被鳥類圍繞——解夢者預言他將在戰場上獲得勝利，但最終死於命運的安排。

## 跨文化對應

| 文化 | 夢境/預言傳統 | 共通點 |
|------|-------------|--------|
| 希臘 | 德爾菲神諭、阿斯克勒庇俄斯神殿的孵夢療法 | 夢境作為神聖訊息的載體；神殿中過夜求夢的儀式 |
| 希伯來 | 雅各的天梯之夢、約瑟的解夢、先知的異象 | 夢境作為上帝與人溝通的媒介；先知通過異象獲得啟示 |
| 埃及 | 圖坦卡門的夢碑、《夢之書》（Papyrus Chester Beatty III） | 夢境分類系統（好夢/壞夢）；夢的解釋作為神聖技藝 |
| 印度 | 《奥义书》的夢境哲學、《摩诃婆罗多》的預言夢 | 夢境作為靈魂的旅行（Upanishad: 祕密之夢）；阿周那的預言之夢 |
| 美索不達米亞 | 《夢的解析》（Iqqur īnūsh）、占卜夢境 | 夢境作為神的訊息；專業解夢者的存在 |
| 中國 | 《周公解夢》、《左傳》中的預言之夢 | 夢境與國家命運的關聯；夢的吉凶分類 |

## 結構性平行分析

### 1. 夢境作為「神聖通訊管道」

在瑣羅亞斯德教中，阿胡拉·馬茲達通過夢境與人類溝通——這與希伯來傳統中上帝在夢中向先知說話（如以西結的異象）、希臘傳統中阿波羅通過德爾菲神諭傳達旨意形成結構平行。三者皆假設：神意可以通過非理性的方式（夢、幻覺、神諭）傳達給特定的人類（先知、國王、祭司）。

### 2. 善夢與惡夢的二元對立

瑣羅亞斯德教的夢境二分法（善神的夢 vs. 惡魔的夢）與埃及《夢之書》的好夢/壞夢分類、希伯來《約瑟解夢》的善惡解夢傳統高度平行。這種二元分類反映了一個共同的文化假設：夢境不是中性的，而是善惡勢力角力的戰場。

### 3. 夢境與政治合法性

波斯國王通過夢境獲得統治合法性——此觀念與古埃及法老的「神聖誕生」神話（法老為拉神之子）、中國皇帝的「天命」觀念、希臘亞歷山大大帝的「宙斯之子」夢境形成平行。夢境在此類傳統中不僅是預言工具，更是政治宣傳的載體。

## 瑣羅亞斯德教對伊斯蘭夢境觀的影響

伊斯蘭教的「真夢」（al-ru'ya al-ṣādiqa）概念——即先知或虔誠者的夢境為真實的神聖啟示——直接承襲自瑣羅亞斯德教的夢境神學。伊斯蘭聖訓（Hadith）中記載：「真夢是四十-six分之一的先知性」（Sahih al-Bukhari），這一觀念在波斯伊斯蘭化的過程中被廣泛接受。波斯蘇菲傳統（如 Rūmī、Hāfez）進一步將夢境發展為靈性修行的核心工具，融合了瑣羅亞斯德教的夢境神學與伊斯蘭的神秘主義。
