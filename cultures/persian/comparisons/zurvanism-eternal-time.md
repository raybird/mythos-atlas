# 瑣羅亞斯德教 Zurvanism 與永恆時間觀——跨文化比較

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **類型：** 跨文化比較 (Cross-Cultural Comparison)

## 概述

 Zurvan（阿維斯塔語 Zruvān，中古波斯語 Zurwān）是瑣羅亞斯德教異端派別「祖爾萬主義」（Zurvanism）中的至上神——永恆時間的化身。在正統瑣羅亞斯德教中，阿胡拉·馬茲達（Ahura Mazda）是唯一的至高神；但在祖爾萬主義的神學體系中，Zurvan 作為「無限時間」（Zrānō Aka rāna 「不可測量的時間」）凌駕於善惡二神之上——阿胡拉·馬茲達與安格拉·曼紐（Angra Mainyu）皆為其子嗣。此觀念在薩珊王朝（224–651 CE）時期極為盛行，深刻影響了波斯哲學、伊斯蘭教的卡達里亞派（Qadariyya）神學，乃至中亞佛教的宇宙時間觀。

## 祖爾萬主義的核心教義

根據《班達希申》（Bundahishn）第1章的記述，Zurvan 以千年獻祭催生了雙生子：阿胡拉·馬茲達（善/光明）與安格拉·曼紐（惡/黑暗）。宇宙的一萬兩千年壽命即為 Zurvan 預定的時間範圍——善惡之戰在這段時間中展開，最終善神勝利，世界 renovation（Frashokereti）完成。

祖爾萬主義的關鍵哲學意涵在於：善與惡皆為永恆時間的產物，它們的對立不是終極的——時間本身才是宇宙的終極實在。這與正統瑣羅亞斯德教的善惡二元論形成根本對立——在正統教義中，善惡是永恒對立的，沒有更高的統一原則。

## 跨文化對應

| 文化 | 概念/神祇 | 共通點 |
|------|----------|--------|
| 希臘 | 柯羅諾斯（Chronos）/ 宙斯之父柯羅諾斯（Cronus） | 時間的擬人化；Cronus 噬子與時間吞噬萬物的隱喻；Hesiod《神譜》中柯羅諾斯為第一代神王 |
| 印度 | 迦拉（Kāla，黑天/Krishna 時間面向） | 《薄伽梵歌》第11章：Krishna 以 Kāla 形態顯現為「吞噬一切的時間」；Kāla 超越善惡 |
| 中國 | 「道」之永恆循環 / 「天命」時間觀 | 《老子》「有物混成，先天地生」——道先於天地，類似 Zurvan 先於善惡；歷史循環論（五德終始） |
| 北歐 | 時間之泉 Urdarbrunnr / 世界循環 | 世界樹從時間之泉汲取養分；Ragnarök 後世界重生——周期性宇宙論 |
| 埃及 | 拉神（Ra）的夜航與再生 | 太陽船每日週期性毀滅與重生；宇宙循環時間觀 |
| 瑪雅 | 五太陽紀 / Baktun 循環 | 宇宙經歷多次毀滅與重建；時間為周期性的、可計算的 |

## 結構分析

祖爾萬主義的「永恆時間生善惡」結構與以下母題形成深層平行：

1. **原始犧牲催生世界**：Zurvan 獻祭生雙子，對應北歐 Ymir 被殺化身世界、印度 Purusha 被獻祭化身宇宙——「原初犧牲」母題
2. **善惡共同起源**：善惡同出一源的觀念，與中國陰陽互根、諾斯替主義（Gnosticism）的「至深神」（Bythos）超越善惡極為相似
3. **時間終結與宇宙更新**：Frashokereti（最終翻新）對應北歐 Ragnarök 後新世界、印度劫波（Kalpa）循環、基督教末日審判——「宇宙更新」母題

祖爾萬主義對伊斯蘭教的影響值得特別關注。早期伊斯蘭教的卡達里亞派（強調自由意志）與賈卜里派（強調宿命）之爭，部分根源於波斯祖爾萬主義的時間宿命論。阿拉伯歷史學者 al-Tabarī 在其《先知與國王的歷史》中記載了波斯伊斯蘭化後這些觀念的融合過程。
