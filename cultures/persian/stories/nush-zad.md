# 努什扎德 (Nush-Zād) — 國王的半魔之子

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)

## 故事背景

努什扎德（Nūsh-Zād，中古波斯語 Nōshzād，意為「從火焰中誕生」或「有福的後代」）是波斯史詩《王書》（Shahnameh）中伊朗國王凱·卡烏斯（Kay Kāvus）與一位圖蘭公主所生的兒子。他的出生是一段禁忌結合的後果——凱·卡烏斯在一次對圖蘭的戰役中俘虜了阿弗拉西亞布（Afrāsiyāb）的妹妹，強行娶她為妻。這位圖蘭公主在婚後生下了努什扎德，但他從出生起就被一種不祥的氣質籠罩：他的血統中流淌著伊朗與圖蘭兩個敵對民族的血液，暗示了善惡交織的命運。

在波斯神話的譜系學中，努什扎德代表的是「混血的悲劇」——他是文明世界（伊朗）與野蠻力量（圖蘭/安格拉·曼紐的代理人）之間禁忌結合的產物。這種「半人半魔」的身份使他在瑣羅亞斯德教的道德宇宙中處於極為尷尬的位置：他既不是完全的邪惡（因為他有伊朗王室的血脈），也不是完全的善（因為他有圖蘭的血統）。

## 情節

### 第一幕：禁忌的婚姻

凱·卡烏斯是波斯王書中最偉大但也最驕傲的國王之一。他曾率領伊朗大軍深入圖蘭腹地，征服了阿弗拉西亞布的領地。在一次戰役中，他俘虜了阿弗拉西亞布的妹妹——一位被描述為美貌無雙的公主。凱·卡烏斯將她帶回伊朗，娶她為妻。這段婚姻本身在波斯文化中是極具爭議的——它是戰爭征服的戰利品，而非兩情相悦的結合。

公主在伊朗的宮廷中生活，但她從未忘記自己的出身。根據一些版本的記述，她暗中保持著對圖蘭的忠誠，甚至秘密祈求阿弗拉西亞布的寬恕。她的內心衝突——作為伊朗王后與圖蘭公主的雙重身份——為努什扎德的命運埋下了伏筆。

### 第二幕：半魔之子的誕生

努什扎德出生時，宮廷中的祭司（Mobedan）立刻察覺到他的不祥——他的面容帶有某種「非伊朗」的氣質，他的舉止暗示著圖蘭血脈中未馴服的野性。在瑣羅亞斯德教的語境中，這種「混血」被理解為安格拉·曼紐對伊朗純潔血統的污染。凱·卡烏斯雖然接受了這個兒子，但宮廷中的祭司與謀臣們對努什扎德始終保持警惕。

努什扎德在成長過程中逐漸意識到自己的特殊身份。他從母親那裡得知了圖蘭的傳說與文化，同時又在伊朗的宮廷中接受了戰士教育。他的內心分裂——他既是伊朗的王子，又是圖蘭的外甥。這種雙重身份使他成為伊朗宮廷中最孤獨的人物。

### 第三幕：背叛與懲罰

在故事的高潮，努什扎德最終選擇了母親的陣營——他秘密與阿弗拉西亞布聯絡，試圖為圖蘭提供伊朗的軍事機密。根據某些版本，他的動機並非純粹的背叛，而是出於對母親的愛與對自身身份的困惑：他想證明自己並不因為有圖蘭血統而低人一等。

陰謀被發現後，凱·卡烏斯面臨了一個痛苦的抉擇——如何處置自己的兒子。最終，根據祭司的建議，努什扎德被處以火刑。在波斯神話中，火刑是最嚴厲的懲罰，因為火（Atar）是阿胡拉·馬茲達的象徵——以火處刑意味著以神聖的火焰淨化邪惡。努什扎德在火焰中死去，他的死亡被理解為伊朗對安格拉·曼紐的又一次勝利——善戰勝了邪惡，即使這邪惡部分地流淌在國王自己的血液中。

### 第四幕：母親的復仇

努什扎德的母親在兒子死後陷入了瘋狂的悲痛與復仇之中。她試圖暗殺凱·卡烏斯，但最終失敗。在一些版本中，她自殺殉子；在另一些版本中，她逃回圖蘭，成為阿弗拉西亞布繼續對抗伊朗的動力。努什扎德的故事因此成為一個完整的悲劇循環：禁忌的結合產生了悲劇的後代，悲劇的後代引發了更多的衝突。

## 跨文化平行

努什扎德的故事在全球神話中有多個平行版本，核心母題是「禁忌婚姻的後果」與「混血者的悲劇命運」：

| 文明 | 故事 | 核心平行 |
|------|------|----------|
| 希臘 | 希波呂托斯 (Hippolytus) | 忒修斯之子因父母的禁忌結合而承受悲劇命運 |
| 希臘 | 俄狄浦斯 (Oedipus) | 王室血脈中的詛咒代代相傳 |
| 北歐 | 海爾 (Hel) | 洛基之女因血統不純被放逐到冥界 |
| 埃及 | 阿努比斯 (Anubis) | 混血神祇在神系中的特殊位置 |
| 印度 | 卡爾納 (Karna) | 婚前之子的悲劇命運與身份困惑 |
| 中國 | 哪吒 | 神魔混血後代的反叛與犧牲 |
