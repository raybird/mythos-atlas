# 費里敦與佐哈克的傳說

- **文化：** 波斯神話 (Persian/Zoroastrian Mythology)
- **類型：** 英雄傳說（*Šāhnāma* 傳統）
- **主題：** 暴君推翻、正義復國、神授王權

## 概要

費里敦（*Fereydun*）是伊朗傳統中象徵正義與復國的英雄王。傳說中，惡魔阿日達哈克（*Aži Dahāka*，即佐哈克）在阿胡拉·馬茲達的允許下統治伊朗，並以暴政荼毒大地。費里敦出生於王室血脈，受卡維鐵匠（*Kāva*）的義旗激勵，在年輕時以巨斧（*bovīne*）起兵，最終推翻佐哈克，將其鎖於達馬萬德山（*Damāvand*）下永遠禁錮，恢復正義王權，開啟伊朗的黃金時代。

## 傳說脈絡

1. **佐哈克的崛起**：佐哈克原為善良的青年，卻為阿利曼（*Angra Mainyu*）所迷惑。阿利曼親吻其肩膀，肩上長出兩條蛇，必須以人腦為食方能止痛，從此墮落為嗜血暴君。
2. **卡維起義**：鐵匠卡維為了保護子女，將自己的皮圍裙綁於長槍成為義旗（*Derafš-e Kāviānī*），號召人民反抗佐哈克。此旗後成為伊朗王權的象徵。
3. **費里敦成長**：費里敦的父親被佐哈克殺害，幼年由牧人撫養長大。隨著年歲增長，他決心復仇，與兄弟伊拉吉（*Ēraj*）、薩爾姆（*Salm*）、圖爾（*Tur*）共同籌備起義。
4. **推翻暴君**：費里敦手持由鐵匠打造的巨斧，在卡維義旗引領下攻入宮殿，生擒佐哈克，並未即刻殺死他，而是依神諭將其鎖於達馬萬德山的岩洞中，以防其再度出世禍害大地。
5. **分國與和解**：費里敦將伊朗分給伊拉吉，將突厥（*Tūrān*）分給圖爾，將羅姆（拜占庭勢力所指地區）分給薩爾姆。後因爭產與猜忌爆發兄弟爭鬥，伊拉吉被殺，導致長年伊朗—圖蘭戰爭，為《王書》後續篇章奠定伏筆。

## 宗教與象徵意涵

- **正義對暴政**：佐哈克象徵*drug*（虛偽、暴力），費里敦象徵*asha*（真理、秩序）。推翻佐哈克是維護宇宙秩序的行動。
- **平民與王權結合**：卡維鐵匠的義旗強調反抗並非僅靠王室血脈，而是平民與英雄共同成就。王權需獲得民心方能正當。
- **鎖而不殺**：費里敦不殺佐哈克而是囚禁，體現瑣羅亞斯德教的倫理：消滅邪惡的根源而非單純洩恨，亦避免重蹈暴力循環。
- **達馬萬德的永囚**：佐哈克被鎖於火山之下，待末世*Frashokereti*（復興）時方能最終被消滅。這與末世大決戰的觀念密切相關。

## 跨文化對應

| 傳統 | 類似主題 | 對比說明 |
|------|----------|----------|
| 希臘神話 | 宙斯推翻克羅諾斯、十二提坦之戰 | 類似「新王朝推翻舊暴政」，但希臘多為神間鬥爭，費里敦則強調人間英雄與平民聯合。 |
| 印度吠陀 | 印陀羅戰勝弗栗多（Vṛtra） | 印陀羅以雷斧破除旱災象徵的巨蛇，費里敦以巨斧破除暴君，皆以「斧／雷」象徵正義。 |
| 巴比倫 | 馬爾杜克戰勝提亞瑪特 | 宇宙創生式的善惡決戰，佐哈克被鎖而非被肢解，強調「禁錮」而非「肢解再造」。 |
| 北歐 | 索爾與耶夢加得、諸神黃昏 | 暴力對抗末世威脅，但北歐傾向宿命悲劇，伊朗更強調復國與正義重建。 |
| 凱爾特 | 庫胡林與暴君、阿瑟王傳說 | 英雄復國與義旗象徵，但卡維義旗的「平民起義」色彩更為突出。 |
| 芬諾-烏戈爾 | 萬能者與巨人衝突 | 多為創世鬥爭，伊朗更聚焦於「道德暴政」而非純粹巨人威脅。 |
| 中國 | 黃帝戰蚩尤、周武王伐紂 | 類似「吊民伐罪」的正當性論述。費里敦強調「斬除暴君」同時限制復仇循環，與中國「順天應人」觀念有共鳴。 |
| 日本 | 神武天皇東征、八岐大蛇傳說（素戔嗚尊） | 除妖與建立王權，佐哈克與八岐大蛇同為多頭／噬人怪物，英雄以斧／劍除之象徵秩序恢復。 |
| 埃及 | 荷魯斯戰賽特 | 秩序（Maat）對混沌（Isfet）的鬥爭，賽特多被制服而非永囚，強調平衡而非單純消滅。 |

## 結語

費里敦與佐哈克的傳說不僅是英雄起義，更是瑣羅亞斯德教政治倫理的縮影。真正的王權不來自血統的傲慢，而來自對*asha*的忠誠與對暴政的抵抗。卡維的圍裙成旗，說明解放往往始於平民的憤怒。佐哈克被鎖於達馬萬德山下，提醒後世：邪惡雖能一時得勢，正義終將將其禁錮，直至末世淨化。
