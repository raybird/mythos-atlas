# 七歲的復仇——扎里爾之死、巴斯瓦爾與《扎里爾紀念》

- **文化：** 波斯神話（瑣羅亞斯德教／伊朗史詩傳統）

## 故事背景

這則故事保存在中古波斯語（Pahlavi）短篇《扎里爾紀念》（Ayādgār ī Zarērān，直譯「扎里爾之追念」）之中，是現存唯一的帕赫拉維語古伊朗史詩標本，僅靠一部一三二二年的抄本流傳。它的情節也見於《阿維斯塔》若干頌歌的暗示：〈亞什特〉五．一〇八、一一二、一一七與十九．八七提到維什塔斯帕（Vištāspa）與扎里里瓦伊里（Zairivairi）對抗邪惡的阿爾賈塔斯帕（Arəǰat.aspa），〈亞什特〉十三．一〇三則已出現巴斯瓦爾的名字（Boyce 1987）。換句話說，這不是後世某一部長篇史詩的插曲，而是一段從口頭史詩時代沉澱下來的宗教戰爭敘事。

故事設在凱揚王朝的傳說年代：國王維什塔斯帕接受了瑪茲達崇拜的「純淨宗教」，消息傳到赫尤恩人（Hyōns，即中古伊朗文獻中的匈人／希奧尼特）之王阿爾賈斯普（Arǰāsp）耳中。阿爾賈斯普遣使送來國書，要求他放棄新信仰，否則兵戎相見。國王不肯。宰相賈馬斯普（Jāmāsp）預言：這場戰役中，國王的兄弟扎里爾（Zarēr）與多名親族將死。預言沒有阻止戰爭，只讓即將到來的死亡顯得更加不可逆轉——史詩的張力不在「是否會死」，而在「死後還能留下什麼」。

## 情節

### 使者、國書與不可逆的預言

使者把阿爾賈斯普的話帶到宮廷：聽聞維什塔斯帕與其子、兄弟、族長和同伴接受了歐爾馬茲德（Ohrmazd）的聖教，赫尤恩人之王感到震驚，國書同時帶有威脅與對叛教者的許諾。國書與預言構成了故事的雙重框架：一邊是外敵對信仰的挑戰，一邊是智者對死亡的知識。扎里爾沒有因為預言而退縮；他做為伊朗軍隊的統帥，選擇把已知的結局走完。

### 山丘上的廝殺與背後的一擊

兩軍各自登上山丘。文獻以誇張的數字形容兵力：維什塔斯帕有十二乘十二萬人，阿爾賈斯普有十二萬的萬倍。扎里爾在戰場上「如烈火落入山中，又有風助勢」：揮劍向前殺十個赫尤恩人，收劍時再殺十一個；飢渴時，他看見敵人的血便已飽足。阿爾賈斯普從山丘上望見，懸賞女兒扎爾斯圖恩與整個國土，要人殺死這位伊朗統帥。

魔法師維德拉夫什（Wīdrafš）應賞而出。他騎著備好的馬，拿著一件由地獄惡魔以憤怒鑄造、浸過「罪惡之水」毒液的武器。他不敢正面迎戰，趁扎里爾專注廝殺時，從背後刺入腰帶之下、聖帶（kustag）之上，穿心而死。弓弦的震動與勇士的吶喊瞬間沉寂。維什塔斯帕在山丘上察覺「伊朗的統帥已被殺」，因為不再有弓聲傳來。此處與本站神祇頁所記「咽喉中箭」的情節不同：帕赫拉維原文是背後腰際的致命傷，《王書》系統另有改寫，二者宜並列而非合併。

### 七歲男孩與父親的遺體

國王懸賞：誰能為扎里爾報仇，便賜女兒霍馬克（Homak）為妻、賜扎里爾的宅邸與伊朗軍權。在場的成年將領無人應聲；只有扎里爾約七歲的兒子巴斯瓦爾（Bastwar）站起來，要求備馬，說要去看看父親是死是活。國王拒絕：他年紀尚幼，手指還未磨出拉弓的繭，不懂戰場的謹慎，萬一被殺，敵人便會同時得到「殺了伊朗統帥」與「殺了統帥之子」兩項功勞。

巴斯瓦爾私下說服掌馬人，騎上父親生前乘坐的馬，一路殺到發現父親遺體的地方。他對著沉默的父親哭喊，追問為何不再回話、為何戰馬也不再嘶鳴。他返回見國王，再次請求復仇；賈馬斯普出面背書，稱這孩子「依靠自己的運氣，必能殺敵」。國王終於備馬，從自己的箭袋取出一支箭賜他，祝福他在攻守諸役中得勝，並授予他指揮伊朗與羅姆聯軍的權柄。

### 亡魂的聲音與正面的箭

維德拉夫什再度從背後偷襲。巴斯瓦爾回頭喝罵，要他正面過來，讓自己用父親教過的弓箭決勝；扎里爾的坐騎聽見呼喝，四蹄踏地，發出九百九十九聲嘶鳴。魔法師拔出那件地獄武器，巴斯瓦爾把它奪下。此刻，扎里爾的靈魂出聲吩咐：「丟掉那武器，拿箭袋裡的箭回敬他。」孩子依言射出一箭，箭穿過維德拉夫什的心臟與背部，把他釘死在地上。巴斯瓦爾取下父親那雙綴珍珠與黃金的白靴，騎父親的馬繼續追擊。

戰役由國王之子斯潘達德（Spandyād，即《阿維斯塔》的Spəntōδāta、《王書》的埃斯凡迪亞爾）收尾：他擒住阿爾賈斯普，砍去一手一足、割去一耳、火灼一眼，再把這位倖存的國王騎著斷尾驢送回本國。值得注意的是，《王書》把殺死維德拉夫什的功勞給了埃斯凡迪亞爾（文中稱「納斯圖爾」），並把一日之戰改寫成一場有書信、演說與單挑的長期戰役；這正是口傳史詩在寫定過程中被貴族英雄吸收的案例。

## 主題分析

第一層是「年齡與授權」。巴斯瓦爾先被國王以「手指未磨出繭」為由拒絕，卻在同一次對話中取得父親的馬、國王的箭與統帥的旗幟；復仇讓一個孩子越過成人的資格門檻。第二層是「武器的合法性」。害死扎里爾的是地獄鑄造、從背後使用的毒器；殺死魔法師的則是父親亡魂指定、正面射出的箭。史詩並非單純歌頌勝利，而是在區分「能殺人」與「有權殺人」。第三層是「紀念做為文本形式」：《扎里爾紀念》不以開天闢地或王室世系為主軸，而以一日的戰鬥、一段哭屍的哀歌和一次子承父志的復仇，把宗教共同體的邊界寫成可誦可記的詩。

## 跨文化對應

| 文化／文本 | 對應人物或母題 | 共通點與差異 |
|---|---|---|
| 伊朗《阿維斯塔》↔《扎里爾紀念》 | Zairivairi ↔ Zarēr、Bastavairi ↔ Bastwar | 同一組人物由頌歌的簡略暗示發展為帕赫拉維語史詩的完整復仇情節 |
| 希臘《伊利亞特》 | 帕特羅克洛斯 ↔ 阿基里斯 | 前線戰友之死引發不可逆的復仇；波斯版則由血親而非摯友接續 |
| 希臘悲劇《俄瑞斯忒斯》 | 阿伽門農 ↔ 俄瑞斯忒斯 | 子為父報仇的正當性辯論；巴斯瓦爾年僅七歲，沒有成年追責的司法場景 |
| 美索不達米亞《吉爾伽美什史詩》 | 恩奇都 ↔ 吉爾伽美什 | 同伴之死使英雄正視死亡；波斯版把哀慟立即轉為作戰指令 |
| 埃及《奧西里斯神話》 | 奧西里斯 ↔ 荷魯斯 | 父子相承的復仇；埃及以王權神化收束，伊朗以信仰共同體的存亡收束 |
| 希伯來《撒母耳記》 | 約拿單 ↔ 大衛 | 大衛的悼歌與巴斯瓦爾哭屍同屬公開哀悼的詩性技術，但前者不涉及復仇 |
| 印度《摩訶婆羅多》 | 阿比曼紐 ↔ 阿周那 | 兒子戰死後父親立誓復仇；波斯版反向由兒子繼承父親，顯示不同的家族軸向 |
| 中國《趙氏孤兒》 | 趙朔 ↔ 趙氏孤兒 | 幼子倖存並完成家族復仇；與巴斯瓦爾同以「年幼者終被授予行動權」為高潮 |
| 日本《曾我物語》 | 父祐泰 ↔ 曾我兄弟 | 兄弟為父復仇的中世武家敘事；波斯版更強調亡魂對武器選擇的指示 |
| 前伊斯蘭阿拉伯《巴蘇斯之戰》 | 巴蘇斯 ↔ 塔格利卜血親復仇 | 一樁殺害觸發長期血仇；波斯版把仇恨壓縮在一日之內並由王權正式蓋印 |
