# 阿爾達·維拉夫的升天之旅 (Ardā Wirāz Namāg)

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)

## 故事背景

《阿爾達·維拉夫之書》（Ardā Wirāz Namāg，意為「正直的維拉夫之書」）是薩珊王朝時期（約 3–6 世紀）成書的瑣羅亞斯德教經典。故事設定的時代背景是：波斯帝國經歷了亞歷山大大帝征服（公元前 330 年）與希臘化統治，大量瑣羅亞斯德教經典被焚毀或散佚。薩珊王朝復興祆教後，宗教領袖們為了確認教義的正確性，需要一位靈魂純淨如雪、從未犯過任何嚴重罪孽的祭司，前往彼岸世界見證天堂與地獄的真實景象，以印證教典。

## 情節

### 選拔與準備

宗教議會在各地尋訪德高望重的祭司。最終七位賢者一致選出阿爾達·維拉夫（Ardā Wirāz，意為「正直的維拉夫」）——一位終身獻身於聖火、從未違反戒律的虔誠祭司。維拉夫起初推辭，認為自己不足以承擔如此神聖的使命，但在眾賢者的懇求下接受了任務。儀式在阿扎爾·法蘭巴格聖火廟（Ādur Farnbāg）舉行——維拉夫飲下摻有曼德拉草與麻藥的聖酒（可能包含 Haoma 汁液），他的肉體被置於潔白的亞麻布上，靈魂出竅開始穿越神聖的宇宙階梯——Chinvat 橋。

### 穿越星空的三層天堂

維拉夫的靈魂由一位美麗的神聖化身——Daēnā（個人良知與信仰的女神）引領。在穿越 Chinvat 橋時，橋在義人腳下寬闊如九支長矛，在惡人腳下細如髮絲。維拉夫首先抵達星界（Hūmāt，善念之星），見到義人靈魂在此安息。第二站為月界（Hūxt，善言之星），居住著德行更高者。第三站為日界（Hvaršt，善行之星），屬於終身行善的信徒。

### 最高天堂：無限光明

第四站為 Garōdmāna（「歌之居所」，即最高天堂），阿胡拉·馬茲達居住於無限光明之中。在這裡維拉夫見到了七位阿梅沙·斯彭塔（Amesha Spenta）圍繞於創造主周圍，散發著比太陽耀眼萬倍的光芒。阿胡拉·馬茲達親自向維拉夫揭示了宇宙善惡鬥爭的完整圖景——從原始牛的犧牲到末日復活。維拉夫在一處神秘的「神聖根源」（Cihrdād）中看見了所有人的靈魂本質被預先決定，但同時賦予自由意志以選擇善惡。

### 地獄之遊

靈魂返程途中，維拉夫被引領參觀地獄（Duzakh）——安格拉·曼紐的黑暗深淵。他見證了各類靈魂的懲罰：貪婪者舌頭被毒蛇啃噬、說謊者倒吊於荊棘之上、暴君被投入熔鐵之河、不孝者永遠無法接近水源。最令維拉夫震驚的是那些「穿戴華服包裹聖火」的人——象徵表面虔誠卻內心腐敗的偽善者，在地獄最深處承受雙倍折磨。這一場景極具警惕意義，成為薩珊波斯道德教化的重要工具。

### 回歸人間

經過七天七夜的靈魂旅程，維拉夫返回肉體，醒後淚流滿面。他將所見景象詳細記錄——此記錄即《阿爾達·維拉夫之書》。此書確認了瑣羅亞斯德教的教義真確性，並警告世人遵循善思、善言、善行三大原則，否則將在死後面臨公正報應。維拉夫的故事不僅強化了祆教的倫理體系，也深刻影響了後來伊斯蘭教的審判日圖景與但丁《神曲》的結構構思。

## 跨文化平行

| 波斯 | 對應故事 | 文化 |
|-----|---------|------|
| 阿爾達·維拉夫在引導者 Daēnā 陪伴下穿越天堂與地獄 | 但丁由維吉爾與貝雅特麗齊引導穿越三界 | 義大利中世紀 |
| 靈魂穿越 Chinvat 橋，義人寬惡人窄 | 伊斯蘭教的綏拉特橋（Ṣirāṭ）審判 | 伊斯蘭 |
| 星界 → 月界 → 日界 → 無限光明的四層天堂 | 中國佛教三十三天與二十八天層級 | 印度/中國佛教 |
| Daēnā 為靈魂的神聖化身，映照生前善行 | 埃及《死者之書》在瑪亞特羽毛前秤心 | 古埃及 |
| 偽善者在地獄深處遭受最重懲罰 | 但丁《神曲·地獄篇》中「瀆職者」在地獄最深處 | 義大利 |
