# 魯斯塔姆與惡魔阿克萬——波斯英雄的深海試煉

- **文化：** 波斯神話（伊朗）

## 故事背景

魯斯塔姆（Rostam）是波斯民族史詩《王書》（Shahnameh）中最偉大的英雄，其傳奇事蹟構成了伊朗神話的核心篇章。在《王書》記載的魯斯塔姆「七項試煉」（Haft Khvān，七次偉大冒險）中，與惡魔阿克萬（Akvan / Aka Manah Div）的對決是最具象徵意義的一章。這個故事不僅展現了英雄的超凡武力，更深刻揭示了波斯神話中「智慧戰勝蠻力」的核心主題——魯斯塔姆在這個故事中第一次，也是唯一一次在純粹武力對決中落敗，最終依靠智謀與堅忍才化險為夷。菲爾多西（Ferdowsi）在《王書》中將此故事安排在魯斯塔姆最巔峰的時期，以凸顯即使是無敵英雄也必須面對失敗的殘酷命運。

## 情節

### 惡魔的陰謀

阿克萬（Akvan Div）是安格拉·曼紐（Angra Mainyu）麾下最狡詐的惡魔之一，其名在阿維斯塔語中意為「邪念」或「惡念」（Aka Manah），是瑣羅亞斯德教中試探人類墮落的原型力量。阿克萬長期觀察魯斯塔姆在圖蘭邊境的征戰，深感這位伊朗英雄的力量已經威脅到了惡魔對人間的控制。他決定設下陷阱——不是正面對決，而是以詭計將魯斯塔姆從伊朗的守護範圍中引開。

阿克萬化為一個牧羊人出現在魯斯塔姆的營地附近，故意散播謠言：一頭巨大的野豬正在山中肆虐，吞噬牧群與村民。魯斯塔姆聞訊立刻帶著忠馬拉赫什（Rakhsh）出發追獵——這是英雄的致命弱點：他的榮譽感使他無法對求救置之不理。當魯斯塔姆深入山區時，阿克萬現出原形——一個巨大的黑色惡魔，雙眼如燃燒的煤炭，雙翼遮蔽了半片天空。

### 被拋入大海

魯斯塔姆毫不畏懼地拔出神劍「米赫里甘」（Mihrgan）與阿克萬展開搏鬥。然而，阿克萬的力量超乎想像——他以巨爪抓住魯斯塔姆，振翅飛向高空，徑直飛往東方的無邊大海（Vourukaša，波斯神話中的原始大海）。在大海上空，阿克萬鬆開雙爪，將魯斯塔姆連人帶馬拋入深海。

這是《王書》中最震撼的場景之一：一位無敵的英雄在惡魔的力量面前完全無能為力，被拋入了波斯宇宙觀中與冥界同等危險的原始水域。菲爾多西在這裡打破了「英雄永遠戰勝」的敘事慣例，以一種近乎殘酷的真實性呈現了命運的無常——即使是魯斯塔姆，也無法逃脫失敗的時刻。魯斯塔姆在墜海時抓住了拉赫什的鬃毛，與忠馬一起在怒濤中載浮載沉。

### 海島求生

幸運的是，海流將魯斯塔姆與拉赫什沖到了一座無名海島上。這座海島被描述為一個荒涼而詭異的地方——有森林、有水源，但沒有人類的蹤跡。魯斯塔姆在島上度過了漫長的日子，他用樹枝搭建 shelter、以野果為食、每日在海邊祈禱阿胡拉·馬茲達的庇護。

在這段流放期間，魯斯塔姆展現了與戰場上完全不同的品質：耐心、謙卑與自省。他反思了自己過去的驕傲與征戰，在孤獨中重新理解了英雄的本質——力量只是工具，堅忍才是品格。波斯學者認為這段情節可能受到了瑣羅亞斯德教「沉默之年」（Yazna-ye Khūshk）修煉傳統的影響——先知瑣羅亞斯德在接受神聖啟示後也曾經歷十年的沉默修煉期。

### 奇蹟般歸來

經過漫長的等待，魯斯塔姆決定冒險離開海島。他為拉赫什編了一個簡易的木筏（一說是用島上的樹木建造了一艘小船），然後在一個暴風雨之夜揚帆出海。命運之神（Baxt）與阿胡拉·馬茲達的旨意共同作用——海流奇蹟般地將他們送回了伊朗海岸。魯斯塔姆抵達陸地後的第一件事是向聖火獻祭感恩，然後立刻出發尋找阿克萬。

### 最終復仇

魯斯塔姆在山區的一個洞穴中找到了正在沉睡的阿克萬。惡魔以為魯斯塔姆早已葬身海底，毫無防備。魯斯塔姆沒有猶豫——他拔出米赫里甘神劍，一劍斬下了阿克萬的頭顱。然而，即使是死亡也無法完全消滅這個惡魔：阿克萬的頭顱在地上翻滾時仍然發出嘲諷的笑聲，因為惡魔在瑣羅亞斯德教的宇宙觀中是無法被真正「消滅」的——它們只能被暫時擊退，直到弗拉肖凱雷提（Frashokereti，宇宙最終更新）之時才會被徹底消滅。

魯斯塔姆將阿克萬的頭顱帶回伊朗，獻給了國王凱·卡烏斯（Kay Kavus）。國王以盛大的儀式慶祝英雄的歸來，而魯斯塔姆在慶功宴上只說了一句話：「沒有任何人能永遠站在頂峰——但真正的英雄是那些在跌落後仍然能站起來的人。」（《王書》，菲爾多西）

## 跨文化平行

| 文明 | 故事 | 共同母題 |
|------|------|----------|
| 希臘 | 奧德修斯 (Odysseus) 海上漂流 | 英雄被神魔力量拋入大海，在海島上流放後歸來 |
| 希臘 | 赫拉克勒斯 (Heracles) 深海冒險 | 英雄進入深海執行不可能任務，最終成功歸來 |
| 北歐 | 西格爾德 (Sigurd) 屠龍 | 英雄斬殺惡龍獲得寶藏與榮耀 |
| 印度 | 阿周那 (Arjuna) 流放森林 | 英雄在流放中經歷內在轉化，歸來後更強大 |
| 中國 | 孫悟空被壓五行山 | 英雄因驕傲受懲罰，在壓制中反思後獲得真正力量 |
| 日本 | 伊邪那岐 (Izanagi) 逃離黃泉 | 英雄逃離死亡國度，經歷潔淨儀式後重生 |

這個故事的核心母題是「英雄的深海流放」（Katabasis / Descent），在世界神話中反覆出現：英雄被超自然力量拋入水界/冥界，在那裡經歷死亡與重生的象徵性體驗，歸來後獲得更高的智慧與力量。與奧德修斯的區別在於：奧德修斯是被神送回家鄉，魯斯塔姆則是完全依靠自己的力量歸來——這反映了波斯神話中對個人勇氣與堅忍的特殊重視。
