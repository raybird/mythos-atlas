# 扎里爾 (Zarir / Zarēr)

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **職掌：** 伊朗勇士英雄、戰士榜樣、忠誠與犧牲的化身
- **象徵：** 戰矛、烈火盔甲、馬背戰士
- **聖典記載：** 《阿維斯塔》〈扎爾〉頌歌（Zarēr Yasht / Yasht 14）、菲爾多西《王書》（Shahnameh）

## 概述

扎里爾（阿維斯塔語 Zarēr，中古波斯語 Zāl / Zāryār）是波斯神話中伊朗與圖蘭戰爭（Iranian-Turanian Wars）最傳奇的英雄之一，被譽為「伊朗之矛」。他是努扎爾（Nōzar / Nowzar）之子、凱·古什塔斯帕（Kay Vishtāspa）的兄弟，在與圖蘭之王阿弗拉西亞布（Afrāsiyāb）的長年戰爭中擔任伊朗軍隊的前鋒指揮官。扎里爾的英勇事蹟主要見於《阿維斯塔》第十四卷〈扎爾頌〉（Zarēr Yasht）與菲爾多西《王書》中「凱·古什塔斯帕的時代」章節，是瑣羅亞斯德教英雄傳統的核心組成部分。

扎里爾的名字詞根與古波斯語 *zara-*（金色、榮耀）相關，暗示他同時是軍事英雄與神聖光輝（Xvarenah）的承載者。在瑣羅亞斯德教的宇宙觀中，扎里爾代表阿沙（Asha，真理與秩序）在戰場上的化身——他對抗的不只是圖蘭的軍隊，更是安格拉·曼紐（Angra Mainyu）透過阿弗拉西亞布所釋放的黑暗力量。

## 神話事蹟

### 扎里爾與阿弗拉西亞布的決戰

扎里爾最著名的神話事蹟是他與圖蘭之王阿弗拉西亞布在巴赫曼（Bahman）草原上的最終決戰。根據《扎爾頌》的記述，阿弗拉西亞布率領大軍入侵伊朗，扎里爾被指派為前鋒。戰鬥異常激烈——扎里爾先後擊殺了多名圖蘭猛將，包括阿弗拉西亞布之子弗里揚（Fryān）和兄弟格里瓦斯瓦（Gərəvaspa）。

在戰鬥的最高潮，扎里爾與阿弗拉西亞布正面交鋒。阿弗拉西亞布以詭計射出一支被邪惡魔法加持的箭，射中扎里爾的咽喉。扎里爾倒下前仍高喊激勵伊朗士兵的口號。他的死並非失敗，而是神聖犧牲——根據瑣羅亞斯德教的末世論，扎里爾的靈魂將在世界末日（Frashokereti）時復活，並在索什揚特（Saoshyant）的最終戰役中率領正義之師。

### 烈火中的復仇

扎里爾之死在伊朗營中引發了巨大的悲痛。他的姪子——年輕的埃斯凡迪亞爾（Esfandiyār）——誓言為叔叔復仇。扎里爾的犧牲成為推動伊朗英雄世代更替的關鍵事件：扎里爾代表的是第一代英雄的純粹武勇，而下一代英雄（如魯斯塔姆 Rostām）則繼承了他的戰矛與使命，但增添了更多複雜的道德抉擇。

在瑣羅亞斯德教的儀式傳統中，扎里爾被尊為「戰死者的典範」——在波斯新年（Nowruz）期間的 Khvarenah（神聖光輝）祈禱中，扎里爾的名字與伽亞馬特（Gayōmaretan）和查拉圖斯特拉（Zarathustra）並列，象徵著犧牲、真理與光輝的三位一體。

## 跨文化對應

| 文化 | 對應英雄/概念 | 共通點 |
|------|--------------|--------|
| 希臘 | 帕特羅克洛斯 (Patroclus) | 前線英雄之死引發連鎖復仇、戰士之間的兄弟情誼 |
| 北歐 | 巴德爾 (Baldr) | 純潔之神的犧牲引發世界末日、死後復活承諾 |
| 印度 | 阿周那 (Arjuna) | 神聖戰士在正法之戰中擔任前鋒、犧牲作為宇宙秩序的維繫 |
| 蘇美 | 吉爾伽美什的伙伴恩奇都 (Enkidu) | 英雄之死驅動敘事轉折、對永生/復活的追問 |
| 埃及 | 荷魯斯 (Horus) | 以武力為父報仇、神聖戰士的使命傳承 |
| 中國 | 關雲長 | 忠義武將的典範、死後升格為神明 |

## 相關神祇/英雄

- Afrasiyab（阿弗拉西亞布）：宿敵，圖蘭之王，安格拉·曼紐的代理人
- Esfandiyār（埃斯凡迪亞爾）：姪子，為扎里爾復仇的下一代英雄
- Rostām（魯斯塔姆）：繼承扎里爾戰矛的最偉大波斯英雄
- Kay Vishtāsp（凱·古什塔斯帕）：扎里爾效忠的伊朗國王、瑣羅亞斯德教的護教者
- Zarathustra（查拉圖斯特拉）：扎里爾時代的先知，為伊朗戰士提供精神指引
