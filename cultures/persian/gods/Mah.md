# 瑪赫 (Mah)

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **職掌：** 月亮、月份、時間循環、夜晚守護
- **象徵：** 新月、銀色光輝、天體運行軌道
- **聖數：** 12（一年之月數）、28/29（月相週期）

## 概述

瑪赫（阿維斯塔語 Māh，中古波斯語 Māh，直譯即「月亮」）是瑣羅亞斯德教萬神殿中掌管月亮的亞扎塔（Yazata，值得崇拜者）。在《阿維斯塔》中瑪赫擁有一部專屬的頌歌（Yasht 7，〈月亮頌〉Māh Yasht），其中描述他為「擁有公牛光輝的月亮」——這在索羅亞斯德的宇宙觀中有深刻的農業象徵：月亮的盈虧被視為影響牲畜繁殖與植物生長的關鍵力量。瑪赫被稱為「房屋的贈予者」與「財富的分發者」，因為月光在夜晚為世界帶來光明，他的光輝具有驅逐黑暗惡魔的力量。在瑣羅亞斯德教的曆法中，每一個月都以一位亞扎塔命名——瑪赫不僅是月亮本身，更守護著一年中每個月份的自然秩序。

## 神話事蹟

〈月亮頌〉（Yasht 7）詳細描述了瑪赫的職能與地位。日出之時，太陽神赫瓦雷·赫沙埃塔（Hvare-khshaeta）驅散黑暗；但在夜晚，月亮承擔起照亮黑暗的任務。瑪赫以三種形態展現：新月（上弦月之始）、滿月（力量巔峰）、虧月（衰減與重生）。這三個階段在《阿維斯塔》中被描繪為「月亮的公牛光輝」的三種狀態——公牛在波斯神話中象徵豐饒與生命力，月亮的陰晴圓對應著生命力的漲落。瑪赫也被認為是星體三位一體的一部分：太陽赫瓦雷·赫沙埃塔、月亮瑪赫、星辰提什特里亞（Tishtrya，天狼星）共同守護蒼穹，對抗安格拉·曼紐的黑暗勢力。在波斯宇宙論中，安格拉·曼紐入侵世界時首先攻擊的就是天空中的光明——瑪赫正面對抗來自黑暗的邪魔，他的光輝不僅是自然的物理現象，更是善神抵抗邪惡的宇宙戰場。在後世的波斯民間信仰中，瑪赫與巫術、占星密切相關——新月之夜被認為是魔法儀式與占卜的最佳時刻，這種傳統一直延續到伊斯蘭化後的波斯文化中。

| 文化 | 對應神祇 | 共通點 |

| 希臘 | 塞勒涅（Selene） | 月神、銀色戰車巡天、與太陽神為兄妹 |
| 希臘 | 阿緹蜜絲（Artemis） | 月亮與狩獵女神、新月象徵、夜晚守護 |
| 埃及 | 托特（Thoth） | 月神、時間與曆法之神、智慧書寫 |
| 印度 | 旃陀羅（Chandra） | 月神、銀色戰車、掌管植物生長與豐饒 |
| 中國 | 嫦娥（Chang'e） | 月宮女神、不死藥、月相周期象徵 |
| 日本 | 月讀命（Tsukuyomi） | 月神、夜晚統治、天地秩序 |

## 相關神祇

- Hvare-khshaeta（赫瓦雷·赫沙埃塔）：太陽神，瑪赫在天空的對應同伴
- Tishtrya（提什特里亞）：天狼星神，瑪赫的星辰戰友
- Anahita（阿娜希塔）：水神，月亮影響潮汐的關聯者
- Amesha Spenta（阿梅沙·斯彭塔）：六大聖者，瑪赫協助其維護宇宙秩序

## 出現在

- 《阿維斯塔》：〈月亮頌〉（Yasht 7）專文
