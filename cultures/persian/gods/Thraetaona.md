# 瑟萊塔歐納 (Thraētaona / Freydun / Fereydun)

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **職掌：** 龍蛇屠殺者、正義復仇者、王權恢復者、民族英雄
- **象徵：** 三叉戟、公牛皮盾、龍血寶劍、鳳凰（Sēnmurv）
- **其他名稱：** 弗雷敦 (Fereydun，《王書》)、弗里丹 (Freydun)、阿維斯塔語 Thraētaona（「治療者之子」）

## 概述

瑟萊塔歐納是伊朗神話中最重要的英雄之一，其地位可比擬為波斯版的赫拉克勒斯（Heracles）與聖喬治（St. George）的合體。他是人類始祖蓋尤瑪爾特（Gayōmaretan）的後裔，維萬格漢特（Vivanghant）之子，因屠殺三首蛇王扎哈克（Zahhāk / Aži Dahāka）而成為正義的永恆象徵。瑟萊塔歐納的名字在阿維斯塔語中意為「治療者的兒子」，暗示他的屠蛇行為具有宇宙性的淨化與療癒功能——蛇在伊朗傳統中不僅是物理威脅，更是謊言（Druj）與疾病的化身。在菲爾多西的《王書》（Shahnameh）中，他以「弗雷敦」（Fereydun）的形象出現，被塑造為推翻暴政、建立公正王權的理想君主。瑟萊塔歐納的故事貫穿了從《阿維斯塔》最古老的〈耶什特〉（Yasht）文獻到薩珊王朝的宫廷史詩，是波斯文化中「屠龍英雄」原型的核心載體。

## 神話事蹟

### 扎哈克的暴政

要理解瑟萊塔歐納的英雄意義，必須先理解扎哈克的恐怖統治。根據〈萬迪達德〉（Vendidad）與《王書》的記述，扎哈克原為阿拉伯王子，受安格拉·曼紐（Ahriman）誘惑——魔鬼化身廚師親吻他的雙肩，從傷口處長出兩條毒蛇，每日必須以兩名青年的腦髓餵養。扎哈克以蛇的飢餓為藉口統治世界長達一千年，在這段時期中，真理與正義從世間消失，人類生活在永恆的恐懼中。

瑟萊塔歐納的父親維萬格漢特是扎哈克統治下的少數倖存者之一。在扎哈克的暴政中，維萬格漢特被指派為「養蛇人」——負責每日捕捉青年送往宮殿餵蛇。這個職位雖然使他免於一死，卻讓他承受了無盡的道德折磨。

### 屠蛇之戰

瑟萊塔歐納在目睹扎哈克的暴行後，決定起義反抗。根據〈耶什特〉第19篇（Zamyad Yasht）的記述，瑟萊塔歐納以一頭神聖的公牛的皮革製成盾牌，手持三叉戟，獨自闖入扎哈克的宮殿。在激烈的戰鬥中，瑟萊塔歐納用三叉戟刺穿了扎哈克的三顆蛇首——每刺穿一顆，蛇頭便不再重生。扎哈克本人被生擒，瑟萊塔歐納將其鎖鏈束縛於德馬萬德山（Damavand）的深谷中。

《王書》的版本更為戲劇化：弗雷敦（瑟萊塔歐納）在戰鬥中使用了一把名為「阿弗拉西亞布之劍」的神兵，此劍由神鑄造，專門用於屠殺邪惡。弗雷敦在戰鬥中大喊：「以正義之名，我將結束你的千年暴政！」蛇王被擊敗後，弗雷敦沒有殺死他——而是將他永遠囚禁於山中，等待世界末日（Frashokereti）時再做最終審判。這個「囚禁而非殺死」的處理方式具有深刻的神學意義：在瑣羅亞斯德教中，邪惡不是被「消滅」的，而是被「束縛」直到最終更新之時。

### 王權的恢復與後代

擊敗扎哈克後，瑟萊塔歐納成為世界的統治者。他建立了公正的王權，恢復了被扎哈克壓制的祭火崇拜，並重新劃分了世界——將大地分為七個地區（heptad），每個區域由他的後代統治。瑟萊塔歐納有三個兒子：萨勒姆（Salm）、圖爾（Tūr）與伊利j（Iraj）。在《王書》中，三兄弟因爭奪繼承權而反目——萨勒姆與圖爾合謀殺害了最小的弟弟伊利j。瑟萊塔歐納因此陷入深深的悲痛，他的王權最終由伊利j的後代（即伊朗人的先祖）繼承。

## 跨文化對應

| 文化 | 對應英雄 | 共通點 |
|------|----------|--------|
| 希臘 | 赫拉克勒斯 (Heracles) | 屠龍/蛇、多項試煉、半神英雄、死後升天 |
| 北歐 | 齊格弗里德 (Siegfried) / 西格爾德 (Sigurd) | 屠龍、飲龍血獲得超能力、英雄悲劇結局 |
| 印度 | 克利希那 (Krishna) / 因陀羅 (Indra) | 屠蛇（克利希那殺Kāliya、因陀羅殺弗栗多） |
| 美索不達米亞 | 吉爾伽美什 (Gilgamesh) | 屠天牛、追求永生、英雄歷險 |
| 基督教 | 聖喬治 (St. George) | 屠龍拯救公主/人民、正義戰勝邪惡的象徵 |
| 中國 | 后羿射日 / 大禹治水 | 屠殺危害人類的怪物/自然力量、恢復秩序 |

瑟萊塔歐納的屠龍母題是印歐神話中最古老的英雄原型之一——語言學家已證明阿維斯塔語「Thraētaona」與梵語「Trita Āptya」同源，後者在《梨俱吠陀》中也是一位屠殺巨蛇弗栗多（Vṛtra）的英雄。這意味著瑟萊塔歐納與因陀羅屠龍的故事可以追溯到公元前 2000 年左右的原始印歐語時期（West 2007: 144–146）。

## 相關神祇

- **扎哈克 (Zahhāk / Aži Dahāka)**：瑟萊塔歐納的主要對手，三首蛇王，邪惡的化身
- **蓋尤瑪爾特 (Gayōmaretan)**：人類始祖，瑟萊塔歐納的先祖
- **維萬格漢特 (Vivanghant)**：瑟萊塔歐納之父，扎哈克統治下的養蛇人
- **凱·霍斯魯 (Kay Khosrow)**：瑟萊塔歐納的後代之一，《王書》中的賢王
- **魯斯塔姆 (Rostam)**：後世的屠龍英雄，延續了瑟萊塔歐納的屠蛇傳統
