# 阿科曼 (Akōman / Akoman) — 惡念之魔

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **職掌：** 惡念、邪惡思想、欺騙、心理操弄
- **別名：** Akōman（阿維斯陀語「邪惡的思想」）、Akem Manah（中古波斯語）、اکمان（波斯語）
- **對立面：** 沃胡·瑪納 (Vohu Manah / 善念)，七位阿梅沙·斯彭塔之一

## 概述

阿科曼（Akōman，字面意為「邪惡的思想」）是瑣羅亞斯德教惡魔體系中地位最高、最具根本性的存在——他是七大阿達瓦（Daevas）之首，代表人類意識中最深層的墮落：不是憤怒、不是貪婪，而是**思想本身被腐化**。在瑣羅亞斯德教的宇宙觀中，阿科曼的對立面是阿胡拉·馬茲達創造的「善念」（Vohu Manah），兩者構成了意識層面善惡鬥爭的核心二元對立。

根據《丁卡爾德》（Dēnkard）第三卷的記載，阿科曼是安格拉·曼紐（Angra Mainyu，惡靈）所生的第一個兒子——他是邪惡意志的具體化身，也是所有其他惡魔的先驅。當阿胡拉·馬茲達在宇宙之初召見七位阿梅沙·斯彭塔（Amesha Spenta，不朽聖者）商議創造時，安格拉·曼紐也召見了他的七位阿達瓦，而阿科曼正是站在最前列的那位。

## 神話事蹟

### 創世之初的對抗

《本達希申》（Bundahišn）記載，在宇宙創造的最原初時刻，阿胡拉·馬茲達以善念（Vohu Manah）為媒介開始構想世界的藍圖，而安格拉·曼紐則以阿科曼為先鋒入侵光明世界。阿科曼的第一個行動是向初人伽約馬爾德（Gayōmard）注入惡念——他不是以物理力量攻擊，而是以思想感染的方式腐化了初人的意識。

根據《丁卡爾德》第三卷的系統記載，人類出生時遭受的三個惡魔攻擊序列是：首先阿科曼（惡念），其次是阿茲（Āz，貪婪），最後是布沙斯帕（Bushyasta，怠惰）。這三者構成了人類墮落的三階段：思想被惡念污染、心靈被貪婪控制、行動被怠惰阻止。

### 惡魔之首的會議

在《耶什特》（Yašt）的記載中，安格拉·曼紐在看到阿胡拉·馬茲達的創造完成後，從深淵中升起了他的七位阿達瓦。阿科曼站在最前列，他向安格拉·曼紐提議：「讓我進入那善的世界，以謊言腐化它。」安格拉·曼紐同意了，並賦予他力量。阿科曼進入光明世界後，第一件事就是觀察人類——他發現人類是唯一具有自由意志的存在，因此將攻擊的重點放在人類的內心。

這種「以思想感染為首」的攻擊模式，使阿科曼在瑣羅亞斯德教的惡魔學中佔有獨特地位。與其他以物理力量或自然災害為武器的惡魔不同，阿科曼是唯一一個直接針對人類意識的邪惡力量。

### 末日論中的角色

在瑣羅亞斯德教的末世論中，阿科曼將在世界末日（Frashokereti）到來時與他的對立面沃胡·瑪納展開最終對決。根據《本達希申》的記載，在最終更新之時，所有邪惡將被徹底消滅——阿科曼將被善念完全取代，人類的意識將獲得徹底的淨化，不再受惡念的侵擾。

## 跨文化對應

| 文化 | 對應角色 | 共同特徵 |
|------|---------|---------|
| 希伯來 | 撒旦 (Satan) | 試探者、以謊言誘惑人心的首席邪惡 |
| 希臘 | 厄里斯 (Eris) / 不和女神 | 以思想混亂而非物理力量製造衝突 |
| 印度 | 摩羅 (Māra) | 以欲望與妄念攻擊修行者的心靈 |
| 北歐 | 洛基 (Loki) 的詭計面向 | 以欺騙與操弄而非正面戰鬥 |
| 基督教 | 魔鬼的「三個試探」 | 在曠野中以思想誘惑耶稣，對應阿科曼對初人的思想攻擊 |
| 中國 | 心魔 | 修行中必須克服的內在邪念 |
| 佛教 | 五蓋（睡眠蓋、掉悔蓋等） | 阻礙正確思維的內在力量 |

阿科曼最獨特的跨文化意義在於他是**「思想的對立面」**——不是行為的對立面。在大多數宗教傳統中，邪惡首先表現為行為（殺戮、欺騙、破壞），但在瑣羅亞斯德教中，邪惡的根源是**錯誤的思想**。這種觀念與後來佛教的「無明」（Avidyā）以及斯多葛學派的「錯誤判斷」（false judgment）有著驚人的平行。

## 相關惡魔

- **安格拉·曼紐 (Angra Mainyu)** ——阿科曼的父親，邪惡的終極源頭
- **阿茲 (Āz)** ——貪婪之魔，阿科曼之後第二個攻擊初人的惡魔
- **布沙斯帕 (Bushyasta)** ——怠惰之魔，第三個攻擊初人的惡魔
- **塔羅馬伊蒂 (Tarōmaitī)** ——傲慢之魔，阿科曼的女性對立面（對應Spenta Armaiti）
