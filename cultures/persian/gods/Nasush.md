# 納舒什 (Nasush / Nasu)

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **職掌：** 腐敗、屍體污染、死亡之後的腐化、疾病
- **象徵：** 黑色蒼蠅群、腐爛的屍體、黑暗中的惡臭之風
- **對立面：** 儀式 purification（聖火、巴爾薩姆枝、牛尿）

## 概述

納舒什（Avestan 語 Nasuš，中古波斯語 Nasūsh）是瑣羅亞斯德教中最令人畏懼的惡魔之一——她掌管屍體的腐敗與污染。在《阿維斯塔》（Avesta）的《萬迪達德》（Vendidad）中，納舒什被描述為一具巨大的、散發惡臭的雌性暗影，一旦有人死亡，她便從北方的黑暗深淵（Duzakh）降臨，降落在屍體之上，使屍體開始腐爛。她的觸碰使一切變得不潔（nāspaša-），污染接觸屍體的人、土地與水源。因此，瑣羅亞斯德教的葬禮儀式（dakhma，曝屍場）極為複雜——屍體必須由犬（سگ، sag-dīh）與秃鷹啄食（「犬之審判」sag-dīh），而非埋葬或火化，以避免污染大地與聖火。

## 神話事蹟

### 納舒什的降臨

《萬迪達德》（Vendidad）第 7 章是描述納舒什最詳細的文獻。當一個人死去時，納舒什「從北方的黑暗中降臨，以一百種疾病的形式降落於屍體之上」。她使屍體在三天內開始腐爛，蛆蟲從她的眼睛、鼻子與口中爬出。她的存在使整個死亡場所（包括方圓數步內的土地）變得不潔。任何接觸屍體或其氣味的人都必須進行嚴格的 purification 儀式——以牛尿（gōmēz）與巴爾薩姆（barsam）枝條清洗身體，並誦讀特定的祈禱文。瑣羅亞斯德教徒相信，納舒什的腐敗力如此強大，以至一口她的「氣息」就能污染整片水源。

### 與死亡儀式的關係

瑣羅亞斯德教的「犬之審判」（sag-dīh）正是為了對抗納舒什的污染力。在曝屍場（dakhma 或astodān），訓練有素的狗被引導至屍體旁——犬的觸碰被認為能驅散納舒什的污染力量。犬的凝視（「犬之凝視」sag-dīh）是一種神聖的保護力量，它使納舒什離開屍體，防止腐敗擴散。在《萬迪達德》第 8 章中，瑣羅亞斯德問阿胡拉·馬茲達：「如何對抗納舒什？」阿胡拉·馬茲達回答：「以巴爾薩姆枝、以牛尿、以聖火、以正確的禱文。這是對抗屍腐之魔的四重防護。」

### 納舒什與疾病的連結

在瑣羅亞斯德教的醫學觀念中，納舒什不僅掌管屍體腐敗，更與活人的疾病密切相關。《萬迪達德》第 7 章列舉了「一百種疾病」——從皮膚病到發燒、從瘟疫到精神錯亂——都是納舒什的產物。當一個人生病時，人們相信是納舒什的觸碰正在侵蝕他的身體。因此，治療疾病不僅需要藥物，更需要精神 purification——誦讀聖火禱文、焚燒巴爾薩姆枝條以驅散納舒什的影響。

## 跨文化對應

| 波斯納舒什 | 對應概念/惡魔 | 文化 |
|-----------|-------------|------|
| 屍體腐敗女魔 | 阿努比斯（Anubis）——但方向相反：阿努比斯保護屍體，納舒什污染屍體 | 埃及 |
| 以疾病懲罰不潔者 | 以色列人因接觸屍體而被隔離（利未記 11-15 章） | 猶太 |
| 屍體污染觸犯神聖 | 約翰福音 19:31 逾越節前不願屍體留在十字架上 | 基督教 |
| 以動物驅散污染 | 印度教中以牛尿淨化的習俗（gau-mutra） | 印度 |
| 女性化的死亡與污染 | 死亡女神赫拉（Hel）的身體一半是活人一半是腐屍 | 北歐 |
| 疾病作為神聖懲罰 | 哈托爾（Hathor）/塞赫麥特（Sekhmet）以瘟疫懲罰人類 | 埃及 |

## 相關神祇/惡魔

- **安格拉·曼紐 (Angra Mainyu)**：納舒什的創造者，所有疾病的根源
- **阿卡·瑪納 (Aka Manah)**：邪念之魔——邪念使人忽視 purification，加劇納舒什的污染
- **阿沙·瓦希什塔 (Asha Vahishta)**：至真之神，其聖火對抗納舒什的腐敗
- **斯拉奧沙 (Sraosha)**：聽從天使，守護死者靈魂免受納舒什侵害
- **達埃納 (Daena)**：死後引導靈魂的良心女神，在 Chinvat 橋上等待義人
