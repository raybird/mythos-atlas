# 安達爾 (Andar / Indar) — 否認之魔

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **職掌：** 否認真理、欺瞞、宗教不信仰、動搖信仰的恶魔
- **象徵：** 黑暗面具、破碎的誓言、毒蛇
- **所屬：** 七大阿達瓦（Daevas）之一
- **對立面：** 阿沙·瓦希什塔 (Asha Vahishta / 至善真理)

## 概述

安達爾（阿維斯塔語 Andar，中古波斯語 Indar）是瑣羅亞斯德教惡魔體系中七大阿達瓦（Daevas）之一，代表「否認」——不是單純的謊言，而是對真理本身的存在性否定。安達爾的邪惡本質在於：他不製造假象，而是說服人們「真理根本不存在」。在《阿維斯塔》〈耶什特〉（Yasht）與〈萬迪達德〉（Vendidad）中，安達爾被描述為安格拉·曼紐（Angra Mainyu）創造的七位核心惡魔之一，與阿科曼（Akoman，惡念）、索魯（Sauru，欺騙）、塔洛馬伊蒂（Taromaiti，傲慢）、佐爾瓦（Zaurva，衰朽）、農海蒂亞（Naonhaithya，不信）和艾什瑪（Aeshma，憤怒）共同構成邪惡的完整光譜。

在瑣羅亞斯德教的道德宇宙觀中，安達爾的位置極為關鍵——他是「不信」（daēva-druz）的化身。阿胡拉·馬茲達創造世界時賦予人類自由意志，讓人類在真理（Asha）與謊言（Druj）之間自行選擇。安達爾的任務正是消除這種選擇的可能性——通過說服人類「沒有真理可言」，從根本上瓦解善惡選擇的基礎。這使得安達爾在七位阿達瓦中佔據了一個獨特的認識論位置：他不是攻擊真理，而是否認真理的可及性。

## 神話事蹟

### 否認之戰

〈耶什特〉記載，安格拉·曼紐創造安達爾時，賦予他「動搖一切信仰」的能力。安達爾的首要攻擊目標不是凡人，而是查拉圖斯特拉（Zarathustra）本人——因為先知是真理在人間的最高體現。在查拉圖斯特拉接受啟示後的早期傳道生涯中，安達爾多次以各種偽裝出現，試圖動搖他對阿胡拉·馬茲達的信仰。根據〈萬迪達德〉的記述，安達爾曾化裝為一位年邁的祭司，質疑查拉圖斯特拉的啟示來源：「你如何確定你聽到的是馬茲達的聲音，而非你自己內心的幻覺？」先知以火焰試煉回應——他跳入熊熊烈火中而毫髮無傷，以此證明他的信仰根基不可動搖。

### 對抗阿沙

安達爾的宿敵是阿沙·瓦希什塔（Asha Vahishta），即「至善真理」，阿胡拉·馬茲達的六大斯彭塔（Amesha Spenta）之一。在瑣羅亞斯德教的宇宙觀中，真理（Asha）是維繫宇宙秩序的核心法則——太陽依 Asha 升落，四季依 Asha 循環，人類社會依 Asha 維持正義。安達爾的存在目的正是摧毀這一秩序。在末世論中，當世界進入最後階段時，安達爾將率領不信者與懷疑者組成的軍隊，與阿沙的追隨者展開最終對決。然而，在索什揚特（Saoshyant）降臨後的最終淨化中，安達爾將被徹底消滅——不是被火焰燒毀（因為他是概念性的存在），而是被真理的完全實現所取代。

### 與安格拉·曼紐的差異

值得注意的是，安達爾與安格拉·曼紐（Ahriman）雖同屬邪惡陣營，但二者的邪惡本質有根本差異。安格拉·曼紐代表的是宇宙性的、本體論層面的邪惡——他是「惡靈」本身，是黑暗與毀滅的終極源頭。安達爾則代表認識論層面的邪惡——他動搖的是人們對真理的認知能力。這種區分使得安達爾在後世的伊斯蘭教魔鬼學（Shaytan/Iblis 的概念）與基督教撒旦學（Satan as the "father of lies"）中留下了深刻的印記——撒旦的核心邪惡不在於暴力，而在於欺騙與否認。

## 跨文化對應

| 安達爾 (Andar) | 對應存在 | 文化 |
|---|---|---|
| 否認真理的恶魔 | 撒旦 (Satan) —「謊言之父」 | 猶太—基督教 |
| 動搖信仰者 | 邪靈（Māra）— 誘惑佛陀放棄修行 | 佛教 |
| 否認因果的虛無主義 | 阿修羅（Asura）— 反秩序力量 | 印度教 |
| 偽裝成祭司的恶魔 | 洛基 (Loki) — 以欺騙瓦解神族秩序 | 北歐 |
| 毀滅真理的虛空 | 泰弗努特 (Tefnut) 反面 — 混沌 | 埃及 |

## 相關阿達瓦

- **阿科曼 (Akoman)**：惡念之魔，安達爾的上級——安達爾是阿科曼意志的執行者
- **索魯 (Sauru)**：欺騙之魔，與安達爾協作——安達爾提供否認，索魯提供偽裝
- **艾什瑪 (Aeshma)**：憤怒之魔，安達爾否認真理後，艾什瑪以暴力鞏固邪惡的統治
- **農海蒂亞 (Naonhaithya)**：不信之魔，與安達爾功能重疊但側重不同——安達爾是主動否認，農海蒂亞是被動不信
