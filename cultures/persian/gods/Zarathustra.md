# 瑣羅亞斯德 (Zarathustra / Zoroaster)

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **職掌：** 先知、祭司制度創立者、善惡之戰的人間代理人、宇宙更新的先驅
- **象徵：** 豪麻 (Haoma) 杯、聖火、白氈袍、公牛角冠
- **時代：** 傳統定年約西元前 1700–1000 年（學術爭議中）

## 概述

瑣羅亞斯德（阿維斯塔語 Zaraθuštra，中古波斯語 Zartosht，波斯語 Zardosht）是波斯神話與瑣羅亞斯德教的創始先知，也是人類宗教史上最具影響力的神秘人物之一。在瑣羅亞斯德教的宇宙觀中，他不僅僅是一位歷史上的宗教改革者——他是阿胡拉·馬茲達 (Ahura Mazda) 親自揀選的「唯一先知」，在物質世界創造之前即已存在於光明之中，其神聖光輝 (Khvarenah) 在宇宙誕生前即被賦予。

在《阿維斯塔》的〈耶斯納〉(Yasna) 加薩讚美詩中，瑣羅亞斯德以第一人稱記述了自己接受神聖啟示的經歷：他在三十歲時於雛德拉河 (Dāitya) 畔接受了沃胡·瑪納 (Vohu Manah，善思) 的第一次異象，從此踏上了長達數十年的傳道之路。他不是被動的接受者，而是一位積極的宇宙戰士——以禱告為武器、以豪麻祭為儀式力量，直接對抗安格拉·曼紐 (Angra Mainyu) 的惡魔大軍。

## 神話事蹟

### 三十年異象與神聖啟示

根據〈耶斯納〉的自我敘述，瑣羅亞斯德出生於貴族家庭，自幼對宇宙的根本問題充滿疑問：「何為善？何為惡？世界為何存在苦難？」在三十歲那年，他來到雛德拉河畔進行晨間洗禮。沃胡·瑪納以一個巨大光明存在的形象降臨，帶領他穿越七重天界，依次見證了阿胡拉·馬茲達創造的六大存在：天空、水、大地、植物、動物、人類。每一重天界都有一位阿梅沙·斯彭塔 (Amesha Spenta) 守護，他們分別是：沃胡·瑪納、阿沙·瓦希什塔 (Asha Vahishta)、斯彭塔·阿爾馬伊蒂 (Spenta Armaiti)、赫瓦雷特·瓦伊里亞 (Khshatra Vairya)、瓦南特 (Vanant) 與赫烏爾瓦塔特 (Haurvatat)。在第七重天界，瑣羅亞斯德見到了阿胡拉·馬茲達本人——一個純粹的光明存在，不具形象卻無處不在。阿胡拉·馬茲達授予他宇宙的根本真理：善惡的鬥爭是宇宙存在的本質，而人類的使命是站在善的一方。

### 十年之忍耐與惡魔試煉

瑣羅亞斯德接受啟示後，安格拉·曼紐立刻派遣惡魔群試圖腐化他。最著名的試煉記錄在〈耶斯納〉第30章與〈萬迪達德〉(Vendidad) 中：惡魔阿格雷思 (Aka Manah，惡念) 以三種形態試圖引誘瑣羅亞斯德——首先以財富與權力，其次以美色與享樂，最後以恐嚇與威脅。瑣羅亞斯德以三聲「阿舍·瓦赫什塔！」(Asha Vahishta!，至善之真理!) 擊退了所有試煉。阿胡拉·馬茲達隨即賜予他三件神聖器物：金劍（斬斷謊言）、白氈袍（淨化不潔）與豪麻杯（賜予先知力量）。此後的十年中，瑣羅亞斯德以「沉默之年」的方式進行內在修煉，直到三十歲時正式開始向世人傳道。

### 與圖蘭國王圖魯納的對決

瑣羅亞斯德最戲劇性的神話對決之一發生在與圖蘭國王圖魯納 (Durēsruva / Tūra) 的衝突中。圖魯納是安格拉·曼紐的人間代理人，他在阿弗拉西亞布 (Afrāsiyāb) 的影響下，下令處決瑣羅亞斯德。惡魔達哈卡 (Dahāka) 指示圖魯納以毒酒殺害先知——但瑣羅亞斯德識破了陰謀，反而將毒酒潑向達哈卡，灼傷了這位蛇王的雙眼。在另一個版本中，瑣羅亞斯德被押赴火刑，但聖火主動退避不願焚燒先知，火焰在他周圍形成一個保護圈，圖魯納的士兵反而被火光灼瞎。

### 普世的未來角色：索什揚特 (Saoshyant)

在瑣羅亞斯德教的末世論中，瑣羅亞斯德的故事並未在死亡時結束。根據〈耶什特〉(Yasht) 第19章的預言，瑣羅亞斯德在死前與一位處女在雛德拉河中行神聖交合 (Yaonāhvarana)，其精子在河中保存千年。在世界末日之際，這份神聖精子將轉化為索什揚特 (Saoshyant，「拯救者」)，他將喚醒所有死者、引領最終的善惡決戰、並帶來弗拉肖凱雷提 (Frashokereti，宇宙最終更新)。瑣羅亞斯德因此不僅是過去的先知，更是未來救贖的神聖源頭——他的存在貫穿了波斯宇宙觀的整個時間軸。

## 跨文化對應

| 文化 | 對應人物 | 共通點 |
|------|----------|--------|
| 猶太教 | 摩西 (Moses) | 接受至高神啟示、立法者、引領民族脫離苦難 |
| 印度教 | 摩奴 (Manu) | 洪水前的義人、文明重建者、神聖律法的傳遞者 |
| 埃及 | 伊姆霍特普 (Imhotep) | 智者、祭司、醫者、建築師、死後被神化 |
| 中國 | 老子/莊子 | 追求宇宙根本真理、建立倫理體系、神聖人物的傳奇化 |
| 基督教 | 耶穌基督 (Jesus Christ) | 受魔鬼試煉、最終救贖者、末世再臨 |
| 希臘 | 奧菲斯 (Orpheus) | 奧菲斯教的創立者，以歌唱與音樂傳遞神聖知識 |
| 伊斯蘭 | 穆罕默德 (Muhammad) | 接受唯一神的啟示、建立新宗教體系、先知傳統的終結者 |

瑣羅亞斯德在跨文化比較中的獨特地位在於：他是「唯一已知的古代先知，其原始宗教文獻至今仍被活態宗教社群使用」。摩西的原始文獻已被猶太教傳統多重改編，摩奴的吠陀文獻經歷了數千年層累，而《阿維斯塔》保留了公元前1000年左右的宗教儀式與神學核心。

## 相關神祇

- **Ahura Mazda（阿胡拉·馬茲達）**：瑣羅亞斯德的啟示者與宇宙創造者
- **Vohu Manah（沃胡·瑪納）**：善思，首次異象的引領者
- **Angra Mainyu（安格拉·曼紐）**：瑣羅亞斯德在人間與之對抗的惡之根源
- **Haoma（豪麻）**：神聖植物，瑣羅亞斯德祭祀體系的核心
- **Sraosha（斯勞沙）**：聽從之神，瑣羅亞斯德與神之間的永恆中介
