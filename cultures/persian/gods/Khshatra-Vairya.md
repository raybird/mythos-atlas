# 赫沙特拉·瓦伊里亞 (Khshathra Vairya / Shahrevar)

- **文化：** 波斯祆教神話 (Persian Zoroastrian Mythology)
- **職掌：** 理想王權、金屬、力量、神聖統治
- **象徵：** 金屬權杖、寶劍、黃金王座、鋼鐵之城
- **中古波斯名：** 沙赫雷瓦爾 (Shahrevar / Shahrivar)，意為「理想的王國」
- **對立魔靈：** 埃什瑪 (Aeshma，暴怒之魔)

## 概述

赫沙特拉·瓦伊里亞（阿維斯塔語：Xšaθra Vairya，意為「可渴望的統治」或「理想的王國」）是祆教七大阿梅沙·斯彭塔（Amesha Spenta，神聖不朽者）中的第三位，代表阿胡拉·馬茲達的神聖權能與完美統治。在祆教的宇宙秩序中，赫沙特拉掌管金屬領域——從最堅硬的鋼鐵到最柔軟的金銀——金屬既是武器（用以擊退邪惡），也是文明進步的物質基礎。中古波斯語稱之為沙赫雷瓦爾（Shahrivar），意為「理想的城市」或「神聖王國」，這一名稱在現代波斯曆法中作為六月之名保留至今。

赫沙特拉的神學定位極為特殊：他不僅是一位聖靈，更是終末更新（Frashokereti）時將降臨於世的神聖秩序的預表。當信徒以真理與善念行事時，他們就在世界上實踐赫沙特拉——使塵世逐漸接近天國的完美王權。

## 神話事蹟

### 金屬的守護者

在《班達希申》（Bundahishn）的創世敘事中，赫沙特拉被分配守護金屬領域。金屬的象徵意義在祆教中具有深層的二元性：一方面，金屬是武器與盔甲的原料，用以對抗安格拉·曼紐（Angra Mainyu）的黑暗勢力；另一方面，金屬也象徵純淨、堅定與不可動搖的真理。祆教經典描述，在終末審判中，山脈將融化為滾燙的金屬河流，所有靈魂必須涉過——義人感到如同溫水，惡人則遭受灼燒的痛苦。這條金屬河流最終淨化地獄，使一切歸於神聖秩序。赫沙特拉在此過程中扮演裁決者的角色，金屬成為真理與謊言之間最終分界的手段。

### 與暴怒之魔的永恆鬥爭

赫沙特拉的永恆敵手是埃什瑪（Aeshma，中古波斯語：Khashm），即暴怒與破壞之魔。埃什瑪是煽動戰爭、屠殺與狂暴的惡魔，在《阿維斯塔》中被描述為「染血的長矛」、「滿懷猙獰的毀滅者」。赫沙特拉代表的是有紀律的力量——以正義為目的、以智慧為引導的權能，而埃什瑪則是盲目的、無差別的破壞衝動。兩者的對立體現了祆教一個重要命題：權力本身並非邪惡，但脫離正義（Asha）約束的權力即淪為暴怒。由此，赫沙特拉的神話本質上是一部關於「正確使用力量」的教訓。

### 與人類的關係

赫沙特拉尤其關心統治者與社會秩序。在祆教倫理中，國王被視為赫沙特拉在人間的代表——其職責是以正義統治、保護弱者、抵抗外敵。薩珊王朝的官方意識形態將「王權之光」（xvarenah）與赫沙特拉的庇佑緊密聯繫：正義的君主受赫沙特拉護持，暴君則失去神聖光輝。菲爾多西的《王書》中反覆出現的主題——正義之君帶來繁榮、暴虐之君導致亡國——正是赫沙特拉神學的史詩化表達。赫沙特拉同時也是一位護佑貧弱者與受壓迫者的聖靈：在《阿維斯塔・加薩》中，赫沙特拉被稱為「關懷窮人者的保護者」，這使他成為社會正義的神聖保證。

## 跨文化對應

| 文化 | 對應神祇/概念 | 共通點 |
|------|-------------|--------|
| 印度吠陀 | 因陀羅 (Indra) | 戰神、王權守護、雷霆力量；因陀羅的「金剛杵」（vajra）與赫沙特拉的金屬象徵相呼應 |
| 希臘 | 宙斯 (Zeus) 與其王權 | 神聖統治權、正義與力量的結合、人間君主的神聖授權 |
| 北歐 | 提爾 (Týr) | 戰神與正義之神、誓言守護、犧牲右手的象徵有助理解赫沙特拉的「正義力量」內涵 |
| 埃及 | 荷魯斯 (Horus) | 王權之神、法老的神聖血統繼承、正義（瑪亞特）的維護者 |
| 中國 | 黃帝 | 為正義而戰的文明君主、中央之帝、馴服金屬（鑄鼎）與建立秩序的神話功能高度一致 |
| 美索不達米亞 | 馬爾杜克 (Marduk) | 以力量擊敗混沌（提亞瑪特）、建立宇宙秩序、正義之君的原型 |

赫沙特拉在類型學中最突出的特點是「力量必須服從於真理」——這一點與因陀羅、宙斯等戰神有所不同：後二者有時展現出任性或情緒化的特質（如宙斯的風流，因陀羅的酗酒），而赫沙特拉始終代表著規範化的力量。這與祆教深刻的倫理二元論傳統密不可分。

## 相關神祇

- **Ahura Mazda（阿胡拉·馬茲達）**：至高主，赫沙特拉的神聖權能來源
- **Asha Vahishta（阿沙·瓦希什塔）**：真理至聖，赫沙特拉的統治必須以真理為前提
- **Vohu Manah（沃胡·馬納）**：善心，智慧引導力量的運用
- **Spenta Armaiti（斯彭塔·阿爾邁蒂）**：虔敬，大地之聖靈，赫沙特拉所統治的王國之基礎
- **Mithra（密特拉）**：契約與光明之神，與赫沙特拉共同守護王權的神聖性
- **Aeshma（埃什瑪）**：暴怒之魔，赫沙特拉的永恆對立面
