# 哈奧斯拉瓦 (Haosravah / Kavi Husravah)

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **職掌：** 卡伊安王朝英雄王、神聖光輝（Khvarenah）持有者、屠龍戰士
- **象徵：** 王權光環、寶劍、龍血、勝利旌旗
- **地位：** 卡伊安（Kayanian）王朝傳奇國王，與色萊塔歐納（Thraētaona）並列為屠龍英雄

## 概述

哈奧斯拉瓦（阿維斯塔語 Haosrauuah，中古波斯語 Xusrōy / Khosrow）是瑣羅亞斯德教神話中卡伊安（Kayanian）王朝的重要傳奇國王。其名字在阿維斯塔語中意為「迅捷的、光輝的」，由詞根 *hū-（善、美）與 *srauuah（聲譽、光輝）組成，暗示其為「享有善譽與光輝的統治者」。他是伊朗民族神話中「神聖王權」概念的核心載體之一——在《扎米亞德·耶什特》（Zamyad Yasht，即阿維斯塔第十九首讚歌）中，他被描述為神聖光輝（Khvarenah / Farrah）的持有者，這道光環是阿胡拉·馬茲達賜予伊朗正統國王的神聖標記。

哈奧斯拉瓦最獨特的身分是他的「神話原型」（mythological prototype）功能——他既是阿維斯塔文獻中的神話英雄，也是後來薩珊王朝（Sasanian Empire，西元224–651年）歷代國王取名「Khosrow」的直接來源。從神話學角度看，一個名字能跨越兩千年（從阿維斯塔時期到伊斯蘭化時期的波斯）持續使用，這在世界神話史上極為罕見。

## 神話事蹟

### 屠龍英雄的同伴

在《扎米亞德·耶什特》（Yasht 19）的英雄譜系中，哈奧斯拉瓦與色萊塔歐納（Thraētaona，即《王書》中的 Fereydun）並列，共同對抗龍蛇惡魔阿吉·達哈卡（Aži Dahāka）。《耶什特》的敘述表明，哈奧斯拉瓦是色萊塔歐納征討龍巢時的重要盟友。在阿維斯塔原文中，他的事蹟被歸入「伊朗英雄的神聖事蹟」序列——這個序列不僅是功績的記錄，更是「神聖光輝如何在不同英雄之間傳遞」的神學敘事。

在《巴赫拉姆·耶什特》（Bahram Yasht，即第十四首讚歌）中，勝利之神伐倫納（Verethragna）以多種形態顯現，其中一次便是在哈奧斯拉瓦面前以「持弓戰士」的形態出現。這表明哈奧斯拉瓦是受神庇佑的戰爭英雄——他的勝利不來自個人武力，而是來自神聖力量的直接介入。

### 神聖光輝的傳承

《扎米亞德·耶什特》的核心主題之一是「卡瓦伊姆·赫瓦雷諾」（Kavaem Hvareno，即「王者光輝」）的流轉。這道光輝最初由阿胡拉·馬茲達賜予耶瑪（Yima / Jamshid），耶瑪因驕傲失去光輝後，光輝依次傳遞給多位英雄與國王。哈奧斯拉瓦是光輝傳承鏈中的關鍵環節——他的統治被認為是伊朗黃金時代的延續，其王權的合法性直接來自光輝的神聖傳承。

這種「光輝傳承」模式在波斯神話中具有深遠意義：它將王權的合法性與宇宙秩序（Asha）綁定，國王不是靠武力奪權，而是靠神聖光輝的「選擇」成為統治者。這與後來中國的「天命觀」（Mandate of Heaven）和日本的「天照大神授權」具有驚人的結構平行。

## 跨文化對應

| 文化 | 對應英雄王/概念 | 共通點 |
|------|----------------|--------|
| 中國 | 周武王（天命所歸） | 王權來自神聖授權，非武力奪取；征伐暴君的正義戰爭 |
| 日本 | 神武天皇（天照授權） | 神聖血脈的王權合法性，建國英雄的神性光環 |
| 希臘 | 赫拉克勒斯（半神英雄） | 與龍蛇戰鬥、完成神聖使命、最終被接納為神 |
| 印度 | 阿周那（因陀羅之子） | 被神選中的戰士、在神聖戰爭中代表正義一方 |
| 北歐 | 西格德（Sigurd） | 屠龍英雄、獲得龍血的力量與智慧 |
| 埃及 | 法老（荷魯斯的化身） | 王權為神的地上代理、神聖光環賦予統治合法性 |
| 美索不達米亞 | 吉爾伽美什（三分之二神） | 半神英雄的屠龍冒險、對永生的追求 |

## 在文獻中的位置

哈奧斯拉瓦主要出現在以下文獻中：
- **《阿維斯塔》〈扎米亞德·耶什特〉（Yasht 19）**：作為神聖光輝的持有者之一被列入英雄譜系
- **《阿維斯塔》〈巴赫拉姆·耶什特〉（Yasht 14）**：伐倫納神以戰士形態顯現在他面前
- **《班達希申》（Bundahishn）**：在宇宙論敘述中作為伊朗正統國王序列的一員
- **《丁卡德》（Denkard）**：作為瑣羅亞斯德教傳說中的理想統治者典範

## 相關神祇與人物

- **色萊塔歐納（Thraētaona / Fereydun）**：屠龍英雄，哈奧斯拉瓦的戰友
- **耶瑪（Yima / Jamshid）**：黃金時代之王，神聖光輝的最初持有者
- **凱·卡烏斯（Kay Kavus）**：卡伊安王朝另一位重要國王
- **凱·霍斯魯（Kay Khosrow）**：卡伊安王朝最偉大的國王，名字直接源自哈奧斯拉瓦
- **伐倫納（Verethragna）**：勝利之神，曾以戰士形態在哈奧斯拉瓦面前顯現
