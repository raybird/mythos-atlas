# 赫瓦雷納 (Xvarenah / Khvarenah / Farr)

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **職掌：** 神聖王權光輝、命運榮耀、天命、王者的合法統治權
- **象徵：** 黃金光芒、火焰冠冕、鳳凰（法爾（Farr）鳥）、太陽光輪
- **別名：** 中古波斯語 Khwarrah／Farr（法爾），新波斯語 Farr（فَرّ）

## 概述

赫瓦雷納（Avestan: Xvarenah，意為「榮耀」或「光輝」）是瑣羅亞斯德教宇宙觀中最抽象卻最具影響力的神聖概念之一——它既是一位雅札塔（Yazata，值得崇敬者），也是一種超越人格化的神聖力量。赫瓦雷納代表阿胡拉·馬茲達賦予義人與合法統治者的神聖光輝，是王權正當性的終極來源。失去赫瓦雷納即失去統治的資格，獲得赫瓦雷納則意味著天命加身。

在《阿維斯塔》的〈阿什特·耶什特〉（Yašt 19，〈赫瓦雷納頌〉）中，赫瓦雷納被描述為「從太陽中降下、從星辰中閃耀、永不枯竭的火焰」。它最初由阿胡拉·馬茲達創造，賦予原初之王伊瑪（Yima/Jamshid）——伊瑪在其庇佑下建立了無死亡、無疾病的黃金時代。然而當伊瑪墮入謊言（Druj）後，赫瓦雷納逃離了他，化為一道光焰飛入湖中，此後在不同的王者之間流轉（Boyce 1975: 98–102）。

## 神話事蹟

### 伊瑪的赫瓦雷納

赫瓦雷納最初的承載者是伊瑪——波斯神話中第一位偉大的人間國王。根據《亞什特》19.34–46，伊瑪在赫瓦雷納的庇佑下統治了三百年，期間大地肥沃、萬物繁盛、沒有死亡也沒有嚴冬。然而伊瑪逐漸驕傲自大，開始對阿胡拉·馬茲達隱瞞真理——他聲稱自己「從未說過謊」，這本身即為謊言。赫瓦雷納因此離開了他，伊瑪的王國隨即衰落。這一敘事建立了波斯政治神話的基本法則：王權來自神恩，而神恩以道德為條件。

### 赫瓦雷納的流轉

伊瑪失去赫瓦雷納後，這道神聖光輝化為一道火焰沉入湖泊。此後它在不同的英雄與國王之間流轉——每一次轉移都標誌著一個新王朝的興起。根據《王書》（Shahnameh）的傳統，赫瓦雷納最終抵達了費雷敦（Fereydun/Thraetaona）——擊敗暴君扎哈克的救世英雄。在費雷敦的後裔中，赫瓦雷納繼續傳承，直到最伟大的伊朗國王——如努什爾萬（Nushirvan/Khosrow I）——以公正統治贏得它的青睞。

### 赫瓦雷納與法爾鳥

在波斯民間傳統中，赫瓦雷納有時被描繪為一隻光焰之鳥——「法爾鳥」（Farr-e Mohammadi，穆罕默德之光的前身概念）。這隻鳥棲息在王者的宮殿上方，若國王行不義之事，法爾鳥便會離去。這個意象在薩珊王朝（224–651 CE）的金屬器皿與印章上反覆出現，成為波斯王權最直觀的視覺象徵。

### 末日中的赫瓦雷納

在世界末日論（Frashokereti）中，赫瓦雷納將最終回歸——它將匯聚在最後的救世主（Saoshyant）身上，象徵正義的最終勝利。屆時，所有曾經失去赫瓦雷納的正義者都將重新獲得它的光輝，而邪惡者將永遠失去任何神聖光芒的可能。

## 跨文化對應

| 文化 | 對應概念 | 共通點 |
|------|----------|--------|
| 印度吠陀 | Ksatra（王權）／Bhaga（份額/福分） | Bhaga 與 Xvarenah 共享「天命分配」概念，王者的統治權來自神授 |
| 希臘 | Tyche（命運）／Basileia（王權） | 城邦與王者的守護神聖力量 |
| 羅馬 | Fortuna Redux（歸返之命運）／Imperium（統治權） | 王朝正當性的超自然來源 |
| 中國 | 天命／龍氣 | 王朝更替的神聖合法性，失德則天命轉移 |
| 北歐 | Ond（靈魂/精神）／Hamingja（命運之力） | 個人與家族的超自然幸運力量 |
| 日本 | 天命（Tenmei）／神器三種 | 皇統正當性的神聖象徵物（鏡、劍、璽） |

赫瓦雷納最獨特之處在於它是一種「可流動的神聖品質」——不同於大多數文化中天命一旦賦予即永久有效，赫瓦雷納可以因為統治者的道德墮落而被收回。這種「條件性的天命觀」在古代近東極為罕見，反而更接近後來儒家的「革命」（天命更替）思想。

## 相關神祇

- Ahura Mazda（阿胡拉·馬茲達）：赫瓦雷納的創造者與最終源泉
- Yima/Jamshid（伊瑪）：赫瓦雷納的首位承載者，因驕傲而失去
- Mithra（密特拉）：契約之神，赫瓦雷納的守護者之一
- Rashnu（拉什努）：公正之神，審判誰配獲得赫瓦雷納
- Sraosha（斯勞沙）：聽從之神，赫瓦雷納流轉過程中的見證者
