# 拉曼 (Raman / Rām)

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **職掌：** 和平、喜悅、和諧、友善的人際關係
- **象徵：** 鴿子、月光、歡樂的聚會
- **曆法對應：** 每月第 21 日

## 概述

拉曼（阿維斯塔語 Rāman，意為「和平、安寧」）是瑣羅亞斯德教中掌管和平、喜悅與人際和諧的 Yazata（值得崇拜的神聖存在）。他的全名常被稱為 Rāman Hvāstra（「擁有美好牧場的拉曼」），這一稱號將其與廣闊而平靜的草原意象聯繫起來——象徵著和平所帶來的富足與繁榮。在瑣羅亞斯德教的月曆（Siroza）系統中，拉曼掌管每月第 21 日，與第 16 日的密特拉（Mithra）和第 17 日的斯勞沙（Sraosha）形成互補——密特拉代表契約與社會秩序，斯勞沙代表服從與紀律，拉曼則是這些秩序所產生的和諧喜悅狀態。

拉曼與密特拉有著密切的聯繫。在《阿維斯塔》中，拉曼經常與密特拉一同被召喚，因為真正持久的和平（Rāman）唯有建立在誠信契約（Mithra）與服從正義（Sraosha）的基礎之上。《耶斯納》（Yasna）第 16 章描述拉曼為「帶來美好牧場的賜予者」，他消滅衝突與仇恨，使人們和睦相處。

## 神話事蹟

拉曼作為和平之神，主要的神話作用是中和戰爭之神與邪惡力量帶來的破壞。在《阿維斯塔》的〈耶斯特〉（Yasht）讚美詩中，拉曼被祈求以平息爭端、促進社會和諧。他與 Rush（爭吵）和 Aeshma（憤怒）——安格拉·曼紐創造的兩位邪惡 Daēva——形成直接對立。Aeshma 是戰爭暴怒的化身，而拉曼則以冷靜與喜悅對抗他的混亂影響。

在瑣羅亞斯德教的末世論（Frashokereti）中，拉曼將在索什揚特（Saoshyant）最終更新世界後，協助重建人與人之間的和諧。屆時所有人類將共享沒有衝突、沒有謊言的完美社會——拉曼作為和平之神將主導這一新時代的人際關係。

在後期波斯傳統中，拉曼的概念逐漸與「Rām」（快樂）的日常用語融合。波斯詩人如菲爾多西（Ferdowsi）與哈菲茲（Hafez）的詩歌中反覆出現的「Rām」意象——快樂的心、寧靜的靈魂——皆可溯源至這位古老 Yazata 的神聖原型。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 希臘 | 厄瑞涅（Eirene） | 和平女神，掌管社會和諧與繁榮 |
| 羅馬 | 帕克斯（Pax） | 和平女神，羅馬帝國和平（Pax Romana）的象徵 |
| 北歐 | 弗雷（Freyr） | 和平與豐收之神，結束戰爭的仲裁者 |
| 印度 | 密多羅（Mitra）/ 商提（Shanti） | 友誼之神的善面；Shanti 為和平的化身 |
| 猶太-基督教 | 沙隆（Shalom）/ 平安 | 和平作為上帝的祝福 |
| 中國 | 和合二仙 | 和諧與團圓的神格化 |

## 相關神祇

- Mithra（密特拉）：契約與光明之神，拉曼的親密戰友
- Sraosha（斯勞沙）：服從與紀律之神，協助維持秩序
- Aeshma（艾什瑪）：憤怒惡魔，拉曼的直接對立面
- Vohu Manah（善念）：引導人們走向和平的內心智慧
- Asha Vahishta（至真）：宇宙正義的化身，和平的總體秩序基礎
