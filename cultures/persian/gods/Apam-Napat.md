# 阿帕姆·納帕特 (Apām Napāt)

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology)
- **職掌：** 水之孫、水源守護者、神聖火焰的持有者、宇宙之水的主宰
- **象徵：** 火焰於水中燃燒、黃金之光、駿馬、漩渦
- **全名：** Apām Napāt（阿維斯塔語，意為「水之子孫/後裔」）

## 概述

阿帕姆·納帕特是波斯神話中最古老的水神之一，其名在阿維斯塔語中意為「水的子孫」或「水的後裔」。他掌管世間一切流動的水源——從宇宙的原初之河到大地上的溪流泉源。在〈耶什特〉文獻中，他被描述為一位以金色光芒駕馭四匹白馬的神祇，居住在宇宙之河阿雷德維（Aredvi Sura）的深處，守護著水源的純淨與豐沛。

阿帕姆·納帕特最令人矚目的特質是他擁有「水中之火」——一種在水中永不熄滅的神聖火焰。這一看似矛盾的意象反映了瑣羅亞斯德教的核心宇宙觀：光明（Asha）的力量無處不在，即使在最黑暗、最潮濕的深淵中也能燃燒。在〈耶什特〉第5章（〈阿班·耶什特〉）中，阿帕姆·納帕特被描述為「以火焰從水中升起的光輝者」，他的存在本身就是善對惡的勝利的證明。

## 神話事蹟

### 宇宙之水的守護者

在阿維斯塔的宇宙論中，宇宙之河阿雷德維·蘇拉·阿娜希塔（Aredvi Sura Anahita）從哈拉神山（Hara）之巔奔流而下，分為一千條河川灌溉大地。阿帕姆·納帕特是這條宇宙之河的守護者與管理者。他坐鎮河源深處，以神聖之火保持水流的純淨，防止邪惡力量（Daevas）污染水源。

在〈阿班·耶什特〉中，阿帕姆·納帕特被讚頌為所有水中最強大者：「在阿帕姆·納帕特的水中，有著超越一切的純淨力量。他的火焰在深淵中燃燒，照亮了宇宙的根基。」這段讚歌反映了古代伊朗人對水源的深切敬畏——在乾旱的伊朗高原上，水是生命最寶貴的資源，而守護水源的神祇自然享有崇高地位。

### 火與水的統一

阿帕姆·納帕特最獨特的神話象徵是「水中之火」。在瑣羅亞斯德教的宇宙觀中，火（Atar）代表阿胡拉·馬茲達的純潔意志，水（Ap）代表生命的流動與滋養。這兩種元素通常被視為對立的——火蒸發水，水熄滅火。然而阿帕姆·納帕特體現了兩者的和諧統一：他的火焰在水中燃燒而不被熄滅，象徵神聖的光明力量能夠穿透一切物質障礙。

這一意象在後世的波斯文化中留下了深刻印記。在薩珊王朝的岩石浮雕中，國王面前常有燃燒的聖火盆置於流水之上——這是阿帕姆·納帕特象徵的世俗化表達，宣示王權同時獲得火與水兩種神聖力量的庇佑。

### 與其他水神的關係

阿帕姆·納帕特與阿娜希塔（Anahita）的關係在學術界存在爭議。部分學者認為兩者原本是同一神祇的不同面相——阿帕姆·納帕特是較古老的男性形態，阿娜希塔是後來發展出的女性形態。在〈阿班·耶什特〉中，兩者同時被祈禱但各有分工：阿娜希塔掌管河流的流動與滋養，阿帕姆·納帕特掌管水源的純淨與守護。另一些學者則認為阿帕姆·納帕特更接近原始印歐宗教中的水神概念，而阿娜希塔受到了美索不達米亞伊什塔爾（Ishtar）崇拜的影響。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 印度吠陀 | 阿帕姆·納帕特 (Apām Napāt) | 同名同源，吠陀中同樣是水之子孫，持有水中之火 |
| 希臘 | 波賽頓 (Poseidon) / 河神 | 水域的統治者，但希臘水神缺乏「水中之火」的特質 |
| 北歐 | 埃吉爾 (Aegir) | 海洋之神，掌管深海的力量 |
| 埃及 | 哈比 (Hapi) | 尼羅河之神，賜予豐收與生命 |
| 美索不達米亞 | 恩基 (Enki/Ea) | 水與智慧之神，守護人類免於洪水 |
| 凱爾特 | 曼南南·麥·利爾 (Manannán mac Lir) | 海洋之神，擁有神聖的財富與力量 |

## 相關神祇

- **阿娜希塔 (Anahita)**：水與豐收女神，與阿帕姆·納帕特共享水域的職掌
- **阿塔爾 (Atar)**：聖火之神，與阿帕姆·納帕特共同體現「水中之火」的神聖統一
- **阿胡拉·馬茲達 (Ahura Mazda)**：最高善神，賦予阿帕姆·納帕特神聖使命
- **密特拉 (Mithra)**：契約與光明之神，在水之淨化儀式中與阿帕姆·納帕特共同出現
- **赫瓦雷·赫沙埃塔 (Hvare-khshaeta)**：太陽神，其光輝與阿帕姆·納帕特的水中火焰相互呼應
