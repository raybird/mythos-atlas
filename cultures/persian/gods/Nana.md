# 娜娜 (Nana / Nanaia)

- **文化：** 波斯神話 (Persian / Zoroastrian Mythology) — 伊朗語族傳統
- **職掌：** 大地、豐饒、生育、母性、庇護
- **象徵：** 獅子座（騎獅）、蓮花、大地之母、金冠
- **其他名稱：** 納奈亞 (Nanaia)、阿娜希塔 (Anahita，部分融合)、粟特 Nana、大夏 Nana

## 概述

娜娜（Nana）是伊朗語族傳統中最重要的母性與大地女神之一，其崇拜跨越了從美索不達米亞到中亞的廣袤地域。她的名字源自原始伊朗語 *nāna（「母親」），與阿維斯塔語 nanā-（母親）同源，也與美索不達米亞的伊南娜（Inanna）有著深遠的語源聯繫。在不同的伊朗文化圈中，娜娜呈現了多重面貌：在粟特（Sogdian）傳統中，她是至高無上的女神，地位僅次於光明之神阿胡拉·馬茲達；在大夏（Bactrian）與貴霜（Kushan）帝國中，她是帝國守護神，出現在錢幣與印章上；在美索不達米亞邊緣，她的名字與伊南娜/伊什塔爾（Ishtar）相互滲透。

## 神話事蹟

### 粟特的至高女神

在粟特文獻（約西元 6–8 世紀，今烏茲別克與塔吉克地區）中，娜娜被尊為萬物之母、宇宙的守護者。在片治肯特（Panjikent，塔吉克斯坦古城）的壁畫中，娜娜以頭戴日月冠冕、騎獅的形象出現——這個圖像學直接延續了美索不達米亞伊什塔爾騎獅的傳統。粟特商人將娜娜的崇拜帶到了絲路沿線的每一座城市——從撒馬爾罕到長安，從敦煌到洛陽。

### 大夏的守護者

在大夏（Bactria，今阿富汗北部）的鍍金青銅器中，娜娜被描繪為一位坐在蓮花寶座上的女神，雙手各持一束麥穗，腳下踩著一頭獅子。在貴霜王朝（約西元 1–3 世紀）的錢幣上，娜娜的形象與希臘的阿爾忒彌斯（Artemis）和印度的吉祥天女（Lakshmi）交替出現，反映了絲路文化的宗教融合。

### 與阿娜希塔的融合

在波斯本土的瑣羅亞斯德教中，娜娜的部分功能被阿娜希塔（Anahita）所吸收。阿娜希塔的水與豐收職掌、騎馬的形象、以及與生育的關聯，都與娜娜的母性特質重疊。這種融合反映了波斯帝國在整合不同地區信仰時的常見策略——將外來女神納入本土萬神殿。

## 跨文化對應

| 文化 | 對應女神 | 共通點 |
|------|----------|--------|
| 美索不達米亞 | 伊南娜/伊什塔爾 (Inanna/Ishtar) | 語源關聯（*nāna- 與 Inanna 同源）、騎獅、愛與豐收 |
| 希臘 | 德墨忒爾 (Demeter) / 赫拉 (Hera) | 大地母神、豐收女神、母性守護 |
| 埃及 | 伊西斯 (Isis) | 母性、豐收、魔法、庇護 |
| 印度 | 拉克什米 (Lakshmi) / 帕爾瓦蒂 (Parvati) | 豐饒、生育、坐騎（獅子/老虎） |
| 羅馬 | 維斯塔 (Vesta) / 康帕斯·馬特 (Cybele) | 母性崇拜、聖火、大地之母 |
| 中國 | 女媧 / 西王母 | 創世母神、庇護者、不死與豐收 |

娜娜與伊南娜的關係最為密切——兩者可能共享同一個原始美索不達米亞-伊朗的母神原型。在烏魯克時期（約西元前 4000 年）的泥板上，「Nanna」曾是月神南納（Nanna/Sin）的名字，後來與女性化的母神形象合流。

## 相關神祇

- **阿娜希塔 (Anahita)**：水與豐收女神，吸收了娜娜的母性功能
- **伊南娜 (Inanna)**：美索不達米亞愛與戰女神，與娜娜語源同源
- **Anahita**：在部分傳統中，Nana 與 Anahita 被視為同一女神的不同面向
- **Shango**：約魯巴雷神（跨文化對應：騎獅的戰士神形象）
