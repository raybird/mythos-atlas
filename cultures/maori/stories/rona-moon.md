# Rona 與月亮——被綁架的女人與月蝕的起源

- **文化：** 毛利神話 (Māori Mythology)，泛波利尼西亞傳統

## 故事背景

Rona（羅娜）的故事是毛利神話中最著名的天文神話之一，解釋了月蝕和月亮表面陰影的成因。這個故事在毛利口傳傳統中廣為流傳，是毛利天文學（Tātai Arorangi）與神話交織的典型範例。Rona 的故事也存在於波利尼西亞其他群島（夏威夷、薩摩亞、湯加），但各地版本在細節上有所不同。

## 情節

### Rona 的日常

在古代毛利社會中，Rona 是一位年輕的女性，居住在海邊的村莊中。她的日常生活中，月亮（Marama）是她最熟悉的存在——她常常在月光下前往溪邊取水，在月光下編織，在月光下聆聽長者講述 Whakapapa（系譜）故事。月亮對她而言不僅是天體，更是一個「在場的、持續的存在」——每一個夜晚都準時出現，如同一位可靠的同伴。

### 激怒月亮的夜晚

某個夜晚，Rona 前往溪邊取水。月亮的光芒正好照在水面上，形成銀色的倒影。Rona 心中煩躁——可能因為天色已晚，可能因為取水的辛勞，也可能因為某種未說出的個人悲傷——她抬頭望向月亮，以粗魯的言語咒罵：

> 「你這該死的月亮！你照亮了所有東西，卻只照亮了我取水的辛苦！你難道不能像太陽一樣溫暖嗎？你這冰冷的、無情的光！」

月亮聽見了這些話。在毛利宇宙觀中，天體是有意識的、有情感的存在——月亮被冒犯了。它從天空伸下一根巨大的樹枝（一說為銀色的藤蔓），纏住了 Rona 的身體，將她從地上提起，拉向天空。

### 月中的囚徒

Rona 驚恐地抓住了那根樹枝——那是她的救命稻草，也是她的枷鎖。她的雙手緊緊握著樹枝，身體懸在半空中，被拉向月亮。當她到達月亮時，她發現自己被困在那裡——無法返回地面，也無法完全融入月亮。

從此以後，Rona 永恆地懸挂在月亮上。在滿月的夜晚，人們可以看見她的身影——她緊緊抓住樹枝的輪廓。她的身體與月亮融為一體，成為月亮表面陰影的一部分。

### 月蝕的解釋

毛利人將月蝕解釋為月亮暫時將 Rona 吞入自己的身體深處——或是 Rona 因思鄉而暫時消失在月亮的光芒中。當月蝕結束，Rona 再次出現，月亮恢復光芒——這被視為 Rona 每次都會「回來」的承諾，即使她永遠無法真正回家。

## 跨文化平行

| 文化 | 神話 | 相似模式 |
|------|------|---------|
| 中國 | 嫦娥奔月 | 女性因某種行為被送到月亮，從此永恆居於月中 |
| 希臘 | 塞勒涅（Selene）與恩底彌翁（Endymion） | 月亮女神與地上凡人的不對等關係 |
| 日本 | 天照大神隱身天岩戶 | 天體暫時消失導致黑暗（類似月蝕的神話功能） |
| 阿茲特克 | 科亞特利奎（Coyolxauhqui） | 女性被放逐到月亮 |
| 印度 | 羅希尼（Rohini）與月亮 | 月亮對某位女性的偏愛導致懲罰 |
| 北歐 | 瑪尼（Máni）駕馬車追月 | 月亮的女性同伴（日與月的擬人化） |

## 故事的文化意義

Rona 的故事在毛利文化中具有多重意義：

1. **天體擬人化**：月亮不是一個無生命的天體，而是一個有意志、會被冒犯的存在。這反映了毛利人對自然的深層敬畏——任何自然力量都可能成為神聖的懲罰者。

2. **言語的力量**：Rona 的災難源於她的咒罵。在毛利文化中，言語（Kupu）具有巨大的力量——詛咒、祈禱、Whakapapa（系譜）都被視為能夠改變現實的力量。

3. **性別與權力**：Rona 是一位女性，她的故事涉及她與月亮（一個天體）之間的不對等關係。一些學者認為，這個故事反映了毛利社會中女性角色的複雜性——女性同時是「滋養者」和「危險力量的擁有者」。

4. **天文學知識的載體**：Rona 的故事是毛利天文學知識的口傳載體。通過講述這個故事，長者向年輕人傳授了月相、月蝕、月亮表面特徵的知識。
