# Papatūānuku — 毛利大地之母

- **文化：** 毛利神話 (Māori Mythology)
- **職掌：** 大地、豐饒、滋養、母性、生命循環

## 概述

Papatūānuku（帕帕圖阿努庫）是毛利神話中的大地之母，與天父 Rangi-nui 共同構成毛利宇宙觀的最根本二元結構。她的名字意為「永恆的土地之母」（Papa = 大地，tū = 永恆站立，ānuku = 以她的方式），強調她是永恆不變的、承載一切生命的存在。在毛利宇宙觀中，Papa 不僅是一片「土地」，而是一個活生生的、有意識的、與所有生命有深厚情感連結的神聖存在。她的身體是山脈、平原、河谷；她的呼吸是地底的熱氣與霧靄；她的淚水是泉水與溪流。

## 神話事蹟

### 天地分離中的痛苦

Papatūānuku 與 Rangi-nui 原初緊密擁抱，黑暗中生下了眾多子女。當 Tāne-mahuta 提議分離父母時，Papa 不願與 Rangi 分離。她是被迫被推開的——她的身體在分離的力量中被撕裂，形成了山脈與峽谷。分離後，她的眼淚化為露水與霧氣，她的嘆息化為地底的熱氣。即使在被分離之後，她仍然深愛著 Rangi——每年春天，萬物從她的懷中生長，是她試圖再次擁抱天空的努力；而 Rangi 的雨露，是他在高空對 Papa 的回應。

### 眾子的母親

Papatūānuku 是所有自然力量的母親。她的孩子們掌管著世界的各個領域：Tāne-mahuta（森林）、Tangaroa（海洋）、Tū-matauenga（戰爭與人類）、Tāwhirimātea（風暴）、Rongo-mā-Tāne（和平與農耕）、Haumia-tiketike（野蕨）。每個孩子都從她那裡獲得力量——森林從她的土壤中汲取養分，海洋在她的盆地中流淌，人類在她的表面行走。但 Papa 最痛苦的是她最小的兒子 Rūaumoko——他在天地分離時仍在她的子宮中，從此永遠生活在地底，他的地震是她身體內部的震動。

### 與人類的關係

在毛利宇宙觀中，人類與 Papatūānuku 的關係最為直接：人類從她那裡獲取食物、住所和一切生存所需。當一個人死亡後，他的身體被埋入 Papa 的懷中，回歸大地之母。這不是一種懲罰或終結，而是一種回歸——死者的身體分解後成為土壤的一部分，滋養新的生命。因此，Papa 同時是生命的賜予者和死亡的接納者。毛利人在耕種前會舉行 Karakia（祈禱），感謝 Papa 的慷慨；在葬禮上會吟誦，將死者交還給 Papa。

## 跨文化對應

| 毛利 Papatūānuku | 對應 | 文化 |
|---|---|---|
| 大地之母與天父分離 | 蓋亞（Gaia）與烏拉諾斯（Ouranos） | 希臘 |
| 大地之母被分離 | Nut（天）與 Geb（地） | 埃及 |
| 永恆的大地母親 | 地母神（Mother Earth）/ Jord（大地） | 北歐 |
| 大地之母的滋養 | 德墨忒爾（Demeter）的豐饒 | 希臘 |
| 大地之母與死亡 | 嫦娥/后土娘娘 | 中國 |
| 大地之母的痛苦 | 詩篇「大地因你的聲音而顫抖」 | 希伯來 |

## 相關神祇

- **配偶：** Rangi-nui（天父）——原初的永恆伴侶
- **子女：** Tāne-mahuta（森林）、Tangaroa（海洋）、Tū-matauenga（戰神）、Tāwhirimātea（風暴）、Rongo-mā-Tāne（和平/農耕）、Haumia-tiketike（野蕨）、Rūaumoko（地震）
- **媳婦/女婿：** Hine-ahu-one（第一位人類女性，由 Tāne 創造）
- **對應關係：** 在泛波利尼西亞傳統中，Papa 與 Rangi 的名字和角色在夏威夷、薩摩亞、大溪地等地都有對應
