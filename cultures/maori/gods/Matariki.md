# Matariki — 昂宿星團與毛利新年歲首之星

- **文化：** 毛利神話 (Māori Mythology)
- **職掌：** 昂宿星團（Pleiades）、毛利新年、歲首曆法、農業豐欠預示、亡靈記憶、星辰導航
- **別名：** Ngā Mata o te Ariki Tāwhirimātea（風神 Tāwhirimātea 之眼）；同源於玻里尼西亞的 Huihui／Matai'i'i、夏威夷 Makali'i

## 概述

Matariki（馬塔里基）在毛利宇宙觀中既是昂宿星團（M45）本身，也是一群星神所組成的「神聖家族」，更是毛利新年的開端標誌。其全名「Ngā Mata o te Ariki Tāwhirimātea」（風神 Tāwhirimātea 之眼）源自創世神話：當 Tāne-mahuta 等眾神分離天父 Ranginui 與地母 Papatūānuku 時，風暴之神 Tāwhirimātea 盛怒之下挖出自己的眼睛擲向天空，化作嵌在父親胸膛上的星群——這即是 Matariki 的起源。與希臘「七姊妹」的數法不同，毛利傳統多數部族計數九顆星，每顆星各有專屬的象徵領域，構成一套完整的歲首占卜與宇宙觀系統。

在傳統毛利社會中，Matariki 在冬季（六月）清晨偕日升（heliacal rising）前重現於東南地平線，標誌一年之始。此一星象同時服務農業（tupuānuku 地食、tupuārangi 天食的豐欠預示）、漁獵（waitī 淡水、waitā 海洋）、氣象（ururangi 風向、waipunarangi 雨水）與社會記憶（pōhutukawa 已故親人）等層面。2022 年紐西蘭通過《Matariki 公共假日法》（Matariki Public Holiday Act 2022），使昂宿升起成為現代國家法定歲首，是傳統天文知識復振的重要里程碑。

## 神格與形象

### 風神之眼：創世星群

在毛利創世敘事中，Matariki 不是獨立的單一神祇，而是 Tāwhirimātea 向天父之胸投擲的九隻（或數目不一）眼睛。此神話使星簇與「分離天地的暴力」相繫——星群既是風暴之神的殘骸，也是天地之間永恆的縫合處。這種「以破壞性動作創造曆法秩序」的結構，在跨文化中並不孤例（見希臘七姊妹的變星傳說）。

### 九星家族

毛利各部族對九顆星的命名與象徵大同小異，常見組合為：

| 星名 | 象徵領域 |
|------|---------|
| Matariki（母星） | 幸福、反思、希望、團聚 |
| Waitī | 淡水與淡水食物 |
| Waitā | 海洋與海產 |
| Tupuānuku | 地中生長的食物 |
| Tupuārangi | 天空來的食物（果實、鳥類） |
| Waipunarangi | 雨水 |
| Ururangi | 年度風向 |
| Pōhutukawa | 已故之人的記憶 |
| Hiwa-i-te-rangi | 願望之星、來年祈願 |

## 神話事蹟

Matariki 的事蹟並非單一英雄敘事，而是以「偕日升儀式」為核心的歲首神話循環。每年六月，長者與 tohunga（祭司）在黎明前觀察昂宿的亮度、排列與顏色：星光明亮預示來年豐收與溫暖，暗淡則預示嚴寒與歉收。觀察完畢後，社區進行 kai atua（祭神飲食）、放飛竹製風箏（pākau）敬天、並以 hākari（盛宴）感謝死去的親人與祖先，象徵生死循環與社群重生。部分部族（如 Ngāi Tahu）以獵戶座 Rigel（Puaka）替代或輔助 Matariki 作為歲首星，反映毛利天文知識的區域多樣性。

此外，Matariki 被視為星辰之神 Rehua 的後裔（另一說為其子女），與 Rehua 的醫療、光明與天文知識職掌相銜接。在毛利航海傳統中，昂宿星團亦作為南太平洋航行的重要參考星群，將曆法、祭儀與大洋遷徙記憶連為一體。

## 相關神祇

- **Tāwhirimātea：** 風暴之神，Matariki 的來源（其眼所化）
- **Rehua：** 星辰與醫療之神，Matariki 的祖先/長輩，天文知識的傳授者
- **Ranginui：** 天父，星群嵌於其胸膛
- **Puaka（Rigel）：** 獵戶座之星，部分部族以之為歲首星
- **Rona：** 月之女子，同屬毛利天文神話系統
- **Hine-te-iwaiwa：** 月亮/織造女神，與以月相定歲的系統並行

## 出現在

- 毛利口傳傳統（Te Arawa、Ngāi Tahu、Ngāti Porou 等部族天文知識）
- 六月歲首觀星祭儀與 hākari 盛宴
- 紐西蘭《Matariki 公共假日法》（2022）
- 毛利天文學（tātai arorangi）與現代天文復振運動
