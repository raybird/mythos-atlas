# 巴力戰巨蛇洛坦 (Baal's Combat with the Serpent Lotan)

- **文化：** 腓尼基／迦南神話 (Phoenician/Canaanite Mythology)

## 故事背景

Lotan（烏加里特語：Ltn；希伯來語：לִוְיָתָן，Leviathan / 利維坦）是迦南神話中一條擁有七個頭的巨大海蛇，象徵海洋的混沌力量。牠是海神亞姆（Yam / Nahar）的寵物，直接威脅宇宙秩序。在烏加里特泥板 KTU 1.5 I 1-8 中，Lotan 是巴力（Baal）必須擊敗的最後一個混沌象徵。巴力在擊敗 Yam 之後必須再處理 Lotan——這一雙重戰鬥（先擊敗海神本人，再擊敗其蛇形化身）構成了迦南版「混沌戰鬥（Chaoskampf）」結構，為希伯來聖經中的利維坦神話提供了直接原型。

## 情節

### 第一章：混沌的遺留

巴力在札豐山（Mt. Saphon）上取得眾神之王地位並建成自己的宮殿之後，宇宙並未完全平靜。海洋深處仍然湧動著未被馴服的力量——Yam 雖被打敗了，但他在世界邊緣留下了最後一道防線：一條七頭巨蛇 Lotan，盤繞在海洋最深處的渦流中，以七張嘴吞吐海水。烏加里特泥板如此描述：「Lotan，那蜿蜒的蛇——Lotan，那七頭的暴君——以火焰塗抹其軀體的怪物。」

### 第二章：雷神與七頭蛇

巴力以雷電為武器前往海洋邊緣。Lotan 的七個頭分別代表七種混沌力量：黑暗深淵（Tehom）、無序潮汐、吞噬船隻的漩渦、腐蝕船底的黏液、使太陽黯淡的水霧、海底毒素與世界邊緣的冰寒。巴力使用由科薩爾（Kothar-wa-Hasis）鑄造的雙面戰斧逐一斬斷蛇頭——但每一顆被斬落的頭都會從斷裂處長出新的頭。Lotan 以七道水柱衝向天空，試圖淹沒眾神的居所。

### 第三章：封印源泉

巴力返回札豐山尋求埃爾的建議。埃爾透露秘密：Lotan 的再生能力來自地底的七道泉水。巴力返回戰場，以巨大石塊堵塞了滋養 Lotan 的七道泉水。當第七個源頭被封閉時，Lotan 失去再生能力。巴力以最後一記雷擊穿 Lotan 心臟——巨蛇身體沉入深海，不再上升。

### 第四章：創世的完成

Lotan 的死象徵創世的完成——迦南神話的宇宙秩序不是在天地分離時完成的，而是在混沌海怪被徹底擊敗時才真正建立。巴力將 Lotan 的七個頭懸掛在札豐山城牆上。然而神話暗示 Lotan 不會永遠被囚禁：預言「在末日之時蜿蜒的蛇 Lotan 將被釋放——然後被神的劍永遠刺穿。」此預言在《以賽亞書》27:1 中被重述。

## 跨文化平行

| 文化 | 對應神話 | 比較 |
|------|---------|------|
| 美索不達米亞 | 馬爾杜克戰提亞瑪特 | 風暴神斬殺混沌海怪，屍體化為宇宙 |
| 希臘 | 阿波羅斬 Python | 秩序英雄消滅混沌巨蛇 |
| 北歐 | 索爾戰耶夢加得 | 雷神對抗環繞世界的巨蛇 |
| 印度 | 因陀羅戰弗栗多 | 雷神擊殺囚禁水源的蛇魔 |
| 希伯來 | 利維坦（以賽亞書 27:1） | 末日神以劍誅殺七頭海蛇 |
| 埃及 | 拉戰阿佩普 | 太陽神每夜對抗混沌巨蛇 |
