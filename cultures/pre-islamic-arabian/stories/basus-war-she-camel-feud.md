# 巴蘇斯之戰——一峰母駝、詩歌與四十年的血親復仇

- **文化：** 前伊斯蘭阿拉伯神話

## 故事背景

在伊斯蘭興起之前的阿拉伯半島，部落記憶並不以編年史保存，而以「阿拉伯人的日子」（ayyām al-ʿarab）流傳：一個「日子」通常是一場決定名譽的戰役，連同參戰者、口號與詩句一起被反覆吟誦。巴蘇斯之戰（ḥarb al-Basūs）正是其中最著名的一場，被後世文學傳統描述為綿延約四十年的同族血仇。它的主角不是神祇，而是兩個自認同源的譜系：巴克里（Bakr b. Wāʾil）與塔格利卜（Taghlib b. Wāʾil），二者共尊傳說祖先瓦伊勒（Wāʾil），又彼此通婚，因此衝突在本質上是「親族之間的內戰」。

必須先說明史料性質：此戰沒有同時代的完整記事。現代研究（如 Peter Webb 為法國國家科學研究中心「古代阿拉伯主題詞典」所寫的條目）指出，我們所讀到的情節是零碎的前伊斯蘭詩句，加上伊斯蘭時期的文學加工與史詩化的結果；早期文獻在動機、人物與次序上彼此出入。這並不減損它作為文化文本的價值，反而顯示阿拉伯傳統如何把一段可能的局部衝突，塑造成關於榮譽、復仇與和解之門檻的典範敘事。

## 情節

### 一峰母駝與一支箭

傳說的導火線極小。巴蘇斯（al-Basūs，本名據說為 Basūs bint Munqidh）是塔米姆與巴克里譜系的女子，受沙伊班分支的貴族穆拉（Murra ibn Dhuhl）庇護，她的母駝誤入塔格利卜領袖庫萊卜（Kulayb ibn Rabīʿa）所主張的牧地或禁牧區（ḥimā）。庫萊卜以箭射殺了這頭牲畜；在另一版本中，爭點是水源與放牧權，而非單純的誤闖。巴蘇斯沒有訴諸法庭，而是作詩哀悼並指責穆拉之子賈薩斯（Jassās ibn Murrah）為她討回公道。詩在這裡不是裝飾，而是點燃行動的裝置：被吟唱的羞辱，使沉默成為不可能。

賈薩斯是庫萊卜的姻親——庫萊卜娶了賈薩斯的姊妹；血緣與婚姻因此把復仇推到更為難解的位置。賈薩斯不久後以長矛刺殺庫萊卜，傳說稱他趁其背對時下手。庫萊卜臨死留下的話語，在後世史詩《齊爾·薩利姆傳》（Sīrat al-Zīr Sālim）中化為反覆出現的禁令：「不要和解」（lā tuṣāliḥ）。據載他以血在石上寫下這句話，交給弟弟阿迪·伊本·拉比阿——即詩人穆哈爾希爾（al-Muhalhil，人稱 Abū Laylā）。

### 「不要和解」的遺言

庫萊卜之弟穆哈爾希爾，在早期文獻中是被殺首領的繼承者與復仇者，也是最早被認為確立長詩（qaṣīdah）格律的詩人之一。他拒絕以賠償金（diyah）了結兄長之死，率塔格利卜與巴克里交戰。在他的詩裡，哀悼與戰鬥是同一件事：淚水尚未乾，矛已上陣；「庫萊卜之血」既是私人的傷口，也是集體的旗幟。

衝突迅速超出最初的兩位當事人。巴克里其餘分支起初認為沙伊班有錯而袖手旁觀，直到穆哈爾希爾殺害調停者哈里斯·伊本·阿巴德的侄子布賈爾，整個巴克里聯盟才加入戰局；這正是血仇的邏輯——每一次「恰當」的報復，都製造下一次「正當」的報復。阿拉伯史籍以一連串「日子」命名各場戰役，例如「慌亂之日」（Yawm al-Hazr）與「剃鬚之日」（Yawm Ṭalḥāq al-Limam），把混亂與羞辱固定在可誦的名詞之中。傳說中戰事長達四十年，其間雙方皆元氣耗損，甚至必須讓新一代長大後再戰，這個細節多半是後世為強調報復代價而添加的敘述。

### 詩人如何延長戰爭

巴蘇斯之戰之所以成為文學經典，不在於戰術，而在於它展示了詩的社會功能。女性詩人寫出控訴，貴族子弟立即行動；男性詩人在戰場上寫下悼亡與威脅，使下一代繼續記得「未償的血」。前伊斯蘭長詩的開頭常停在廢墟與舊營地，這種「停下哭泣、然後出發」的修辭，在穆哈爾希爾的傳世詩句中特別清晰。

口傳詩人（rāwī）的記誦，讓評判權從法庭轉移到聽眾：一首詩被傳誦，等於判決被執行。同時，詩也提供了唯一的降溫途徑——當雙方詩人開始互相譏諷、誇耀與哀嘆時，羞辱已可被語言消化，未必還需以人死亡來償還。晚期史詩把穆哈爾希爾打造為傳奇英雄齊爾·萨利姆，著名的「拉·圖薩利赫」（不和解）口號甚至流傳到近現代政治抗議之中；學者 Shady Nasser 指出，史詩版本與早期的「歷史消息」（akhbār）在性格與結局上差異甚大，說明同一素材可被不同時代反覆改寫。

### 四十年的終局與轉化

在傳統的尾聲裡，和解終於到來：肯達王國的國王哈里斯·伊本·阿姆魯（al-Ḥārith ibn ʿAmr）出面仲裁，雙方接受調停；部分塔格利卜人此後遷往伊拉克、下幼發拉底與賈濟拉一帶，並在薩珊邊疆與伊斯蘭時代的歷史中繼續出現。另一版本中，和解之所以可能，是因為復仇者已老、死者已遠，榮譽的算術終於容許妥協。

伊斯蘭興起後，血親復仇被宗教法規重新框限：復仇仍被承認，但：「誰被不義地殺害，我們已給予其親屬權力，但他在復仇中不可過度」（《古蘭經》17:33）；「同態復仇」與贖罪金的制度把無盡的循環改寫為可被計量的正義。巴蘇斯之戰因而留下一句警世格言：一峰母駝可以燒掉兩個部族的青年。它既是「血仇如何開始」的故事，也是「血仇如何被敘事終止」的故事。

## 跨文化對應

| 前伊斯蘭阿拉伯 | 跨文化對應 | 共通點 |
|---------------|-----------|--------|
| 巴蘇斯之戰：母駝被射殺引發四十年內戰 | ↔ 愛爾蘭《奪牛長征》（Táin Bó Cúailnge）：褐牛被奪引發史詩大戰 | 珍貴牲畜作為榮譽載體，小損失引爆大規模動員 |
| 巴蘇斯以悼詩催促親族復仇 | ↔ 索馬利氏族的 geeraar 戰詩：詩句動員血親集團 | 口傳詩不是旁白，而是復仇的點火器 |
| 穆哈爾希爾拒絕賠償金、堅持「不和解」 | ↔ 荷馬《伊里亞德》阿基里斯拒絕阿伽門農的贈禮（卷九） | 榮譽邏輯壓倒財物補償，調停屢屢失敗 |
| 庫萊卜之死與跨代復仇 | ↔ 希伯來聖經《民數記》35:19–21 的「血的復仇者」（go'el ha-dam） | 復仇被制度化為親屬義務，而非私人情緒 |
| 雙方以「日子」命名戰役，記憶反覆被誦 | ↔ 冰島《尼雅爾薩迦》（Njáls saga）：焚屋、復仇與 Thing 仲裁 | 口傳敘事既保存仇恨，也提供結案的舞台 |
| 血親部族間的長期內戰 | ↔ 印度《摩訶婆羅多》：俱盧族與般度族的家族大戰 | 同族相殘的悲劇需要外部調停者（黑天／肯達王） |
| 女性以詩激化復仇 | ↔ 德國《尼伯龍根之歌》克里姆希爾德的復仇 | 女性成為記憶與復仇的持久化力量 |
| 詩人記誦使仇恨跨越世代 | ↔ 南斯拉夫 gusle 口傳史詩（科索沃循環） | 無文字法庭的社會裡，詩即是檔案 |
| 庫萊卜的主張引發「禁牧」之爭 | ↔ 羅馬共和時代的公有牧地（ager publicus）之爭 | 看似技術性的放牧權，實為身分與權力的界線 |
| 伊斯蘭以復仇限制與贖罪金收束血仇 | ↔ 漢謨拉比法典第 196 條「以眼還眼」及其賠償邏輯 | 從無限復仇走向可計量的報復，國家壟斷正義 |

這十組對應指出一個反覆出現的結構：在缺乏中立司法權的社會裡，名譽必須由公開言說來維護，而公開言說又會把一時事件固定成永久義務。牲畜、女人或田界之所以能釀成大禍，不是因為它們本身價值無限，而是因為它們被拿來 衡量 群體的尊嚴。

另一個差異同樣值得注意。愛爾蘭與印度史詩中的大戰，往往證成國王或英雄的命運；巴蘇斯之戰卻以「不和解」的遺言為核心，將選擇權交給還活著的人。它的悲劇不是戰敗，而是明知代價仍被榮譽推著走；因此阿拉伯諺語引用它時，語氣更接近警告，而非頌揚。

最後，這則故事也提醒我們神話研究的史料邊界。現存詩句、譜系與「消息」（akhbār）經過九世紀以前的層層編集，史詩《齊爾·薩利姆》又再添加新的價值觀。我們能可靠地說的，是阿拉伯傳統「如何講述」一場血仇，而不是它「是否」照那樣發生；而講述方式本身，正是神話學要處理的對象。
