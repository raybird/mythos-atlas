# 懺悔青銅板：女僕與天之主

- **文化：** 前伊斯蘭阿拉伯神話 (Pre-Islamic Arabian Mythology) — 南阿拉伯／薩巴

## 故事背景

在薩巴文化圈的哈拉姆（Haram）村，矗立著兩座奉祀天之主都·薩馬維（Dhu-Samawi）的聖所——亞格魯（Yagruw，位於瓦迪·舒代夫，通往納季蘭的商路上）與馬蘭（Maran）。亞格魯以兩口涼井聞名，其名即「有涼水之處」。進入神殿範圍的人必須遵守嚴格的儀式純淨規則：不得穿著沾染喪葬穢氣的衣物、進入聖井區前須淨化、不可未淨化便在聖井邊停留。違反規則者會觸怒天之主，遭致疾病、牲畜損失與厄運；唯一的補救之道是公開懺悔、以祭品贖罪並繳納罰金，將懺悔鐫刻在青銅板上懸於神殿。這類懺悔青銅板共出土七件，其中至少五件獻給都·薩馬維，且執筆者多為女性。

## 情節

女僕豪利雅特（Hawliyyat）是蘇萊姆（Sulaym）氏族的家奴，平日負責紡織羊毛與看守井水。開春後主人賞賜她一件新斗篷與羊毛衣裳。她欣喜地穿上新衣，卻不知道——或者不願承認——這件羊毛衣沾染過喪葬之穢。

她穿上那件衣物，一如往常前往亞格魯聖井區汲水。當她俯身觸碰井沿的清涼水面時，天界的風忽然停歇，井水泛起不祥的暗紋。她心知自己違反了淨化規則，卻因懼怕主人責罰而選擇隱瞞。

當夜，她的羊群開始接連病倒，三日後她自己也高燒臥床，夢中屢屢見到一位居於天空的身影以懲罰的言語威嚇。氏族中的長者聞訊，斷言她冒犯了天之主，唯一的生路是前往神殿公開懺悔。

豪利雅特拖著病體來到亞格魯。祭司以涼井之水為她淨身，她在神殿前俯首跪下，將自己穿戴不潔衣物、向主人隱瞞的過錯一一陳述。祭司命人將她的懺悔鐫刻於青銅板上：「豪利雅特，蘇萊姆氏族之僕，因穿戴不潔斗篷與汙穢羊毛衣，且向主人隱瞞所犯，已向天之主、巴彥（Bayan）之主懺悔；懇請都·薩馬維以恩惠相報。」她獻上祭品，繳納罰金，自此謙卑謹守淨化之禮。

青銅板被懸掛於神殿牆上，供往來商旅觀瞻。她的病痛消退，羊群復甦。從此，哈拉姆一帶的人們更加敬畏天之主——也敬畏那面記載著誠實與悔改的青銅板。

## 跨文化平行

| 懺悔青銅板 | 對應傳統 | 文化 |
|---|---|---|
| 違反儀式純淨須公開認罪 | 贖罪祭與潔淨之禮（利未記） | 以色列 |
| 穿不潔衣物觸怒神明 | 神聖物與潔淨禁忌 | 古希臘／羅馬 |
| 向神懺悔並獻祭贖罪 | 懺悔詩（šigû）與贖罪儀式 | 美索不達米亞 |
| 罪罰以疾病牲畜降身 | 罪愆與疫病之罰 | 以色列／美索不達米亞 |
| 還願碑銘刻於神殿 | 希臘羅馬 ex-voto 還願碑 | 希臘／羅馬 |
| 聖井淨化後進神域 | 恆河沐浴淨化與聖泉 | 印度 |
