# Ad族與Thamud族的毀滅：阿拉伯沙漠中的先知懲罰傳說

- **文化：** 前伊斯蘭阿拉伯神話 (Pre-Islamic Arabian Mythology)

## 故事背景

Ad族（ʿĀd，عاد）與 Thamud族（Thamūd，ثمود）的毀滅傳說屬於阿拉伯半島最古老的「先知懲罰」（punishment of the prophets）故事類型。這兩個族群在《古蘭經》中被反覆提及（如《古蘭經》第11章 Hud、第7章 Al-A'raf、第69章 Al-Haqqah），但伊斯蘭降啟前已有口傳版本存在於南阿拉伯與納季德（Najd）地區的部落記憶中。Ad族居住在也門東部與阿曼邊境的 Ahqaf（沙丘之地）地區，Thamud族則聚居在西北阿拉伯的瑪甸沙勒（Madā'in Ṣāliḥ，今沙烏地阿拉伯 al-Ḥijr）——該地的岩石切割建築至今仍存。Ad族以高大的身材、宏偉的城市建築與農業灌溉系統聞名；Thamud族則以精湛的岩石建築技術著稱。兩者皆因驕傲與違反聖約而遭受天譴毀滅——這類傳說在阿拉伯神話中的功能是維護部落間的道德秩序，並警告人類不可挑戰神的權威。

## 情節

### Ad族的黃金時代與驕傲

Ad族是先知Hud（هود）的族人，居住在南阿拉伯的 Iram dhāt al-ʻImād（以柱聞名的伊蘭姆城）——這座傳說中的城市以高聳的圓柱建築聞名，據說其華麗程度在阿拉伯無可比擬。Ad族擁有優越的體格——男子身高超過正常人類兩倍，使用巨大的石塊建造城牆與堡壘。他們發展了先進的灌溉系統（可能反映真實的也門 Marib 水壩文明），農業豐產使族群累積巨額財富。但財富與權力使 Ad族變得傲慢——他們拒絕承認神的恩典，轉而崇拜三女神（Al-Lat、Al-Uzza、Manat）與其他部落神像，迫害窮人與孤兒。

### 先知Hud的警告

神派遣 Hud——Ad族中的正直者——向族人傳道。Hud 警告族人放棄偶像崇拜與社會不義，否則將面臨毀滅。Hud 說：「你們在每一座高地上建造紀念碑，嘲笑經過的旅人。你們建造堅固的堡壘，彷彿你們會永遠活著。」Ad族嘲笑 Hud——他們說：「你只是個瘋子，被我們的眾神迷惑了。」他們要求 Hud 展示神蹟以證明他的訊息。Hud 回答：「我的證據來自神，你們無法理解。」Ad族威脅以神像的力量懲罰 Hud——如果他們的三女神降災，Hud 必死無疑。

### 三年乾旱與毀滅風暴

Hud 的警告被忽視後，神降下三年乾旱懲罰 Ad族——天空不再降雨，牧場枯萎，河流乾涸。Ad族向 Hud 求助，Hud 建議他們懺悔——但他們只在嘴上說「我們信了」，內心仍舊懷疑。當他們看見地平線上升起一片巨大的烏雲時，興奮地歡呼：「這是帶來雨水的雲！」但 Hud 告訴他們：「那不是帶來生命的雲——那是帶來毀滅的風。」一股極其猛烈的風暴（阿拉伯語：rīḥ ṣarṣar / 酷寒的暴風）襲擊 Ad族——風暴持續七天七夜，將 Ad族從地面上徹底抹去。他們的巨大建築變成廢墟，身體被風捲入沙漠深處。僅 Hud 與少數追隨者在神的保護下倖存——他們遷往哈德拉毛（Hadramawt）地區，成為現代 Hadramawt 人的祖先。

### Thamud族與母駱駝的奇蹟

Thamud族的故事發生在Ad族滅亡之後。Thamud族居住在 al-Ḥijr（岩石之地）——他們以高超的石匠技藝將山壁切割成巨大的房屋與陵墓（今瑪甸沙勒的納巴泰式岩石建築可能與 Thamud族的後代有關）。神派遣先知 Ṣāliḥ（صالح）向 Thamud族傳道，但他們要求 Ṣāliḥ 展示神蹟作為證據。Ṣāliḥ 指向一塊巨大的岩石——在他的祈禱下，岩石裂開，從中走出一頭懷孕的母駱駝（nāqat Allāh / 神的駱駝）。Ṣāliḥ 告訴族人：這頭駱駝是神的標記，牠必須自由地在土地上吃草飲水——一天喝水一天不喝，輪流與族人共享水資源。

### 母駱駝的屠殺與天譴

Thamud族起初遵守約定，但時間久了心生不滿——認為一頭駱駝消耗過多水源。族中最邪惡的人——Qudar ibn Salif——在其他人支持下用劍砍斷母駱駝的腿筋，將其殺死，並警告 Ṣāliḥ：「如果你真的是先知，現在就讓你的神懲罰我們吧！」Ṣāliḥ 預言：「三天之內，毀滅將降臨。」第三天早晨，Thamud族醒來時臉色發黃（第一天），轉為發紅（第二天），再到發黑（第三天）。第三天傍晚，一聲巨大的雷鳴（ṣayḥah）從天而降——所有 Thamud族人被當場震死，房屋倒塌，身體化為灰燼。Ṣāliḥ 與信徒因提前離開而倖存。

## 跨文化平行

| 阿拉伯傳說 | 跨文化對應 | 文化 |
|-----------|-----------|------|
| Ad族的 Iram 柱城 | 巴別塔（人類驕傲建造通天塔） | 希伯來 |
| 暴風毀滅 Ad族 | 宙斯以雷霆毀滅巨人族 | 希臘 |
| 母駱駝從岩石中走出 | 密涅瓦從朱庇特頭中誕生 | 羅馬 |
| 三天預警變色（黃→紅→黑） | 埃及十災（水變血、黑暗之災） | 希伯來／埃及 |
| Thamud族的岩石建築 | 納巴泰佩特拉／埃及神廟雕刻 | 納巴泰 |
| 先知懲罰類型 | Šuruppak 的洪水警告（Ziusudra） | 蘇美 |
| Ad族因驕傲滅亡 | 柳宗元《蝜蝂傳》／道德教化寓言 | 中國 |
