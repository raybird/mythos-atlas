# Amur (عمرو) — 男神

- **文化：** 前伊斯蘭阿拉伯神話 (Pre-Islamic Arabian Mythology)
- **職掌：** 部落守護、生命之力、祖先崇拜

## 概述

Amur（阿拉伯語：عمرو，亦拼作 Amr 或 ʿAmr）是前伊斯蘭阿拉伯萬神殿中一位較少被獨立記載的男性神祇。其名字可能源自閃族語詞根 *ʿ-m-r*（「居住、命令、人民」），暗示他與部落定居、社群秩序及生命力的賜予密切相關。在南阿拉伯碑文中，類似詞根的神名屢次出現——例如哈德拉毛王國的銘文中曾提及 ʿAmm（「叔父」），可能與 Amur 共享同一語源傳統。希羅多德在《歷史》第三卷中記載阿拉伯人崇拜兩位主要神祇——Alilat（即 Al-Lat）與 Orotalt（可能對應 Ruḍā 或 Dushara），而 Amur 作為地方性男神，可能在這些廣泛崇拜的背後扮演了部落層級的守護角色。

在前伊斯蘭阿拉伯的宗教結構中，神祇體系具有強烈的地方性與部落性——每位部落（qabīla）往往有自己的守護神（shaym），其功能超出中央萬神殿的範疇。Amur 的名字在部分貝都因口傳中與「祖先」及「血脈延續」的概念相關聯——他被視為保佑部落子孫繁衍、牧群興旺的神靈。伊斯蘭化之前的阿拉伯半島，游牧部落的生存高度依賴水源、牧場與血親紐帶，因此這類守護性男神在日常生活中扮演著比大型萬神殿神祇更為切實的角色。在一些傳說中，Amur 的形象被描述為手持長矛的戰士，守護部落營地免受敵人與惡靈侵擾。

## 神話事蹟

### 部落守護者的起源

根據貝都因口傳，Amur 是最古老的部落守護神之一——在其他神祇如 Hubal 或 Al-Lat 的崇拜興起之前，Amur 已是游牧部落在沙漠中遷徙時祈求庇護的對象。傳說 Amur 曾在一次嚴重的沙塵暴中為迷路的牧人指引方向——他以一道光柱劃破風沙，將牧人引回營地。此故事的結構與許多閃族文化中「神以光引導子民」的母題一致——希伯來傳統中耶和華以火柱引領以色列人出埃及，美索不達米亞神話中恩基以智慧之光指引人類。

### 血盟與誓言

Amur 在部分部落傳說中被視為誓言之神——當兩個部落缔結同盟時，首領會在 Amur 的聖石前宰殺牲畜，以血灑地，象徵盟約的神聖不可侵犯。這類血盟儀式（ʿahd）在前伊斯蘭阿拉伯極為普遍，而 Amur 被認為是監督盟約履行的神靈——違背誓言者將遭到 Amur 的懲罰，其牲畜死亡、水源乾涸。此功能與希臘神話中 Zeus Horkios（誓言之宙斯）及希伯來傳統中耶和華作為盟約之神的角色形成跨文化對應。

### 與其他神祇的關係

在一些南阿拉伯銘文中，Amur 與月神 Ilmaqah（或 Almaqah）並列出現——可能是作為 Ilmaqah 的輔佐神或地方代理。在沙巴王國的宗教儀式中，Amur 可能負責具體的部落事務（如仲裁與保護），而 Ilmaqah 則掌管更宏觀的灌溉與豐饒。這種「至高神＋部落守護神」的雙層結構在美索不達米亞（安努＋恩利爾＋恩基）和埃及（拉＋歐西里斯）神系中均有對應。

## 跨文化對應

| 文化 | 對應神祇 | 關係說明 |
|------|---------|---------|
| 美索不達米亞 | Nergal（戰/瘟疫） | 部落守護與戰爭保護的共同功能 |
| 希臘 | Zeus Horkios（誓言之宙斯） | 監督盟約神聖性的角色 |
| 希伯來 | El（至高神/部落之神） | 部落祖先與守護者的原型 |
| 北歐 | Heimdallr（守望者） | 保護社群免受外敵侵犯 |
| 印度 | Indra（部落之王） | 保佑戰士與牧群的武裝守護神 |

## 相關神祇

- **Hubal**：麥加卡巴的主神，Amur 可能作為 Hubal 的地方替代或輔佐存在
- **Ilmaqah / Almaqah**：沙巴王國的至高神，Amur 在部分文獻中與其並列
- **Wadd**：馬因王國的月神，與 Amur 同為北阿拉伯起源的男神
- **Dushara**：納巴泰的主神，可能與 Amur 共享「部落之主」的功能
