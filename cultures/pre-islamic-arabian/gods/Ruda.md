# 魯達 (Ruḍaw / Ruda)

- **文化：** 前伊斯蘭阿拉伯（Pre-Islamic Arabian）— 北阿拉伯遊牧部族
- **別名：** 古北阿拉伯文 rḍw（Ruḍay）、古典阿拉伯語 رضى
- **職掌：** 月亮、戰爭、復仇、援助、誓言見證

## 概述

魯達（Ruḍaw，中古薩法伊特銘文中作 Ruḍay）是北阿拉伯最受崇拜的神祇之一，也是薩法伊特（Safaitic）銘文中出現頻率僅次於阿拉特（Allāt）的神明。他的信仰至少可追溯至公元前一千紀初葉，最早見於新亞述王以撒哈頓（Esarhaddon）的銘文，其後貫穿整個古北阿拉伯碑銘傳統，直到晚古時期仍有崇拜痕跡。魯達的信仰地理集中在北阿拉伯中部的沙漠與綠洲地帶——從事半遊牧生活的貝都因部族在其留下的數千則塗鴉性祈禱文中反覆呼喚他的名字，這使他成為「沙漠之民」神話與儀式生活的核心。

魯達在古北阿拉伯的星辰神學中佔有明確的位置：他與努哈伊（Nuhay，太陽）、阿塔爾薩梅（ʿAttarsamē，金星）組成「星辰三元組」（astral triad），在此三元結構中，魯達通常被對應為月亮。學者對其專屬功能提出多種解讀——援助、戰爭或復仇，反映了遊牧生活中祈求勝利、庇護與公正的共同面向；亦有觀點將他與帕爾米拉的阿爾蘇（Arsu）聯繫。魯達的性別為男性，其「月亮」位格與北阿拉伯另一位月神瓦德（Wadd）形成區域性格的對比。

## 神話事蹟

魯達缺乏長篇敘事史詩，其「神話」主要呈現在兩個層面：其一為刻在玄武岩與沙漠礫石上的祈禱與還願銘文。薩法伊特人在戰役、掠奪與遠行前呼求魯達，銘文格式常為「以魯達之名，願他保護我」（b-rḍw / f-h l rḍw），祈求「祓除沙漠的傷害」—此足以顯示他作為沙漠遠行守護神的地位。其二為伊斯蘭早期的「神廟毀滅」傳說：伊本·伊斯哈格（Ibn Isḥāq）與伊本·希沙姆（Ibn Hishām）記載，魯達的神廟在伊斯蘭擴張期間被摧毀，其神像遭毀——此傳說的歷史核心雖難以考證，卻與其他阿拉伯偶像（如 Isāf 與 Nāʾilah）的「石化」敘事同樣反映偶像崇拜被正式廢除的過程。

魯達信仰的消退速度相當可觀：到了伊斯蘭初期，活絡的崇拜記憶已經模糊。伊本·卡勒比（Ibn al-Kalbī）在《書集》（Kitāb al-Aṣnām）中僅透過化石化的神名記錄魯達——如 ʿAbdu-Ruḍà（魯達之僕）此類以部落祖先為名的稱號，他坦承已無法確知這些名稱最初所指的偶像樣貌。這使魯達成為「神名比神話敘事更持久」的典型例證。

## 跨文化對應

| 前伊斯蘭阿拉伯 | 跨文化對應 | 共通點 |
|--------------|-----------|--------|
| 魯達（月/星辰三元組成員） | ↔ 蘇美 Nanna-Sin／巴比倫 Sin | 月亮位格與天文神學 |
| 星辰三元組（魯達/努哈伊/阿塔爾薩梅） | ↔ 巴比倫 辛/沙瑪什/伊什塔爾 | 日月金星的階序結構 |
| 魯達＝戰爭/復仇之神 | ↔ 希臘 Ares／北印度 Skanda | 戰神受理戰事與勝負裁決 |
| 神名殘存於部落族名 | ↔ 迦南 Baal／埃及 Amun | 神名轉化為人名與地名的神聖痕跡 |
| 伊本·卡勒比記載神廟毀滅 | ↔ 古蘭經 偶像毀滅敘事 | 偶像崇拜敘事被「書寫化」的過程 |

## 相關神祇

- **努哈伊（Nuhay）** — 太陽神，魯達在星辰三元組中的同伴
- **阿塔爾薩梅（ʿAttarsamē）** — 金星神，三位一體結構的另一成員
- **瓦德（Wadd）** — 南阿拉伯月神，與魯達共享月亮位格的不同區域傳統
- **阿拉特（Allāt）** — 薩法伊特銘文中出現頻率最高的女神，與魯達並列為北阿拉伯主要崇拜對象
- **阿爾蘇（Arsu）** — 帕爾米拉的駱駝商隊守護神，部分學者主張與魯達同源

## 文化遺產

魯達的案例提醒我們：前伊斯蘭阿拉伯的宗教生活並非以「神話敘事」為主要載體，而是以銘文、還願與神名傳承為骨架。當敘事缺位，我們仍能透過萬餘則沙漠祈禱文重構一個以月亮為軸心、以守護與復仇為訴求的貝都因神學。此外，伊斯蘭早期文獻（伊本·伊斯哈格／伊本·卡勒比）對其神廟毀滅的記載，是「前伊斯蘭多神教被正式終結」的重要文獻憑證，也使魯達成為研究宗教轉型與偶像崇拜廢除的關鍵標本。
