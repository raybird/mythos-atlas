# 湯加洛阿（Tangaloa）

- **文化：** 波利尼西亞神話 — 東加王國（Tonga）
- **職掌：** 天界 `Langi` 的統治者、天空、海與風暴之力、神聖王權的授予者
- **同源異名：** Tangaroa／Tagaloa／Taʻaroa／Tanaʻoa／Kanaloa／Angaro
- **分化神：** 東加至少七位同名神，各司一職（`Lafitani 2017` 整理）
- **詞源：** 通說指「長頜骨」，即「長口／長舌」，與「善於言說者」相通
- **天系：** 父 Taufulifonua（`Taufulifonua`「天底」）、母 Havea Lolofonua、兄 Hikuleʻo（`Hikuleʻo`）
- **象徵：** 金鴿 `tulī`（太平洋金斑鳩）、海蛇 Hemoana、長鰭魚、長舌
- **對應神：** [Tangaroa](Tangaroa.md)（夏威夷 Kanaloa，海洋）、Māui（冥界之主）、Hikuleʻo（`Pulotu` 陽間之主）

## 概述

湯加洛阿（Tangaloa）是東加神話中最具政治學意味的神。但在開始之前必須先釐清一個容易犯的錯誤：**東加的 Tangaloa 不是海神，而是天界之主。** 同一個詞根在夏威夷構成了海洋神 Kanaloa，在毛利構成了潮汐之神 Tangaroa-whakamautai，在大溪地構成了自卵創世的 Taʻaroa；而在東加，他坐在 `Langi`（天界）上，向下望見的只有海。這個反差本身就是最值得比較的文化史現象：同一神名在擴散過程中，把「天」與「海」的權限做了交換。

東加版本的宇宙秩序不是靠弒父建立的，而是靠**分封**建立的。Gifford 1924 記載的開篇譜系是：Taufulifonua 成年之後，其姊 Havea Lolofonua 為他生下 Hikuleʻo，於是三兄弟分配創造物——Hikuleʻo 取 `Pulotu`（陽間、現世），Tangaloa 取天界，Māui 取冥界。剩餘的部分再由兩位形體化神瓜分：Hemoana 以海蛇之形取海，Lupe 以鳩之形取陸地。這段四分法把天空、陸地、海與冥界一次性分配完畢，之後所有的神話——島嶼如何生成、人類從哪裡來、第一位國王為何有權统治——都只是在這個框架內填入內容。

詞源進一步印證了這位神的社會面向。通說 `Tangaloa` 指「長頜骨」，即「長口」「長舌」，象徵善於言說、能宣告未來的人。現代的譜系研究（`Lafitani 2017`）據此把 Tangaloa 視為一個被神格化的氏族 `haʻa Tangaloa`——「發言者、宣告者、講述未來者」——並認為其世系功能是口傳史的守護。東加王國的權力結構建立在 `haʻa` 諸氏族之上，其中 `haʻa Loʻau` 掌物質技藝與社會工程，`haʻa Tangaloa` 掌言說與預見；兩者的分工正是東加「天（`Langi`）／地（`Maama`）／冥界（`Lolofonua`）」三分宇宙觀的政治翻譯。

## 名號與分化

東加至少有七位 Tangaloa，各有明確職掌（`Lafitani 2017`；`Moala 1994: 4`）：

| 名號 | 職掌 |
|------|------|
| Tangaloa ʻEiki（主） | 統治天界 `Langi` |
| Tangaloa Langi | 自然現象的統御者 |
| Tangaloa Mana | **海洋**之神；東加的海神是這一位，而非 Tangaloa 本體 |
| Tangaloa Tufunga | 物質技藝之神，鑿製器物、雕出島嶼 |
| Tangaloa ʻAtulongolongo | 神的使者，化金鴿巡島 |
| Tangaloa ʻEitumatupuʻa | 葬祭之神，第一位 Tuʻi Tonga 的父 |
| Tangaloa Tamapoʻuliʻalamafoa | 名號見於諸錄，職掌記載不一 |

必須提醒的是：**各來源對這些神的親子關係互相矛盾。** Craig 在《Dictionary of Polynesian Mythology》（1989: 100）明確指出，不同來源對 Tangaloa 與 Hikuleʻo、Māui 之間究竟是兄弟、父子還是表親各有說法。這種矛盾本身就是資料：東加口傳並無單一權威文本，神話隨氏族而變，學者只能在多條譜系間並置。

## 神話事蹟

### 一、拋下木屑造島

年老的 Tangaloa 從天上往下看，只看見海，於是派 Tangaloa ʻAtulongolongo 化為金鴿 `tulī` 下去偵查。金鴿回報只找到水下一片暗礁（後來的 ʻAta）。Tangaloa 便命 Tangaloa Tufunga 把正在雕製的器物木屑一塊塊拋進海裡。金鴿前後三次飛下，前兩次都撲空，第三次發現木屑已堆成一座島——**ʻEua**。之後再拋，成 Kao 與 Tofua（Gifford 1924）。

這段神話的結構極為重要：**島嶼不是被「造」出來的，而是被「敲下來的剩料」堆積而成的。** 神的世界其實早於人的世界存在，人的島只是神的工作場所的副產品。這與毛利「Tāne 以雙腳頂開天地」那種以身體暴力重塑宇宙的想象，形成同一文化圈內的兩種極端。

### 二、蚯蚓生人

金鴿再度飛往 ʻAta，銜來一粒種子；種子長成覆蓋全島的藤蔓。金鴿啄斷藤根，數日後再來，根已腐爛，其中盤著一條肥厚的蟲子。金鴿把蟲子啄成兩截：上半截化為人，名 **Kohai**；下半截也化為人，名 **Koau**。金鴿喙上還黏著一點碎屑，抖落，也化為人，名 **Momo**。三人是東加最早的人類；Māui 從 `Pulotu` 為他們娶妻，其後裔即東加人（Gifford 1924: 49）。

這是本輪新增的另一頁《蚯蚓、鳥蛋與黏土：波利尼西亞與全球的原初物質比較》的錨點。三位始祖既非神所捏造，也非神之子，而是**一條腐爛蟲子的兩半**。有趣的是，王權神話隨後又把這三人貶抑為「蟲之裔」（offspring of the worm），以襯托天之後裔的正當性——同一批祖先在兩套神話裡得到完全相反的評價。

### 三、ʻAhoʻeitu：第一位由神授權的國王

Tangaloa 之子 Tangaloa ʻEitumatupuʻa 屢次降到地面，與 Niuatoputapu 島貝殼採集女子 Ilaheva（又作 Vaʻepopua）同居，返天後留下兒子 ʻAhoʻeitu。男孩長大後追問父親下落，母親告知須攀上 `toa`（鐵樹）通天。他爬上去，見到父親，也見到四位同父異母的哥哥。四人嫉妒，將他殺死並吃掉。

Tangaloa 察覺後大怒，命四人把屍體吐入 `kumete`（木碗），施法使他復活。此後他宣布：既然四兄弟犯下殺弟之罪，若他們也想下到地上，就必須**侍奉** ʻAhoʻeitu。於是 ʻAhoʻeitu 被送回地面，成為第一位 Tuʻi Tonga（由神授王權者），代表其父統治；四位哥哥則成為最初的 `Falefa`「四House」之首，其中最年長的 Talafale 雖最接近王位，卻永遠不能繼承——父親的話是：「Talafale，你永遠不會是 Tuʻi Tonga，因為你是殺人者」（Gifford 1924: 42；1929: 49–59；`Rutherford 1977: 28`）。

Gifford 依三十九代世系與平均在位三十年回推，估計 ʻAhoʻeitu 約於公元 950 年即位（末代 Tuʻi Tonga 逝於 1865 年）。這條時間軸讓東加王室的「神授」說法落在可計算的歷史窗口內。

這段神話與卡瓦（`kava`）儀式結構上幾乎逐拍對應：屍體被分食後要求吐回、以水復活（`Bott 1972: 227` 稱 ʻAhoʻeitu 神話「幾乎逐句複述卡瓦儀式」）——國王的加冕與卡瓦的傳遞，共享同一套「分食—吐回—澆水—復活」的腳本。可參照本站〈卡瓦起源〉與〈神聖飲料比較〉。

### 四、誓言與禁忌

東加人以 Tangaloa 立誓（`fakawai ʻo Tangaloa`），此誓以天神為見證人，法律效力高於人證；違誓即構成 `tapu` 破犯，可由國王以 `moei-moei` 解咒儀式赦免（`Gifford 1929` 關於國王禁忌與解咒的記載；`Mariner 1819` 亦記國王觸犯禁忌須由他人餵食十個月）。本文不採用流行說法中「違誓者會被 Tangaloa 之浪捲走」的敘述——該說法在所查一手文獻中未獲支持，僅見於通俗改寫。

## 跨文化對應

| 文化 | 對應存在 | 共同結構與差異 |
|------|---------|---------------|
| 夏威夷 | Kanaloa | 同源詞根，但權限互換：夏威夷的 Kanaloa 是海神與航海守護神，東加的 Tangaloa 在天。`Encyclopaedia.com`「Tangaroa」條並指出夏威夷傳教士曾把 Kanaloa 改寫為撒旦，是同源神被殖民者重編的最著名案例 |
| 薩摩亞 | Tagaloa | 今日薩摩亞國父 Tuʻi Atua Tupua Tamasese Taʻisi Efi 稱 Tagaloa 為「a very important founding ancestor」，主張一切土地與頭銜都回溯至他（2014: 42–44），並稱其為「一切生物的祖先」（2014: 43）——這是把 Tangaloa 重新置於創世位置的當代政治神學 |
| 大溪地 | Taʻaroa | 同源名，但職能完全不同：大溪地 Taʻaroa 敲破卵殼、由身體各部位生出諸神，屬於「自卵創世」；東加 Tangaloa 不創造世界，只**統治已分封的天界**。詳見〈波利尼西亞創世神話與全球創世類型比較〉 |
| 毛利 | Tangaroa-whakamautai | 同一詞根在毛利成為潮汐控制者，可見 Tangaroa 系神祇的海洋職能是在東 Polynesia 側被強化的 |
| 美索不達米亞 | 安／安努（`cultures/mesopotamian/gods/安.md`） | 兩者共享「父王把宇宙權柄委派給子嗣」的結構：Anu 承 An 及諸神之位，東加的 Taufulifonua 把天界分給 Tangaloa。差別在結果——美索不達米亞的天子最終被奪權與殺害（`cultures/mesopotamian/gods/` 提亞瑪特相關記錄），東加的天王從未被弒殺，王權只能經由半神中介下放到地面 |
| 埃及 | 努特與蓋布（`cultures/egyptian/gods/努特.md`、`蓋布.md`） | 埃及的天（Nut）是**人格化的空腔**，靠分離才成世界；東加的 `Langi` 是**已劃分完成的主權領域**，分離是政治行為而非宇宙事件。比較〈天父地母分離〉可見兩種「天」的性質 |
| 全球 | 分封制與委命宇宙秩序 | 與蘇美爾王權神授、波斯王權神授同屬「權柄自上而下逐級授予」的模型；東加的特殊處在於**每一級都留下可追溯的名字**（七位 Tangaloa、四位 `Falefa` 兄長、`haʻa` 氏族），使神話成為一份可背誦的政治檔案 |

東加 Tangaloa 最獨特之處，在於他同時是**自然神學的主權者**與**口傳的守護者**。天空與風暴屬於他，宣告與講述也屬於他；把「天」與「言說」綁在一起，是其他文化少見的組合，也是東加王權能以「祖先出自天」為理由持續千年的文化技術。
