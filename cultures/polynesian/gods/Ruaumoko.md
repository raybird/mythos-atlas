# 魯奧莫科 (Ruaumoko)

- **文化：** 波利尼西亞神話（毛利／玻里尼西亞）
- **職掌：** 地震、火山、季節變換
- **象徵：** 大地顫動、地熱蒸汽、噴發

## 概述

魯奧莫科（Ruaumoko / Rūaumoko）是波利尼西亞神話中的地震之神，為天父蘭吉努伊（Ranginui）與地母帕帕圖阿努庫（Papatūānuku）的末子。在所有天地分離的神話變體中，魯奧莫科具有獨特的地位——他是唯一未曾經歷「光明世界」的神祇，因為天地分離時他仍在母親的子宮中吸吮母乳。當帕帕圖阿努庫因思念丈夫而翻身嘆息時，魯奧莫科在她腹中移動，引發大地震動。他的每一次翻滾都是地震的源頭；他的呼吸從地裂中竄出，成為地熱蒸汽與火山噴發。

在毛利語中，Rū 意為地震、轟鳴或震動，aumoko 則指向大地深處。南島民族遷徙過程中，關於地底巨人的神話隨著玻里尼西亞人的航海足跡散布至夏威夷、紐西蘭、復活節島與社會群島。

## 神話事蹟

### 天地分離中的嬰兒

在天地分離神話中，眾神商議如何分離緊密交合的天地父母。森林神塔內（Tāne）以雙腳頂開天空後，風暴神塔威力馬提亞（Tāwhirimātea）因反對分離而掀起風暴報復眾兄弟。戰爭中，地母帕帕圖阿努庫為了安慰自身而轉動身體——但她忘了魯奧莫科仍在她的懷中吸乳。這翻身之動讓魯奧莫科驚醒並蠕動，從此開啟了地震的時代。此版本記載於《毛利神話與傳說》（George Grey, 1855）的天地分離敘事中。

### 地下之火與火山

部分口傳傳統（特別是懷卡托地區的毛利部落）將魯奧莫科與地熱活動直接連結。傳說魯奧莫科在地下用母親的體溫烤火取暖，偶爾將火焰噴出地表形成火山。當他向母親抱怨寒冷時，帕帕圖阿努庫便以地下岩漿為他供暖——這些岩漿來自天堂的火焰，被塔內困在地窟中。因此羅托魯瓦（Rotorua）地區的大量間歇泉與地熱池被視為魯奧莫科的呼吸孔。

### 季節的掌控者

在某些說法中，魯奧莫科也掌管季節的轉換——當他在母親腹中面向不同方向時，地面上的季節隨之變化。當他面朝北時，北半球（赤道以北的玻里尼西亞島嶼）正值夏季；當他轉向南方時，南半球（紐西蘭）迎來溫暖。此觀念反映了毛利人對地震與季節間關聯性的觀察。

## 跨文化對應

| 文化 | 神祇 | 相似點 |
|------|------|--------|
| 日本 | 大鯰（Namazu） | 地底大鯰魚震動引發地震，被鹿島神以要石鎮壓 |
| 希臘 | 波賽頓（Poseidon） | 地震之神（Enosichthon／撼地者）兼海洋之神 |
| 北歐 | 洛基（Loki） | 被縛於地底，其掙扎引發地震 |
| 印度 | 八婆龍（Shesha／Adishesha） | 支撐世界的巨蛇，翻身時引發地震 |
| 中國 | 鰲魚 | 大地由巨鰲背負，鰲魚眨眼時大地震動 |
| 美洲原住民 | 龜島傳說相關 | 巨龜背負世界，龜動則地震 |
| 印尼 | 巴厘神話 | 地底巨人（Bhoma）翻身引發火山與地震 |

## 相關神祇

- **天父蘭吉努伊（Ranginui）**：被分離的父親
- **地母帕帕圖阿努庫（Papatūānuku）**：母親，魯奧莫科在其腹中永恆居住
- **塔內（Tāne）**：森林神，執行天地分離的兄弟
- **胡魯（Huru）與阿胡瓦（Ahuwa）**：部分部落傳說中協助魯奧莫科的地底精靈
