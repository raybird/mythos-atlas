# 塔維里—馬提亞 (Tāwhiri-mātea)

- **文化：** 波利尼西亞神話 (Polynesian Mythology)
- **職掌：** 風與風暴之神、天空之父之子

## 概述

塔維里—馬提亞（Tāwhiri-mātea，也拼作 Tāwhiri）是波利尼西亞（特別是毛利）神話中的風與風暴之神，為天父朗吉（Rangi）與地母帕帕（Papa）之子。在所有神祇之中，塔維里—馬提亞是唯一拒絕父母分離的神——當他的兄弟姐妹們決定推開天空以讓光線進入世界時，他憤怒地反對，從此成為天空之子中與人類世界敵對的力量。他的名在毛利語中意為「風的精髓」，細分為十二種不同的風向，每一種都有專名與特定的性格。

## 神話事蹟

### 天地分離的異議者

在著名的朗吉與帕帕分離神話中，大神塔內（Tāne）以巨力將天空推向上方，其他眾神跟隨協助。但塔維里—馬提亞從未同意這場分離。他對兄弟們的背叛感到暴怒，認為毀壞父母永恆的擁抱是不可饒恕的罪行。他追隨父親朗吉升入天空，從此盤踞於天界的各個角落，以風與風暴向人間與眾神報復。

### 風暴的征伐

塔維里—馬提亞向眾神發動了一場全面的戰爭。他召集了所有的風之子——包括東風、西風、南風、北風，以及狂風、颶風、暴風雨、龍捲風。他首先攻擊海洋之神坦加羅亞（Tangaroa）——掀起巨浪翻覆海洋、淹沒海域、追殺坦加羅亞的後代魚類。坦加羅亞的兩個孩子被迫逃到陸地避難，使坦加羅亞從此對陸地神明懷有怨恨。

然後塔維里—馬提亞轉向攻擊農業之神隆戈（Rongo）與未耕作物之神豪米亞（Haumia），以風暴擊打大地。但地母帕帕將隆戈與豪米亞藏入自己的身體（大地）中，使他們免於被連根拔起。最後他攻擊戰神庫（Tū）——庫雖然在暴風中搖晃但始終不曾被擊倒。最終風暴止息，塔維里—馬提亞回到天父身邊，成為永遠盤旋在天空的風之主。庫隨後以人類替代品報復——他編織陷阱捕捉了風的後代，從此人類雖然可以設法抵抗風暴，卻永遠無法完全征服風的力量。

### 風的十二個面向

毛利傳統中塔維里—馬提亞的權力分為十二種風向（但各部落分類略有不同），每一種風由其特定的子神掌管：東北風（Marangai）帶來雨；西南風（Hauāuru）帶來涼爽；南風（Tonga）來自南極的寒冷；北風（Tokerau）溫暖而乾燥。戰士在出征前向特定的風祈禱，漁民與領航者根據風向判斷航行的吉凶。

## 跨文化對應

| 波利尼西亞 | 跨文化對應 |
|-----------|-----------|
| 塔維里—馬提亞（Tāwhiri-mātea） | ↔ 北歐索爾（Thor）— 雷電風暴之神，與眾神有衝突 |
| | ↔ 印度因陀羅（Indra）— 風暴之主、以金剛杵作戰 |
| | ↔ 希臘埃俄羅斯（Aeolus）— 風的掌管者 |
| | ↔ 日本素戔嗚尊（Susanoo）— 暴風神，與天照大神衝突後被放逐 |
| | ↔ 馬雅瓦奇（Huracan）— 颶風之神，創世神話中的毀滅力量 |
| | ↔ 中國風伯（Feng Bo）— 風神，掌管風向 |

塔維里—馬提亞與日本素戔嗚尊的平行最為精確：兩者都是自然之子（天父/天照的兄弟），因反對天界的既有秩序而發動暴力反抗，導致與兄弟姐妹的永久分裂。但塔維里—馬提亞留在天界繼續為風，而素戔嗚尊被放逐降至地上成為出雲的英雄祖先。另外，塔維里—馬提亞與父親留在天界而攻擊地面的姿態，也與希臘神話中泰坦神反對奧林帕斯新神的結構相似。

## 相關神祇

- **Rangi** — 天父，塔維里—馬提亞的父親，與他一同留在天空
- **Papa** — 地母，塔維里—馬提亞的母親
- **Tāne** — 森林與鳥類之神，天地分離的主要執行者，塔維里—馬提亞的首要敵人
- **Tangaroa** — 海洋之神，遭塔維里—馬提亞攻擊後退入深海
- **Tū** — 戰神，在風暴中未被擊倒
- **Rongo** — 農業之神，遭追殺後藏入大地
