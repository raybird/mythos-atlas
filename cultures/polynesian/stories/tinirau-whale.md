# 提尼勞與鯨魚凱 (Tinirau me Te Tohorā)

- **文化：** 波利尼西亞神話 (Polynesian Mythology)

## 故事背景

提尼勞（Tinirau）是海洋之神坦加羅亞（Tangaroa）的兒子，掌管魚類與海洋生物。他的名字在部分波利尼西亞島嶼中意為「無數的魚群」。提尼勞居住在大洋深處的一座美麗島嶼上，那裡永遠是夏天。他最珍貴的伴侶是一頭名為圖圖努伊（Tutunui，一說名為凱「Kae」的鯨魚）的巨大鯨魚——提尼勞將其馴化為坐騎，騎乘牠穿越太平洋各島。此故事廣泛流傳於紐西蘭毛利、庫克群島、薩摩亞與夏威夷的波利尼西亞傳統中。

## 情節

### 第一幕：神聖的鯨魚

提尼勞與鯨魚圖圖努伊之間存在一種特殊的連結——提尼勞在鯨魚的背上建造了一座小型的神聖祭壇，每當他騎鯨出行，他在祭壇上誦唱引導歌，鯨魚便按照歌聲的方向前進。圖圖努伊不只是一個坐騎——提尼勞可以與牠溝通，鯨魚是提尼勞與海洋之間的靈性橋樑。村人視鯨魚為半神，每個月向海中投入祭品以確保鯨魚繼續保護島嶼。

### 第二幕：祭司的背叛

一位名叫凱（Kae）的祭司兼巫師拜訪提尼勞的島嶼。凱看見圖圖努伊的巨大與優美，內心升起貪婪。他向提尼勞請求騎乘鯨魚一遊，提尼勞勉強同意，但告誡他不可在鯨魚背上進行任何傷害性的行為，並必須在日落前返回。凱騎上鯨魚，卻將牠引向自己的村落。抵達淺灘後，凱召集村民將鯨魚拖上岸並殺死——切開鯨魚的腹部，將肉分給全村食用。鯨魚的鮮血染紅了整片沙灘。

### 第三幕：追蹤與發現

提尼勞等待鯨魚歸來，但日落後仍無蹤影。他感到鯨魚的靈魂已從海洋中消失。提尼勞派他的姊妹（或隨從）沿著海岸線搜尋——但凱為了躲避追查，將鯨魚的骨頭藏入了一個秘密的洞穴中。提尼勞的姊妹們有一種特殊的能力：她們會一個接一個地在各村落中跳舞，所有人的目光都會被她們吸引，而鯨魚的骨頭若藏在附近，則會在舞蹈進行時發出震動。

姊妹們來到凱的村落，開始跳舞。村落中的人們為她們的舞姿而著迷，而藏在洞穴中的鯨魚骨頭也開始顫動，發出低沉的共鳴聲。提尼勞的姊妹順著震動找到了鯨魚的骨頭——凱的背叛被暴露了。

### 第四幕：復仇與律法

提尼勞得知真相後，命令海浪淹沒凱的村落。他派遣鯊魚與梭魚群攻擊凱的海岸，使凱的族人永遠無法安全地進入海中捕魚。凱本人被提尼勞施展的魔法變成一條永遠在淺灘中翻滾的魚（一說被變為第一條魟魚）。

從此之後，波利尼西亞的漁民在捕到鯨魚後，必須舉行特定的儀式向提尼勞請求寬恕，並將鯨魚的第一塊肉（心臟或舌頭）歸還給海洋——這是因為鯨魚是提尼勞的神聖動物，人類只有在極度需要時才可獵鯨，且必須以儀式修補人與海洋神靈之間的裂縫。

## 跨文化平行

| 波利尼西亞元素 | 跨文化平行 |
|---------------|-----------|
| 神聖的鯨魚被殺，英雄追蹤復仇 | ↔ 北歐亞爾維斯（Álvíss）神話被欺騙 |
| | ↔ 希臘赫拉克勒斯殺死神牛 |
| 以舞蹈引出隱藏的骨頭 | ↔ 北非的歌唱尋骨童話 |
| 背叛的客人 | ↔ 希臘坦塔洛斯（Tantalus）以神之宴測試眾神 |
| 祭司轉化為魚 | ↔ 美索不達米亞奧安內斯（Oannes）— 魚形使者 |
| 獵鯨後的儀式賠罪 | ↔ 西伯利亞尼夫赫人（Nivkh）的熊節禮儀 |

提尼勞的故事最特殊的結構在於「海洋的回報」——鯨魚不被視為資源，而是有靈魂的靈性存在，人類對鯨魚的利用必須通過儀式協商，而非單方面的掠奪。這種觀點與西伯利亞民族在獵殺熊後舉行「送熊儀式」的邏輯完全一致——動物為了人類的生存而犧牲，人類有義務以歌聲與舞蹈送其靈魂回歸神界。
