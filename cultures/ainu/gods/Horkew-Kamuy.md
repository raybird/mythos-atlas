# Horkew-Kamuy — 神聖熊之使徒

Horkew-Kamuy（霍爾克烏·卡穆伊）是阿伊努神話中以熊形態降臨人間的神靈使徒，與 Kim-un-kamuy（山之主）密切關聯但具有獨特的神話角色。Horkew-Kamuy 不是熊本身，而是「以熊之形旅行至人間的 Kamuy」——一個跨越神人邊界的使者，每年秋季循固定路徑從山界（Kim-un mosir）降臨河谷的人類村落。

## 神格與屬性

- **領域：** 神人邊界穿越、季節訊使、食物贈禮、Iyomante 熊祭核心
- **象徵：** 灰色或棕色的年輕公熊
- **地位：** Kamuy 的使者（非至高神，但地位崇高）
- **出現時機：** 每年秋季，從山界降臨人間

## 神話事蹟

### 從神界到人間的旅程

根據阿伊努 Kamuy Yukar（神謠），Horkew-Kamuy 在每年秋季接到 Kim-un-kamuy 的指令，離開山界的營火（據說山頂的篝火就是熊靈的營火），沿著河谷下行至人類村落。牠知道哪些人類家庭遵循禁忌、善待動物——只有這些家庭才會被 Horkew-Kamuy 選中。

人類家庭發現一頭落單的年輕熊時，知道這是 Horkew-Kamuy 的化身。他們以最好的食物餵養牠、以溫和的語言與牠對話、為牠取名字——從此刻起，這頭熊成為「神的子孫」（kamuy-pasuy），享受與人類嬰兒同等的待遇。

### 飼養期：一至兩年的等待

Horkew-Kamuy 在人間被飼養一至兩年，期間享有特殊地位：
- **女性飼養者**（kamuy-cha）以母乳餵養小熊，建立擬血緣關係
- 熊被允許在村落中自由行走，不可被驅趕或鎖鏈束縛
- 人類避免在熊面前爭吵或使用暴力——因為熊會將所見帶回神界報告

這段飼養期是阿伊努宗教最獨特的元素之一：它不是「豢養獵物」而是「款待神的使者」，時間的長短反映了人類對 Kamuy 的尊敬程度。

### Iyomante：送返儀式

當 Horkew-Kamuy 被認為已充分享受人間生活後，舉行 Iyomante（送返儀式）。儀式中：
1. 薩滿（tusu-guru）向熊吟誦送別詞，感謝牠帶來的祝福
2. 以最莊嚴的方式結束熊的生命（非屠宰，而是「送返」）
3. 熊的頭骨被供奉於 inau-sir（祭壇），象徵靈魂已安全返回神界
4. 全村落共享熊肉（分配規則嚴格：不同部位歸不同性別與年齡層）
5. 頭骨被保存數年後，舉行第二次小型儀式，將頭骨送入森林

### 熊的回報

Horkew-Kamuy 返回神界後，向 Kim-un-kamuy 報告人類的善惡。如果人類善待了牠，Kim-un-kamuy 將在來年賜予更多獵物與豐收；如果人類怠慢了牠，山神將減少鹿群與鮭魚的數量，使人類挨餓。此邏輯構成了阿伊努「以善意換取自然恩賜」的核心宇宙觀。

## 跨文化對應

| 阿伊努 Horkew-Kamuy | 對應概念 | 文化 |
|---|---|---|
| 動物作為神的使者降臨人間 | 阿努比斯（Anubis）以胡狼形態引導靈魂 | 埃及 |
| 飼養神聖動物後獻祭 | 埃及 Apis 神牛 | 埃及 |
| 熊返回神界報告人類善惡 | 北歐 Odin 的渡鴉 Huginn/Muninn | 北歐 |
| 神使以特定動物形態降臨 | 印度毗濕奴（Vishnu）十化身 | 印度 |
| 養與殺的神聖循環 | 薩米人熊祭（Bear Ceremony） | 北歐薩米 |
| 動物自願獻身的信念 | 北美原住民「動物犧牲」觀 | 北美原住民 |

Horkew-Kamuy 的核心獨特處在於「飼養期」——其他文化的神聖動物通常直接被獻祭（埃及 Apis），而阿伊努要求人類先與動物建立情感連結，再將其「送返」。此差異反映阿伊努的世界觀：動物不是祭品，而是訪客。

## 關聯 Kamuy

- **Kim-un-kamuy：** Horkew-Kamuy 的派遣者與最終裁判者
- **Rep-un-kamuy：** 海神，與山神形成陸海二元對應
- **Inau-Kamuy：** 在 Iyomante 中承載送別祈禱的媒介
