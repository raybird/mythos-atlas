# 奧基庫爾米 (Okikurmi)

- **文化：** 愛努神話 (Ainu Mythology)
- **職掌：** 文化英雄、人類的教導者、神人之中介

## 概述

奧基庫爾米（Okikurmi，又稱 Okikurumi、Aynurakkur、Okikurmi Kamuy）是愛努神話中最重要的人類英雄形象。他的名字有多種解釋——「熊之父」或「活著的神」——反映出他作為神與人之間橋樑的特殊地位。根據不同的口傳版本，奧基庫爾米可能是天上的神降臨人間、也可能是最早的人類，但無論何種出身，他在愛努神話中的角色都是統一的：**他是將文明帶給人類的文化英雄**。

與純粹的神（Kamuy）不同，奧基庫爾米以人類的形態生活於村莊中，與凡人共同狩獵、捕魚、生活。他是愛努神話中「凡人英雄」的代表——他的英勇、智慧與慈悲成為愛努人自我認同的核心。許多愛努部落傳說以「奧基庫爾米與……」開頭——他是愛努口傳文學（yukar）中最常出現的主角。

## 神話事蹟

### 馴服惡神與野獸

奧基庫爾米最著名的事蹟是驅逐危害人類的邪惡存在。在一則故事中，大地上的邪惡巨人（或說邪神）不斷襲擊村落、奪取食物與婦女。奧基庫爾米以其超凡的體力與智慧逐一擊敗這些敵人：他識破惡神變形欺騙的手段、以巧計使其互相殘殺、最終將邪惡力量驅逐至冥界（Pokna Mosir）。這些戰鬥故事不僅是勇氣頌歌，也解釋了世間邪惡為何存在——邪惡被驅離但未被消滅，故仍會伺機侵擾人類。

### 教導人類生活之道

與純粹的戰士不同，奧基庫爾米同時是文明導師。傳說中他向人類傳授了捕魚的方法——包括如何設置魚梁（teppe）與製作魚叉；教導女性如何編織（attus，樸樹皮織布）與縫製衣物；教導人類正確的狩獵儀式——狩獵前後必須以禮敬的心對待動物的靈魂（ramat），否則獵物之靈將返回神界並使人類再也得不到食物。奧基庫爾米也因此成為愛努與獵物之間「契約」的建立者——人與動物的關係不是征服而是互惠，這正是愛努世界觀的核心。

### 與神明的談判

奧基庫爾米有時也作為人類的代表與神明談判。在一則重要的神話中，海神（Rep-un-kamuy）因人類的冒犯而封鎖魚群，使村莊陷入飢荒。奧基庫爾米潛入深海的神殿，與海神進行辯論——他以雄辯說服海神原諒人類的無知，並教導海神信任人類的祭祀。他帶回豐收的承諾，同時也帶回神明對人類的要求：必須遵守祭祀規矩、不得貪婪索取。這個故事將奧基庫爾米定位為**人類與神界之間的永久談判者**——他的存在保證了宇宙秩序的平衡。

## 跨文化對應

| 愛努 | 跨文化對應 |
|------|-----------|
| 奧基庫爾米（文化英雄、文明導師） | ↔ 希臘普羅米修斯（Prometheus，盜火傳技者） |
| 奧基庫爾米（驅逐邪神的戰士） | ↔ 北歐托爾（Thor，驅逐巨人的雷神） |
| 奧基庫爾米（潛海與海神談判） | ↔ 波利尼西亞茂伊（Māui，釣起群島、偷取火的英雄） |
| 奧基庫爾米（教導狩獵與捕魚） | ↔ 美洲原住民渡鴉（Raven，盜光與傳授技藝） |
| 奧基庫爾米（人類與神的調停者） | ↔ 希臘荷米斯（Hermes，神與人的使者） |
| 奧基庫爾米（凡人英雄） | ↔ 吉爾伽美什（Gilgamesh，半人半神的王者） |
| 奧基庫爾米（口傳文學主角） | ↔ 凱爾特庫胡林（Cú Chulainn，史詩英雄） |

## 相關神祇

- **Ae-Oyna-kamuy（阿埃-奧伊納）** — 另一文化英雄神祇，與奧基庫爾米常被視為同源或兄弟角色
- **Kamuy-huci（火女神）** — 家宅與火的主宰，奧基庫爾米遵守其教誨的對象
- **Rep-un-kamuy（海神）** — 海洋主宰，奧基庫爾米談判的對象
- **Chikap-kamuy（貓頭鷹神）** — 村落守護神，與奧基庫爾米同為人類盟友
- **Pokna-moshiri-kamuy（冥界神）** — 邪惡被驅逐之所的掌管者

## 出現在

- 愛努口傳敘事詩（yukar，ユーカラ）——特別是以第三人稱敘述的「yukar」類別
- 金田一京助（Kindaichi Kyōsuke）記錄的愛努口傳文學集（《Ainu Jojishi Yukara Shū》）
- 知里真志保（Chiri Mashiho）對愛努口傳文學與神話的系統研究
