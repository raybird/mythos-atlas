# Pokna-moshiri-kamuy（地下世界之神）

- **文化：** 阿伊努神話（Ainu Mythology）
- **職掌：** 地下世界統治者、亡靈審判者、混沌之力掌控者

## 概述

Pokna-moshiri-kamuy（阿伊努語 `pokna`「下方」+ `moshiri`「土地/世界」+ `kamuy`「神」）是阿伊努宇宙觀中掌管地下世界的至高神靈。在阿伊努的三層宇宙結構中——天界（Kanto）、人間界（Ainu-moshiri）、地下界（Pokna-moshiri）——Pokna-moshiri-kamuy 統治最底層，負責接納人類的靈魂並維持宇宙的平衡。他同時被稱為「Pase-kamuy」（沉重之神），因為他承載著上方世界的重量；或「Shitumba-kamuy」，意指一切歸於塵土的掌控者。其形象被描述為一位身披黑色熊皮的老者，雙眼如炭火般在黑暗中發出紅光。他不發一語，因為言語屬於人間；他的工具是無聲的天平——衡量人的一生所作所為。死者的靈魂在告別儀式（shinot）結束後，沿著薩滿的祈禱杖（inau）敲擊的路徑，從火竈（ペチ）下方的一條通道進入地下世界——這條通道只在死亡時刻開啟。Pokna-moshiri-kamuy 判定靈魂的歸宿：善者留在其領域中安息，等待重新化生；惡者則被投入更深的「泥濘沼澤」（toyta-moshiri），靈魂逐漸消散於虛無。此審判觀與一般薩滿信仰的「模糊來世」不同——阿伊努擁有明確的道德審判體系。

## 神話事蹟

最重要的敘事圍繞 Pokna-moshiri-kamuy 與 Kotan-kar-kamuy（創造神）之間的對立協作。創造神在地上造人時，Pokna-moshiri-kamuy 從地下領域伸出一隻手，要求人類的靈魂在最終必須歸他所有——此即死亡起源的神話解釋。Kotan-kar-kamuy 同意此條件，但規定靈魂在 Pokna-moshiri 中沉睡一定時間後可再次輪迴——此為阿伊努靈魂循環觀的核心。

第二則重要神話：Pokna-moshiri-kamuy 與火女神 Kamuy-huci 的契約。Kamuy-huci 的火焰照亮人間也溫暖家庭，但火焰燃盡後的灰燼會落入 Pokna-moshiri。Pokna-moshiri-kamuy 以此灰燼餵養亡靈，使其不至於在黑暗中消散。因此阿伊努人在熄滅爐火時必須低聲祝禱，因為爐灰的下落等同於送往亡者之界的食物。第三，傳說 Pokna-moshiri-kamuy 有時會釋放地底的動物靈體回到人間——這就是為什麼地震被認為是地下世界之神的憤怒信號。阿伊努人在地震發生時會敲擊地面，呼喊「請安靜下來」，以此安撫 Pokna-moshiri-kamuy 的震怒。

## 跨文化對應

| 阿伊努 | 跨文化對應 | 共通點 |
|--------|-----------|--------|
| Pokna-moshiri-kamuy | ↔ 希臘 Hades 黑帝斯 | 地下世界統治者，亡靈接受的冷漠之神 |
| | ↔ 北歐 Hel 赫爾 | 死者的歸宿地，陰冷黑暗 |
| | ↔ 埃及 Anubis 阿努比斯與 Osiris 奧西里斯 | 亡靈審判與靈魂衡量 |
| | ↔ 日本伊邪那美命（Yomi-no-kami） | 黃泉國主宰，死亡與汙穢之神 |
| | ↔ 印度 Yama 閻摩 | 亡者之王，業力審判者 |
| 靈魂秤量 | ↔ 埃及《死亡之書》心臟秤量儀式 | 以善惡平衡判定靈魂去向 |
| 爐灰餵養亡靈 | ↔ 墨西哥亡靈節 ofrenda 祭壇 | 以人間食物供養亡者之界 |

Pokna-moshiri-kamuy 在跨文化冥神譜系中與希臘 Hades 最為接近——二者皆為冷靜、公正、不主動干預人類事務的審判者。不同於印度 Yama 的輪迴管理體系或埃及 Anubis 的直接秤量儀式，阿伊努的審判缺乏明確的「代言人」角色——Pokna-moshiri-kamuy 從不親自執行懲罰，而是由領域本身的特性（善者安息，惡者消散）自動完成。

## 相關神祇

- **Kotan-kar-kamuy**（創造神）——Pokna-moshiri-kamuy 的對等協作者，掌管上方世界
- **Kamuy-huci**（火女神）——以灰燼供養亡靈，二神共治生死的邊界
- **Nusa-kor-kamuy**（祭壇守護神）——引導靈魂從人間進入 Pokna-moshiri
- **Chup-kamuy**（月神）——月光照亮通往 Pokna-moshiri 的路徑
