# 世界承載之魚——愛努地震神話

阿伊努神話中，我們所居的大地並非自古漂浮於虚無，而是由一尾沉潛海底的巨魚（moshir kor kar-kamuy 一系的巨獸）穩穩馱負。這尾「承載世界之魚」以背脊頂托整個世界——山、河、平地與人煙。祂終日靜緩游動，維持絕妙的平衡；而人類所感受到的地震，正是這尾巨魚在海底翻身、挪動或受到驚擾的瞬間。

## 神話敘事

遠古之時，眾神將大地安置於洋面之上，但大地隨風漂流、無法安頓。於是創世之神命一尾巨物潛入海底，以脊背馱住大地，將其牢牢托住。巨魚的四鰭對應東、南、西、北四方位，祂緩慢游轉以求平衡，使山岳立足、河川依循河床而行。人類無法直視此魚，只能透過地震與潮汐的節律，間接感知祂的存在。

## 地震與巨魚的律動

關於地震的成因，阿伊努人廣為流傳的說法是：當巨魚感到疲憊、受驚，或因為人類在土地上的惡行而被觸怒時，祂的龐大身驅便會在水底晃動，地層隨之劇烈搖動。諸傳中並告誡人類不可在聖山或重要地層「謾罵大地」，否則巨魚將更頻繁地翻身。此一宇宙觀，把地質運動歸因於一位仁慈卻負擔沉重的海洋巨物，是一種極具包容性的災難解釋。

## 宇宙結構

- **底層為海洋：** 巨魚潛於海底，馱負整片大地
- **中層為人間：** 現世（aynu mosir）位於巨魚的背脊之上
- **律動為節奏：** 巨魚的呼吸被比擬為潮汐；翻摯則為地震

阿伊努人依靠與海洋維持良性的「贈予—回贈」關係來維繫巨魚的平穩：捕鮭適度、不濫撈、祭祀海神，以此換取巨魚的安定。此一循環把「地質災害的防避」轉化為「人與自然的倫理責任」。

## 跨文化對應

| 阿伊努 世界承載之魚 | 對應概念 | 文化 |
|---|---|---|
| 世界負載於海底巨物 | 日本大鯰（Namazu）撼動大地 | 日本 |
| 屬性水族承擔世界 | 神鼇（巨龜）負山、鼈足撐天 | 中國 |
| 震動源於負載者移動 | 北歐 Jörmungandr 環繞世界之蛇 | 北歐 |
| 海底巨物的平衡決定陸地 | 印度 Kurma 神龜承載須彌山 | 印度 |
| 地底受困巨獸的翻動 | 希臘 Enceladus 鎮於埃特納火山下 | 希臘 |

阿伊努「世界承載之魚」的獨特之處，在於將地震與潮汐整合為同一海底巨物的雙重律動，並把「行為是否合宜」與巨魚的平和直接串聯，形成山與海、土地與人倫整體一致的宇宙觀。

## 相關 Kamuy

- **Rep-un-kamuy：** 海神，與承載世界之魚同屬海洋領域
- **Kotan-kar-kamuy：** 創建地形與村鎮的神
- **Pokna-moshiri-kamuy：** 冥界之神，掌管最底層
- **Rera-kamuy：** 風神，與巨魚一同調節自然的律動
