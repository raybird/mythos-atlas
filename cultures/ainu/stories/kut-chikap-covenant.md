# 貓頭鷹與人類的約定——Chikap-Kamuy 的審判

## 故事背景

在阿伊努 Kamuy Yukar（神謠）中，Chikap-Kamuy（奇卡普·卡穆伊）是貓頭鷹之神，掌管陸地、森林與夜間的智慧。阿伊努人稱貓頭鷹為「Kamuy-pasuy」（神的子孫），絕不殺害或食用貓頭鷹——此禁忌源自一則關於人類與 Chikap-Kamuy 簽訂「約定」的古老故事。

## 情節

### 一、初始的平等

太古之時，Chikap-Kamuy 與第一個人類（或文化英雄 Ae-oyna-kamuy）共同生活在同一片大地上。那時人類與貓頭鷹在外表、能力上差別不大——兩者都能在白天與黑夜中活動，都能使用簡單的工具，都以狩獵維生。

Kotan-kar-kamuy（創世神）決定分配「能力」予各物種：他召集群獸與第一批人類到面前，問：「誰想要白天活動的能力？誰想要夜晚活動的能力？」

### 二、分配的關鍵時刻

Chikap-Kamuy 第一個站出來：「我要夜晚的能力——我能在黑暗中看見一切，在風中聽見遠方的聲音。」Kotan-kar-kamuy 點頭同意，以手指觸碰 Chikap-Kamuy 的眼睛——從此貓頭鷹的瞳孔巨大如滿月，能在完全的黑暗中精準地捕捉獵物。

人類第二個站出來：「我也想要夜間的能力——黑夜太長，我們在黑暗中飢餓無助。」Kotan-kar-kamuy 卻搖頭：「你已經有了最寶貴的東西——白日的光明與同類的語言。若再給你夜視的能力，其他動物將如何生存？」

人類不滿，與 Chikap-Kamuy 爭吵。Chikap-Kamuy 提議：「讓我們以力量與智慧的比賽來決定。」

### 三、比賽與約定

比賽分三項：
1. **射箭比賽：** Chikap-Kamuy 以夜間視力在黑暗中射中靶心，人類在白日射中靶心——平手。
2. **飛行比賽：** Chikap-Kamuy 飛越高山，人類無法飛行——Chikap-Kamuy 勝。
3. **智慧比賽：** 人類以語言說服 Chikap-Kamuy 一個秘密（如「 Kamuy 最怕什麼」），Chikap-Kamuy 被說服——人類勝。

最終 Kotan-kar-kamuy 裁決：兩者各有所長，不可相互取代。從此 Chikap-Kamuy 成為夜間的守護者與審判者——在阿伊努信仰中，貓頭鷹的叫聲是 Kamuy 對人類行為的「評語」。如果叫聲平和，表示 Kamuy 滿意；如果叫聲淒厲，表示 Kamuy 對人類的行為不滿。

### 四、禁忌的確立

此故事確立了阿伊努最重要的動物禁忌之一：不得傷害貓頭鷹。違反者將遭受 Chikap-Kamuy 的懲罰——失明、迷路、或在森林中永遠找不到回家的方向。阿伊努獵人在夜間森林中聽見貓頭鷹叫時，會停下來低聲說：「Kamuy，請指引我。」

## 跨文化平行

| 阿伊努 Chikap-Kamuy | 對應神話 | 文化 |
|---|---|---|
| 貓頭鷹為夜間審判者 | 雅典娜的貓頭鷹（智慧象徵） | 希臘 |
| 貓頭鷹為死亡信使 | 死神的貓頭鷹（Lilith） | 美索不達米亞 |
| 動物與人類的能力分配賽 | 普羅米修斯與宙斯的分配 | 希臘 |
| 貓頭鷹為禁忌動物 | 日本「不吉之鳥」禁令 | 日本 |
| 夜間智慧與夜視力 | 奧丁的渡鴉（夜間飛行的智慧使者） | 北歐 |
| 以比賽決定物種差異 | 印度「誰先笑」的賽跑决定物種 | 印度 |

阿伊努 Chikap-Kamuy 故事最獨特之處在於「平等賽後的互補」——不同於其他文化中人類「戰勝」或「統治」動物的敘事，阿伊努版本強調人類與動物各有不可替代的能力，必須互相尊重。此觀念與阿伊努整體的「人與自然平等」世界觀一致。
