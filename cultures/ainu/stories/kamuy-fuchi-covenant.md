# 火女神的契約：家竈之火的規則 (The Covenant of Kamuy-huci)

- **文化：** 愛努神話 (Ainu Mythology)

## 故事背景

Kamuy-huci（カムイフチ，火女神，又稱 Ape-huci「竈火之婆」）是愛努神話中最崇高、最受尊敬的神明之一。愛努人相信她是太陽神的女兒，是眾神中最早降臨人間、也最接近人類日常生活的神。每一個愛努家庭的家竈（hearth）都是她的居所——竈火一旦點燃，Kamuy-huci 便降臨其中。因為她居住在人類家中，愛努人所有的祈禱與祭祀都從「向火祈禱」開始。這則故事講述 Kamuy-huci 在太古時代與人類訂立的契約——這項契約構成了愛努人生活的全部規範。

## 情節

### 第一幕：火的降臨

在太古時代，人類還沒有火。他們與動物一樣生食獵物，在寒冷中瑟縮於洞穴，沒有熟食、沒有溫暖、沒有驅散黑暗的力量。有一天，太陽神的女兒——火女神——從天上降臨到人間的第一個村莊。她在人類的竈坑中點燃了第一縷火苗，火焰驅散了洞穴的陰影。人類圍坐在火旁，第一次感受到溫暖，第一次品嘗到烤熟的獵物。

但火女神對人類提出的第一個警告隨之而來：「這火是你們的生命。記住：火一旦熄滅，我的靈魂便離開你們的屋子——你們的家族也會失去靈魂。」

### 第二幕：火的規矩

Kamuy-huci 開始教導人類竈火的完整規範。這些規則構成了愛努生活的核心法典：

- **火不可熄滅**：竈火是家庭生命延續的象徵，愛努家庭絕不讓竈火完全熄滅——熄火被視為家族衰敗的預兆。
- **火不可受污**：不得向火中丟棄汙穢之物、頭髮、指甲或動物的骨頭殘渣。火是神聖的，玷污火等同於玷污神明。
- **火前不可爭吵**：家人圍坐於火邊時不可爭執——因為 Kamuy-huci 在火中注視著一切，她在場時爭吵即是對神明的冒犯。
- **灰燼的禁忌**：清晨撥火時，必須小心將灰燼置於竈邊的特定位置，不可任意揚灑——灰燼同樣承載神聖性。

「你們要記住，」火女神說，「你們的生命維繫於火。當你們傷害火，就是傷害你們自己。」

### 第三幕：祈禱的開始

Kamuy-huci 同時建立了人類與所有神明溝通的管道。她對人類說：「眾神之中，唯有我居住在你們家中。當你們要向任何神明祈禱——無論是狩獵之神、海神還是山神——都必須先向我祈禱。我會為你們傳達祈願，也會為你們辯護。」

自此之後，愛努人在所有儀式中首先進行「對火的祈禱」：手握 inau（削製的神聖木杖），以清水或米酒沾唇，先向竈火舉杯。愛努諺語「一切祈禱始於火」正是這項教誨的遺產。火女神成為人類與神界之間最忠實的中介——因為她居住於人間，她比任何神都更了解人類的苦難與需要。

### 第四幕：人與火的永恆契約

傳說中，當人類拒絕遵守火女神的規範時，大地便會降下災難。飢荒、瘟疫與狩獵的失敗都被解釋為「火女神收回了她的保護」。反之，當人類謹守竈火的規矩，火女神便會保佑家庭平安、獵物豐足、子孫繁衍。

這項契約至今仍在愛努家庭的儀式中延續。即使在現代，愛努人在重要聚會、新屋落成、婚喪喜慶時仍會舉行向火的祈禱——將米酒或清酒灑向竈火，感謝 Kamuy-huci 的看護。火女神的契約，是愛努世界觀「萬物有靈、人神互惠」的具體象徵：神明不是被崇拜的抽象存在，而是與人類同居共食的夥伴。

## 跨文化平行

| 愛努 Kamuy-huci 契約 | 跨文化對應 |
|---------------------|-----------|
| 竈火為家庭生命之魂，不可熄滅 | ↔ 羅馬維斯達（Vesta，不滅聖火）／希臘赫斯提亞（Hestia） |
| 火前不可爭吵，火為家中注視者 | ↔ 中國灶神（臘月廿三回天庭稟報家中善惡） |
| 一切祈禱始於向火祈禱 | ↔ 印度阿耆尼（Agni，祭祀的嚮導與傳送者） |
| 玷污火即玷污神明 | ↔ 立陶宛加比亞（Gabija，竈火女神，被視為神聖） |
| 火熄滅＝家族衰敗之兆 | ↔ 斯拉夫 Domovoy（家靈，家庭存續的守護者） |
| 火的規矩構成生活法典 | ↔ 瑣羅亞斯德教聖火崇拜（火為真理象徵） |
