# Rep-un-kamuy 拯救飢荒村莊

## 文化背景

本故事是阿伊努口傳文學（yukar）中關於海洋神靈幫助人類的典型敘事。Rep-un-kamuy（虎鯨之神，亦稱 Orca Kamuy）在阿伊努神話中被視為海洋的最高主宰，掌管海上安全與漁獲的多寡。不同於 Kim-un-kamuy（熊神）以陸上動物的形態降臨人間，Rep-un-kamuy 以虎鯨為其現身形貌——虎鯨在阿伊努海域頻繁出沒，被漁民視為豐收的預兆與保護者。阿伊努人稱虎鯨為「海洋的守護者」，並相信一頭虎鯨的出現意味著神靈正在巡視其領地。

## 故事正文

很久以前，在鄂霍次克海沿岸的一個阿伊努村落，連續三年的冬天沒有見到鮭魚迴游。海面結了厚冰，森林中的鹿群消失無蹤。老人們說這是因為有人在上一個夏天在河邊處理動物內臟時沒有遵守祭祀規則——海洋的 Kamuy 受到了冒犯。

到了第三年的仲冬，糧倉完全見底。嬰兒因缺乏母乳而哭泣，老人開始自願減少食物分配。村落的長老（ekasi）決定舉行最後的請神儀式。在族長的帶領下，全村人將珍藏的最後一條乾鮭魚、一小瓶清酒和一束精心雕刻的 inau（祈禱杖）放置在海岸邊的祭壇上。他們面朝大海唱誦 yukar——那首最古老的〈Rep-un-kamuy 之歌〉。

歌詞的內容是這樣的：「Rep-un-kamuy，海中的黑者，背脊如黑岩般隆起者。請聽見我們的話——不是我們为自己祈求，而是為了初生的嬰兒，為了無法走路的老人。」

他唱了整整三天三夜。第三天的黃昏，當疲憊的村民準備放棄時，海面上突然掀起一道巨大的黑色背鳍——虎鯨群出現在結冰的海域邊緣。帶頭的虎鯨——其體型之大，村民說如同一座黑色的島——游到祭壇正前方的淺灘處停下。牠張開口，噴出一道水柱，然後轉身將尾鳍重重拍打海面三次。村民明白這是 Rep-un-kamuy 的回應。

黎明時分，當村民再次來到海邊，他們發現淺灘上擱淺了數十條巨大的鮭魚與比目魚——都是虎鯨群連夜從遠海驅趕而來的。魚的數量剛好足夠整個村落度過冬天，每一條魚的尺寸都和一個成年人的手臂一樣長。

長老率領全村向大海深深鞠躬，並將一頭虎鯨的圖案刻在村莊的 totem 柱上。從此以後，這個村莊每年在舉行 iyomante（送熊靈）之後，會額外舉行一次感謝海洋的儀式——將部分漁獲歸還給 Rep-un-kamuy，確保海洋的饋贈永不枯竭。直到今日，這個村的後代在出海前仍會唱誦那首〈Rep-un-kamuy 之歌〉——因為他們知道，虎鯨不只是動物，而是從海洋深處傾聽人類苦難的神祇化身。

## 跨文化平行

| 阿伊努 | 跨文化對應 | 共通點 |
|--------|-----------|--------|
| Rep-un-kamuy 以虎鯨現身拯救村莊 | ↔ 毛利神話 **Tinirau** 騎鯨救漁民 | 海洋神以鯨豚形象救助人類 |
| | ↔ 北歐神話 **Ægir** 或 **Njörðr** 提供魚群 | 海神操控漁產的豐歉 |
| | ↔ 希臘傳奇 **Arion** 騎海豚逃脫 | 海豚/鯨作為人類與神的中介 |
| | ↔ 日本 **惠比壽**（Ebisu） | 漁業之神、漂流而來的豐饒神 |
| | ↔ 玻里尼西亞 **Maui** 釣魚建島 | 海洋提供生命的物質基礎 |
| 第三年魚群回歸 | ↔ 希臘 **Demeter** 的冬旱與復甦 | 三年飢荒型敘事結構 |

此故事中 Rep-un-kamuy 的三次尾鳍拍擊是一個關鍵儀式數字——阿伊努神話中以「三」代表完整的神聖溝通（唱誦三天、虎鯨拍三下），與日本神話的「三擊」習俗及西伯利亞薩滿的鼓擊三次有深層結構關聯。

## 文化意義

Rep-un-kamuy 救助人類的敘事反映了阿伊努人與海洋之間的根本契約：人類必須遵守祭祀規則，神靈才會繼續提供資源。故事中飢荒的起因不是自然災害，而是人類的儀式失誤——這與阿伊努倫理觀中「正確行為決定自然秩序」的前提一致。Rep-un-kamuy 拯救村莊並非出於憐憫，而是因為村民在極限匱乏時仍然遵守儀式規範（以最後的乾鮭魚和 inau 獻祭），證明了他們對海洋神靈的忠誠。
