# 村落創造者——科坦卡爾卡穆伊教導人類定居

- **文化：** 愛努神話（Ainu Mythology）

## 故事背景

科坦卡爾卡穆伊（Kotan-kar-kamuy，亦稱 Kotankorokamuy）是愛努神話中的**村落創造神**。他的名字直譯為「村落創造者之神」或「村落之神」。在愛努的創世與人類教化敘事中，科坦卡爾卡穆伊扮演了文明導師的角色——他不僅創造了各地的村落（kotan），更教導愛努人如何定居、建立家屋（cise）、在自然環境中以適合社會組織的方式生活。

與愛努神話中其他教化英雄（如 Ae-oyna-kamuy 教導狩獵與烹飪、Okikurumi 教導農耕與符文）不同，科坦卡爾卡穆伊的領域是**定居與社會空間的組織**。他的神話從空間的角度解釋了愛努人為何居住於特定的河流谷地、村落為何呈現特定的布局、以及家屋的神聖意義。

## 情節

### 第一幕：漂泊的人類

在遠古時代，人類尚未懂得定居的意義。愛努人像野獸一樣在山林間漂泊，沒有固定的住所，無法儲存食物，家庭與家庭之間缺乏穩定的社會聯繫。他們不知道如何建造房屋、如何選擇適宜居住的場地、如何以村落的形式組織生活。人類的這種漂泊狀態在愛努神話中被描述為「像落葉一般被風吹散」。

### 第二幕：科坦卡爾卡穆伊的降臨

科坦卡爾卡穆伊從天上（神之國度 Kamuy Mosir）俯瞰大地，看見人類的苦難。他決定降臨到凡間——但他的降臨方式並非像 Ae-oyna-kamuy 一樣以英雄人類的形態出現，而是以一位睿智老人的形象出現在各處的河流交匯處。

他首先前往**石狩川**（Ishikari River）流域——這是北海道最長的河流，也是愛努人世代生活的核心地帶。他站在河岸邊，觀察山勢、水流與風向，然後說：「這裡，山勢如盾擋住北風，河流如帶提供魚類，這片台地不受洪水侵襲。」他在那裡豎立了一根 Inau，標記了第一個神聖村落的選址。

### 第三幕：教導村落建造

科坦卡爾卡穆伊召集漂泊的人類，逐步教導他們建村的知識：

1. **選址法則**：村落應位於河流彎曲處的台地，背後有山林阻擋冬季的西北風，前方有河灘便於獨木舟停靠與鮭魚捕撈。

2. **村落布局**：房屋（cise）應沿河流排列，面朝東南－西北方向，入口朝東南以迎接早晨的太陽。村落的盡頭必須設有祭壇（nusa），豎立 Inau 以供奉諸神。

3. **房屋建造**：家屋以茅草與樹皮覆頂，中央設爐灶（在愛努信仰中爐灶是最神聖的場所，由火神 Kamuy-huci 守護）。

4. **公共空間**：村落應有廣場（ure）供集會與熊靈送還儀式（Iomante）使用。村落周圍需預留狩獵與採集區域，以永續利用的方式管理。

### 第四幕：神聖契約

科坦卡爾卡穆伊在完成教導之後，與人類訂立了契約：

> 「記住：當你們居住於村落之中，就必須尊重這片土地的山與水。每年以 Inau 獻祭，感謝大地提供了住所。任何破壞村落與自然和諧的行為，都將使這片土地失去神的保護。」

說完之後，他消失於山林之中，從此人類不再漂泊，開始以村落的形式居住在北海道各地的河流谷地中。

## 版本與比較

科坦卡爾卡穆伊造村的神話屬於「文化英雄教導定居」的泛文化母題。類似的故事出現在：

| 文化 | 人物／神祇 | 教導內容 |
|------|----------|---------|
| 愛努 | Kotan-kar-kamuy | 村落選址、房屋建造、祭壇設置 |
| 希臘 | 特里普托勒摩斯（Triptolemos） | 農業與定居文明 |
| 中國 | 后稷、有巢氏 | 農業、巢居與房屋建造 |
| 美索不達米亞 | 恩基（Enki） | 文明七藝（me）教導人類 |
| 印加 | 曼科·卡帕克（Manco Cápac） | 建立庫斯科城、教導定居 |
| 日本 | 大國主命 | 國土經營與生活技藝 |
