# Api — 大地母神跨文化比較

## 概述

Api 是斯基泰萬神殿中的大地母神（希臘文獻中對應 Gaia），與天父 Papaios 共同構成斯基泰宇宙觀中的「天地父母」二元結構。希羅多德在《歷史》卷四第59節記載斯基泰人「崇拜 Zeus（Papaios）與 Gaia（Api），稱 Gaia 為 Hestia 的母親」。Api 的名字可能源自原始印歐語 *\*h₂ep-*（水/滋養），暗示她不僅是大地本身，更是大地中的水源——草原生命的根本。

## 關鍵分析

### 1. 天地父母的原初交合

斯基泰的 Papaios（天父）與 Api（地母）在宇宙之初緊密交合——這與希臘的 Ouranos 與 Gaia、毛利的 Rangi-nui 與 Papa-tūā-nuku 的原初狀態完全一致。世界創造的第一步不是「從無到有」，而是「從合到分」——天地的分離是創造的前提。

在斯基泰版本中，天地的分離並非通過暴力（如希臘 Cronus 攻擊 Ouranos），而是通過自然的過程——天地「自行」擴張分開，留下了中間的大氣層。這更接近印度的版本：Dyaus Pitar（天父）與 Prithivī（地母）以自然的方式分離，中間由 Varuna（宇宙秩序）維繫。

### 2. Api 作為「水之母」

Api 的名字 *\*h₂ep-* 暗示她不僅是乾燥的大地，更是大地中的水源——草原上的河流、泉水、地下水脈。在歐亞草原上，水是比任何東西都更珍貴的資源——控制水源等於控制生命。斯基泰人將 Api 同時理解為「大地」與「大地中的水」，這種二元性在其他文化中也有對應：

- 希臘的 Gaia 同時是大地與大地中的礦藏
- 埃及的 Geb 是大地本身
- 波斯的 Anahita 是水女神同時也是大地的滋養者
- 中國的后土（土地神）與河伯（河神）在功能上有所重疊

### 3. 女性生育力的神聖化

Api 的核心功能是「生育」——她生出牧草、糧食、礦藏，以及人類自身。斯基泰人每年春季在 Api 的祭壇上傾倒新鮮牛奶與蜂蜜，祈求草原豐收。這種「大地母親的哺育」信仰在整個歐亞大陸普遍存在：

- 弗里吉亞的 Cybele（大母神）以獅子為伴，掌管山脈與 fertility
- 印度的 Prithvi 在吠陀祈禱中被祈求「如母親般哺育」
- 中國的女媧以泥土造人，同時也是大地的象徵
- 芬蘭的 Maan-emä（大地之母）在《卡勒瓦拉》中被祈求賜予豐收

### 4. Api 與 Tabiti 的關係

Api 與 Tabiti（至高火女神）在斯基泰萬神殿中可能代表同一女神的兩個面向：
- **Tabiti** = 天火/爐灶之火（人間的、文明的、王權的）
- **Api** = 大地之水/地下水源（自然的、生育的、牧群的）

這種「火—水」二元結構在印度神話中有精確對應：Agni（火）與 Varuna/Indra（水/雷雨）共同維繫宇宙秩序。斯基泰版本將 Tabiti 置於至高地位，可能反映了游牧社會對「火」的優先性——在草原上，爐火是家庭與王權的最核心象徵。
