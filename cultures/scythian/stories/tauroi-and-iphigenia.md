# Tauri 與「少女」——被認出來的 Iphigenia 與插在屋頂的頭顱

- **文化：** 斯基泰神話 (Scythian Mythology)／陶里奇海峽 (Tauric Chersonese)
- **文獻地位：** 希羅多德《歷史》卷四第102節（首度被列名）、**第103節**（習俗與女神身分）
- **文類：** 民族誌記錄 + 身分指認神話；希臘人早已自行發展出同一素材的悲劇版本

## 故事背景：Tauri 是七族之首，卻在卷四沒有自己的聲音

希羅多德 4.102 記 Idanthyrsos 召集七族議事：**Budini、Geloni、Sauromatae** 同意出兵；**Tauri、Agathyrsi、Androphagi、Melanchlaeni、Neuri** 拒絕。Tauri 列在拒絕名單首位。

4.103 是 Tauri 唯一的專節，長度不過半頁。希羅多德在其中報告兩件事：一是他們向誰獻祭、怎麼獻祭；二是**他們所供的神，他們自己說是誰**。

## 情節

### 一、祭品

> Tauri 的習俗如下：所有遇難的海上漂流者，以及他們出海掠奪所能捕獲的希臘人，他們都獻祭給「**少女**」。獻祭的作法是：完成最初的獻儀之後，**用棍棒擊打祭品的頭**；有人說，接著把屍體從其神廟所在的**崖頂**推下去，並把頭**刺穿立起**；另一些人同意關於頭的部分，但說屍體是埋入土中，而非推落崖下。

注意希羅多德在此**同時記錄了兩個互相牴觸的版本**，而且不裁定。這是卷四的一貫做法，但在此處特別關鍵：屍體是「丟下懸崖」還是「入土」，決定了這是一個**獻給女神的祭典**還是一個**處理屍體的制度**。希臘人後來寫的《伊菲革涅亞在陶里斯》選了懸崖版，因為那樣才有戲劇張力；希羅多德保留了土葬版，那才是他認為可能發生的事。

### 二、神的身分：陶魯人自己說的

> **Tauri 自己說，他們所獻祭的這位神就是 Agamemnon 的女兒 Iphigenia。**

這是全節的爆炸點。一個黑海民族在沒有任何希臘家系的情況下，把阿特柔斯家的女兒收進自己的神廟。希羅多德不加評論地記下——而他對卷四其他神話（Arimaspi 的 arima-spou 拆字、Zalmoxis 的奴隸出身）都會附上嘲弄。此處沉默。

### 三、敵人的頭：屋頂上的守護者

> 至於他們所征服的敵人，每個人都砍下**敵人的頭**，帶回家中，把頭**刺穿在一根長竿上**，把竿立得高高高，高過住屋，**多半高過煙囪**。這些頭，人們說，是被立起來**守衛整座房屋**的。Tauri 靠掠奪與戰爭維生。

這一段是本頁最值得停留的地方，因為它把三件事疊在一起：

1. **戰利品即防衛。** 頭顱不放進庫房、不供在神廟，而是**立在生活空間上方**，持續執行保護功能。戰爭的成果因此不停留在過去，而是每天早上從窗戶看見。
2. **頭與煙囪的關係。** 「多半高過煙囪」是全卷最精確的一個技術細節：煙囪是煙的出口，頭顱是記憶的出口；它們被安排在同一條垂直線上，且頭在上面。希羅多德用半句話完成了對「紀念碑建築學」的描述。
3. **頭是主動的。** 希臘世界幾乎一致地視頭顱為被動的戰利品或凶兆（戈爾貢除外）；在 Tauri 這裡，頭是**被部署的守衛**，句子的主語在頭顱。

正是這種「頭顱是守衛」的邏輯，構成了希臘悲劇的全部張力：《伊菲革涅亞在陶里斯》裡，Iphigenia 之所以必須被認出，是因為**她的頭本來就該出現在這裡**。歐里庇得斯把陶魯人的這套風俗一節不差地搬進劇本（*IT* 1434 記陶魯人以頭顱為門柱），希臘觀眾對此並不陌生。

## 分層：這是希臘神話，不是陶魯神話

本頁必須明確區分三件事，否則會把希臘文學的產物誤記為黑海民族的信仰：

| 層次 | 內容 | 性質 |
|---|---|---|
| 希臘悲劇傳統 | Agamemnon 欲祭 Iphigenia、Dionysus 以替代者蒙混、海風取代、陶里斯認親 | 埃斯庫羅斯《Oresteia》、歐里庇得斯《伊菲革涅亞在陶里斯》 |
| 希羅多德的記錄 | Tauri 祭一位「少女」神，用棍棒擊頭、刺穿立頭、屍體或墜崖或入土，**並稱此神為 Iphigenia** | 民族誌 + 希臘人的身分指認 |
| 考古材料 | 克里米亞南岸晚期青銅時代至希臘化時期墓葬與祭坑的人骨、馬骨 | 物質證據，**不支持**希臘神話的具體情節 |

關鍵在方向：希羅多德寫的是**陶魯人自稱**如此，**不是**他判定如此。也就是說，希臘世界把自己的悲劇投射到一個族群身上，而這個族群（至少經由希臘化的陶魯中介者的口）**回應了這個投射**。

這與 Scyles 的案例方向相反：Scyles 是接受希臘儀式而被殺（見 [Scyles 與酒神入教](scyles-and-the-bacchic-initiation.md)），Tauri 則是被希臘命名而接受。**接受儀式 vs 接受名字**這一組對比，是本庫目前對「希臘化時期黑海族群自我表述」最有價的材料。

## 「少女」該對應到哪一位 Artemis

希羅多德使用的是中性詞 "the Maiden"（παρθένος），沒有給出神名。學界長期把陶魯神廟等同於 **Artemis Paralia**（海洋的 Artemis），並進而以「Artemis Taurica」稱呼之；但這個等同的依據主要是歐里庇得斯戲劇在文獻上的成功，而非陶魯方面的獨立證據。

另有一點須注意：希臘化時期該神廟的祀像在傳統中是**一塊石頭**，其擬人化過程見於 Orestes 與 Pylades 的相關傳說（Herod. 1.52；Strabo 6.3.5）。若 Tauri 的「少女」原本是無像石，那麼「希臘人把她認成 Iphigenia」這個行為，就正好是把一個**無像神**轉化為**有家系的神**。這與 Scyles 的「關門換衣」屬同一方向的操作：**希臘化即賦予可辨識的身世。**

## 跨文化對應

| 文化／傳統 | 對應 | 共通點與差異 |
|---|---|---|
| 希臘（陶里斯 Artemis 與伊菲革涅亞） | 《伊菲革涅亞在陶里斯》的認親情節 | 素材同源；希臘悲劇把「被認出」寫成高潮，本頁則把「被希臘人認出」本身當作政治事件處理 |
| 希臘（Argos 陣圖） | 以女兒換風的替代者儀式 | 祭司宣稱「這是 Artemis 的女兒」，與陶魯人的「這是 Agamemnon 的女兒」是同一個**身分置換**裝置的兩種方向 |
| 塞爾特（愛爾蘭） | 戰利首級與獵首傳統 | 蓋爾戰士斬首並保存，戰利品與**身分**綁定；Tauri 的用途則是**防衛**——聲望對守護，是本表最應分清的一組差異 |
| 毛利 | 戰首（kauaha）作為尊榮標識與護衛物 | 與 Tauri 最接近：頭顱既被保存又被當作保護性物件，並置於村莊入口；同屬「將記憶物理化於居所上方」 |
| 印加 | 頭顱（*utaku*）與瓦伊卡里的儀式性容器 | 結盟部族彼此交換人頭、製成器皿共享聖物；與 Tauri 的「斬首守屋」同屬頭顱作為外交與祭祀對象的傳統 |
| 日本 | 御首與代代首級祭祀 | 以敵將首級為祭祀對象並傳承；神道的水葬與土葬二分，與希羅多德記錄的陶魯人「墜崖 vs 入土」版本分歧幾乎同型 |
| 中國（先秦） | 斬首與獻俘 | 《春秋》系統中首級是戰功憑證；希臘的 *kephalē* 與中國的「首」同樣具備戰利、身份、祭祀三重功能 |
| 印度（摩訶婆羅多） | Yudhishthira 斬下 Duryodhana 之首 | 勝者取首為戰利與正當性；與 Tauri 的差異在於 Tauri 的頭不被獻給神，而是被**派給守衛**——獻神對派任守護，是本頁另一組應分清的對立 |
| 高加索（阿布哈茲） | 部落聖物由特定家族世代守護 | 與 Tauri 讓戰利首級執行防衛功能同屬「物件的守護者化」；差別是 Abkhaz 守護的是繼承物，Tauri 守護的是敵人的身體 |
| 亞述 | Elam 與 Achaemenid 壁面浮雕上的首級 | 宮廷壁畫把首級掛在樹上作戰利品展示；與 Tauri 差在位置（宮廷 vs 民居）與功能（展示 vs 防護） |
