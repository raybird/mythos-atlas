# Ariantas 與箭鏃人口普查——用一隻巨釜清點一個民族

- **文化：** 斯基泰神話 (Scythian Mythology)
- **文獻地位：** 希羅多德《歷史》卷四第81–82節
- **類型：** 王權測量術；並非神話，而是被卷四收錄為「唯一奇觀」的工藝與暴政敘事

## 故事背景：希羅多德為什麼要記這個

卷四第81節的主詞是希羅多德自己。開篇第一句就是承認無知：

> 「斯基泰人有多少人，我**無法確切得知**；但我聽到的說法彼此不符，有人說極多，有人說極少。」

然後他說：關於這件事，「他們讓我亲眼看到的是這樣的」——於是引出巨釜。這個敘事結構值得注意：**希羅多德先用三句話宣布自己無知，再用一件器物故事來填補。** 一件可以量體積的物證，恰好取代了他缺少的數字。

因此這則故事同時是三樣東西：一則工藝奇聞、一個關於統計暴政的寓言、以及希羅多德敘事技巧的示範。

## 情節

### 一、命令

> 在 **Borysthenes**（第聶伯河）與 **Hypanis**（南布格納河）之間有一片地方，名叫 **Exampaeus**——我在說到那裡有一道鹹水泉、使 Hypanis 不堪飲用時，曾提過這個地名。**這片地方立著一口青銅器皿**，比 Kleombrotos 之子 **Pausanias** 在 Pontus 入口所奉獻的那口鍋要大六倍。凡未見過後者的人，我可以這樣說明我的意思：這口斯基泰青銅器皿**輕易容納五千四百加侖**，壁厚**六指**。

「Exampaeus」在斯基泰語中意為**聖道**（希臘語 ἱεροί），而這個地名同時也是鹹水泉所在——希羅多德在 4.52 已交代。此處把神聖地名與飲用水毒化並置，是卷四常見的那種冷峻的地理反諷。

### 二、徵集

> 這器皿（當地人這樣說）是用**箭鏃**製成的。他們的國王名叫 **Ariantas**，想知道斯基泰人的人數，就命令**每一個斯基泰人**帶來他箭上的**箭頭尖端**，並威脅不從者處死。於是極大量的箭鏃被帶來；他決定用它們製作並留下一件紀念物，**他便用這些箭鏃鑄成了這口青銅器皿**，把它立在 Exampaeus 這個地方。

### 三、量測：如何知道它容納五千四百加侖？

希羅多德在 4.81 並未停在奇聞，他把量測的方法也保留下來：**與 Pausanias 在 Pontus 入口奉獻的那口鍋相比，大六倍。** Pausanias 的鍋是希臘世界可見的定標物（4.82 記希臘人在 Borysthenes 以東的河邊見過一件「極大的器皿」）。希羅多德實際上做的是：**用一件已知尺度的外物，把一件不可數的本地物轉成可比較的數。** 這是全卷中他最接近「科學」的一次操作。

## 為什麼這不是神話

這則敘事常被當作「神話」收錄，但它的機制與卷四其他段落不同，值得明說：

| 判準 | 本則敘事 | 對照：蛇足女神、Tabiti |
|---|---|---|
| 是否解釋自然或社會的起源 | 否 | 是 |
| 是否有神名 | 否（全篇只有一個國王名） | 是 |
| 是否有超自然行為 | 否（鑄造一隻器皿是技術行為） | 是 |
| 是否有道德／象徵結構 | 有（強制徵集、以死亡威脅） | 有 |
| 敘事時態 | 希羅多德宣稱為當代可見之物 | 明確屬「他們說」 |

所以它屬於卷四中的**第三類**：習俗記錄（4.59–4.72）與神話（4.5 Zalmoxis、4.27 Arimaspi、4.8 起源）之外的**物質記錄**。把這類材料當神話寫，是資料庫分類上最常見的錯誤。本頁因此把它放進 `stories/` 而不放進 `gods/`，並在內文標明其性質。

## 暴政的結構：一次成功的統計

Ariantas 的設計在政治上非常有效，值得逐項分析：

1. **以全民為單位。** 不是抽樣、不是問村莊，而是**每一個人**。這使得它無法規避。
2. **以死為唯一罰則。** 沒有替代選項：交或不交。沒有部分履行的空間。
3. **徵集物本身就是被統計者的生產工具。** 箭鏃是獵人每天都要用的東西；被徵集的不是財富、不是土地、不是穀物，而是**他們謀生的器物**。因此這個普查在象徵層面等同於徵收生業本身。
4. **產物是永久的、不可逆的、公共的。** 器皿被立在聖道上，不是熔掉還劍。**被統治者的日常工具被凝固成王權的紀念碑**，而這座紀念碑同時公開了被統治者的總數——這是最尖銳的一點：**Ariantas 得到了他想要的數字，方式是把它鑄成一件任何路過的人都能量的巨物。** 統治者想要的資訊與被統治者想要的隱私，在這一則裡正面相撞。
5. **戰爭背景。** 這段記述緊接在 4.80（Scyles 被斬）之後、4.83（大流士備戰）之前。希羅多德把它放在「被征服的隱憂」與「即將到來的戰爭」之間，一個刻意令人不安的位置。

## 4.82：全境唯一的奇觀，以及它的問題

希羅多德在 4.82 收束「此地面無奇觀」一節，但立刻給出一個例外：

> 除了河流（其大小與數量為世界之最）與平原的廣闊之外，有**一件對我最為驚異的事**：他們在 **Tyras** 河附近指給我看一個岩石上的 **Heracles 足印**，形如人的腳印，但**長達兩肘**。

這裡有一處文本問題必須指出：希羅多德在同一節（4.82）說「此地面無奇觀」，然後立即給出「最為驚異」的奇觀。**「無奇觀」與「最為驚異的奇觀」並存在相鄰兩句之內。** 這通常被解釋為他把 4.81 的巨釜排除在「奇觀」之外（因為它已被歸入「人數」的討論），但 4.82 結尾的足印又被算作奇觀，因此排除標準未被明說。無論如何，這是希羅多德編輯行為的一個可見痕跡，本庫不應抹平。

更值得留意的是足印的功能：它是**一個超自然存在被印在岩石上的、不可移動的物證**——與巨釜同為「可量測的物證」。兩件物證都與 Heracles 有關（巨釜在聖道上，足印在 Tyras 河邊），而 Heracles 在卷四是**被希臘人認定的英雄，不是斯基泰的神**（他出現在 4.59 的神祇清單中，4.8 另有三子故事）。因此這兩則奇觀共同做了一件事：**它們把一個希臘英雄的痕跡，物理地固定在一片不承認希臘習俗的土地上。** 這是帝國地理學與神話地理學交會處最典型的一次操作。

## 跨文化平行

| 傳統 | 對應 | 共通點與差異 |
|---|---|---|
| 希臘（《伊利亞特》與荷馬史詩中的寶庫清點） | 阿基里斯在帳中清點戰利品 | 同為「把掠奪轉為可清點之物」的儀式；差在阿基里斯清點的是**戰利品**，Ariantas 清點的是**臣民** |
| 波斯（Herod. 7.100–102） | 大流士在歐里西安清點軍隊 | 希臘人記錄波斯國王如何以文字與名冊治理；Ariantas 以青銅器治理，兩者是帝國統計手段的兩端 |
| 印度（《薄伽梵歌》2.20 及諸王皆被「一、二、三」代數統治） | 連那數者之數的宇宙統治者 | 同為以**數**作為秩序保證的神學 |
| 羅馬（*census* 與 Servian 壁） | 塞維亞的公民普查與名錄 | 羅馬把普查結果刻在石上；Ariantas 把普查結果鑄成器皿。**刻名 vs 鑄量**是同型操作的兩種媒介選擇 |
| 聖經（《民數記》21） | 以色列人口的十二支派點名 | 同為「按支派逐人點算」；希伯來文本刻意強調點算的聖潔性與恐懼，與 Ariantas 的強制性質相反 |
| 中國（《禮記·王制》） | 三年一籍籍，與「三年一大比」核對人口 | 制度化的人口登記；與 Ariantas 的一次性奇觀式清點形成「常設官僚 vs 個人奇想」的對比 |
| 阿卡迪亞／呂加維亞（Pausanias 1.28） | 呂加維烏姆的重寶（歐里提亞戰役的戰利品） | 希臘世界把蠻族寶藏置於聖所中作為戰利品陳列，與 Ariantas 把箭鏃置於聖道同屬「戰利品的公共化」 |
| 斯基泰本土（4.72） | 王死滿一年後以五十名侍從與五十匹馬殉葬 | **同一卷內的對照**：4.72 的集體犧牲以「人與馬各五十」為單位，設計目的是**榮耀死者**；4.81 的集體徵用以「人人一鏃」為單位，設計目的是**計算生者**。**榮耀 vs 計算**是本頁最應分清的一組對立 |
| 格里芬與守金神獸 | [守金神獸跨文化比較](../comparisons/守金神獸跨文化比較.md) | 4.27 的 Arimaspi 與 4.82 的足印同屬「北方有希臘痕跡」母題 |
