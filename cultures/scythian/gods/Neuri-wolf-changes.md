# Neuri 的化狼變形 (Werewolves of the Neuri)

- **文化：** 斯基泰神話 (Scythian Mythology)／黑海北岸
- **職掌：** 每年一次的短暫人狼變形；薩滿式變形信仰的早期希臘記錄
- **文獻地位：** 希羅多德《歷史》卷四第105節（**卷四中唯一提及此信仰的一節**）
- **族群定位：** 紐里人 (Neuri)——希羅多德 4.102 列於被 Idanthyrsos 徵詢結盟卻拒絕出兵的七族之首

## 概述：整卷只有一句話，卻留下三個問題

希羅多德 4.105 對人狼變形的記載極短：

> 「紐里人遵行斯基泰的風俗。**在大流士大軍到來之前一代**，他們因蛇而被迫完全離開自己的土地：他們的土地生出大量蛇，而更多的蛇自國境上方的荒野湧下；最後他們受不住压迫，遂離開故土，定居於布狄noi（Budini）之中。這些人看來是**巫师（wizards）**；因為斯基泰人、以及定居在斯基泰土地上的希臘人都說：**紐里人每年每人都要變成狼數日，之後再恢復原形**。」

然後希羅多德立刻加了一句他自己都不信的話：

> 「**我個人不相信他們這樣說**，但他們確實這樣宣稱，而且還對此發誓。」

這段文字的價值不在內容本身（希臘人顯然當它是真的希臘人故事），而在於它的結構：**一個被明確標記為「不信」的信仰記錄，同時又被三個獨立群體（斯基泰人、居住在斯基泰的希臘人、紐里人自己）宣稱並以誓言担保。** 希羅多德在卷四裡對斯基泰習俗的態度一貫是「記錄—懷疑—照錄」，而 4.105 是這種態度最乾淨的一次示範。

## 三個值得追問的問題

### 一、為什麼是「一年一代」？

蛇災發生的時機被希羅多德標為「大流士大軍到來之前**一代**」（προτέρῃ γενεῇ）。這不是神話時間，而是他自己推算的年代位置——希羅多德在卷四中反覆做這種定位。於是「人狼」與「蛇災」在時間上被綁定：蛇是迫使紐里人遷徙的直接原因，而遷徙去 Budini 恰恰使他們進入布狄人的森林——4.109 記載 Budini 境內有一座大湖與蘆葦沼澤。**蛇（地下／沼澤）→ 遷徙 → 森林湖畔 → 狼** 這個序列不是我們加上去的，是文本自身給出的地理條件。

### 二、為什麼是「數日」而非永久？

4.105 的關鍵詞是 εἰς αὖτις（若干日）與 μετέπεσαν εἰς τὸν αὖ αὖ πάλιν εἶνον（再次回到原形）。這與 4.66 的年度祭、4.62 的巨型柴堆祭、4.69 的五十年期喪禮不同：**紐里人的變形是一個週期性的、可逆的、且小規模的**週期。

這正是「變形巫術」而非「獸形化身神話」的判準。祂亞的 Natanzu、Lycaon 變狼、Šukuna 與 Ōkuninushi 的 animal-possession 儀式都屬後者——變形是**一次性懲罰或神恩**。紐里人的版本沒有懲罰也沒有神恩，變形只是**年度的常態義務**，像attendance。這一點使它比任何單一神話都更接近考古與民族志記載的高地亞狼群儀式。

### 三、為什麼是「每年每個人」？

希臘文的 εἰς ἔτος ἕκαστος 是「逐年、各人」。個人性與普遍性同時被宣稱：不是「某些人」（氏族祭師）能變，而是「每個人」。這與 4.67 的 Enareis 構成有趣的對照——Enareis 以柳枝占卜，而其占卜技藝是**世襲的**（κληρονομίη），並被說成由 Aphrodite 授予。同一卷裡，一邊是世襲的專門神職，一邊是全民的年度義務。希臘人顯然更樂於把「全民皆巫」描述成一個外族群體的集體怪異。

## 「狼」作為草原身份的物質基礎

紐里人的記載有一層常被忽略的經濟解釋。希羅多德在卷四留下了關於斯基泰世界物質條件的冷靜記錄：4.58 說斯基泰的草是「已知牧場中最催膽的」；4.28 說極北之地八個月結冰、海與辛梅亞海峽全封，行軍需走冰面，驅車橫行；4.105 說紐里人的土地自己產蛇。

在這種環境裡，**狼不是象徵，是生業**。紐里人被蛇趕出土地時，帶走的技能只能是牧獸；定居 Budini 森林後，狼既是害獸也是皮貨來源。早期歐亞研究（Küng 1964；伯爾斯提出的「狼崇拜」假說）正是從這個物質面切入，試圖解釋為何「祖靈化狼」在印歐語世界普遍出現。Ustinova 對博斯波魯王國至高神的分析也把動物形態神格放在黑海殖民地的希臘化語境中處理——即：希臘人記錄的「原始」信仰，很可能是**已經被希臘殖民者觀察並重新編碼**的信仰。

## 文本可靠性：必須交代的兩個矛盾

1. **希羅多德自稱不信。** 這在本卷是例外狀況。他對 4.5 的 Zalmoxis 用同樣口氣（並補上「據說是 Dacian 的 slave，其實是 Pythian 的 slave」這種嘲弄），對 4.105 亦然。所以不能把 4.105 當作希羅多德採信的證據，只能當作**他記錄了什麼的證據**。
2. **卷四無其他呼應。** 化狼在卷四只此一處，既無神名，也無節慶名，也無对应的神話解釋（無 Lycaon、無被罰的起因）。這使得它更像一個**在希臘世界已有既有意義框架的傳說**（Lycaon 之狼、Arcadia 的狼人、月神的犬），被希臘聽眾套用到一個他們無法歸類的北方民族身上。換言之，4.105 可能記載的是「希臘人如何想像北方蠻族」，而不是「北方蠻族如何想像自己」。

## 跨文化對應

| 文化／傳統 | 對應 | 共通點與差異 |
|---|---|---|
| 希臘（阿卡迪亞） | Lycaon 變狼（Ovid *Metamorphoses* 1.313–323） | 同為人變狼；差在 Lycaon 是一次性懲罰，帶有明確的褻瀆起因，且神王宙斯以雷擊回應。**週期性 vs 一次性**是兩者最要的分界 |
| 希臘（Pieria） | Zeuxo／Lycaon 之女的月神傳說 | 希臘人始終把狼人化放在**月亮**的框架裡（Zeuxo 生 Arcas 的母狼故事），紐里人的記載沒有月亮角色 |
| 斯拉夫 | *vьlkolak*（-serpent／wolf 之血族裔） | 歐亞最完整的化狼民俗帶；與紐里人同屬「變形是血統繼承」而非「變形是週期儀式」的類型 |
| 日耳曼／北歐 | 芬尼爾（Fenrir）與 *úlfhVéatr*（狼咬） | 愛國者的死亡不是變形，而是名字被記錄；正好構成「變形」／「標記」的對位 |
| 愛爾蘭 | Cú Chulainn 的 eidolon 與 *werewolf* 民俗 | 愛爾蘭把犬科恐怖放在戰鬥與讖歌框架內，幾乎不涉神話宇宙論 |
| 日本 | 狛犬、大國主的「魂魄」移附 | 日本的動物化是**靈魂移入他體**而非人身變形，方向相反 |
| 中國（山海經） | 開明獸、人狼同形類條目 | 結構上最接近：不是神話因果，而是**圖譜式並列**的異形存在登記 |
| 印度 | *śāṅkhin*／部分 Śūdra 巫者的虎變 | 與紐里人同屬「人可暫時取得動物形態」的巫者傳統，且同樣與難以清除的叢林地帶綁定 |
| 中亞 | 蒙古—突厥的狼祖（Asena／波什拉克系譜） | 差在方向：這是**血統起源**（狼為祖），不是週期性變形。**祖源說 vs 變形說**是本頁最應分清的一組對立 |
| 西伯利亞 | 科雷亞克（Koryak）與阿伊努的「人變熊」 | 最接近的現代民族志對應：周期性、可逆、由祭司引導，並與狩獵季同步 |
