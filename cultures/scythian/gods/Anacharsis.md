# Anacharsis（阿納卡爾西斯）— 被希臘世界聖化的「野蠻智者」

- **文化：** 斯基泰神話 (Scythian Mythology)／希臘化傳統
- **職掌：** 哲學、節制、格言傳作者；非神祇，而是被抬升為聖者的凡人
- **文獻地位：** 希羅多德《歷史》卷四第46、76–77節；第歐根尼·拉爾提斯《名哲學家傳》卷一第101–106節

## 概述：先講清楚一件事——他不是神

本頁必須從一個方法論聲明開始，否則整頁會變成希臘人願意相信的東西的轉述：

**斯基泰本土文獻中沒有 Anacharsis 的任何祭祀記錄。** 希羅多德卷四記載的斯基泰神祇共七位（Tabiti、Papaios、Api、Goitosyros、Argimpasa、Herakles、Ares，另王族祭 Thagimasadas），Anacharsis 不在其中；他出現在卷四的方式，是一個被自己的族人以箭射殺的政治事件。

那麼為什麼他值得一座神祇頁？因為他確實被**聖化**了——只是聖化他的是希臘與羅馬文獻傳統，而這套聖化装置本身就是本頁的 研究對象。這是資料庫處理「文獻所載的神話」與「文獻所構造的神話」時必須分開的兩件事。

## 系譜：卷四唯一一份可考的族譜

希羅多德 4.76 給出 Anacharsis 的完整父系鏈，這是他在本卷中唯一具有可考身世的非王室人物：

> Anacharsis 是 Idanthyrsos 的伯父（父系），Gnurus 之子，Lykos 之子，Spargapeithes 之孫。

關鍵推論希羅多德自己也明說了：既然 Idanthyrsos 是「殺死 Anacharsis 的那個 Saulios 之子」，那麼 Anacharsis **死在自己兄弟手上**。這是全卷少數可以閉合的家系邏輯。

第歐根尼·拉爾提斯 1.101 給出另一套說法：Anacharsis 是 Gnurus 之子、**Caduidas（斯基泰王）之弟**，母親是希臘人，故能說兩種語言。「母為希臘人」這一點解釋了為何他能讀寫希臘文，也是後世「半希臘的斯基泰王子」形象的來源。Suda（Alpha 258）另稱他為 Daucetas 之子。三說互斥，本頁並列而不強行調和。

## 4.46：一個被精心構造的「唯一例外」

卷四最值得注意的，不是 Anacharsis 的死亡，而是希羅多德在 **4.46** 為他預留的例外：

> 「我們無法指出黑海彼岸任何民族有什麼明智之處；**（若不把斯基泰民族與 Anacharsis 算在內）** 我們也不知道那裡出過什麼有名望的人物。」

希羅多德接著用整整一段讚美斯基泰——不是讚美其人，而是讚美其**戰術發明**：無城無郭、居處在車上、以馬為家的騎射手，使來犯者無從追蹤、無從逃脫。這是卷四對斯基泰唯一的稱讚，而它是一個純技術性的稱讚，與德性無關。

於是形成一個精確的修辭結構：

1. 先把整個地區判定為無知（4.46 前段：「沒有人在黑海這一側比別人更愚鈍」）；
2. 挖出一個例外，而且這例外只有一位、只有一個領域（智識）；
3. 稱讚這個民族，但只在一個領域（軍事生存），且該領域與智識無關；
4. 然後在 4.76 讓這唯一一位智者因為愛希臘而被族人射殺。

**希臘傳統必須先給斯基泰一個智者，才能殺掉他；而殺掉他的正是他愛的那個希臘。**這是「野蠻智者」母題的引擎：聖性不是天賦，而是被否定後才顯形的東西。第歐根尼·拉爾提斯 6.54 記錄了犬儒派對此的冷笑——有人問 Anacharsis 怎麼會變成斯基泰人，他答：一個斯基泰人在路上遇到我。這句話把整套構形自己說破了：野蠻性是可以被**穿上的**，正如希臘衣可以被穿上（見 [Scyles 與酒神入教](../stories/scyles-and-the-bacchic-initiation.md)）。

## 希臘方面的聖化装置

- **七賢名單**：第歐根尼·拉爾提斯 1.41–42 收錄的七賢名單把 Anacharsis 列入其中。注意各家名單不一致（柏拉圖《普羅泰戈拉》的第七位是 Myson of Chenai），因此「七賢之一」應表述為「部分名單列入」，而非定論。
- **雅典公民權與入教**：他約於前 589 年抵達雅典（第歐根尼·拉爾提斯 1.101，經 Sosicrates 說），傳聞獲雅典公民權並得以參與厄琉西斯祕密祭禮——這在當時是對通曉希臘語者的特權。普魯塔克《梭倫傳》5 記他與梭倫的交往。
- **著作與墓誌**：他寫過論希臘與斯基泰制度的八百行詩（第歐根尼·拉爾提斯 1.102，此書已佚），並留下銘文：「我從旅行歸來／一心要希臘化所有的斯基泰人／才講到一半，激怒了眾人的心……」
- **格言與書信**：大量所謂 Anacharsis 格言與書信（如致 Croesus 者）皆屬**後人偽托**。小普林尼《自然史》7.11.28 記他是唯一寫下箴言的斯基泰人。此區分的必要性正是本頁的職責。
- **十八世紀的再生命**：Jean-Jacques Barthélemy 於 1788 年出版《年輕的 Anacharsis 的希臘旅行記》，把這位斯基泰智者寫成歐洲會讀的小說主角，Anacharsis 從此成為啟蒙時期「高貴野蠻人」的定式。

## 死亡：一個被結構化反轉的場景

希羅多德 4.76 的場景是全卷最精緻的敘事之一：Anacharsis 渡過赫勒斯滂彭，於 Cyzicus（Kyzikos，Propontis 岸）遇眾神祇盛大慶典，遂向**眾神之母**立誓——若平安返國，便以完全相同的方式獻祭並舉行夜祭。返國後他進入名為 **Hylaia** 的樹林（正對 Achilleus 的跑道一帶），手持**手鼓**、身繫**神像**，行全套儀式。一名斯基泰人見狀稟告國王 **Saulios**，國王親至，以**一箭**射殺之。

其後：「今日若問起 Anacharsis，斯基泰人便說他們不認識他。」

希羅多德並不滿足於此。他補上兩層。第一層來自 Ariapeithes 的管家 Tymnes，即上文那條家系（→ 死於兄弟之手）。第二層是伯羅奔尼亞人版本：Anacharsis 是國王派往希臘的使者，回國後稟報「所有希臘人都忙於各種學問，唯獨拉刻代夢人不然；但只有他們懂得如何有分寸地交談」——希羅多德親自加上評語：**「這是希臘人自己為了取樂捏造的故事。」**（πέπλασται）

結構上的要點：希臘必須同時**擁有** Anacharsis（好讓自己顯得開明地承認他）與**否認**他是自己捏造的（好讓自己不為他的死負責）。希羅多德把這第三種選擇寫進了正文，讓讀者自己判斷。

另需與既有頁面對照：[[Anacharsis 的悲劇]] 記的是同一事件，該頁處理希臘方面的「高貴野蠻人」評價；本頁處理的是他在希臘文獻中被聖化的過程，以及 4.46 與 4.76 之間的修辭落差。

## 跨文化對應

| 文化／傳統 | 對應人物或構形 | 關係與差異 |
|---|---|---|
| 希臘（犬儒派） | Anacharsis 作為「高貴野蠻人」 | 犬儒派刻意讓他**同時**代表野蠻的優點與野蠻的粗蠻（拒絕使用餐具、對陶盆小便），使他無法成為理想化對象 |
| 希臘（七賢名單） | Thales／Bias／Solon／Pittacus 等 | 名單本身就是「把外來智慧納入希臘秩序」的装置；Anacharsis 與 Myson 是名單上兩個明顯的外來／邊緣位置 |
| 羅馬 | Cornelius Nepos《外族名将傳》(De excellentibus ducibus exterarum gentium) | 整部書把「異族的德性」做成專門文類，是 Anacharsis 構形的制度化後繼；Nepos 寫的 Miltiades 正是同一邏輯 |
| 羅馬 | 西元前一世紀的「蠻族德性」論述（塔西陀《阿格里科拉》43 的 Calgacus） | 羅馬帝國需要一個比希臘更好而更純的德性來源，於是反轉希臘的野蠻人論 |
| 凱爾特 | Caesar《高盧戰記》1.31 的 Druid Diviciacus | 最接近的結構：羅馬自己的「野蠻智者」，且同樣以演說詞形式被錄下、同樣出現在征服者的文本中 |
| 波斯 | Darius 宮廷中的智者（Otanes 等，Herod. 3.120–134） | 希臘人對「蠻族有賢人」的想像在別處也成立，可見這是常見敘事裝置而非孤例 |
| 印度 | ṛishi 與哲學王（Daśaratha、Janaka、Devaśarman） | 婆羅門傳統中的「非婆羅門／非雅利安聖賢」同樣承擔道德批判功能 |
| 中國 | 《論語》「蠻夷」與賢者的相對位置 | 儒家把聖人放在「有教無類」的超越位置，對應的是否定血緣的普遍主義；與希臘肯定野蠻自然質素的方向相反 |
| 印加 | Manco Cápac 與「安第斯之母」Auquyñakuya | 給野蠻智慧一個神話化而非理性化的源頭，是與希臘式構形相反的處理方式 |
| 俄羅斯 | 正教的聖愚 (yurodivyi) | 以「裝瘋」取得智慧位置，與 Anacharsis 的格言型智慧形成另一條路徑 |
