# 馬神崇拜 — 斯基泰神聖馬匹信仰

- **文化：** 斯基泰神話 (Scythian Mythology)
- **職掌：** 馬匹、戰爭機動、祖先靈魂載體、獻祭媒介
- **希臘對應：** Poseidon Hippios（馬神波賽頓）
- **梵文對應：** Ashvins（雙馬神）

## 概述

馬在斯基泰文明中的地位遠超工具或戰略資產——馬是神聖的存在，是連接人界與天界的活媒介。希羅多德在《歷史》卷四第 61 節記載，斯基泰人「以馬血向 Zeus（Papaios）獻祭」，而在王室葬禮中，國王的坐騎被一同殉葬，象徵馬承載國王靈魂升入天界。考古發現（如帕茲里克 Frozen Tomb、庫爾—奥巴 Kurgan）證實了大規模馬匹殉葬的規模——一座斯基泰精英墓葬中可發現多達二百匹馬的骨骼，排列成完美圓形，彷彿在冥界繼續為主人巡行。

斯基泰人是人類歷史上最早將馬完全融入宗教體系的民族之一。與其說他們「崇拜馬神」，不如說他們將馬視為一種「活著的神聖」——馬的奔跑象徵太陽的運行，馬的嘶鳴被認為能驅散惡靈，馬血是洗滌罪愆的聖水。這種觀念在後來的突厥、蒙古、哈薩克等草原民族中延續了兩千年以上。

## 神話事蹟

### 馬與創世

斯基泰起源神話中，始祖英雄 Targitaus 與馬有密切關聯。希羅多德記載，Targitaus 是「Zeus 與 Borysthenes 河神之女」的後代——而 Borysthenes 河（第聶伯河）在斯基泰語中意為「馬之河」，暗示馬與水、馬與創世的原始連結。在印歐比較神話中，原始馬往往被視為宇宙的承載者——印度《梨俱吠陀》中的Ashvins（雙馬神）在黎明時分載著太陽穿越天空，與斯基泰人將馬與太陽運行連結的觀念完全一致。

### 王室殉馬

斯基泰國王去世時，其最心愛的坐騎被活殺殉葬。希羅多德記述了這一儀式：「他們選出国王最喜愛的馬，將其殺死——不是用刀，而是以木棒擊殺——然後將馬屍安置在墓室中。」這匹馬的靈魂被認為會在冥界繼續為國王服務。在帕茲里克 Frozen Tomb 中，考古學家發現了一匹被精心保存的冰凍馬匹，馬身上裝飾著黃金飾片，馬鬃編成精緻的辮子——這是斯基泰人將馬視為高等存在的直接證據。

### 薩滿坐騎

斯基泰的薩滿（希羅多德稱其為「Enarees」或「Anarioi」）在進行通靈儀式時，會以馬匹作為靈魂飛升的載體。薩滿擊鼓或吟唱時，其靈魂被認為化為馬形升入天界與祖先溝通。這種「薩滿騎馬飛升」的母題在西伯利亞薩滿教中完整保留——雅庫特薩滿至今仍以馬骨製成面具，象徵靈魂乘馬穿越三界。

## 跨文化對應

| 文化 | 對應信仰 | 共通點 |
|------|----------|--------|
| 印度 | Ashvins（雙馬神）/ Ashva（馬） | 馬與太陽運行、王權象徵 |
| 北歐 | Sleipnir（奧丁八足馬） | 馬作為靈魂穿越三界的載體 |
| 波斯 | Aspa（馬）/ Bahram（勝利） | 聖馬崇拜、王權合法性 |
| 蒙古 | 馬奶酒祭天/天馬崇拜 | 馬與長生天(Tengri)的連結 |
| 中國 | 天馬/龍馬 | 馬與天界、龍的原型連結 |
| 希臘 | Poseidon Hippios | 馬神作為海神的次級神格 |

## 相關神祇
