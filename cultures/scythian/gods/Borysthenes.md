# Borysthenes（鮑里斯提涅斯）— 第聶伯河神與王族外祖

- **文化：** 斯基泰神話 (Scythian Mythology)
- **職掌：** 河流、豐饒、王權血統、疆域主權
- **語源：** 古伊朗語 *\*varu-stānā-*（「寬廣者」）→ 希臘語 Βορυσθένης
- **希臘對應：** 河流之神 Acheloös / 河神綜合體

## 概述

Borysthenes 是第聶伯河（Dnipro）的古名，也是斯基泰神話中以河神身分被崇拜的原始神靈。希羅多德在《歷史》卷四第5節記載斯基泰創世神話時明確指出：斯基泰始祖 Targitaus 的父母是「Zeus 與 Borysthenes 河的女兒」——換言之，Borysthenes 是斯基泰王族的**外祖父**，整個斯基泰民族的王權血統直接出自河神的後裔。希羅多德同時坦率表示「我不相信這個故事，但他們如此傳說」（Hdt. 4.5.1），保留了這則本土神話作為希臘人的轉述文本。

現代比較神話學學者（Benveniste、Dumézil、Ivantchik）指出，Borysthenes 之女在斯基泰神話的另一個版本中即為大地母神 **Api**（「水性者」）。《波羅的海—北地》（septentrio 論文）與 Lincoln 的研究均確認：Borysthenes 之女在別處以「蛇足女神」或 Api 之名出現，與 Papaios（Zeus）交合而生 Targitaus。因此 Borysthenes 並非孤立的水神，而是嵌入天地父母宇宙觀中的「父系水流」一環——他同時連接地母的滋生與天父的權威。

## 神話事蹟

### 河神之女與王族誕生

根據希羅多德的轉述，斯基泰人自認「全世界最年輕的民族」。他們說最初大地上無人居住，一名叫 Targitaus 的男子出現於此。Targitaus 的父母為 Zeus（即 Papaios）與 Borysthenes 河的女兒。Targitaus 育有三子——Lipoxais、Arpoxais 與最年幼的 Colaxais。三兄弟統治期間，天降金器（犁、軛、劍、酒杯），唯有幼子 Colaxais 能接近燃燒的黃金，因而取得王權（Hdt. 4.5.2-4）。這段敘事以「河神—天帝」雙系血統奠定王權合法性，並以「天降金器」完成王權的神聖授受。

### 作為疆域主權象徵的河流

第聶伯河對斯基泰人而言不僅是水源，更是**核心領土的主權標誌**。希羅多德稱 Borysthenes 為「除尼羅河外所有河流中最高產」（Hdt. 4.53），沿河分布最肥沃的牧場與最豐美的草原。斯基泰人將王族血統系於此河，等於宣示其對第聶伯河流域的統治乃由神授——河神的後裔天然擁有河岸土地。這與埃及法老自認尼羅河之子、波斯君主自認「阿娜希塔之水」的庇佑，結構上完全同構。

### 河神與創世地理

在希羅多德的敘事中，Borysthenes 之女作為「蛇足女神」住在 Hylaia（「林區」）的洞穴中——該地正位於第聶伯河下游海岸附近。學者認為這是「河神之女」與「蛇足地母」兩種形象的合流：河流既是大地之水的出口，蛇足女神則象徵地下深淵的孳生力。Borysthenes 因此同時是「地表之河」與「冥界之水」的雙重化身，橫跨生者世界與地母的宮殿。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 希臘 | Acheloös（希臘最大河神） | 河神為王族/英雄祖先，可變形 |
| 埃及 | 尼羅河神 Hapi | 河流為國土豐饒與王權合法性的來源 |
| 波斯 | Anahita（水/豐饒女神） | 王權沐浴、水流庇佑君主 |
| 中國 | 河伯（黃河之神） | 河神受國家祭祀、王權與河流相繫 |
| 印度 | Ganga（恆河女神） | 聖河後裔、王族血統與河水連結 |
| 北歐 | 沃盧斯帕中的河流 | 冥界之河作為生界邊界 |

Borysthenes 的獨特處在於：他既是**河流的化身**，又是**王族的外祖父**——王權的來源不是「征服河流」，而是「出自河流」。這使斯基泰王權神話帶有強烈的本土自動敘事色彩，與中國大禹「治水定國」的征服模式、希臘英雄「馴服河神」的試煉模式皆不同。
