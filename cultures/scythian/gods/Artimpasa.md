# Artimpasa — 豐收與動物女神

- **文化：** 斯基泰神話 (Scythian Mythology)
- **職掌：** 動物繁衍、草原豐收、女性生育、自然力量
- **語源：** 斯基泰語 *\*arti-*（正確/秩序）+ *\*mpasa*（可能為蛇/爬蟲語根）
- **希臘對應：** Artemis / Aphrodite（混合特質）

## 概述

Artimpasa（希臘文獻中有时拼寫為 Argimpasa 或 Artimpasa）是斯基泰萬神殿中最重要的女性神祇之一，地位僅次於 Tabiti（至高火女神）。希羅多德在《歷史》卷四第59節將她對應希臘的 Aphrodite（愛與美之神），但 Artimpasa 的功能遠比 Aphrodite 複雜——她同時掌管動物繁衍、草原豐收、女性生育與蛇的神聖力量。希羅多德特別提到斯基泰人稱 Artimpasa 為「Ojosir」，可能與後世阿蘭人（Alans）的「Asht」女神信仰有關。

在斯基泰藝術中，Artimpasa 常以蛇女神的形象出現——她的身體由多條蛇交織而成，手持權杖或聖杯。帕茲里克墓葬中出土的「蛇女神」金器飾件被認為是 Artimpasa 的化身。這種蛇女神形象在整個近東與地中海地區都有平行對應：克里特島的蛇女神、希臘的 Medusa、弗里吉亞的 Cybele 皆具有蛇與女性力量的結合特質。

## 神話事蹟

### 蛇女神與草原

Artimpasa 的蛇形身體象徵大地的 fertility（繁殖力）——蛇在地下穿行，帶來水脈與肥沃的土壤。斯基泰人相信蛇是 Artimpasa 的化身，每年春天蛇從地下甦醒時，草原開始復甦。殺蛇被視為對 Artimpasa 的褻瀆，可能招致牲畜死亡與女性不孕。

### 與 Heracles 的相遇

希羅多德記載了一則重要的神話：希臘英雄 Heracles 在斯基泰遊歷時，其馬群被半人半蛇的「怪物」偷走。Heracles 追蹤至一座洞穴，發現偷馬者為一位蛇身女神（即 Artimpasa）。二人結合，生下三子：Agathyrsos、Georgos 與 Scythes——後者成為斯基泰人的始祖。這則神話反映了希臘人對斯基泰蛇女神信仰的詮釋，同時保存了 Artimpasa 作為民族始祖母的神聖地位。

### 王室女性的守護者

斯基泰王后與女性祭司在 Artimpasa 的祭祀中扮演核心角色。帕茲里克墓葬中出土的女性墓主穿著精美的金箔服飾，頭戴蛇形冠冕，被認為是 Artimpasa 的祭司或化身。斯基泰女性在戰爭中同樣勇猛——希羅多德記載的「亞馬遜女戰士」（Sauromatae）傳說可能與 Artimpasa 崇拜密切相關。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 克里特 | 蛇女神（Potnia） | 蛇與女性力量、大地之母 |
| 希臘 | Medusa / Artemis | 蛇髮、野性女神、動物守護 |
| 弗里吉亞 | Cybele（大地母神） | 蛇、山洞、狂喜儀式 |
| 印度 | Nagini（蛇女/那伽） | 蛇與豐收、地下水脈 |
| 中國 | 女媧（蛇身創世母神） | 蛇身女性、創世/生育 |
| 埃及 | Wadjet（蛇神/王權守護） | 蛇與王權、保護力量 |

## 相關神祇
