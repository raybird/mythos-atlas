# 奧伊托敘羅斯（Oitosyros / Goitosyros）— 斯基泰的阿波羅

- **文化：** 斯基泰神話（Scythian Mythology）
- **職掌：** 弓箭、預言、音樂、光與真理之神
- **聖地：** 無特定建築——斯基泰人不為諸神造像建廟（除阿瑞斯外）
- **象徵：** 弓箭、天鵝、金色光芒、預言之聲

## 概述

奧伊托敘羅斯（希臘語：Οἰτόσυρος，拉丁化：Oitosyros，亦作 Goitosyros）是斯基泰萬神殿中對應希臘阿波羅（Apollo）的神祇。根據希羅多德《歷史》4.59的記載，斯基泰人崇敬七位主要神靈——塔比提（Hestia）、帕派奧斯（Zeus）、阿皮（Gaia）、奧伊托敘羅斯（Apollo）、阿爾金帕薩（Aphrodite Urania）、赫拉克勒斯（Heracles）與阿瑞斯（Ares）——其中奧伊托敘羅斯排名第四，僅次於天地父母。

奧伊托敘羅斯的語源可追溯至古伊朗語 *vahu-čitra-*（「美好的光輝」）或 *gauša-čitra-*（「耳聞的光」），暗示其本質與**光明**及**聽見／預言**的雙重能力相關。學者Boyce與Skjærvø認為此名與古波斯神話中對應阿波羅·赫利奧斯的太陽神職能一致。

## 神話與事蹟

### 斯基泰萬神殿中的位階

在希羅多德的清單中，奧伊托敘羅斯的排名是有意義的：塔比提（聖火）是最高階，因為她代表斯基泰社會的核心——部落的延續與冬季生存的關鍵。帕派奧斯（天父）與阿皮（地母）位列其後，代表宇宙結構的基本框架。奧伊托敘羅斯位居第四——他屬於宇宙秩序的「運作層」：他使天空的意志得以溝通至人間。

希羅多德將奧伊托敘羅斯等同於阿波羅，但兩者之間存在顯著差異。希臘的阿波羅是一位強烈人格化的神——他有母親（勒托）、出生地（提洛島）、箭袋與豎琴。奧伊托敘羅斯則缺乏這種神話傳記——他是更抽象的光輝力量，主要職能表現在兩個領域：弓箭與預言。

### 弓箭之神

在斯基泰社會中，弓箭不僅是武器，更是斯基泰人身分的根本標誌。希羅多德記載了一個波斯人眼中的斯基泰格言：「我們斯基泰人沒有城鎮與農田——我們是弓箭的主人。」奧伊托敘羅斯被視為弓箭技能的神聖來源。斯基泰人在狩獵與戰鬥前向奧伊托敘羅斯祈禱，請求他賦予箭矢以精確的路徑。

然而，與希臘阿波羅的不同在於：斯基泰的奧伊托敘羅斯從不以弓箭引發瘟疫——希臘阿波羅以銀弓降下疫病（如伊利亞特開篇），而奧伊托敘羅斯的箭只導向獵物與敵人，不懲罰崇敬者。

### 預言之源

希羅多德描述了斯基泰的占卜習俗：以柳枝排列來預測未來（類似阿波羅·達佛涅菲俄斯對月桂枝的使用）。此種柳枝占卜被歸屬於奧伊托敘羅斯的指導。

值得注意的是，斯基泰沒有類似德爾斐的神諭場所——他們的預言是移動的、與遊牧生活方式一致的。占卜者（Enares）在部落遷徙的過程中以柳枝為工具進行預言。奧伊托敘羅斯是「移動的神聖聲音」，不像在希臘那樣固定於一個地理中心。

### 與天鵝的關聯

在部分希臘化時代的記錄中，斯基泰人將天鵝視為奧伊托敘羅斯的聖鳥——與阿波羅相同。天鵝的道別之歌（kukneios aoidē）被認為是預言的載體。斯基泰人是否直接崇拜天鵝無法確定，但黑海北岸的斯基泰墓葬中出土了大量以天鵝為主題的金屬飾牌。

## 跨文化對應

| 斯基泰 Oitosyros | 對應神祇 | 文化 |
|-----------------|---------|------|
| 弓箭、預言、光輝之神 | 阿波羅（Apollo）——完全對應 | 希臘 |
| 與太陽光輝相關的男性神 | 密特拉（Mithra）——契約與光明之神 | 波斯 |
| 與光同名的古老神祇 | *Vahu-čitra-*（美好的光輝） | 古伊朗 |
| 弓箭之神 | 烏拉諾斯之子／箭神——多種弓箭相關神 | 北歐（烏勒爾） |
| 無神廟的移動預言 | 德爾斐式神諭的對立模式 | 遊牧文化普遍特徵 |
| 天鵝為聖鳥 | 阿波羅的天鵝車——天鵝與預言的關聯 | 希臘 |
