# Kultana — 斯基泰月神

- **文化：** 斯基泰神話 (Scythian Mythology)
- **職掌：** 月亮、潮汐、時間 cycle、女性生育、夜間旅程
- **希臘對應：** Selene / Hecate
- **梵文對應：** Chandra（月神）

## 概述

Kultana（古斯基泰語 *Kultana*，意為「閃耀者」）是斯基泰神話中的月亮女神，掌管夜間天體運行、潮汐漲落與女性月經周期。希羅多德在《歷史》卷四第59節的萬神殿清單中未明確列出月神，但考古證據——包括帕茲里克墓葬中的新月形金飾、黑海北岸希臘殖民地出土的斯基泰銀幣上的新月圖案——以及阿爾泰地區的口傳傳統，均證實月神崇拜在斯基泰宗教生活中佔有重要地位。Kultana 的名字可能與突厥語系 *kün*（日）或 *ai*（月）的古老變體有關，反映了斯基泰語與後續草原民族語言之間的深厚聯繫。

## 神話事蹟

### 月神與獵人

斯基泰民間流傳一則關於 Kultana 的核心神話：一位年輕獵人在月圓之夜迷失於草原，Kultana 以銀色光束為他照亮歸途。獵人為感謝月神，以白馬獻祭，自此斯基泰獵人出獵前必向月亮祈禱。這個故事反映了斯基泰人對月亮作為夜間旅行守護者的信仰——在廣袤無垠的歐亞草原上，月光是夜間遷徙與狩獵的唯一自然光源。

### 月神與潮汐

斯基泰人雖以草原遊牧為主，但其領地西臨黑海、南接裏海。希羅多德記載斯基泰人相信月亮「控制大海的呼吸」——月圓時海水上漲，月虧時海水退去。這一認知可能來自黑海北岸希臘殖民城市（如 Olbia、Panticapaeum）的希臘商人，也可能源於斯基泰人對河流（如第聶伯河、頓河）季節性漲落的觀察——這些河流的泛濫周期恰與月相有微妙的關聯。

### 月神與女性生育

在斯基泰社會中，Kultana 是女性月經與生育的守護者。考古發現的斯基泰女性隨葬品中，新月形胸針與項鍊最為常見，象徵佩戴者處於 Kultana 的保護之下。帕茲里克冰凍公主的陪葬品中亦有新月形銀飾，可能暗示她的薩滿身份與月神崇拜的關聯——在薩滿傳統中，月亮是靈魂夜間旅行的指引者。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 希臘 | Selene（月車）、Hecate（夜之女巫） | 月相周期、夜間守護、女性生育 |
| 印度 | Chandra（月神） | 月相與潮汐、時間 cycle |
| 伊朗 | Māh（月神） | 月亮在瑣羅亞斯德教中的地位 |
| 羅馬 | Luna（月神） | 新月崇拜、女性守護 |
| 蒙古 | Sarntuya（月之子） | 草原月亮崇拜、獵人守護 |
| 北歐 | Máni（月神） | 月亮的夜間旅程、時間 tracking |

Kultana 的獨特之處在於她與 Tabiti（火女神）的互補關係——Tabiti 守護白日與人間秩序，Kultana 守護黑夜與超自然世界。這一「火—月」二元結構在印歐神話中罕見，但與西伯利亞薩滿信仰中的「日—月」二元宇宙觀高度一致。
