# Apidai（阿庇代）——斯基泰神聖馬群

- **文化：** 斯基泰神話 (Scythian Mythology)
- **職掌：** 馬匹繁殖、王權象徵、王族始祖
- **來源：** 希羅多德《歷史》卷四 9-10
- **跨文化對應：** 希臘 Poseidon Hippios（馬神波塞冬）、印度 Ashvins（雙馬童）

## 概述

Apidai（古希臘語：Ἀπιδαῖοι）是斯基泰神話中具有神聖血統的馬群，其名稱源自希臘語「 apis 」（蜂），可能暗示其毛色上的斑點如蜂巢般金黃。希羅多德在《歷史》卷四第 9-10 節記載了這群神馬的完整起源故事：它們是希臘英雄赫拉克勒斯（Heracles）在第十項功績（將革律翁的牛群趕回希臘）途經斯基泰時所留下的後代。赫拉克勒斯的牛群在斯基泰荒野中走失，他四處尋找時來到一片原始森林，發現了一座獻給「處女神」（希臘語 Parthenos，可能指 Argimpasa 或蛇足女神）的聖所。女神告知他牛群已被偷走，但條件是赫拉克勒斯必須與她結合。赫拉克勒斯將弓與弓袋留在聖所作為信物後離去。女神後來生下三子——Agathyrsos（阿伽提爾索斯）、Gelonos（蓋洛諾斯）與 Scythas（斯基泰人）——其中只有幼子 Scythas 獲准留在母親身邊繼承王位，兩位兄長因不具備完全的純正血統而被放逐。

## 神話事蹟

### 赫拉克勒斯與蛇足女神的聖婚

希羅多德的記述暗示赫拉克勒斯在聖所中入睡時，女神化身為蛇與他結合——這一細節在帕茲里克與庫爾—奧巴（Kul-Oba）出土的斯基泰金器上有生動描繪：一位裸體女性上半身與赫拉克勒斯並肩而坐，下半身則化為蛇尾纏繞著他的腿部。赫拉克勒斯醒來後發現弓與弓袋已不見，蛇足女神告知他弓已被她的後代取走，但允許他帶著牛群離開。這段「聖婚」（hieros gamos）的神話結構與近東的神聖婚姻傳統有著深刻的對應關係——女神與外來英雄的結合象徵著土地與外來力量的融合，為王權正統性提供神聖依據。

### Apidai 的神聖血統

赫拉克勒斯留下的牛群後代成為 Apidai 神馬群。希羅多德記載，斯基泰王室每年都會從這些神馬的後代中選出十二匹最優良的馬匹，以酒潑灑後放生，令其自由奔跑。若有凡人觸碰這些神馬，將被處以嚴厲的刑罰——鞭打全身直到皮肉模糊。這項祭祀儀式被稱為 **Appendix**（「放生」），與赫拉克勒斯離開聖所時將神馬放歸草原的行為形成直接呼應。Apidai 的存在使斯基泰王族的統治合法性建立在「英雄之血」之上——三位斯基泰分支的祖先 Agathyrsos、Gelonos 與 Scythas 分別統治了歐洲部分的斯基泰人、靠近希臘殖民地的斯基泰人以及純正血統的斯基泰人，而只有 Scythas 的後代享有最純正的赫拉克勒斯與蛇足女神的神聖血脈。

## 跨文化對應

| 文化 | 對應概念 | 共通點 |
|------|----------|--------|
| 希臘 | Poseidon Hippios（馬神波塞冬） | 與馬匹的神聖關聯、王權象徵 |
| 印度 | Ashvins（雙馬童） | 神聖馬匹、治療與保護功能 |
| 希臘 | Pegasus（飛馬） | 英雄的馬匹伴侶、神聖血統 |
| 中國 | 龍馬 | 神聖動物輔佐王權、天授意象 |
| 北歐 | Sleipnir（八足馬） | 神馬作為跨越生死的載體 |
| 波斯 | 庫斯魯的白馬 | 王室白馬的神聖性 |

Apidai 的獨特之處在於馬匹本身即為神聖存在，而非僅作為神祇的坐騎。斯基泰社會以遊牧為核心，馬匹既是軍事力量的基礎，也是王權的直接象徵——這使得 Apidai 的神聖地位超越了單純的宗教意義，成為政治合法性的核心支柱。每年春季的馬匹祭祀（希羅多德《歷史》卷四第 59 節）是斯基泰最重要的宗教活動之一，其中十二匹 Apidai 後代的放生儀式標誌著王權的年度更新。

## 相關神祇

- 赫拉克勒斯（Heracles Scythicus）：Apidai 的始祖
- 蛇足女神（Argimpasa/Artimpasa）：Apidai 神聖血統的母親
- Thagimasadas：掌管海洋與馬匹的神祇，可能與 Apidai 的保護有關
