# 巴爾沙敏 (Barsamin / Barshamin)

- **文化：** 亞美尼亞神話 (Armenian Mythology)
- **職掌：** 天空與天氣之神、雷雨、蒼穹

## 概述

巴爾沙敏（Barsamin，亞美尼亞文 Բարշամին）是亞美尼亞基督教化之前萬神殿中的天空與天氣之神，其名直接來自西北閃語的巴力·沙敏（Baal Shamin，意即「天之主」）。這並非本土原生神祇，而是經由美索不達米亞—黎凡特路線傳入亞美尼亞高原的異域神格：庫爾基安（Vahan Kurkjian）記載，此神像是由亞美尼亞國王提格蘭（Tigran）自美索不達米亞運回，安置於達拉納希（Daranaghi）地區、靠近古城阿尼（Ani）的托爾丹村（Tʿordan）。根據莫夫謝斯·霍列納齊《亞美尼亞史》（2.14），巴爾沙敏在托爾丹設有著名的神廟，其偶像以象牙與水晶製成、以銀紋飾，通體瑩白，故被冠以「白榮」（spitakapʿaṙ）的美稱——這與敘利亞—巴爾米拉地區以白（潔淨、天光）表徵天空之神的傳統一致。在帕爾米拉，巴力·沙敏正是城中兩位至尊神之一，以鷹與閃電為表徵，並與月神阿格利波爾（Aglibol）、太陽神馬拉格貝爾（Malakbel）組成三元組。

值得注意的是，巴爾沙敏進入亞美尼亞後並未維持獨立至尊的地位，反而在時間推移中逐漸被吞併：學者指出，巴力·沙敏的正面功能最終被吸收進最高神阿爾馬茲德（Aramazd）的形象之中——後者的「眾神之父」稱號、雷電職能與蒼穹身分，實則兼容了本地造物主與外來天神的雙重遺產。這使巴爾沙敏成為亞美尼亞宗教「多源混成」（syncretism）最鮮明的例證之一。

## 神話事蹟

巴爾沙敏最著名的神話，並非他自身的事蹟，而是他與亞美尼亞本土雷火之神瓦哈根（Vahagn）的對決。七世紀天文學家阿納尼亞·希拉卡齊（Anania Shirakatsi）在《宇宙學與曆法》（Tiezeragitutʿiwn ew tomar）中記錄了一則古遠傳說：嚴冬時分，瓦哈根為了溫暖他的人民，潛入亞述人始祖巴爾沙姆（Barsham，即巴爾沙敏）的倉庫，偷走一捆稻草；逃跑途中稻草沿途散落，撒在蒼穹之上，化作燦爛的銀河——亞美尼亞人因此稱銀河為「偷稻草者的路」（Hardagoghi chanaparh）。希拉卡齊同時指出，他並不同意這則神話，而主張銀河實為大量星體聚集的光帶，此說竟比望遠鏡發明早了整整一千年。

此外，霍列納齊與民間傳統還保存了另一組鬥爭敘事：亞美尼亞先祖阿拉姆（Aram）曾擊殺「巴比倫的巨人巴爾沙敏」；庫爾基安進一步指出，「哈伊克射殺貝爾、瓦哈根鬥敘利亞的巴爾沙姆、阿拉姆戰巴比倫的巴爾沙敏」，實為亞美尼亞歷代王侯（烏拉爾圖諸王、阿爾塔謝斯、提格蘭）對抗亞述與巴比倫之戰爭的神話化投射——天上的神戰，是地上國戰的倒影。此外，亞美尼亞民間的薩法伊提克（Safaitic）銘文傳統同樣顯示，巴力·沙敏在閃族世界中幾乎壟斷降雨：雨水不被他「派發」，而是他自身直接的物質顯現；亞美尼亞人承襲了這套邏輯，將旱澇、雷暴歸諸於他。

## 跨文化對應

| 對應神祇 | 文化 | 對應關係 |
|---------|------|---------|
| Baal Shamin（巴力·沙敏） | 巴爾米拉／腓尼基 | 直接語源來源，同為「天之主」、鷹與閃電表徵 |
| Hadad（哈達德） | 烏加里特／迦南 | 同為風暴、雷雨之神，巴力稱號常被冠於其名 |
| Zeus Olympios（奧林匹斯宙斯） | 希臘 | 希臘化時期被以「天宙斯」詮釋，雷電職能對應 |
| Aramazd（阿爾馬茲德） | 亞美尼亞 | 吞併吸收巴爾沙敏的正面功能，同掌蒼穹 |
| Vahagn（瓦哈根） | 亞美尼亞 | 宿敵／競爭者，同為天氣與火之神，以神戰對決 |
| Teisheba（泰斯帕斯） | 烏拉爾圖 | 同屬高加索天氣／雷電傳統，氣質相近 |
| Ahura Mazda（阿胡拉·馬茲達） | 波斯 | 同為天界之主，亞美尼亞以之對譯「天上至尊」 |

## 相關神祇

- **Aramazd**（吞併其功能的最高神）：天空之父、造物主
- **Vahagn**（宿敵）：本土雷火英雄，「偷稻草者」銀河神話的另一主角
- **Aram**（擊殺巨人巴爾沙敏者）：亞美尼亞先祖英雄
- **Mihr / Nane / Anahit**（同殿諸神）：與巴爾沙敏同屬混成萬神殿
