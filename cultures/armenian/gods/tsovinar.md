# 佐維納爾 (Tsovinar / Nar /  ծովինար)

- **文化：** 亞美尼亞神話 (Armenian Mythology)
- **職掌：** 水與火之神、湖泊與海洋女神、雷暴與閃電

## 概述

佐維納爾（Tsovinar，亞美尼亞語「海之女」之意，tsov = 海）是亞美尼亞神話中的水與火複合女神，同時掌管海洋、湖泊、降雨、雷電與火焰。她的名字反映了她的雙重本質——她是「水中的火焰」，一個看似矛盾卻在神話邏輯中完全自洽的存在。佐維納爾在亞美尼亞口傳傳統中以兩種面貌出現：一是美麗的湖中女子，長髮如波浪；二是憤怒的雷暴女神，駕馭閃電劃破烏雲。

她是火神與戰神瓦哈格恩（Vahagn）的母親。根據亞美尼亞著名史家莫夫謝斯·霍列納齊（Movses Khorenatsi，5世紀）的《亞美尼亞史》，瓦哈格恩誕生於「蒼穹與大地在苦痛中呻吟、紫海也同感陣痛」之時，瓦哈格恩從蘆葦中冒出火焰和煙霧——這個生產場景的「陣痛者」正是佐維納爾，她作為海洋的化身承受了分娩的劇痛。

佐維納爾的傳說與凡湖（Lake Van）密切相關——凡湖是亞美尼亞高原上最大的湖泊，也是亞美尼亞神話的核心地理象徵。民間傳說中，佐維納爾居住在凡湖的水下宮殿中，夜間浮出水面沐浴，她的美貌使月亮也為之失色。凡湖上突如其來的暴風雨被認為是佐維納爾發怒的表現——當她在深處翻轉身體時，湖面便掀起滔天巨浪。

佐維納爾的雙重性（水＋火）在比較神話學中極為罕見。世界神話體系中的水神幾乎總是純粹的水屬性（如希臘波塞頓、中國共工），但佐維納爾的水中蘊含火焰，使她同時具有創造與毀滅的能力。她的雨水滋潤大地，孕育豐收；她的雷電則可焚燒敵人的村莊。這種水火同體的概念與波斯神話中的阿納希塔（Anahita）——既是水之女神也是戰爭之神——有明顯的平行。部分學者認為，佐維納爾在阿契美尼德時期受到了波斯阿納希塔崇拜的影響，後來又與希臘的阿芙洛黛特（Aphrodite）在亞美尼亞化時代進行了融合。

## 跨文化對應

| 文化 | 神祇 | 對應關係 |
|------|------|---------|
| 波斯 | 阿納希塔 (Anahita) | 水之女神+戰爭，佐維納爾最接近的平行 |
| 希臘 | 阿芙洛黛特 (Aphrodite) | 愛與海洋的女神，在亞美尼亞化時代與佐維納爾融合 |
| 希臘 | 雅典娜 (Athena) | 從水中／天上誕生的智慧與戰爭女神 |
| 美索不達米亞 | 提阿瑪特 (Tiamat) | 原始海洋女神，眾神之母 |
| 北歐 | 瀾 (Rán) | 海之女神，以網捕捉溺水者 |

## 相關神祇
- **Vahagn**：兒子，火與戰神，亞美尼亞三主神之一
- **Astghik**：愛與美之女神，與佐維納爾同屬亞美尼亞女神系統
- **Aramazd**：眾神之父，亞美尼亞萬神殿的至高神
