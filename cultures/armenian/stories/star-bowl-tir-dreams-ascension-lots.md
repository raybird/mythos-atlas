# 星辰之碗——提爾的夢殿與亞美尼亞昇天節占運之夜

- **文化：** 亞美尼亞神話 (Armenian Mythology)

## 故事背景

亞美尼亞的古老神殿裡，有一位不握閃電、也不自動物的神。他是提爾（Tir／Tiur），阿拉馬茲德（Aramazd）的書記，職掌文字、技藝、夢境與預言。阿加坦格霍斯（Agathangelos）記載，他在阿爾塔沙特（Artaxata）附近有一座聖所，名為埃拉扎莫因（Erazamoyn）；名稱中的 *eraz* 即「夢」，希臘文中的對應說法也指向解夢之所。求卜者在此潔身、獻祭、於內殿入睡，讓神以夢回答；貴族與平民都把難解的夢帶到這裡，由祭司解讀。希臘化時期，提爾被拿來與阿波羅、赫密士相比，但學者指出他更接近巴比倫的納布（Nabu）：同是文字與智慧之神，同被聯於水星，同被想像為在泥板上寫下人的命運。

民間傳說把這位神的筆延續到基督教的天使格羅赫（Grogh，「書寫者」）。嬰兒出生時，格羅赫翻開冊頁記下壽數；人死時，他引導靈魂接受清算。古代觀念則說，人的額頭上已有「額上之書」，肉眼可以看見紋路，卻無人能解讀。命運因此具有雙重形象：一方面它是已寫定的字，另一方面它仍等待被翻譯、被讀出。昇天節前的占運儀式，正是把不可讀的天命轉成可觀察的記號。

## 情節

### 一、春天之夜，天地安靜下來

古老的說法描述復活節後第四十天的昇天節前夜（Hambarjman tawn）：在某個不可預知的時刻，整個自然突然靜默，泉水和河流停止流動，花、灌木、山丘與石頭彼此招呼，各自說出自己的功效；咬住自己尾巴的蛇王也在這一夜學會花的語言。若有人掌握那一刻，把物品浸入水中並以自己的名義許願，物品便會化為黃金；有些版本甚至說泉水流動的是金液，只有恰逢其時的人才能取得。這些敘述不是煉金術手冊，而是對「宇宙在歲序轉換時短暫敞開」的神話描寫：平時封閉的天，在這夜容許秘密流泄到地面。

照亮這條思路的是伊朗學者詹姆斯·羅素（James R. Russell）對 *hawrot-mawrot* 花的討論。這對植物之名源自瑣羅亞斯德教的 Haurvatāt 與 Amərətāt（完整與不朽），在亞美尼亞民間成了象徵戀人的一對花。昇天節前夜，未婚女子把它們的花瓣撒入一碗水，又放入可辨識的私人物品，在露天星光下守候；天門打開，秘密隨水流下。隔日抽取物品時，旁人誦讀四行詩，預告她愛情與婚姻的運氣。羅素推測，這種被稱作 *vičakaxał*（「抽籤遊戲」）的儀式，可能與古代伊朗的擲籤傳統相關，甚至為《以斯帖記》與普珥節的擲籤留下了遙遠回聲；但他同時強調這是歷史推論，不是可直接證明的單線傳承。

### 二、七泉之水與蒙眼的命運

十九世紀蒐集亞美尼亞民間故事的 A. G. 塞克勒米安（A. G. Seklemian）留下了更完整的儀式場景。黃昏時，村中女孩秘密集合，沉默地到七處泉水取水，裝進罈罐；其間只要有人說一句話，咒語便失效。她們把罐子藏在露天之處，讓星星整夜「看守」。年輕男子設法尋找罐子，或從女孩口中套出藏處，卻總是徒勞——儀式的效力正建立在女性空間的封閉性上。

隔天清晨，女孩們把罐子鄭重取出，以花環裝飾，排隊走到村外草地。每人投入一件易於辨認的小物：戒指、錢幣、蝸牛殼。一位約四歲、身穿白衣、蒙住眼睛的小女孩代表「命運」（Fortune）站在罐旁；年長女孩唱起詩句，眾人合唱。蒙眼女孩逐件抽出物品，舉起給眾人看，歌詞即被視為物主的運勢預言。直到所有物品都被取出，儀式才結束；眾人牽手繞圈跳舞，每位女孩另編一個花十字，掛在家裡爐灶附近，保存到隔年「命運日」。

這段情節把命運呈現為一個孩子：她看不見，卻能伸手決定次序；她不頒布法律，只抽出一物。抽中戒指的女子或將婚配，抽中錢幣者或將致富，但真正的預言藏在歌詞裡。換句話說，未來不是被直接看見，而是被朗誦出來；占卜的技術不在水晶球，而在詩、物與群體的聲音。

### 三、鹹餅、水杯與聖薩爾基斯

基督教化之後，春天占運的機制並未消失，而是換上聖徒的名字。聖薩爾基斯（St. Sarkis）本是軍人殉道者，在亞美尼亞民間成為青年與戀人的守護者。節前夕，年輕人吃下特別鹹的餅（*aghablit*），此後不得喝水，帶著口渴入睡；夢中前來遞水的人，據信就是未來伴侶。葉里溫國立大學整理的民俗記載更細：杯子若是金、銀、銅或陶，預示配偶的貧富；水盛滿、半滿或僅剩少許，象徵共同生活的長短。其他地區在屋頂撒烤穀，等待聖徒馬蹄留下印記；也有人把食物放在屋頂，清晨看鳥飛往哪個方向，以判斷未來伴侶從何方而來。

從提爾的夢殿到聖薩爾基斯的鹹餅，變的是神名，不變的是方法：製造一個身體上的匱乏（想夢、想喝水），在限定時間內等待超自然者送來答案，再由社群共同解讀。教會把節期安排在四旬期與聖週的框架內，民俗卻仍保留七泉、星光、花瓣、隨身物與詩句——也就是那套「讓命運被讀出來」的古老語法。

## 跨文化對應

| 亞美尼亞 | 跨文化對應 | 共通點與關鍵差異 |
|----------|-----------|------------------|
| 提爾的埃拉扎莫因神殿以解夢聞名 | ↔ 巴比倫納布神的書吏傳統與馬爾杜克的命運泥板 | 書寫、夢解與命運登記合於一身；亞美尼亞將它帶入春天年度儀式 |
| 額上之書、格羅赫的冊頁 | ↔ 伊斯蘭「受守護的碑板」（al-Lawḥ al-Maḥfūẓ）與前定（qadar） | 天命被設想為已書寫的文字；前者可經由儀式被解讀，後者強調神意志的不可更改 |
| 蒙眼小女孩代表命運，自碗中抽物 | ↔ 羅馬幸運女神 Fortuna 的盲目與命運之輪 | 兩者都以「看不見」表達分配的不可預測；亞美尼亞讓抽取由兒童執行，增添純潔與過渡象徵 |
| 星光下守碗、抽取物主未來 | ↔ 希臘德爾菲阿波羅的神諭與阿斯克勒庇俄斯廟的睡夢求兆 | 皆在特殊地點、特殊時段等待神意；差別在於亞美尼亞由群體自行誦詩解兆，不必經正式祭司 |
| 七泉之水與私人物品置於碗中 | ↔ 斯拉夫伊萬·庫帕拉節的花環水上占卜 | 水與植物是愛情占卜的共同介質；庫帕拉環繞夏至，亞美尼亞儀式掛在復活節後的昇天節 |
| 花瓣、泉水與 *hawrot-mawrot* 的成對象徵 | ↔ 伊朗 Haurvatāt 與 Amərətāt 的「完整／不朽」配對 | 植物名稱保存伊朗神名；在亞美尼亞村民口中，兩位善靈轉為一對戀人 |
| *vičakaxał*「抽籤遊戲」與《以斯帖記》普珥節擲籤 | ↔ 希伯來聖經《以斯帖記》3:7 的「普爾」（pur，籤） | 都以抽籤把重大集體命運交給偶然；普珥節已將它納入紀念敘事，亞美尼亞版仍以婚戀為主 |
| 抽取物品後誦四行詩判斷運氣 | ↔ 波斯以哈菲茲詩集開卷取詩的 *fāl* 占卜 | 詩句不是裝飾而是神諭載體；一口語、一書面，皆讓既成文字回答當下問題 |
| 鹹餅後夢中喝水，遞水者即配偶 | ↔ 英格蘭、愛爾蘭聖艾格尼絲前夜的夢配偶習俗 | 都在特定聖徒前夕以飲食誘發預示婚姻的夢；亞美尼亞尤其重視杯的材質與水量 |
| 女孩沉默取七泉水，男子不得窺知罐子 | ↔ 中國月下老人以紅線預定婚姻 | 兩者都把婚姻描成事先被神秘力量連結；前者靠女子群體的儀式窺見，後者靠旅人遇見老人而得知 |

十組對應顯示，占卜並不等於單純「預知」。它同時是社會技術：誰能取水、誰能唱歌、誰能解夢，決定了哪些人享有接近未來的權利。亞美尼亞尤其值得注意，因為同一套實踐在不同歷史層次被反覆改寫：異教時代隸屬提爾神殿，基督教時代掛在昇天節與聖薩爾基斯名下，今日又成為家庭與社群維繫青年婚戀期待的習俗。

另一個對比是「書寫的命運」與「抽取的命運」如何並存。格羅赫的筆暗示一個已被記錄、終將清算的人生；碗中抽出的戒指或蝸牛殼，卻把未來交給混亂的偶然。這看似矛盾，其實是儀式特有的雙重保證：若命運過於確定，人無從行動；若完全隨機，人又無從信賴。亞美尼亞的做法讓天命存在於書中，卻讓答案由柳暗花明的一抽與一句詩顯現——確定的是「會有答案」，不確定的是「答案為何」。

最後必須畫出史料邊界。塞克勒米安在十九世紀記錄的是口傳習俗，羅素對 *vičakaxał* 的古代伊朗根源與普珥節關係提出的是推測，阿加坦格霍斯與後世民間信仰之間更隔著一千多年的基督教化歷史。因此，不宜把七泉儀式直接說成「提爾神廟的原始禮儀」；可以說的是：亞美尼亞傳統善於把同一個問題——人如何讀出自己的命運——交給不同的神、聖徒與物件來回答。
