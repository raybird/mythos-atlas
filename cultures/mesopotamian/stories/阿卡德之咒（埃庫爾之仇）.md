# 阿卡德之咒：埃庫爾之仇 (The Curse of Agade: The Ekur Avenged)

- **文化：** 美索不達米亞神話（蘇美語；烏爾第三王朝抄本，內容可能承自更早）
- **類型：** 城邦哀歌 × 訓誡文學（didactic literature）

## 故事背景

《阿卡德之咒》（又譯《阿卡德之詛》或《埃庫爾之仇》）是美索不達米亞文獻中一座**城市的滅亡神話**，也是唯一一篇以「神如何放棄自己的城」為核心、並明確宣告其文學目的的作品。現存最完整的抄本屬烏爾第三王朝（約前2112–前2004），但學界普遍認為其底層材料更早，甚至可能承襲了被推翻的烏第三王朝（Ur III）對**阿卡德王朝覆滅**的官方敘述。

主角是阿卡德第三位統治者**納拉姆辛（Naram-Sin，前2254–前2218，約56年）**——薩爾貢之孫。阿卡德王朝建立了人類史上第一個跨區域帝國，納拉姆辛在位時版圖達於極盛：他擊敗馬甘的首領、征服札格羅斯山區的盧盧比人，國勢延伸至地中海一帶。然而他也是史書中**第一位在生前自稱神的美索不達米亞君主**，名寫作 D Na-ra-am D Sîn——名字前加上了神格限定符，與諸神之名同格。

歷史層與神話層在此交錯。考古與地質證據顯示，阿卡德帝國的崩潰發生於前2200年前後，北方幼發拉底河上游地區因**氣候急劇乾旱**（地質學上的「4.2 千年事件」）而全面廢棄，饑荒導致大規模南遷與衝突；後來古提人（gutians）自東方山區湧入。納拉姆辛親自鎮壓的「大叛亂」亦有實據：一塊古巴比倫時代的納拉姆辛銘文（Kutscher 文本）記載基什王伊普爾基什與烏魯克王阿馬爾吉里德南北夾擊，聯盟幾乎合圍首都。而古提人的描述本身帶有傳統的輕蔑定性：「一群不知節制者，有人的本能在、犬的智慧、猴的面容」——文獻同時在記錄事件與貶抑敵人。

## 情節

### 一、恩寵的靜默撤銷

詩篇開場是一段輝耀的頌揚，隨即轉入厄運：「當恩利爾的話語令人不安／因恩利爾之故，整個阿卡德顫抖起來，恐懼襲上了烏爾馬克（Ulmac）的伊南娜。她離開了城市，返回她的家。」這段揭示了美索不達米亞政治神學的核心公理：**神實際居住在城市之中**。所多瑪被毀、耶路撒冷被毀之所以成立，是因為神會離開；反過來說，城廢墟的考古學意義不只是物質崩壞，而是**神 withdrew 其臨在**。

### 二、伊南娜的撤軍與諸神的逐一取走

接下來是一段極具畫面感的清單式退場，逐一記錄每位神從阿卡德取走了什麼：伊南娜帶走了戰鬥與勝利；尼努爾塔把王權的寶石、冠冕、徽記與王座帶回自己的 E-cumeca；**沙馬什取走了這城的口才；恩基取走了它的智慧**；安取走了那直上天際的威勢；恩基抽掉了它那根牢牢繫於阿卜蘇的聖纜。詩中形容城的生命終結「如同深水中一尾小鯉的生命」，各城目睹；它「如一頭垂首的巨象，……如一條垂死的龍，把頭拖在地上」。

### 三、七年的哀禱

納拉姆辛在夜中見幻夢，得知恩利爾不讓阿卡德王國擁有舒適而長久的居所，會使其未來全然不利。他未將夢說出，只是披上喪服、以蘆蓆覆蓋戰車、扯下典禮船的蘆篷、捨棄王家的儀仗，**持續七年**。「誰曾見一位國王把頭埋在手中七年？」然而神終不回應。

### 四、破廟：不可饒恕的一步

七年無答，國王終於動員軍隊，進軍尼普爾的恩利爾神廟**埃庫爾**（E-kur）。文本的破壞描寫不厭其詳：架梯如劫盜攀牆、揮動雙刃大斧、把鐵鍬插進根基直到「像山土一樣碎裂」、把神廟「如同巨船般拆解」，直到「神廟如一名陣亡的士兵，頸項伏地」，而所有異邦也都跟著俯首。

這一步的關鍵在於語義：**廟不是信徒的集會場所，而是神的住所。** 文本隨即指出「百姓得以看見那不識日光的寢室／阿卡德人得以望見眾神的聖寶匣」——毀壞已越界為褻瀆與掠奪。荷馬式的「英雄的憤怒」在此被轉寫為**神學的不可逆轉折**。

### 五、諸神降詛

恩利爾召集眾神。下達的不是懲罰一人，而是**集體的、超出物理的懲罰**：古提人被召來，饑荒蔓延，屍體在街上腐爛。此時蘇恩、恩基、伊南娜、尼努爾塔、烏圖、伊什庫爾、努斯庫與**尼薩芭（Nisaba）**八位大神共同作出裁決：為保全其餘蘇美土地，阿卡德必須被毀。於是降下集體詛咒，其意象密度驚人：

> 「願你的泥土歸於阿卜蘇，成為受恩基詛咒的泥土！願你的穀物歸於田溝，成為受埃濟努詛咒的穀物！願你的木材歸於森林，成為受尼爾杜瑪詛咒的木材！願宰殺牲畜者宰殺自己的妻子，願剝羊皮的以自己的孩子為剝對象！」

隨後是經濟層面的崩解：錢的購買力被顛倒（金以銀的價錢買到、銀以黃鐵礦的價錢買到、銅以鉛的價錢買到）；一隻羊只能換半西拉穀物、半西拉油或半米納羊毛；「一西拉穀物只得一西拉」；人們躺在屋頂上餓死，躺在屋裡的人連屍體都無人收殮。城市最終化為生態荒原：渡口的草長滿了，系車道上長滿哀草，野羊與蛇不再讓人通行，平原上原本長著悅心之草的地方長出「哀泣之蘆」，「曾為你流淌的甘美之水，現在流的是苦水」。

### 六、恩利爾的反應：贊美取代降詛

最反直覺的一段在最後。倖存的老婦、老者與首席哀歌者**反向而行**——他們架起七面大鼓，日夜連續七天七夜，敲打出對恩利爾的**讚美**（而非哀號）：「吾城亡矣」之類的哀聲被抑制，轉為擊鼓讚美。恩利爾因此「進入他的神聖寢室，禁食躺下」。**毀滅者的悔意被儀式性地轉化為對毀滅者的稱頌**——這正是這篇作品作為「訓誡文學」的核心機關：阿卡德滅亡的教訓，不是「我們無罪而受罰」的控訴（那是哀歌的功能），而是「**要曉得敬畏**」。

## 結構與文類定位

| 文類 | 是否為哀歌 | 是否有過錯 | 目的 |
|---|---|---|---|
| 《烏爾覆滅哀歌》 | 是 | 部分（蘇美無辜） | 哀悼、重建秩序 |
| 《阿卡德之咒》 | 否（結尾反轉為讚美） | 是（國王僭越） | 教訓：敬畏神、勿毀神廟 |
| 《埃努瑪·埃利什》 | 否 | 是（提亞瑪特為混沌） | 宇宙秩序的立法 |

《阿卡德之咒》與《埃努瑪·埃利什》共享同一套敘事模板：一位掌權者挑戰至高權威、隨後被天界盟友聯手懲罰。這說明烏爾第三王朝末期，作為《埃努瑪·埃利什》創作母題的「神話範式」已經成熟並被廣泛複用。

## 跨文化平行

| 文化 | 對應敘事 | 對應結構 |
|---|---|---|
| 以色列（亞伯拉罕傳統） | 所多瑪與蛾摩拉的毀滅（創19） | 神因罪「離開」該城、以火與硫降毀、留下鹽柱作為物證 |
| 以色列 | 巴別塔與語言變亂（創11） | 同一座城、同一組神、同一種越界（通天）→ 毀滅／分散 |
| 以色列 | 耶路撒冷被尼布甲尼撒毀滅（耶25–29、《哀歌》） | 聖城失恩、廟宇被毀，作為《阿卡德之咒》的近東後裔寫作 |
| 希臘 | 柏拉圖《蒂邁歐篇》中的阿特蘭提斯 | 神在正義失效後放棄島國，並使其在晝夜之間消失 |
| 希臘 | 赫西俄德《女史樂章》「時代」與宙斯的隱退 | 神的世代更替與「黃金時代」作為秩序的階段性失效 |
| 印度 | 《摩訶婆羅多》中迦爾毗耶族的滅絕 | 神助力的正義戰爭完成族群清算，並附有延續至後代的詛咒 |
| 波斯 | 巴比倫的驟然崩塌（居魯士前539）與《以賽亞書》13章 | 「巴比倫的傾覆」被描寫為宿命的降罰，與美索不達米亞式「神廢之城」同構 |
| 中國 | 商的崩潰與周人的「天命」敘事（《尚書》《詩經》） | 新王朝以「受命」正當化推翻舊王朝，滅亡被解釋為德行與命運的失配 |
| 日本 | 出雲國「讓國」與天孫降臨（《古事記》《日本書紀》） | 國土連同其神聖恩寵一併轉移予新主權者，恩寵具地理載體 |
| 印加 | 庫斯科在大動盪時期的地震與「Viracocha 的退隱」 | 神撤回臨在→首都崩壞→災難後於他處建立新秩序中心 |
| 希臘 | 底比斯的「残瓦」之劫（荷馬史詩） | 神罰落於城，建築殘骸被提升為永久的聖地標記 |
| 中美洲 | 特爾奇特里瓦的崩解與托爾特克的流散（《都城紀事》） | 首都因神罰而毀，神職者散播各邦，文明由中心退化為邊陲 |

最關鍵的結構性對應有三點：**(1)** 神的存在是地理性的、可被撤離的；**(2)** 懲罰的載體是城市而非個人（集體連坐）；**(3)** 毀滅同時被當作教材，而非僅是災難記錄。
