# 蒙古宇宙樹神話（聖樺樹與三界之柱）

- **文化：** 蒙古神話 (Mongolian Mythology)

## 故事背景

蒙古薩滿宇宙觀的核心是一座支撐三界的宇宙樹——在布裡亞特與阿爾泰蒙古的口傳傳統中，這棵樹被確認為一棵巨大的聖樺樹（ Mongolian: уулсын хууч / ulsiin khuu，「世界之樺」）。樺樹是蒙古草原最具標誌性的樹種——白色樹皮在冬季雪原中閃耀，春季最先發芽，秋季最後落葉，其生命節奏與遊牧民族的季節遷徙完全同步。因此，樺樹被選為宇宙的支撐結構，並非偶然的文化選擇，而是草原生態與精神信仰的有機融合。

在蒙古薩滿的宇宙模型中，世界分為三層——上界（Od / 天界）、中界（Dund / 人間）、下界（Doo / 地底）。宇宙樹貫穿三界：樹冠伸入天界的最高層，與 Tengri 的九十九重天相連；樹幹穿過人間，其根部深入地底的 Tam（地獄），與 Erlik Khan 的冥界王國相接。每一層的居民——天神、人類、亡靈——都依賴這棵樹的養分維持存在。樹若枯萎，三界將同時崩潰。

## 情節

### 創世與宇宙樹的種植

蒙古創世神話的一個版本記載：最初世界只有無邊汪洋與黑暗。Bai-Ulgan（白老翁）從原水中升起，以雙手分開天地，但天地不斷試圖重新合攏。Bai-Ulgan 從地底深處取出一粒樺樹種子，以自己的鮮血澆灌——種子迅速生長為一棵遮天蔽日的巨樺，其白色樹幹成為天地之間永恆的支撐。Bai-Ulgan 命令宇宙樹的三根主根分別伸向三個方向——一根深入地底的 Erlik 之國，一根伸向東方的 Ataa Ulaan 惡天神領域，一根伸向西方的 Khoormusta 善天神領域。樹幹本身則成為薩滿靈魂旅程的通道。

### 薩滿攀樹升天

蒙古薩滿的最重要儀式之一為「攀宇宙樹」——薩滿在恍惚狀態中以靈魂攀爬聖樺樹升入天界。此過程在儀式詩篇中被詳述：薩滿擊鼓、吟唱，節奏由慢轉快，象徵攀爬的加速。薩滿的靈魂穿過樹幹中的七個樹瘤——每一個樹瘤代表一層天界，通過一個樹瘤即進入更高一層。每層天界由不同的天神把守，薩滿必須以歌聲或祭品通過。最頂層為 Tengri 的永恒藍天——薩滿在此獲得天命與預言之能。

攀樹的過程中，薩滿會遇到三重障礙——(1) 風暴：象徵天界的考驗，薩滿必須以穩定的鼓聲抵抗風暴的侵襲；(2) 毒蛇：纏繞在樹根處的黑暗力量，代表 Erlik 的僕從 Asuri，薩滿必須以聖火驅逐；(3) 枯枝：象徵宇宙樹的衰老——若薩滿無法喚醒枯枝，三界將陷入黑暗。

### 樹的衰老與宇宙毀滅

蒙古薩滿預言宇宙樹終將枯萎——當人類違背 Törü（天道）的次數超過天界所能容忍的極限，宇宙樹將從頂端開始枯萎，九十九重天依次崩塌。地底的 Erlik 與 Asuri 將趁機入侵人間——洪水、地震、瘟疫同時爆發，人類文明毀滅。但宇宙樹並非永恆毀滅——在最後一棵樺樹苗從灰燼中重生時，新的三界將重新建立。此「宇宙樹枯萎→世界毀滅→新樹重生」的循環結構與北歐諸神黃昏（Ragnarök）後 Yggdrasil 重新發芽、印度宇宙循環（Kalpa）中世界毀滅與重生的敘事高度平行。

## 跨文化平行

- **北歐：** Yggdrasil（世界樹） — 三根樹根連接三界，鹿群啃食樹枝，樹若枯萎諸神黃昏降臨。蒙古聖樺樹與 Yggdrasil 的結構對應在跨文化世界樹研究中被廣泛討論——二者的三界結構、樹與動物的共生關係、樹的衰老作為世界毀滅的前兆均高度一致
- **西伯利亞：** 通古斯的世界樺樹/雅庫特的 Aal Luuk Mas — 北亞薩滿傳統中宇宙樹為薩滿升天的通道，與蒙古的聖樺樹共享「薩滿攀樹」的母題
- **美索不達米亞：** 生命之樹（Huluppu Tree） — 蘇美神話中伊南娜的神聖之樹，樹根通冥界、樹冠達天界，與蒙古宇宙樹的三界結構平行
- **印度：** 阿修羅樹（Ashvattha） — 吠陀文獻中「根在天上、枝在地下」的倒置宇宙樹，與蒙古宇宙樹的結構形成有趣的鏡像對應
- **中國：** 建木 — 《山海經》記載的天地通道之樹，眾神由此上下天地，與蒙古宇宙樹的「薩滿通道」功能直接對應
- **美洲原住民：** 奧吉布瓦的吉基諾達（Gitche Manidoo 的世界樹） — 北美原住民的宇宙樹概念，以松樹或楓樹為原型
