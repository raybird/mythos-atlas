# 扎亞加奇 (Zayagachi / Zayan) — 蒙古的命運神

- **文化：** 蒙古神話 (Mongolian Mythology)
- **別名：** Zayagachi（札牙阿赤）、Zayan Sagaan Tengri（白命運天神）、Zayaanda（命運之令）
- **職掌：** 命運、財富、牲畜繁衍、生命早期預定
- **象徵：** 命運之書、白色的毛皮、生命線

## 概述

扎亞加奇（Zayagachi）是蒙古薩滿信仰中掌管命運與財富的神祇，其名源自蒙古語「zaya-」（創造、指定、預定），字面意為「創造者」或「預定者」。在布里亞特蒙古傳統中，Zayan 被稱為 Zayan Sagaan Tengri（白色命運天神），與 Esege Malan Tengri 及 Huhedey Mergen Tengri 並列西方三天神的最高三位一體。Dugarov（2020）指出，這三尊天神構成了布里亞特史詩《阿拜·格薩爾》中天界秩序的核心，Zayan 在其中扮演著書寫與保管命運的關鍵角色。

Zayagachi 的信仰具有深刻的雙重性：一方面他是慷慨的賜予者——決定牲畜的繁衍、家庭的財富、狩獵的成功；另一方面他的決定不可更改——人的壽命、婚姻、子女數目都在出生時由 Zayagachi 預先書寫。蒙古諺語說：「Zayagachi 決定的，連 Tengri 也無法改變。」這使 Zayagachi 在蒙古萬神殿中佔有獨特地位——他不是最高神祇（Tengri 才是），但卻是最不可抗拒的存在。人類的行為與祈禱只能試圖「讀取」而非「改變」他的決定（Dampilova & Kuzmina 2024）。

## 神話事蹟

### 命運的預定

根據蒙古薩滿的宇宙觀，每個靈魂在從上界降臨人間之前，Zayagachi 已在天上的命運之書中記錄了這個人一生的所有重大事件：何時出生、與誰結婚、生多少子女、何時死亡。薩滿的任務不是改變命運——因為那是不可能的——而是透過占卜（通常觀察星象、動物行為或羊肩胛骨裂紋）解讀 Zayagachi 的決定。這種「命運可讀不可改」的觀念，與希臘的莫伊拉（Moirai）與北歐的諾倫三女神（Norns）形成深刻的跨文化共鳴，但 Zayagachi 並非紡織命運的女性形象，而是書寫命運的男性神祇。

### 牲畜與財富的守護

在科爾沁蒙古的薩滿頌歌中，Zayagachi 被反覆呼喚為牲畜與財產的保護者。Heissig 收集的薩滿經文中包含了專門獻給 Zayagachi 的系列歌曲——牧民在春季與秋季舉行儀式，以馬奶酒與奶油祈求 Zayagachi 賜予牛羊繁殖、駱駝健康。這些歌曲的結構呈現清晰的三段模式：先是呼喚 Zayagachi 的名字與稱號，其次是描述他的外貌與居所，最後是具體的祈求內容（Chiodo 2009）。

### 氏族守護者

每個蒙古氏族都有自己特定的 Zayan——它是該氏族最偉大薩滿死後的靈魂，升格為氏族的守護神。這些 Zayan 的遺體被置於樹上或山中的特製棺木中，被稱為 khadaulan-öbökhöd（山中的老人）。薩滿在進行重要儀式前須先向自己氏族的 Zayan 祈禱，獲得允許後才能與更高層次的神靈溝通（Czaplicka 1914）。

### 成吉思汗的命運

Zayagachi 的信仰與蒙古帝國意識形態密切交織。《蒙古秘史》記載的成吉思汗崛起歷程——被遺棄、被奴役、被追殺——在傳統解釋中被視為 Zayagachi 早已預定的命運軌跡。成吉思汗的敵人不是在與他作戰，而是在「與世界的形狀對抗」——因為 Zayagachi 已將帝國書寫入他的命運。這一觀念賦予了蒙古征服強烈的預定論色彩：每一場戰役的結果在開戰前就已決定。

## 跨文化對應

| 文化 | 對應存在 | 共通點 |
|------|---------|--------|
| **希臘** | 莫伊拉（Moirai, Klotho/Lachesis/Atropos） | 命運紡織者，不可抗拒的生命定數 |
| **北歐** | 諾倫三女神（Urðr/Verðandi/Skuld） | 紡織命運之線，書寫每個人的終局 |
| **印度** | Vidhata / Brihaspati（命運賦予者） | 決定一生的幸與不幸 |
| **羅馬** | Parcae（Decima/Nona/Morta） | 出生時決定壽命長短 |
| **日耳曼** | Holda / Perchta（命運考察者） | 決定新生兒的未來富貴貧賤 |
| **斯拉夫** | Rodzanicy（命運三女神） | 新生兒出生夜拜訪，決定命運 |
| **芬蘭** | Syntymä（出生精靈） | 出生時分配一生的運氣 |

## 相關神祇

- **Esege Malan Tengri**（父親天神）——布里亞特西方三主神之首
- **Huhedey Mergen Tengri**（智慧天神）——三主神之一，賦予智慧
- **Tengri**（永恆藍天）——命運的終極來源，Zayagachi 執行其意志
- **Ot / Otqan**（火神之母）——接受 Zayagachi 決定的力量，為人類代禱
- **Daichi Tengri**（戰神）——決定戰爭勝敗的另一個命運執行者
