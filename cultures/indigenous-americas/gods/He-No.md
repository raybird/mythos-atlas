# 海諾 (He-No) — 易洛魁雷神與天界戰士

- **文化：** 美洲原住民神話 (Indigenous American Mythologies) — 易洛魁聯盟（Haudenosaunee／五族聯盟）
- **職掌：** 雷電、暴風雨、天空、對抗邪惡巨蛇與黑暗力量、文化英雄
- **別名：** Hino、Hé-no、Thunderer、Thunder Spirit
- **象徵：** 雷聲、雲、巨斧、彩虹

## 概述

海諾（He-No，亦作 Hino／Hé-no）是易洛魁聯盟（Mohawk、Oneida、Onondaga、Cayuga、Seneca 五族）口傳神話中最具代表性的天界戰士之一，其名在莫霍克語中與「雷聲」相關，故此神常被直接譯為「雷神」或「雷電者」（Thunderer）。與北歐、希臘的雷神不同，海諾並非至高創造者——易洛魁創世敘事中，至高之神被稱為大神（Great Spirit／Hawenniyó），而海諾是大神麾下守護人類、懲治邪惡的戰士階層之首，其職責核心在於「以雷電驅除盤踞大地的黑暗力量」。這一從屬關係在《世界樹與天界》等易洛魁敘事中反覆出現：雷電不是神權的威嚇，而是正義對邪惡的執行手段。

在易洛魁宇宙觀中，海諾率領一群「雷電者」（Thunderers）盤據雲端，專門追獵危害人類的惡靈——尤其是藏身水域、吞噬小孩的巨蛇（Great Serpent／Onyare 或 Ohiarí:ha）。他與妻子「彩虹」（Rainbow）一同守護天界與人間的通道，並在天氣劇變時現身。此一「雷電者軍團」的集體形象，正是拉科塔等平原部落「雷鳥」（Thunderbird）觀念的近親，兩者皆以雷電為武器、以驅邪護民為天職。

## 神話事蹟

**斬殺巨蛇 Onyare：** 最著名的海諾事蹟是與巨蛇 Onyare 的戰鬥。傳說巨蛇曾阻塞河道、掀起洪水並吞食往來的獵人與孩童。海諾自雲端擲下雷電之斧（或雷石），劈開山嶺，巨蛇被迫逃入深淵，洪水始得消退。此故事可視為易洛魁版本的「秩序神屠殺混沌巨蛇」——與美索不達米亞馬爾杜克斬提亞瑪特、北歐索爾釣殺耶夢加得、印度因陀羅屠弗栗多在結構上完全同型。

**彩虹之妻與天空之梯：** 另一廣為流傳的敘事中，海諾住在第四重天的雲中屋舍，以彩虹為其妻的腰帶。當人類在人間舉行豐年祭或陷入危難時，海諾會順著彩虹下降到山巔，將雷聲作為回應。部分版本描述凡人英雄沿彩虹或雲梯登天，向海諾祈求雨水與勝利——此母題與希臘眾神沿奧林帕斯下降、中國巫覡沿建木通天形成平行。

**雷霆懲罰不義：** 在易洛魁道德敘事中，海諾的雷電只打罪人與邪靈，不傷無辜。若雷擊中無辜者，傳說認為那是惡靈躲在樹中或化身為該人。此「雷電即天罰」的觀念，與中國「雷公懲惡」、北歐索爾之錘、斯拉夫佩倫之箭、以及希臘宙斯的雷霆高度一致——雷神普遍被賦予「神聖秩序的執行者」角色。

## 跨文化對應

| 文化 | 對應神祇 | 相似點 |
|------|---------|--------|
| 北歐 | 索爾 (Thor) | 雷電武器、巨蛇宿敵、守護人類 |
| 希臘 | 宙斯 (Zeus) | 雷霆天罰、天空主宰 |
| 印度 | 因陀羅 (Indra) | 屠蛇（弗栗多）、雷電金剛杵 |
| 斯拉夫 | 佩倫 (Perun) | 雷神屠蛇、秩序對立 |
| 馬雅 | 恰克 (Chaac) | 雷電與雨水、農業豐收 |
| 中國 | 雷公 | 雷電天罰、懲惡揚善 |
| 拉科塔／平原 | 雷鳥 (Thunderbird) | 雷電護民、屠蛇驅邪 |

海諾與北歐索爾最具結構相似性：兩者皆是「戰士型」雷神，皆以巨大雷電武器為標誌，皆與巨蛇/巨蟲展開永恆鬥爭，且皆在諸神體系中承擔「人類保護者」的職責。而其「從屬於大神、執行正義」的面向，則更接近斯拉夫的佩倫與中國的雷公——雷電象徵的不是混亂的力量，而是宇宙正義的裁決。

## 相關神祇

- **大神 (Great Spirit／Hawenniyó)：** 易洛魁至高神，海諾的上級
- **天空女人 (Sky Woman／Ataensic)：** 易洛魁創世女神，天界秩序的代表
- **雷鳥 (Thunderbird)：** 平原部落對雷電之靈的稱呼，與海諾互為近親
- **雙生子 (Twins)：** 易洛魁創世中的善惡雙子，善子與海諾同屬光明陣營
