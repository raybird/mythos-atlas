# 관음보살 (Gwanseeum Bosal／觀世音菩薩)

- **文化：** 韓國神話 (Korean Mythology) — 韓國大乘佛教與海東民間信仰
- **職掌：** 大慈大悲、救苦救難、觀世音聲、隨緣應化
- **核心屬性：** 무연대비（無緣大悲）／보문시현（普門示現）／32·33應身
- **相關信仰：** 韓國大乘佛教／海東觀音信仰／道教·巫俗的龍王信仰之會流

## 概述

관음보살（觀音菩薩），完整名號為觀世音菩薩（觀世自在菩薩，梵語 Avalokiteśvara），是韓國最普及的佛教神祇，也是韓國民間信仰中與本土龍王、山神系統結合最深的一位「降臨之神」。其名號含義有數層：梵語 Avalokita（觀看）＋ īśvara（自在／世之主），意即「觀照世間音聲、隨聲救度」；早期漢譯作「光世音」（唐玄奘以前古譯），玄奘之後定譯為「觀自在菩薩」，而民間與後世經論多取《法華經·觀世音菩薩普門品》的略稱「觀音」。韓國自三國時代起即以「관음／관세음（觀音／觀世音）」音譯此名；這組譯名後來原樣傳入日語（かんおん／Kannon）與越南語（Quán Âm），成為漢字文化圈觀音信仰共用的名號。

與印度本土傳統中 Avalokiteśvara 常被視為**男性**菩薩不同，觀音在韓國幾乎完全女性化。學界一般認為，7 世紀中葉以後印度女神崇拜（durgā／śakti 系統）流入佛教傳經系統，是觀音女性化的關鍵轉折；至宋代與高麗時代，觀音的女性形象在韓國已壓倒性主導（參見 서경수〈관음신앙〉《한국민족문화대백과사전》）。這種女性化不是裝飾性的，而是被系統化地編入經典與儀式：觀音被稱為「聖觀音」本身，其餘三十二／三十三應身則是「普門示現」的變化身——救度眾生的管道。

## 神話事蹟

### 一、觀音的三十三應身

韓國觀音信仰最具特色處，是「**應身的編號化**」。經典傳統將觀音本身定為「聖觀音」，其餘形貌為觀音為適應眾生需求而顯現的「普門示現」變化身：

| 層級 | 名號 | 象徵功能 |
|---|---|---|
| 本尊 | 聖觀音（성관음） | 大慈大悲本體 |
| 七觀音（六應身） | 千手觀音 | 千手普度；一手一眼，遍察世間 |
| | 十一面觀音 | 十一面備觀過去三世十方 |
| | 楊柳觀音 | 楊枝甘露，灑之濟世 |
| | 如意輪觀音 | 如意輪返照，延命回生 |
| | 馬頭觀音 | 馬頭明王（Hayagrīva），降伏魍魉之忿怒身 |
| | 準提觀音 | 准提淨灑，息災拔苦 |
| 應身代表 | 不空羂索觀音 | 不空羂索（Amoghapāśa），羂索鉤取眾生，執持不放 |
| 進階 | 白衣・葉衣・魚籃・普門觀音等 | 合稱三十二觀音／三十三觀音 |

《法華經》普門品中說「**具足神通力，廣修智方便**，十方諸國土，無剎不現身」，這句話正是韓國觀音廟遍佈海岸與山澗的經典依據。而韓國現存造像中出現頻率最高的，正是**十一面觀音、楊柳觀音與千手觀音**三種（서경수，前引）。十一面觀音的「十一面」有明文規格：《十一面觀音神呪經》記「本面之外，頭上附加十一面：正面三面，左右各三面，後面一面，頂上一面」——即以「多面」象徵同時觀照過去、現在、未來十方國土的無遺漏。慶州**石窟庵第十一面觀音菩薩像（國寶第 24 號）**是統一新羅 8 世紀的代表作，也是韓國觀音信仰最古老的物質證據。

### 二、觀音與龍王：海東觀音信仰的獨特接合

韓國觀音信仰最不同於中國與印度之處，在於觀音與**本土龍王**（용왕／龍王）的深層結構性結合。在《Encyclopedia of Korean Buddhism》的記述中，韓國寺院內的龍王閣常將觀音繪於背景，或讓觀音**騎／立於青龍或黃龍之上**漂蕩於娑婆世界（sahā）的波濤間，龍王則退居為觀音的助侍；而海岸岩礁上至今仍可見祭祀龍王的小龕。這意味著：韓國並未把觀音當作印度佛國的降臨者，而是讓她**騎在本土水神之上抵達**。

這種接合產生了三個制度性後果：

1. **海東三大海上觀音聖地**：仁川江華郡**寶文寺（보문사，635 年會正道大師於金剛山親見觀音後創建）**、江陵**洛山寺（낙산사）**、金海**寶石庵（보리암）**——三寺皆緊鄰海岸，是觀音「由海而來」的地理表徵。寶文寺的韓名「보문」在民間常被諧讀為《法華經》普門品之「**普門（보문）**」，使寺名本身就成為觀音聖地的名號。
2. **觀音的治療與送子功能**：《法華經》普門品列舉的求願中，**求子、求婦女頭目、治病、滅罪**佔極大比重。寶文寺於 1928 年在寺後山麓起造大型**磨崖觀音坐像**，以三十二應身與十一面之數象徵觀音的圓滿應化，成為韓國觀音祈願文化的地標之一。
3. **最早的大眾觀音文獻**：1712 年（肅宗 38 年）於金海仙於山甘露寺開版的**《觀世音菩薩靈驗藥草（관세음보살영험약초）》**，是韓國第一部把觀音信仰推入民間、並以靈驗故事系統普及觀音應身的白話文獻。此後尚有聖一居士（성일거사）1610 年撰《海東繪出一百八觀音之圖并讚》（해동일백팔관음의 그릴것），把 108 觀音繪譜引入韓國。

### 三、觀音與「救苦」的民間倫理

韓國觀音信仰最終落實為一種**救苦倫理**，而非抽象的形上觀想。民眾直接稱之為「관음보살님」，其護佑範圍極廣：海難（慶尚南道海東龍宮寺一系的海水觀音、海水觀音菩薩像）、產難（送子觀音）、疾病（觀音兼藥師）、戰亂（朝鮮壬辰倭亂 1592–1598 年間寺刹大量湧現觀音顯靈記錄），以及亡者救度（海岸岩間「水月觀音」形象被視為渡亡之舟）。壬辰倭亂是觀音信仰在朝鮮王朝全面世俗化的關鍵轉折點——觀音不再是經院文本的對象，而成為戰亂流民日常祈願的具體對象。

## 跨文化對應

| 文明 | 相應名號 | 核心功能 | 與韓國觀音的差異 |
|---|---|---|---|
| 印度 | Avalokiteśvara／不空羂索 | 大悲、觀世音聲 | 印度本土多為男性形像；印度教化色彩濃，與 durgā／śakti 女神崇拜共存 |
| 中國 | 觀音（Guanyin）／送子觀音 | 慈悲、送子、難遭遇 | 中國完成「觀音＝慈母」的家庭化；韓國仍保留更多龍王騎乘與海岸聖地色彩 |
| 日本 | 観音（Kannon）／観世音 | 救苦、結縁 | 日本偏重「結縁」與講經、法語的學問傳統，觀音的女性化較中國、韓國晚近 |
| 越南 | Quán Âm | 慈悲聖母 | 越南 Quán Âm 幾乎完全聖母化，並與天主教「聖母瑪利亞」在民間信仰中合流 |
| 西藏 | རྟེ་སྐུ（Sitatapatrā／多羅女神）、不空羂索觀音 | 智慧、救度、驅邪 | 藏傳以「多羅天（ Tara）」為觀音的女性化轉身，108 種形貌系統更為完整 |
| 斯里蘭卡 | Śrī Subhramaṇi（śrī sūbhramaṇī- Avalokiteśvara） | 傳統、國族庇護 | 錫蘭大乘傳統中觀音多以男性化、國王守護神面貌出現，並與山神 Saman 的國家祭祀並立 |
| 法國 | Notre Dame（聖母瑪利亞） | 慈悲之母、孩童守護 | 結構最接近韓國觀音的大眾角色，但完全無「三十二應身」的編號系統 |

韓國觀音的獨特位置可歸納為三點：**（1）唯一以本土龍王為坐騎抵達的觀音系統；（2）唯一把「應身」徹底編號化（32／33／108）並與海岸聖地綁定的觀音傳統；（3）最徹底的聖母化，卻保留了比中國更原始的水神結構。** 對照台灣的觀音信仰——同樣是海島、同樣有海岸觀音，但因漢人移民神譜相對完整，觀音在台灣較接近「觀音佛祖」而較少與龍王騎乘結合——可看出韓國觀音信仰帶有更早的**海洋國家巫俗底層**。

## 相關神祇

- **龍王（용왕）**——觀音的坐騎與助侍，構成韓國觀音信仰的水靈支柱（見本目錄 `龍王.md`）
- **地藏王菩薩（지장보살）**——同屬大乘救度體系，分工為「度亡」；韓國民間常將觀音、地藏合稱觀地藏
- **彌勒（미륵）**——同為大乘救苦願生，但彌勒面向「未來」，觀音面向「當下」（見 `彌勒.md`）
- **山神（산신）**——陸域守護的本土靈，與觀音的海域守護構成水陸對位
- **觀自在菩薩（관자재보살）**——與觀音同名的男身表述，說明其性別的多元歷史層積
