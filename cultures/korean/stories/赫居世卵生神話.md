# 赫居世卵生神話：白馬、大卵與新羅王權的太陽譜系

- **文化：** 韓國神話 (Korean Mythology)
- **體裁：** 建國神話（foundation myth）／卵生始祖傳說（egg-birth origin legend）
- **核心母題：** 無君之世、白馬神使、瓠卵剖嬰、日神譜系、井龍為后
- **主要文獻：** 《三國史記》卷一〈新羅本紀第一〉、《三國遺事》卷一〈紀異第一〉（引佚書《古記》）

## 故事背景

新羅（Silla，신라）的建國神話保存於兩部朝鮮半島史籍：金富軾於高麗仁宗二十三年（1145）編成的《三國史記》卷一〈新羅本紀第一・赫居世居西干〉，以及一然（普覺國尊）約於十三世紀末編撰的《三國遺事》卷一〈紀異第一・赫居世〉。《三國遺事》在其間引用了現已亡佚的《古記》，使彼此異文得以並存對讀。兩書共同的敘事主幹是：辰韓（진한）之地原本沒有國君，直到一匹白馬在閼川（알천）一帶跪地長嘶，留下一枚巨大的卵，卵中孵化出日後被推戴為王的男嬰。

這則神話的歷史背景可由《三國志・魏書・東夷傳》與《後漢書・東夷列傳》對辰韓、馬韓部落聯盟的記載加以參照：漢代文獻所見的東夷社會「各有渠帥」，尚未形成後世意義的中央王權。神話以「無君長」開場，並不是單純的文學鋪陳，而是把西元前一世紀辰韓十二部落由鬆散聯盟走向單一王國的過程，濃縮為「天降君主」的戲劇性事件。

傳世紀年稱赫居世（Hyeokgeose，혁거세）生於西元前六十九年，於漢宣帝五鳳元年（西元前五十七年）即位，在位六十一年，死於西元四年。「居西干」（거서간）是辰韓語中對統治者的稱號，與新羅稍後的「尼師今」「金智大路」等王號同屬在地語彙的音譯層。其姓朴（Bak／Park），而在朝鮮語中「朴」正有「瓠」（瓢瓜）之義，傳說即以此解釋卵形與姓氏的關係。

## 情節

### 一、徐羅伐無君，白馬跪嘶

相傳古時徐羅伐（서라벌，新羅都城慶州的古稱）一帶草木繁茂，居民散居山野，沒有君長，也沒有城郭與法度。就在這樣一片尚待命名的土地上，出現了一匹通體雪白的馬。牠走到閼川（一說楊山）之下，前膝跪地，仰首長嘶。等候在附近的眾人循聲趕來時，白馬已不知去向，只有一枚大卵留在原地——文獻形容其「大如瓠」，也就是像一顆掏空了的小瓜那般巨大。

白馬在此不是尋常牲畜。朝鮮半島巫俗中，白馬是迎送神靈、引渡亡魂的「神馬」（신마），也是王權與軍事威儀的象徵；高句麗建國神話中，朱蒙亦與白馬結伴逃亡。換句話說，白馬的跪嘶本身就是一道可讀的訊號：它不是「誰騎來的馬」，而是「神把什麼交給了這片土地」。

### 二、剖卵得嬰與「朴」姓的由來

接下來的細節在不同版本中略有出入。較通行的說法是眾人好奇欲剖開巨卵，卻怎麼也剖不開；正當猶豫之際，嬰兒自行破殼而出，容貌俊異，落地即能言語（此類「生而知之」的筆法，是東亞始祖神話常見的强化手段）。另一說則直接記為「剖卵得男兒」。（編按：此處並存異文，不作定論。）

嬰兒的降生同時解決了兩件事：一是統治者的來源，二是姓氏的來源。卵「大如瓠」的形貌被拿來解釋「朴」姓——「朴」即瓠、瓢，王族因而以盛裝神卵的容器為氏。這種把神話情節轉化為姓氏詞源學的寫法，與中國「簡狄吞玄鳥卵而生契，賜姓子氏」的敘事策略如出一轍：神話不只是「從前發生過的事」，更是「我們為什麼叫這個名字」的答案。

### 三、閼英井龍：天地交合的王室婚姻

赫居世即位之後，另有則與之配對的傳說。相傳王宮附近有一口「閼英井」（아영정），井中出現一名女子，後世稱她為閼英夫人（아영부인）；一說她本是井中龍女。王娶之為妃，生南解（남해），是為新羅第二代君主。在位二十一年（相傳為西元前三十七年）迎娶的說法，見於《三國遺事》系統的記載。

若把兩段傳說放在同一張結構圖上，輪廓便十分清楚：赫居世來自「天」——白馬、巨卵、光與日；閼英來自「地」——井水、龍與生育。王的卵生確立了統治的神聖授權，王妃的井生則確立了土地與水的豐產。兩人的婚姻不是私人情感故事，而是一次宇宙論層次的「天地交合」，新羅王室由此取得貫通天、地、人三界的身分。

### 四、王號的確立與太陽譜系

嬰兒長成後，眾人「推戴為王」，稱之為「赫居世居西干」。「赫」字有光明、顯赫之義，歷來學者多以其為新羅王室太陽信仰的語言化石：王是「赫赫在上」的日神後裔，其統治如日之恆常。這個理解還可以與同書所錄的檀君神話相互印證——桓因（환인）之子桓雄（환웅）降於太白山，與熊女結合而生檀君（단군），同樣是「天神降臨—地母承接—君王出世」的三段式。

新羅神話的可塑性還表現在它容許「第二個卵」。傳說脫解尼師今（탈해니사금）時，金城西門外有雞鳴，人們在那裡發現一隻金櫃，櫃中又有金卵，卵中孵出男嬰，是為金閼智（김알지），雞林（계림）由此得名，金氏始祖的譜系於確立。另方面，伽倻的金首露王（김수로）傳說則有六枚卵自龜旨（거지）峰降下，金卵最後出現，因而成為國王。同一套「卵—王權」語法，在朴氏、金氏、伽倻之間被反覆使用，構成朝鮮半島古代政治神話的共同詞彙。

## 跨文化對應

赫居世的「白馬—巨卵—剖嬰」並非孤例，它屬於分佈極廣的「神聖誕生」母題家族。下表列出可具體對讀的傳統：

| 傳統 | 主要文本 | 神聖誕生的媒介 | 與赫居世的具體對應 ↔ |
|------|---------|---------------|---------------------|
| 新羅（朴氏） | 《三國史記》《三國遺事》 | 白馬跪嘶、大卵如瓠、剖卵得嬰 | 主體：神使預告＋卵中誕生＋姓氏詞源 ↔ 各欄共通的起步點 |
| 新羅（金氏） | 《三國遺事・脫解尼師今》 | 雞鳴處金櫃中的金卵孵出金閼智 | 同一王國內的第二個卵生始祖 ↔ 卵生語法被不同氏族挪用以爭取正統 |
| 高句麗 | 《三國史記・東明王本紀》 | 柳花感日光而生大卵，孵出朱蒙；白馬伴其逃亡 | 日感、卵生、白馬三元素幾乎完全重合 ↔ 最貼近的半島內對照 |
| 伽倻 | 《三國遺事・金首露王》 | 龜旨峰降下六卵，金卵最後出而成王 | 卵的數量與先後決定王位歸屬 ↔ 同為「卵的排序即政治排序」 |
| 中國商族 | 《詩經・商頌・玄鳥》、《史記・殷本紀》 | 簡狄吞玄鳥之卵而生契 | 卵生始祖的經典中國版本 ↔ 媒介由白馬換成神鳥，邏輯不改 |
| 中國上古 | 盤古「混沌如雞子」傳說 | 天地最初如一枚雞蛋 | 宇宙卵 ↔ 新羅把宇宙卵的微縮形式用在王室起源上 |
| 滿洲（清） | 《滿洲源流考》等所載始祖傳說 | 三仙女吞朱果而生布庫里雍順 | 神物入口而受孕 ↔ 果實替代卵，仍是「物—孕—始祖」的鏈條 |
| 日本 | 《古事記》《日本書紀》 | 天照大神授命，瓊瓊杵尊自天降臨 | 日神直系的天孫降臨 ↔ 與卵生中介不同，但同樣以日神為王統源頭 |
| 印度 | 《摩訶婆羅多》 | 貢蒂與太陽神蘇利耶生迦爾納，嬰兒置筐順水漂流 | 太陽神之子＋棄嬰容器 ↔ 日神譜系與「容器—誕生」雙重對應 |
| 希臘 | 阿波羅多洛斯《書庫》 | 宙斯化天鵝與勒達結合，卵中孵出海倫與狄俄斯庫里 | 卵作為神人交合的容器 ↔ 卵的「包裹—揭示」功能完全一致 |
| 埃及 | 《金字塔文本》《亡靈書》 | 原初之卵孵化太陽神拉；荷魯斯亦以「荷魯斯之卵」為象徵 | 卵與太陽王權的結合 ↔ 新羅的「赫」與日神崇拜可與之對讀 |
| 芬蘭 | 《卡勒瓦拉》 | 伊爾瑪塔膝上的蛋孵化出世界 | 宇宙卵的極北版本 ↔ 再次顯示卵是「尚未分化的世界」的通用隱喻 |

### 結構分析一：卵作為不可偽造的出身證明

建國神話的核心難題是：如何讓「某人為什麼可以統治所有人」顯得不言可喻？赫居世故事給出的答案是讓出身本身成為奇蹟。混亂的無君狀態先被鋪陳，接著白馬以跪嘶標記地點，再留下一枚無人能剖的卵；當嬰兒自行破殼，天命便不再是宣稱，而是眾目共睹的事件。卵在此扮演的是「物證」角色——它既封閉又透明，既神祕又可觸摸。相較之下，中國玄鳥卵的故事重心在於「吞卵受孕」的身體事件，新羅版本則把重心放在卵這個「被集體圍觀的物件」上，因而更接近政治正當性的公演示範。

### 結構分析二：白馬、井龍與日神的天地配對

把白馬、卵、井龍三項母題排在一起，會發現它們各自佔據不同的宇宙論位置。白馬會移動、會發聲，代表自上而下的召喚；卵靜置於地，卻蘊含生命，是天意落入土地後的結晶；井龍則屬水、屬陰、屬內在，代表土地自身的生育力。赫居世取白馬與卵，閼英取井與龍，兩人的婚姻把「天賜的統治權」與「地生的豐饒」縫合成一個完整的王國模型。這與檀君神話中桓雄（天）與熊女（地）的結合是同一副骨架，只是新羅用卵與井替代了山與熊，顯示朝鮮半島建國神話在共享結構之下仍有鮮明的在地變體。

### 結構分析三：卵生母題的可複製性與王位競爭

最耐人尋味的是，卵生語法在新羅內部並未被獨佔。朴氏有赫居世卵，金氏有雞林金卵，伽倻有龜旨六卵，高句麗有柳花之卵。同一個情節單元被不同氏族反覆套用，正說明它是一套可以被「引用」的政治語言：誰能講出最有效的卵生故事，誰就能在王位競爭中多一分神聖性。《三國史記》與《三國遺事》之所以並存異文，與其說是史料的混亂，不如說是這些競爭性版本被一併收錄的結果。讀者今日所見的「赫居世卵生」，其實是一個已被多方重寫、卻仍保留白馬跪嘶那一幕古老特徵的層積文本。
