# 阿爾泰創世：烏爾根與埃爾利克的泥土之爭

- **文化：** 西伯利亞神話（阿爾泰突厥，騰格里信仰）

## 故事背景

這則創世神話由俄國民族學家瓦西里·拉德洛夫（Vasily Radlov）於十九世紀在阿爾泰地區記錄，是「大地潛水者」（earth-diver）創世母題在歐亞大陸最著名的突厥語版本。故事解釋了三個核心宇宙事實的來源：大地何以存在、地表為何崎嶇不平、以及善惡二神為何分居天界與地下。阿爾泰薩滿在祭儀中反覆誦唱此創世敘事，作為其宇宙觀的奠基文本（Radloff, 1866; Eliade, 1964）。

## 情節

**第一幕：混沌中的二位造物者。** 世界之初，天地未分，唯有無邊無際的原初之海。至高天父卡拉罕（Kayra）造就了拜·烏爾根（Bai-Ülgen）與埃爾利克（Erlik）二神。埃爾利克既聰明又野心勃勃，他不甘居於烏爾根之下，暗自渴望擁有屬於自己的世界。

**第二幕：潛水取泥。** 烏爾根需要泥土以造大地，遂命埃爾利克潛入海底。埃爾利克遵命下潛，取回一把淤泥，卻悄悄在口中另藏了一份——他打算用它私造一座屬於自己的世界。烏爾根將埃爾利克交出的泥土鋪於水面，泥土奇蹟般地向四方擴展，形成平坦光滑的大地。

**第三幕：口中的山脈。** 然而，埃爾利克藏在口中的泥土同樣急速膨脹，令他幾乎窒息。他被迫吐出——被吐出的泥土化作高聳的山脈與低濕的沼澤。故世間一切崎嶇、危險、荒蕪之地，皆源於埃爾利克的欺瞞與野心。

**第四幕：逐出天界。** 烏爾根看穿埃爾利克的心思，將其逐出天界，打入大地最深處的第九層——無光的地下世界（Tamag）。埃爾利克在此建起鐵質的宮殿，成為死亡與災厄之主；烏爾根則永居第十六層天，二者自此分疆而治，不再跨越彼此之域（Radloff, 1866; Wikipedia: Erlik）。

**尾聲：善惡的立約。** 另一變體記載，天神對埃爾利克宣示：「你犯了罪，圖謀反叛於我。追隨你的人將行惡，聽從我的人將純淨而仰望太陽。」（Verbitski 1903; İnan 1972）此段成為阿爾泰善惡二元宇宙觀的教義核心——人間之事，無非天界善靈與地下惡靈的拉鋸。

## 跨文化平行

| 阿爾泰創世 | 對應故事 | 文化 |
|---|---|---|
| 埃爾利克潛水藏泥造山 | 惡魔藏泥造山（earth-diver） | 北亞／北美廣泛流傳 |
| 烏爾根與埃爾利克善惡對立 | 阿胡拉·瑪茲達 vs 安格拉·曼紐 | 祆教 |
| 埃爾利克被逐出天界 | 撒旦／路西法的墮落 | 亞伯拉罕宗教 |
| 首造者叛變受罰 | 伊布利斯拒絕跪拜阿丹 | 伊斯蘭 |
| 混沌之海與潛水造地 | 提亞瑪特／原水創世 | 美索不達米亞 |
| 口中藏泥化為山丘 | 潘古（pan-ku）宇宙由肢體化生 | 中國 |
| 九層地下世界 | 塔爾塔羅斯／那落迦 | 希臘／印度 |

此故事與布里亞特的 Qormusta 對抗 Atai Ulaan、以及北美原住民的渡鴉／騙徒創世敘事共享深層結構：一個居上位的主造者與一個受託卻背叛的次級者，其失敗的野心往往正是世界不完美性的神話解釋。
