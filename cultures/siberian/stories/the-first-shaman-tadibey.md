# 第一位薩滿：Tadibey 的降世與入冥

- **文化：** 西伯利亞神話（通古斯 / 布里亞特 / 蒙古系）

## 故事背景

西伯利亞薩滿信仰的宇宙觀中，薩滿並非自願成為通神者——而是被選中、被召喚、被迫經歷死亡與重生的過程。「第一位薩滿」的神話在不同族群中有不同名稱：通古斯語稱 Tadibey 或 Daldyrga，布里亞特語稱 Böö，蒙古語稱 Bööci。但核心情節一致——宇宙最初沒有薩滿，人類無法與天界溝通、無法治療疾病、無法引導亡靈。Buga（至高神）或天神決定派遣第一位薩滿下凡，而這個過程本身就是一場穿越三界的史詩旅程。

## 情節

**第一階段：天界的決定**

在第九層天上，Buga 的孩子們發生爭執——誰也不願下凡到充滿苦難的人間。他們互相推諉：「人間有寒冷、飢餓與疾病，為何要我去？」Buga 感到憤怒——人類在中界痛苦呼號，天神卻安於天界的溫暖與光明。Bug a 宣布：「你們之中必須有一人下降到人間，成為人類與天界的橋樑。」沉默良久，最小的天子——他的名字在各版本中為 Tadibey、Böö 或 Daldyrga——站了出來。他說：「我去。」

**第二階段：下降與考驗**

Tadibey 的下降不是一次平靜的旅程——他必須穿越七層天界（通古斯版本）或九層天界（布里亞特版本）。每一層都有守護者試圖阻止他。在第一層天，他遇到巨大的老鷹擋路——老鷹說：「你放棄天界的永生，值得嗎？」Tadibey 以歌聲回答，老鷹讓路。在第三層天，他遇到狂風與暴雪——他必須在風暴中保持清醒，不被吹回天上。在第七層天（最接近人間的一層），他遇到 Erlik 的使者——兩頭黑犬攔住去路，以疾病與死亡的氣息籠罩他。

**第三階段：入冥取魂**

Tadibey 到達人間後，發現人類被疾病折磨——瘟疫蔓延、嬰兒夭折、獵人受傷無法癒合。他意識到：所有疾病的根源在 Erlik 的冥界——Erlik 扣押了人類的靈魂。Tadibey 必須下達冥界，與 Erlik 談判。

他以薩滿鼓為「靈魂之舟」，敲擊鼓面進入出神狀態。他的靈魂脫離肉體，穿越宇宙樹的樹根，到達冥界第九層——Erlik 的黑色宮殿。Erlik 坐在鐵椅上，鬍鬚燃燒著火焰，兩頭黑犬蹲踞兩側。

Erlik 說：「你來取回人類的靈魂？可以。但你必須證明你值得。」

Erlik 提出三個條件：（1）Tadibey 必須正確回答 Erlik 的謎語——任何一個錯誤都會使他的靈魂永遠困在冥界；（2）Tadibey 必須在 Erlik 的宴席上與他對飲——但 Erlik 的酒杯中盛的是死亡之水；（3）Tadibey 必須擊敗 Erlik 的 champion——一個由骨頭與黑鐵組成的巨人。

在布里亞特版本中，Tadibey 成功回答謎語（謎底是「呼吸」——因為呼吸是生與死的界線），但被酒杯中的死亡之水擊倒。他的靈魂在冥界漂流了三天三夜——最終被他自己的薩滿鼓聲喚醒。鼓面的震動穿透三界，將他從冥界的深淵中拉回。

**第四階段：回歸與傳承**

Tadibey 回到人間後，成為第一位薩滿——他教導人類如何舉行儀式、如何使用鼓與鈴、如何與靈界溝通。但他也付出了代價：他的左眼永遠變成了灰色（通古斯版本）——那是冥界在他身上留下的印記。從此，西伯利亞的薩滿被稱為「半盲者」——一隻眼看人間，另一隻眼看靈界。

## 跨文化平行

| 西伯利亞 Tadibey 降世 | 對應故事 | 文化 |
|---|---|---|
| 薩滿入冥取回靈魂 | Inanna 下冥界後復活 | 蘇美 |
| 穿越七層天界 | 奧丁穿越九界尋求智慧 | 北歐 |
| 以鼓聲為穿越工具 | 薩滿鼓作為靈魂之舟 | 環北極 |
| 死後三天復活 | 俄西里斯死後三天復活 | 埃及 |
| 左眼變色作為印記 | 洛基失去一隻眼 | 北歐 |
| 教導人類儀式 | 文化英雄教導文明 | 多種文化 |
| 天子下降人間 | 天子下凡/道成肉身 | 許多宗教傳統 |

此故事的核心結構——「天界存在下凡→經歷死亡/考驗→以某種方式重生→攜帶特殊知識回到人間」——與全世界的「救世主」（Soter）神話結構高度一致。Eliade（1964）認為，薩滿入冥的神話是人類最古老的宗教經驗敘事之一，可能早於所有書面宗教傳統。
