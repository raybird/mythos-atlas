# Ajy 善靈與 Abasy 惡靈的永恆鬥爭——雅庫特宇宙二元論

- **文化：** 西伯利亞神話——雅庫特（薩哈共和國）
- **相關神祇：** Yryn-Ajy（造物主）、Ajy（善靈群）、Abasy（惡靈群）、Nurgun-Bootur（英雄）

## 故事背景

雅庫特（Sakha）神話的核心是強烈的宇宙二元論——世界並非由單一力量創造與維持，而是始終處於善（Ajy）與惡（Abasy）兩種力量的永恆拉鋸之中。雅庫特人居住於勒拿河中游的寒帶針葉林帶——冬季長達七個月、氣溫低至攝氏零下六十度——在此極端自然環境下，生存本身就是一場與自然力量的持續抗爭。Abasy 不是抽象邪惡，而是對嚴酷物質世界的超自然投射：暴風雪、凍傷、飢荒、流行病、狩獵失敗——這些都是 Abasy 在人間活動的證據。反之，Ajy 是生命、溫暖、豐收與秩序的守護者。

雅庫特英雄史詩「奧隆霍（Olonkho）」——聯合國教科文組織非物質文化遺產——記錄了這兩種力量在人類世界中的激烈鬥爭。Ajy 與 Abasy 的鬥爭不是道德劇（moral drama）——它關乎人類的實際生存，每一天的狩獵、每一次的遷徙、每一場與自然的博鬥中都在上演。

## 情節

### 創世——雙重起源

Ajy 的創造者 Yryn-Ajy（白色造物主）居住在上界第九層天，以神聖的樺樹（Aal Luuk Mas）的樹脂與泥土塑造最初的人類——將靈魂吹入人的口鼻，使其成爲有生命的存有。但 Yryn-Ajy 並非唯一的創造者——Usun Dyostyogyor（Abasy 之主）居住在地底深處，祂的創作則是毒蛇、猛獸、瘟疫與所有傷害人類的力量。人類從誕生的第一刻起就被夾在兩種力量之間——Ajy 賜予靈魂與生命，Abasy 帶來疾病與死亡。雅庫特人相信，人類身體由 Ajy 創造，但人類的皮膚與毛髮中潛藏著 Abasy 植入的「死亡種子」——這就是爲何所有人都終將死去，無人能夠逃脫。

### 英雄 Nurgun-Bootur 的誕生

當 Abasy 的侵襲越來越頻繁——瘟疫襲擊村莊、暴雪封鎖獵場、湖中巨魚翻船吞噬漁民——天空的 Ajy 決定派遣最強大的勇士下凡拯救人類。這便是 Nurgun-Bootur（雅庫特史詩《Nurgun-Bootur Swift》的主角）。Nurgun-Bootur 並非凡人——他是 Ajy 的後裔，擁有九倍於常人的力量，能夠在暴風雪中睜眼行走、一拳擊碎巨岩、一箭貫穿九層天。

### 三界大戰

Nurgun-Bootur 的戰鬥涵蓋了雅庫特宇宙觀的三界：上界（九層天，Ajy 居所）、中界（人間，人類與動物共存）、下界（九層地，Abasy 居所）。Abasy 不只從外部攻擊人類——祂們也從內部腐蝕：引誘人類違反薩滿禁忌、將惡夢植入睡眠者的頭腦、以幻覺迷惑獵人走入冰原深處。

Nurgun-Bootur 的第一戰發生於中界的勒拿河畔——一個村莊遭到 Abasy 的瘟疫侵襲，村民的皮膚出現黑色斑點，身體日漸冰涼。Nurgun-Bootur 以樺木弓射出三支箭——第一支射向天空打開 Ajy 的通道，第二支射入大地封鎖 Abasy 的上升路徑，第三支射向村莊上方的黑暗——瘟疫之雲破碎，陽光重新照耀。但 Nurgun-Bootur 知道這只是暫時的勝利——Abasy 無法被消滅，只能被驅逐。

### 下界的終極對決

Nurgun-Bootur 在薩滿的引導下進入下界（Allaraa Doydu），尋找 Abasy 力量的源頭。下界是一片永恆的冰凍荒原——沒有陽光、沒有樹木、只有寒風與黑暗。他在第九層遇到了 Abasy 的領袖 Usun Dyostyogyor——一個擁有九頭、九臂的怪物。戰鬥持續了九天九夜——Nurgun-Bootur 砍下祂的一個頭，馬上長出兩個；斬斷祂的一臂，立刻生出三臂。最終 Nurgun-Bootur 以 Yryn-Ajy 賜予的三枝神箭釘住 Usun Dyostyogyor 的九頭——不是殺死祂（這是不可能的），而是將其封印於地心深處，讓人類獲得一個時代的安寧。

### 循環的命運

Nurgun-Bootur 返回地面後成爲雅庫特人的祖先與守護者。但他的勝利不是終局性的——在奧隆霍史詩的其他章節中，封印終將鬆動，Abasy 再次崛起，新的英雄（Ajy 的後裔）必須再次出征。這就是世界的本質——永恆的鬥爭，沒有最終的和平。

## 核心母題與跨文化平行

| 母題 | 雅庫特版本 | 跨文化對應 |

| 宇宙二元善惡鬥爭 | Ajy vs Abasy | Ahura Mazda vs Angra Mainyu（波斯） |
| 英雄被神派遣下凡 | Nurgun-Bootur | 聖喬治屠龍／因陀羅戰弗栗多 |
| 瘟疫來自惡靈 | Abasy 的疾病噴射 | Nergal（美索不達米亞）、Apollo 的瘟疫箭 |
| 英雄下冥界 | Nurgun-Bootur 入下界 | 伊南娜、奧菲斯、伊邪那岐 |
| 無法消滅的混沌力量 | Abasy 只能被封印 | 希臘 Typhon 被封印於埃特納火山下 |
| 九層宇宙結構 | 九層天與九層地 | 北歐九界、薩滿宇宙樹 |
| 循環鬥爭 | 封印鬆動→英雄再出征 | 印度 Yuga 循環、諸神黃昏後重生 |

## 文化意義

Ajy 與 Abasy 的鬥爭不僅是史詩敘事，更反映了雅庫特人對極寒環境的世界觀理解——善不是常駐的狀態，而是個人與集體每天必須主動選擇與爭取的行動。薩滿儀式中反覆舉行「驅逐 Abasy」的儀式，不是迷信，而是以象徵語言提醒所有人：生存是每一天的戰鬥，必須保持警惕。
