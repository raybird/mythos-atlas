# Kalau（楚科奇毀滅惡靈）

- **文化：** 西伯利亞神話（楚科奇 / 科里亞克 / 伊捷爾緬）
- **職掌：** 毀滅、混沌、疾病、死亡

## 概述

Kalau（亦作 Kala、Kaläu、G'eläu）是楚科奇—堪察加語系民族信仰中最強大的惡靈（evil spirit）。不同於布裏亞特—阿爾泰傳統中的 Erlik（偏向冥界主宰），Kalau 更接近「毀滅本身」——祂的存在目的即爲破壞、吞噬和終結。在楚科奇（Chukchi）與科里亞克（Koryak）創世神話中，Kalau 曾經與至高神（Kere-tkun / Quikinna-qu）共存於太初，但其本質爲混沌（Chaos）的人格化。人類所以有死亡、疾病、自然災害乃至精神錯亂，皆因 Kalau 的活動。Kalau 並不居住在特定的冥界——祂們無所不在，尤其在夜晚、暴風雪與邊界地帶最爲活躍。楚科奇薩滿（Enenyl？yn）最重要的職責即抵禦 Kalau 的侵擾，透過鼓聲與靈魂旅程將其驅逐。

## 神話事蹟

**Kalau 的起源：** 根據科里亞克神話，最初偉大的烏鴉（Raven / Quikinna-qu）創造世界時，Kalau 從原始黑暗的殘餘中自發誕生——祂不是被創造的，而是創世後留下的混沌殘渣。此觀念與埃及的阿波菲斯（Apophis，拉神創世後仍存在的混沌之蛇）及波斯的 Angra Mainyu（在 Ahura Mazda 創造光明後入侵的黑暗力量）在結構上高度對應。

**Kalau 與渡鴉的鬥爭：** 楚科奇宇宙論的核心敘事之一即渡鴉 Raven（文化英雄／造物主）與 Kalau 的永恆鬥爭。Raven 代表秩序、光明與生命；Kalau 代表混沌、黑暗與毀滅。Raven 曾多次擊敗 Kalau，卻無法將之徹底消滅——此雙元對立與 Zoroastrian 的 Spenta Mainyu/Angra Mainyu、北歐的 Aesir/Jotnar、乃至中國的陰陽概念雖非完全相同，但共享善惡力量互爲存在前提的宇宙觀。

**世界毀滅：** 楚科奇版本的世界末日前景中，Kalau 最終將吞噬世界，引發大火與洪水席捲一切——但毀滅後渡鴉將重新創造新世界。此循環毀滅與重建的主題與印度教的宇宙循環（Kalpa）、北歐的諸神黃昏（Ragnarök）以及瑪雅的五太陽紀形成跨文化對應。

**致病與治療：** 楚科奇人將許多疾病歸因於 Kalau 偷走病人的靈魂或將「惡質」注入人體。薩滿治療儀式即進入昏迷狀態（靈魂旅程），穿越下界尋找被 Kalau 藏匿的病人靈魂，透過與 Kalau 談判或鬥爭取回靈魂。若薩滿失敗，病人即死亡——Kalau 如願以償獲得一個靈魂。

## 跨文化對應

| 楚科奇 Kalau | 對應概念 | 文化 |
|---|---|---|
| 混沌殘渣 | Apophis | 埃及 |
| 毀滅惡靈 | Angra Mainyu / Ahriman | 波斯祆教 |
| 宇宙黑暗極 | Jotnar（霜巨人） | 北歐 |
| 世界毀滅者 | Loki／Surtr | 北歐 |
| 疾病之源 | Namtaru／Pazuzu | 美索不達米亞 |
| 善惡鬥爭 | Asura vs Deva | 印度 |
| 無法消滅的惡 | Satan（質疑者角色） | 亞伯拉罕宗教 |
| 致病靈 | 瘟鬼／疫鬼 | 中國民間信仰 |

Kalau 最重要的特徵在於其不可毀滅性——這與多數二元論宗教不同：Zoroastrian 預言終末時 Angra Mainyu 將被消滅，基督教預言 Satan 最後被投入火湖，但楚科奇世界觀中 Kalau 作爲宇宙的結構性元素永遠存在，世界只能週期性地被毀滅與重建。

## 相關神祇

- **Kere-tkun / Quikinna-qu：** 至高神與造物主，Kalau 的永恆對立面
- **Raven（渡鴉）：** 文化英雄，在楚科奇神話中代替至高神與 Kalau 直接鬥爭
- **Erlik：** 布裏亞特—阿爾泰的冥界之王，功能與 Kalau 部分重疊但定位不同
- **Abasy：** 雅庫特惡靈群，與 Kalau 同屬「惡靈」範疇
- **Kalau（複數：Kalaut）：** 在民間信仰中 Kalau 並非單一存在，而是泛指所有惡靈——楚科奇人相信有無數 Kalaut 散佈在世界各處
