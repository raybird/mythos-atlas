# 安·阿拉赫欽·霍屯 (Aan Alakhchyn Khotun / Аан Алахчын Хотун) — 雅庫特地母女神

- **文化：** 西伯利亞神話（雅庫特 / 薩哈傳統）
- **職掌：** 大地、土地豐產、草料與野獸繁衍、旅人庇護、家宅守護
- **別名：** Aan Darkhan Khotun（初始偉大夫人）、Aan Aalay Khotun、Aan Doydu ichchite（中世界之母神）

## 概述

安·阿拉赫欽·霍屯（Aan Alakhchyn Khotun）是雅庫特（薩哈）信仰中「地主精靈」（ichchi）體系之首。名字意譯為「廣大的樺樹林女主人」——*Aan* 指「初始／廣大」，*Alakhchyn* 與樺樹林地相關，*Khotun* 意為「夫人／女主人」。她不是高居天界、與人間遙遠的抽象創世神，而是具體大地的司掌者：居住在中世界 Orto Doydu 的聖樹 Aal Luuk Mas 根部與古樺樹林中，以白髮老太太的形象出現。蘇聯民族學家波波夫（A. A. Popov）記載，維柳伊（Viluy）地區的雅庫特人又稱她為 Aan Doydu ichchite Nelberdeen 或 N'adjay Baraan khotun——「中世界的母神」。在阿爾西斯（algys）祈禱文中，她以「泡沫般的胸脯、油膩的雙手、以脂油潤滑的膝蓋」被讚頌——這些修辭描繪她為一位勤勞的母神：擠奶、宰牲與供奉脂油留下的痕跡，象徵豐產與滋養。

## 神話事蹟

**創世中的迎接者：** 據約切爾森（Jochelson）與克謝諾豐托夫（Ksenofontov）記錄的薩哈創世傳說，白創造主尤倫·阿伊·托永（Ürüng Aiyy Toyon）從第九重天造出第一代人並送往中世界時，安·阿拉赫欽·霍屯正在世界樹根部等候——她迎接人類，並將馬與牛賜給他們。自此牲畜成為薩哈人生活的根基，而「地母賜畜」成為創世敘事中固定的一幕。

**勇士土地的守護者：** 在長篇史詩奧隆霍（olonkho）中，她是勇士（bogatyr）故土的守護女神：在勇士出征前給予睿智的建議與祝福，監護其土地不受惡靈侵擾，並在史詩敘事中作為正義一方的重要援護者。

**禁忌與報應：** 最廣為流傳的信仰是嚴禁砍伐古樺樹與老樹——樹林是她的居所與身體延伸。民俗記載她「能隨心所欲」報復冒犯者：砍伐古樹之人會喪子或失去牲畜，草原歉收亦被歸因於觸怒地母。

**祭祀方式：** 雅庫特人以「德爾比爾格」（delbirge）儀式祭祀她——用白馬鬃毛搓成長繩，懸掛犧牲的牲口，對「本鄉地主」祈願。夏季主節「伊西阿赫」（yhyakh）祭典上，白薩滿（aiyy oyuuna）亦向她祈禱，祈求牧草豐盛、畜群繁衍。

**與生育女神的同源：** 學者札哈洛娃（A. E. Zakharova）考證其形象的古老根源，指出地母原型與生育女神阿吉瑟特（Aiyysyt）同源，並保有杜鵑（繁殖徵兆）、母牛（地母與下界）、猞猁（狩獵圖騰）等獸形化身——反映這個形象從遠古動物神、樹神逐步演化為人形地母的過程，也解釋為何她同時掌管土地豐產與人間子嗣繁衍。

## 跨文化對應

| 西伯利亞 安·阿拉赫欽·霍屯 | 對應神祇 | 文化 |
|---|---|---|
| 地母／大地女神 | Gaia（大地母神） | 希臘 |
| 土地豐產與繁衍 | Ninhursag（眾母） | 蘇美 |
| 地祇／土地守護 | 后土 | 中國 |
| 地母與牲畜賜予 | Bhūmi-Pṛthivī | 印度 |
| 樺樹聖木崇拜 | Laima（樺樹／命運女神） | 波羅的海 |
| 大地母親 | Maan-emo（Maan-em） | 芬蘭 |
| 地母 | Pachamama | 安地斯 |

與希臘蓋亞（Gaia）相比，安·阿拉赫欽·霍屯的顯著差異在於「人神距離」：她不是抽象而不可侵犯的宇宙大地，而是住在鄰近樺樹林中、會被凡人冒犯、也會接受和解的「當地地主」。這體現西伯利亞萬物有靈觀——每個地域都有一位可與之日常互動的主宰精靈。與中國后土相近之處在於二者都掌管土地與農牧豐產、同屬「地祇」層級；最獨特的是她與樺樹聖木的緊密綁定，將「地母」與「樹神」兩種崇拜複合為一體，呼應北亞薩滿的宇宙樹觀。

## 相關神祇

- **Ürüng Aiyy Toyon**：白創造主，地母在創世中的接應者與配對者
- **Aiyysyt**：生育女神，與地母原型同源，同掌繁衍
- **Bayanai**：森林之主，與地母分別掌管野獸與土地
- **Erlik**：下界之王，與地母對應中世界「地」與下界「地」之別
- **Kuubai-khotun**：薩滿之母，同屬雅庫特母性神靈譜系
- **Shaman**：白薩滿為人類與地母間的中介，主持德爾比爾格與伊西阿赫祭儀

## 出現在

- 奧隆霍（olonkho）史詩（如《紐爾恭·鮑圖爾》）

- 德爾比爾格（delbirge）白馬鬃毛懸祭儀式
- 伊西阿赫（yhyakh）夏季主節祭典
- 波波夫、約切爾森、克謝諾豐托夫的民族誌記錄
