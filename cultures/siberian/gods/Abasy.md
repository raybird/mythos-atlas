# Abasy（阿巴塞惡靈群）

- **文化：** 西伯利亞神話（雅庫特 / 薩哈）
- **職掌：** 冥界惡靈、疾病與災厄之源、靈魂掠奪者、宇宙混沌力量

## 概述

Abasy（雅庫特語：Абаасы）是雅庫特（Sakha）萬神殿中最龐大的黑暗力量體系——一群居住在冥界底層的惡靈集團。他們與天界善神 Aiyy 形成嚴格的二元對立：Aiyy 掌管光明、秩序與生命，Abasy 掌管黑暗、混亂與死亡。Abasy 的數量被描述為無限——他們像蟻群一樣充斥冥界的每一個角落，不斷尋找機會侵入人間。Abasy 的統治者為 Erlik Khan（在雅庫特版本中稱 Erlik-Omio），他居住在冥界最深處的黑色堡壘中。每一位 Abasy 都有特定的職能——有的專門散播瘟疫，有的負責扭轉獵人的命運，有的在夜間潛入帳篷掠奪新生兒的靈魂。

## 神話事蹟

Abasy 最核心的神話功能為「與 Aiyy 的永恆戰爭」。雅庫特傳說中，天界與冥界之間存在一道名為 Suluus 的光之屏障——Aiyy 從上方維持屏障，Abasy 從下方侵蝕。每當人間發生重大災難（瘟疫、乾旱、連續死亡），雅庫特人便認為是 Abasy 暫時突破了 Suluus 屏障。

在雅庫特史詩《Nurgun-Bootur》中，英雄 Nurgun-Bootur 深入冥界對抗 Abasy 的首領。他穿越七層冥界，每一層由不同的 Abasy 守衛——第一層是飢餓之靈（製造飢荒），第二層是寒冷之靈（製造嚴冬），第三層是混淆之靈（使人瘋狂）。Nurgun-Bootur 以薩滿鼓擊退每一層的 Abasy，最終抵達 Erlik 的堡壘。但他並未消滅 Erlik——因為善惡必須維持平衡。Nurgun-Bootur 與 Erlik 達成協議：Abasy 不再主動侵襲人間，但人類必須定期舉行獻祭儀式以安撫惡靈。

另一則流傳於維爾霍揚斯克地區的故事描述 Abasy 的起源：最初宇宙只有善神 Aiyy——但過度的完美導致宇宙失去活力。Buga（至高神）因此從自身的暗面分裂出 Abasy，賦予他們破壞的能力，使宇宙獲得動態平衡。Abasy 的存在不是邪惡本身，而是宇宙循環中「死與再生」的必要一環。

## 跨文化對應

| 西伯利亞 Abasy | 對應神靈體系 | 文化 |
|---|---|---|
| 冥界惡靈群 | Jinn（精靈）| 伊斯蘭／前伊斯蘭阿拉伯 |
| 惡靈集團 | Asuras（阿修羅）| 吠陀印度 |
| 冥界惡靈 | demons of Duat | 埃及 |
| 冥界亡靈 | restless dead / Draugr | 北歐 |
| 惡靈群 | Angra Mainyu 的 Daeva 隨從 | 波斯瑣羅亞斯德 |
| 疾病之靈 | 瘟神 / 疫鬼 | 中國 |
| 冥界守衛 | Ereshkigal 的冥界隨從 | 蘇美 |
| 混沌力量 | Giants（霜巨人）| 北歐 |

Abasy 與吠陀印度的 Asuras 具有結構性對應——二者都是「被放逐的神靈集團」，在各自神系中扮演對立力量。值得注意的是，伊朗語系中 Asura（Ahura）是善神稱謂，而吠陀印度將 Asura 轉為惡稱——這種語義翻轉在 Abasy/Aiyy 的二元結構中亦有反映：雅庫特的 Abasy 並非絕對邪惡，而是宇宙平衡的必要一端。

## 結構特徵

Abasy 的組織結構反映雅庫特社會的恐懼投射：

| Abasy 類型 | 職能 | 人間災厄對應 |
|---|---|---|
| Chcha-Chyryata（寒靈）| 製造嚴冬與凍傷 | 嚴冬死亡、雪災 |
| Djar-Chyryata（火靈）| 製造森林火災 | 夏季野火 |
| Syy-Chyryata（血靈）| 散播出血性疾病 | 瘟疫、流行病 |
| Iia-Chyryata（夢靈）| 在夢中掠奪靈魂 | 失眠、精神疾患 |

每一種 Abasy 都對應一種雅庫特人最恐懼的自然災害——這種分類系統反映了北亞游牧民族在極端環境中的生存焦慮。

## 相關神祇

- **Erlik Khan**：Abasy 的最高統治者，冥界之王
- **Aiyy 群**：天界善靈，Abasy 的永恆對立者
- **Buga**：至高神，Abasy 的創造者（從自身暗面分裂）
- **Nurgun-Bootur**：雅庫特英雄，曾深入冥界對抗 Abasy
- **Shaman**：薩滿為唯一能穿越 Abasy 領域並全身而退的人類
