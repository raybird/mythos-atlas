# Aiyy Spirits（艾伊聖靈群）

- **文化：** 西伯利亞神話（雅庫特 / 薩哈）
- **職掌：** 天界與自然力量的神聖靈體群，掌管宇宙各領域

## 概述

Aiyy（雅庫特語：Айы）是雅庫特（Sakha）萬神殿中最核心的神靈體系——一群居住在第九層天界（Aal Luuk Mas）的聖靈。他們不同於單一至高神的模式，而是以群體方式掌管宇宙各個領域。雅庫特傳統中，Aiyy 共有五十五或七十七位，其中最重要的是十三位主要 Aiyy，每位對應一種自然力量或社會功能。Aiyy 的概念與蒙古長生天 Tengri 的九十九尊天神有結構性的對應關係——二者可能共享古老的阿爾泰—突厥共同神話基底。Aiyy 不是抽象概念——他們被描述為具體的存在，居住在金色宮殿中，騎乘白馬穿越天界，以雷霆與彩虹顯示神蹟。

## 核心神靈

**Aiyy-Toyon（艾伊主人）**：Aiyy 群體中的首領，掌管天界秩序與宇宙法則。他不直接干預人間事務，但通過次級 Aiyy 傳達意志。Aiyy-Toyon 的宮殿位於第九層天的中心，以白銀柱子支撐，屋頂鑲嵌星辰。

**Kün-Khoroï Toyon（太陽主人）**：掌管太陽與光明，雅庫特人每天清晨向太陽祈禱時呼喚其名。他駕駛金色馬車穿越天界，每夜在西方世界的邊緣休息，次日從東方重新升起。Kün-Khoroï Toyon 的功能與通古斯太陽神 Utu 以及突厥 Sol Tanrï 有直接的譜系關係。

**Aiyy-Suora（艾伊信使）**：天界與人間的中間人，負責傳遞 Aiyy-Toyon 的旨意。他常以鷹或白馬的形象出現。在雅庫特儀式中，薩滿在降神時會呼喚 Aiyy-Suora 的名字，請他打開通往天界的通道。Aiyy-Suora 與希臘 Hermes、北歐 Heimdall 在「信使/守門者」功能上形成結構性對應。

**Mün-Kharaččy（月之黑駿馬）**：掌管月亮與潮汐，也與女性生育相關。雅庫特婦女在滿月時向 Mün-Kharaččy 祈求順產，新生兒的臍帶埋於地下時也向其禱告。

## 跨文化對應

| 西伯利亞 Aiyy 群 | 對應神系 | 文化 |
|---|---|---|
| 五十五/七十七位 Aiyy | 九十九尊 Tengri | 蒙古 |
| 五十五/七十七位 Aiyy | 三百三十尊 Devas | 吠陀印度 |
| Aiyy-Toyon | Tengri / Bai-Ulgan | 蒙古 / 布里亞特 |
| Kün-Khoroï Toyon（太陽主人）| Sol Tanrï / Suruya | 突厥 / 通古斯 |
| Aiyy-Suora（信使）| Hermes / Heimdall | 希臘 / 北歐 |
| Mün-Kharaččy（月）| Sin / Nanna / Chandra | 美索不達米亞 / 印度 |

Aiyy 群的多神結構反映了西伯利亞薩滿信仰中「神靈數量等於世界複雜度」的觀念——雅庫特人相信每一種自然力量（風、雨、雷、河、山、樹）都有專門的 Aiyy 掌管。這種「萬物皆有專職神靈」的觀念在印度吠陀的 Devas 體系與蒙古的 Tengri 天神群中同樣存在。

## 與其他西伯利亞神系的關係

Aiyy 體系是雅庫特族所特有的——通古斯族（Evenki/Oroqen）使用更簡化的天神概念（Buga 為至高神，下轄少數次級神），而布里亞特族則在蒙古 Tengri 信仰影響下發展出九十九尊天神的分類。值得注意的是，Aiyy 的某些名稱與阿爾泰、哈卡斯等突厥語系民族的神名有共同詞根，暗示一個更古老的西伯利亞突厥共同萬神殿。

## 相關神祇

- **Yryn-Ajy**：雅庫特至高神靈（在某些版本中為 Aiyy-Toyon 的另一面）
- **Abasy**：冥界惡靈群，Aiyy 的對立者
- **Erlik**：阿爾泰—布里亞特冥界之王，與 Abasy 在功能上平行
- **Umai**：地母與生育女神，在雅庫特體系中地位等同於主要 Aiyy
