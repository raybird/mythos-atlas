# 老奶奶多希亞（Baba Dochia）的春季變形：達基亞季節神話

## 文化背景

Baba Dochia（老奶奶多希亞）是達基亞—羅馬尼亞神話中最重要的季節轉換人物。她的傳說既解釋了冬春交替的氣候現象，也傳達了對待母親與老人的道德教訓。Baba（老奶奶）在東南歐民間傳統中是一個跨越異教與基督教的人物——她的名字可能源自達基亞女神或羅馬曆法的三月（Martius→Dochie）。在羅馬尼亞，Baba Dochia 被稱為「三月初的惡婆婆」——她拉著羊群爬山的形象在三月初的寒冷天氣中出現，預示著春天將要來臨。

## 故事正文

### 牧羊人的婚約

傳說在很久以前，有一個善良的牧羊男孩——有些版本說他就是巴爾幹神話中最偉大的英雄之一，但更多的版本將他描述為一個普通的牧羊人。他愛上了一個勤勞溫柔的女孩，決定在春天時結婚。然而男孩的母親是一個苛刻的老婦人——Baba Dochia——她認為這個女孩配不上她的兒子。

### 不可能的考驗

Dochia 給了準媳婦一個不可能的任務：她在冬天給女孩一團黑色的羊毛，命令她到河邊將黑羊毛洗成白羊毛。女孩在冰凍的河邊哭泣——冬天不可能將黑色洗成白色。然而耶穌／聖母／或某位守護聖者（因基督教化的版本而異）可憐她，送給她一朵白色的花。她以花放入水中，黑羊毛在水中神奇地變成了白色。

### Dochia 的憤怒

Dochia 看到羊毛變白後大怒。她撕扯自己的衣服，解開她的羊皮外套——憤怒到不顧天氣的寒冷。她穿上九件（或十二件）羊皮大衣，帶著一頭羊（或山羊）爬上山，誓言要離開這個家和即將舉行的婚禮。在山上，天氣以神話式的諷刺回應她：三月的天氣突然變得溫暖如夏。Dochia 的九件大衣變得沉重不堪。她一件一件地脫下——而每當她脫下一件，天氣就變得更加狂野。太陽的灼熱、風暴的襲擊、隨後的冰雪——她脫到只剩最後一件時，一場巨大的風暴將她凍結在山上。

### 化為石頭的形成

Dochia 與她的羊一起變成了石頭。在羅馬尼亞的某些山區（尤其是 Bucegi 山脈），你可以看到被稱為「Baba Dochia 與她的羊群」的巖層——幾塊巨大的石頭矗立在山脊上，形狀像一個老婦人和她的山羊。從此以後，每年的三月一日至三月九日（或三月的頭十二天），天氣反覆無常——寒冷與溫暖交替——這是 Dochia 脫下大衣的每一天。這個天氣時期在羅馬尼亞被稱為「Baba Dochia 的日子」（Zilele Babei）。

## 跨文化平行

| 達基亞 | 跨文化對應 | 共通點 |
|--------|-----------|--------|
| Dochia 在冬天命令洗黑羊毛（不可能任務） | ↔ 希臘 Psyche 的任務（Aphrodite 要求分類種子） | 準媳婦必須完成不可能的任務 |
| | ↔ 中國 孟姜女送寒衣（或織布任務） | 女性勞動與自然的矛盾 |
| Dochia 的九件大衣脫下 = 天氣變化 | ↔ 北歐 Skaði 的雪鞋冬天 | 神話人物身體狀態直接控制天氣 |
| | ↔ 日本 やまんば（山姥）的脫皮 | 老婦人脫去外層＝循環與更新 |
| Dochia 變成石頭 | ↔ 希臘 Niobe 因喪子化為石頭 | 懲罰性的石化變形 |
| | ↔ 波斯或阿拉伯 Lot's wife 化為鹽柱 | 回頭/不服從導致石化 |
| 三月天氣反覆（Dochia 的日子） | ↔ 世界各地春分神話 | 季節變換的病因學解釋 |

Baba Dochia 的故事在巴爾幹地區存在多種變體——保加利亞有「Baba Marta」（三月奶奶），她也是一位脾氣暴躁的老婦人，她的笑容帶來春天，皺眉帶來寒冷。希臘對應的是「Martis」的傳說（三月老太太）。這批神話的共同核心是一個老婦人（而非美麗少女）作為春天到來的推動者——這在北半球的季節神話中相對罕見，因為大部分文化以處女或年輕女神（Persephone、Ostara）代表春季。

## 文化意義

Baba Dochia 顯示了達基亞神話的一個特點：它不將季節變化浪漫化（如 Persephone 歸來的春天綻放），而是以衝突、憤怒、不可能任務和石化懲罰來解釋天氣。這與喀爾巴阡山脈嚴酷的春季氣候直接相關——三月的溫暖與寒流反覆交替，對於農民來說是焦慮的季節（早霜會毀掉作物），而非詩意的重生。Dochia 不是被同情的角色——她是人類的缺陷（嫉妒、控制慾）投射到神話中的鏡子，她的石化既是懲罰也是她成為自然力量的途徑。
