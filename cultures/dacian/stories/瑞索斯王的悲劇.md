# 瑞索斯王的悲劇 (Rhesos / Ῥῆσος)

- **文化：** 達基亞神話 (Dacian Mythology)／色雷斯神話 (Thracian Mythology)

## 故事背景

瑞索斯（Rhesos）是色雷斯國王，其父為色雷斯地區的河流之神斯特律蒙（Strymon），其母為謬斯女神之一（多數版本指卡利俄佩或忒耳普西科瑞）。瑞索斯擁有傳說中最俊美的白色駿馬，體型高大、奔馳如風，據說一旦他的戰馬飲過特洛伊的河水或食過特洛伊平原的青草，特洛伊城將永不陷落。此神諭使瑞索斯成為特洛伊戰爭中遠征而來的最關鍵援軍。

## 情節

### 第一幕：遠征特洛伊

特洛伊戰爭第十年，特洛伊國王普里阿摩斯向所有盟邦求援。瑞索斯率領色雷斯戰士跨越赫勒斯滂（達達尼爾海峽），駕著鑲金戰車、率白馬大軍抵達特洛伊城外。特洛伊人歡欣鼓舞，認為瑞索斯的神駿將徹底扭轉戰局。荷馬《伊利亞德》中描述瑞索斯僅在特洛伊停留了一日，尚未參戰便已引起希臘聯軍的極度戒備。

### 第二幕：奧德修斯的夜襲

希臘聯軍統帥阿伽門農得知瑞索斯抵達後，派遣奧德修斯與狄奧墨德斯執行夜間偵察任務。兩位英雄在夜色掩護下潛入色雷斯營地，發現瑞索斯的軍隊因長途行軍而沉睡——連哨兵都在飲酒後不省人事。奧德修斯指引道路，狄奧墨德斯揮劍接連殺死十二名色雷斯戰士，最後來到瑞索斯王面前。在瑞索斯驚醒的瞬間，狄奧墨德斯一劍刺穿他的喉嚨，結束了這位從未真正戰鬥的國王的生命。

### 第三幕：神駿的命運

奧德修斯與狄奧墨德斯將瑞索斯著名的白馬解韁牽走，迅速返回希臘營地。天亮後特洛伊人發現色雷斯全軍覆沒、瑞索斯被殺，士氣遭受重創。希臘人將白馬獻祭給雅典娜，或在戰車競賽中使用（版本各異）。此後預言中「特洛伊永不陷落」的條件被徹底打破，特洛伊城的命運隨之注定。

### 後續傳說

後期傳說（特別是「瑞索斯」悲劇，傳統上歸於歐里庇得斯）補充了更神話性的結局：瑞索斯的母親——謬斯女神——得知兒子慘死後降臨戰場哀悼。她指責雅典娜與奧德修斯暗中操縱了這一切，並預言瑞索斯的靈魂不會進入冥界，而是將以半神的身分居住在色雷斯的洞穴中，成為地下神諭的守護者。達基亞人後世在瑞索斯傳說的地點建立祭壇，相信該英雄會顯現神諭。

## 跨文化平行

| 瑞索斯故事元素 | 跨文化平行 |
|---------------|-----------|
| 初抵戰場即被暗算的英雄 | ↔ 中國三國張飛（睡夢中被部下斬首） |
| 神諭條件式的不可戰勝城邦 | ↔ 希臘特洛伊木馬計（條件式毀滅） |
| 白馬作為勝利象徵 | ↔ 印度阿修瓦美達祭（戰馬決定疆域） |
| 夜襲敵營 | ↔ 聖經參孫夜襲迦薩；荷馬多隆情節 |
| 母親女神哀悼英雄 | ↔ 蘇美伊南娜哀悼杜姆茲；埃及伊西斯哀悼奧西里斯 |
| 英雄化身地下神諭 | ↔ 希臘特洛福尼奧斯洞穴神諭；中國巫山神女 |

瑞索斯的故事體現了「命運的致命反轉」——英雄擁有扭轉戰局的絕對力量，卻在力量被使用之前便遭暗殺而永遠失去作戰機會。這一母題與張飛在睡夢中被帳下將領暗殺的故事結構極為相似。而瑞索斯的母親謬斯降臨哀悼的部分，則與蘇美的伊南娜與杜姆茲、埃及的伊西斯與奧西里斯共享同樣的「女神為凡人英雄之死哀慟」的深層神話結構。
