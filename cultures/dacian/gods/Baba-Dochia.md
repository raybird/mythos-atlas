# Baba Dochia（芭芭·多希亞）

- **文化：** 達基亞/羅馬尼亞神話 (Dacian/Romanian Mythology)
- **職掌：** 冬春過渡、季節輪替、命運女神、老婦原型

## 概述

Baba Dochia 是達基亞—羅馬尼亞神話中最古老的女性原型之一，代表冬末與初春之間的過渡力量。她的名字在羅馬尼亞語中意為「多希亞老嫗」，但其神話根源可追溯至達基亞時期的季節女神崇拜。Baba Dochia 被描繪為一位白髮蒼蒼的老婦，身披九層羊皮外套，手持紡錘或手杖，在冬末春初的山間遊蕩。她的核心神話是：每年二月末或三月初，當她看到黑刺李樹（sângerân）開出第一朵花時，便以為春天已至，欣喜地一層層脫去羊皮外套——但倒春寒來襲，她在寒冷中凍成石頭。

Baba Dochia 在羅馬尼亞民間傳統中具有豐富的曆法功能——從聖布魯斯日（2月1日至3月1日）的九天中，每一天對應 Baba Dochia 的一件羊皮外套。羅馬尼亞民間至今仍以「Baba Dochia 的日子」來預測春天何時到來：若她在第一天脫衣時遇到晴天，則春天來得早；若遭遇風雪，則冬天將延長。這套曆法系統在結構上與其他文化的季節過渡神話高度平行。

## 神話事蹟

**九層羊皮與季節輪替：** 傳說 Baba Dochia 是一位牧羊人的祖母，每年冬天她都會帶著羊群上山，在喀爾巴阡山的牧場中度過嚴冬。春天來臨時，她會一層層脫去羊皮外套。第一層代表對春天的第一線希望，第二層代表對寒冷的警惕，但隨著每一層的脫去，她的防備也在消減。當她脫到最後一層時，倒春寒的暴風雪猛然襲來——Baba Dochia 在風雪中凍僵，身體化為岩石，永遠留在山頂。她的石像至今在喀爾巴阡山區多處被辨認出來。

**Baba Dochia 與命運之線：** 在另一個版本中，Baba Dochia 手持紡錘紡織命運之線——她紡出的線決定了每個人的壽命長短。這使她與希臘神話中的命運三女神（Moirai）以及北歐的諾恩三女神（Norns）形成結構對應。Baba Dochia 的紡錘象徵著時間的不可逆轉與命運的不可抗拒。

**Baba Dochia 與黑刺李傳說：** 在羅馬尼亞南部的版本中，Baba Dochia 的凍僵與一株黑刺李樹有關——她看到黑刺李開花便以為春天到來，但黑刺李在羅馬尼亞民間是象徵死亡與重生的植物。春天最早開花的黑刺李同時也是最脆弱的——一場霜凍就能將其摧毀。Baba Dochia 與黑刺李的結合象徵著早春的危險與過渡期的脆弱。

## 跨文化對應

| 文化 | 對應神祇/人物 | 共通點 |
|------|--------------|--------|
| 希臘神話 | Demeter（德墨忒爾） | 季節輪替、大地豐瘠的控制者 |
| 北歐神話 | Skadi（斯卡蒂） | 山中女神、冬季與嚴寒的化身 |
| 斯拉夫神話 | Maslenitsa（馬斯列尼察） | 冬季慶典的擬人化老婦，春天前焚燒 |
| 中國神話 | 嫦娥/西王母 | 不老與衰老的季節性隱喻 |
| 日本神話 | 稻荷神的田女命 | 農業豐收與季節過渡 |
| 色雷斯神話 | Kotys（科提斯） | 大地之母、狂喜與季節循環 |
| 印度神話 | Kali（迦梨） | 老婦/毀滅與重生的女神原型 |
| 愛爾蘭神話 | Cailleach（卡利赫） | 冬季老婦神，敲擊岩石創造地貌 |

Baba Dochia 與愛爾蘭的 Cailleach（卡利赫）尤為相似——二者皆為冬季老婦神，皆與岩石地貌的形成有關，皆在春天到來時消失或死亡。這暗示了一個可能的原始印歐「冬祖母」原型。

## 相關神祇

- **Kotys（科提斯）**——大地之母，Baba Dochia 的季節力量可能源自 Kotys 崇拜的變體
- **Bendis（本迪斯）**——月神與狩獵女神，與 Baba Dochia 的月亮循環象徵有聯繫
- **Zalmoxis（札爾莫克西斯）**——造物主，Baba Dochia 的凍僵與復甦呼應 Zalmoxis 的消失與回歸
- **Heros（赫羅斯）**——騎馬英雄神，某些版本中 Heros 試圖拯救凍僵的 Baba Dochia
