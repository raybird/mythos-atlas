# Zibelthiurdos（齊貝爾蒂烏爾多斯）

- **文化：** 達基亞/羅馬尼亞神話 (Dacian/Romanian Mythology)
- **職掌：** 風暴與雷電女神、天空之母、大地豐收、王室守護、Zalmoxis 的配偶

## 概述

Zibelthiurdos（亦有學者拼作 Zibethiurdos 或 Zibelthiurdus）是達基亞神話中最具爭議也最少被記載的神祇之一。其名最早出現於 5 世紀拜占庭學者赫西基烏斯（Hesychius）的《詞彙錄》與 6 世紀哥特史家約爾達尼斯（Jordanes）的《哥特人的起源與事蹟》（Getica）——後者記載達基亞人在雷暴中呼喚「Zibelthiurdos」之名，視她為掌控風暴與雷電的女神。她與天空與雷電之神 Gebeleizis、不死之神 Zalmoxis 構成了達基亞天空三神的核心：Zalmoxis 掌冥界與輪迴，Gebeleizis 掌天空與暴風，Zibelthiurdos 則被視為孕育大地、以雷雨滋養穀物的天空之母。部分現代研究者將她解釋為 Zalmoxis 的配偶——正如希臘神話中赫拉之於宙斯、北歐神話中弗麗嘉之於奧丁。由於達基亞人沒有留下系統性的文字文獻，Zibelthiurdos 的細節主要依賴希臘—羅馬作家的零散記載、喀爾巴阡山區的考古遺存與後世民俗學的逆向推論，使她在達基亞神系中保持著神秘而崇高的地位。

## 神話事蹟

**雷雨中的天空之母：** 約爾達尼斯記載，達基亞人相信雷電是 Zibelthiurdos 的憤怒或顯現——每逢春雷乍響，村民會走出家門迎接她的洗禮，認為春雷預示豐年。這種「以雷為神」的信仰與印歐語族共通的女神模式高度一致：印度神話中因陀羅的妻子 Indrāṇī 分掌雷雨，斯拉夫神話中雷神佩倫的伴侶 Diva 司雨，而達基亞的 Zibelthiurdos 正是此一印歐「雷神配偶」原型在巴爾幹半島的具體化身。考古發現的達基亞黃金飾品上常見閃電與渦旋紋樣——學者推測這是 Zibelthiurdos 的聖符，用以祈求她驅散冰雹、護佑豐收。

**豐收與王室女神：** 除風暴之外，Zibelthiurdos 亦被賦予大地豐產與王室血統的職能。羅馬尼亞民俗研究者指出，達基亞王室可能以她為神聖血統的來源——正如希臘王室宣稱血脈源於宙斯，達基亞君主也可能宣稱自己是 Zibelthiurdos 與 Zalmoxis 的後裔。在後世羅馬尼亞民間信仰中，她的形象部分融入「Sfânta Maria」（聖母瑪利亞）與掌管春雷的聖伊利亞（Sfântul Ilie）傳說——基督教化後，原本屬於 Zibelthiurdos 的「雷雨催熟穀物」職能，被嫁接到駕著火馬車巡遊天空的聖伊利亞身上。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 希臘神話 | Hera（赫拉） | 主神配偶、天空/雷電、王室守護 |
| 北歐神話 | Frigg（弗麗嘉） | 主神配偶、預知與天空 |
| 印度神話 | Indrāṇī（因陀羅之妻） | 雷神之妻、雷雨女神 |
| 斯拉夫神話 | Diva（迪瓦） | 佩倫之妻、雷雨與生育 |
| 赫梯神話 | 太陽女神 Arinna（阿里納） | 天空女神、王權守護、戰時助力 |
| 埃及神話 | 塞赫麥特（Sekhmet） | 神之怒、以力量護佑王權 |
| 中國神話 | 電母（Dianmu） | 雷電女神、雷神之伴侶 |

## 相關神祇

- **Zalmoxis**（不死之神）——被視為 Zibelthiurdos 的配偶，冥界與輪迴之主
- **Gebeleizis**（雷電之神）——與 Zibelthiurdos 共享風暴職能，或為其兄弟
- **Kotys**（大地之母）——與 Zibelthiurdos 同屬巴爾幹大女神傳統
- **Bendis**（月神/狩獵女神）——與 Zibelthiurdos 同為達基亞女性神祇
