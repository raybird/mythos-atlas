# Liber Pater（利貝爾·帕特）

- **文化：** 達基亞/羅馬尼亞神話 (Dacian/Romanian Mythology)
- **職掌：** 酒神、植物與豐產之神、地下礦藏守護者、祕儀之主

## 概述

Liber Pater 是羅馬統治達基亞期間最受崇拜的神祇之一。他本為古義大利的豐產與解放之神 Liber（與女神 Libera 成對出現），羅馬人將其與希臘狄奧尼索斯（Dionysus/Bacchus）完全合一。在達基亞，Liber Pater 絕非單純的「外來」羅馬神——學者認為他背後隱藏著達契亞—色雷斯既有的酒神與植物神傳統。羅馬尼亞學者 Valeriu D. Călărăşanu 更主張：達基亞社會以狄奧尼索斯崇拜為主導，近乎「準國教」，多任達契亞國王之名 Kotys/Cotiso 本身就是酒神祭司—君王的聖號。因此 Liber Pater 是「interpretatio romana」（羅馬式對應翻譯）雙向融合的典型案例——羅馬名字包裹之下，是根植於多瑙河下游的古老神聖傳統。

考古證據同樣豐富：1989 年於 Apulum（阿普盧姆，今阿爾巴尤利亞）發掘出 Liber Pater–狄奧尼索斯聖所，出土弗里吉亞／以弗所大理石雕刻的十一件狄奧尼索斯神像（哈德良時期，117–138 年）；Ulpia Traiana Sarmizegetusa 建有官方 Liber Pater 神廟，與 Silvanus、Diana 合組「達基亞三神」（此組合同時出現在圖拉真凱旋門浮雕上）；Porolissum 軍區亦發現疑似神廟；羅西亞蒙塔納（Alburnus Maior）金銀礦區的 Hăbad 聖地出土二十七座祭壇，其中多座獻予 Liber Pater。

## 神話事蹟

**葡萄酒的古老根基：** 達基亞的葡萄種植早於羅馬征服。蘇奇達瓦（Sucidava）的羅馬墓誌記載死者遺贈兩尤格拉（iugera）葡萄園；阿爾伯努斯·馬約爾的蠟板則記錄葡萄酒交易與本地替代飲品。酒在達基亞並非羅馬輸入品，而是與本土農業禮儀深植一體——酒神崇拜因此能迅速與在地傳統接合。

**礦區的守護者：** 在 Alburnus Maior 金銀礦區，Liber Pater 與 Terra Mater（大地之母）、Silvanus（森林神）、Mercurius 一同被礦工供奉。學者 Dušanić 指出其在礦業脈絡中的職能是「土壤與地底層的豐產」——葡萄之神同時庇佑地下的礦脈，體現酒神特有的雙重地下性（根莖深植大地＋地底寶藏的守護）。

**與 Zalmoxis 不死教義的融合：** 希羅多德記載的 Zalmoxis 靈魂不死信仰，部分學者（如 Ioana-Iulia Olaru）主張其在狄奧尼索斯—奧菲斯祕儀的語境中曾被重新詮釋——死亡非終結，而是回歸神的國度，與酒神祕儀的「死而復生」高度同構。Apulum 聖所另發現私人狄奧尼索斯祕儀團體（希臘與東方祕儀混合）的聚會建築，證明祕儀傳統在達基亞的活躍。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 希臘神話 | Dionysus（狄奧尼索斯） | 酒神祕儀、死而復生、狂喜解放 |
| 羅馬神話 | Bacchus／原始 Liber | 與 Libera 成對、解放（libertas） |
| 埃及神話 | Osiris（歐西里斯） | 葡萄酒即神之血、死而復活、祕儀 |
| 蘇美神話 | Ninkasi（寧卡西） | 發酵飲料神化、釀造讚歌 |
| 阿茲特克神話 | Mayahuel（馬雅威爾） | 植物化為酒、女神受難轉化 |
| 色雷斯神話 | Sabazios（薩巴茲奧斯） | 色雷斯酒／豐產神，與狄奧尼索斯互相融合 |

## 相關神祇

- **Zalmoxis**（不死／冥界神）——酒神祕儀在達基亞的冥界對應面
- **Silvanus**（森林神）——「達基亞三神」之一，礦區與邊界守護
- **Diana**（月神／狩獵）——「達基亞三神」之一
- **Kotys**（大地之母／狂喜）——與酒神狂喜同源的大地女神
- **Gebeleizis**（雷神）——Deceneus 禁酒焚園改革中與酒神崇拜並存的張力面
