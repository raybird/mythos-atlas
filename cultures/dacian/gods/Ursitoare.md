# Ursitoare（烏爾西托亞蕾）

- **文化：** 達基亞/羅馬尼亞神話 (Dacian/Romanian Mythology)
- **職掌：** 命運女神、新生兒命運的紡織者、三姊妹三重奏

## 概述

Ursitoare（單數 Ursitoare，源於拉丁語 "fata" 與羅馬尼亞語 "ursire"「命定」）是羅馬尼亞民間信仰中最具代表性的命運三女神。在傳統信仰中，每個新生兒出生後第三天夜裡，三位 Ursitoare 會降臨到家中，在搖籃旁紡織、丈量並剪斷一根無形的生命之線，以此決定這個孩子一生的命運——包括壽命長短、婚姻對象、富貴貧賤與死亡方式。這三位女神被民間想像為老中青三個世代的女性形象：第一位手持紡錘，紡出生命之線；第二位以手指丈量線的長度，決定壽命與福份；第三位以剪刀裁斷，終結人的一生。羅馬尼亞家庭對這個儀式極其慎重——嬰兒出生的第三天被稱為「Ursitoare 之夜」，家中須留一盞整夜不熄的燈、在窗台放置麵包與鹽、並避免在深夜開門，以免觸怒降臨的女神。Ursitoare 的信仰根植於達基亞—羅馬時期對「fata 三姊妹」的繼承，同時又與斯拉夫、日耳曼的命運女神傳統在巴爾幹半島交織融合，形成獨具喀爾巴阡山脈特色的命運觀。

## 神話事蹟

**降臨之夜與命運紡織：** 羅馬尼亞民俗學者記載了大量關於 Ursitoare 降臨的傳說。民間相信，三位女神會從「世界的另一端」乘著看不見的光線而來，坐在搖籃左側的矮凳上輪流紡織。第一根線的長短決定孩子的壽命，紡得愈長命愈久；第二根線的粗細決定財富，愈粗愈富裕；第三根線的色彩決定德行與性格——紅線主熱情勇敢，白線主純潔智慧，黑線則預示苦難。若母親在這一夜偷看女神，命運會被打破重織且通常轉壞；反之若家人為女神備好食物與酒，命運之線會被紡得更長更順。故事常見的情節是：一位母親透過巫術或祈求讓 Ursitoare 醉酒，使她們「失手」紡出更長的生命線，成功延長孩子壽命——但代價往往是母親自身受到懲罰，象徵凡人不可逾越命運的界線。

**三姊妹與人類的契約：** 某些地區的傳說將 Ursitoare 描述為三位可以交涉的靈體，而非全然冷酷的裁定者。在摩爾達維亞的版本中，一位農婦在 Ursitoare 降臨之夜以「分享一壺牛奶」的善意換取了孩子的智慧而非財富；在特蘭西瓦尼亞的版本中，Ursitoare 曾賜予一位被遺棄的孤兒「百鳥之語」的天賦。這些敘事顯示，羅馬尼亞人將命運視為可以部分協商的、而非絕對命定的力量——只要人以誠意與德行回應女神，命運便可能給出轉圜的餘地。此一觀念與希臘—羅馬「Parcae 可被儀式暫時安撫」的古老邏輯一脈相承，同時又帶有達基亞民間特有的務實色彩。

## 跨文化對應

| 文化 | 對應女神 | 共通點 |
|------|----------|--------|
| 希臘神話 | 莫伊賴（Moirai，三女神） | 紡線/丈量/剪線的命運三姊妹 |
| 羅馬神話 | Parcae（帕耳開） | 羅馬版命運三女神、命名於嬰兒出生時 |
| 北歐神話 | 諾恩（Norns） | 於搖籃旁紡織命運、三姊妹 |
| 斯拉夫神話 | Roženice／Sudice | 出生時降臨裁定命運的三姊妹 |
| 日耳曼神話 | 三位女巫（Wyrd 姊妹） | 出生夜降臨、決定一生 |
| 凱爾特神話 | 三女神（Matres） | 三重女神、生育與命運 |
| 中國民間 | 註生娘娘／三官賜福 | 出生賜福、命理裁定 |

## 相關神祇

- **Muma Pădurii**（森林老嫗）——羅馬尼亞民間另一重要的老婦靈體，與 Ursitoare 同屬「三界之外的女性權威」
- **Kotys**（大地之母）——巴爾幹大女神傳統，命運女神的上位根源
- **Iele**（山林仙女）——與 Ursitoare 同為羅馬尼亞民間不可觸怒的女性靈體
