# 坎達翁 (Kandaon / Κανδαύων)

- **文化：** 達基亞神話 (Dacian Mythology)／色雷斯神話 (Thracian Mythology)
- **職掌：** 戰爭、屠戮、戰士的狂怒與死亡

## 概述

坎達翁（Kandaon）是達基亞與色雷斯地區崇拜的戰爭之神，其名可能源自色雷斯語字根 *kand-*，意為「燃燒」或「憤怒」。希臘化時期常與阿瑞斯（Ares）混同，部分古希臘文獻直接以「色雷斯的阿瑞斯」稱呼坎達翁。他的信仰中心位於達基亞的戰爭氏族之間，戰士在出征前祭獻黑公羊或戰馬以獲取坎達翁的護佑。

坎達翁的形象為持雙矛或雙刃戰斧的武士，常有戰犬或禿鷹伴隨——後者代表戰死者的靈魂升空。在部落戰爭中，祭司將坎達翁的圖騰（鐵製狼首）帶入戰場，認為神靈親自引領突襲。

## 神話事蹟

坎達翁最著名的神話記載於希臘史家希羅多德（Herodotus）的記述中。達基亞人相信坎達翁與冥界神祇 Zalmoxis 有共生關係——死於戰場的戰士直接被坎達翁引領至 Zalmoxis 的地下殿堂，獲得永生戰士的榮譽。坎達翁每年唯一一次的祭典被稱為「血宴之日」：戰士們飲用祭祀用血液混合的葡萄酒（與達基亞人的 Dionysian 傳統相關），在狂舞中進入戰鬥恍惚狀態。他們相信此時坎達翁附身於祭司身上，透過祭司之口預言戰爭的成敗。

坎達翁亦與達基亞的「不朽」信仰相關：達基亞人認為被坎達翁選中的戰士不會真正死亡，靈魂將直接回歸天地。劍首或盾牌上常刻有坎達翁的簡化符號——一個閃電與劍交叉的圖案，象徵戰爭的不可預測性。

## 跨文化對應

| 達基亞 | 跨文化對應 |
|--------|-----------|
| 坎達翁 (Kandaon) | ↔ 希臘阿瑞斯 (Ares) |
| | ↔ 羅馬馬爾斯 (Mars) |
| | ↔ 北歐提爾 (Týr) |
| | ↔ 印度戰神卡爾蒂凱耶 (Kartikeya) |
| | ↔ 凱爾特墨丘利般的戰神 (Teutates) |
| | ↔ 斯基泰的阿瑞斯崇拜形式 |

坎達翁與阿瑞斯最為接近：兩者皆代表戰場上的狂怒與屠戮，但在各自的民族中皆被視為部落守護者。不同於阿瑞斯在希臘萬神殿中地位較低，坎達翁在達基亞部落中是備受敬畏的核心神祇。北歐提爾同樣承擔戰爭與正義的雙重職能，而坎達翁更側重純粹的戰士神力。斯基泰人也有類似的阿瑞斯崇拜形式——以戰刀插入土丘作為聖壇，與坎達翁的戰前鐵祭有著深層結構的相似性。

## 相關神祇

- **Zalmoxis** — 達基亞冥界大神，坎達翁引領戰士死後歸屬
- **Gebeleizis** — 雷神與雨神，與坎達翁共同構成達基亞戰士的雙重保護
- **Sabazios** — 騎神，與坎達翁在戰場護佑中有所重疊
- **阿瑞斯 (Ares)** — 希臘對應的戰爭神
- **馬爾斯 (Mars)** — 羅馬對應的戰神
