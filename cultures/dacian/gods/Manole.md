# Manole（馬諾列）

- **文化：** 達基亞神話（Dacian Mythology）／羅馬尼亞民間傳說
- **職掌：** 建築、祭祀、創造的犧牲、工匠神

## 概述

Meșterul Manole（馬諾列大師傅）是達基亞—羅馬尼亞神話中最著名的文化英雄，也是東南歐「建築犧牲」（foundation sacrifice）母題的代表人物。他不是傳統意義上的神祇，而是人類工匠——但由於他的悲劇命運，他被提升到了神話英雄的高度。他的故事講述了最美麗的教堂以活人為地基的傳說：為了使建築永不倒塌，建築師的妻子被砌入牆中。Manole 的故事不僅是建築起源神話，更是關於創造的代價、藝術家的驕傲與神聖要求的深刻寓言。

## 神話事蹟

傳說在 14 世紀瓦拉幾亞（今羅馬尼亞）的阿爾傑什（Argeș），親王內戈·沃德（Neagoe Vodă）召集了九位頂尖的泥水匠大師，包括最傑出的 Manole，為他建造一座前所未有的修道院。九位大師每日砌牆，但次日清晨所有工程都會倒塌。親王威脅要處死他們。Manole 在夢中受到啟示——必須將工地的第一位來訪者活活砌入牆中，建築才能屹立不倒。

Manole 與其他八位大師立下誓約：誰的妻子（或姊妹）第二天最先送來午餐，誰就要犧牲她。Manole 私下祈禱妻子不要出現——但她為了送飯，比所有人更早來到工地。Manole 試圖以各種方式阻止她接近，但天命不可違。他含淚將妻子砌入牆中。奇蹟發生：牆壁不再倒塌，修道院在牆中的哭聲中順利建成。

然而故事並未結束。親王為了讓這座絕美的修道院成為獨一無二——為了避免 Manole 為他國建造同樣美麗的建築——下令殺死所有大師。Manole 從屋頂跳下（或試圖以自製的木翼飛行逃脫——此變體與希臘的伊卡洛斯直接平行），墜落處湧出一口泉水，泉水至今被稱為 Manole 之泉。

## 跨文化對應

| 達基亞 | 跨文化對應 | 共通點 |
|--------|-----------|--------|
| Manole 的妻子被砌入牆中 | ↔ 日本「人柱」（hitobashira） | 為確保建築穩固而活埋人類 |
| | ↔ 塞爾維亞 Zidanje Skadra／保加利亞三兄弟傳說 | 南斯拉夫建築犧牲傳說，結構與 Manole 幾乎相同 |
| | ↔ 中國 孟姜女哭長城 | 女性因建築工程而死的哀悼故事 |
| Manole 的木翼飛行 | ↔ 希臘 伊卡洛斯（Icarus） 的蠟翼 | 以人造翅膀逃離高塔，墜落死亡 |
| 九位大師的集體犧牲 | ↔ 中國 秦始皇坑殺工匠（陵墓秘密） | 為保守建築秘密而殺死建造者 |
| 牆中傳出的哭聲 | ↔ 日本 夜泣き石（哭泣之石）傳說 | 犧牲者的靈魂依附在建築中持續哀泣 |
| 夢中獲知犧牲的天啟 | ↔ 北歐 奧丁以自己獻祭自己（世界樹） | 神聖建築需要神諭指定的犧牲 |

Manole 在印歐比較神話學中的位置相當獨特：它是「創建犧牲」（foundation sacrifice）母題在東南歐最完整的敘事體現。與日本的人柱不同（犧牲者通常是自願或隨機選擇），Manole 的故事充滿了悲劇性諷刺——Manole 祈禱妻子不要出現，但她仍然來了，因為她的愛超越了一切算計。這使得 Manole 的犧牲不僅是一個建築儀式，更是一個關於命運與愛情不可共存的深刻故事。

## 文化意義

此神話在羅馬尼亞文化中的地位相當於伊卡洛斯在希臘文化中的地位——它既是對人類野心與創造力的頌揚，也是對其代價的警告。阿爾傑什修道院（Curtea de Argeș Monastery）至今被認為是 Manole 的作品，牆上據說仍可看到一個女人的輪廓。每年有成千上萬的訪客前來，銘記這個關於建築與犧牲的故事。
