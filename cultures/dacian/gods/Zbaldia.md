# Zbaldia（茲巴爾迪亞）

- **文化：** 達基亞/羅馬尼亞神話 (Dacian/Romanian Mythology)
- **職掌：** 戰爭與死亡之神、戰士靈魂的引渡者、戰場守護者
- **象徵：** 鐵矛、血色盾牌、戰場上的烏鴉

## 概述

Zbaldia（茲巴爾迪亞）是達基亞神話中一位較少被希臘—羅馬文獻直接記載的戰爭與死亡之神，在達基亞宗教體系中擔任 Zalmoxis 的戰爭執行者。他的名字可能源自達基亞語詞根「zbal-」（燃燒/狂怒），暗示其與戰火和戰士狂暴狀態（berserker-like fury）的關聯。在達基亞的三重宇宙觀中，Zbaldia 屬於武力層——與 Gebeleizis（雷神）和 Dacian Mars（戰神）共同構成達基亞戰士宗教的核心。不同於 Gebeleizis 的天界懲罰功能或 Dacian Mars 的戰術智慧，Zbaldia 專注於戰場上的生死邊界——他是「即將死去之人最後看到的神」，也是靈魂從戰場到 Zalmoxis 冥界之間的引渡者。

希羅多德記載蓋塔人（達基亞人的一支）相信戰死者的靈魂由 Zalmoxis 接收，但在實際的戰場語境中，靈魂的引渡由 Zbaldia 執行。斯特拉波提到達基亞戰士在出征前會向一位戰爭之神獻祭黑色公羊，血灑在戰士的武器上——這位神祇很可能就是 Zbaldia。在達基亞的軍事祭司（kristai）體系中，Zbaldia 的祭司負責在戰前解讀鳥兆（尤其是烏鴉的飛行方向），並在戰後主持亡者安魂儀式。

## 神話事蹟

**戰士狂暴的賜予：** 達基亞傳說中，Zbaldia 賜予忠誠戰士一種稱為「zbaldie」（狂怒）的超自然力量——戰士在戰場上進入一種忘我的狂暴狀態，刀劍不入，勇猛無比。這種力量類似北歐的 berserker 狂戰士狀態或希臘的 mania（迷狂）。然而 Zbaldia 的狂怒不是無差別的——只有在正義之戰（defensive war）中為保護族人而戰的勇士才會獲得此恩賜。若戰士為貪婪或侵略而戰，Zbaldia 的狂怒會反噬——戰士會發瘋自殘或在戰場上失控。達基亞人因此嚴格區分「正義之戰」與「非正義之戰」，這也解釋了為什麼 Zalmoxis 的和平教義與 Zbaldia 的戰爭功能可以並存——Zbaldia 只在防禦性質的戰爭中活躍。

**與 Gebeleizis 的合作：** 達基亞神話中有一則關於 Zbaldia 與 Gebeleizis 共同對抗混沌力量的故事。當邪惡的巨人或怪物威脅達基亞領土時，Gebeleizis 以雷電削弱敵人，Zbaldia 則引領戰士衝鋒。在某些版本中，Zbaldia 被描繪為騎在黑色戰馬上的無面戰士——他的臉被血色面具遮蓋，只有眼睛在面具後燃燒如火。這個形象在達基亞的青銅與金屬工藝品中有所反映——出土的達基亞戰士面具（如 Costesti 與 Căpâlna 要塞的考古發現）可能與 Zbaldia 的崇拜有關。

**戰場上的烏鴉：** 達基亞人將烏鴉視為 Zbaldia 的使者。戰前，祭司觀察烏鴉群的飛行方向——若烏鴉向敵方飛去，預示 Zbaldia 保佑己方；若烏鴉向己方飛回，則需重新獻祭以平息神怒。戰後，烏鴉啄食戰場上的遺體——這被視為 Zbaldia 接收靈魂的象徵。這個傳統與北歐神話中奧丁的渡鴉（Huginn 與 Muninn）以及愛爾蘭神話中 Morrigan 變為烏鴉的形象有跨文化平行。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 北歐神話 | Odin（奧丁） | 戰爭之神、烏鴉使者、戰士靈魂的引渡者 |
| 希臘神話 | Ares（阿瑞斯） | 戰場狂暴、血腥戰爭的化身 |
| 印度神話 | Rudra（魯陀羅） | 毀滅與戰爭、瘟疫與死亡、野生力量 |
| 斯拉夫神話 | Veles（維列斯） | 冥界接引、戰士靈魂引渡、與大地的關聯 |
| 埃及神話 | Anubis（阿努比斯） | 死亡引渡者、靈魂從戰場到冥界的中介 |
| 凱爾特神話 | The Morrigan（摩莉甘） | 戰爭女神、烏鴉化身、死亡預兆 |
| 日本神話 | 戰神八幡 | 武士守護、戰後安魂、軍神信仰 |

## 相關神祇

- **Zalmoxis**（至高神）——Zbaldia 的最高主人，靈魂的最終接收者
- **Gebeleizis**（雷神）——Zbaldia 的天界盟友，以雷電配合戰場作戰
- **Derzelas**（健康/冥界神）——負責戰後傷者的治癒，與 Zbaldia 的死亡功能互補
- **Heros**（騎馬英雄神）——人類英雄死後的戰場同伴
- **Dacian Mars**（戰略戰神）——與 Zbaldia 的戰場狂暴功能形成分工

## 出現在

- 達基亞軍事祭司（kristai）的戰前鳥卜儀式
- Costesti 與 Căpâlna 要塞的考古遺址（戰士面具與祭祀器物）
- 羅馬征服達基亞後的混合宗教碑銘（如 Adamclissi 紀念碑）
- 達基亞戰士的軍旗與盾牌圖騰（烏鴉與火焰紋飾）
