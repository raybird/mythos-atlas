# 普羅米修斯 (Prometheus / Προμηθεύς)

- **文化：** 希臘神話 (Greek Mythology)
- **職掌：** 泰坦神、盜火者、人類的創造者與文明導師、先見者

## 概述

普羅米修斯是泰坦神族的一員，其名取自希臘文 προμηθής（「先見」／「深謀遠慮」），與其弟厄庇墨透斯（Epimetheus，「後見」／「悔之晚矣」）恰成對比。他是伊阿珀托斯（Iapetus）與海洋女神克呂墨涅（Clymene）之子，因此與雅典娜、荷米斯並列為希臘神話中最重視人類的奧林匹亞盟友。不同於一般泰坦的冥頑不靈，普羅米修斯在泰坦之戰中選擇倒戈支持宙斯，因而泰坦族潰敗時未遭囚禁於塔爾塔羅斯。

然而，他與宙斯的同盟並未持久——他對人類的偏愛最終使他與眾神之王決裂。普羅米修斯最為人所知的兩大神話事蹟分別是「造人」與「盜火」：前者使他成為人類的創造者，後者使他成為人類文明的奠基者。後世的文學與哲學傳統中，他更被視為反抗神權、為人類犧牲的「第一位反叛者」原型，其形象橫跨埃斯庫羅斯悲劇、浪漫主義詩歌乃至現代科幻中的「普羅米修斯之火」隱喻。

## 神話事蹟

### 造人與人類的分配

赫西俄德《工作與時日》記載，普羅米修斯以黏土塑造了人類的形體，雅典娜向泥像吹入生命之氣。在神話中，人類最初對眾神一無所知，也不知道該如何向諸神獻祭。普羅米修斯在美科涅（Mekone）的祭宴上設計了著名的「分配之計」：他將祭牛的肉與內臟藏在牛皮之下，將骨頭裹在晶亮的脂肪之中，誘使宙斯選擇了脂肪包骨頭，使人類得以保有肉食——此舉確立了希臘祭祀「焚骨祭神、食肉自用」的禮制，同時也被視為對宙斯的欺騙。

### 盜火

宙斯識破計謀後勃然大怒，剝奪了人類的火。普羅米修斯遂從太陽戰車（或赫菲斯托斯的鍛造坊）盜取火種，藏於茴香莖（narthex）中帶回人間，使人類得以烹食、鍛造金屬、禦寒並在黑夜中照明。火不僅是照明與取暖的工具，在希臘神話中更是「文明的種子」——普羅米修斯也因此傳授人類技藝：天文、算術、文字、醫藥、建築與農業。為懲罰人類，宙斯命赫菲斯托斯造出第一個女人潘朵拉（Pandora），她的盒子釋放出世間一切災禍，僅餘希望留在盒底——這便是人類苦難的起源。

### 被縛的普羅米修斯

宙斯將普羅米修斯鎖於高加索山崖，每日遣鷲鷹啄食其肝臟，入夜後肝臟復原，如此循環不絕。埃斯庫羅斯悲劇《被縛的普羅米修斯》（*Prometheus Bound*）將此場景化為不朽文學：被縛的普羅米修斯拒絕向宙斯的使者荷米斯屈服，寧願承受痛苦也不洩露「誰將推翻宙斯」的秘密（此秘密最終指向海洋女神忒提斯之子）。直至赫拉克勒斯在完成十二試煉途中以箭射殺鷲鷹，普羅米修斯才獲得釋放，並以不死之身換取人馬喀戎（Chiron）的永生之位。其後他戴著鐵環（上綴高加索石）作為象徵，成為希臘火祭中不可少的神明。

## 跨文化對應

| 希臘 | 跨文化對應 | 對應關係 |
|------|-----------|---------|
| 普羅米修斯（盜火） | 波利尼西亞茂伊（Māui） | 兩者皆以巧妙手段為人類取得火種 |
| 普羅米修斯（盜火） | 美洲原住民渡鴉（Raven）／狐狸盜火 | 北美與亞洲流傳「取火者被處罰」母題 |
| 普羅米修斯（造人） | 中國女媧 | 皆以黏土造人，賦予人類生命 |
| 普羅米修斯（造人） | 蘇美恩基（Enki）／巴比倫馬爾杜克 | 美索不達米亞造人神話中的智神角色 |
| 普羅米修斯（被縛受苦） | 北歐奧丁（Odin）懸掛世界樹九夜 | 皆以自我犧牲換取智慧與文明 |
| 普羅米修斯（文明導師） | 蘇美恩基（傳授文明技藝） | 「智慧即恩賜人類」的神話母題 |

## 相關神祇

- **宙斯（Zeus）** — 對手與懲罰者，但後期和解
- **厄庇墨透斯（Epimetheus）** — 其弟，娶潘朵拉為妻
- **雅典娜（Athena）** — 造人時賦予生命之氣的同盟
- **赫菲斯托斯（Hephaestus）** — 打造潘朵拉與鎖鏈的工匠神
- **赫拉克勒斯（Heracles）** — 射殺鷲鷹、解救普羅米修斯的英雄
