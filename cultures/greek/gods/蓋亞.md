# 蓋亞 (Gaia / Γαῖα)

- **文化：** 希臘神話 (Greek Mythology)
- **職掌：** 大地女神、萬物之母、原始創世神、神諭之源
- **象徵：** 大地本身、豐饒之角、穀穗、眾母之象

## 概述

蓋亞（希臘文 Γαῖα，羅馬名 Terra）是希臘神話中最古老的原始神祇之一，其名本身就是「大地」一詞。赫西俄德《神譜》（*Theogony*, 116–118）開篇即道：混沌（Chaos）之後生出「胸懷寬廣的大地，那永遠穩固的根基，諸神的永恆居所」——蓋亞作為「萬物之母」先於一切具體神明而存在，是泰坦、巨神與奧林帕斯諸神共同的祖源。她並非後世想像中遠離人間的抽象概念，而是被希臘人直接體驗的實體大地：高山是她聳起的骨幹，洞穴是她沉入的胸懷，地震是她震怒的翻身。這種「大地＝神祇」的擬人化，是希臘宗教中最接近自然崇拜的古老層次。

蓋亞在神話系譜中扮演「原初母體」的角色：她無性生殖誕下天空神烏拉諾斯（Ouranos）、山脈（Ourea）與海神蓬托斯（Pontus），再與烏拉諾斯結合生下十二泰坦、三名獨眼巨人與三名百手巨神。她的名字在誓詞文化中佔有極重分量——古希臘人以「對蓋亞、太陽與諸神起誓」作為不可違背的誓言格式，因為大地是一切存有的根基，也是萬物最終的歸宿。

## 神話事蹟

### 王權更替的推手

蓋亞是希臘「眾神王權世代更替」神話的核心推手。當烏拉諾斯將子女囚禁於地母腹中，蓋亞感到痛苦難忍，遂打造金鐮，唆使最年幼的兒子克洛諾斯（Cronus）閹割其父，開啟了烏拉諾斯→克洛諾斯→宙斯的三代王權循環（《神譜》, 154–210）。宙斯崛起之際，蓋亞又預言克洛諾斯將被自己的兒子推翻，並在提坦之戰中指導宙斯釋放被囚禁的百手巨神與獨眼巨人以為盟友。值得注意的是，蓋亞並非單純的「母神」——她同時是神諭與預言的掌握者，誰能與她對話，誰就能洞悉命運的走向。

### 蓋亞與提豐的誕生

宙斯穩固王權後，蓋亞因泰坦後裔被打入塔爾塔羅斯而震怒，與深淵神塔爾塔羅斯（Tartarus）結合，生下了萬怪之祖提豐（Typhon）——祂是噴吐火焰、頭觸星辰的恐怖巨獸，也是宙斯最後一場嚴峻考驗的對手。蓋亞生育提豐，象徵著大地母親的「反叛面」：當她所孕育的秩序背叛她，她便會生出毀滅秩序的怪物。這一母題與蘇美神話中提亞瑪特（Tiamat）生出十一頭怪獸對抗新一代神明，結構上完全平行。

### 德爾斐神諭的原始主人

古典作家埃斯庫羅斯《復仇女神》（*Eumenides*, 1–8）記錄了德爾斐神諭的遞嬗譜系：最初的神諭之地屬於蓋亞，她傳給忒彌斯（Themis），忒彌斯再傳福柏（Phoebe），最後傳給阿波羅。這條「大地→秩序→光明」的傳承序列，反映希臘人相信神諭的根基深植於地母的胸膛——大地的裂縫中升起預言之氣，先知憑藉大地的震動與氣息宣示神意。蓋亞因此既是萬物之母，也是「第一先知」；她的神諭功能與其說是她個人的特權，不如說是大地本身「會說話」的宗教想像。

| 希臘 | 跨文化對應 | 對應關係 |
|------|-----------|---------|
| 蓋亞（原初大地母神） | 蘇美基／寧胡爾薩格（Ki／Ninhursag） | 皆為創世之初的天與地，地母生眾神 |
| 蓋亞（地母生天父） | 埃及努特與蓋布（Nut／Geb） | 天地原為一體，後被分離 |
| 蓋亞（萬物之母） | 印度普利提維（Prithvi） | 皆為與天父結合的大地母神，豐饒之源 |
| 蓋亞（地母） | 中國后土／女媧 | 后土為社稷大地之神，女媧煉石補地 |
| 蓋亞（地母生怒生子） | 美索不達米亞提亞瑪特（Tiamat） | 原初母神生出混沌怪物，被新一代神斬殺 |
| 蓋亞（地母） | 印加帕查瑪瑪（Pachamama） | 安地斯地母，掌豐收、災禍與生死 |
| 蓋亞（地母） | 毛利帕帕圖阿努庫（Papatūānuku） | 地母與天父緊抱，諸神將其分離開天闢地 |
| 蓋亞（北歐對應） | 北歐約爾德（Jörð） | 雷神索爾之母，大地的人格化 |

## 相關神祇

- **烏拉諾斯（Ouranos）** — 其夫兼其子，天空神，與蓋亞合生泰坦諸神
- **克洛諾斯（Cronus）** — 其子，受蓋亞唆使閹割父親
- **宙斯（Zeus）** — 其孫，依蓋亞之預言推翻克洛諾斯
- **忒彌斯（Themis）** — 其女，承接德爾斐神諭
- **提豐（Typhon）** — 蓋亞與塔爾塔羅斯所生之萬怪之祖
- **蓬托斯（Pontus）** — 蓋亞無性生殖所生之海神
