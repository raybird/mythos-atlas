# 黑帝斯 (Hades / Ἅιδης)

- **文化：** 希臘神話 (Greek Mythology)
- **職掌：** 冥界之王、地下財富之神

## 概述

黑帝斯是克羅諾斯與瑞亞的長子，與宙斯、波賽頓、赫拉、得墨忒耳、赫斯提亞為手足。泰坦之戰後三兄弟抽籤劃分宇宙：宙斯得天界，波賽頓得海洋，黑帝斯得冥界。他因此成為希臘眾神中唯一不住在奧林帕斯山的奧林匹亞主神，而是統治地下的幽冥國度（同名的哈得斯／Ἅιδης）。

雖然黑帝斯常被現代文化誤解為「死亡之神」或「邪惡之神」，但在古希臘宗教中他並非死神——死神是塔納托斯（Thanatos）。黑帝斯的角色是冥界的統治者與審判秩序的監督者，而非死亡本身的化身。他的別名 Polydegmon（「萬客接納者」）和 Plouton（「財富者」）暗示兩層涵義：所有死者終將歸於他，而地下埋藏的金屬礦物也歸他掌管。

黑帝斯最重要的神話是綁架姪女珀耳塞福涅（Persephone，得墨忒耳之女）為冥后。他說服珀耳塞福涅吃下六顆石榴籽，使她每年必須在冥界度過六個月——這段時間大地陷入冬日的荒蕪。此神話是典型的季節性死亡—重生循環，希臘的厄琉西斯秘儀（Eleusinian Mysteries）以這對夫妻為核心，構成古希臘最重要的宗教儀式。

黑帝斯擁有一頂隱形頭盔（κυνέη，Cyneae），源自獨眼巨人的禮物，他在泰坦之戰中曾以此頭盔潛入敵陣。他身邊常伴三頭地獄犬刻耳柏洛斯（Cerberus）以及冥府判官米諾斯、拉達曼堤斯與艾亞哥斯。與其他奧林帕斯神不同，黑帝斯極少離開冥界，希臘藝術中的描繪也較為稀少，通常以手持雙叉戟或鑰匙、頭戴基納頭盔的沉靜王者形象出現。

## 跨文化對應

| 文化 | 神祇 | 對應關係 |
|------|------|---------|
| 埃及 | 歐西里斯 (Osiris) | 冥界審判者，死者之王 |
| 美索不達米亞 | 埃蕾什基伽爾 (Ereshkigal) | 冥府女王，統治地下世界 |
| 北歐 | 赫爾 (Hel) | 冥界統治者，接納未戰死之靈魂 |
| 印度 | 閻魔 (Yama) | 死神、冥界審判者、正法守護者 |
| 中國 | 酆都大帝 | 陰間統治者 |
| 日本 | 伊邪那美 | 黃泉國主，冥界之神 |
