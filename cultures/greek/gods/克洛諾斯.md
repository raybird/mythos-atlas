# 克洛諾斯 (Kronos / Cronus)

- **文化：** 希臘神話 (Greek Mythology)
- **職掌：** 泰坦之王、時間、農業、世代更替

## 概述

克洛諾斯（希臘語 Κρόνος）為希臘神話中泰坦十二神之首，天神烏拉諾斯（Ouranos）與地母蓋亞（Gaia）之子。他是時間的化身，亦為農業之神，其羅馬對應為薩圖恩（Saturn）。在赫西俄德《神譜》的宇宙世代論中，克洛諾斯代表從原始混沌走向奧林帕斯秩序的關鍵過渡——他推翻父親的暴政，卻又因自身的暴虐而被兒子宙斯取代，構成希臘神話中「三代神王」（烏拉諾斯→克洛諾斯→宙斯）的核心敘事。

## 神話事蹟

### 推翻烏拉諾斯

烏拉諾斯以暴力統治世界，將百臂巨人（Hecatoncheires）與獨眼巨人（Cyclopes）囚禁於蓋亞的子宮（大地深處），令蓋亞痛苦不堪。蓋亞以暗色燧石打造一把鋒利的鐮刀，交給最小的兒子克洛諾斯。克洛諾斯趁父親與母親交合之際，以鐮刀閹割烏拉諾斯，將其生殖器拋入大海。從傷口溅出的血液中生出復仇女神（Erinyes）、巨人族（Gigantes）與命運三女神（Moirai）。烏拉諾斯臨終詛咒克洛諾斯：「你亦將被自己的兒子推翻。」此創傷性場景象徵天空與大地的強制分離，為宇宙秩序建立的前提。

### 吞子與黃金時代

克洛諾斯娶妹妹瑞亞（Rhea），統治天空，開啟所謂的「黃金時代」（Golden Age）——人類無需勞動，沒有悲傷與戰爭，壽命漫長如神明。然而父親的詛咒始終籠罩。每逢瑞亞生子，克洛諾斯便將嬰兒吞入腹中：赫斯提亞（Hestia）、德墨忒爾（Demeter）、赫拉（Hera）、黑帝斯（Hades）、波賽頓（Poseidon）相繼被吞。此行為反映泰坦時代的專制本質——父王恐懼被取代，以吞噬延緩必然的命運。

### 被推翻

當第六個兒子宙斯即將誕生時，瑞亞逃往克里特島的狄克特山洞，在那裡產下宙斯。她以襁褓包裹一塊石頭交給克洛諾斯吞食（此石後來被置於德爾菲，成為神諭聖石）。宙斯在寧芙與山羊的哺育下長大，成年後返回，強迫克洛諾斯吐出五位兄姊。隨後宙斯率領新一代神祇發動泰坦之戰（Titanomachy），歷經十年，最終在百臂巨人的協助下將泰坦囚禁於塔爾塔羅斯深淵。克洛諾斯的時代至此終結。

## 跨文化對應

| 希臘 克洛諾斯 | 對應神祇/概念 | 文化 |
|---|---|---|
| 泰坦王被兒子推翻 | 庫馬爾比（Kumarbi）被特舒布取代 | 赫梯/胡里安 |
| 世代更替（父→子奪權） | 安努→庫馬爾比→特舒布 | 赫梯 |
| 吞子以阻止命運 | 乌蘭納斯被閹割（阻止後代） | 希臘自身 |
| 黃金時代統治者 | 薩圖恩（Saturn）的黃金時代 | 羅馬 |
| 時間之神 | KRONOS（時間）與CRONUS（泰坦王）的混淆 | 希臘晚期 |
| 以鐮刀為武器 | 農業收割之鐮 | 印歐農業文化 |
| 被囚於深淵 |提豐被壓於埃特納山下 | 希臘 |

## 相關神祇

- **烏拉諾斯（Ouranos）：** 父親，第一代天神，被克洛諾斯閹割推翻
- **蓋亞（Gaia）：** 母親，大地之母，策劃推翻烏拉諾斯
- **瑞亞（Rhea）：** 妹妹兼妻子，宙斯之母，泰坦之后
- **宙斯（Zeus）：** 兒子，推翻克洛諾斯，建立奧林帕斯秩序
- **赫斯提亞、德墨忒爾、赫拉、黑帝斯、波賽頓：** 兒女，曾被克洛諾斯吞噬
