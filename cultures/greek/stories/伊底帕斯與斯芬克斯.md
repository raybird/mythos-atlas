# 伊底帕斯與斯芬克斯 (Oedipus and the Sphinx)

- **文化：** 希臘神話 (Greek Mythology)

## 故事背景

斯芬克斯（Sphinx，源自 σφίγγω「緊縛」）是堤豐（Typhon）與艾基德娜（Echidna）所生的人面獅身女妖，守衛底比斯（Thebes）城外的要道。當底比斯王拉伊俄斯（Laius）因觸犯神諭──擄走珀羅普斯之子克律西波斯──而遭諸神懲罰時，赫拉（或阿波羅）遣斯芬克斯降臨底比斯，以謎題折磨全城。她向每個過路者提出同一謎題，答不出者即被撕碎吞食，底比斯陷入恐慌。

伊底帕斯（Oedipus，名字意為「腫腳」）的身世本身即是一樁悲劇的伏筆：拉伊俄斯曾獲神諭「其子將弒父娶母」，故命牧人將新生兒的腳跟刺穿棄於山中。伊底帕斯被牧人救起、輾轉由科林斯王波呂波斯撫養成人。成年後，他為逃避「弒父娶母」的預言離開科林斯，在通往底比斯的岔路上因爭路而殺死一位老者──那正是他的生父拉伊俄斯。隨後他遭遇了攔路的斯芬克斯。

## 情節

### 第一幕：謎題

斯芬克斯向伊底帕斯提出著名的謎題：「什麼生物早晨用四隻腳行走，中午用兩隻腳，晚上用三隻腳？」（τί ἐστιν ὃ μίαν ἔχον φωνὴν τετράπουν καὶ δίπουν καὶ τρίπουν γίγνεται）

謎面考驗的是對「人」的隱喻認知：幼年（早晨）以四肢爬行，成年（正午）以雙足行走，老年（黃昏）拄杖如三足。希臘人自小熟知「人是一日的尺度」的觀念，謎題實為智慧型「猜謎考驗」（riddle-initiation）的典型。伊底帕斯答出「人」（ἄνθρωπος），斯芬克斯敗北，自崖上墜亡（一說被伊底帕斯所殺）。

### 第二幕：王者之城的代價

解謎成功的伊底帕斯被底比斯人擁立為王，並迎娶先王遺孀伊俄卡斯忒（Jocasta）──此即實現「娶母」的預言。斯芬克斯之禍雖解，底比斯的瘟疫卻隨之而來。忒瑞西阿斯（Tiresias）揭發瘟疫源於「弒父娶母者的汙染」，伊底帕斯逐步追查，最終發現自己即是兇手。伊俄卡斯忒自縊，伊底帕斯以伊俄卡斯忒的金別針刺瞎雙目，自我流放，由女兒安提戈涅（Antigone）伴隨浪跡。

### 第三幕：謎題的象徵

斯芬克斯謎題表面是「猜謎」，實則預示伊底帕斯的命運──他解答了「人是什麼」，卻未能認識「自己是誰」。雅典娜式的智慧在此轉為反諷：解謎使他登上王座，而「自我認識」的失敗使他墜落。索福克勒斯《伊底帕斯王》在希臘悲劇中確立「認識你自己」（γνῶθι σεαυτόν）的主題，斯芬克斯遂成為「知識與盲目之辨」的永恆象徵。近代佛洛伊德更以「戀母情結」之名挪用此神話，使斯芬克斯謎題成為精神分析學的經典圖像。

## 跨文化平行

| 希臘伊底帕斯故事 | 跨文化對應 |
|-----------------|-----------|
| 斯芬克斯謎題考驗（答錯者死） | ↔ 中國《莊子》「一足之夔」問答／《史記》鄒忌與「何能王此座」之問 |
| 解謎者繼承王位 | ↔ 聖經但以理（解伯沙撒牆上文字獲高位）；《天方夜譚》謎題娶親母題 |
| 弒父娶母的預言 | ↔ 北歐伏爾松傳說中辛菲厄提（Sinfjötli）；印度《摩訶婆羅多》的亂倫禁忌 |
| 人面獅身混合獸 | ↔ 埃及獅身人面像（哈夫拉的守衛）、美索不達米亞人首翼獅（Lamassu） |
| 棄嬰─身世謎─回歸 | ↔ 吉爾伽美什母題；摩西與神話學「英雄的出生」原型（蘭克《英雄誕生的神話》） |
| 預言與自我實現 | ↔ 印度「受詛者」故事；北歐瓦爾基里的命運觀 |
