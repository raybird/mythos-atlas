# 烏辛什 (Ūsiņš)

- **文化：** 波羅的神話 (Baltic Mythology)
- **職掌：** 馬匹、蜜蜂、春天之光之神

## 概述

烏辛什（Ūsiņš，亦作 Ūsiņš / Usins / Usyns）是拉脫維亞神話中掌管馬匹、蜜蜂與春日之光的神祇，是波羅的海體系中最能體現「季節性回歸」的神靈之一。他的名字在語源上與「asinis」（血液）或印歐語系「清晨／黎明」詞根相關，象徵春回大地、萬物血脈重新流動的時刻。不同於雷神佩爾庫納斯的狂暴力量，烏辛什的力量是溫和的、方向性的——他駕馭的不是風暴，而是太陽回歸後第一縷照進穀倉與馬廄的光。

在拉脫維亞民間歌謠（dainas）中，烏辛什常被描述為騎著灰白色駿馬的青年，金馬刺閃耀，馳騁於初綠的田野上。他既是馬匹之神，也是養蜂之神——蜜蜂被視為烏辛什的僕役，蜂箱中的第一滴蜜須供奉給他。四月下旬的聖喬治節（Jura diena）曾是烏辛什的節慶，這一天牧民將馬匹初次放出馬廄，牧人與養蜂人共同祈禱烏辛什賜福。此一節日在基督教化後被聖喬治（Saint George）取代，但「聖喬治之馬」的祝福習俗至今仍保留烏辛什的古老內核。

## 神話事蹟

烏辛什最重要的神話事蹟圍繞「春之歸來」。傳說在寒冬，世界被維爾尼亞斯（Velnias）的黑暗籠罩，馬匹無力、蜂群沉睡、種子蟄伏。烏辛什於春分後的黎明誕生——民間歌謠稱他「從馬蹄踏過的第一塊融雪中升起」，一手執金色韁繩，一手執盛蜜的角杯。他首先造訪大地女神 Žemyna 的懷抱，以韁繩敲擊地面喚醒沉睡的種子；接著走訪每座馬廄，將力量重新灌入馬的四肢與鬃毛。

烏辛什與雙馬神 Ašvieniai 關係密切。在部分 dainas 版本中，烏辛什被描寫為 Ašvieniai 雙馬的牧者或馭手——他每天清晨將雙馬從太陽女神 Saulė 的馬廄中放出，駕著她衝出東方的海面。因此烏辛什有時被視為「太陽的馬夫」，太陽回歸的功勞有一部分歸於他。養蜂儀式「烏辛什的開箱」（Ūsiņa atvēršana）也是他的重要祭典：養蜂人於首次採蜜時以蜂蜜酒祭拜蜂箱，呼喚烏辛什的名字，相信這樣蜜蜂將整年不棄巢、蜂蜜豐盈——蜜蜂的勤勉與馬的奔馳，在此被連結為同一種「春之生命力」的顯現。

烏辛什也有守護兒童與家畜的一面。民間相信新生小馬駒若鼻間有白星，便是「烏辛什的印記」，此馬一生將受他庇護。立陶宛對應的神靈為「Jorė」或「Jurgis」（聖喬治），立陶宛人在春日亦舉行「Jorės」節，放牧、祭馬、繞行田地，與拉脫維亞的烏辛什節慶形成南北呼應。

## 跨文化對應

| 波羅的海 | 跨文化對應 |
|---------|-----------|
| 烏辛什（Ūsiņš） | ↔ 印度雙馬童阿什文（Aśvins）— 馬與曙光之神 |
| | ↔ 希臘狄俄斯庫里兄弟（Dioscuri）— 馭馬神 |
| | ↔ 希臘阿波羅（Apollo）— 牧群／春之光明神 |
| | ↔ 基督教聖喬治（St. George）— 基督教化的馬神 |
| | ↔ 斯拉夫弗洛斯（Veles）／立陶宛對應 Jorė — 牧畜神 |

烏辛什最接近印度吠陀的阿什文雙馬童與希臘的狄俄斯庫里兄弟——三者皆屬印歐「神聖雙馬」傳統的不同面向。阿什文在黎明前駕馬車拯救落難者、賜予蜂蜜與療癒，與烏辛什「駕雙馬、賜蜂蜜」的功能高度同構；狄俄斯庫里兄弟亦為駿馬的主人與海上遇難者的拯救者。烏辛什的特殊之處在於他同時整合了「馬神」與「蜂神」兩重身份——這在跨文化中較為少見，僅希臘的阿波羅（作為牛群的保護者與頌歌的給予者）有類似的「畜牧＋秩序」綜合性格。聖喬治在拉脫維亞的節日層疊，是基督教化過程中「神聖騎手」形象的轉譯，與波羅的海以外的歐洲地區（如英國、喬治亞）的聖喬治馬神崇拜同構。

## 相關神祇

- **Saulė** — 太陽女神，烏辛什所駕馭之雙馬的主人
- **Ašvieniai** — 雙馬神，烏辛什的牧者對象與夥伴
- **Žemyna** — 大地女神，烏辛什喚醒種子的對象
- **Jumis** — 豐收穀靈，烏辛什春耕秋收循環的另一端
- **Velnias** — 冥界黑暗之神，烏辛什所對抗的寒冬源頭

## 出現在

- 拉脫維亞民間歌謠（Latviešu dainas），馬與蜜蜂主題群組
- 立陶宛 Jorės 春日節慶記錄
- 基督教化後聖喬治節（Jura diena）的民間習俗
