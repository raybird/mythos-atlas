# 奧絲泰亞 (Austēja)

- **文化：** 波羅的神話 (Baltic (Lithuanian/Latvian) Mythology)
- **職掌：** 蜜蜂、蜂蜜、蜂巢、豐饒、太陽之女的守護者

## 概述

奧絲泰亞（拉脫維亞語 Austēja，亦有 Austeja／Austra 的異寫）是波羅的海神話中掌管蜜蜂與蜂蜜的女神，被民間歌謠（dainas）尊稱為「蜜蜂之母」（bišu māte）。她的名字與拉脫維亞語 `aust`（「破曉、升起」）同源，暗示她與太陽女神索蕾（Saulė）之間的親密關係——在拉脫維亞的世界觀中，蜜蜂被視為太陽的生物，是陽光凝聚成的小小飛行體。奧絲泰亞的職掌橫跨三個領域：蜜蜂的繁衍與蜂群的秩序、蜂蜜作為神聖食物的生產，以及由「甜蜜」延伸而來的豐饒與婚姻祝福。她不像佩爾庫納斯（Perkūnas）或萊瑪（Laima）那般位居萬神殿核心，卻在波羅的海農村的日常生活中占有無可取代的地位——養蜂是家家戶戶的營生，而蜂群的存亡被認為直接繫於奧絲泰亞的喜怒。

奧絲泰亞的形象在文獻中並無明確的人形描繪，更多是透過行為來認識她：她會在黎明時分巡視蜂房，驅趕熊與鳥類等掠食者；若蜂群離巢，便是奧絲泰亞對家宅主人不滿的徵兆。在部分民歌中，她以年輕女子的形象出現，手持蜂蜜罐，坐於太陽的花園中，與太陽的女兒們（Saulės dukterys）一同紡織——紡織與養蜂在此構成姊妹意象，兩者都是「以耐心換取甜美果實」的技藝。

## 神話事蹟

### 蜜蜂的太陽血統

在拉脫維亞民歌中，最核心的奧絲泰亞神話是她與太陽的關係。傳說索蕾駕著金車穿越天穹時，車輪激起的金色火星落入人間，化為第一批蜜蜂——因此蜜蜂被稱為「太陽的僕人」或「太陽的種籽」。奧絲泰亞是這群太陽生物的總管，她替索蕾照料牠們，並在冬日為蜂群尋找庇護，讓太陽的生命力在寒冷中得以延續。這則神話將蜂群的季節性死亡與重生，對應為太陽在冬夜與春晨之間的循環，使養蜂成為一項帶有宇宙意義的活動。

### 蜂蜜的神聖契約

奧絲泰亞的另一項職責是守護「蜜的契約」。民間信仰規定，蜂房的所有者不得在未告知奧絲泰亞的情況下取蜜；每年首次割蜜前，主人須以蜂麵包或蜜酒祭拜，並在蜂房上畫一個太陽符號，請求奧絲泰亞的許可。據說違反契約者會招致蜂群死亡或蜂蜜變苦。此契約反映了一種互惠的宇宙觀：蜜蜂的甜蜜並非免費贈禮，而是奧絲泰亞與人類之間透過儀式維持的平衡——與中國《山海經》中「蜂蜜之盧」的祭祀，以及希臘的蜜祭傳統，屬於同一種以蜜溝通神人的思維。

### 婚禮與死亡的蜜蜂

奧絲泰亞與人間的嫁娶、喪葬緊密相連。波羅的海習俗中，新娘會在嫁妝中帶上一箱蜜蜂，作為「甜蜜婚姻」的祝福；喪禮中則會「告知蜂群」——家中有喪事時須輕敲蜂房並向蜜蜂低語死者之名，否則蜜蜂會飛走或死亡。此俗亦見於英格蘭、法國與斯拉夫世界，是歐洲普遍流傳的「蜜蜂通靈」習俗，其背後的神話邏輯是：蜜蜂作為太陽與彼界的中介，必須被納入生死的儀式秩序之中。

## 跨文化對應

| 波羅的海 | 跨文化對應 |
|---------|-----------|
| 奧絲泰亞（Austēja） | ↔ 希臘亞里斯泰俄斯（Aristaeus）— 養蜂之神 |
| | ↔ 希臘蜜拉（Melissa）— 女祭司／蜜蜂化身 |
| | ↔ 埃及拉之眼（Ra 之淚）— 蜜蜂源自太陽神 |
| | ↔ 馬雅阿赫·穆森·卡伯（Ah Muzen Cab）— 蜜蜂之神 |
| | ↔ 印度婆羅摩利（Bhramari）— 蜂群女神 |
| | ↔ 凱爾特布里姬德（Brigid）— 蜂與療癒 |

奧絲泰亞在「蜜蜂源於太陽」這點上與埃及神話最為接近——埃及的蜜蜂從太陽神拉的淚水中誕生，而波羅的海的蜜蜂則從索蕾的車輪火星中誕生，兩者都把蜜蜂視為太陽能量的物質化。在職能上，她最接近希臘的亞里斯泰俄斯與馬雅的阿赫·穆森·卡伯：三者都是專司養蜂與蜂蜜的神祇，肩負教導人類照料蜂群的文明使命。不同之處在於，希臘與馬雅的神祇具有明確的神話傳記與廟宇崇拜，奧絲泰亞則幾乎純然存在於民間儀式與民歌之中——這使她更接近民間「穀精」式的神靈，而非國家級神祇。

## 相關神祇

- **索蕾（Saulė）** — 太陽女神，蜜蜂的創造者與奧絲泰亞的主宰
- **太陽的女兒們（Saulės dukterys）** — 與奧絲泰亞一同紡織的姊妹
- **奧什琳涅（Aušrinė）／瓦卡琳涅（Vakarinė）** — 晨星與暮星，太陽的兩名侍女，與奧絲泰亞共享黎明意象
- **朱米斯（Jumis）** — 豐收與穀物之神，與奧絲泰亞同屬農業豐饒體系
- **維爾尼亞斯（Velnias）** — 冥神，被視為破壞蜂群的黑暗力量，與奧絲泰亞對立

## 出現在

- 拉脫維亞民間歌謠（dainas）中與蜜蜂、蜂蜜相關的篇目
- 立陶宛與拉脫維亞的養蜂民俗誌（蜂房祭祀、告知蜂群習俗）
- Pēteris Šmits《拉脫維亞神話》（1926）
- 歐洲「蜜蜂通靈」習俗比較研究（英格蘭、法國、斯拉夫）
