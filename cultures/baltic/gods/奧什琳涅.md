# 奧什琳涅 (Aušrinė)

- **文化：** 波羅的海神話（立陶宛／拉脫維亞）
- **職掌：** 晨星、黎明女神、健康與青春

## 概述

奧什琳涅（Aušrinė，拉脫維亞語為 Auseklis）是波羅的海神話中的晨星女神，職掌黎明、健康、青春與愛情。她的名字源於波羅的語詞根 *auš-（黎明、破曉），與原始印歐語的黎明女神 *H₂éwsōs 直接同源——這使她與希臘的厄俄斯（Eos）、羅馬的奧蘿拉（Aurora）、印度的烏莎斯（Ushas）以及日耳曼的厄歐斯特雷（Ēostre）屬於同一神話家族。

在立陶宛神話中，奧什琳涅被視為太陽女神 Saulė 的女兒之一（Saulės dukterys，太陽的女兒們）。她每天清早在太陽升起之前先行出現，為母親的到來鋪路。她是天界馬車的駕駛者之一，有時被描繪為牽引兩匹白馬的少女，為日出開道。在拉脫維亞的民間歌謠中，Auseklis（晨星）常與 Mēness（月神）一同出現——晨星與月神曾經一起等待太陽的歸來。

奧什琳涅同時掌管健康與治癒。傳統立陶宛民間習俗中，人們在清晨朝向晨星祈禱以獲得健康與青春。少女們在重大節日前以晨露洗臉，傳說這能帶來如奧什琳涅般的美貌。她的對應者是傍晚之星 Vakarinė（或 Vakara），兩者分別標誌晝夜的開端與終結——她們是太陽的一對侍女，掌管時間的門檻。

## 跨文化對應

| 文化 | 神祇 | 對應關係 |
|------|------|---------|
| 希臘 | 厄俄斯 (Eos) | PIE 同源 *H₂éwsōs，晨光女神 |
| 羅馬 | 奧蘿拉 (Aurora) | 同源，晨光之神格化 |
| 印度 | 烏莎斯 (Ushas) | 同源，永恆青春、黎明駕車 |
| 日耳曼 | 厄歐斯特雷 (Ēostre) | 同源，復活節名稱來源 |
| 斯洛維尼亞 | Zorya 姊妹 | 晨星 Zorya Utrennyaya |
| 日本 | 天鈿女命 (Ame-no-Uzume) | 以舞蹈呼喚黎明 |
| 埃及 | Tefnut（部分面向） | 晨露與黎明相關 |
