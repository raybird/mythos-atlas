# 朱米斯 (Jumis)

- **文化：** 波羅的神話 (Baltic Mythology)
- **職掌：** 豐收、農業、穀物之靈、雙穀穗之神

## 概述

朱米斯（Jumis）是拉脫維亞與立陶宛神話中掌管豐收與農業的神祇，其名與拉脫維亞語 `jumis`（雙穀穗）同源，象徵農田中長出的連體穀穗——被視為豐收的極致祝福。不同於其他農業神以風雨雷電控制農作，朱米斯的職掌更為具體：他即穀物生長力本身。每當收割時節，農人會刻意在田間保留一束穀穗未割，稱為「朱米斯的腰帶」（Jumja josta），相信這樣能將穀物之靈留在田裡以確保來年豐收。

朱米斯的形象多與雙穗、結繩、交纏的麥稈相關。在拉脫維亞的民間歌謠（dainas）中，朱米斯常被描述為「穿亞麻衣的小人」或「金色的侏儒」，躲在穀倉或田埂之間。他的脾氣既有祝福力也有破壞力——若農人未在收成後舉行適當的儀式，朱米斯會使穀物腐爛或讓明年的田地面目全非。

## 神話事蹟

朱米斯最重要的神話環繞「雙穗的誕生」。傳說世界之初，大地女神 Žemyna 與太陽神 Saule 共同創造了植物，但最初的麥田只結單穗。朱米斯誕生於第一陣秋風吹過成熟麥田的那一刻——風將兩個穀穗交織在一起，從中跳出了朱米斯。他手持一條以麥稈編織的金色腰帶，從此腰帶象徵連接大地與太陽的農業契約。

每年豐收時節的重頭戲是「追逐朱米斯」（Jumja medības）：最後一個割下成熟麥束的人被稱為「捕捉了朱米斯」，須將麥束編成人形（Jumja tēls）穿戴於身，在村落中繞行，眾人以歌謠歡送朱米斯之神力回到倉庫。若無人願意收最後一束，則須以公雞祭祀朱米斯——將其埋在田頭，以血液滋養地母以確保來年豐收。此習俗在立陶宛名為「Jomis」或「Jomauti」，是歐洲古老穀精信仰的典型表現。

朱米斯也與冥界有間接連結——冬至時朱米斯被認為進入地底，與地母 Žemyna 共處三個月，春分時重返地面，攜來新的發芽生命。此循環使朱米斯成為從播種到收成、從死亡到重生的完整象徵循環。

## 跨文化對應

| 波羅的海 | 跨文化對應 |
|---------|-----------|
| 朱米斯（Jumis） | ↔ 希臘狄蜜特（Demeter）／普路托斯（Ploutos） |
| | ↔ 羅馬刻瑞斯（Ceres） |
| | ↔ 北歐弗雷（Freyr）— 豐收之神 |
| | ↔ 中國后稷 — 稷神／農業始祖 |

| ↔ 英國 John Barleycorn — 人格化穀精 |

朱米斯最接近希臘的普路托斯（財富與穀物之神）和埃及的奧西里斯——後者雖是冥神與復活之神，在民間信仰中同樣被視為大麥的化身，受死、入地、重生三部曲與朱米斯的冬冥復歸結構高度一致。不同於刻瑞斯和狄蜜特這類奧林帕斯級農業神，朱米斯更像是「穀精」（corn spirit）——一種地方性的植物神靈，其儀式也保留在民間習俗而非國家祭典中，與英國的 John Barleycorn 及中國的后稷傳說更為同構。

## 相關神祇

- **Žemyna** — 大地女神，朱米斯冬季的伴侶與回歸處
- **Saule** — 太陽女神，朱米斯生命力來源
- **Perkūnas** — 雷神，以雨水滋養朱米斯的穀物
- **Laima** — 命運女神，與朱米斯共同決定農家一年的運勢
- **Velnias** — 冥界與混亂之神，朱米斯的對立面
