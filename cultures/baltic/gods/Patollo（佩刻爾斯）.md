# Patollo（佩刻爾斯）

- **文化：** 波羅的神話 (Baltic / Old Prussian Mythology)
- **職掌：** 地下世界、死亡、亡者靈魂、冥界審判

## 概述

Patollo／Peckols（立陶宛語作 Pikulas 或 Pikuolis，又作 Pocols、Pecols、Picullus）是古普魯士與波羅的海神話中掌管地下世界與亡者的神祇。雖然名稱變體繁多，多數學者認為 Peckols、Patollo、Pattol、Patollu 等其實指向同一位神——負責地下世界、死亡與亡靈的冥界主宰，性格暴烈、嚴厲，與立陶宛的 Velnias（冥神）在職掌與形象上極為相近。Patollu 一名最早見於 1418 年瓦爾米亞主教致教宗馬丁五世的信函，信中提到普魯士人「不再崇拜 Patollu 與 Natrimpe」。十六世紀編年史家 Simon Grunau（1529）的記載雖多有想像成分，卻使 Patollo 形象廣為流傳：他是年老、白鬚、戴白色頭巾的男子，是令人畏懼而無情的死者之神，凡輕慢祭司、未按古禮供奉祭品就埋葬亡者的人，都會被他騷擾與折磨。

## 神話事蹟

根據 Sudovian Book（《蘇多維安之書》，1520 年代）與 1530 年教會教令《Constitutiones Synodales》的記載，古普魯士人崇奉 Peckols（地獄與黑暗之神）與 Pockols（空中飛翔的邪靈／魔鬼）兩者。在此雙神系統中，Peckols 被早期傳教士比附為羅馬的冥神普魯托（Pluto），而 Pockols 則被比附為希臘的復仇女神（Furies）。這種對應是基督教傳教士為了讓歐洲人理解異教信仰所做的轉譯，帶有強烈的妖魔化色彩。Jonas Bretkūnas 描述 Picollus 為「年老、頭髮灰白、面色死白、身穿白衣、從腋下窺視他人的老人」，並直言其名即「魔鬼」之意；他同時將「XIII. Pikols——地下世界與黑暗之神」與「XIV. Pikuliūnus——飛行的邪靈」分列。現代學者則傾向認為 Peckols 原本更接近希臘的哈迪斯、北歐的赫爾這類「亡者領域的看守者」，而非基督教意義上的邪惡化身；其後期被轉化為惡魔形象，正是征服宗教重新詮釋舊神靈的典型過程。

## 語源與名號

「Peckols」等名號的語源長期是波羅的海語言學者爭論的焦點。Christoph Hartknoch 認為其源自薩爾馬提亞語 pieklo（地下世界）；August Schleicher 主張由立陶宛語詞根 pik-／pyk- 加後綴 -ul- 構成，該詞根涉及「死者及其靈魂（vėlė）」的概念；Kazimieras Būga 則將 piktas（邪惡、憤怒）、pykti（發怒）等立陶宛語詞歸於同一詞根。另有一說主張普魯士語 pyculs（地獄）為西斯拉夫語 pьkъlъ（地獄）的借詞，反映基督教「地獄」觀念對原住民死亡觀的重新塑形。值得注意的是，有學者推測 Peckols 與斯拉夫的 Veles（維列斯，耶夢冥界之神）可能是同一波羅的海神祇的不同名稱——兩者皆主掌地下世界，又都在後期與「魔鬼」畫上等號，這反映了波羅的海與斯拉夫信仰深厚的親緣關係。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 斯拉夫神話 | Veles（維列斯） | 地下世界、財富、與雷神對立 |
| 希臘神話 | Hades／Pluto（哈迪斯） | 冥界主宰、亡者看守 |
| 北歐神話 | Hel（赫爾） | 亡者領域、與雷神索爾對應 |
| 羅馬神話 | Pluto／Dis Pater | 傳教士比附對象、冥界主神 |
| 埃及神話 | Osiris（歐西里斯） | 冥界審判、亡者靈魂 |
| 立陶宛神話 | Velnias（維爾尼亞斯） | 同源相類之冥神 |

## 相關神祇

- **Perkūnas**（雷神）——與 Peckols 在 Grunau 三神體系中並列，象徵秩序與雷電
- **Potrimpo（波特里姆波）**——豐收、穀物與流水之神，亦屬三神體系
- **Velnias**（立陶宛冥神）——Peckols 的立陶宛對應者
- **Dievas**（天父）——天界主宰，與地下世界相對
- **Giltinė**（死亡女神）——擬人化死亡的另一面
