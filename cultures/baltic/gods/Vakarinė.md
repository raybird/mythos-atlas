# 瓦卡琳涅 (Vakarinė)

- **文化：** 波羅的神話 (Baltic (Lithuanian/Latvian) Mythology)
- **職掌：** 暮星（金星）、黃昏、夜的來臨、太陽的侍女、誕生與離別

## 概述

瓦卡琳涅（立陶宛語 Vakarinė，字面意「黃昏之星」；對應拉脫維亞語 vakarā）是波羅的海神話中的暮星女神，與晨星女神奧什琳涅（Aušrinė）為一對姊妹神，共同擔任太陽女神索蕾（Saulė）的兩名侍女。她掌管黃昏時分——太陽落山後，第一顆在西方天空點亮的星，即為她的化身。與奧什琳涅預告黎明的角色相對，瓦卡琳涅宣告黑夜的降臨，並在夜間守護旅人、疲憊者與赴死者。兩姊妹共同構成了波羅的海宇宙觀中晝夜交替的門檻：奧什琳涅開門，瓦卡琳涅閉門。

在立陶宛民間歌謠中，瓦卡琳涅常被描繪為一位手持燈籠的少女，在太陽之後駕著小船或騎馬離開天際。她的星——金星——在西方天空格外明亮，被稱為「晚之引路人」（vakaro kelrodė），是農人結束一日勞作、牲畜歸欄的信號。不同於奧什琳涅受歡迎的地位，瓦卡琳涅帶有淡淡的哀愁色彩：她與黃昏、離別、夕陽西沉相連，象徵一日的結束與生命之暮。

## 神話事蹟

### 太陽的侍女與夜的開關

瓦卡琳涅最根本的神話職能是太陽的黃昏侍者。傳說索蕾的白馬在白晝奔馳一天後，於黃昏時分疲憊不堪，瓦卡琳涅便以她明亮的星芒為索蕾照亮歸途，並在西方天邊支起一幅巨大的暮色帷幕，遮擋世人窺探太陽的休息。她手中的燈籠被認為是金星的光——立陶宛語中以 `Vakaro žvaigždė`（暮星）稱之。待索蕾安然入睡，瓦卡琳涅便點亮夜空，邀請月神梅內西斯（Mēness）接替白晝的巡行。

### 誕生與離別的女神

瓦卡琳涅同時是生育與離別之神。在立陶宛民俗中，她與姊妹奧什琳涅各有分工：奧什琳涅接引黎明出生的嬰兒，瓦卡琳涅則護送黃昏離世者的靈魂踏上冥途。產婦若在傍晚臨盆，會點燃油燈並向瓦卡琳涅祈禱，相信她能以暮星之光引導嬰兒平安來到人世。在喪葬儀式中，送葬隊伍會在日落時出發，因為民間相信瓦卡琳涅的星是通往彼岸世界的路標——此一職能使她與冥界守護者形成間接連結。

### 與月神的婚約

拉脫維亞民歌中保存了一則關於瓦卡琳涅與月神的重要母題：月神梅內西斯向太陽之女求婚，太陽將兩名女兒（晨星與暮星）交由其選擇，月神選中了暮星瓦卡琳涅，因此月亮與金星在天上永遠相伴——月亮每夜都追隨著暮星運行。部分學者認為此母題與希臘神話中塞勒涅與恩底彌翁、以及月神相戀的普世母題相通，反映印歐神話中「日月—星」家族的婚姻結構。

## 跨文化對應

| 波羅的海 | 跨文化對應 |
|---------|-----------|
| 瓦卡琳涅（Vakarinė） | ↔ 希臘赫斯珀洛斯（Hesperus）— 暮星之神 |
| | ↔ 羅馬維斯帕（Vesper）— 昏星 |
| | ↔ 希臘赫斯珀里德斯姊妹（Hesperides）— 西方黃昏少女 |
| | ↔ 埃及努特（Nut）— 太陽黃昏吞沒者／天空女神 |
| | ↔ 中國長庚星 — 金星黃昏出現的稱號 |
| | ↔ 印度烏莎斯（Ushas）— 與暮色相關的晝夜女神 |

瓦卡琳涅在結構上與希臘的赫斯珀洛斯完全對應——二者都是金星的黃昏化身，且都被安排在太陽的西方歸宿地。她的姊妺關係也呼應希臘赫斯珀里德斯姊妹：西方黃昏之地的少女，看守太陽的果實。不同於希臘將晨昏星視為兩位神明（Phosphorus 與 Hesperus），波羅的海傳統保留了更古老的「雙侍女」架構，與中國天文學中金星「啟明（晨）／長庚（昏）」的雙重稱號構成驚人的平行——這顯示人類在不同的天文體系中，都選擇以「一顆星、兩個名字、兩位神」來表現金星的雙面性。

## 相關神祇

- **奧什琳涅（Aušrinė）** — 晨星女神，瓦卡琳涅的姊妹與對應神
- **索蕾（Saulė）** — 太陽女神，瓦卡琳涅所侍奉的主人
- **梅內西斯（Mēness）** — 月神，傳聞中瓦卡琳涅的婚約對象
- **奧絲泰亞（Austēja）** — 蜜蜂女神，同屬太陽女僕體系
- **維爾尼亞斯（Velnias）** — 冥神，與瓦卡琳涅的黃昏冥途職能相對
