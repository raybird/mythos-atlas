# 波特里姆波 (Potrimpo)

- **文化：** 波羅的神話 (Baltic (Lithuanian/Latvian) Mythology)
- **職掌：** 春天、穀物、流水、蜜蜂與繁榮之神（古普魯士神系）

## 概述

波特里姆波（Potrimpo，古普魯士語亦作 Potrimpus／Potrympus，立陶宛學界作 Patrimpas，早期文獻作 Natrimpe，另有水流神格變體 Autrimpo）是古普魯士人（Old Prussians）信仰中的主神之一，與雷神珀庫納斯（Perkūnas）、冥神帕托洛（Patollo／Peckols）並列為西蒙·格魯瑙（Simon Grunau，約 1470–1530）《普魯士編年史》（Preussische Chronik）所載的「普魯士三聯神」。他的神名首見於 1418 年瓦爾米亞主教致教宗馬丁五世的備忘錄（Collatio Episcopi Varmiensis），文中稱普魯士異教先民崇拜「Natrimpe」等「惡魔」。格魯瑙描述波特里姆波是一位神情歡快的年輕男子，頭戴穀穗編成的花環，手中持穀束，位於羅姆瓦（Romuva）聖橡樹三穴偶像的其中之一，與中年的珀庫納斯、蒼老的帕托洛構成三世代的三聯圖像。

波羅的海神系橫跨三支系：西波羅的海的古普魯士、中部的立陶宛與北部的拉脫維亞。立陶宛、拉脫維亞的神祇（如珀庫納斯、索蕾、萊瑪）在民間歌謠 dainos/dainas 中留下豐富記錄；而古普魯士人在 13 世紀遭條頓騎士團征服、16 世紀前後徹底基督教化，其神系僅存於教會文件、編年史與《蘇多維亞書》（Sudovian Book）等零散文獻中。波特里姆波正是古普魯士神系中資料最完整、且被現代立陶宛學界（如 Vykintas Vaitkevičius 等）認定具有真實信仰基礎的神祇。格魯瑙的編年史向來被部分學者斥為想像之作，但近年研究傾向於在其誇飾的敘述中提取可靠的普魯士宗教層：波特里姆波的神格──穀物、蜜蜂、蛇、以蠟供養的聖火、水流與預言──與波羅的海其他支系的農業神體系高度一致。

## 神話事蹟

### 穀物與春天的神子

格魯瑙筆下的波特里姆波是「戰事與諸事好運之神」，其祭禮要求祭司齋戒三日、赤裸臥於大地、於以蠟養火的爐中焚香。這些細節指向一個春之神：蠟（蜂產品）、裸地（冬眠的大地）與齋戒，都是迎接自然復甦的儀式語彙。立陶宛史家 Daukantas 總結波特里姆波為「春天、幸福、豐裕、牛畜與穀物之神」，與格魯瑙所述互補。學界普遍將其視為波羅的海版的「春季神子」（divine youth），職掌與斯拉夫神話中每年死而復生的春日之神雅里洛（Jarilo）幾乎完全同構──青年形象、穀穗花環、歡快的性情、與冬死相對的春生循環。

### 蛇與蜂的祭祀

波特里姆波最特殊的屬性是蛇與蜜蜂。格魯瑙記載普魯士人崇拜草蛇（žaltys），以牛奶餵養，視其為波特里姆波的神使；16 世紀的波蘭史家 Maciej Stryjkowski 更記載羅姆瓦神廟中供有以銅鑄成的盤蛇像，即獻給波特里姆波的聖像。另一方面，《蘇多維亞書》與 Malecki 的記載將波特里姆波與「流水」連結：祭司將熱蠟倒入水中，依凝結的形狀占卜未來。蠟、蜜、蛇、水四者在此匯聚為一個神學意象──蜂將花粉帶回蜂巢化為蜜，蛇蟄伏地中隨春甦醒，蠟在火中融化復於水中凝固，皆是「死而復生、凝聚與轉化」的自然隱喻。維爾紐斯大學的專題研究更進一步指出，養蜂（bitininkystė）正是波特里姆波祭祀的核心領域，此點使他有別於一般農業神，而與拉脫維亞的蜂神奧絲泰亞（Austēja）及春日馬神烏辛什（Ūsiņš）遙相呼應──三者的共同點是「以蜂蜜聯繫神人」。

### 羅姆瓦的聖橡樹

格魯瑙描述普魯士人的主聖所羅姆瓦（Romuva／Rickoyoto）中有一棵常綠巨橡，橡幹上開鑿三個樹穴，分別安放三聯神的偶像；橡樹前的聖火以蠟與木持續供養，由祭司與女祭（waidelinns）看守。這棵「橡中之穴」與橡樹前的永火，後來成為波羅的海新異教運動羅姆瓦（Romuva）的命名根源。聖橡樹、三穴、三世代之神，與立陶宛民間「珀庫納斯的橡樹」（Perkūno ąžuolas）母題相扣──雷神與春神共享同一棵世界橡樹，樹冠象徵珀庫納斯的天界雷火，樹根處盤踞的蛇則是波特里姆波的地下之水。波特里姆波的祭祀在基督教化後轉化：教會將他與羅馬神話的波呂克斯（Pollux）相比（《宗教會議章程》Constitutiones Synodales, 1530），與卡斯托耳（Castor）及海神尼普頓相比的是流水神格變體 Autrimpo；17 世紀起他逐漸被聖喬治（St. George）等聖徒節慶所覆蓋。

## 跨文化對應

| 波羅的海 | 跨文化對應 |
|---------|-----------|
| 波特里姆波（Potrimpo） | ↔ 斯拉夫雅里洛（Jarilo）— 春日青年神、死而復生 |
| | ↔ 希臘阿多尼斯（Adonis）／提雅（Thiasos 少年神）— 春季植被之神 |
| | ↔ 北歐巴德爾（Baldr）— 俊美的青年神 |
| | ↔ 羅馬波呂克斯／卡斯托耳（Pollux／Castor）— 早期基督教化對應 |
| | ↔ 中國句芒（Goumang）— 東方春神、掌管草木萌發 |
| | ↔ 印度甘摩（Kāma）— 青春與繁茂之神 |

波特里姆波在功能與結構上最接近斯拉夫神話的雅里洛：兩者同為印歐／波羅的-斯拉夫語族的「春日青年神」，同以穀穗為標誌，同經歷「春生──秋亡──冬眠──復甦」的循環。與希臘阿多尼斯的差異在於：阿多尼斯是被動受苦的植物愛人，波特里姆波則是主動施惠、主司戰爭好運的青春王子，較近於北歐的巴德爾（光明、俊美、受人愛戴的青年神）。中國的句芒為五行春神、主東方與草木，功能相近但屬國家祭典體系，而波特里姆波始終是村落性的農牧信仰──此點與其「蛇與蜂」的鄉野祭禮一致。早期文獻將他類比於波呂克斯與卡斯托耳，反映基督教傳教士慣以希臘羅馬神話為座標翻譯異教神靈的操作，也為我們留下「波特里姆波為青年、雙生、流水」的側寫。

## 相關神祇

- **珀庫納斯（Perkūnas）** — 雷神，三聯神的中心，波特里姆波的「天界」對應
- **帕托洛（Patollo／Peckols）** — 冥神，三聯神中的老者，波特里姆波的「地底」對應
- **奧絲泰亞（Austēja）** — 拉脫維亞蜂神，共享蜜蜂與蜂蜜的祭祀領域
- **烏辛什（Ūsiņš）** — 春日馬神，與波特里姆波同屬春季復甦神格
- **維爾尼亞斯（Velnias）** — 立陶宛冥神，與帕托洛功能相近的跨支系對應
