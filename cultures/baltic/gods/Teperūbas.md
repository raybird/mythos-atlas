# Teperūbas (特佩魯巴斯)

- **文化：** 波羅的神話 (Baltic (Lithuanian/Latvian) Mythology)
- **職掌：** 地下世界、洞穴、礦藏、地下火焰

## 概述

Teperūbas（立陶宛語）是波羅的海神話中掌管地下世界與洞穴的神祇，為 Velnias（冥神）的從屬或另一面相。在立陶宛民間傳統中，Teperūbas 居住於地下深處的洞穴與礦脈之中，守護著金屬、寶石與地下火焰。他的形象通常為一位長鬚矮人，手持鐵錘與火把，身披岩石與苔蘚。Teperūbas 與礦工、鐵匠密切相關——礦工在下井前會向他祈禱，鐵匠則在鍛造時呼喚他的名字以求金屬品質精良。他的名字可能源自原始波羅的海語 \*tep-（「塗抹」或「地下」），與地下世界的黏土、礦物概念相關。在拉脫維亞民間，Teperūbas 被稱為 Velns 的地下僕人，負責管理冥界的財富。部分學者認為 Teperūbas 是 Perkūnas（雷神）在地下的對應——Perkūnas 管轄天界，Teperūbas 管轄地底，二者共同維護宇宙的垂直秩序。Teperūbas 在基督教化後被降格為「矮人精靈」（dwarfs）或魔鬼的僕人，但其古老形象保留在立陶宛與拉脫維亞的礦區傳說中。

## 神話事蹟

Teperūbas 最重要的神話是他與鐵的起源。傳說在世界初造之時，Dievas（天父）將不同顏色的泥土分給各族——人類得到表層的黃土，精靈得到森林的黑土，而 Teperūbas 得到最深處的紅土與黑鐵。Teperūbas 將這些金屬鑄成工具與武器，從地下送給人類。第二個神話涉及他與 Perkūnas 的關係——當 Perkūnas 的雷斧落地後，Teperūbas 在地下拾起碎片，將其鍛造為新的雷斧歸還天界。這個循環賦予雷神戰車永恆的動力。第三，在立陶宛民間故事中，Teperūbas 常以矮人形象出現在礦井深處，向勇敢的礦工贈送寶石與金屬，同時懲罰貪婪者——他會讓貪心的礦工迷失在地下迷宮中。Teperūbas 也與地震相關——當他在地下翻身或敲擊岩石時，大地便會震動。在拉脫維亞的 Livonian 傳說中，他被稱為 Purgalis，是地下王國的守門人，只有通過九道鐵門才能到達他的寶庫。

## 跨文化對應

| 文化 | 對應神祇／概念 | 共通點 |
|------|----------------|--------|
| 希臘神話 | Hephaestus（赫菲斯托斯） | 鍛造、地下火焰、金屬工藝 |
| 北歐神話 | Dwarves（侏儒） | 地下居民、寶石與金屬守護者 |
| 印度神話 | Tvashtr（陀湿多） | 鍛造之神、神器製造者 |
| 中國神話 | 太上老君（八卦爐） | 地下/爐火、金屬鍛造 |
| 日耳曼神話 | Wayland（維蘭） | 鐵匠英雄、地下工坊 |

## 相關神祇

- **Velnias**（冥神）——Teperūbas 的上級或冥界同僚
- **Perkūnas**（雷神）——與 Teperūbas 有地表／地下的互補關係
- **Žemyna**（地母）——同為地下世界的相關神祇
