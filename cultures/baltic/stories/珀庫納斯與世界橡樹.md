# 珀庫納斯與世界橡樹

- **文化：** 波羅的神話 (Baltic (Lithuanian/Latvian) Mythology)

## 故事背景

在世界最初的時代，太陽索蕾（Saulė）駕著金車駛過的穹頂之下，還不存在星辰的秩序。那時，大地中央與世界之洋的交界處，長著一棵橡樹──立陶宛民歌稱它為「金色的橡樹」（aukso ąžuolas），拉脫維亞歌謠則稱「灰色的老橡樹」（pelēks ozols）。這棵橡樹不是普通的樹：它的樹冠撐著天穹，正好位於太陽西行落下的路徑上，索蕾每日黃昏行經樹梢時，會將腰帶解下掛在枝上歇息，清晨再取回腰帶，駕車從東方的海底通道重新升起。傳說這棵樹高到窮盡視線，樹梢沒入雲層，樹根則盤入維爾尼亞斯（Velnias）的地下國度──樹冠、樹幹、樹根正好貫通天界、人間與冥界三層宇宙。民間禁忌因此絕不可砍伐巨橡，因為每一次斧刃觸及樹皮，都可能驚動棲居其上的整個世界。

## 情節

### 一、棲滿眾生的巨樹

據古老的立陶宛傳說，這棵世界橡樹是天地間所有生靈最初的居所。樹梢的最高處築著鷹巢，雄鷹棲於其頂，雙翼一張便遮蔽半邊天，鷹眼俯視著太陽的軌道；樹幹中段的枝椏間盤踞著巨大的蜂巢，成群的蜜蜂在此釀蜜，蜜汁沿樹皮淌下，被稱為「太陽的種籽」──據說蜜蜂正是太陽車輪激起的火星所化；樹根深處的洞穴裡，則蜷伏著一條巨蛇，蛇身盤繞樹根三匝，守著通向冥界的入口。這三種生物──鷹、蜂、蛇──分別代表了天空、大地與地下三個世界，整棵橡樹就是一幅豎立的宇宙地圖。然而，巨樹棲滿生靈的狀態既是繁榮，也是封閉：世間的一切力量都困在樹上，鳥不能離巢遠飛，獸不能落地行走，江河不能奔流，世界停滯在永恆的黎明裡，等待一個打破寧靜的力量。

### 二、雷神的雷斧

立陶宛民歌《太陽的婚禮》唱道：珀庫納斯（Perkūnas）在趕赴太陽之女奧什琳涅（Aušrinė）婚禮的路上，手持雷斧，駕著雙輪戰車奔馳天穹。他看見那棵金色的橡樹擎天而立，遮蔽了陽光通往世界的路，便舉起雷斧。雷斧劈下的一瞬，天地間迸發第一道閃電──立陶宛語稱「珀庫納斯的雷石」（Perkūno akmuo）從樹心崩落，化作人間的燧石與石斧，這就是為何農人在田裡掘出的古老石斧總被認為是雷神的兵器。巨雷炸響之際，橡樹由頂至底裂成兩半。民間歌謠記載：樹裂之時，鷹驚飛沖天，蜂群四散紛飛，蛇從樹根滑入地底──三者各歸其位，鷹歸天界、蜂歸人間花叢、蛇歸地下。世間萬物從此不再困於一樹，而是散落大地各安其所。從那以後，每當春天第一聲雷響，人們便說那是珀庫納斯重訪世界橡樹的舊事重演──雷聲喚醒沉睡的種子，劈開冬天的封閉，一如當年他劈開宇宙的停滯。

### 三、聖橡樹的後裔

珀庫納斯的雷斧留下兩道遺產。其一，樹幹裂開之處，天界與冥界的通道自此開啟，太陽得以每日從海底行至樹梢，世界有了晝夜與季節的節律；其二，巨樹雖裂，其根系仍存──立陶宛各地供奉「珀庫納斯的橡樹」（Perkūno ąžuolas），最著名的是普倫蓋（Plungė）附近樹齡五至八百年的古橡，以及相傳超過一千五百年的施特爾穆熱（Stelmužė）橡樹。16 世紀的編年史家格魯瑙記載，古普魯士人在羅姆瓦（Romuva）聖所供奉一棵橡幹開有三穴的常綠巨橡，三穴中各安放一尊神像，橡前聖火不熄──正是「世界橡樹」在現實祭祀中的遺存。直到今日，立陶宛民俗仍相信：在春雷初響時於橡樹下許願，或將雷石藏在屋簷下，便能得到珀庫納斯的庇佑；而砍伐巨橡，則必然招來雷擊。

## 跨文化平行

| 波羅的海 | 跨文化平行 |
|---------|-----------|
| 世界橡樹（三層宇宙、鷹頂／蜂中／蛇根） | ↔ 北歐世界樹尤格德拉西爾（Yggdrasil）— 鷹頂、龍根 |
| 珀庫納斯以雷斧劈樹 | ↔ 雷神索爾／宙斯／因陀羅 — 以雷威懲罰並建立秩序 |
| 太陽之樹、索蕾掛腰帶 | ↔ 中國扶桑／日本《古事記》太陽之樹 |
| 巨樹分裂、萬物各歸其位 | ↔ 印度原人普魯沙（Purusha）分裂創世 |
| 聖橡樹祭祀 | ↔ 希臘多多納（Dodona）宙斯聖橡、凱爾特聖橡 |

珀庫納斯劈裂世界橡樹，與北歐神話中奧丁懸身於尤格德拉西爾、巨鷹棲於樹頂而毒龍尼德霍格（Níðhöggr）啃咬樹根，共享「世界樹承載三界」的構圖；但波羅的海版本更強調「分裂」的創世意義──不是神懸於樹上求取智慧，而是雷神以暴力斬開停滯，使萬物得以分散繁衍。此一結構與印度《梨俱吠陀》中原人普魯沙被肢解而化成萬物的敘事同型：神聖實體的分裂，正是世界秩序誕生的條件。多多納的宙斯聖橡則提示了印歐語族共同的「雷神──橡樹」連結（拉丁語 quercus「橡樹」與 *Perkʷūnos「雷神」共享同一詞根），證明波羅的海版本保存了印歐神話極古老的層次。
