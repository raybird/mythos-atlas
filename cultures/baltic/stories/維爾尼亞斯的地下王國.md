# 維爾尼亞斯的地下王國——波羅的海的財富守護者

- **文化：** 波羅的神話 (Baltic (Lithuanian/Latvian) Mythology)

## 故事背景

維爾尼亞斯（Velnias）在波羅的海神話中是一個極為複雜的角色——他既是冥界之主、魔鬼的化身，也是地下寶藏與自然資源的守護者。在基督教傳入前的波羅的海原始信仰中，Velnias 並不完全是「邪惡」的存在，而是宇宙秩序中不可或缺的對立力量。他統治地下世界（apatinis pasaulis），那裡藏有金銀、琥珀、寶石與各種礦藏。這個故事描述 Velnias 如何建立他的地下王國，以及他與人類之間關於寶藏的複雜關係。Velnias 的形象在基督教化後被妖魔化，但在更古老的口傳傳統中，他是大地深處的智慧守護者。

## 情節

### 第一部：Velnias 的領地

在 Dievas（天父）創造天地後，世界被分為三層：天界由 Dievas 與 Perkūnas（雷神）統治，地表由 Saulė（太陽女神）與 Žemyna（地母神）照耀，而地下世界則歸 Velnias 所有。Velnias 的地下王國被描述為一個由黑暗寶石與發光礦脈構成的宮殿——牆壁嵌滿琥珀與紫水晶，地面鋪著金砂與銀礫，河流中流動著液態的光。Velnias 在此統治著一眾小鬼與地精（žemėlipiai），他們負責開採寶藏、鍛造金屬、守護地下的秘密。Velnias 的王座是一塊巨大的黑曜石，上方懸掛著一顆永恆燃燒的地下火——這是地球內部的火焰，也是人間火種的源頭。

### 第二部：寶藏的誘惑

Velnias 雖然守護寶藏，但他並不禁止人類尋寶——相反，他以寶藏作為誘惑，考驗人類的貪婪與智慧。傳說中，Velnias 會在月圓之夜派出他的僕從引導誠實的採礦者找到金脈，但同時也會以幻象迷惑貪婪之人，讓他們在地下迷宮中永世徘徊。有一則著名的立陶宛傳說：一個名叫 Stabrakas 的農夫在森林中遇見一位穿黑衣的老人（Velnias 的化身），老人指著一棵橡樹說：「挖開這裡，你會找到屬於你的寶藏。」Stabrakas 挖開橡樹根部，發現了一罐金幣。但老人提出條件：「這些金幣每用一枚，你就要多活一年——但這一年中你必須為我服務。」Stabrakas 貪心地拿走了所有金幣，卻發現自己被困在 Velnias 的地下王國中，被迫為冥神勞動一百年才獲得自由。

### 第三部：琥珀的秘密

Velnias 最珍視的寶藏是琥珀——波羅的海的「液態黃金」。在神話中，Velnias 將琥珀視為太陽 Saulė 的眼淚凝結而成的寶石，具有強大的神秘力量。每當 Perkūnas 以雷電擊中地面，Velnias 就會趁混亂之際收集散落的雷石（Perkūno akmuo），將它們化為琥珀。這些琥珀中封存著遠古的昆蟲、花粉與空氣，被視為宇宙記憶的載體。Velnias 允許人類撿拾海邊沖上來的琥珀——這是他的慷慨——但禁止人類深入地下開採未成熟的琥珀。違反此禁忌者會遭到懲罰：船隻在海上遭遇風暴，漁網被神秘力量撕裂，或者採礦者在坑道中聽見 Velnias 的笑聲而發瘋。

### 第四部：Velnias 與 Perkūnas 的地下之戰

當 Perkūnas 的雷電深入地下時，有時會觸及 Velnias 的王國。Velnias 被視為對此感到憤怒，但這實際上是一場宇宙性的力量交流——Perkūnas 的雷電帶來金屬礦脈的能量，Velnias 則將這些能量轉化為大地的肥沃。傳說中，Perkūnas 的雷斧落地後會化為火石，Velnias 拾起火石將它們鑲嵌在自己的王座上，使地下王國永遠溫暖。這個神話解釋了為什麼波羅的海地區的礦藏特別豐富——因為 Perkūnas 的雷電與 Velnias 的地下力量在此交匯。Velnias 與 Perkūnas 的關係因此不是單純的對立，而是一種宇宙性的互補。

## 跨文化平行

| 文化 | 對應概念 | 共通點 |
|------|----------|--------|
| 希臘 | Hades 的地下寶藏 | 冥界之主、寶藏守護、人類貪婪的考驗 |
| 北歐 | Dwarves（矮人）的地下王國 | 地下寶藏、鍛造、對黃金的執著 |
| 印度 | Kubera（財神）的地下宮殿 | 財富守護者、寶藏與試煉 |
| 日本 | 龍宮城（Ryūgū-jō） | 海底寶藏、觸犯禁忌的懲罰 |
| 中國 | 龍王的水底寶藏 | 水界寶藏、人類不可貪取 |
| 美索不達米亞 | Nergal 的地下王國 | 冥界之主、與地上秩序的對立 |
