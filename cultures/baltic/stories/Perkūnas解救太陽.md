# 佩爾庫納斯解救太陽 (Perkūnas Išlaisvina Saulę)

- **文化：** 波羅的神話 (Baltic Mythology)

## 故事背景

在波羅的海神話的時間開端，太陽女神撒烏萊（Saule）駕著金色馬車穿越天空，白天照耀大地、夜晚落入波羅的海休息。然而冥界與地下之神維爾尼亞斯（Velnias）覬覦太陽的光芒，策劃了一個將世界陷入永恆黑暗的陰謀。此故事記錄於拉脫維亞與立陶宛的多首民間歌謠（dainas）中，是波羅的海神話體系的宇宙級敘事核心。

## 情節

### 第一幕：太陽被盜

維爾尼亞斯化身為巨大的黑蛇（一說黑馬），在撒烏萊返回波羅的海休息時潛入她的寢宮。當太陽在海底殿堂沉睡，維爾尼亞斯用九條鐵鍊鎖住撒烏萊的馬車，以黑暗之布覆蓋她的光芒，將她囚禁於地底深處。世界瞬間陷入寒冷與黑暗——河流冰封、農作物枯萎、人類與動物皆在恐懼中求救。民間歌謠描述：「太陽不在的天空，石頭也在哭泣。」

### 第二幕：戰神披掛上陣

雷神佩爾庫納斯（Perkūnas）察覺世界的異常，發現撒烏萊的光芒已從天地間消失。他登上由兩匹白馬（即 Ašvieniai 雙馬）牽引的花崗石戰車，手持由大地女神 Žemyna 鑄造的閃電雙刃斧——一斧為金、一斧為銀。他率領天空中的星辰戰士（民間傳說中死去的勇士化為星宿）沿著世界樹（Austras koks）的主幹深入地下。

### 第三幕：天界的戰鬥

佩爾庫納斯在地底深處找到維爾尼亞斯的堡壘——以沉船與骨頭建成的黑暗宮殿。維爾尼亞斯召喚出蛇群、蟾蜍與所有冥界生物抵擋雷神。佩爾庫納斯發動了一場持續三天三夜的戰鬥：他的閃電劈開黑暗，每一擊都照亮地宮、驅散蛇群。維爾尼亞斯最後化為黑公羊衝向雷神，但佩爾庫納斯用金斧砍下公羊的右角——象徵維爾尼亞斯的力量核心被摧毀。鐵鍊在金斧的撞擊下斷裂。

### 第四幕：太陽重現

佩爾庫納斯救出被囚的撒烏萊，將她與馬車一起舉出地底。他將維爾尼亞斯的碎片拋入大海，警告他永遠不得再觸碰太陽。撒烏萊重新升上天際，陽光恢復溫暖大地，冰河融化、植物發芽。鳥兒第一次歌唱——民間歌謠說：「當太陽的馬車再次駛過天空，所有淹沒的影子都活了過來。」

### 後續傳說

此後的每逢日蝕或暴風雨，波羅的海民間仍相信這是維爾尼亞斯試圖再次偷竊太陽、但佩爾庫納斯即時趕到並以雷電驅趕他的證明。這也是為什麼波羅的海民族在暴風雨來臨時會敲打金屬器皿——模仿佩爾庫納斯的雷聲，協助他驅趕黑暗。

## 跨文化平行

| 波羅的海元素 | 跨文化平行 |
|------------|-----------|
| 太陽被囚禁於地下 | ↔ 希臘太陽神赫利俄斯每日穿越冥界 |
| | ↔ 埃及拉穿越杜亞特（Duat） |
| | ↔ 日本天照大神躲入天岩戶 |
| 雷神戰蛇救太陽 | ↔ 北歐索爾（Thor）戰蛇耶夢加得 |
| | ↔ 印度因陀羅（Indra）斬蛇弗栗多 |
| | ↔ 希臘宙斯戰堤豐（Typhon） |
| 黑公羊作為黑暗化身 | ↔ 北歐海姆達爾戰洛基（公羊／海豹之爭） |
| 星辰戰士跟隨雷神 | ↔ 北歐女武神帶領英靈戰士 |
| 鐵鍊囚禁太陽 | ↔ 北歐芬里爾狼被格萊普尼爾鎖鏈束縛 |
| 敲金屬助雷神 | ↔ 中國古代鳴鑼驅天狗救日月 |

佩爾庫納斯解救太陽的模式與希臘神話中赫利俄斯每日穿越冥界並未被囚禁（實為自然循環）不同；它更接近日本天照大神隱居的結構——光明被藏匿、世界陷入黑暗、靠眾神之力恢復。另一個極具可比性的個案是北歐神話中光明之神巴德爾死後世界陷入黑暗、赫爾莫德嘗試解救卻失敗的敘事——但波羅的海版本以雷神成功救回太陽作結，體現了該文化對宇宙秩序終將勝利的樂觀信念。
