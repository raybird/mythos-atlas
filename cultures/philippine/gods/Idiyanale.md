# Idiyanale（伊迪亞納萊）

- **文化：** 菲律賓神話（他加祿 Tagalog）
- **職掌：** 勞作女神、好行為的賞賜者、農業與工藝女神

## 概述

Idiyanale（亦作 Idiyanale 或 Idianale）是他加祿神話中掌管勞作、勤奮、好行為與農業技藝的女神。其名可能源自他加祿語詞根 `-diyan` 與 `-ale`，語意近似「值得讚美的行為」。她是早期菲律賓人倫理觀的神格化身——她不是威嚴的天神，而是監督人類日常行為的處世之神。Idiyanale 被視為 Bathala（至高神）的意志在人間的具體執行者。她的丈夫是 Dimangan（或 Dumangan，也有文獻認為與 Idiyanale 同神）。她同時被認為是狩獵神 Mapulon 與農業神 Dumangan 的母親或配偶，視不同部落傳統而定。她的象徵物是成熟的稻穗與紡織用的梭子——分別對應農業與家庭手工業，二者在古代菲律賓經濟中皆以女性主要勞動者為核心。

她的信仰在西班牙殖民前的他加祿社會中極為重要。早期菲律賓人將每一天的勞動開始前先供奉一把米或一塊貝殼給 Idiyanale，祈求這一天的工作順利且無災無禍。怠惰者被認為會受到她的「冷遇」——不僅是物質上的懲罰，更是在倫理層次被社會排斥。Idiyanale 也與「誓言」相關——在簽訂社區約定或婚姻契約時，雙方會呼喚 Idiyanale 的名作為見證，違約者等同於冒犯她。她的存在反映了前殖民時期他加祿社會以勤儉與誠信為核心的道德體系。

## 神話事蹟

Idiyanale 的神話多半以教訓性敘事保存。最著名的故事是「懶惰的農夫」：從前有一位農夫每日祈禱稻穀豐收卻從不耕作，Idiyanale 以老婦人形象現身，將農夫田中的雜草變為黃金——但黃金無法食用。農夫在饑餓中向 Bathala 哭訴，Bathala 說：「Idiyanale 給你的不是懲罰而是鏡子。你祈求收穫卻不行勞動，如同祈求溪水卻不鑿渠道。」農夫從此勤奮耕作，Idiyanale 便將黃金重新化為真正的稻穀。另一則傳說：Idiyanale 教導婦女編織第一批蕉麻（abacá）纖維。傳說她編織的布料具有隱形能力——只有勤勞的人才能看見；懶惰的人看見的只是一片空白。Idiyanale 也掌管祭祀的正確程序——如果獻祭時心懷不敬或獻祭物不足，她會使祭壇上的食物變為石頭。

## 跨文化對應

| 菲律賓 | 跨文化對應 | 共通點 |
|--------|-----------|--------|
| Idiyanale | ↔ 希臘 Tykhe（Tyche）— 機運與行為之神 | 好行為帶來好運；怠惰召喚衰敗 |
| | ↔ 羅馬 Ops — 收穫女神 | 勞動與農業豐收的神聖化 |
| | ↔ 印度 Annapurna — 食物的女神 | 以勞動與供養來理解神的恩惠 |
| | ↔ 日本大國主（Ōkuninushi）— 農業與醫藥之神 | 勞動、勤奮與教導耕作的倫理價值 |
| | ↔ 義大利 Feronia — 豐收與勞動女神 | 勞動者的守護，怠惰者的警示 |

Idiyanale 的獨特之處在於她是「行為的神格化」而非「領域的神格化」——她代表的不是某種自然力量（雷、雨、日、月），而是人類的倫理行為本身。此特質使她更接近道德概念的人格化（如希臘 Dike／正義、Nemesis／報應），而非傳統的農業神。

## 相關神祇

- **Bathala**（至高神）——Idiyanale 執行其道德意志
- **Dimangan**（收穫之神）——Idiyanale 的配偶
- **Lakapati**（豐饒女神）——Idiyanale 在農業領域的對應神，Lakapati 掌管生殖力，Idiyanale 掌管勞動力
- **Mapulon**（狩獵神）——Idiyanale 之子
