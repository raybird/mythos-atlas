# 瑪麗安·馬基林 (Mariang Makiling)

- **文化：** 菲律賓神話 (Philippine Mythology)
- **別名：** Dayang Makiling（公主馬基林）、Dian Masalanta / Dayang Masalanta（菲律賓前殖民時期原始神名）
- **職掌：** 山靈（diwata）、自然守護者、豐饒與自然之母
- **聖地：** 馬基林山（Mount Makiling，位於菲律賓拉古納省）
- **象徵：** 白色長袍、長黑髮、白蝴蝶

## 概述

瑪麗安·馬基林是菲律賓神話中最廣為人知的 diwata（自然精靈），職掌馬基林山的自然資源與靈性能量。在西班牙殖民前的菲律賓宗教中，她被尊稱為 Dayang Masalanta（或 Dian Masalanta），是一位被祈求以平息洪水、風暴與地震的神靈——這顯示她最初是一位掌管自然力的女神，而非單純的「仙女」或「森林精靈」。

「Mariang Makiling」一名是西班牙語與他加祿語的融合：來自「Maria ng Makiling」（馬基林的瑪麗亞）。西班牙傳教士在殖民時期將原住民原有的「Dayang Makiling」（dayang 為南島語系詞彙，意為公主）改寫為帶有天主教色彩的「Maria」。殖民者試圖將她重新包裝為聖母瑪利亞的在地化身，但民間傳說中保留了她的前基督教根源：她是 Bathala（至高神）派遣至馬基林山協助人類日常生活的 anito（靈體）（Rizal 1890; Barile 1995）。

## 神話事蹟

### 山中的守護者

瑪麗安·馬基林被描繪為一位超自然美麗的女性——身高修長、膚色如陽光般溫暖、黑眸深邃、長髮及膝。她穿著由月光與山霧織成的白色長袍，在林中行走時步履輕盈，連腳下的草葉也不彎折。她掌管山上的所有資源——樹木的果實、溪流中的魚、林間的獵物——並慷慨地提供給山腳下的居民。據說她在風暴過後會親自修補折斷的樹枝、將墜落的雛鳥放回巢中、清理溪流的淤塞（Rizal 1890）。

### 薑變黃金

瑪麗安最著名的故事之一與她幫助窮人的方式有關。貧窮的村民上山向她求助時，她會慷慨地給予生薑。村民帶著薑回家後，驚訝地發現這些薑塊已變成了黃金。在某些版本中，貪婪的村民潛入她的花園查看其他植物是否也是黃金——發現了人類的貪婪後，瑪麗安深受傷害，退往山的高處，她的白色長袍自此與山頂的雲霧融為一體，再也不輕易顯露人間。

### 悲傷的愛情

瑪麗安的愛情故事有多種版本，最廣為流傳的版本與菲律賓國族英雄荷西·黎薩（José Rizal）的改編有關。一位年輕的農夫／獵人偶然進入了瑪麗安的山中王國，兩人墜入愛河。農夫承諾永遠忠誠，每日上山與她相會。但戰爭爆發後，軍隊徵召未婚男子——農夫為了逃避兵役而答應了與凡間女子的包辦婚姻。臨行前他最後一次上山。瑪麗安悲傷地說：「我多希望你曾全心信任我。我可以保護你與你的家人的。」從此消失無蹤。傳說自此之後，再也沒有人見過瑪麗安·馬基林——偶爾有人說在月光明亮的夜晚看到山上有白色身影掠過，但那更可能是山霧與月光交織的幻象（Rizal 1890; Lanuza 2005）。

### 禁忌與信仰

瑪麗安·馬基林在菲律賓民間信仰中至今仍具有實際影響力。以下禁忌至今在馬基林山區仍被認真遵守：
- 可以上山採摘果實當場食用，但**不可攜帶任何果實下山**——違者將在山中迷路，遭受蟲蟻叮咬與荊棘刺痛。唯一的解決方法是丟棄果實並將衣服反穿，以示不再藏匿。
- 若有人在山中失蹤，傳統上認為是瑪麗愛上了此人並將他帶入自己的住處。
- 菲律賓大學洛斯巴尼奧斯校區（位於馬基林山腳）的學生仍流傳著夜間白衣女子攔車的傳說——見到她時不可停車。

## 跨文化對應

| 文化 | 對應神靈 | 共通點 |
|------|---------|--------|
| **菲律賓（邦板牙）** | Mariang Sinukuan（阿拉亞特山） | 同為 diwata / 山靈，守護各自的山脈 |
| **菲律賓（宿霧）** | Maria Cacao（蘭托伊山） | 山靈與可可種植移民史交織 |
| **日本** | Yama-uba（山姥） | 山中的女性自然靈，兼具養育與吞噬的雙面性 |
| **希臘** | 寧芙（Nymphs） | 自然地點的女性守護靈 |
| **斯堪地那維亞** | Huldra | 森林中的美麗女性靈體，引誘人類後消失 |
| **中國** | 山鬼（《楚辭》） | 山中女神，戀愛悲劇、雲霧為衣 |
| **安地斯（印加）** | Pachamama | 大地之母、自然資源的守護者與賜予者 |

## 相關神祇

- **Bathala**（至高神）——派遣 Mariang Makiling 到人間
- **Anitun-Tabu**（風雨女神）——與 Mariang 同為掌管自然力的女性神靈
- **Apolaki**（太陽戰神）——菲律賓萬神殿中的主要男性神祇
- **Bakunawa**（月食 serpent）——菲律賓神話中最著名的神獸
