# 西坦 (Sitan)

- **文化：** 菲律賓神話 (Philippine Mythology)
- **職掌：** 冥界 Kasanaan 之主、亡魂的拘禁者與懲罰者、疾病與邪祟的根源

## 概述

Sitan（亦作 Sitan-sa-Kasanaan）是他加祿（Tagalog）神話中的冥界之神，統治名為 Kasanaan 的地下領域。與米沙鄢神話中較溫和的死亡之神 Sidapa 不同，Sitan 的形象帶有明顯的陰暗面：祂接收亡者的靈魂（kaluluwa），將他們留置於地下，並依生前行為施以懲罰。祂同時被視為疾病、厄運與邪靈的源頭，其麾下有四位著名的「部長」——Manggagaway、Manisilat、Mangkukulam 與 Hukluban——分別掌管道術、欺詐、巫術與衰老，是菲律賓民間信仰中所有病痛與災禍的神格化。

這種「冥界主宰＋疾病之源」的雙重身分，使他加祿宇宙觀呈現出清楚的上下二元：上方是 Bathala 所居的 Kaluwalhatian（天界），下方是 Sitan 的 Kasanaan（冥界），中間則是人類與祖先靈（anito）活動的大地。生與死、健康與疾病，被理解為兩個領域之間的拉鋸。

## 神話事蹟

在西班牙殖民時期留下的他加祿民族誌中，Sitan 被描述為 Bathala 之下掌管死亡與懲罰的神祇。當一個人死去，其 kaluluwa 會離開肉體，被引往 Kasanaan；善者的靈魂得到祖先接納，惡者則落入 Sitan 的看守之下受罰。這種「審判—拘禁」的結構，與 Sidapa 單純「計時取命」的職能形成鮮明對比，也顯示菲律賓群島內部死亡觀的多樣性。

Sitan 的四位部長各有專司：Manggagaway 以幻術使人瘋狂，Manisilat 破壞婚姻與家庭和睦，Mangkukulam 以針刺人偶或焚燒施咒致病，Hukluban 則能使人瞬間衰老。人類生病時，babaylan（薩滿／女祭司）往往必須判斷是哪一位部長作祟，再以獻祭、草藥或祈禱與之協商。這套「疾病即神罰、治療即談判」的邏輯，構成菲律賓傳統醫療儀式的神學基礎。

值得注意的是，部分學者（如 Potet）指出「Sitan」一詞的陰暗化，可能深受西班牙傳教士將本土冥神比附為撒旦（Satan）的影響；即便如此，祂在民間敘事中的功能——看守亡魂、懲治惡行——仍延續了南島語族固有的祖靈與地下世界觀念，而非單純的基督教移植。

## 跨文化對應

| 文化 | 對應神祇 | 共享特徵 |
|------|---------|---------|
| 希臘 | 哈帝斯（Hades） | 冥界之主、拘禁亡魂、不輕易放死者返回陽間 |
| 埃及 | 奧西里斯（Osiris）／阿努比斯（Anubis） | 冥界審判與亡魂看守，但埃及強調死後審判的正義性 |
| 美索不達米亞 | 涅伽爾（Nergal）與埃列什基伽勒（Ereshkigal） | 地下王國的主宰，兼具瘟疫與死亡職能 |
| 印度 | 閻摩（Yama） | 亡者之王、依業力審判，與 Sitan 的懲罰功能最接近 |
| 北歐 | 赫爾（Hel） | 收容非戰死者，冥界界線森嚴 |
| 中國 | 閻羅王／酆都大帝 | 地府審判與刑罰，與 Kasanaan 的懲惡結構平行 |
| 日本 | 伊邪那美（黃泉津大神） | 黃泉之主，死者一旦食其食物便不得返陽 |
| 馬雅 | 西巴爾巴（Xibalba）諸神 | 地下試煉與死亡之神，同屬中美洲—南島的冥界懲罰類型 |

## 相關神祇

- **Bathala：** 至高神，Sitan 的權力來源與天界對應者
- **Sidapa：** 米沙鄢的死亡之神，職能相近但形象較中性
- **Magwayen：** 米沙鄢冥界 Sulad 的靈魂渡者，與 Sitan 同屬冥界體系
- **Manggagaway、Manisilat、Mangkukulam、Hukluban：** Sitan 麾下四位疾病與邪祟之神
- **Apolaki：** 太陽與戰爭之神，象徵天界秩序，與冥界勢力對立

## 出現在

- 他加祿（Tagalog）口傳傳統與西班牙殖民時期民族誌
- 菲律賓民間治療儀式（babaylan 傳承）中對疾病來源的判別
- 現代菲律賓奇幻文學與恐怖影視中「冥界之主」的原型
