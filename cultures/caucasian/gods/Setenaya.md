# Setenaya（賽坦納亞）

- **文化：** 高加索神話（Nart 史詩傳統，Ossetian／Circassian／Abkhaz）
- **職掌：** 納特人的母親、智慧女神、家宅守護者、魔法與預言者

## 概述

Setenaya（奧塞梯語：Сатæна／Sætæna；切爾克斯語：Сэтэнай；阿布哈茲語：Сатанеј）是所有高加索納特（Nart）史詩傳統中最核心的女性角色。她不是一個普通的女性角色——她是所有納特英雄的「母親」，但並非以生育而是以智慧、魔法與社會凝聚者的身分定義了納特人的文明。她同時具備女神與凡人的雙重性質：她能預見未來、施展變形魔法、調解英雄之間的衝突，並掌握著納特人最神聖的器物——「納特人的十二腳鼓」與「納特人的魔法磨坊」。Setenaya 的美貌被形容為足以使太陽短暫失色，她的智慧則被認為是整個高加索山區的最高智識——就連以狡猾聞名的 Syrdon 也承認無法在智慧上勝過她。在奧塞梯 Nartamonga（納特人的宴會）中，Setenaya 擁有男性英雄們都沒有的特權：她可以在男性集會上發言，且她的意見永遠是最終決定。此獨特的性別角色使 Setenaya 成為古代高加索社會中女性權威的罕見神話投射。與其說她是女神，不如說她是「文明之母」——沒有 Setenaya 的智慧，納特人只是一群空有蠻力的戰士。

## 神話事蹟

Setenaya 出現在幾乎所有重要的 Nart 神話中。最著名的是 Sosruko 的誕生：Setenaya 在海邊散步時，一塊被太陽賦予生命的石頭擊中了她的子宮，使她懷孕。她懷了 Sosruko 十個月，但 Sosruko 出生時是一塊燒紅的鐵——Setenaya 必須將他浸入狼奶中七次，才能從鐵塊中分離出人的形體。她的眼淚滴落在鐵上冷卻了他，這就是為什麼 Sosruko 除了膝蓋一處之外全身刀槍不入。第二則核心敘事：Setenaya 的魔法之鏡——她擁有一面可以看到全世界任何角落的銀鏡，所有納特英雄在外征戰時，Setenaya 以此鏡監視他們的安危。當 Batradz 在遠方戰鬥時，Setenaya 從鏡中看見他的劍有裂痕，立即派遣魔法渡鴉送了一把新劍給他。第三，Setenaya 操縱了納特人的淘汰賽——當納特人決定將最弱的成員推下懸崖以減少人口時，Setenaya 設計了多場考驗，使真正有價值的年輕成員脫穎而出，而不是單純以力氣淘汰。她的智慧和遠見確保了納特文明的延續，而非暴力。

## 跨文化對應

| 高加索 | 跨文化對應 | 共通點 |
|--------|-----------|--------|
| Setenaya | ↔ 希臘 Hera 赫拉 | 眾英雄之母，敵視／保護英雄的雙面性 |
| | ↔ 希臘 Athena 雅典娜 | 智慧女神、紡織、戰術、調解英雄爭端 |
| | ↔ 北歐 Frigg 弗麗嘉 | 全知、預言、家宅守護、調解男性衝突 |
| | ↔ 凱爾特 Brigid 布莉姬 | 智慧、詩歌、家庭守護、女性權威 |
| 魔法之鏡 | ↔ 中國《西遊記》照妖鏡 | 觀看遠方真相、辨識偽裝 |
| 鐵中生 Sosruko | ↔ 北歐 Sigurd 以龍血浴身 | 鐵水／龍血賦予刀槍不入的身體 |

Setenaya 與 Frigg 的共通性最深——二者都是「全知的母親」，明知未來的災難卻無法阻止，只能以智慧延緩。不同於希臘雅典娜的「處女戰神」形象，Setenaya 的智慧來自為人母的經驗——她的決策永遠以「納特人的集體存活」為最高考量。

## 相關神祇

- **Sosruko**（鐵骨英雄）——Setenaya 以魔法所生之子，納特勇士的領袖
- **Syrdon**（騙子神）——Setenaya 的對立面，狡猾但缺乏遠見
- **Uastyrdzhi**（戰神）——Setenaya 的盟友，共同守護納特的道德秩序
- **Barastyr**（冥神）——Setenaya 與冥界之間的微妙邊界，她曾以歌聲安撫死者
