# Mardagan（馬爾達甘）— 高加索雷神

- **文化：** 高加索神話 — 納爾特史詩（Caucasian Mythology — Nart Sagas）
- **職掌：** 雷電、暴風雨、天空力量、戰爭

## 概述

Mardagan（奧塞提亞語：Мардаґъан，阿迪蓋語：Мэрдэ）是高加索納爾特史詩中的雷神，掌管雷電與暴風雨。在不同的高加索民族中，他的名字與職能略有差異——奧塞提亞傳統中他被稱為 Mardagan，而在阿迪蓋（切爾克斯）傳統中對應的雷神為 Shyble（Шыблэ）。他是天空力量的化身，每次暴風雨來臨時，人們認為那是 Mardagan 在天上駕駛雷車、擲出閃電。

Mardagan 在納爾特萬神殿中的地位僅次於造物主 Xwycau，但他的職能與 Uastyrdzhi（聖喬治的基督教化前身）有所重疊——在部分版本中，Uastyrdzhi 逐漸吸收了 Mardagan 的雷電功能，使 Mardagan 的形象變得模糊。儘管如此，在最古老的納爾特敘事中，Mardagan 作為獨立的雷神仍然清晰可辨。

## 神話事蹟

### Mardagan 與納爾特人的契約

在納爾特人的黃金時代，Mardagan 與納爾特英雄們訂立了一項神聖契約：納爾特人必須在每次暴風雨時舉行獻祭儀式——以公牛的血潑灑在最高的石碑上。作為回報，Mardagan 以雷電保護納爾特人的牧場免受冰雹與乾旱侵襲。這項契約由 Safa（誓約之神）擔任見證人。

然而，隨著納爾特人日漸傲慢，他們開始忽視這項獻祭。在一次特別猛烈的暴風雨中，納爾特英雄 Batradz 拒絕獻祭，反而向天空揮拳挑釁。Mardagan 憤怒地劈下一道閃電，將 Batradz 的盾牌擊碎——這是納爾特英雄少數無法以武力克服的挫敗。Batradz 最終承認了自己的傲慢，重新舉行獻祭，Mardagan 才平息了怒火。

### Mardagan 的閃電鎚

傳說 Mardagan 擁有一把由 Tlepsh（鐵匠神）鍛造的閃電鎚。每次他揮動這把鎚子，鎚頭撞擊鐵砧時便發出雷聲，從鎚面飛出的火花便是閃電。這把鎚子的造型與功能對應了印度因陀羅的金剛杵（vajra）——兩者都是雷神的標誌性武器，象徵著不可摧毀的力量。在某些版本中，Mardagan 的閃電鎚被放置在一座懸浮在雲端的鐵匠鋪中，由 Tlepsh 定期維護。

## 跨文化對應

| 文化 | 對應神祇 | 共享特徵 |
|------|---------|---------|
| 希臘 |宙斯（Zeus） | 雷電之神、天空之主、以雷霆懲罰傲慢者 |
| 北歐 |索爾（Thor） | 雷神、以錘為武器、保護人類免受巨人威脅 |
| 印度 |因陀羅（Indra） | 雷雨之神、金剛杵（vajra）、與巨蛇/惡龍戰鬥 |
| 斯拉夫 |Perun | 雷電之神、與蛇神 Veles 的永恆對立 |
| 腓尼基 |巴力（Baal） | 雷雨與豐收之神、以閃電武器戰勝海神 |
| 美索不達米亞 |Ishkur/Adad | 雷暴之神、掌管降雨與農業 |

## 相關神祇

- **Xwycau**：造物主，Mardagan 的上级，掌管宇宙秩序
- **Tlepsh**：鐵匠神，為 Mardagan 鍛造閃電鎚
- **Safa**：誓約之神，見證 Mardagan 與納爾特人的契約
- **Uastyrdzhi**：聖喬治的前身，在基督教化後吸收了部分 Mardagan 的雷電功能
- **Donbettyr**：海神，與 Mardagan 構成天（雷）與海（水）的對應

## 出現在
