# Dzerassa（德澤拉莎）

- **文化：** 高加索神話（Nart 史詩傳統，Ossetian／Circassian／Abkhaz）
- **職掌：** 納特人的起源之母、眼淚化河的水之女神、預言者、宴會釀酒者

## 概述

Dzerassa（奧塞梯語：Дзерасса／Dzerassæ；切爾克斯語：Дзэрэщ；阿布哈茲語：Дзырасса）是 Nart 史詩中最具宇宙性意義的女性角色——她是所有納特勇士的「起源之母」。不同於 Setenaya 的「文明之母」角色（以智慧與社會秩序定義），Dzerassa 的母親身份是字面意義上的：納特英雄們是從她的眼淚中誕生的。她是動物之神 Æfsati 的女兒，被囚禁在山頂的水晶塔中。她的美貌被描述為「足以使月亮在夜空中黯然失色」，但她的悲傷同樣深不可測——因為她渴望自由卻永遠無法逃離水晶塔的束縛。她的眼淚從塔頂流下，沿山坡匯聚成七條河流，在每條河的源頭，第一批納特勇士從水花與泡沫中崛起。這一創世敘事賦予了納特人獨特的民族性格：他們是「從悲傷中誕生的戰士」，血液中流淌著眼淚的記憶。Dzerassa 不僅是生物學意義上的母親——她還掌握著納特人最重要的社交儀式：釀造薩諾（sanon，一種發酵蜂蜜酒），並在宴會中擔任主祭。在納特人的等級制度中，Dzerassa 的地位僅次於 Satana（賽坦納亞），但她代表了一種更原始、更接近大地的力量——水、淚、酒的三重象徵。

## 神話事蹟

### 水晶塔中的囚徒

Dzerassa 的父親 Æfsati 將她囚禁在山頂的水晶塔中，因為她的美貌引來了太多追求者——從凡人戰士到半神英雄，無一不為之瘋狂。水晶塔的牆壁透明如空氣，Dzerassa 可以看到外面的世界卻無法觸及。她日夜不休地哭泣，眼淚沿塔壁流下，滲入岩石縫隙，匯聚成七條河流。每當月圓之夜，河水會散發銀色的光芒——這是 Dzerassa 的眼淚在月光下的折射。

### 納特人的誕生

七條河流的源頭成為了納特人的搖籃。第一批納特英雄從水花中站起：Sosruko（從河底的石頭中崛起）、Batradz（從沸騰的瀑布中浮現）、Uryzmag（從最深的漩渦中浮出）。他們的手中有劍——從河床的礦石中自然形成；他們的胯下有戰馬——從水霧中凝結而成。納特人從此知道自己是「水之子」，他們的血管中流動的不是普通的血，而是 Dzerassa 的眼淚。這也解釋了為什麼納特人在戰鬥後會不由自主地流淚——那不是懦弱，而是他們的起源記憶在呼喚。

### 與 Sosruko 的禁忌之戀

最著名的 Dzerassa 故事是 Sosruko 對她的追求。Sosruko 愛上了 Dzerassa——雖然從血緣上來說，她是他的「母親」（從她的眼淚中誕生了他）。Sosruko 擊敗了看守水晶塔的七頭巨人，爬上塔頂見到 Dzerassa。但 Æfsati 以神聖的狩獵法則阻止了他們的結合——「孩子不能追求母親，即使她是眼淚中的母親。」在另一版本中，Dzerassa 最終被釋放，嫁給了納特的智者 Uryzmag，成為納特社會中最受尊敬的女性。她為 Uryzmag 生下了後代，延續了納特人的血脈。

### 薩諾的釀造

Dzerassa 掌握著納特人最重要的釀酒秘方——薩諾（sanon），一種以蜂蜜、水與神聖草藥發酵而成的飲料。薩諾不僅是宴會的飲品，更是納特人用來測試勇氣與真誠的聖物：真正的英雄飲下薩諾後會獲得力量與預言能力，而懦夫或說謊者飲下後會立即嘔吐或陷入昏迷。Dzerassa 在每次大鍋 Nartyamonga 的宴會前都會親手釀造薩諾，她的釀酒儀式被視為與神靈溝通的神聖行為。

## 跨文化對應

| 高加索 | 跨文化對應 | 共通點 |
|--------|-----------|--------|
| Dzerassa 眼淚化河 | ↔ 希臘 Daphne 化為月桂 | 美女因悲傷或恐懼而轉化為自然元素 |
| Dzerassa 水晶塔囚禁 | ↔ 希臘 Danaë 金雨囚禁 | 美女被父親囚禁，因神聖力量而懷孕 |
| Dzerassa 七河創世 | ↔ 埃及 Hapi 尼羅河泛濫 | 水流帶來豐饒與生命 |
| Dzerassa 眼淚生英雄 | ↔ 印度 Purusha 祭祀化身 | 牺牲或苦難產生人類/英雄 |
| Dzerassa 釀造聖酒 | ↔ 凱爾特 Brigid 聖泉 | 女性神聖釀造者/水之守護者 |
| Dzerassa 水之母 | ↔ 日本 Amaterasu 太陽女神 | 至高女性力量與自然力量的結合 |

Dzerassa 與 Danaë 的平行最為深刻——二者都是被囚禁的美女，都因超自然力量而成為母親。但 Dzerassa 的「囚禁」是宇宙性的（她是納特人起源的必要條件），而 Danaë 的囚禁是政治性的。Dzerassa 與 Hapi 的水之聯繫也很重要——兩者都代表了水帶來生命的宇宙原則。

## 相關神祇

- **Æfsati**（艾弗薩提）——Dzerassa 的父親，動物之神與狩獵之主
- **Uryzmag**（烏里茲馬格）——Dzerassa 的丈夫，納特人的智者與領袖
- **Sosruko**（索斯魯科）——從 Dzerassa 眼淚中誕生的最偉大英雄
- **Batradz**（巴特拉茲）——從 Dzerassa 眼淚中誕生的鋼鐵戰士
- **Satana**（賽坦納亞）——Dzerassa 的繼任者，納特社會的最高女性權威
