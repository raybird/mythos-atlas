# Dyela — 車臣-印古什的太陽天神

- **文化：** 高加索神話 (Caucasian Mythology)
- **族群：** 車臣人 (Chechen / Nokhchi)、印古什人 (Ingush / Ghalghaj)
- **職掌：** 太陽、天空、至高神、宇宙秩序

## 概述

Dyela（車臣語：Дела）是車臣與印古什傳統信仰中的至高天神，也是太陽與天空的主宰。在瓦伊納赫（Vainakh）神系中，Dyela 被視為宇宙的創造者與秩序維持者，擁有對人類命運的最終裁決權。與許多高加索神話中的至高神相似，Dyela 具有退隱（deus otiosus）的特徵——祂創造世界後，將具體的日常管理交由次級神靈（如風暴神 Sela、雷電神 Pkharmat 等）代理。瓦伊納赫人相信 Dyela 居住在天界最高處的白色宮殿中，每日乘坐金車穿越天空（Jaimoukha 2005: 105-110）。

## 神話事蹟

根據瓦伊納赫創世神話，Dyela 首先創造了天空、大地與海洋。天地最初太過接近，Dyela 命令風暴神 Sela 將天空向上推開，才有了今日的空間。人類是由 Dyela 用泥土塑造而成，但祂將靈魂吹入人類身體時，不小心賦予了人類過多的智慧——這導致人類開始挑戰神的權威。

其中最著名的故事是英雄 Pkharmat（車臣版的普羅米修斯）像 Prometheus 一樣偷取了 Dyela 的火焰（一說為太陽的光芒）贈予人類，使人類得以在寒冷中存活。Dyela 震怒之下將 Pkharmat 鎖在高加索山脈的 Kazbek 峰上，令巨鷹啄食其肝臟——這一神話與希臘普羅米修斯故事的高度相似性，引起了比較神話學家對古代高加索-希臘文化接觸的長期討論（Colarusso 2002: 58-65; Jaimoukha 2005: 112-115）。

在民間信仰中，Dyela 也掌管道德與法律。發假誓者會被 Dyela 以雷電擊斃；殺人者的土地會受到 Dyela 的詛咒，寸草不生。瓦伊納赫人在春分與秋分時節舉行祭祀 Dyela 的儀式，以白公羊為犧牲，祈求豐收與公正。

Dyela 的形象在伊斯蘭化後的車臣文化中發生了轉變：傳統的 Dyela 信仰與伊斯蘭教的安拉概念逐漸融合，但許多原有的太陽崇拜元素（如向東方的祈禱、以日出為神聖時刻）被保留在車臣的蘇菲派伊斯蘭實踐中。

## 跨文化對應

| 文化 | 對應神靈／概念 | 共通點 |
|------|-------------|-------|
| 希臘 | 宙斯 | 至高神、雷電、人類創造者 |
| 北歐 | 奧丁 | 至高天空之神、退隱特徵 |
| 中國 | 昊天上帝 | 至高天神、道德與自然秩序 |
| 波斯 | 阿胡拉·馬茲達 | 創造、秩序、善的原則，至高無上 |
| 埃及 | 拉（Ra） | 太陽神、創造者、金車橫越天空 |
| 印度 | 因陀羅／伐樓那 | 天空秩序、道德約束、無所不見 |
| 西伯利亞 | 騰格里（Tengri） | 藍天之神，至高主宰，不直接干預 |

## 相關神祇

- **Sela**：風暴與雷電之神，Dyela 的代理人
- **Pkharmat**：文化英雄，盜火者（高加索版普羅米修斯）
- **Mäkkä** / **Mekk**：部分瓦伊納赫傳統中與 Dyela 並列的神聖存在
- **Mintsa**：大地女神，與 Dyela 共同管理世界
