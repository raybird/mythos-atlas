# 拿特人的金蘋果樹——青春之果與孤獨的守望者

## 故事背景

在高加索拿特（Nart）史詩中，金蘋果樹是一個反覆出現的核心象徵——它代表著青春、不死與豐饒，但同時也是災禍的根源。這則故事在切爾克斯（Adyghe）、阿布哈茲、奧塞梯、車臣等拿特傳統中各有不同版本，但其核心敘事一致：拿特人需要金蘋果來恢復青春，但蘋果樹由巨龍或女巫（有時是七頭巨人）守護，只有最勇敢的英雄才能取得。

## 情節

在拿特的黃金時代，世界中央生長著一棵巨大的蘋果樹，其枝葉觸及天空、根部深入冥界。每當月圓之夜，樹上會結出三顆金蘋果——凡食之者，不論多麼蒼老，都能恢復青春力量。這棵樹由一位名為「Thaghalij」的七頭巨靈（或一位名為「Lady of the Tree」的巫婆）守護。

拿特人中最年長的首領——已衰老至無法騎馬的戰士——向聚會提出請求：「誰能為我取來金蘋果？」年輕的戰士們一個接一個出發，但無一歸來。他們全數被守樹者的目光化為石像，或被困於樹根的迷宮之中。

最後，年幼的拿特英雄阿沙梅茲（Ashaméz / Atshamaz）——一位以笛聲動人的年輕戰士——自願出發。他不是帶著刀劍，而是帶著他的蘆笛。他來到蘋果樹前，沒有與守護者戰鬥，而是坐在樹下吹起了笛子。笛聲如此悲傷而美麗，以至於守護者的七顆頭顱全部哭泣不止，七雙眼睛全部閉上沉睡。阿沙梅茲摘下三顆金蘋果，帶回拿特村莊。

然而，蘋果的奇蹟卻帶來了新的問題。老首領恢復青春後不願將權力讓給年輕人，而吃了蘋果的戰士們變得驕傲自大。拿特人因為金蘋果而陷入了內戰。智慧的拿特女智者莎塔娜（Satana）勸說：「永遠年輕並不是祝福——這讓我們忘記了死亡是生命的必要部分。」於是她將最後一顆金蘋果的種子埋在土中，讓樹木轉化為凡間普通的果園，從此金蘋果不再出現於人間（Colarusso 2002: 215-225; Dumézil 1930: 145-150）。

## 跨文化平行

| 文化 | 對應故事 | 相似之處 |
|------|---------|---------|
| 希臘 | 赫斯珀里得斯的金蘋果 | 巨龍拉冬守護的金蘋果樹，赫拉克勒斯偷取 |
| 北歐 | 伊登的青春蘋果 | 青春女神伊登保管的金蘋果，眾神靠其維持不老 |
| 凱爾特 | 阿瓦隆的青春蘋果 | 蘋果島（Avalon）上的不死與治療果實 |
| 中國 | 王母娘娘的蟠桃 | 三千年結果一次的蟠桃，食之長生不老 |
| 印度 | 如意果（Kalpavriksha） | 滿足一切願望的神樹 |
| 波斯 | 豪馬（Haoma）植物 | 給予永生的神聖植物 |
