# 維納莫寧的圖奧內拉之行：三句咒語、冥河羅網與蛇形逃脫（Väinämöinen in Tuonela）

- **文化：** 芬蘭—烏戈爾神話（Finno-Ugric，芬蘭）
- **來源：** 埃利亞斯·隆恩羅特（Elias Lönnrot）編《卡勒瓦拉》（Kalevala）第十六歌〈維納莫寧在圖奧內拉〉；Kirby 1907、Friberg 1988 英譯本
- **角色：** 維納莫寧（Väinämöinen）、桑普薩·佩勒沃伊寧（Sampsa Pellervoinen）、圖奧內塔爾（Tuonetar，圖奧尼之女）、圖奧尼之子（彎指者）
- **地點：** 圖奧內拉（Tuonela）／瑪納（Manala）之國、圖奧尼河與水中岩石

## 故事背景

《卡勒瓦拉》第十六歌是史詩中最陰暗的一段「冥界遊記」。在此之前，維納莫寧已參與創世、戰勝尤卡海寧、迎娶艾諾、鍛造 Sampo，幾乎無所不能；然而在此歌中，他卻被一個極小的缺口難住——造船只差**三句咒語**（sanat，意為「詞語」）。他請桑普薩·佩勒沃伊寧找來橡木，連續吟唱三天造船，龍骨、船舷與船首皆已成形，唯獨最後三詞無論如何想不起來。人間的詞語他都試遍：以馴鹿鋪滿田野、以松鼠堆滿長凳換來的詞語全無用處。於是這位不朽的吟唱者做出一個悖理性的決定——到死者之國去「收集詞語」。他不是為求不死藥，也不是為救回摯愛，而是為了補齊一項技術的最後零件。此歌與緊接的第十七歌形成鮮明對照：在圖奧內拉，他一無所獲、狼狽逃回；在巨人安特羅·維普寧的腹中，他才真正取得魔詞。兩條路徑合起來，構成芬蘭神話對「知識必須跨越死亡邊界」的雙重陳述。

## 情節

### 缺三句咒語的船

維納莫寧感嘆自己找不到所需的詞，遂想到「圖奧尼的幽暗居所、瑪納的永恆家園」必有成百的詞語可資取用。他徒步前往：第一週穿過灌木叢，第二週穿過花楸林，第三週穿過杜松林，終於抵達瑪納的可怕島嶼與圖奧尼的閃耀山丘。在圖奧內拉的深河岸邊，他放聲呼喊：「圖奧尼的女兒，送船來；瑪納的孩子，划我過去！」正在黑色河水中洗衣、捶打衣裳的矮小女子抬頭應話——她正是圖奧尼之女圖奧內塔爾（亦稱 Manalatar）。她不接受含糊的請求，先立下審查：既然疾病未曾征服你，死亡未曾制伏你，也無其他命運逼迫你，究竟為何前來？

### 渡口的四重謊言與身體證據

維納莫寧先後編了四個理由，每一個都被女子以可見的身體記號當場拆穿。他說「是圖奧尼把我帶來、瑪納把我從故鄉拖來」，她反駁：若真如此，圖奧尼本人該與你同行，肩上該有圖奧尼的帽子，手上該有瑪納的手套。他改稱「是鐵把我帶到瑪納、鋼把我拖到圖奧內拉」，她說：若真如此，你的衣裳該滴血。他再說「是水把我帶到瑪納、波浪把我送到圖奧內拉」，她追問衣服何以未濕。他最後說「是火把我帶到圖奧內拉、火焰把我送到瑪納」，她指出頭髮與鬍鬚毫無燒焦痕跡。連續四次否證之後，他終於坦白：造船時缺三句詞，雪橇的鑽孔需要圖奧尼的錐子，故來冥界求取。這段問答把「說謊」與「身體證據」並置——冥界的守門者不以邏輯辯難，而以痕跡判真偽。女子痛斥他愚蠢，勸他趁早回頭，因為「許多人來到這裡，極少人回到原處」；但還是把船划了過來，並在渡河時預言：「你活著來到瑪納，不死地踏入圖奧內拉，真是可悲。」

### 青蛙與蚯蚓的啤酒

上岸後，圖奧內拉的女主人端來一缸啤酒，雙手捧著請他飲用。維納莫寧向缸內細看，見青蛙在其中繁殖、蚯蚓在缸壁蠕動，立即拒絕：「我不是為了喝瑪納的杯子、圖奧尼的酒缸而來；凡飲此酒者必醉，必死於此。」女主人再問一次來意，他如實陳述缺三句造船咒語的困境。她的回答等同死刑判決：圖奧尼永不會給你那些詞，瑪納永不會教你咒語；只要你還活著，就永遠離不開此地，永遠回不了家。在此，冥界的「宴席」不是款待而是歸屬儀式——吃喝即承認死者國度的管轄，拒飲則是拒絕被死亡收編。

### 鐵床、沉睡與百張羅網

他被安置在圖奧尼的床榻上，疲憊地沉沉睡去；醒來時已成為人質。冥界之中住著一名紡織老嫗，她紡鐵線、拉銅絲，在一個夏夜裡於水中岩石上織成百張網；另有一名三指巫師，在同一夜、同一石上織出鐵網與銅網共計千百張。圖奧尼的兒子手指彎曲、硬如鋼鐵，取過這些網，橫向、縱向又斜向地張設在圖奧尼河上，使維納莫寧終身不能再逃——只要金色月亮仍舊照耀，便無間隙可乘。網在此是「死亡的技術」：由冥界工匠以金屬的材料、在一夜之間完成的嚴密秩序，專為捕捉活人而設。

### 化身水獺與鐵蛇

維納莫寧沒有以咒語或蠻力對抗，而是先問自己是否注定毀滅於此，隨即**變形**：像水獺般滑入蘆葦叢，像鐵蛇般扭動身軀，像小蝮蛇般急促游動，橫越圖奧尼河，安然穿過圖奧尼的層層網目。次日清晨，彎指之子前去巡視網具，網中捕得百條紅點鮭與數千尾小魚，唯獨不見維納莫寧、不見那位老烏萬托拉伊寧（Uvantolainen，維納莫寧的別名）。逃跑成功後，他向後世留下雙重警告：其一，任何人都不可前往瑪納、進入圖奧尼之國；其二，不可對無辜者行惡，否則必在圖奧尼的幽暗居所受到報應——那裡的罪人躺在燒紅的石下、灼熱的石板下，身蓋毒蛇之被。他帶回人間的並非夢寐以求的三句咒語，而是一篇「不可前往」的冥界見聞。

## 故事分析

### 為「詞語」而下的冥界：技術缺口與死者檔案

本歌最獨特之處，是將語言設為可攜帶、可匱乏、可偷取的技術物件。造船的一切材料都已備齊，唯三句「詞」缺席——文明工程的完成取決於話語。維納莫寧向死者求詞，等於把冥界設為一座檔案館：亡者掌握起源的知識，因為他們已穿越界線。有趣的是這次收穫為零，真正的三詞要在下一歌由巨人維普寧吐出；兩條取徑的失敗與成功共同說明，死者之國提供的是「知識的匱乏感」，而巨人（象徵大地本身）才是知識的源頭。

### 渡口審查：以痕跡驗證身份的否定邏輯

守門女子的四次反駁都採取同一形式：若你的說法為真，你的身體就該留下某種痕跡——帽子、手套、血、濕衣、焦髮。這是「否定證明」的修辭：她不提出正面證據，而是指出缺憾。此一結構把冥界描寫成不容許身分含混的空間；在這裡，語言可以被拆穿，身體不會說謊。維納莫寧最終承認「我確實說了些謊」，才獲得渡船——真相是通行證，而非力量。

### 拒飲與變形：兩種身體政治

青蛙與蚯蚓的啤酒將「死者的食物」具體化為腐生生物，拒飲即拒絕與冥界建立互惠關係；這與珀耳塞福涅的石榴形成強烈對比。逃亡則採取相反策略：他不強化人的身體，而放棄人的形體，化為水獺、鐵蛇與小蝮蛇，才能穿過專為人設計的金屬網。手工編織的網代表死亡的秩序化，動物變形代表生命的流動性——兩者較量，後者獲勝。

### 歸來的見證者：冥界遊記作為警示文體

維納莫寧回到人間後沒有說「我得到了什麼」，而是說「你們千萬別去」。冥界之旅的產物因此是敘事與禁令，而非寶物；他成為一位見證者，把恐怖的所見轉譯為倫理誡命（勿害無辜）。這與《吉爾伽美什史詩》中恩基杜的冥界報告、但丁《神曲》的地獄遊記共享同一文體邏輯：活人短暫跨越死界，唯一能帶回的是「如何不再跨越」的知識。

## 跨文化對應

| 芬蘭—烏戈爾《卡勒瓦拉》第十六歌 | 對應故事／文本 | 共通點 |
|------|------|------|
| 為造船缺三句咒語而赴冥界 | 美索不達米亞《吉爾伽美什史詩》第十二泥版：恩基杜自冥界歸返述所見 | 活人為匱缺的知識下界，帶回見聞而非寶物 |
| 圖奧尼之女在渡口追問動機、拆穿四謊 | 希臘神話卡戎（Charon）渡冥河前的身分查驗；埃及《亡靈書》「消極懺悔」 | 渡河者須通過質問，虛假陳述將被揭穿 |
| 青蛙與蚯蚓的啤酒、拒飲 | 珀耳塞福涅食石榴；希臘神話食蓮者（Lotophagi） | 食飲死者之地物即被該國度收編 |
| 被置於圖奧尼床榻、沉睡遭擒 | 北歐神話赫爾莫德（Hermóðr）馳赴海爾之家為巴德爾求返 | 活人踏入死者領域即受「主人」管轄 |
| 三指巫師與老嫗一夜織成百張鐵銅網 | 希臘神話赫菲斯托斯（Hephaestus）的無形羅網；北歐命運女神的命網 | 網作為不可掙脫的命運與捕獲技術 |
| 化為水獺、鐵蛇、小蝮蛇穿網而逃 | 日本伊邪那岐自黃泉逃歸、以巨石堵塞黃泉比良坂；西伯利亞薩滿化獸潜行 | 以變形或機智逃離冥界的追捕 |
| 彎指之子清晨收網只見魚群 | 因紐特與西伯利亞漁獵傳說中「網中無人」的追失情節 | 冥界獵者與人間英雄的捕捉與失落互換 |
| 返國後告誡後人勿往圖奧尼 | 但丁《神曲·地獄篇》遊歷後返世敘述；基督教「降入地獄」傳統 | 冥界見聞轉化為道德訓誡的見證文體 |
| 欲取圖奧尼的錐子以完成歌船 | 玻里尼西亞毛利神話 Maui 取火；希臘普羅米修斯盜火 | 文化英雄自超自然取得文明的關鍵技術 |
| 灼熱石板與毒蛇被褥的罪人居所 | 佛教八熱地獄；希臘塔耳塔洛斯（Tartarus） | 死後世界的刑罰地景與倫理威懾 |

上述對應顯示三個深層結構。第一，**「渡河—問答—宴飲—逃逸」是一段可跨文化移動的儀式序列**：幾乎每個傳統都把冥界寫成須經關卡、回答問題、面臨食物試探的空間；差異只在於誰把關、吃什麼、能否回頭。第二，**芬蘭版本的「拒食」比「取物」更為核心**：維納莫寧既沒拿到咒語，也沒嚐冥界的酒，他的成功僅在於保持自身邊界完整——這與強調「帶回寶物」的吉爾伽美什或赫拉克勒斯大異其趣。第三，**變形逃生把薩滿技術推到前台**：穿網的不是英雄的力氣，而是化身動物的能力；這使本歌與西伯利亞、愛努的熊祭與薩滿入門傳統相近，也與同文化《卡勒維波格》靠蠻力衝破鐵橋的地獄行形成方法論上的對比。

若再與本文化其他兩則冥界故事並讀，差異更為清晰：萊明凱寧赴圖奧內拉射天鵝，靠的是箭術卻遭暗算身亡，須由母親撿骨縫合才得復生；卡勒維波格則以肉身踏破地獄鐵橋、辨識力量與虛弱之水。維納莫寧既不行獵，也不戰鬥，他靠說謊、拒飲與變形——三種「柔性」策略使這則故事成為《卡勒瓦拉》中最細膩的冥界敘事。
