# 坎特雷的誕生：巨梭魚的琴 (Kanteleen Synty: Haugin Hampaat)

- **文化：** 芬蘭神話 (Finnish Mythology)／芬蘭-烏戈爾神話 (Finno-Ugric Mythology)

## 故事背景

坎特雷（kantele）是芬蘭最古老的弦樂器——一種撥弦琴，被視為擁有超自然力量的神器。傳說中第一把坎特雷是由永恆的智者維納莫伊寧（Väinämöinen）以巨梭魚（hauki）的頜骨製成。此故事收錄於《卡勒瓦拉》（Kalevala）第四十章至第四十二章，是史詩中最優美也最具宇宙論意義的段落之一。

## 情節

### 第一幕：尋找造船的木料

維納莫伊寧與鐵匠薩姆波·伊爾馬里寧（Seppo Ilmarinen）以及一群戰士為前往波赫尤拉（Pohjola，北地）奪回桑波魔法磨（Sampo），需要一艘堅固的船。維納莫伊寧來到海邊，以斧頭砍伐船用木材，卻在砍倒一棵巨松時不慎傷到了膝蓋。

年輕的戰士勒明蓋寧（Lemminkäinen）誓言能為他止血，但維納莫伊寧拒絕了他的幫助，轉而以咒語止血——但傷口已經感染發炎。他前往拉普蘭尋找巫師，發現沒有任何草藥能醫治他的傷。最終維納莫伊寧回到卡勒瓦拉，以創世神話級別的咒語——回憶鐵的起源——才終於使傷口癒合。

### 第二幕：巨梭魚的浮現

船造好後，維納莫伊寧、伊爾馬里寧與勒明蓋寧率眾出海前往波赫尤拉。航行了三天三夜後，他們的船突然無法前進——彷彿撞上了一個水中的巨物。戰士們往水中窺視，發現一條前所未有的巨型梭魚環繞在船底，牠的長度超過船身的三倍，鱗片閃爍如北極光。梭魚張開巨口想吞噬船隻。

維納莫伊寧抽出寶劍，躍入水中與巨梭魚搏鬥。經過一場史詩級的戰鬥——海水翻騰如沸、波浪高如山丘——維納莫伊寧最終以智慧而非蠻力取勝：他唱起催眠的咒語，使巨梭魚陷入沉睡，然後一劍刺入梭魚的腹部。巨梭魚死後沉入海中，維納莫伊寧將牠拖到沙灘上。

### 第三幕：第一把坎特雷

人們宰殺梭魚，分部食用，伊爾馬里寧問維納莫伊寧梭魚的骨頭應如何處理。維納莫伊寧仔細端詳巨梭魚的頜骨——彎曲如弓、堅硬如鐵，上有天然的細溝。他突然頓悟：這將是一把樂器！他將梭魚的頜骨雕刻為琴身，以牠的脊骨磨製為琴栓，以馬尾的鬃毛（一說梭魚的鰭刺）為弦。於是世界的第一把坎特雷誕生了。

### 第四幕：萬物因音樂而泣

維納莫伊寧調好琴弦，開始彈奏。坎特雷的聲音傳遍了陸地與海洋——森林中的熊走出洞穴、水中的魚躍出水面、天上的鳥兒停止飛行、樹木彎下枝椏聆聽。所有聽見琴聲的生物都流下了眼淚——不是悲傷，而是超越語言的感動。

更神奇的是，維納莫伊寧的眼淚滴入大海，化為海中的寶石——芬蘭民間傳說中說，波羅的海的琥珀就是維納莫伊寧的第一滴眼淚。坎特雷被放置在卡勒瓦拉最高的杉樹上，讓風吹過琴弦時繼續歌唱。從此芬蘭人的心中永遠有一條琴弦，連接著悲傷與美。

## 跨文化平行

| 芬蘭元素 | 跨文化平行 |
|---------|-----------|
| 以動物骨頭製作第一把樂器 | ↔ 希臘赫爾墨斯以龜殼造里拉琴 |
| | ↔ 中國女媧製笙簧 |
| | ↔ 西伯利亞薩滿鼓以鹿皮覆框 |
| 音樂使萬物流淚 | ↔ 印度黑天（Krishna）的笛聲使牧女流淚 |
| | ↔ 希臘奧菲斯的琴聲使石頭與樹木流淚 |
| 以咒語催眠巨魚 | ↔ 希臘奧菲斯的歌聲催眠守衛犬刻耳柏洛斯 |
| 神的眼淚化為自然資源 | ↔ 波羅的海撒烏萊的眼淚化為琥珀 |
| 樂器擁有超自然力量 | ↔ 北歐奧丁的魔法；達基亞的聖鼓 |

坎特雷誕生神話最值得注意的是它將「音樂的起源」與「漁獵的日常」直接連結——不同於希臘赫爾墨斯以龜殼造琴的神聖偷竊故事，維納莫伊寧以每日可見的梭魚骨造琴，將音樂扎根於芬蘭湖泊的自然生態中，使坎特雷成為湖泊文明的神聖心臟。
