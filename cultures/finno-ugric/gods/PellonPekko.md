# Pellon Pekko（佩爾沃·佩科）

- **文化：** 芬蘭-烏戈爾神話 (Finno-Ugric Mythology)
- **職掌：** 大麥、穀物、啤酒、豐收與農耕

## 概述

Pellon Pekko 是芬蘭-烏戈爾神話中的穀物與啤酒之神，掌管大麥的生長、啤酒的釀造與農田的豐收。「Pellon Pekko」字面義為「田野的佩科」（Pekko of the field），他是芬蘭農業信仰中最鮮為人知卻最受農民倚賴的神祇之一。在芬蘭、卡累利阿與英格里亞（Ingria）的民間傳統中，Pekko 是唯一以「個人化神祇」身分出現在穀物咒語中的農業神——每當春季播種、夏季祈求好天氣、秋季收割之際，農民便吟唱祈禱文呼喚 Pekko。他的主要象徵物是大麥穗與盛滿啤酒的木杯。芬蘭北部與東部地區每逢夏至前後會舉行「Pekko 的祭宴」（Pekon juhla），以新釀啤酒獻祭並祈求大麥茁壯。

## 神話事蹟

### 與 Ukko 的分工

Pekko 與天空之神 Ukko 之間存在明確的「神聖分工」：Ukko 掌管天氣——雷電、雨水與雲層；Pekko 則掌管土地的收成——大麥發芽、穀穗飽滿與釀酒所需的酵母。傳統咒語中常將二者並列呼喚：「Ukko 開天降雨、Pekko 讓大麥結穗」。有些口傳版本描述 Ukko 將天上的酒甕傾倒成雨，Pekko 則在田間承接這「天酒」使其化為大麥。這種分工反映芬蘭農民對「天氣」與「土壤」兩大農業要素的神話化分類。

### 大麥與啤酒的起源

Pekko 傳說中最重要的主題是「啤酒的起源」。在卡累利阿的咒語傳統中，Pekko 是第一位懂得以大麥釀造啤酒的存在——他將大麥芽搗碎、以樺木桶發酵，釀出「永不枯竭的啤酒」。民間故事更將啤酒的「泡沫」擬人化為 Pekko 的化身——泡沫被描述為「Pekko 的鬍鬚」，因此倒啤酒時若泡沫過多，會被戲稱「Pekko 在笑」。芬蘭諺語「沒有 Pekko 就沒有啤酒」（Ei Pekkoa, ei olutta）流傳至今，顯示 Pekko 在芬蘭飲酒文化中的核心地位。

### 田野的保護者

Pekko 也被視為農田與牧場的守護者——他保護穀物免受霜害、蟲害與巫術的侵襲。芬蘭農民相信，若在田角埋下一塊麵包並呼喚 Pekko 之名，田野便能免受邪靈破壞。播種時農民會將最後一把種子留在田埂上「獻給 Pekko」，以確保來年豐收。這種「保留最後一把穀物」的習俗，與世界各地的穀物精靈信仰高度呼應——從歐洲的「穀物靈」（Corn Spirit）到東亞的稻靈信仰皆然。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 希臘神話 | Demeter（穀物女神） | 穀物豐收、土地生育 |
| 希臘神話 | Dionysus（酒神） | 發酵、釀造、歡宴 |
| 埃及神話 | Osiris（重生與穀物之神） | 穀物死而復生、農業週期 |
| 美索不達米亞 | Ninkasi（啤酒女神） | 釀造啤酒的守護神 |
| 羅馬神話 | Ceres（穀物女神） | 農田豐收、穀物崇拜 |
| 日耳曼神話 | Byggvir（大麥之神） | 大麥與釀造、弗雷侍從 |

## 相關神祇

- **Ukko**（天空之神）——掌管天氣降雨，與 Pekko 分工合作確保豐收
- **Akka**（地母神）——大地之母，與 Pekko 共同掌管土地生育力
- **Väinämöinen**（吟唱智者）——傳說中向 Pekko 學習釀酒咒語的智慧老者
- **Hiisi**（惡靈）——Pekko 保護田野抵禦的邪惡存在
