# Vellamo（維拉莫）

- **文化：** 芬蘭-烏戈爾神話 (Finno-Ugric Mythology)
- **職掌：** 海洋女神、天氣與風暴的掌控者、水界之母

## 概述

Vellamo（芬蘭語：Vellamo，又作 Wellamo）是芬蘭神話中的海洋女神與天氣之母，海神 Ahti（阿赫蒂）之妻。她居住在波赫尤拉（Pohjola）北方的深海之中，統治著一切水域——從波羅的海的冰冷波濤到芬蘭內陸數以萬計的湖泊。Vellamo 的名字可能源自芬蘭語「velloa」（沸騰、翻湧），象徵海洋的不安定力量。在卡累利阿（Karelia）的民間信仰中，Vellamo 不僅是海的象徵，更是女性水域力量的化身——她的長髮由海藻編成，身上披著由海浪泡沫織成的斗篷。每逢漁民出海前，必須向 Ahti 與 Vellamo 同時祈禱，否則將一無所獲。Vellamo 也與天氣密切相關——她能掀起海嘯、召喚暴風雪，也能平息風浪使船隻安全歸航。

## 神話事蹟

在《卡勒瓦拉》（Kalevala）中，Vellamo 最突出的角色出現在 Lemminkäinen（萊明凱寧）的冒险故事中。當 Lemminkäinen 為追求 Louhi 的女兒而遠征波赫尤拉時，他必須穿越 Vellamo 統治的危險海域。Vellamo 在某些版本中被描繪為波赫尤拉女主人 Louhi 的盟友，以狂風巨浪阻撓入侵者。然而，在另一些口傳版本中，Vellamo 展現出慈悲的一面——她拯救了 Lemminkäinen 溺水的身體，將其送回岸邊，最終由 Lemminkäinen 的母親以魔法使其復活。

Vellamo 的另一個重要神話功能是「天氣預兆」。在芬蘭民間傳說中，Vellamo 在海底梳理她的長髮——頭髮的方向預示著暴風雨的來臨。當她的長髮向南飄動，漁民知道暴風即將到來，必須立即返航。這一母題在芬蘭 coastal community（沿海社群）中流傳數千年，至今仍有漁民以「Vellamo 的頭髮」來形容海面的風向變化。Vellamo 也以「海之母」的角色出現在婚禮祈禱中——卡累利阿新娘在婚禮前會向 Vellamo 祈求婚姻幸福與子孫繁盛，因為海洋在芬蘭文化中同時象徵生育力與無盡的生命力。

## 跨文化對應

| 文化 | 對應角色 | 共通點 |
|------|----------|--------|
| 北歐神話 | Ran（蘭）——海上女神 | 統治海洋、以網捕人 |
| 希臘神話 | Amphitrite（安菲特里忒）——海后 | 海神之妻、平靜海洋 |
| 埃及神話 | Tefnut（泰芙努特）——濕氣女神 | 水界女性力量 |
| 日本神話 | 綿津見（Wadatsumi）——海神 | 海洋統治者、漁業守護 |
| 美索不達米亞 | Tiamat（提亞瑪特）——原初海洋 | 混沌海洋、原始力量 |
| 印度神話 | Varuna（伐樓拿）——水域之主 | 海洋統治、道德秩序 |

## 相關神祇

- **Ahti（阿赫蒂）**——丈夫，海神與水中萬物之主
- **Tapio（塔皮奧）**——森林之王（與 Vellamo 共同構成芬蘭自然的二元對應：森林與海洋）
- **Louhi（洛烏希）**——波赫尤拉女主人（在某些版本中為 Vellamo 的敵對者）
- **Ukko（烏科）**——天空之神（Vellamo 的天氣功能與 Ukko 的雷暴相互交織）
