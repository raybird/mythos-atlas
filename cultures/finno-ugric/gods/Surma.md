# 蘇爾瑪 (Surma)

- **文化：** 芬蘭神話 (Finnish Mythology)／芬蘭-烏戈爾神話 (Finno-Ugric Mythology)
- **職掌：** 暴力死亡的化身、地獄之犬、冥界的執行者

## 概述

蘇爾瑪（Surma）是芬蘭神話中暴力死亡與毀滅的化身，其名在芬蘭語中直接意為「死亡」。不同於冥神圖奧尼（Tuoni）——後者是冥界圖奧內拉（Tuonela）的統治者、以中立被動的態度接納所有死者——蘇爾瑪是死亡的積極執行者：牠是在邊境巡邏的野獸，將不應進入冥界者撕裂。在《卡勒瓦拉》（Kalevala）史詩中，蘇爾瑪的形象是一隻長著獠牙的凶犬（或狼形怪物），守衛在圖奧內拉入口的激流之外的黑暗森林中。牠的雙眼如沼澤的磷火，呼吸能使人瞬間僵硬。

## 神話事蹟

蘇爾瑪在《卡勒瓦拉》中出現於維納莫伊寧（Väinämöinen）前往冥界圖奧內拉尋找咒語的段落。維納莫伊寧穿越黑水河，踏上死亡之島後，圖奧尼的女兒以黑啤酒麻痺他，試圖將他永遠留在冥界。當維納莫伊寧試圖逃脫時，圖奧尼放出蘇爾瑪——一隻渾身覆蓋苔蘚的犬形怪物——追殺他。蘇爾瑪的牙齒是生鏽的鐵刺，共有百枚，每一枚上都刻著不同的死法。維納莫伊寧依靠智慧與咒語的力量才得以逃脫，返回人間。

蘇爾瑪不僅守衛冥界出口，也被認為在戰場上徘徊——以牠的牙齒選擇將死之人。某些民間歌謠（runo）中，蘇爾瑪被描述為有數百個頭與舌頭，能夠同時在不同地點奪取生命。當蘇爾瑪在森林中長嚎三聲，即意味三人將在三日內死於非命。

與圖奧尼不同，蘇爾瑪不接受祭祀或祈求——牠不受任何形式的討價還價，是芬蘭神話中最接近「絕對死亡」的概念。部分神話學者認為蘇爾瑪反映了芬蘭古代對於「非自然死亡」的恐懼——死於刀劍、火焰或野獸的人被認為會被蘇爾瑪直接吞噬，靈魂無法進入圖奧內拉享受冥界的安息。

## 跨文化對應

| 芬蘭 | 跨文化對應 |
|-----|-----------|
| 蘇爾瑪（Surma） | ↔ 希臘刻耳柏洛斯（Cerberus）— 冥界守門犬 |
| | ↔ 北歐加爾姆（Garmr）— 地獄犬，諸神黃昏時掙脫束縛 |
| | ↔ 埃及阿努比斯（Anubis）— 死亡處理者與引導者 |
| | ↔ 印度閻魔的雙犬（Shyama 與 Sabala）— 冥界信使 |
| | ↔ 波斯維斯雷沙（Vīsaresha）— 索羅亞斯德教冥界守護者 |
| | ↔ 中國牛頭馬面 — 冥界拘魂使者 |
| 具有操弄死亡、不能被收買 | ↔ 希臘塔納托斯（Thanatos） |
| 以犬形象呈現的死亡 | ↔ 北歐加爾姆；印度閻魔犬 |

蘇爾瑪在芬蘭神話中最接近的角色是希臘神話的刻耳柏洛斯——兩者都是冥界入口的犬形守衛。但蘇爾瑪不僅是守門者，更是「奪取性死亡」的化身：刻耳柏洛斯只阻止活人進入冥界，蘇爾瑪則是會主動追殺試圖逃出冥界者。這個「反向守門」——阻止死者返回人間——在跨文化中較為罕見，體現了芬蘭神話中「死者的世界一旦進入便不可回頭」的嚴格界線觀念。

## 相關神祇

- **Tuoni** — 冥界之神，圖奧內拉的統治者，蘇爾瑪的主人
- **Tuonetar** — 冥后，圖奧尼的妻子
- **Väinämöinen** — 曾遭遇蘇爾瑪追殺的遠古智者
- **Kalma** — 死亡的氣息／惡臭的人格化，與蘇爾瑪共同巡行
