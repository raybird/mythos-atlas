# 伊庫-圖爾索 (Iku-Turso)

- **文化：** 芬蘭神話 (Finnish Mythology)／芬蘭-烏戈爾神話 (Finno-Ugric Mythology)
- **職掌：** 海洋巨獸、永恆巨人、深海的破壞者、與「起源時代」相連的原初存在
- **別名：** Iku-Tursas、Meriturso（海之圖爾索）、Tursas、Turisas、「永恆的老人」

## 概述

伊庫-圖爾索（Iku-Turso）是芬蘭神話中最古老也最神秘的海洋巨獸。其名字 Iku- 意為「永恆」，Turso 可能與古北日耳曼語 *þur(i)saz（巨人）相關——赫爾辛基大學學者指出，此字經原始芬蘭語 *tur(i)sas 借入，語源上與北歐神話的霜巨人（þurs）同源。他被視為「永恆的巨人」，是深海與原初混沌的化身，與世界起源的時代緊密相連。

在《卡勒瓦拉》（Kalevala）中，伊庫-圖爾索同時具有「巨大而可怖」與「具有古老智慧」的雙重性格。他潛居深海，能掀起風暴、燃燒島嶼，也能被智者以咒語馴服。某些魯諾（runo）歌謠甚至將他描繪為維納莫伊寧（Väinämöinen）的父親——一個在太古時代「以手指掀開子宮出生、出生即全副武裝騎馬佩劍」的原始巨人，暗示芬蘭神話中存在一條從海洋巨人到創世英雄的血緣譜系。

## 神話事蹟

### 海上的火焰與巨橡

在《卡勒瓦拉》第二詩章中，伊庫-圖爾索從海中升起，燃燒了一堆乾草。灰燼中生出一顆橡實，這顆橡實迅速長成遮蔽天地、擋住太陽與月亮的巨橡——此即「巨橡傳說」的開端。維納莫伊寧呼喚水之母，派出一位從水中升起、全身銅甲、僅拇指大小的巨人（一說正是伊庫-圖爾索的化身）將巨橡斬倒。巨橡倒下後，遮擋太陽與月亮的黑暗解除，世界重獲光明。在此神話中，海洋巨人既是混亂的製造者，也是傳奇事件的起點。

### 桑波的爭奪

在《卡勒瓦拉》第四十二詩章（桑波之戰）中，波赫尤拉（Pohjola）的女主人婁希（Louhi）發現桑波（Sampo）被維納莫伊寧等人奪走，便召喚海霧籠罩海面，並命令伊庫-圖爾索吞沒卡勒瓦拉的英雄們。維納莫伊寧以神劍劈開海霧脫困後，伊庫-圖爾索憤怒地浮上海面。維納莫伊寧毫不畏懼，一把抓住巨獸的雙耳，連續質問三遍。伊庫-圖爾索最後坦白自己是奉婁希之命而來，並發誓「永遠不再從海底升起」後被釋放。此段落是芬蘭史詩中「人類智者以言語馴服深海巨獸」的經典場景。

### 太古巨人的祖先

除史詩外，芬蘭民間歌謠另有「伊庫-圖爾索為維納莫伊寧之父」的說法。歌謠描述「古老永恆的巨人」之子不耐待在子宮中，僅以一指輕抬便自行誕生，出生時已全副武裝。此母題將海洋巨獸提升為「起源時代的原初父親」，與北歐神話的始祖巨人尤彌爾（Ymir）、世界蛇尤蒙剛德（Jörmungandr）並列，成為芬蘭版圖中最接近「混沌巨獸」的角色。

## 跨文化對應

| 芬蘭 | 跨文化對應 |
|-----|-----------|
| 伊庫-圖爾索（Iku-Turso） | ↔ 北歐尤蒙剛德（Jörmungandr）— 環繞世界的深海巨蛇 |
| | ↔ 北歐始祖巨人尤彌爾（Ymir）— 原初巨人、世界由其身軀構成 |
| | ↔ 希臘提豐（Typhon）— 撼動天地的百首巨獸 |
| | ↔ 美索不達米亞提亞瑪特（Tiamat）— 原初混沌海怪 |
| | ↔ 聖經利維坦（Leviathan）— 上帝馴服的深海巨獸 |
| 從海中升起、與太陽月亮相關 | ↔ 埃及阿佩普（Apep）— 每日威脅太陽船的混沌蛇 |
| 被智者言語馴服 | ↔ 北歐索爾釣取尤蒙剛德；希臘宙斯鎮壓提豐 |

伊庫-圖爾索最特別之處在於他兼具「混沌巨獸」與「起源之父」的雙重身分——他既是需要被馴服的破壞力量，又是某些歌謠中維納莫伊寧的父親。這種「原初巨人＝祖先」的模式與北歐尤彌爾（其身軀成為世界）高度相似，反映了芬蘭與北日耳曼神話在語言與神話層面的深層親緣。

## 相關神祇

- **Väinämöinen** — 曾與之對峙並馴服他的智者；一說為其子
- **Louhi** — 波赫尤拉女主人，召喚他阻擋桑波爭奪的英雄們
- **Ukko** — 天空與雷電之神，與海洋巨獸相對的天界秩序
- **Ahti** — 另一水神，與伊庫-圖爾索分屬不同水系的神格
