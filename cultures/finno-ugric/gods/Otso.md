# Otso / Karhu（奧特索／卡爾胡）

- **文化：** 芬蘭-烏戈爾神話 (Finno-Ugric Mythology)
- **職掌：** 森林之王、熊之神、動物之王、森林蜂蜜之主

## 概述

Otso（亦稱 Karhu、Ohto、Kontio、Metsän kuningas「森林之王」）是芬蘭-烏戈爾神話中的熊神——他既是獵物、圖騰先祖，也是地位崇高的神聖存在。芬蘭人對熊的稱呼多用「雅號」而非本名（Karhu 本身即為婉稱，意為「粗糙、毛茸茸者」），反映對熊的敬畏——直呼其名被視為召喚災禍。在《卡勒瓦拉》第四十六詩篇中，Otso 被稱為「森林的蘋果」、「蜂蜜爪」、「森林鬍鬚的金色主人」，其出身神話化：熊並非野獸，而是天界的貴族之子——由森林女神 Mielikki 的蜜乳撫養，降臨人間時以金床與銀枕迎接。芬蘭語與愛沙尼亞語的熊名（Kalevipoeg 中也有 Karu）皆顯示熊在烏拉爾語系民族中的核心地位。考古與民族誌證據顯示，芬蘭與西伯利亞的熊崇拜共享同一根源——熊被視為祖先轉世，獵熊後必須舉行「祭祀盛宴」(peijaiset) 以安撫其靈魂，並將頭骨掛在松樹上使其回歸天界。

## 神話事蹟

《卡勒瓦拉》第四十六詩篇描述了完整的「熊獵敘事」：卡勒瓦拉眾人得知熊降臨森林後，Väinämöinen 前往獵熊——他首先請求森林女神 Mielikki 與 Tapio 的許可，並以歌聲召喚熊「前來赴宴」。熊被射殺後，Väinämöinen 以隆重的儀式迎接：「歡迎你，蜂蜜爪！請進屋內！」——他宣稱熊並非被殺，而是「自己滑落到樹下」，以此安撫熊靈。隨後舉行盛大的熊宴（karhunpeijaiset）：眾人享用熊肉，將熊骨仔細埋藏、頭骨掛於松樹（karsikko）上，朝向東方——相信熊的靈魂將返回天界（Otavainen 星座，即北斗七星，在芬蘭被稱為「熊座」），並守護森林的繁榮。此儀式與西伯利亞鄂溫克、雅庫特及日本愛努民族的熊祭（Iyomante）結構一致：獵殺、盛宴、安魂、送靈。Väinämöinen 最後吟唱「熊之歌」警告人類不可濫獵——森林之王是自然秩序的化身，尊重牠即是尊重整個森林生態。

## 跨文化對應

| 文化 | 對應神祇 | 共通點 |
|------|----------|--------|
| 愛努神話 | Kim-un-kamuy（熊神）／Iyomante 熊祭 | 熊為神之使者，獵後送靈回天 |
| 西伯利亞神話 | 雅庫特／鄂溫克熊神 | 熊為圖騰先祖，熊宴安魂 |
| 北美原住民 | 熊族神話（易洛魁／奧吉布瓦） | 熊為醫者與守護靈 |
| 薩米神話 | 熊祭儀式（Bieggolmai 之獵） | 熊為神聖獵物，獵後安魂 |
| 希臘神話 | Artemis（阿爾忒彌斯） | 女獵神與熊之聖獸（Brauronia 熊舞） |
| 中國神話 | 熊圖騰（黃帝號有熊氏） | 熊為氏族始祖與力量象徵 |

## 相關神祇

- **Mielikki**（森林女神）——以蜜乳撫養 Otso，森林的恩主
- **Tapio**（森林之王）——Otso 的守護者與獵場之主
- **Väinämöinen**——主持熊宴、詠唱熊之歌的智者
- **Nyyrikki**（狩獵神）——Tapio 之子，指引獵人獵獲 Otso
