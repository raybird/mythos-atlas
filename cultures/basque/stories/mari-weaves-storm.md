# Mari 編織風暴：巴斯克女神的洞穴與巴斯克雷電的由來

## 文化背景

Mari 是巴斯克神話中至高無上的女神，居住在 Aizkorri 山脈深處的洞穴中。在巴斯克民間信仰中，Mari 每天在洞穴中以黃金的紡車編織——她編織的不是一般的線，而是風暴、雷電、乾旱與洪水。當她梳理她的長髮時，山間會吹起強風；當她梳洗完畢將梳子中的落髮拋出時，天空會降下暴雨。本故事是巴斯克神話中最具代表性的自然現象解釋神話之一——它解釋了巴斯克山區為何以劇烈且突然的雷陣雨聞名。

## 故事正文

在巴斯克最高的山峰 Aizkorri 的心臟地帶，有一個洞穴——不是普通的洞穴，而是 Mari 的宮殿。洞口的岩石上刻滿了只有她才知道的符號，洞內的牆壁以一千塊水晶覆蓋，每一塊水晶反射的都是地球某一個角落的景象。Mari 坐在洞穴最深處，她的面前是一座黃金的紡車。她以雲朵為棉花、以雨水為潤絲、以雷電為梭子——每天她編織一條巨大的白色布匹，那布匹不是布料，而是當天的天氣。

每一天早晨，Mari 會先看看天空。如果她滿意，她編織的是晴朗的藍天——陽光會穿過比利牛斯山，溫暖巴斯克的每一個谷地。如果她不高興——如果人類說了謊話、如果有人在她的聖泉中洗滌了不潔的衣物、如果有人砍了神聖的橡樹——Mari 就會在紡線中混入黑色的雲絲。她的丈夫 Sugaar（一條有角的巨蛇）從洞穴深處爬到她的腳邊，詢問她為何生氣。Mari 不回答，只是加快了紡車的速度。

紡車愈轉愈快，洞穴中開始迴盪低沉的轟鳴。那是雷電在紡線中生成的徵兆。當她一把抓起織好的布匹扔出洞口時——布匹在半空中崩解為無數碎片——每一塊碎片化作一朵烏雲，碎片之間的撕裂聲就是雷聲，碎片中迸出的金線就是閃電。

傳說有一次，一個村莊的牧民為了爭奪水源殺死了鄰村的年輕人。Mari 在洞穴的水晶牆中看見了這場殺戮。她停下紡車，靜坐了整整三天。第四天，她站起來，將七年的紡線全部剪斷，將所有線頭綁在一起，擲出洞口。天空中出現了一團前所未見的巨大烏雲——雲中夾雜著冰雹和火焰。暴風雨連續下了七天七夜，洪水沖走了爭奪水源的兩個村莊，只留下山谷中一條全新的河流。從此以後，這條河被稱為「Mari 的眼淚」（Mariaren malkoak）。而巴斯克的牧民都知道：如果在山頂看到一朵孤立的黑色烏雲迅速擴大，那是 Mari 正在編織新的懲罰——最好趕快檢查自己有沒有違反古老的禁忌。

## 跨文化平行

| 巴斯克 | 跨文化對應 | 共通點 |
|--------|-----------|--------|
| Mari 以紡車編織天氣 | ↔ 北歐 Frigg 紡織雲朵 | 女神以紡織控制天象 |
| | ↔ 波利尼西亞 Hine-nui-te-pō 編織命運 | 紡織與宇宙秩序的掌控 |
| 洞穴作為天氣製作所 | ↔ 希臘 Aeolus 的風穴 | 天氣被鎖在洞穴中由神靈控制釋放時機 |
| 閃電＝紡線斷裂迸出的光芒 | ↔ 日本 雷神（Raijin）敲鼓產生雷鳴 | 自然現象源自神的具體動作 |
| Mari 的憤怒＝洪水毀滅村莊 | ↔ 聖經 Noah 大洪水 | 人類的道德腐敗導致自然災害作為懲罰 |
| Mari 以水晶牆觀看人間 | ↔ 北歐 Frigg 的 Fensalir 廳 | 女神從居所觀看人間的全知能力 |

Mari 的紡車神話對應於全球廣泛分布的「紡織女神」原型（Frigg、Athena、Ix Chel、棚機津女），但 Mari 是其中唯一直接以織物決定**天氣**而非命運或工藝的女神。在巴斯克的宇宙觀中，天氣不是物理現象，而是女神對人類行為的即時道德反應——每一次雷電都是 Mari 對謊言或暴力的回應。

## 文化意義

Mari 編織天氣的神話在巴斯克農牧社會中具有極深的實踐含義：它為不可預測的山區天氣提供了道德解釋框架。當一場夏季的冰雹摧毀農作物時，它不是隨機的自然災難，而是 Mari 對某個社區的道德警告——長老們會檢討社區中是否有尚未和解的糾紛。此神話因此不僅是病因學的解釋，也發揮了社會調解的功能。
