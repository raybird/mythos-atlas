# 阿塔拉比 (Atarrabi) — 光明祭司

- **文化：** 巴斯克神話 (Basque Mythology)
- **別名：** Atarrabi（巴斯克語）、Atarrabia
- **職掌：** 光明、祭司職責、儀式淨化、生命之力
- **象徵：** 白色蠟燭、聖水、教堂、白馬

## 概述

阿塔拉比（Atarrabi）是巴斯克神話中至高女神瑪麗（Mari）與雷蛇蘇加爾（Sugaar）所生的雙胞胎之一。他的兄長米凱拉茨（Mikelats）選擇了黑暗與魔法的道路，阿塔拉比則選擇了光明與祭司的道路。兩兄弟的對立構成了巴斯克神話中最深刻的二元結構——這不是善惡的絕對對抗（如基督教中上帝與撒旦），而是宇宙秩序中光明與黑暗兩大領域的必要分工。阿塔拉比從未徹底消滅米凱拉茨，正如白晝從未消滅黑夜——二者的交替與共存賦予世界以平衡。

阿塔拉比的名字詞源學說不一：一說來自巴斯克語「atar」（門檻）與「erabi」（行者），意為「穿越門檻者」，象徵他作為祭司在神聖與世俗之間的中介角色。另一說則認為他與納瓦拉地區的聖阿塔拉比（San Atarrabi）傳說有關——此聖人傳說很可能是基督教化後對這位原始光明神的重新詮釋。

## 神話事蹟

### 雙胞胎的選擇

瑪麗生下雙胞胎後，並未決定二人的命運——她將他們放在安博托山洞的入口，讓他們自行選擇未來的道路。米凱拉茨走出山洞，走入黑暗的森林，跟隨蓋科（Gaueko，夜之靈）學習黑暗魔法。阿塔拉比則走入山谷中的教堂，在聖壇前跪下，以白色亞麻布包裹雙手，成為祭司的學徒。

瑪麗從山洞頂端注視著兩個兒子的選擇，既未讚許也未阻止——巴斯克神話特有的宿命論在此體現：母親不干涉兒子的本質天性，因為光明與黑暗同樣是自然秩序的一部分。此情節與波斯神話中佐爾萬（Zurvan）將王權同時賜予奧爾馬茲德（Ohrmazd）與阿赫里曼（Ahriman）的故事具有結構性的平行關係。

### 聖水與風暴的對決

阿塔拉比與米凱拉茨最著名的神話圍繞著他們在烏爾基奧拉山（Urkiola）頂的魔法對決。故事記述一個村莊因居民的道德敗壞受到詛咒——田園枯萎、水源乾涸、嬰兒夭折。村民尋求阿塔拉比的幫助，他以聖水灑遍村莊的每一座房屋，淨化詛咒。但米凱拉茨在遠處的山峰上以黑暗魔法召喚風暴，試圖沖走聖水的效力。阿塔拉比以祈禱之力將聖水升華為光之屏障，阻擋風暴。二人僵持了七天七夜——在此期間，白天阿塔拉比佔上風，夜晚米凱拉茨佔上風。

最終瑪麗親自介入：她取出一把金色的鐮刀，將天空從中間切開——東側永遠光明成為阿塔拉比的領域，西側永遠黑暗成為米凱拉茨的領域。但瑪麗的裁定也帶來了永久的後果——從此之後，巴斯克山谷中的每一天都是光明與黑暗交替的循環，人類不得不在兩種力量之間保持平衡。

### 牧羊人的神諭

阿塔拉比在巴斯克民間傳說中也以「助人者」的形象出現。傳說一位牧羊人在安博托山谷迷路三日，瀕臨死亡時夢見阿塔拉比騎著白馬出現。阿塔拉比以手中的蠟燭照亮迷霧，引導牧羊人找到出路。牧羊人為了報恩，在遇救處建造了一座小禮拜堂——此建築至今仍存在於比斯開省的某個山丘上，當地人稱之為「阿塔拉比的燈」（Atarrabiaren Argi）。這則傳說雖然經過基督教化的改編，但仍保留了阿塔拉比作為「引導者」與「光明賜予者」的原始功能——他與蓋科的黑暗領域形成對照，蓋科使迷路者更加迷失，阿塔拉比則引導迷途者歸返。

## 跨文化對應

| 文化 | 對應神靈 | 共通點 |
|------|---------|--------|
| **波斯** | 斯彭塔·曼紐（Spenta Mainyu） | 光明之靈，與善神阿胡拉·馬茲達（Ahura Mazda）共同對抗惡靈 |
| | 阿胡拉·馬茲達本體 | 光明的至高之神、秩序與真理的維護者 |
| **希臘** | 阿波羅（Apollo） | 光明、淨化、預言與祭司之神；阿塔拉比雖無預言職能，但淨化與祭司角色高度對應 |
| **北歐** | 巴德爾（Baldr） | 光明之神、純潔之象徵；巴德爾之死代表了光明被黑暗吞噬的悲劇 |
| **埃及** | 荷魯斯（Horus） | 光明之神、秩序戰勝混亂；荷魯斯之眼象徵被奪走後重獲光明 |
| **基督教** | 聖米歇爾（St. Michael） | 光明天使的領袖、以聖水與劍對抗黑暗；但阿塔拉比與兄長的對抗並非善惡戰爭 |
| **中國** | 陽（概念而非人格神） | 陰陽對立互補而非對抗——阿塔拉比與米凱拉茨的關係更接近陰陽而非善惡二元論 |

跨文化比較中最值得注意的是：阿塔拉比與米凱拉茨的鬥爭並非多數神話中典型的「正義戰勝邪惡」敘事，而是一種類似中國陰陽哲學的互補關係。在多數印歐神話中（如波斯、希臘、北歐），光明力量最終會徹底擊敗黑暗；但在巴斯克神話中，瑪麗的裁決使二者永遠共存——她拒絕選擇站在任何一方。這可能反映了巴斯克社會前基督教時期對自然世界的根本理解：大自然既非善也非惡，而是光明與黑暗交替運行的永恆循環。

## 相關神祇

- **母親：** 瑪麗（Mari，大地女神，維持光明與黑暗的平衡）
- **父親：** 蘇加爾（Sugaar，雷蛇，地下力量的象徵）
- **兄長（對立者）：** 米凱拉茨（Mikelats，黑暗精靈之主、黑暗魔法的統治者）
- **盟友：** 埃古茲基（Eguzki，太陽神，白晝秩序的共治者）
- **象徵物：** 白色蠟燭（atabarri argi）、聖水（ur bedeinkatu）、白馬
