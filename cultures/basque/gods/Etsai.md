# Etsai — 巴斯克的洞穴惡魔與教師

- **文化：** 巴斯克神話 (Basque Mythology)
- **其他名稱：** Aatxe（紅公牛）、Aatxegorri、Deabru、Beigorri
- **職掌：** 邪惡、黑暗、懲罰、變形、地下教學

## 概述

Etsai 在巴斯克語中直譯為「敵人」或「惡魔」，是巴斯克神話中最主要的邪惡靈體。祂居住在洞穴深處，以紅公牛（Aatxe）的型態出現，但也變形為龍、豬、馬或公山羊。與基督宗教引入的惡魔觀念不同，Etsai 在巴斯克傳統中具有雙重角色：既是懲罰作惡者的恐怖存在，也是傳授科學與藝術的地下教師。學生進入 Etsai 的洞穴學習後必須付出代價——其中一人必須永遠留下來侍奉 Etsai。這種「知識與犧牲的交換」結構在巴斯克傳說中反覆出現（Barandiarán 1972: 88-94）。

Etsai 的洞穴位於 Sara 的 Leixa 洞穴以及 Zugarramurdi 的女巫洞穴——後者因西班牙宗教裁判所的最大規模女巫審判而聞名。Etsai 的外觀通常被描述為一隻紅色的公牛，從洞穴深處向人類發出咆哮。在 Christianity 傳入後，Etsai 與基督宗教的魔鬼（Deabru）逐漸融合，但其作為洞穴教師的獨特意涵——「惡魔即教師」——在歐洲神話中幾乎是獨一無二的（Webster 1877: 55-62）。

## 神話事蹟

### 洞穴中的知識交換

Etsai 最著名的神話圍繞著祂的「地下大學」。來自各地的年輕學生進入 Etsai 的洞穴學習天文、數學、醫術與文字。每批學生中最後完成學業的人必須永遠留在洞穴中，成為 Etsai 的奴僕。這一規則透過一種名為 Txotx-Ala-Motx 的抽籤遊戲來決定——抽中最短樹枝者即為犧牲者。

最著名的故事涉及 Atarrabi（Mari 的善子）與 Mikelats（Mari 的惡子）兄弟。為了讓兄長 Mikelats 獲得自由，Atarrabi 自願代替兄長留下。但 Mikelats 獲釋後仍然心懷惡意，試圖以風暴摧毀 Atarrabi 的麥田。Atarrabi 擲出鞋子化解了風暴，但兄弟之間的裂縫從此不可修復。這個故事反映了巴斯克神話中深刻的二元論：善與惡不是截然分離的力量，而是一對被命運綁定的兄弟，各自擁有無法改變的本性。

### Aatxe：紅公牛

Etsai 最常見的化身是 Aatxe（巴斯克語「小公牛」）——一頭從洞穴深處咆哮而出的紅色公牛。Aatxe 在暴風雨的夜晚特別活躍，專門攻擊罪犯與道德敗壞者。有時祂也保護人類——當危險逼近時，Aatxe 以震耳欲聾的咆哮迫使村民留在家中避免災難。

在 Isturits 和 Sara 等洞穴中發現的舊石器時代野牛壁畫——距今超過一萬年——被學者推定為 Aatxe 信仰的史前起源。如果此推測正確，Etsai／Aatxe 可能是歐洲最古老的連續崇拜對象之一，其根源可追溯至冰河時期的狩獵採集社會（Barandiarán 1972: 96-101）。

## 跨文化對應

| 文化 | 對應神靈／概念 | 共通點 |
|------|-------------|-------|
| 希臘 | 黑帝斯（Hades） | 地下世界的統治者 |
| 希臘 | 奇戎（Chiron） | 洞穴中的智慧教師（非邪惡） |
| 北歐 | 洛基（Loki） | 變形者、麻煩製造者、必要的邪惡 |
| 美索不達米亞 | 帕祖祖（Pazuzu） | 以恐怖面容驅趕更邪惡的力量 |
| 基督教 | 墮落天使路西法 | 知識的驕傲與邪惡的合體 |
| 日本 | 鬼（Oni） | 洞穴居住的邪惡變形者 |
| 斯堪地那維亞 | 巨怪（Troll） | 住在洞穴中的非人教師 |
