# 阿科貝爾茨 (Akerbeltz / Akerbeltz)

- **文化：** 巴斯克神話 (Basque Mythology)
- **職掌：** 山羊靈、牧群守護者、治癒、生育、地下財富

## 概述

阿科貝爾茨（Akerbeltz，巴斯克語「aker」= 公山羊、「beltz」= 黑色，意為「黑公羊」）是巴斯克神話中地位獨特的神靈——他既非至高神也非人格化的神祇，而是一隻黑色的山羊形靈體，掌管著牧群的繁衍、疾病的治癒、以及隱藏於地下的財富。在基督教化過程中，阿科貝爾茨被教會妖魔化為惡魔的化身（部分原因正是因為黑山羊的形象與基督教撒旦的重疊），但在巴斯克農民的傳統信仰中，他實為仁慈且不可或缺的守護者。

與瑪麗（Mari）掌管天氣與大規模自然力量不同，阿科貝爾茨的權力範圍是局部的、農家層級的——他守護的是每一座農舍的牛棚與羊圈。

## 神話事蹟

### 牧群的靈魂

巴斯克農民相信，每一群牲畜的體內都有一個「Akerbeltz」——牠不是具體的某一隻羊或山羊，而是整個牧群的集體靈魂，以一隻黑色山羊的形象顯現。如果這隻黑山羊健康活潑，整群牛羊就會繁衍興旺；如果牠生病或消失，瘟疫將降臨整個牧場。

在巴斯克傳統中，農民從不殺害羊群中唯一的黑色山羊——即使其餘的羊全被賣出或宰殺，黑山羊必須被保留至自然老死。此禁忌極為嚴格：傳說有一個村莊在饑荒中宰殺了黑山羊，結果第二年所有牲畜都死於神祕的疾病。

### 治癒的力量

阿科爾貝茨的治癒能力與巴斯克民間醫學緊密相連。傳統上，當嬰兒患有疝氣或百日咳時，母親會將嬰兒三次從黑山羊的腹下穿過——此儀式被稱為「Akerbeltz-ganatiko pasatzea」。村民相信黑山羊吸收了嬰兒的病氣，換來了健康。同樣的儀式也用於治療家畜的乳頭炎與蹄部感染。

在某些地區，阿科爾貝茨的毛髮被焚燒成灰，混入飲水中作為通用解毒劑。基督教傳教士將這些習俗視為巫術並加以禁止——但直到19世紀，巴斯克山區仍有人在執行此類療程。

### 地下財富的守護者

巴斯克神話中，阿科爾貝茨也與地下的礦脈與寶藏相關。傳說黑山羊以蹄敲擊地面時，可以感知地下是否有金屬或水源。巴斯克礦工在開採鐵礦（巴斯克地區自古以優質鐵礦聞名）之前，會在山腳下放置黑山羊的毛作為獻祭，祈求阿科爾貝茨指引礦脈的位置。

### 巫魔會的參與者

在西班牙宗教裁判所的記錄中，阿科爾貝茨頻繁出現於巴斯克地區巫魔會（Akelarre，巴斯克語「aker」= 公山羊、「larre」= 草地，即「公山羊草地」）的描述中。裁判官記錄顯示，被告的巴斯克婦女描述自己被帶到一片草地上，在那裡一隻巨大的黑山羊主持聚會。學者普遍認為：Akelarre 一詞本身就源於 Akerbeltz 的形象；巴斯克原有的豐饒崇拜（以黑山羊為中心）被教會重新解釋為魔鬼崇拜，Akelarre 這個詞也因此進入了歐洲巫術史的核心詞彙。

## 跨文化對應

| 文化 | 對應神靈 | 共享特徵 |
|------|---------|---------|
| 希臘 | 潘（Pan） | 羊足、角、掌管牧群與荒野，但潘同時是音樂與狂歡之神 |
| 北歐 | 索爾的兩頭山羊（Tanngrisnir & Tanngnjóstr） | 山羊作為神聖動物，可被食用後復活，象徵永恆的豐饒 |
| 凱爾特 | 塞爾農諾斯（Cernunnos） | 鹿角神，動物與自然的守護者，地下財富之神 |
| 印度 | 阿耆尼（Agni）以山羊為坐騎 | 山羊與火、潔淨、治療的連結 |
| 基督教 | 撒旦（Satan） | 黑山羊形象被挪用為惡魔象徵，但原始功能為正面守護者 |
| 芬蘭 | 烏戈（Ukko）以山羊為祭品 | 山羊作為與至高神溝通的祭品媒介 |

## 相關神祇

- **瑪麗（Mari）：** 至高女神，阿科爾貝茨從屬於其自然秩序
- **蘇加爾（Sugaar）：** 蛇神，阿科爾貝茨的陸地對應——蛇守護地下水源，山羊守護地上牧群
- **巴薩豪恩（Basajaun）：** 森林之主，共同守護自然界的平衡
- **Lamiak：** 水邊的精靈，與阿科爾貝茨共享「邊界守護者」的功能
