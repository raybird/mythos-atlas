# Mikelats（米凱拉茨）

- **文化：** 巴斯克神話（Basque Mythology）
- **職掌：** 黑暗精靈之主、惡靈統治者、Mari 的叛逆之子

## 概述

Mikelats（亦作 Mikelatz 或 Mikelotz）是巴斯克神話中統治邪惡靈魂與黑暗精靈（sorginak、lamiak 中的墮落者）的神祇。他是至高女神 Mari 與蛇神 Sugaar 所生的雙胞胎之一——他的兄弟 Atarrabi 選擇了光明與祭司的道路，Mikelats 則選擇了黑暗與魔法。兩兄弟的對立構成了巴斯克神話中獨特的善惡二元結構，反映了基督教化之前巴斯克人對宇宙中光明與黑暗力量的並存認知。Mikelats 的領域在地下深處——據說他在 Aizkorri 山底的洞穴中統治著一支由墮落 sorgin（女巫）與 gaizkin（惡靈）組成的軍隊。他的形象被描述為一身黑衣、頭戴黑鐵冠、雙眼如燃燒的煤炭。不同於基督教引入的「魔鬼」概念，Mikelats 不是宇宙邪惡的化身，而是一種必要的力量——Mari 創造世界時同時賦予了光明（Atarrabi）與黑暗（Mikelats）以維持平衡。若無 Mikelats，人類的選擇便無意義。巴斯克民間有諺語：「沒有 Mikelats 的夜晚，Atarrabi 的蠟燭不會發光。」此概念與摩尼教的二元論有著驚人的結構平行，但 Mikelats 從未被描述為「墮落天使」——他從一開始就是黑暗的守護者，而非背叛者。

## 神話事蹟

Mikelats 最著名的神話是他與兄弟 Atarrabi 的競爭。傳說 Mari 將雙胞胎交給人類撫養，並給予他們自由選擇的權利。Atarrabi 選擇進入教堂成為祭司，以祈禱和聖水對抗邪靈；Mikelats 則走進深山，跟隨 Gaueko（夜之靈）學習黑暗魔法。當 Atarrabi 試圖以聖水淨化一個被詛咒的村莊時，Mikelats 以風暴阻礙他——兄弟二人在山頂展開了一場持續七天七夜的魔法對決。最終 Mari 親自介入，將天空一分為二——Atarrabi 統治白晝的秩序，Mikelats 統治黑夜的力量。第二則核心神話是 Mikelats 與 Basajaun 的交易：Basajaun（森林之主）守護者人類的農業秘密，Mikelats 引誘 Basajaun 以交換一條河流的改道（因為黑暗精靈需要乾燥的河床作為通道）。此交易說明了為何巴斯克地區某些河流會突然乾涸——那是 Mikelats 與 Basajaun 的古老契約。

## 跨文化對應

| 巴斯克 | 跨文化對應 | 共通點 |
|--------|-----------|--------|
| Mikelats（黑暗子） | ↔ 波斯 Ahriman／Angra Mainyu | 黑暗力量的統治者，與光明神為永恆競爭者 |
| Atarrabi（光明子） | ↔ 波斯 Ahura Mazda | 光明的守護者、祭司與秩序的代表 |
| Mikelats 與 Atarrabi 的對決 | ↔ 馬尼教二元論（光暗分治） | 宇宙被一分為二，二者的競爭維持世界運行 |
| | ↔ 中國陰陽（並非競爭而是互補） | 二者的鬥爭維持平衡（而非互補轉化） |
| Mikelats 的「必要之惡」 | ↔ 北歐 Loki | 混沌在宇宙秩序中的必要角色 |
| | ↔ 埃及 Seth | 混亂與黑暗之神，但仍是神聖秩序的一部分 |

Mikelats 在跨文化黑暗之神譜系中最接近波斯神話的 Ahriman——二者都非「原初邪惡」，而是在創世之初選擇了黑暗的領域。不同於基督教 Lucifer 的「墮落天使」敘事（從光明墮入黑暗），Mikelats 從一開始就被創造為黑暗面的守護者，使巴斯克二元論更像伊朗的 Zurvanism（時間之神同時生出光明與黑暗），而非善惡勢力的後天分裂。

## 相關神祇

- **Mari**（大地女神）——Mikelats 的母親，維持光明與黑暗的平衡
- **Sugaar**（蛇神）——Mikelats 的父親，地底力量的象徵
- **Atarrabi**——Mikelats 的雙胞胎兄弟，光明與祭司的代表
- **Gaueko**（夜之靈）——Mikelats 的導師，黑暗魔法的傳授者
- **Basajaun**（森林之主）——Mikelats 的交易對象與偶爾的盟友
