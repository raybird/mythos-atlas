# 索爾金 (Sorgin) — 巴斯克的智慧女巫

- **文化：** 巴斯克神話 (Basque Mythology)
- **別名：** Sorgina（單數絕對格）、Sorginak（複數）、Anbotoko Sorgina（安博托女巫）、Aketigiko Sorgina（阿凱特吉女巫）
- **職掌：** 智慧、醫藥、占卜、自然守護、中介 Mari 與人間
- **象徵：** 黑貓、掃帚、草藥、洞穴

## 概述

索爾金（Sorgin）是巴斯克神話中最複雜且最具爭議性的存在——她的詞源至今仍是語言學的辯論焦點。一派學者主張 sor 來自 sorte（命運），因此 sorgin 意為「命運的知曉者」；另一派則認為 sor 是 sortu（創造）的詞根，sorgin 即「創造者」。無論哪一種解釋，都指向她作為智慧與儀式專家的原始地位。

在基督教化之前，Sorgin 是女神 Mari 的助手與人間代理人，負責執行占卜、草藥醫治、接生與儀式魔法。她們在星期五夜晚於偏遠山洞舉行 akelarre（巫會），向 Mari 致敬並預測天氣與收成。然而隨著 16-17 世紀宗教裁判所的擴張，特別是在 1610 年 Logroño 的 Zugarramurdi 審判中，這些智慧女性被系統性地妖魔化為惡魔崇拜者（Barandiarán 1960; Henningsen 1980）。

巴斯克地區至今留存大量以 sorgin 命名的地名——Sorginkoba（女巫洞）、Sorginzubi（女巫橋）、Sorginiturri（女巫泉）、Sorginpelota（女巫球場）——這些地名記錄了 Sorgin 在巴斯克集體記憶中的深層印記。Mari 本人也常被稱為 Anbotoko Sorgina（安博托女巫），顯示女神與女巫之間的本質連續性。

## 神話事蹟

### Mari 的代理人

Sorginak 是 Mari 的隨從與人間使者。她們在安博托、阿凱特吉等聖山的洞穴中侍奉 Mari，於 akelarre 聚會中接收女神的指示，然後將之傳達給人類社群。這些聚會在星期五夜間舉行——正是 Mari 與 Sugaar 相會引發暴風雨的日子。Sorginak 塗抹草藥油膏後飛行至聚會處，傳說中她們唸誦「越過所有灌木，穿過所有雲層」的咒語以獲得飛行之能。

### 巨石建造者

巴斯克民間傳說中，Sorginak 與 Lamiak（水精靈）、Jentilak（巨人族）共同建造了巴斯克地區的巨石墓（dolmen）與石圈。這些新石器時代至青銅時代的巨石建築在神話中被解釋為女巫在一夜之間完成的工程——若在黎明前未完成，建造者將化為石頭。此母題與北歐、凱爾特神話中的巨人建築傳說形成平行，但巴斯克版本賦予了女巫而非巨人建造者的角色。

### 黑貓變形

Sorgin 最著名的變形能力是化為黑貓。一則經典故事描述：一位婦女每夜在廚房紡紗，同時一隻黑貓定時出現在窗邊。丈夫起疑後偽裝為妻子留守廚房，當黑貓出現時以棍棒擊打——隔日鄰居婦女手臂骨折，村民因此確認她是 Sorgin。這則故事的深層結構揭示了歐洲巫術信仰中「動物化身」與「替代受傷」的普遍邏輯——傷害動物的形態等同於傷害變形者本人，與北歐的 hamrammr（靈魂形態）概念一致。

### 扎加拉穆爾迪審判的歷史創傷

1610 年，西班牙宗教裁判所在 Logroño 對扎加拉穆爾迪（Zugarramurdi）的 Sorginak 進行了大規模審判。根據審判記錄，數百名被指控的女性承認參加 akelarre、崇拜黑山羊 Akerbeltz、以及以草藥害人。雖然現代學者認為這些認罪是在酷刑下取得的，但這次審判永久地改變了巴斯克女巫的形象——從 Mari 的神聖代理人轉變為魔鬼的同夥。Gustav Henningsen 的研究指出，扎加拉穆爾迪事件是歐洲女巫恐慌中最具文獻記錄的案例之一，保存了完整的審判檔案與被告供詞（Henningsen 1980）。

## 跨文化對應

| 文化 | 對應存在 | 共通點 |

| **義大利** | Strega / Strix | 詞源同為夜行鳥；草藥知識；夜間飛行聚會 |

| **凱爾特** | Cailleach / Bean Feasa | 智慧女性；草藥治療；巨石關聯 |
| **日耳曼** | Hexe / Weisse Frau | 飛行掃帚；星期五聚會（Blocksberg） |
| **斯拉夫** | Baba Yaga / Vedma | 林中孤屋；飛行臼／掃帚；智慧考驗 |

## 相關神祇與存在

- **Mari**（大地女神）——Sorgin 的主人與原型（Mari 被稱為 Anbotoko Sorgina）
- **Akerbeltz**（黑山羊）——akelarre 中的儀式主導者，被基督教等同於魔鬼
- **Lamiak**（水精靈）——常與 Sorginak 混淆，均與巨石建造傳說相關
- **Etsai**（惡魔）——基督教化後 Sorgin 被認為服從 Etsai
