````markdown
# Mythos Atlas: Gods of Land and Lore — Game Design Document

> **Version:** 0.1 (Draft)
> **Genre:** 4X Turn-Based Strategy
> **Target Engine:** Godot 4
> **Core Inspiration:** Sid Meier's Civilization VI, Endless Legend, Humankind

## Design Philosophy

Mythos Atlas is a 4X strategy game where players lead a mythological civilization through ages, wielding their native pantheon's power while discovering the shared mythic heritage of humanity.

**Three Pillars:**
1. **Mythos Over Might** — Divine favor is as important as military strength
2. **Cross-Cultural Discovery** — Meeting other civilizations reveals shared mythic roots (syncretism mechanic)
3. **Living Mythology** — Mythic quests from 150+ analysis articles create dynamic narrative events

## Core Loop

Each turn consists of:

1. **Edict Phase** — Set civ-wide policies (mythos focus, production priority, research direction)
2. **Movement Phase** — Move units on hex map (sequential by initiative)
3. **Action Phase** — City production, tech research, diplomacy, unit actions
4. **Divine Phase** — Pantheon favor accumulates; gods may grant boons or demand tributes
5. **Event Phase** — Mythic quests, global events, random narrative encounters
6. **End Turn** — Yields collected, timers advance, era progress calculated

## Turn Structure Detail

| Phase | Player Actions | AI Actions |
|-------|---------------|------------|
| Edict | Set 1-3 policy slots | Adjust priorities based on strategy |
| Movement | Move units, attack, explore | Pathfind, engage |
| Action | Queue buildings, choose tech, trade | Queue buildings, research, trade |
| Divine | Invoke god abilities, spend favor | Auto-cast based on situation |
| Event | Respond to mythic quest choices | Scripted responses by personality |
| End Turn | Review yields, confirm | Process simulation |

## Victory Conditions

### 1. Conquest Victory
Control all original capitals **OR** eliminate all other civilizations.

### 2. Mythos Victory (Culture)
Generate enough cumulative Mythos Influence to trigger a "Pantheon Ascension" — your civilization's mythos becomes the dominant world narrative. Threshold: accumulate Mythos Influence equal to 150% of all other civs' combined Culture output.

### 3. Knowledge Victory (Science)
Complete the "Cosmic Truth" tech chain (final tier of the 28-theme tech tree) by researching all ultimate technologies, then build the "Axis Mundi" project.

### 4. Pantheon Victory (Religion)
Your chosen pantheon's 3 patron gods all reach max Favor level (Divine Rank 5), and your state religion is practiced in 60%+ of all cities across all civilizations.

## Era / Age Progression

Eras are defined from `_catalog.json` timeline data:
- **Age of Stone** (pre-history) — Ancient era, basic units
- **Age of Bronze** (early civilizations) — City-states, first techs
- **Age of Iron** (empires) — Classical civs, writing
- **Age of Faith** (post-classical) — Organized religion, mythos focus
- **Age of Discovery** — Cross-cultural contact, syncretism
- **Age of Mythos** (endgame) — Pantheon ascension, cosmic truth

Each era transition triggers a "World Age" event drawn from `analyses/world-ages-cosmic-cycles-comparative.md`.

## Scale

- **Map:** 80×50 hex grid (standard), 60×36 (small), 100×64 (large)
- **Turns:** 500 standard pace
- **Players:** 2-8 (human + AI), plus up to 12 minor "city-states" from thinner cultures
- **Units:** 20+ unit types per civ, 3 unique per civ from pantheon
````

```markdown
# Civilization Design Principles

## Data Source
Each civilization is defined by its entry in `_catalog.json`. The following fields map to game mechanics:

| Catalog Field | Game Mechanic |
|--------------|---------------|
| `name` / `name_en` | Civ display name |
| `region` | Starting biome, adjacency bonuses |
| `era` | Starting era, tech unlocks |
| `sources` | Civilopedia entries, unique research bonuses |

| `creation` | Pantheon origin story (unlockable lore) |
| `flood` | Mythic disaster immunity or bonus |
| `pantheon` | Available patron gods (pick 3 per game) |
| `stories` | Quest chain material |
| `timeline.start_year/end_year` | Age progression pace |
| `timeline.periods` | Era flavor text, transition bonuses |

## Civilization Data Contract

Each civ markdown file must specify:
1. **Identity** — Name, region, era range
2. **Unique Ability** — Derived from the civ's core mythic motif

   - Active Ability (costs Favor)
   - Passive Bonus (always active)
4. **Unique Unit** — Mythic creature or hero from `stories/`
5. **Unique Infrastructure** — Sacred site or monument
6. **Starting Bias** — Preferred terrain
7. **Agenda** — AI personality derived from mythic ethos
8. **Quest Chain** — 3 mythic quests from `stories/`
```

```markdown
# Resource System

## Five Core Resources

| Resource | Icon | Source | Primary Use |
|----------|------|--------|-------------|
| **Mythos** (Faith) | 𓃥 | Temples, Pantheon, Quests, Events | Invoke god abilities, recruit heroes, mythic quests |
| **Knowledge** (Science) | ☀ | Libraries, Academies, Great Scientists | Tech research, civic policies |
| **Production** | ⚒ | Mines, Forests, Workshops | Build units, buildings, wonders |
| **Gold** | � | Trade routes, Markets, Commerce | Unit maintenance, bribes, purchasing |
| **Food** | 🌾 | Farms, Pastures, Fishing Boats | City growth, unit healing |

## Secondary Resources

| Resource | Source | Use |
|----------|--------|-----|
| **Divine Favor** | Pantheon devotion, quest completion | Activate god abilities (per-god pool, max 100) |
| **Great Person Points** | Specialized districts | Generate Great Prophets, Scientists, Engineers, Generals |
| **Influence** | Culture buildings, trade routes | Diplomatic pressure, city-state levying |
| **Era Score** | Milestones, first discoveries, wonders | Trigger Golden Ages, era transitions |

## Resource Equations (Base)

```
City Food = Σ(Farm tiles) × (1 + 0.1 × pop) + Granary (bonus 2)
City Production = Σ(Production tiles) + Workshop bonus
Knowledge/turn = Population * 0.5 + Libraries + Academy adjacency
Gold/turn = Σ(Commerce tiles) * trade_route_multiplier
Mythos/turn = Σ(Temple devotion output) + Pantheon synergy bonus
```

## Mythos Favor Generation

Mythos (the game's distinct resource) generates from:
- **Base:** +1 per city with a Temple
- **Devotion:** +1 per population following your pantheon
- **Syncretism:** +2 per active trade route with a civ that shares a mythic parallel
- **Quest Reward:** +5-20 per mythic quest completed
- **Great Prophet:** +3 per turn when assigned to a city
```

```markdown
# Mythos System

## Core Concept
Mythos is the game's unique "faith with flavor" resource. It represents how deeply your civilization's mythological worldview permeates its culture, politics, and military.

## Mythos Generation

```
Base Mythos = Σ(cities with Temple district) × 1
Devotion Bonus = Σ(population following your pantheon) × 0.5
Syncretism Bonus = Σ(trade routes to civs sharing parallels) × 2
Great Prophet = +3 per assigned city
Quest Rewards = +5 to +20 flat per completion
```

## Divine Favor

Each patron god has an individual Favor pool (max 100 Favor per god).

**Favor generation per god:**
- +2/turn base if Temple district exists
- +1/turn per Holy Site adjacency
- +5 per successful action aligned with god's domain (e.g., Athena → researching a tech)
- +10 per mythic quest completion aligned with god

**Favor expenditure:**
- **Passive Blessing (5 Favor/turn sustained):** Small yield bonus while active
- **Active Ability (30 Favor once):** God's unique active power
- **Divine Intervention (50 Favor once):** Emergency effect (e.g., instant wall repair, unit heal)
- **Summon Mythical Unit (40 Favor once):** Spawn a god-specific mythical unit

## Pantheon State Machine

```
IDLE → (favor >= 10) → BLESSING_ACTIVE → (ability used) → COOLDOWN → IDLE
         ↘ (favor >= 30) → ABILITY_AVAILABLE → (ability used) → COOLDOWN → IDLE
         ↘ (favor >= 50) → INTERVENTION_AVAILABLE
```

## God Displeasure
If Favor accumulates unspent at max for 5+ turns, the god may:
- Demand a tribute (gold, units, or a city's production for 5 turns)
- Withhold bonus for 10 turns
- In extreme cases, send a mythic disaster (e.g., Poseidon → tsunami)
```

```markdown
# Engine Choice: Godot 4

## Comparison

| Criteria | Godot 4 | Unity 6 | Unreal 5 |
|----------|---------|---------|----------|
| License | MIT (free) | Runtime fee per install | 5% royalty >$1M |
| 2D/3D Hybrid | Native 2D + 3D | Good | Overkill for 4X |
| Turn-based logic | GDScript async/await | C# Task | C++/BP heavy |
| Hex grid support | Built-in TileMap layers | Tilemap + custom | Blueprint heavy |
| Modding support | .pck file loading | AssetBundle | Modding framework |
| Linux build | Native | Good | Native |
| Community 4X templates | Growing (no mature toolkits) | Mature (Civ-like clones) | Mostly FPS/TPS |
| Learning curve | Low | Medium | High |
| File size | ~50MB | ~200MB | ~10GB+ |

**Recommendation:** Godot 4 for a turn-based 4X game because:
1. TileMapLayer nodes with hex grids are first-class
2. GDScript signals perfectly match the event-driven turn structure (Edict→Movement→Action→Divine→Event)
3. No license fees — critical for long development timeline
4. .pck modding allows community content expansion
5. Linux-native build (server hosting, Steam Deck)

## Potential Challenges
- No built-in pathfinding for large hex grids (will implement A* with custom heuristic)
- No built-in diplomacy AI (will use utility AI with weighted scoring)
- Resource loading for 44+ civs (will use lazy-loading pattern)
```
