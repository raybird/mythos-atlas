# 文明設計原則

## 資料來源
每個文明由其 `_catalog.json` 中的條目定義。以下欄位映射到遊戲機制：

| 目錄欄位 | 遊戲機制 |
|----------|---------|
| `name` / `name_en` | 文明顯示名稱 |
| `region` | 起始生物群落、鄰接加成 |
| `era` | 起始時代、科技解鎖 |
| `sources` | 文明百科條目、獨特研究加成 |
| `motifs` | 此文明可用的獨特神話任務 |
| `parallels` | 與共享平行的文明外交加成 |
| `creation` | 萬神殿起源故事（可解鎖傳說） |
| `flood` | 神話災難免疫或加成 |
| `pantheon` | 可用的守護神（每局選 3 位） |
| `stories` | 任務鏈素材 |
| `timeline.start_year/end_year` | 時代進程節奏 |
| `timeline.periods` | 時代風味文字、過渡加成 |

## 文明資料契約

每個文明 markdown 檔案必須指定：
1. **身份** — 名稱、區域、時代範圍
2. **獨特能力** — 源於文明的核心神話母題
3. **守護神** — 來自 `gods/` 目錄的 3 位可選神祇，每位具有：
   - 神聖領域（映射到產出加成）
   - 主動能力（消耗恩寵）
   - 被動加成（始終生效）
4. **獨特單位** — 來自 `stories/` 的神話生物或英雄
5. **獨特基礎設施** — 聖地或紀念碑
6. **起始偏好** — 偏好地形
7. **議程** — 源於神話精神的 AI 人格
8. **任務鏈** — 來自 `stories/` 的 3 個神話任務
