# 英雄系統

## 招募方式
英雄通過完成神話任務線解鎖。每個文明有 3 條任務鏈，每完成一條解鎖一位英雄。

## 英雄特性
- 英雄是獨立單位不可量產
- 初始 3 級（相較於普通單位的 1 級）
- 擁有獨特名稱和視覺外觀
- 可透過戰鬥和任務升級，最高 10 級
- 死亡後可在 20 回合後重生

## 英雄技能樹
| 等級 | 技能池（選 1） |
|:----:|---------------|
| 3 | 領導力（相鄰單位 +3 戰鬥力）／先攻（首次攻擊 +10 戰鬥力） |
| 5 | 神聖祝福（每回合 +2 HP治療）／百戰（擊殺後恢復 50 HP） |
| 7 | 傳奇（相鄰單位經驗 +50%）／不死（首次死亡不消耗） |
| 10 | 神化（轉變為神話單位，獲得 +10 永久戰鬥力） |
