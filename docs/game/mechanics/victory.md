# 勝利條件

## 1. 征服勝利
控制所有原始首都或消滅所有其他文明。

## 2. 神話勝利
累積 Mythos 影響力達到觸發「萬神殿飛升」。你需要使你的 Mythos 影響力累積達到所有其他文明文化輸出總和的 150%。

## 3. 知識勝利
研究完第 6 層全部 3 個終極科技，然後建造「軸心世界」奇觀項目。

## 4. 萬神殿勝利
你的 3 位守護神全部達到最高恩寵等級（神階 5），且你的國教在全世界 60% 以上城市中傳播。

## 時代分數
當某文明距離勝利條件最近時會觸發「危機時代」，其他文明獲得針對該文明的加成：
- +5 戰鬥力對抗領先文明
- 間諜行動對領先文明快 50%
- 可形成聯合陣線
