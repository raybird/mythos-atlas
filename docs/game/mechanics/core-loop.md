# 核心機制：回合結構

## 每回合階段

### 1. 敕令階段
玩家可設定 1-3 個政策槽（取決於時代與科技），影響文明產出：

| 敕令槽 | 解鎖條件 | 效果範例 |
|--------|---------|---------|
| 軍事專注 | 青銅工藝 | +2 生產力、-1 文化 |
| 神聖專注 | 神廟 | +2 神話、-1 科學 |
| 經濟專注 | 貨幣 | +3 金幣、-1 食物 |
| 文化專注 | 文字 | +2 文化、-1 生產力 |
| 探索專注 | 造船 | +1 移動力、-1 神話 |

### 2. 移動階段
按單位速度順序移動。所有玩家同時進行（同步回合）或依序（熱座）。

### 3. 行動階段
包括不消耗移動力的行動：城市生產、科技選擇、外交互動、單位升級。

### 4. 神聖階段
- 恩寵累積換算
- 心懷不滿的神祇可能提出要求
- 玩家可施放被動祝福或主動能力

### 5. 事件階段
- 神話任務進度檢查
- 全球事件觸發（時代過渡、神話災難）
- 隨機遭遇

### 6. 結束回合
- 產出收集與顯示
- 時代分數計算
- 文明存檔
