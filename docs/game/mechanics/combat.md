# 戰鬥系統

## 戰鬥公式

傷害 = 30 x e^(戰鬥力差 / 25) / (1 + e^(戰鬥力差 / 25))

其中戰鬥力差 = 攻擊方CS - 防禦方CS + 修正值
結果為對防禦方HP的傷害百分比（範圍 ~5% 至 ~95%）。

## 地形修正

| 地形 | 防禦加成 | 說明 |
|------|:--------:|------|
| 平原 | 0 | 無加成 |
| 丘陵 | +3 | 遠程攻擊命中率 -10% |
| 森林 | +3 | 騎乘單位 -3 戰鬥力 |
| 叢林 | +5 | 視線受阻 |
| 河流（攻擊方跨河） | -5 | 攻擊方跨河攻擊 |
| 山脈 | 不可進入 | — |
| 城市 | +5 | +5 每層城牆 |
| 要塞 | +7 | 改良設施 |

## 單位晉升

| 等級 | 所需XP | 效果範例 |
|:----:|:------:|---------|
| 1 | 0 | 基礎 |
| 2 | 15 | +3 戰鬥力 |
| 3 | 30 | 特殊晉升選擇 |
| 4 | 60 | +5 戰鬥力 |
| 5 | 100 | 精英晉升（獨特效果） |

## 特殊戰鬥規則
- **夾擊：** 每個友方相鄰單位提供 +2 戰鬥力（上限 +10）
- **支援：** 遠程單位攻擊相鄰友軍目標時無誤傷
- **掠奪：** 近戰單位可掠奪改良設施，獲得小額金幣 + 移除改良
- **攻城：** 轟炸類單位可直接攻擊城市HP
