# 外交系統

## 關係等級

| 等級 | 數值範圍 | 效果 |
|------|:--------:|------|
| 聯盟 | 75-100 | 開放邊境、聯合戰爭、科技共享 |
| 友好 | 50-74 | 開放邊境、貿易加成 |
| 中立 | 25-49 | 基本貿易 |
| 冷淡 | 0-24 | 無法締約 |
| 敵對 | -25 以下 | 自動宣戰 |

## AI 外交人格
每個文明依其「AI 議程」（在文明文件中定義）有不同的權重偏好。例如：
- 天命（中國）：重視文化產出高的文明
- 黃金中庸（希臘）：重視平衡發展
- 永恆秩序（埃及）：重視忠誠與穩定
- 光榮戰死（北歐）：重視軍事實力
