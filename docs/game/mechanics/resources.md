# 資源系統

## 五種核心資源

| 資源 | 來源 | 主要用途 |
|------|------|---------|
| **神話 (Mythos)** | 神廟、萬神殿、任務、事件 | 召喚神祇能力、招募英雄、神話任務 |
| **知識 (Knowledge)** | 圖書館、學院、大科學家 | 科技研究、公民政策 |
| **生產力 (Production)** | 礦場、森林、工坊 | 建造單位、建築、奇觀 |
| **金幣 (Gold)** | 貿易路線、市場、商業 | 單位維護、賄賂、購買 |
| **食物 (Food)** | 農場、牧場、漁船 | 城市增長、單位治療 |

## 次要資源

| 資源 | 來源 | 用途 |
|------|------|---------|
| **神聖恩寵** | 萬神殿奉獻、任務完成 | 啟動神祇能力（每神獨立，上限 100） |
| **偉人點數** | 專業區域 | 產生大先知、科學家、工程師、將軍 |
| **影響力** | 文化建築、貿易路線 | 外交壓力、城邦招募 |
| **時代分數** | 里程碑、首個發現、奇觀 | 觸發黃金時代、時代過渡 |

## 基礎資源計算

每城食物 = 農場地格食物總和 x (1 + 0.1 x 人口) + 穀倉(額外 2)
每城生產力 = 生產力地格總和 + 工坊加成
每回合知識 = 人口 x 0.5 + 圖書館 + 學院鄰接加成
每回合金幣 = 商業地格總和 x 貿易路線倍率
每回合神話 = 各神廟奉獻輸出 + 萬神殿協同加成

## 神話恩寵生成

神話是遊戲的獨特資源，來自：
- 基礎：每座有神廟的城市 +1
- 虔誠：追隨你萬神殿的每人口 +1
- 融合：與共享神話平行的文明每條活躍貿易路線 +2
- 任務獎勵：每次完成神話任務 +5 至 +20
- 大先知：指派到城市時每回合 +3
