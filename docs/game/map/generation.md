# 地圖生成

## 坐標系統
六角格軸向坐標 (axial coordinates)：q (行)、r (列)

## 地形生成
雙層噪聲圖：
1. 溫度層 — 決定基礎生物群落（赤道=沙漠/叢林，極地=雪地/凍原）
2. 降水層 — 決定植被特徵（高降水=森林/叢林，低降水=平原/沙漠）

## 文明起始位置
依文明起始偏好生成：
1. 篩選符合文明"區域"的地圖區域
2. 在該區域內搜尋符合"起始偏好"地形的地格
3. 文明間最小間隔 8 格

## 神話特徵放置
- 世界樹：地圖地理中心附近
- 冥界之門：地圖南北兩極附近
- 聖山：最高海拔的山脈連線上
- 原始之水：地圖中央海洋區域
