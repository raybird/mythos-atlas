# 主畫面佈局

## 畫面區域（1920x1080 參考）

```
+----------------------------------------------------------------+
| [回合][時代][文明名]    [神話][知識][生產][金幣][食物]         | 頂欄
+-----------------------------------+----------------------------+
|                                   |                            |
|                                   |  小地圖                     |
|                                   |  (20% 畫面)                |
|     主要視口                       |                            |
|     (六角格等距網格)               +----------------------------+
|                                   |  活動單位面板               |
|                                   |  單位統計、行動             |
|                                   +----------------------------+
|                                   |  通知                       |
|                                   |  (任務、事件)               |
+-----------------------------------+----------------------------+
| [單位][城市][科技][萬神殿][外交][百科]                            | 底欄
+------------------------------------------------------------------+
```

## 頂欄元素
- 回合計數器 + 結束回合按鈕
- 時代指示器（含進度條）
- 資源條：5 核心資源及每回合增減
- 萬神殿恩寵：每位守護神目前/最大值（小型圖示）

## 底欄
- 快速行動按鈕（6）：單位列表、城市列表、科技樹、萬神殿、外交、百科
- 所選單位/地格資訊
- 小地圖切換
