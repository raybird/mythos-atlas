# 城市管理畫面

## 佈局

```
+------------------------------------------+
| 城市名稱  人口: X  忠誠: X%   產出概覽     | 頂欄
+------+-----------------------------------+
|      | 建築序列                           |
|      | [當前建築] ............ ████ 45%   |
| 市   | 隊列：[圖書館] [兵營] [+添加]      |
| 區   +-----------------------------------+
| 地   | 公民分配                           |
| 圖   | 未分配公民: 3                      |
|      | 農田 ●● 礦山 ● 商業 ● 神學 ●     |
|      +-----------------------------------+
|      | 產出詳細                           |
|      | 食物: +12/回合 (庫存: +5)         |
|      | 生產力: +8/回合                   |
|      | 神話: +2/回合 (來自神廟)          |
+------+-----------------------------------+
| [購買] [轉換生產] [派遣建造者] [關閉]      | 底部
+------------------------------------------+
```

## 功能
- 查看城市產出細節
- 序列建築生產
- 分配公民到地格
- 一鍵購買（花費金幣完成建築）
- 轉換建築為項目（神話項目、偉人項目）
