# 時代進程系統

## 時代分數

時代分數通過以下方式獲得：
| 行動 | 分數 |
|------|:----:|
| 建立第一個城市 | +3 |
| 首次遇見文明 | +5 |
| 首次建造區域 | +3 |
| 首次研究該時代科技 | +2 |
| 建造世界奇觀 | +10 |
| 完成神話任務 | +5 |
| 消滅獨立勢力 | +3 |
| 首次達到人口 10 | +5 |

## 時代狀態

| 時代 | 分數閾值 | 效果 |
|:----:|:--------:|------|
| 黑暗時代 | < 時代標準 50% | -20% 產出，但 +30% 軍事產出 |
| 普通時代 | 50%-100% | 無修正 |
| 黃金時代 | > 標準 150% | +20% 全部產出、+1 移動力 |
| 英雄時代 | > 標準 200% | +30% 全部產出、+2 移動力、免費英雄 |

## 時代過渡
達到時代分數閾值後，觸發時代過渡：
1. 世界時代事件（取自 analyses/）
2. 在黃金/英雄時代時，可選擇一個「忠誠度」加成（持續到下一時代過渡）
3. 所有文明的戰爭疲勞重置
