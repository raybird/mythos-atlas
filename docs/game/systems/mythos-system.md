# 神話系統

## 核心概念
Mythos 是遊戲中獨特的「信仰加風味」資源。代表你的文明神話世界觀滲透到文化、政治和軍事的深度。

## Mythos 生成

基礎 Mythos = 有神廟區域的城市 x 1
虔誠加成 = 追隨萬神殿的人口 x 0.5
融合加成 = 與共享平行的文明貿易路線 x 2
大先知 = 指派城市每回合 +3
任務獎勵 = 每次完成 +5 至 +20

## 神聖恩寵

每位守護神有獨立的恩寵池（上限 100）：

恩寵生成：
- 若有神廟區域，+2/回合
- 每層聖地鄰接，+1/回合
- 每次與神祇領域一致的行動 +5（如雅典娜→研究科技）
- 每次與神祇相關的神話任務完成 +10

恩寵消耗：
- 被動祝福（5 恩寵/回合持續）：小型產出加成
- 主動能力（30 恩寵一次性）：神祇獨特能力
- 神聖干預（50 恩寵一次性）：緊急效果
- 召喚神話單位（40 恩寵一次性）：神祇特定神話單位

## 神祇不滿
如果恩寵在滿池未使用超過 5 回合，神祇可能：
- 要求進貢
- 暫停加成 10 回合
- 極端情況下降下神話災難
