# 全球事件系統

## 事件類型

| 事件 | 來源 | 觸發條件 | 效果 |
|------|------|---------|------|
| 世界洪水 | analyses/flood-myths-geological-origins.md | 某文明解鎖第 4 層科技 | 全地圖海岸洪水、沿海改良受損 |
| 諸神黃昏 | analyses/world-ages-cosmic-cycles-comparative.md | 某文明進入第 6 層科技 | 全域戰爭加成、神話產出翻倍 |
| 磁極偏移 | analyses/magnetic-pole-shift.md | 知識勝利即將達成 | 地圖重組、文明被迫遷移 |
| 星空異變 | analyses/star-myths.md | 隨機（每時代一次） | 神話產出 +50% 持續 10 回合 |
| 神話覺醒 | analyses/sacred-mountains.md | 首次發現聖山 | 山脈地格 +2 神話（永久） |

## 事件規則
- 每個事件在一局遊戲中只發生一次
- 事件可以經由科技預測
- 部分事件可以被文明行動阻止或延緩
- 事件影響所有文明（不分敵我）
